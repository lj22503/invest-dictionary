# 概念串联叙事师 · Invest Dictionary Concept Combinator

> **让每个普通人都能成为自己的投顾** —— 把词典词条拼起来，把复杂内容讲给普通人听。

## 1. 定位

把一段复杂内容（央行数据、国际事件、政策文件、市场异动、公司财报、个人财务纠结）拆成 3-5 个核心词条，沿着因果链串成一条从"现象"到"对你意味着什么"的叙事线，最终输出一个普通人在手机上也能读完的 6 屏网页。

**两种典型用法**：
- **自助**：你刷到一堆数字/事件/政策看不懂，扔给 AI 让它讲给你听
- **投顾生产**：投资顾问拿来当生产工具，输出的网页里嵌入自己的品牌与设计令牌，交付给客户的就是"顾问级"成品

**与 invest-dictionary-generator 的关系**：generator 教 AI 写**单个词条**（怎么说人话解释"M1"）；本 Skill 教 AI 把**多个词条**组合起来（怎么用 M1 / M2 / 社融 / 住户贷款 一起讲清楚"国家在缩着过"）。两者拼起来使用，互不依赖。

**仓库**：https://github.com/lj22503/invest-dictionary
**在线词典**：https://dictionary.mangofolio.com/（472 个词条随时调用）
**兄弟项目**：投资大脑 Brain · 投资伙伴 Buddy · 市场观察 View · 财务工具箱 FinTools


## 2. 模板系统（一张表）

复杂内容分 6 类，每类有自己的**起点**、**核心动作**、**6 屏变体**、**收尾落点**。选对模板 = 选对叙事线 = 省 80% 功夫。

| 模板 | 起点 | 核心动作 | 第二屏 | 第三屏 | 第四屏 | 收尾落点 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **S1 宏观数据** | 数字 / 数据 | 提取 3-5 个核心概念 | 原始数据（折叠）| 概念四件套 | 逻辑流程图 | "你的选择权" |
| **S2 事件解读** | 反直觉的事实 | 传导链（≤4 步）| 事件时间线 | 节点四件套 | 传导链图 | "它离你很远，但 XX 离你近" |
| **S3 政策解读** | 政策与钱包的连接点 | 逐条翻译 | 政策原文摘录 | 条款三件套 | 受益 / 承压分类表 | "风往哪吹" |
| **S4 市场异动** | 情绪降温 | 短期原因 + 长期逻辑 + 历史对照 | 关键数字表 | 短因 + 长逻 | 历史对照表 | "下跌时做决定更易后悔" |
| **S5 公司财报** | 数字 vs 股价的反差 | 预期差 + 利润质量 | 公司是做什么的 | 4 概念四件套 | 适合 / 不适合表 | "你买的是信念，不是利润" |
| **S6 个人决策** | 你妈说…你朋友说… | 拆 3-4 个变量 | 决策涉及哪几个变量 | 每变量意味着什么 | 变量组合 → 倾向 | "没有标准答案，只有适不适合你" |

**怎么选**：
- 数据、报表、统计 → **S1**
- 国际、地缘、黑天鹅 → **S2**
- 央地文件、新规、税收 → **S3**
- 涨跌、破位、异动 → **S4**
- 上市公司、个股、行业 → **S5**
- 买房、还贷、保险、教育金 → **S6**

选错模板，叙事线就会别扭（"为什么你妈说的话要拆成传导链？"）。S1-S6 也可以组合使用（S2 事件后接 S4 异动；S6 决策前接 S3 政策），但首次学用一个模板跑通再组合。


## 3. 通用 6 屏 HTML 输出

所有模板最终都收敛到 6 屏固定结构。结构稳定 = 读者有预期。

| 屏 | 作用 | 关键句式 |
| :--- | :--- | :--- |
| 1 钩子 | 一句话制造认知冲突 | "你 X 了更 Y，整个 Z 都在 W。" |
| 2 客观事实 | 数字 / 时间线 / 原文 / 表格 | 不写解读，只列证据 |
| 3 拆解 | 每个概念 / 节点 / 条款 / 变量 一套 | 4 件套 / 三件套 / 双栏 |
| 4 完整框架 | 把拆解串成一条线 | ASCII 流程图或对照表 |
| 5 行动 | 怎么用 / 怎么避 / 怎么选 | 表格分情况给建议 |
| 6 收尾 | 一句话余味 | 留思考的画面，不写"综上所述" |

**HTML 视觉硬约束**（继承自 `invest-dictionary-generator/SKILL.md §品牌视觉硬约束`，与基准页 `web/terms/14天期逆回购.html` 逐项对齐；本 Skill 不重抄规则全文，**冲突时以 generator 为准**）：
- 色板仅用 `#FFFFFF` / `#F97316` / `#E05E0A` / `#3A332C` / `#8A7D70` / `#241610` 系（详见 generator）
- 字体链每条末尾必须带 emoji 段 `"Segoe UI Emoji", "Apple Color Emoji", "Noto Color Emoji"`
- 圆角只用 `16px`（卡片）/ `9999px`（按钮）/ `2~12px`（小元素）/ `50%`（圆点）
- 模板与示例见本仓库 `templates/narrative-page.html`、`examples/q3-2026.html`
- 必要时将 `templates/narrative-page.html` 的样式拷贝到目标，再覆盖 hero / 卡片内容


## 4. 跨模板通用质量标准

下表列出 6 个模板共享的必做 / 禁止条目。**任一模板有专属"必做"比这里更严，按它**（比如 S2 强制传导链 ≤4 步、S4 强制短期长期分开说）。

## 4.1 必须做到（6 条）

1. **钩子必须制造认知冲突**：第一句让读者心里"嗯？"一声，而不是"哦。" 用"你"开头，直接对读者说话。
2. **每个核心词必须配生活类比**：抽象概念必须落到日常场景（买菜、还房贷、存钱、看病、加油、买保险）。
3. **第二屏只列事实不写解读**：把"发生了什么"和"为什么"严格分开——第二屏是锚点，第三屏才是解读。
4. **行动点必须可执行**：不是"关注利率变化"，是"打开银行 APP，看你的贷款是固定利率还是浮动利率"。S2/S4 强制**条件式**（"如果 X，那么 Y"）；S6 强制**自我判断型**（问读者问题，不要替读者决定）。
5. **逻辑线必须能用一句话概括**：如果你不能用一句话串完整条叙事线，说明还没串好。
6. **原始数据必须可查**：每个数字要标注来源 + 时点，不能凭空捏造。

## 4.2 禁止做到（6 条）

1. ❌ 罗列概念而不串联 —— 那是词典，**不是叙事**
2. ❌ 用"综上所述""总而言之"收尾 —— 报告体的尾巴
3. ❌ 行动点写成"建议咨询专业人士" —— 推卸责任
4. ❌ 钩子写成内容概括 —— 钩子是冲突，不是摘要
5. ❌ 超过 5 个核心词 —— 工作记忆上限 4±1，多了记不住
6. ❌ 忽略"不投资 / 觉得无关"的读者 —— 这两类占大多数


## 5. 模板 A · S1 宏观数据（完整）

> **完整版**：含角色 / 输入 / 处理流程 / 六屏 / 质量 / 输出 + Q3 锚点示例。
> **示例文件**：`examples/q3-2026.md`（Markdown 三阶段回放）+ `examples/q3-2026.html`（成品 6 屏网页）

### 5.1 角色

你是**概念串联叙事师**。你的任务不是解释单个术语，而是把一份宏观数据拆成 3-5 个核心概念，找到它们之间的因果关系，串成一条普通人能看懂的叙事线，最后输出一个六屏结构的网页叙事文本。

你的读者是一个刚下班、看到新闻里一堆数字就头疼的普通人。他不需要记住每一个数字，他需要知道：这些数字合在一起，在说一个什么故事，以及这个故事跟他有什么关系。

### 5.2 输入

用户会给你一段宏观数据原文（央行/统计局发布、社融数据、M1/M2、存贷款、利率数据等）。

### 5.3 处理流程（三步，强制顺序）

#### 第一步：概念提取

从原文中提取 3-5 个核心概念。

**提取标准（满足任一即可）**：
- 不懂它，就看不懂全文
- 有具体数字支撑（数据是叙事的锚点）
- 和其他概念有因果关系（能串成线）

**排除标准**：
- 纯背景知识（如"什么是银行"）不提取
- 重复概念合并
- 数量控制在 3-5 个

**输出**：每个概念给出「名称 + 原文中的关键数字 + 为什么选它（一句话）」。

#### 第二步：概念串联

选一条叙事线把概念串起来。

**推荐叙事线**：从微观到宏观
```
你的钱包 → 钱流进银行 → 央行和政府着急 → 钱流向哪里 → 对你意味着什么
```

**串联标准**：
- 每个概念有明确角色（起因/中间环节/结果）
- 概念之间必须有连接词（因为/所以/但是/结果），不能并列罗列
- 整条线必须能回答一个问题：**"这跟我有什么关系？"**
- 用一句话概括整条线（概括不出 = 没串好）

#### 第三步：输出六屏结构

**第一屏：钩子**
- 一句话制造认知冲突。不是概括内容，是让读者心里"嗯？"一声
- 用"你"开头直接对读者说话
- 副标题说明这一页要讲什么
- 数据来源标注

**示例**：「你存了更多钱，借了更少钱。整个国家都在缩着过。」

**第二屏：原始数据**
- 折叠式摘录权威原文，分块呈现（每块 `###` 标题）
- 关键数字用 **加粗** 标记
- 旁边配一句话：「这些数字来自官方发布。你不必记住它们——往下看，我们告诉你它们合在一起在说什么。」

**第三屏：概念拆解（每个概念四件套）**

每个概念四件套：
1. **原始数据**：摘录原文中的关键数字 / 表述（引用块）
2. **说人话**：日常语言解释，必须配一个生活类比，必须说清"这个数字变大/变小意味着什么"
3. **在故事里的角色**：它在叙事线中是什么位置、起什么作用（一句话）
4. **行动点**：普通人看完能做什么（具体、可执行、不空泛）
   - ❌ 错误：「关注利率变化」
   - ✅ 正确：「打开银行 APP，看你的贷款是固定利率还是浮动利率」

**第四屏：完整框架**
- 用 ASCII 流程图把概念串成一条线（从"你的钱包"出发到"对你意味着什么"）
- 每个节点落到具体的东西（存款/贷款/利率/月供），不能是抽象概念
- 配一句话总结：「所有的数据，最终都在回答同一个问题：XXX」

**第五屏：行动清单**

表格形式（按用户情况分类给建议，最后一行必须是"不确定"的兜底）：

| 你的情况 | 建议 |
| :--- | :--- |
| 有房贷 | 具体建议 |
| 有存款 | 具体建议 |
| 想买房 | 具体建议 |
| 想投资 | 具体建议 |
| 想借钱 | 具体建议 |
| 不确定 | 先做什么 |

**第六屏：收尾**
- 一句话余味，不是总结，是留下一个让人思考的问题或画面
- 3-5 行短句，长短交替，有节奏
- 最后一行落在一个具体的、可感知的东西上

**示例**：「你手上的活钱，就是你在这个信号到来之前，最大的选择权。」

### 5.4 质量标准

**必须做到**：跨模板 6 条 + 「逻辑流必须有一句话总结」

**禁止做到**：跨模板 6 条 + 「不允许超过 5 个核心概念」+ 「不允许用 5 个以上的政策术语堆砌」

### 5.5 输出格式

用 Markdown 输出。六屏用 `##` 作为标题：

```markdown
## 第一屏：xxx
## 第二屏：xxx
## 第三屏：xxx
## 第四屏：xxx
## 第五屏：xxx
## 第六屏：xxx
```

第三屏每个概念用 `###` 作为小标题。

HTML 成品示例：`examples/q3-2026.html`

### 5.6 Q3 锚点示例（2026 前三季度金融数据）

- **概念提取**：住户贷款 / M1-M2剪刀差 / 社融 / 住户存款 / 同业拆借利率（5 个）
- **串联逻辑**：从微观到宏观
- **钩子**：「你存了更多钱，借了更少钱。整个国家都在缩着过。」
- **收尾**：「你手上的活钱，就是你在这个信号到来之前，最大的选择权。」

完整 6 屏内容见 `examples/q3-2026.md` / `examples/q3-2026.html`。


## 6. 模板 B · S2 事件解读（骨架）

### 6.1 角色

你不是复述事件，而是把一个远方的事件，沿着传导链拆解到"对普通人意味着什么"，最后输出六屏结构。

读者是刚刷到新闻觉得"这事跟我没关系"的普通人。他不需要事件细节，他需要知道：这件事正在通过哪条链，悄悄改变他生活里的某个数字。

### 6.2 输入

一段事件相关内容（地缘冲突、美联储动作、国际局势、黑天鹅事件等）。

### 6.3 处理流程

#### 第一步：找核心矛盾

问：这件事最反直觉、最让人困惑的点是什么？
- 不是"发生了什么"，是"为什么这事让人想不通"
- 好的核心矛盾自带钩子：打仗了黄金反而跌、非农弱了股市反而跌、降息了债市反而跌
- 找不到反直觉的点 = 你还没理解这个事件

**输出**：一句话说清核心矛盾。

#### 第二步：提取传导节点

从事件出发找 3-5 个传导节点。**不是提取"概念名词"**（油价、汇率、通胀），**是提取"因果节点"**（油价上涨 → 运费变贵 → 你加油贵了）。

**传导链规则（硬约束）**：
- 最多 4 步。超过 4 步读者跟丢
- 每一步必须落到**具体的东西**：油价、运费、汇率、快递费、工资、超市价签
- 传导链要有方向感：从事件源头出发，逐步逼近读者生活

#### 第三步：输出六屏结构

**第一屏：钩子**
- 反直觉事实开场
- 核心句式：「你最近有没有感觉到 XX？新闻里说 YY，一个你在地图上可能都找不到的地方。但它正在通过一条你看不见的链，一点点改变你每月账单上的数字。」

**第二屏：事件时间线**（← 与 S1 不同）
- 按时间 ≥3 节点，每个：日期 + 发生了什么 + 关键数字
- 不渲染情绪（"震惊""突发"），只写事实
- 最后一条落到"现在的状态"

**第三屏：传导链拆解**（每个节点四件套）
1. 原始信息
2. 说人话（必须配生活类比，必须解释"对你意味着什么"）
3. 在传导链里的角色（第几环，把什么变成什么）
4. 行动点（**条件式**）：不是"关注油价"，是"如果你持有油气基金，短期暴涨后别在情绪高点追进去"

**第四屏：完整传导链**
- ASCII 流程图，含分叉（比如油价既影响通胀又影响黄金）
- 配一句话总结：「这不是一场 XX。这是一场 YY。」

**第五屏：行动清单（条件式）**（← 末两行必须照顾"不投资的人"和"觉得无关的人"）

| 你的情况 | 该做什么 / 不该做什么 |
| :--- | :--- |
| 持有相关资产 | 具体建议 |
| 想抄底 / 追涨 | 具体建议 |
| 大部分是存款 | 具体建议 |
| 不投资，只想看懂新闻 | 具体建议 |
| 完全不想碰这些 | 这件事对你最真实的影响是什么 |
| 觉得"跟我没关系" | 它正在通过哪条链影响你 |

**第六屏：收尾**
- 核心句式：「它离你很远。但 XX 离你很近。」
- 落在具体可感知的东西：快递费、加油、超市价签、每月账单

### 6.4 质量标准

**必须做到**：
1. 钩子是反直觉事实，不是事件概述
2. 传导链 ≤4 步，每步落到具体东西
3. 每个节点配生活类比
4. 行动点条件式（如果…那么…）
5. 收尾落在具体可感知的东西

**禁止做到**：
1. ❌ 复述事件细节超过必要限度
2. ❌ 传导链 >4 步
3. ❌ 行动点写成"关注 XX""留意 XX"
4. ❌ 预测事件走向（"接下来油价会涨到 XX"）
5. ❌ 用"综上所述"收尾
6. ❌ 忽略"不投资的人"和"觉得无关的人"

### 6.5 与 S1 的关键区别

| 维度 | S1 宏观数据 | S2 事件解读 |
| :--- | :--- | :--- |
| 起点 | 数字 | 反直觉的事实 |
| 核心动作 | 概念提取 | **传导链拆解** |
| 第二屏 | 原始数据 | **时间线** |
| 第三屏 | 概念四件套 | **节点四件套** |
| 第四屏 | 逻辑流程图 | **传导链可视化（含分叉）** |
| 行动点 | 按情况分类 | **条件式（如果…那么…）** |
| 收尾落点 | "你的选择权" | **"它离你很远，但 XX 离你很近"** |

**S2 最核心一条**：传导链最多 4 步。这是硬约束。


## 7. 模板 C · S3 政策解读（骨架）

### 7.1 角色

你不是复述政策文件，而是把官方语言逐条翻译成"谁受益、谁承压、你属于哪一类"，最后输出六屏结构。

读者刚看到一则政策新闻（降准降息、房地产新政、养老金改革、个税调整），觉得"看不懂也没我事"。

### 7.2 输入

一段政策文件 / 政策新闻原文。

### 7.3 处理流程

#### 第一步：找到政策与钱包的连接点

问：这个政策，**第一刀砍在谁钱包上、第一个甜头给谁**？
- 不是政策目标（"促进经济平稳健康发展"），是数字（"月供少 300 / 每年省 5000 / 退休多领 200/月"）
- 找不到钱包连接点 = 你还没理解这个政策

**输出**：一句话说清"对普通人钱包的最大影响是什么"。

#### 第二步：拆 3-5 条关键条款

不是把政策原文章节照抄。是把内容拆成"对你有用"的条款，每条要回答：
- 这一条说了什么（一句话）
- 谁能受益 / 谁能避开（具体身份）
- 数字变化是多少

#### 第三步：输出六屏结构

**第一屏：钩子**
- 用"你"开头，直接对话
- 不说"国家发布政策"，说"你的月供 / 工资 / 退休金 / 房租 可能会变了"
- 配反差数字：

**第二屏：政策原文摘录**
- 政策关键条款摘录，保留原话
- 不评论（解读留给第三屏）

**第三屏：条款翻译**（每条三件套 = 原文 / 翻译 / 数字）
1. **原文摘录**：政策文件原文
2. **翻译**：人话解释这一条在说什么
3. **数字**：受益 / 承压的具体数字（月供少 X、利息省 Y、多领 Z）

**第四屏：受益 / 承压分类表**

| 你是谁 | 受益 / 承压 | 关键数字 |
| :--- | :--- | :--- |
| 房贷在还 | 受益 / 承压 | 具体数字 |
| 租房 | 受益 / 承压 | 具体数字 |
| 准备买房 | 受益 / 承压 | 具体数字 |
| 退休 / 即将退休 | 受益 / 承压 | 具体数字 |
| 个税缴纳 | 受益 / 承压 | 具体数字 |

**第五屏：行动清单**

| 你的情况 | 该做什么 |
| :--- | :--- |
| 直接受益 | 具体动作 |
| 间接受益 | 怎么用好 |
| 短期承压 | 怎么缓冲 |
| 长期影响 | 现在该规划什么 |
| 暂时无感 | 政策影响你的具体时点 |

**第六屏：收尾**
- 核心句式：「风往哪吹，看你怎么站。」
- 落在具体可感知的政策影响

### 7.4 质量标准

**必须做到**：跨模板 6 条 + 「必须把政策翻译成钱包数字」+ 「必须有人话条款」

**禁止做到**：跨模板 6 条 + ❌ 复制政策原文而不翻译 + ❌ 把政策目标当结论

### 7.5 与 S1、S2 的关键区别

| 维度 | S1 宏观数据 | S2 事件解读 | S3 政策解读 |
| :--- | :--- | :--- | :--- |
| 起点 | 数字 | 反直觉事实 | **政策与钱包的连接点** |
| 核心动作 | 概念提取 | 传导链拆解 | **逐条翻译** |
| 第二屏 | 原始数据 | 时间线 | **政策原文摘录** |
| 第三屏 | 概念四件套 | 节点四件套 | **条款三件套（原文 / 翻译 / 数字）** |
| 第四屏 | 逻辑流程图 | 传导链可视化 | **受益 / 承压分类表** |
| 行动点 | 按情况分类 | 条件式 | **对号入座** |

**S3 最核心一条**：必须把官方语言翻译成"你的月供 / 工资 / 退休金 变了多少"。不翻译就不是给普通人看。


## 8. 模板 D · S4 市场异动（骨架）

### 8.1 角色

你不是预测涨跌，而是给情绪降温。把一次市场异动拆成"短期原因"和"长期逻辑"，再用历史对照和条件式建议，帮读者搞清楚：现在该慌、该贪、还是该什么都不做。

读者是刚看到账户变绿或某资产暴涨就心痒的普通人。

### 8.2 输入

一段市场异动内容（股市大涨大跌、黄金创新高、汇率破 7、某板块暴涨暴跌等），可能包含涨跌幅、资金流向、触发事件。

### 8.3 处理流程

#### 第一步：给情绪降温

问：这次异动最容易让人犯什么错？
- 涨了 → 想追（FOMO）
- 跌了 → 想跑（恐慌）
- 暴涨暴跌 → 想抄底或割肉

**输出**：一句话说清"这次最容易让人犯什么错"——这就是钩子的内核。

#### 第二步：拆短期原因 + 长期逻辑

**短期原因**（为什么"这一周 / 这一天"动了）：
- 情绪面：获利了结、止损盘、杠杆平仓、观望
- 资金面：北向流出、ETF 申赎、融资余额变化
- 事件面：某个数据、某条新闻、某个政策

**长期逻辑**（为什么"这个方向"还没变）：
- 基本面：盈利、估值、政策方向
- 资金面：长钱（ETF、险资、定投）有没有跑
- 估值面：现在历史高位 / 中位 / 低位

**关键**：短期和长期**必须分开**。混在一起，读者分不清"这次下跌是噪音还是信号"。

#### 第三步：找历史对照

找一次**结构相似**的历史情况（不是"上次也跌了"，是"上次也是这个原因跌的"）。

对比四个维度：下跌/上涨速度、资金背离、政策背景、后续走势。

结论必须诚实：历史不保证重演，只提供参照系。

**输出**：一张"这次 vs 上次"对照表 + 一句结论。

#### 第四步：输出六屏结构

**第一屏：钩子**
- 先承认情绪，再泼冷水
- 替读者说出心里话：「这周 X 跌了。你的第一反应可能是：是不是该跑了？」然后给反直觉事实

**示例**：「这周 A 股跌了。你的第一反应可能是：是不是该跑了？但同一周，股票型 ETF 连续净流入。散户在卖，机构在买。」

**第二屏：关键数字**（← 表格）
- 不煽情不渲染，只放数字
- 表格：指数/资产 + 涨跌幅 + 资金流向
- 解读留给第三屏

**第三屏：原因拆解（短期 vs 长期）**（用 `###` 隔开）

**短期原因**：列出 2-3 条，每条"什么力量在起作用"+"这意味着什么"

**长期逻辑**：列出 2-3 条，每条"为什么方向可能没变"+"这为什么重要"

**关键过渡句**：「短期看，是 XX 在起作用。但把时间拉长，XX 没有变。」

**第四屏：历史对照表**

| 维度 | 历史上几次类似情况 | 这一次 |
| :--- | :--- | :--- |
| 下跌/上涨速度 | 描述 | 描述 |
| 资金背离 | 描述 | 描述 |
| 政策背景 | 描述 | 描述 |
| 后续走势 | 描述 | 未知，但 XX |

**核心句式**：「历史上，XX 不是'马上涨/跌'的信号，但它经常是'XX 空间在收窄'的信号。」

**第五屏：条件式建议**

| 你的情况 | 该做什么 / 不该做什么 |
| :--- | :--- |
| 你空仓，想抄底 | 具体建议 |
| 你满仓，跌得难受 | 具体建议 |
| 你在定投 | 具体建议 |
| 你持有特定板块 | 具体建议 |
| 你想跟着资金流向买 | 具体建议 |
| 你完全不投资 | 这件事对你最直接的关系是什么 |

**关键**：每条**条件式**（如果…那么…），不预测涨跌，每条必须具体（不是"控制仓位"，是"如果跌了 10% 你会睡不着，说明仓位重了"）。

**第六屏：收尾**
- 核心句式：「在下跌的时候做决定，比在上涨的时候做决定，更容易后悔。」
- 落在"你不需要证明自己是对的"上

**示例**：「这一周，指数在跌，ETF 在买。两拨人擦肩而过，互道一声'傻子'。谁对谁错，不是这一周能决定的。但你不需要在这一周证明自己是对的。你只需要确保，这一周做的决定，是你在平静的时候也会做的那个。」

### 8.4 质量标准

**必须做到**：
1. 钩子先承认情绪，再给反直觉事实
2. 短期原因和长期逻辑分开说，中间有过渡句
3. 历史对照必须具体（哪一年、什么背景、后来怎么走）
4. 行动点条件式（如果…那么…）
5. 最后一行必须照顾"完全不投资的人"
6. 语气降温，不煽动情绪

**禁止做到**：
1. ❌ 预测涨跌（"接下来会涨到 XX"）
2. ❌ 行动点写成"现在该买 / 该卖"
3. ❌ 把短期原因和长期逻辑混在一起说
4. ❌ 用"震惊""暴雷""血洗"等煽动性词汇
5. ❌ 只写利好或只写利空，必须两面都说
6. ❌ 用"综上所述""总而言之"收尾
7. ❌ 忽略"完全不投资的人"

### 8.5 与 S1-S3 的关键区别

| 维度 | S1 宏观 | S2 事件 | S3 政策 | S4 异动 |
| :--- | :--- | :--- | :--- | :--- |
| 起点 | 数字 | 反直觉 | 政策与钱包连接点 | **情绪降温** |
| 核心动作 | 概念提取 | 传导链拆解 | 逐条翻译 | **短因 / 长逻 + 历史对照** |
| 第二屏 | 原始数据 | 时间线 | 政策摘录 | **关键数字表** |
| 第三屏 | 概念四件套 | 节点四件套 | 条款三件套 | **短因 + 长逻** |
| 第四屏 | 逻辑流程图 | 传导链可视化 | 受益 / 承压 | **历史对照表** |
| 行动点 | 按情况分类 | 条件式 | 对号入座 | **情绪管理型** |
| 收尾 | "你的选择权" | "它离你很远" | "风往哪吹" | **"下跌做决定更易后悔"** |

**S4 最核心一条**：短期原因和长期逻辑**必须分开说**。分清这两件事，是普通人在市场异动里最需要的能力。


## 9. 模板 E · S5 公司财报（骨架）

### 9.1 角色

你不是数字复读机，也不是股票推荐机。你要把一份公司财报 / 行业动态，拆成"市场在定价什么"和"真实利润质量如何"，再帮读者判断：这个公司值得研究，还是热闹而已。

读者是看到新闻"某公司暴雷 / 财报超预期 / 行业政策变化"的普通人。

### 9.2 输入

一段公司财报 / 公告 / 行业事件内容。

### 9.3 处理流程

#### 第一步：找数字 vs 股价的反差

问：市场反应（涨/跌）和数字本身（赚/亏）一致吗？
- 赚了但股价跌 → 市场在担心什么（利润是否可持续、是否透支了预期）
- 亏了但股价涨 → 市场在为未来定价（亏损是成长代价吗）
- 数字与反应一致 → 不是本 Skill 的菜（用 S4 异动）

**输出**：一句话说清这个反差——这就是钩子的内核。

#### 第二步：拆预期差 + 利润质量

**预期差**（市场原本预期 vs 实际结果）：
- 哪个数字 vs 预期差异最大（收入 / 利润 / 增速 / 利润率）
- 反差是因为什么（一两个月的巧合，还是结构性问题）

**利润质量**（赚的钱到底是不是真钱）：
- 经营性现金流 vs 净利润（如果差距大，利润可能是应收账款）
- 一次性收益占比（卖资产、政府补贴、汇兑收益）
- 客户集中度（大客户依赖）
- 应收账款周转（钱能不能收回来）

#### 第三步：输出六屏结构

**第一屏：钩子**
- 用反差开场
- 核心句式：「某公司刚发了财报。数字看起来 XX，但股价 YY。这是因为……」

**第二屏：公司是做什么的**（← 与 S1/S2/S3 都不同：先告诉读者公司是干嘛的）
- 一段话讲清主营业务（不超过 5 行）
- 顺手说清它靠什么赚钱（卖货、订阅、广告、抽佣……）

**第三屏：4 个核心概念四件套**（每个概念四件套）
- 行业地位：它在行业里排第几？护城河是什么？
- 增长来源：这次的数字增长，靠的是新客户、老客户涨价、还是新业务？
- 利润质量：赚的钱是不是真钱？（现金流、一次性收益占比）
- 估值锚：当前市值 vs 真实利润，PE 多少？跟同行比贵还是便宜？

**第四屏：适合 / 不适合表**

| 你是什么情况 | 适合 / 不适合研究 |
| :--- | :--- |
| 长线价值投资者 | 适合（如果……）/ 不适合（因为……）|
| 短线投机者 | 适合（如果……）/ 不适合（因为……）|
| 行业 ETF 持有人 | 这家公司对你意味着什么 |
| 完全不持股 | 这件事对你最真实的影响是什么 |
| 觉得"跟我没关系" | 它正在通过哪条链影响你的生活 |

**第五屏：条件式建议**

| 你的情况 | 该做什么 / 不该做什么 |
| :--- | :--- |
| 已持仓 | 是否要减仓 / 加仓的判断条件 |
| 想买入 | 你需要先确认什么 |
| 在观望 | 等什么信号才动手 |
| 同行业其他公司 | 这份财报对它们意味着什么 |
| 完全不投资 | 这件事对你生活最直接的影响 |

**第六屏：收尾**
- 核心句式：「你买的是信念，不是利润。」
- 落在「好公司不一定是好股票，好数字不一定好生意」

### 9.4 质量标准

**必须做到**：
1. 钩子必须用"数字 vs 股价"反差
2. 必须先讲公司是做什么的（行业外读者也能懂）
3. 利润质量必须分清"真钱 vs 假钱"
4. 行动点条件式
5. 不替读者决定买不买

**禁止做到**：
1. ❌ 给目标价（"应该涨到 XX 元"）
2. ❌ 直接说"买 / 卖"
3. ❌ 只讲利好看多 / 只讲利空看空
4. ❌ 把会计科目当结论（"ROE 上升就是好事"）
5. ❌ 忽略"不持股的读者"
6. ❌ 用"综上所述"收尾

### 9.5 与 S1-S4 的关键区别

| 维度 | S1 宏观 | S2 事件 | S3 政策 | S4 异动 | S5 公司 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 起点 | 数字 | 反直觉 | 政策连接点 | 情绪降温 | **数字 vs 股价反差** |
| 核心动作 | 概念提取 | 传导链 | 逐条翻译 | 短/长期 + 历史 | **预期差 + 利润质量** |
| 第二屏 | 原始数据 | 时间线 | 政策摘录 | 关键数字 | **公司是做什么的** |
| 第三屏 | 概念四件套 | 节点四件套 | 条款三件套 | 短/长 | **4 概念四件套** |
| 第四屏 | 逻辑流程 | 传导链图 | 受益承压 | 历史对照 | **适合/不适合表** |
| 行动点 | 分类 | 条件式 | 对号入座 | 情绪管理 | **预期管理型** |
| 收尾 | 选择权 | 离你很远 | 风往哪吹 | 下跌决定 | **"你买的是信念，不是利润"** |

**S5 最核心一条**：先找预期差，再拆利润质量。这两件事决定了"数字好但股价跌"的真相。


## 10. 模板 F · S6 个人决策（骨架）

### 10.1 角色

你不是替人做决定，而是把一个让人纠结的财务决策，拆成 3-4 个可判断的变量，让读者自己对号入座，最后自己得出结论。

读者正在纠结"要不要提前还贷""要不要买房""要不要买年金""要不要辞职""教育金怎么存"。他不需要标准答案（因为不存在），他需要的是：把"纠结"拆成"变量"，把"变量"对应到"我的情况"。

### 10.2 输入

一个个人财务决策问题（可能附带个人情况：收入、负债、利率、家庭结构）。

### 10.3 处理流程

#### 第一步：一句话说清正在纠结的决策

不是"提前还贷的利弊分析"，是"你手里有 50 万，房贷利率 4.2%，理财收益 2.5%，要不要还"。

- 必须包含**具体数字**（利率、金额、期限）——没有具体数字的决策问题，无法拆解
- 用户给的信息不够 → 用合理假设补全，开头注明「以下分析基于假设：……」

#### 第二步：识别 3-4 个关键变量

问：这个决策，本质上是在权衡哪几件事？

**常见变量池**（按决策类型选 3-4 个）：
- **收益类**：利率、收益率、利差、机会成本
- **安全类**：应急金、负债率、收入稳定性
- **流动性**：这笔钱多久不用、急用钱时能不能取
- **心理类**：背债焦虑、看到浮亏睡不着、怕错过
- **家庭类**：配偶意见、家庭责任、孩子教育、父母养老

**变量选择标准**：
- 必须能影响决策方向
- 必须是读者**自己能回答**的（不是"未来利率走势"这种预测）
- 每个变量必须能落到**具体数字或状态**

#### 第三步：每变量对"你"意味着什么

不是讲概念，是讲"你的情况"：
- 「你的房贷利率是 4.2%。如果你的钱只放在 2.5% 的理财里，还贷相当于赚了 1.7% 的无风险利差。」
- 「你的应急金是 3 个月生活费。还完贷款后，如果家里突然要用钱，你拿不出来。」

**关键**：每个变量必须有**判断标准**（"高于/低于""够/不够""能/不能"），判断标准必须**可量化**。

#### 第四步：不同情况下，答案不一样

表格形式（**分类给倾向，不给统一答案**）：

| 你的情况 | 倾向 |
| :--- | :--- |
| 变量 A 高 + 变量 B 低 + 变量 C 够 | 倾向 X |
| 变量 A 低 + 变量 B 高 + 变量 C 够 | 倾向 Y |
| 变量 C 不够 | 先做 Z，别做 X/Y |

**关键要求**：
- 每行必须是**变量组合**，不是单一变量
- 倾向是"倾向"，不是"应该"——留读者自己判断空间
- 必须有一行"某个变量不满足时，先别做"的兜底建议

#### 第五步：输出六屏结构

**第一屏：钩子**
- 用"你妈说…你朋友说…"的场景开场
- 替读者说出他听到的两种相反声音
- 然后点破：你夹在中间，不知道听谁的
- 最后一句：这个决策没有标准答案，但有 3-4 个变量，你填进去，答案自己就出来了

**示例**：「你手里有 50 万，房贷利率 4.2%，理财收益 2.5%。你妈说'赶紧还了，无债一身轻'，你朋友说'别还，留着钱生钱'。你夹在中间，不知道听谁的。」

**第二屏：这个决策涉及哪几个变量**
- 列出 3-4 个变量，每个一句话
- 列表 + 符号（🔑 利率 / 🛡️ 应急金 / 💰 收益 / 🧠 心理）
- 每变量配一句"为什么它重要"

**第三屏：每变量意味着什么**（每变量一个小节）
- 你的情况是什么（具体数字）
- 这个数字意味着什么（判断标准）
- 如果不满足 / 满足，会发生什么

**关键**：不堆术语，每个变量说清"高了会怎样、低了会怎样"。

**第四屏：不同情况下，答案不一样**
- 用步骤四的表格
- 表格下方配一句话：「没有标准答案，只有适不适合你的情况。」

**第五屏：你该问自己的三个问题**
- 列 3 个问题，把决策权还给读者
- 每个问题必须是**读者自己能回答**的（不是"未来利率会怎样"这种预测）
- 问题有递进：第一个问安全，第二个问收益，第三个问心理

**示例**：
1. 还完之后，我家还能拿出 6 个月生活费吗？
2. 我不还的这笔钱，能稳定赚到比房贷利率更高的收益吗？（不是"可能"，是"稳定"）
3. 我更怕"多付利息"，还是更怕"急用钱时拿不出来"？

**第六屏：收尾**
- 核心句式：「XX 没有标准答案。它是一道用 A 换 B 的题。」
- 落在"四个变量，你填进去，答案自己就出来了"

**示例**：「提前还贷没有标准答案。它是一道用'无风险收益'换'流动性'的题。你放弃的是现金的灵活性，换来的是确定的利息节省。划不划算，不取决于别人怎么说，取决于你的利率、你的收益能力、你的应急金、你的心理承受力。四个变量，你填进去，答案自己就出来了。」

### 10.4 质量标准

**必须做到**：
1. 钩子用"你妈说…你朋友说…"场景
2. 变量 3-4 个，每个能落到具体数字
3. 每变量有判断标准（高于/低于、够/不够）
4. 第四屏是"变量组合 → 倾向"表格，不是单一变量
5. 第五屏三个问题必须是读者自己能回答的
6. 收尾必须说"没有标准答案"

**禁止做到**：
1. ❌ 替读者做决定（"你应该还贷"）
2. ❌ 给统一建议（"建议所有人都……"）
3. ❌ 用"因人而异"敷衍（要说清"因什么而异"）
4. ❌ 变量是"未来利率走势"这种读者无法回答的
5. ❌ 用"综上所述"收尾
6. ❌ 忽略"应急金不够"这种兜底情况

### 10.5 与 S1-S5 的关键区别

| 维度 | S1 宏观 | S2 事件 | S3 政策 | S4 异动 | S5 公司 | S6 个人决策 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 起点 | 数字 | 反直觉 | 政策连接点 | 情绪降温 | 数字反差 | **你妈说…你朋友说…** |
| 核心动作 | 概念提取 | 传导链 | 逐条翻译 | 短/长期 | 预期差+利润 | **变量拆解** |
| 第二屏 | 原始数据 | 时间线 | 政策摘录 | 关键数字 | 公司是啥 | **决策变量** |
| 第三屏 | 概念四件套 | 节点四件套 | 条款三件套 | 短/长 | 4 概念四件套 | **每变量意味着什么** |
| 第四屏 | 逻辑流程 | 传导链图 | 受益承压 | 历史对照 | 适合不适合 | **变量组合 → 倾向表** |
| 行动点 | 分类 | 条件式 | 对号入座 | 情绪管理 | 预期管理 | **自我判断型（还决策权）** |
| 收尾 | 选择权 | 离你很远 | 风往哪吹 | 下跌决定 | 信念 | **"没有标准答案"** |

**S6 最核心一条**：不给标准答案。它的价值不在"告诉你怎么做"，而在"把纠结拆成变量，让你自己判断"——这是 6 个 skill 里**唯一把决策权还给读者**的。

## 12. 怎么用这个 Skill

**方式一：直接复制 prompt 到 AI 对话框**

每个模板的开头（角色 + 输入 + 处理流程 + 六屏 + 质量标准 + 输出格式）就是一个完整 prompt。

**方式二：作为项目 Skill 加载**

放在 `~/.claude/skills/` 或等价路径下，对 AI 说「用 `invest-dictionary-concept-combinator` 跑 S2 处理这篇文章」即可。

**方式三：拆成三步**

觉得单次输出太长？把每个模板的三步拆开走：
1. 第一步 prompt：让 AI 输出「提取的概念 + 关键数字 + 选择理由」
2. 第二步 prompt：让 AI 输出「一句叙事线 + 每个概念的角色」
3. 第三步 prompt：让 AI 输出六屏文本 / HTML

## 附录 C · 提交前自检（投顾工作台视角）

跑完一遍任何模板后，过这 6 问：

1. **钩子冲突**？第一句让读者"嗯？"还是"哦。"？（"哦。" = 重写）
2. **第二屏纯事实**？有没有把解读混进去？（有 = 拆到第三屏）
3. **每概念四件套齐全**？原始数据 + 说人话（带类比）+ 在故事里的角色 + 行动点（具体）？
4. **行动点可执行**？打开哪个 APP / 看哪个数字 / 设什么阈值？
5. **最后两行照顾了"不投资 / 觉得无关"**？这是大多数读者
6. **收尾是余味不是总结**？有没有出现"综上所述""总而言之"？

过完所有 6 问 → 才能交给客户（投顾模式）/ 发出去（自助模式）。
