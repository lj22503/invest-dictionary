# Mangofolio · 把投资的词翻译成人话

8 个 Skill，一套方法论：**先把词讲明白，再谈这件事跟你有什么关系，最后只给分界线、不给买卖结论。**

配套词库：[dictionary.mangofolio.com](https://dictionary.mangofolio.com/)（1000+ 中文投资词条）

---

## 什么时候用哪个

| 你遇到的情况 | 用这个 |
| :--- | :--- |
| 我买的理财亏了 / 我妈被推荐了个高息产品 / 听说黄金要涨 | **理财急诊**（symptom-lookup） |
| 这个产品能买吗 / 我该问销售什么 / 他说的保本保息靠谱吗 | **防坑提问器**（question-probe） |
| 提前还贷还是买增额寿 / 存定期还是买理财 / 买房还是租房 | **二选一擂台**（duel-compare） |
| 我要不要提前还贷 / 该不该给孩子存教育金 | **决策拆解桌**（decision-mosaic） |
| 这段新闻什么意思 / 降准对我是好是坏 / 这份财报怎么看 | **新闻翻译机**（combo-narrative） |
| 今天市场在聊什么 / 今天有什么热点 | **每日热词**（daily-hotword） |
| 把这段做成客户能看懂的 6 屏网页 | **概念串联**（concept-combinator） |
| 帮我写一个「XX」词条 | **词条生成器**（generator） |

**一句话分辨**：说「要不要」→ 决策拆解；说「还是」→ 二选一；说「亏了 / 被推荐」→ 急诊；说「产品 / 话术」→ 防坑。

## 八个 Skill 各做什么

**01 理财急诊（symptom-lookup）**
你描述一句口语化的现象，它倒查出你真正该搞懂的几个概念，并告诉你先看哪一条。

**02 防坑提问器（question-probe）**
给一个产品名或一段销售话术，输出你该当面问销售的 3-5 个问题，每个配「为什么重要」和「对方可能的回避话术」，外加红灯信号。

**03 二选一擂台（duel-compare）**
把「A 还是 B」放进同一个场景并排对比。先校验两者是不是真在同一个场景里对打，再按最坏情况 / 流动性 / 收益来源 / 适合谁四个维度比，给分界线与当场能算的试算。

**04 决策拆解桌（decision-mosaic）**
面对「我要不要做这件事」，拆出这个决策取决于哪几个变量，每个变量配一个该看的词条，给分界线与今天就能做的行动清单。

**05 新闻翻译机（combo-narrative）**
把一段看不懂的财经新闻 / 宏观数据 / 政策文件拆成核心概念，串成从「现象」到「对你意味着什么」的因果链。

**06 每日热词（daily-hotword）**
围绕一条今日热点，挑出 3-5 个必须懂的热词，逐个讲人话，串成一条能复述给别人听的话题解读。

**07 概念串联（concept-combinator）**
把复杂内容拆成核心词条，沿因果链串成叙事线，输出一个普通人在手机上能读完的 6 屏网页。

**08 词条生成器（generator）**
把任何一个金融概念，写成普通人 3 分钟能看懂、AI 和搜索引擎都能读懂的词条。

## 三条底线

1. **说人话** —— 不用术语解释术语，必须用术语时紧跟一句大白话。
2. **不给结论** —— 只给「什么条件下倾向 A、什么条件下倾向 B」，从不替你做决定。
3. **不编词条** —— 每个 Skill 都带一份词条索引（`references/term-index.txt`），输出前核对；索引里没有的词，不凭空造。
