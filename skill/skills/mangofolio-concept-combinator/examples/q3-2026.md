## 阶段一：概念提取

从央行原文里挑出 5 个核心概念。挑的依据：不懂它，就看不懂全文 + 有数字支撑 + 能串成线。

### 概念 01 · 住户贷款

- **关键词**：`住户贷款` / slug `住户贷款`（词典已有词条）
- **原文摘录**：前三季度住户贷款减少 **1.03 万亿元**（短期贷款减 1.14 万亿、中长期贷款增 1062 亿）
- **为什么选它**：这是叙事的**第一环**——你和邻居们在"缩着过"
- **判断标准**：不懂它，就看不懂"国家在缩"的判断

### 概念 02 · 住户存款

- **关键词**：`住户存款` / slug `住户存款`
- **原文摘录**：前三季度住户存款增加 **9.39 万亿元**，9 月末住户存款余额约 100 万亿级别
- **为什么选它**：叙事的**第二环**——有钱但不敢花，全堆银行
- **判断标准**：与"住户贷款"形成"存款↑贷款↓"对照，是核心信号

### 概念 03 · M1-M2 剪刀差

- **关键词**：`剪刀差`（M1 / M2 派生）/ slug `M1-M2_剪刀差`
- **原文摘录**：M2 同比 +7.2%，M1 同比 +3.2%，**剪刀差 4 个百分点**
- **为什么选它**：叙事的**第三环**——钱在"沉淀"不在流动，最敏感的温度计
- **判断标准**：有具体数字 + 能解释"为什么 M1 追不上 M2"

### 概念 04 · 社会融资规模

- **关键词**：`社会融资规模` / slug `社会融资规模`（词典已有）
- **原文摘录**：9 月末社融存量 468.17 万亿，同比 +7.1%；结构上政府债券 +13.7%、实体贷款 +4.8%
- **为什么选它**：叙事的**第四环**——总量 + 结构，谁在撑经济
- **判断标准**：结构数据揭示"政府独自借"

### 概念 05 · 同业拆借利率

- **关键词**：`同业拆借利率` / slug `同业拆借利率`
- **原文摘录**：9 月同业拆借加权平均利率 1.4%，比上月 +0.02 pct、比去年同期 -0.05 pct
- **为什么选它**：叙事的**第五环**——央行最直接的工具，决定 LPR 走向、决定月供
- **判断标准**：是连接"央行"和"你的钱包"的最短链条

## 阶段二：概念串联

### 串联逻辑类型

- [x] 从微观到宏观（推荐叙事线）

### 一句话叙事线

**"你的钱包缩着过 → 钱堆进银行 → 央行想让它活起来 → 政府独自撑 → 利率可能继续降"** —— 整个链条回答"这跟我有什么关系"。

### 每个节点的角色

| 序 | 概念 | 角色 | 在叙事线中的位置 |
| :--- | :--- | :--- | :--- |
| 1 | 住户贷款 | 起因 | 你和邻居们"信心温度计"的最低读数 |
| 2 | 住户存款 | 行为 | 钱没消失，但堆进银行不敢动 |
| 3 | M1-M2 剪刀差 | 中间环节 | 钱在"沉淀"，经济活性下降 |
| 4 | 社会融资规模 | 中间环节 | 总量温和 + 政府独自撑（结构关键） |
| 5 | 同业拆借利率 | 结果 / 杠杆 | 央行最直接的工具，决定你的月供 |

### 这条线回答了什么问题？

**「你存了更多钱，借了更少钱，整个国家都在缩 —— 这是真的吗？我该缩还是该动？」**

答：是真的。央行已经在想办法，但你别跟政策反向加杠杆。

## 阶段三：六屏内容

### 第一屏：钩子

- **核心句式**：「你存了更多钱，借了更少钱。整个国家都在'缩着过'。」
- **副标题**：央行 9 月 + 三季度数据翻译 — 把一堆数字变回你钱包里的故事
- **数据源**：中国人民银行 · 国家金融监督管理总局（2026-10）

### 第二屏：原始数据

折叠面板：

- **社融存量**：468.17 万亿，同比 +7.1%
- **前三季度社融增量**：27.46 万亿（少 2.63 万亿）
- **货币供应**：M2 +7.2%（359.63 万亿）、M1 +3.2%（116.76 万亿）
- **住户存贷款**：存款 +9.39 万亿、贷款 -1.03 万亿
- **银行间利率**：同业拆借 1.4%、质押式回购 1.4%

**锚定语**：你不必记住这些数字 —— 往下看，我们告诉你它们合在一起在说什么。

### 第三屏：概念拆解（5 个，每个四件套）

每个概念完整四件套见 `q3-2026.html` 第三屏，这里只列**每概念行动点**（最易出错的部分）：

### 第四屏：完整框架（ASCII 流程图）

```
你的钱包
   ├─ 你存了更多（存款 +9.39 万亿）
   └─ 你借了更少（贷款 -1.03 万亿）
       │
       ▼
   钱流进银行
       ├─ 活钱变慢（M1 +3.2% 追不上 M2 +7.2%）
       └─ 总钱还在增（M2 总量 359 万亿）
           │
           ▼
       央行和政府着急
           ├─ 政府拼命借（社融里政府债券 +13.7%）
           └─ 企业和居民不借（贷款 +4.8%）
               │
               ▼
           钱流向基建 + 补贴
               │
               ▼
           对你意味着什么
               ├─ 利率可能继续降（LPR ↓）
               ├─ 别再加杠杆
               └─ 保住现金流（活钱 = 选择权）
```

**核心句式总结**：所有的金融统计数据，最终都在回答同一个问题 —— **"钱在哪里？它在干什么？它接下来会去哪里？"**

### 第五屏：行动清单

| 你的情况 | 建议 |
| :--- | :--- |
| 有房贷 | 每月看 LPR / 别再追加杠杆 |
| 有存款 | 6 个月生活费留活期 / 别锁长期低息 |
| 想买房 | 再等 3-6 个月 / 刚需不靠预测 |
| 想投资 | 别押单一资产 / 等 M1 起来 |
| 想借钱消费 | 全国在缩，等收入稳住 |
| 不确定 | 打开 APP 看活钱 / 死钱比例 |

**最后两行照顾**：兜底"不确定"的人 — 给他们一个起点（看活钱/死钱比例）。

### 第六屏：收尾

- 你存了更多钱，借了更少钱。
- 整个国家都在"缩着过"。
- 但钱没有消失 —— 它只是在你看不见的地方，安静地堆着。
- 央行在想把"死钱"变"活钱"，政府在想怎么让你敢花钱。
- 降息、降准、降 LPR —— 这些动作已经在路上了。
- **你手上的活钱，就是你在这个信号到来之前，最大的选择权。**
