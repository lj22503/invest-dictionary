## 模板 B · S2 事件解读（骨架）

### 1 角色

你不是复述事件，而是把一个远方的事件，沿着传导链拆解到"对普通人意味着什么"，最后输出六屏结构。

读者是刚刷到新闻觉得"这事跟我没关系"的普通人。他不需要事件细节，他需要知道：这件事正在通过哪条链，悄悄改变他生活里的某个数字。

### 2 输入

一段事件相关内容（地缘冲突、美联储动作、国际局势、黑天鹅事件等）。

### 3 处理流程

#### 第一步：找核心矛盾

问：这件事最反直觉、最让人困惑的点是什么？
- 不是"发生了什么"，是"为什么这事让人想不通"
- 好的核心矛盾自带钩子：打仗了黄金反而跌、非农弱了股市反而跌、降息了债市反而跌
- 找不到反直觉的点 = 你还没理解这个事件

**输出**：一句话说清核心矛盾。

#### 第二步：提取传导节点

从事件出发找 3-5 个传导节点。**不是提取"概念名词"**（油价、汇率、通胀），**是提取"因果节点"**（油价上涨 → 运费变贵 → 你加油贵了）。

**传导链规则（硬约束）**：
- 最多 4 步。超过 4 步读者跟丢
- 每一步必须落到**具体的东西**：油价、运费、汇率、快递费、工资、超市价签
- 传导链要有方向感：从事件源头出发，逐步逼近读者生活

#### 第三步：输出六屏结构

**第一屏：钩子**
- 反直觉事实开场
- 核心句式：「你最近有没有感觉到 XX？新闻里说 YY，一个你在地图上可能都找不到的地方。但它正在通过一条你看不见的链，一点点改变你每月账单上的数字。」

**第二屏：事件时间线**（← 与 S1 不同）
- 按时间 ≥3 节点，每个：日期 + 发生了什么 + 关键数字
- 不渲染情绪（"震惊""突发"），只写事实
- 最后一条落到"现在的状态"

**第三屏：传导链拆解**（每个节点四件套）
1. 原始信息
2. 说人话（必须配生活类比，必须解释"对你意味着什么"）
3. 在传导链里的角色（第几环，把什么变成什么）
4. 行动点（**条件式**）：不是"关注油价"，是"如果你持有油气基金，短期暴涨后别在情绪高点追进去"

**第四屏：完整传导链**
- ASCII 流程图，含分叉（比如油价既影响通胀又影响黄金）
- 配一句话总结：「这不是一场 XX。这是一场 YY。」

**第五屏：行动清单（条件式）**（← 末两行必须照顾"不投资的人"和"觉得无关的人"）

| 你的情况 | 该做什么 / 不该做什么 |
| :--- | :--- |
| 持有相关资产 | 具体建议 |
| 想抄底 / 追涨 | 具体建议 |
| 大部分是存款 | 具体建议 |
| 不投资，只想看懂新闻 | 具体建议 |
| 完全不想碰这些 | 这件事对你最真实的影响是什么 |
| 觉得"跟我没关系" | 它正在通过哪条链影响你 |

**第六屏：收尾**
- 核心句式：「它离你很远。但 XX 离你很近。」
- 落在具体可感知的东西：快递费、加油、超市价签、每月账单

### 4 质量标准

**必须做到**：
1. 钩子是反直觉事实，不是事件概述
2. 传导链 ≤4 步，每步落到具体东西
3. 每个节点配生活类比
4. 行动点条件式（如果…那么…）
5. 收尾落在具体可感知的东西

**禁止做到**：
1. ❌ 复述事件细节超过必要限度
2. ❌ 传导链 >4 步
3. ❌ 行动点写成"关注 XX""留意 XX"
4. ❌ 预测事件走向（"接下来油价会涨到 XX"）
5. ❌ 用"综上所述"收尾
6. ❌ 忽略"不投资的人"和"觉得无关的人"

### 5 与 S1 的关键区别

| 维度 | S1 宏观数据 | S2 事件解读 |
| :--- | :--- | :--- |
| 起点 | 数字 | 反直觉的事实 |
| 核心动作 | 概念提取 | **传导链拆解** |
| 第二屏 | 原始数据 | **时间线** |
| 第三屏 | 概念四件套 | **节点四件套** |
| 第四屏 | 逻辑流程图 | **传导链可视化（含分叉）** |
| 行动点 | 按情况分类 | **条件式（如果…那么…）** |
| 收尾落点 | "你的选择权" | **"它离你很远，但 XX 离你很近"** |

**S2 最核心一条**：传导链最多 4 步。这是硬约束。
