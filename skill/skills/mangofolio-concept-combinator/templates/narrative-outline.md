## 阶段三：六屏内容

### 第一屏：钩子

- **核心句式**：______
  - S1 示例：「你存了更多钱，借了更少钱。整个国家都在缩着过。」
  - S2 示例：「你最近加油，是不是贵了？」
  - S3 示例：「你的月供 / 工资 / 退休金 可能会变了」
  - S4 示例：「这周 X 跌了。你的第一反应可能是 …… 但同一周，Y 在。」
  - S5 示例：「某公司赚了 X%，但股价 Y% ……」
  - S6 示例：「你手里有 50 万，你妈说 X，你朋友说 Y。」
- **副标题**：______（≤80 字，说明这一页要讲什么）
- **数据 / 事件来源标注**：______

### 第二屏：客观事实

- **类型**：
  - S1 原始数据（折叠面板摘录）
  - S2 时间线（≥3 节点）
  - S3 政策原文摘录
  - S4 关键数字表（指数/资产/涨跌幅/资金流向）
  - S5 公司是做什么的（一段话）
  - S6 决策涉及哪几个变量（变量列表）
- **内容**：______
- **锚定语**：______（"你不必记住这些数字" / "你只需要看时间线" / "你只看这一段"）

## 提交前自检（6 问）

- [ ] **钩子冲突**：第一句让读者"嗯？"（不是"哦。"）？
- [ ] **第二屏纯事实**：有没有把解读混进去？（有 = 拆到第三屏）
- [ ] **每概念四件套齐全**：原始 + 说人话（带类比）+ 角色 + 行动点？
- [ ] **行动点可执行**：打开哪个 APP / 看哪个数字 / 设什么阈值？
- [ ] **最后两行照顾"不投资 / 觉得无关"**：他们是大多数
- [ ] **收尾是余味不是总结**：有没有出现"综上所述"？

全部 ✓ → 转 `templates/narrative-page.html` 出 HTML。
