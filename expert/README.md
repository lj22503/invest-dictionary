# Mango · 理财说人话专家

把投资的词翻译成人话：查词条、拆新闻、比方案、防话术坑、拆财务决策——只帮理解与分辨，不给买卖建议。

## 类型

Agent 型（单个 AI 专家）

## 功能

Mango 来自 Mangofolio 投资词典项目，围绕 1000+ 中文投资词条，把 8 个场景技能收进一个专家：

| 技能 | 场景 | 什么时候用 |
| :--- | :--- | :--- |
| 理财痛点 | 理财焦虑说人话 | "我买的理财亏了" / "我妈被推荐了个高息产品" |
| 话术防坑 | 销售话术说人话 | "保本保息靠谱吗" / "我该问销售什么" |
| 产品对比 | 产品对比说人话 | "存定期还是买理财" / "买房还是租房" |
| 财务决策 | 财务决策说人话 | "我要不要提前还贷" / "该不该存教育金" |
| 新闻拆解 | 财经新闻说人话 | "这段新闻什么意思" / "降准对我是好是坏" |
| 热点追踪 | 市场热点说人话 | "今天市场在聊什么" / "今天有什么热点" |
| 概念串联 | 宏观事件说人话 | "把这段做成客户能看懂的 6 屏网页" |
| 投资翻译 | 金融词条说人话 | "帮我写一个 XX 词条" / "解释这个金融概念" |

专家自身负责三件事：判断用户真正在问什么、路由到对应技能、把结果压成一句能复述的话。

## 使用示例

- 我买的理财最近亏了，帮我看看该先搞懂哪几个词
- 这段财经新闻看不懂，帮我拆成人话
- 销售说这个产品保本保息，我该当面问他什么

## 安装

专家包位于：

```
C:\Users\lj225\.workbuddy\plugins\marketplaces\my-experts\plugins\mango\
```

注册到市场（注册后才能在客户端左侧「专家」里看到）：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
python3 scripts/package_expert.py <expert-dir>
```

## 上架 WorkBuddy 开放平台

平台结构与本包一致（`.codebuddy-plugin/plugin.json` + `agents/` + `avatars/` + `skills/`），
zip 后从 https://open.workbuddy.cn/ 发布管理 → 专家 → 创建专家 上传即可。
参考 `docs/上架填写资料.md`。
