# 停牌 / 复牌

> **停牌 = 交易所暂停某只股票的交易，复牌 = 恢复交易。** 常见原因：重大资产重组、股价异常波动、退市风险、年报未按时披露等。

## 1. 这是什么

**停牌 = 交易所暂停某只股票的交易，复牌 = 恢复交易。** 常见原因：重大资产重组、股价异常波动、退市风险、年报未按时披露等。

## 2. 为什么重要

停牌期间你的钱被锁在股票里，既不能卖也不能跑；复牌当天往往剧烈波动，重组成功可能连续涨停，失败则可能连续跌停。

## 3. 怎么用 / 怎么看

- 1. 看停牌公告：分清原因（重组 / 核查 / 风险）。
- 2. 查停牌时限：长期停牌要警惕流动性风险。
- 3. 复牌首日观察集合竞价与量能再决策。

## 4. 常见坑 / 误区

- - 停牌≠利好，退市风险停牌是利空。
- - 长期停牌占用资金，错过其它机会。
- - 复牌一字涨停买不进、一字跌停卖不出。
