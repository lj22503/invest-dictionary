# 裸贷

**一句话定义：裸贷 = 以裸照或不雅视频作"抵押"借高利贷，逾期就威胁公开，是校园贷乱象里最恶劣的一种。**

## 1. 这是什么

裸贷的流程通常是：借款人（多为年轻女性、学生）向放贷人提供手持身份证的裸照/视频，借几百到几千元；一旦逾期，放贷人就以"把照片发给你通讯录所有人"相要挟，逼你还钱、续贷甚至做更多违法的事。利息往往按"周"计算，实际年化可达百分之几百。

## 2. 为什么重要

裸贷不是普通的借贷，它同时踩了三条法律红线：非法放贷、敲诈勒索、传播淫秽物品。2017 年监管部门对"校园贷"全面整顿后，裸贷转入地下，但换皮形式依然存在——"美容贷""培训贷""回租贷"都可能是它的变种。对借款人来说，最大的损失不是钱，而是隐私一旦交出，就等于把人生的把柄交给了别人。

## 3. 怎么用

- 明确结论：任何要求提供裸照/不雅视频作为"担保"的贷款，一律不碰
- 真缺钱走正规渠道：银行消费贷、正规消金公司、助学贷款、向家人坦白
- 已经陷入裸贷：停止转账，保留聊天记录和转账凭证，立刻报警
- 遇到威胁曝光：不妥协、不私下转账，报警后保存证据提交警方

## 4. 常见坑

- "不露脸也能借"：你以为只露身份证，对方截图时照样拍下你的脸
- 逾期后"以贷养贷"：越滚越大，最终被逼做违法兼职还债
- 以为删掉照片就没事：对方早有多份备份，还会发给通讯录好友
- 被"律师/中介"两头骗：花钱找"平事"的人，结果再被宰一刀
