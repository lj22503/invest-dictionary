# 市场中性策略

> 一边买股票、一边做空股指期货，把"大盘涨跌"的影响抹平，只赚选股的钱（阿尔法）。

## 1. 这是什么

市场中性策略 = 多头仓位 + 空头对冲。基金经理选出一篮子自己看好的股票（多头），同时用股指期货等工具做空等量的市场敞口（空头），于是大盘涨跌带来的收益被对冲掉，剩下的只有"我选的股票比市场强多少"的部分——这部分专业上叫阿尔法（α）。

打个比方：你同时押注"张三跑得比李四快"，而不是赌"今天刮不刮风"。风（大盘）对两个人影响一样，抵消掉；真正决定输赢的是两个人的实力差（选股能力）。

关键机制是"中性"：多空两边市值大致相等，方向相反，市场涨 2% 你的空头亏 2%、多头赚 2%，基本打平；只有你的股票组合跑赢/跑输指数，才产生盈利或亏损。

## 2. 为什么重要

市场中性策略追求的是"低波动、和涨跌无关的收益"：牛市不用羡慕别人暴涨，熊市也不用担心自己暴跌，目标是每年稳稳赚一个"选股超额收益"。

但它远不是"稳赚不赔"。2024 年初就是典型：A 股大跌，同时股指期货大幅贴水（期货比现货便宜），做空对冲的成本陡然升高，加上量化基金扎堆、超额收益普遍下降，不少市场中性产品回撤明显——"中性"只对冲了市场风险，没对冲掉对冲成本、风格踩踏和超额收缩的风险。

对普通人的意义：它适合作为组合里的"低波动增强"部分，但别把它当"类固收"看，它的波动和亏损都是真实存在的。

## 3. 怎么用 / 怎么看

- 看对冲成本：股指期货贴水越深，做空成本越高，中性策略越难做；观察期指贴水幅度，能预判这类产品未来一段时间好不好过。
- 看超额收益的稳定性：别只看年化收益，要看"跑赢指数的部分"是否稳定；用信息比率（IR，超额收益/超额波动）衡量，一般大于 1 算优秀。
- 看最大回撤：中性策略也有回撤（2024 年不少产品回撤 5%~10%），提前确认自己能否接受。
- 看持仓集中度与风格：有些"中性"产品实际暴露了行业或风格偏好（如重仓小盘），风格一反转，超额可能变负超额。
- 口诀：收益看超额、风险看回撤、成本看贴水、别当保本买。

## 4. 常见坑 / 误区

- 把"中性"理解成"没风险"：它只是把市场风险对冲掉，选股错误、对冲成本、流动性风险都还在，照样能亏钱。
- 忽略贴水成本：贴水 2% 意味着策略一开始就背着 2% 的成本，超额收益赚不到 2% 以上，就是白忙。
- 只看"年年正收益"的历史：中性策略的高光年份往往是特定市场环境（比如小盘股长期跑赢），环境一变，历史收益不可持续。
- 误以为随时能赎回：很多中性策略产品有封闭期或限赎，行情不好时想跑跑不掉，流动性风险也是风险。
