# 报复性消费

> 报复性消费，是憋了很久之后"不管价格先买再说"的消费反弹。

## 1. 憋久了，钱包会"报复"

疫情居家、加班熬夜、考试结束、分手失恋……凡是"压抑"了一段时间，人就容易想用花钱来补偿自己：平时舍不得买的，突然就买了。这种"压抑后反弹式消费"就叫报复性消费。
> **一句话**：不是你需要，是你憋坏了。

## 2. 为什么重要：商家最擅长等这一刻

大促、节后、解封节点，商家会集中投放"补偿自己"的话术报复性消费往往伴随分期付款，花的可能是未来的钱它能把一次"犒劳"变成账单、负债、和更深的焦虑心理学上叫"补偿机制"：越压抑，反弹越猛，花得越没数

## 3. 怎么用：让"报复"来得晚一点、轻一点

冲动来了先写购物车，设24小时冷静期，多数会消掉一半给"报复预算"设上限：比如犒劳自己只花500块用非消费的方式补偿：睡饱、旅行、运动，效果不比买东西差把大额心愿拆成"攒钱计划"，花得安心又有仪式感

## 4. 常见坑：报复完了，账单来报复你

用花呗/信用卡分期"犒劳"自己，等于借未来的钱买情绪报复性消费后容易"报复性后悔"，但退货冷静期很短别把报复性消费包装成"投资自己"，买课买装备也是消费商家"限时优惠"就是利用报复心理的临门一脚
