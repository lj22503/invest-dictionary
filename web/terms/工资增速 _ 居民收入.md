# 工资增速 / 居民收入

> **工资增速 = 工资收入比去年涨了多少；居民收入 = 居民人均可支配收入的增速与结构。** 它俩是衡量“老百姓口袋里有没有钱”的核心指标。

## 1. 这是什么

**工资增速 = 工资收入比去年涨了多少；居民收入 = 居民人均可支配收入的增速与结构。** 它俩是衡量“老百姓口袋里有没有钱”的核心指标。

## 2. 为什么重要

收入决定消费，消费决定企业订单，企业订单决定就业和股价。工资增速放缓，消费、楼市、股市都会承压。

## 3. 怎么用 / 怎么看

- 1. 看居民人均可支配收入增速 vs GDP 增速。
- 2. 看工资性收入占比与增速。
- 3. 结合消费数据验证收入是否真流入消费。

## 4. 常见坑 / 误区

- - 人均数字掩盖结构：高收入人群拉高平均。
- - 名义增速没扣通胀：实际增速才是真涨。
- - 只盯工资不看转移收入：补贴也是钱。
