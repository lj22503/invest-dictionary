# 保证金交易

> **保证金交易 = 交一笔保证金（押金），就能买卖比保证金大几倍到几十倍的合约。** 常见于期货、融资融券、期权卖方等场景。

## 1. 这是什么

**保证金交易 = 交一笔保证金（押金），就能买卖比保证金大几倍到几十倍的合约。** 常见于期货、融资融券、期权卖方等场景。

## 2. 为什么重要

杠杆让盈亏同步放大：10 倍杠杆下，标的涨 1% 你的本金赚 10%，跌 1% 本金亏 10%。方向做反，几天就能亏光本金。

## 3. 怎么用 / 怎么看

- 1. 算杠杆倍数：合约价值 ÷ 保证金。
- 2. 设止损：单笔亏损别超过总资金 2%。
- 3. 盯维持保证金：临近强平线主动减仓。
- 4. 留足余量：别满仓加杠杆。

## 4. 常见坑 / 误区

- - 满仓高杠杆：一次回调就爆仓。
- - 忽视强平线：被强平才后悔。
- - 逆势加仓：越亏越加，越加越亏。
- - 杠杆当“免费午餐”：利息和费用很高。
