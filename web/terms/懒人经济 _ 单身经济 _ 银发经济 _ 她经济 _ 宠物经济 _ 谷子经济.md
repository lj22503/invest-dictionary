# 懒人经济 / 单身经济 / 银发经济 / 她经济 / 宠物经济 / 谷子经济

> 这六个"经济"是按人群划分的消费风口：懒人、单身、老人、女性、宠物主和二次元爱好者。

## 1. 六个人群，六个钱包

懒人经济：为"省事"付费，外卖、上门服务、预制菜；单身经济：一人食、小家电、宠物陪伴；银发经济：老年康养、适老化产品；她经济：围绕女性消费的美妆、服饰、健康；宠物经济：猫粮狗粮、宠物医疗、寄养；谷子经济：二次元周边（徽章、立牌、吧唧）的买买买。
> **一句话**：人群在哪，钱就在哪。

## 2. 为什么重要：看懂风口，才能看懂产品和投资

老龄化、少子化、单身化是确定趋势，银发/单身/宠物是长坡厚雪谷子经济、她经济背后是"情绪消费"，爆发快但也可能退潮快企业蹭概念很容易，投资时看真业绩，别只看"经济"标签对个人：知道自己属于哪个"经济"，能避开为概念多付的溢价

## 3. 怎么用：你是哪个"经济"的贡献者

盘点自己的钱去哪了：外卖费、宠物开支、情绪消费各占多少想省钱，先砍"为省事付的溢价"：预制菜 vs 自己煮想投资，看政策支持和真需求：养老、宠物比纯概念更稳给自己设消费标签：别让"单身经济"变成"孤独税"
