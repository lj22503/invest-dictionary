# CTA 策略

> 让程序跟着趋势自动买卖期货的基金策略，俗称"管理期货"，专门赚"大行情"的钱。

## 1. 这是什么

CTA（Commodity Trading Advisor，商品交易顾问）策略，简单说就是：用计算机模型追踪价格趋势，趋势向上就做多、趋势向下就做空，主要战场是期货市场（股指期货、商品期货、国债期货等）。

它不是靠"预测"赚钱，而是靠"跟随"：模型检测到某个品种开始持续上涨或下跌，就顺势进场，赚趋势延续的那一段。因为可以多空双向操作，理论上"涨也赚、跌也赚"，但前提是——得有像样的趋势。

打个比方：CTA 像冲浪的人，不预测浪什么时候来，但浪一起来就站上去，浪平了就下来等下一波。

## 2. 为什么重要

CTA 最大的价值是"危机阿尔法"：它和股票、债券的相关性都很低，股市大跌时它常常能赚钱或少亏，是资产配置里的"保险丝"。

真实例子：2022 年全球股债双杀（沪深 300 跌约 21%、债券基金也回撤），但不少 CTA 策略反而盈利——因为当年商品市场（原油、天然气等）走出大趋势，趋势跟踪策略赚到了钱。这类"别人亏它不亏"的特性，正是机构和个人把它加入组合的原因。

对普通人的意义：如果你持有一堆股票基金，加一点 CTA 类产品，可以在系统性下跌时平滑整体波动。但它不是稳赚神器，震荡市里它会反复挨打。

## 3. 怎么用 / 怎么看

- 先看相关性：一个 CTA 基金和沪深 300 的滚动相关性如果长期接近 0 甚至为负，才是真正有"分散价值"的；相关性高的 CTA 意义不大。
- 再看回撤：CTA 在震荡市可能连续回撤 10%~20%，先问自己扛不扛得住，再决定配多少（一般建议占总仓位 5%~15%）。
- 看收费结构：CTA 普遍收"管理费 + 业绩提成"（常见 1.5% + 20%），业绩提成可能按新高法（创新高才提），看清楚再买。
- 看策略类型：趋势跟踪（赚大行情）、套利类（赚价差）、主观 CTA（靠人判断），不同类型风险收益差别很大，别只看"CTA"三个字。
- 口诀：危机才显身手、震荡最磨人、相关性第一位、回撤先问自己。

## 4. 常见坑 / 误区

- 以为 CTA"永远赚钱"：它是趋势策略，震荡市（涨一点跌一点反复来回）里会被来回打脸，连续小亏很正常。
- 把"涨也赚跌也赚"理解成"每天都赚"：CTA 赚的是大趋势的钱，不是每天的钱，拿它当短线工具会很难受。
- 只看历史高收益：过去几年商品大牛市让 CTA 业绩很好看，但那是"有趋势"的年份；遇到趋势平淡的年份，收益可能很平庸甚至为负。
- 忽视业绩提成：业绩提成按 20% 算，意味着基金赚 20%，你要分 4% 给管理人；长期下来成本不低，别只看宣传的"年化收益率"。
