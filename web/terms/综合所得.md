# 综合所得

> 把工资、劳务、稿酬、特许权使用费四类收入合并计税，按年算总账、多退少补。

## 1. 四类收入合并算账

**综合所得 = 工资薪金 + 劳务报酬 + 稿酬 + 特许权使用费，四类收入合并后按年计税。**
2019 年个税改革前，这四类是分开算税的；改革后合到一起，按年累计收入对照 3%~45% 的超额累进税率。
每类收入的“打折不样”：劳务报酬按收入的 80% 计入、稿酬按 56% 计入（80%×70%）、工资全额计入。
> 一句话：综合所得是“四项收入一张税单，一年算一次总账”。

## 2. 为什么重要：它决定你每年交多少税

你每个月工资条上的个税，只是“预缴”；全年到底该交多少，要看年度综合所得总额落在哪个税率档。
很多人除了工资还有兼职（劳务报酬）、写稿（稿酬）、专利授权（特许权使用费），这些收入单独看税率低，合并后可能跳档——所以预缴和实际该缴常常对不上。
每年 3~6 月的个税汇算清缴，就是把四类收入合并算一遍：多预缴的退税，少预缴的补税。
> 一句话：不搞懂综合所得，你可能多交税，也可能被通知补税。

## 3. 怎么用：汇算清缴就是多退少补

- **每年 3~6 月办理汇算**：在“个人所得税”App 里申报综合所得年度汇算，系统会自动算出应退/应补；
- **检查专项附加扣除**：房贷、租房、赡养老人、子女教育等扣除项别漏填，每项都能直接抵税；
- **核对四项收入**：劳务报酬、稿酬是否被预扣税了但没进综合所得申报，别让收入“漏报”；
- **补税别拖着**：应补未补会收滞纳金，次年汇算前补齐更稳妥。
> 一句话：每年 3 月打开个税 App，把一年的账算明白。

## 4. 常见坑：以为劳务报酬不用报税

- **以为兼职收入不用交税**：劳务报酬超过 800 元就要预扣个税，且要并入综合所得；
- **漏报稿酬**：写稿、公众号流量主收入都是稿酬所得，同样要并入年度汇算；
- **重复填扣除**：房贷和租房不能同时享受专项附加扣除，二选一；
- **以为补税是坏事**：说明你收入结构在变好，配合汇算补齐即可，别用逃避心态处理。
