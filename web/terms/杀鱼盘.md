# 杀鱼盘

> 杀鱼盘，是针对"想占小便宜"人群的诈骗：假红包、假返利、假优惠，先给甜头再杀一刀。

## 1. 专钓"贪小便宜"的鱼

骗术圈把受害者分"猪、鸟、鱼"：杀猪盘骗感情，杀鸟盘骗兼职，杀鱼盘骗"贪便宜"——"扫码领红包""进群领优惠券""0元购""做任务返利"，用蝇头小利引你上钩，再让你垫钱、交保证金、套个人信息。
> **一句话**：你以为在薅羊毛，其实你是那条鱼。

## 2. 为什么重要：金额不大，但收割效率极高

单笔几百到几千，很多人被骗了也不报警，骗子成本极低利用"贪便宜"心理，受害者往往不止一次上当有的杀鱼盘和刷单、贷款诈骗串联，小骗变大骗个人信息一旦交出，后续会不断被精准轰炸

## 3. 怎么用：识别杀鱼盘的三步

看动机：真优惠不用你"垫钱"，凡是先转钱再返利=诈骗看平台：拉进微信群/QQ群做任务返利，基本全是杀鱼盘看规则：提现要"满额""冲正""解锁"，都是拖着你不让走守住底线：任何情况不交出验证码、支付密码、身份证照片

## 4. 常见坑：以为薅到羊毛，其实被宰

"做任务返利"前三单真给钱，第四单就让你垫大额"0元领手机"要你付运费+保证金，钱一去不回杀鱼盘也玩"内测名额"：说是限量的，其实是演给你看的被骗后别"自认倒霉"，保存记录去反诈中心报案，小额也要报
