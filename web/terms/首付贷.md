# 首付贷

**一句话定义：首付贷 = 借钱付首付。首付不够，中介或贷款机构帮你垫上，本质是"用贷款的钱再去贷款买房"。**

## 1. 这是什么

首付贷不是一款固定产品，而是一类"凑首付"的操作总称：开发商垫资、消费贷/信用贷套出来付首付、过桥资金短期垫付、甚至"首付分期"打白条。买家以为自己只是"提前上车"，实际上是在负债之上再加负债。

## 2. 为什么重要

监管部门对首付贷的态度是明令禁止：首付必须是自有资金。因为一旦允许借钱付首付，楼市的杠杆会被无限放大——房价一跌，先崩的就是这批"零首付"买家；银行按揭也形同虚设，系统性风险成倍增加。对个人来说，首付贷的利率远高于房贷，而且放贷机构随时可能抽贷，等于把房子盖在流沙上。

## 3. 怎么用

- 首付不够时，先看正规替代：攒够再买、降低预算、公积金余额提取、父母/亲友真实赠与并留好转账凭证
- 真需要周转，用期限长、利率低的公积金或消费贷，并确保资金流水能证明"自有"
- 签约前问清三个问题：钱从哪来、利率多少、银行会不会发现
- 保留所有还款凭证，避免被认定为违规挪用

## 4. 常见坑

- 中介承诺"包过审"，结果被银行拒贷，定金和垫资利息全打水漂
- 经营贷/消费贷套现付首付，被银行查到后抽贷断贷，征信直接变黑
- 开发商垫资看似"免息"，其实利息藏在房价里
- 首付分期合同条款模糊，逾期一天就按高利贷计息
