# 白户 / 花户

**一句话定义：白户 = 从没贷过款也没办过信用卡，征信是一张"白纸"；花户 = 短期申请记录太多，把征信"刷花"了。**

## 1. 这是什么

征信报告里有两类人让银行很纠结：白户查不到任何借贷历史，银行不知道你靠不靠谱；花户则刚好相反——一打开报告，全是各种贷款和信用卡的申请查询记录。一个是"没历史不敢批"，一个是"到处借钱不敢批"，殊途同归：都容易被拒贷。

## 2. 为什么重要

银行审批贷款时，白户和花户都过不了"评分关"：白户缺乏信用行为数据，模型给不出高分；花户的"硬查询"次数太多，被解读为极度缺钱、多头借贷的信号。这直接影响你能不能贷到款、利率高不高——同样是买房，别人 3.9% 你 4.8%，二十年下来差出一辆车的钱。

## 3. 怎么用

- 白户养征信：办 1-2 张信用卡，正常消费、按时还款，6-12 个月就有信用记录
- 花户养征信：立刻停止一切贷款和信用卡申请，硬查询记录 2 年滚动消失，通常 3-6 个月就有改善
- 只保留真实需要的账户，长期不用的卡及时注销
- 申请前先查自己的征信报告，心里有数再动手

## 4. 常见坑

- 为了"养征信"频繁申卡，越申越花
- 相信"征信修复"中介，钱花了，查询记录还多了一条
- 白户为了有记录去借高息小贷，得不偿失
- 代养征信骗局：把手机号和验证码交出去，被拿去申请贷款
