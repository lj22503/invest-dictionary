自动续费陷阱

—— 理财字典 · 第十七篇：日常支付与账户管理

①

你手机里藏着一台自动印钞机

不是帮你印钞票，是帮别人从你口袋里印。

你下载过一个扫描APP，点了"免费试用7天"，7天后你忘了。一年后换手机翻账单，才发现它已默默扣了你198元。

你不是一个人。每三个订阅用户里，就有一个——至少一个——正在为某个"忘了关"的服务付款。

自动续费不是"方便你续费"，是"赌你忘记关"。你每忘一个月，商家就多赚一个月的钱。他们的商业模式，就是你的遗忘。

想想看：你现在能说出你正在为几个APP付月费吗？说不出来？那就有问题了。

②

小王换了手机，才发现2000多块不见了

小王用了一年多的华为手机，换新机时导出账单。不看不知道——每个月都有几笔9.9、19.9、29.9的小额扣款。加起来一算，过去18个月，自动续费总共扣了他2300多块。

五笔扣款来自：一个修图APP（月费19.9）、一个"永久免费"的PDF工具（月费29.9）、一个当初为了看一部剧买的视频会员（月费25）、一个天气预报APP（月费9.9）、一个冥想APP（年费198）。

五笔里，小王真正在用的只有一个（视频会员）。其他四个，他早就忘了存在。

9.9元——"一顿早餐钱"。19.9元——"一杯奶茶"。这些微小的数字恰好低于你的"警觉阈值"。你不会为9.9块打开APP翻三层菜单去取消——你的大脑自动把它归类为"不值得花时间处理的事"。

商家的精算师早就知道：金额越低，取消率越低。这就是为什么自动续费很少超过30元/月。

③

今天花5分钟，做一次订阅大扫除

  • 微信：我 -> 服务 -> 钱包 -> 支付设置 -> 扣费服务 -> 逐个检查，不需要的点进去"关闭服务"。
  • 支付宝：我的 -> 设置（右上角） -> 支付设置 -> 免密支付/自动扣款 -> 逐个检查并关闭。
  • Apple用户：设置 -> 点击头像 -> 订阅 -> 查看所有活跃订阅并取消不需要的。
  • 关完后，截一张当前订阅列表的图，下个月同一天再打开对比——看看有没有"新来的"。

以后任何"免费试用"——先在手机日历设一个试用到期前2天的提醒，提醒自己决定要不要续。

④

你买的是"服务"，还是"忘了关"？

自动续费最深的陷阱不在钱包——在心理。

它让你产生一种错觉："我在用"。你每月付着云存储的钱，但你最后一次打开那个APP是什么时候？你付着健身APP的年费，但你已经三个月没点开它了。

你买的不是服务，是"以为自己在用"的感觉。这种幻觉每月只要9.9——不算贵，但你不买的话，钱还是你的。

更深的追问：为什么我们宁可每月被扣9.9，也不愿意花3分钟去关掉它？

因为关掉意味着承认——"我当时下载它是个冲动的决定，后来也一直懒得管"。自动续费是商家喂给你的"不做决定的舒适区"。走出舒适区需要意志力，而9.9块一个月，刚好低于你动意志力的价格。
