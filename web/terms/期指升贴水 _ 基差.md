# 期指升贴水 / 基差

> 股指期货价格比现货（指数）贵叫"升水"，便宜叫"贴水"，这个差价就是"基差"。

## 1. 这是什么

基差 = 期货价格 − 现货价格。股指期货（比如沪深 300 股指期货）的价格，通常不会和现货指数完全一样：期货贵就叫升水（正基差），期货便宜就叫贴水（负基差）。

打个比方：你楼下超市的鸡蛋今天 5 元一斤（现货），但"三个月后提货的鸡蛋合约"标价 5.5 元（期货）——这就是升水；如果只标 4.8 元，就是贴水。

基差存在的原因：一是资金成本（持有现货要占用资金，期货相当于"先锁定价格、后付钱"，里面含着利息）；二是市场对未来的预期（大家觉得后面要涨，期货就抢着溢价买，反之就折价卖）。到了交割日那天，期货价格会强制向现货价格靠拢，这个"靠拢"叫基差收敛。

## 2. 为什么重要

升贴水是市场情绪的"体温计"，尤其对做对冲的人，它是实打实的成本。

举个真实例子：2024 年初 A 股连续调整，沪深 300 股指期货一度出现明显贴水（期货比现货便宜 1%~2%）。贴水意味着：做空股指期货对冲的人，能以"打折价"买到保护——但对做市场中性策略的基金来说，贴水就是额外的对冲成本，贴水越深，策略越难赚钱。

反过来，如果期货大幅升水（比如 2020 年 7 月行情启动时），说明市场情绪火热、大家抢着看涨，这时候现货往往也在往上走；但升水太高，也常被解读为"短期涨过头"的信号。

一句话：升贴水不决定你买哪只股票，但它决定"市场现在怕不怕、贪不贪"，以及"对冲要花多少钱"。

## 3. 怎么用 / 怎么看

- 看方向：期货 > 现货 = 升水（偏乐观）；期货 < 现货 = 贴水（偏谨慎），方向反映市场情绪。
- 看幅度：基差超过 1% 就算比较极端（历史上沪深 300 期指贴水超过 2% 往往伴随阶段性底部区域），幅度越大，情绪越极端。
- 看变化：贴水在收窄还是加深？贴水持续收窄，往往意味着恐慌在缓解；突然加深，可能是避险需求爆发。
- 看期限：近月合约（当月/下月）的升贴水更贴近当下情绪，远月合约更多反映长期预期，别拿远月说近事。
- 口诀：情绪看方向、极端看幅度、缓解看收敛、交易看交割——到了交割日，基差基本归零。

## 4. 常见坑 / 误区

- 把升水当"必涨信号"：升水只说明"期货买家愿意出更高的价"，不等于现货明天就涨，极端升水后回落的情况很常见。
- 把贴水当"必跌信号"：2024 年初贴水很深，但随后市场反而走出一波反弹——贴水是情绪极值，往往对应"别人恐惧"的位置。
- 忽略交割日收敛：基差不会永远存在，交割日前必须收敛；如果你拿远月合约猜基差，却忽略了时间价值，容易看走眼。
- 拿商品期货的升贴水逻辑硬套股指：商品有仓储、运输成本，升贴水含义更复杂；股指的升贴水更接近"情绪 + 资金成本"，两者别混为一谈。
