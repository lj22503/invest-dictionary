# 房贷利率 / 首付比例

> **房贷利率 = 你借银行的钱一年要付的利息比例；首付比例 = 买房时必须先自己掏的那部分房款。** 房贷利率主要看 LPR（贷款市场报价利率）+ 加点，首付比例各地因城施策（首套/二套不同）。

## 1. 这是什么

**房贷利率 = 你借银行的钱一年要付的利息比例；首付比例 = 买房时必须先自己掏的那部分房款。** 房贷利率主要看 LPR（贷款市场报价利率）+ 加点，首付比例各地因城施策（首套/二套不同）。

## 2. 为什么重要

它们一起决定你"买不买得起"和"供不供得起"：利率差 1 个百分点，30 年 300 万贷款月供能差几百元、总利息差几万到几十万；首付比例则直接决定上车门槛。

## 3. 怎么用 / 怎么看

- 1. 看 LPR：每月 20 日公布，5 年期以上 LPR 是房贷基准。
- 2. 算加点：你的房贷利率 = LPR + 加点，同一 LPR 下加点因人而异。
- 3. 试算月供：用房贷计算器输入金额、期限、利率，月供占收入比建议 ≤30%。

## 4. 常见坑 / 误区

- - 只看"利率下降"不看加点，存量利率可能并不便宜。
- - 首付比例各地不同，买前先查当地政策。
- - 月供占比超收入一半，等于给银行打工。
- - 以为是固定利率，实际可转 LPR 浮动。
