# 双循环 / 内循环 / 外循环

> **双循环 = 以国内大循环为主体、国内国际双循环相互促进的发展格局；内循环指国内生产-分配-消费的闭环，外循环指进出口与跨境投资。**

## 1. 这是什么

**双循环 = 以国内大循环为主体、国内国际双循环相互促进的发展格局；内循环指国内生产-分配-消费的闭环，外循环指进出口与跨境投资。**

## 2. 为什么重要

大国经济不能只靠外需：外部波动大时，内需是稳定器；同时外循环保持竞争力，两端平衡才能抗风险。

## 3. 怎么用 / 怎么看

- 1. 看内需：消费、地产、基建投资数据。
- 2. 看外需：出口、贸易顺差、汇率变化。
- 3. 找交集：国产替代、扩大内需是长线主线。

## 4. 常见坑 / 误区

- - 以为双循环=闭关锁国：外循环依然重要。
- - 只看口号不见数据：政策落地看投资和消费数据。
- - 忽视供给端：内循环也要技术和供应链自主。
