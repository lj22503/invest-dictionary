# 养老规划五步法

**一句话定义：养老规划五步法 = 算缺口 → 定目标 → 选工具 → 配比例 → 动态调，把“老了够不够花”的模糊焦虑，拆成五道能算清的题。**

## 这是什么

它不是一个理财产品，而是一套流程。第一步算缺口：估算退休后每月要花多少（生活费、医疗、爱好），减去社保和已有积蓄，缺口自然浮现；第二步定目标：把缺口换算成每月存多少、期望收益率多少；第三步选工具：社保打底、个人养老金省税、商业养老险锁长期、基金定投博增长；第四步配比例：年龄越大稳健资产占比越高；第五步动态调：每年或家庭大变故后复盘调整。

## 为什么重要

社保养老金替代率普遍只有 40%-50%，退休后收入可能腰斩，缺口只能自己补。个人养老金账户每年 1.2 万元额度还有节税效果，放着不用就是浪费。

## 怎么用

先把个人养老金 1.2 万元/年的税优额度用满，再用“退休收入测算”类工具重算缺口，最后按年龄配好稳健与进取的比例。

## 常见坑

没算缺口就买产品；忽略通胀和长寿风险；把社保当全部；定投比例十年不变；以为一次规划管一辈子。
