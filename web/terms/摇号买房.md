# 摇号买房

**一句话定义：摇号买房 = 新房开盘时大家先登记，再由公证处像抽签一样随机决定谁能先选房，用来给"打新热"降温。**

## 1. 这是什么

当新楼盘限价、和周边二手房出现明显价差时，买到就是赚到，看房人能把售楼处挤爆。摇号买房就是在这种情况下推出的分配机制：符合条件的购房人先登记、冻资，再由公证机构公开摇号，中签者按顺序选房。部分城市还会给无房家庭、人才优先的摇号批次，保证刚需先上车。

## 2. 为什么重要

没有摇号之前，热门楼盘拼的是"关系"和"茶水费"，普通人连参与资格都没有。摇号把分配权交给随机性，让价差红利有机会落到真刚需头上。对购房者来说，理解摇号规则意味着你知道自己该走哪个批次、冻资要冻多少钱、中签率大概多少——这些直接决定你的打新策略。

## 3. 怎么用

- 提前查楼盘"登记时间表"和社保/户口积分规则，确定自己属于哪个批次
- 按时登记并冻资（冻资一般冻结到摇号结束，期间资金不可用）
- 摇号当天盯结果，中签后按顺序选房，选完当场签约交定金
- 没中签及时解冻资金，保持征信干净，下次再战

## 4. 常见坑

- "内部名额""茶水费"骗局：正规楼盘摇号全程公证，任何收钱保中签都是诈骗
- 中签后弃选：定金不退，还可能被记入"摇号黑名单"一段时间
- 为了凑无房资格假离婚/腾名额，结果人房两空
- 只盯价差不看楼龄和品质，买到"倒挂"的老盘，卖时才发现不好出手
