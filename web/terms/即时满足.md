# 即时满足

> 即时满足，是"想要就立刻得到"的冲动；与之相对的是延迟满足——等一等再拿。

## 1. "想要"和"等得起"的拉锯战

刷到新手机，马上就想下单；看到奶茶，立刻想喝；发工资就想犒劳自己。即时满足就是这种"念头一起、立刻满足"的模式。与之相反，延迟满足是愿意把快乐放到后面：先存钱，后享受。
> **一句话**：一个马上爽，一个以后爽。

## 2. 为什么重要：它决定你的钱往哪走

大部分月光、负债，都是从"即时满足"开始累积的商家设计"一键下单、先用后付"，就是放大你的即时满足投资里也一样：追涨杀跌是即时满足，定投是延迟满足能控制即时满足的人，存得下钱、拿得住资产、睡得着觉

## 3. 怎么用：把"立刻要"改造成"计划要"

想买大件先加购物车，设7天冷静期，70%的冲动会消失给"想要"排优先级：愿望清单里只留最想要的三样用"先付款后到账"的强制储蓄（定投、零存整取）对冲冲动把延迟满足变成习惯：每忍住一次，奖励自己记一笔

## 4. 常见坑：把"即时满足"妖魔化

即时满足不是罪恶，它是人性；完全压抑会反弹成报复性消费不是所有即时消费都错：吃饭、交通、小额快乐很正常别用'延迟满足'绑架自己到苦行僧，那样反而更难坚持警惕"先用后付/花呗"这类工具：它们把即时满足的成本藏起来了
