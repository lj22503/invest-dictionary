# 期权到期日 / 行权

> **到期日 = 期权合约的最后一个交易日；行权 = 到期时按约定价格买入或卖出标的资产。** 期权是有“保质期”的，过期作废。

## 1. 这是什么

**到期日 = 期权合约的最后一个交易日；行权 = 到期时按约定价格买入或卖出标的资产。** 期权是有“保质期”的，过期作废。

## 2. 为什么重要

到期日当天，期权的时间价值清零：实值期权（行权价优于市价）不行权就白白损失内在价值，虚值期权（行权价不利）行权反而亏更多。

## 3. 怎么用 / 怎么看

- 1. 到期前确认自己是实值还是虚值。
- 2. 实值期权：提前平仓或准备行权资金。
- 3. 虚值期权：直接放弃，别强行行权。

## 4. 常见坑 / 误区

- - 忘记到期日：实值期权没平仓/没行权，收益归零。
- - 虚值强行行权：行权价不利还硬买，亏上加亏。
- - 最后一天才操作：流动性差，滑点大。
