# 放量上涨 / 缩量下跌

> **放量上涨 = 成交量明显放大同时股价上涨；缩量下跌 = 成交量明显萎缩但股价下跌。** 量价配合是判断趋势真假的核心工具。

## 1. 这是什么

**放量上涨 = 成交量明显放大同时股价上涨；缩量下跌 = 成交量明显萎缩但股价下跌。** 量价配合是判断趋势真假的核心工具。

## 2. 为什么重要

放量上涨说明资金真金白银进场，趋势可信；缩量下跌说明抛压不大，往往是洗盘而非崩盘。反之放量下跌要警惕出货。

## 3. 怎么用 / 怎么看

- 1. 放量上涨：趋势启动，可跟踪。
- 2. 缩量上涨：动能不足，警惕见顶。
- 3. 放量下跌：出货信号，先撤。
- 4. 缩量下跌：洗盘居多，观察支撑。

## 4. 常见坑 / 误区

- - 只看价不看量：假突破骗你进场。
- - 只看量不看位置：底部放量和顶部放量完全相反。
- - 把缩量下跌当没事：长期缩量阴跌也是慢性失血。
