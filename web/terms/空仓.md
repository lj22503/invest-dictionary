# 空仓

> 手里一只股票（或基金份额）都没有，全部是现金——这也是一种仓位状态，叫"空仓"。

## 1. 这是什么

空仓 = 不持有任何仓位。你今天打开账户，股票持仓为零、全是可用资金，就是空仓。

很多人把"空仓"当成"踏空"或"失败"，其实它是仓位管理里一个正经的状态：满仓是"全押上"，半仓是"留一半"，空仓是"先观望"。空仓不等于离开市场，而是"拿着现金等机会"。

打个比方：空仓像开车时挂空挡——不是要停车回家，而是路况不明的时候先不踩油门，看清了再挂挡走。

## 2. 为什么重要

空仓最大的作用是"躲开下跌"：市场趋势向下的时候，你不在场内，就不会亏钱，还留着一手现金，跌出来的便宜货你有钱捡。

但它也有代价——"躲过下跌"的另一面是"错过上涨"。2024 年 9 月底 A 股突然放量大涨，不少提前空仓的人眼睁睁看着踏空，比亏钱还难受。空仓的意义不是"永不亏损"，而是"在你没有把握的时候，用现金保护自己"。

对普通投资者来说，空仓是一种被严重低估的能力：大部分人是"永远满仓"，所以涨跌全靠运气；会空仓的人，至少把"看不清就不动"写进了自己的纪律。

## 3. 怎么用 / 怎么看

- 判断趋势：大盘处于明确的下跌趋势（均线空头排列、反弹一波比一波低）时，空仓是合理选择，别用"万一反弹呢"说服自己接飞刀。
- 判断胜率：你研究半天也说不清"现在该买什么、为什么买"，说明胜率不够，先空仓、继续观察，好过瞎买。
- 设定空仓纪律：比如"跌破某条关键均线就清仓、等重新站稳再回来"，把空仓变成规则，而不是情绪。
- 空仓期间做功课：别干等，把目标股票列好，设好观察价，机会来了第一时间执行。
- 口诀：看不清就空仓，下跌趋势不硬扛，空仓不是不关心，是在等更好的价格。

## 4. 常见坑 / 误区

- 空仓焦虑、手痒乱买：空仓两天就受不了，随便买只股票"解闷"，结果本来躲过的下跌全挨回来。
- 把空仓当"踏空"：踏空是"想买没买、看着涨"，空仓是"主动选择不买"，心态完全不同；主动空仓的人不会因为反弹一天就崩溃。
- 从满仓突然变空仓的极端：要么永远满仓，要么一慌全清，没有中间态——这不是纪律，是情绪化，来回打脸成本很高。
- 空仓=完全退出：空仓时连盘都不看、功课也不做，等行情真来了，你也不知道该买什么，等于把主动权交给别人。
