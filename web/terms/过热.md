# 过热

> **过热 = 经济增速超过潜在产出，需求太旺、供给跟不上。** 表现：物价上涨、产能紧张、资产泡沫、央行加息收紧。

## 1. 这是什么

**过热 = 经济增速超过潜在产出，需求太旺、供给跟不上。** 表现：物价上涨、产能紧张、资产泡沫、央行加息收紧。

## 2. 为什么重要

过热是繁荣的最后阶段：看起来一片火热，实则通胀侵蚀购买力，央行加息会刺破泡沫，股市债市都可能剧烈调整。

## 3. 怎么用 / 怎么看

- 1. 关注央行是否连续加息。
- 2. 减少高估值成长股，留意现金流好的价值股。
- 3. 债市警惕利率上行，现金和短债是避风港。

## 4. 常见坑 / 误区

- - 把过热当繁荣：最后接盘的人最惨。
- - 忽视政策转向：加息周期里高杠杆资产最受伤。
- - 以为过热永远持续：周期终会反转。
