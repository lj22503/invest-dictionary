About

谁在写这些词条、怎么写、以及我们绝不做什么。

投资词典（dictionary.mangofolio.com）是 Mangofolio 系列中的一块——术语平权。我们不卖课、不代客理财、不接荐股广告，只做一件事：把投资的词，翻译成人话。

1. 我们是谁

本站由 Mangofolio 团队维护，是一个独立的投资术语科普与投教参考站点。我们不是持牌投资咨询机构，不提供任何面向具体个人的投资建议。

团队背景：长期做投资内容产品与金融数据工具（投资大脑 Brain、投资伙伴 Buddy、市场观察 View、财务工具箱 FinTools 均属同系列）。词条写作采用「AI 起草 + 人工整理校订」的方式，公开在 GitHub 仓库，接受公开纠错。

2. 我们怎么写词条

每个词条固定四张卡，顺序是刻意设计的：

  • 一句话：只用一句大白话说清它是什么，不许出现术语解释术语；
  • 它到底在说什么：把定义拆成人能联想的场景；
  • 为什么它重要 / 坑在哪：讲清这个数字或概念会怎么影响你的判断；
  • 怎么用 / 怎么避坑：给可执行的自查动作，但不给买卖结论。

3. 三条编辑红线

① 说人话——能用生活比喻说清的，不许甩术语。
② 不堆术语——解释一个词时，不许引入三个你还得再去查的新词。
③ 不给买卖结论——本站不荐股、不预测点位、不给买入卖出建议，只讲概念本身和判断方法。

这三条是我们区别于大多数「财经科普」的地方，也是我们最不想妥协的部分。

  • 来源：公开金融教材、监管机构投教材料（证监会 / 央行 / 交易所投教栏目）、基金与银行公开披露文件、主流财经媒体的术语释义；
