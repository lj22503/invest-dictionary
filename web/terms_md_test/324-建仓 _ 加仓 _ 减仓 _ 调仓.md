# 建仓 / 加仓 / 减仓 / 调仓

> —— 理财字典 · 第十六篇：金融市场黑话与交易场景

**定义**：建仓=第一次买入，加仓=继续追加买入，减仓=卖出一部分，调仓=卖出一些再买入另一些来调整持仓结构。

## 什么是这四个动作：买卖节奏的四个手势

> 一句话：这四个动作组合起来，就是你的“买卖节奏”。

建仓=第一次买入某只股票或基金；加仓=在已有持仓上继续买入；减仓=卖出一部分，落袋或降风险；调仓=卖出一些、买入另一些，调整整体持仓结构。

做饭类比：建仓是下锅，加仓是添菜，减仓是盛出来一部分，调仓是把不好吃的换成好吃的。

## 为什么重要：会买的是徒弟，会卖的才是师傅

> 一句话：建仓决定成本，加减仓决定心态，调仓决定长期结构。

同一只股票，有人一次梭哈买在最高点，有人分批建仓摊低成本，两年后收益可能差一倍。

不懂减仓和调仓的人，赚了也会坐过山车亏回去——“会买”只决定起点，“会卖”才决定终点。

## 怎么用 / 怎么看：分批操作的口诀

建仓：首次买入计划仓位的 1/3 到 1/2，先试错再加大。

加仓：下跌时分批加要设上限（越跌越买不是无限摊），最好用定投自动执行，别因为手痒追高加仓。

减仓 / 调仓：达到目标收益或基本面变坏时执行；先卖“最不看好”的，而不是先卖“正在赚钱”的（那是处置效应）。

写下来：每次动作前记录理由，避免凭感觉乱动。

## 常见坑 / 误区：加仓摊平烂股最致命

**坑 1**：把建仓当 All in：一次梭哈式建仓，遇到回调只能干瞪眼。

**坑 2**：把加仓当成“摊平烂股”：基本面已经坏了还一路加仓，越跌越买是把小错变大错。

**坑 3**：减仓后马上后悔追回：落袋为安就安心，别看着它涨又高价买回来，来回打脸。
