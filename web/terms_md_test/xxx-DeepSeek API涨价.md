# DeepSeek API涨价

> —— 理财字典 · 每日热词

**定义**：DeepSeek官宣V4-Pro与调价方案：高峰时段输出最高27元/百万tokens，涨幅350%。AI服务为什么集体涨价？跟你有什么关系？

## DeepSeek 官宣涨价：最高涨 350%

> 一句话：AI 大模型集体涨价，背后是算力供需缺口——用 AI 的人越来越多，算力不够卖了。

8 月 13 日，DeepSeek 发布 V4-Pro 正式版，同时公布 API 调价方案，**8 月 17 日 0 点生效**。

采用`峰谷定价`：高峰时段（北京时间 9:00-12:00、14:00-18:00）V4-Pro 输出价 **27 元/百万 tokens**，较现价涨 350%；空闲时段 13.5 元。V4-Flash 高峰输出价从 2 元涨到 9 元。

这不是孤例——智谱年内三次上调 API 价格，Kimi K3 定价较上代提升 3-4 倍，腾讯云、阿里云、百度智能云都上调了 AI 算力产品价格。

## API 是什么，为什么要涨价

- **供需失衡。Token 调用量爆发式增长，但 AI 加速卡产能有限——涨价是供需矛盾的直接证据。**
- **国产替代。华为昇腾、寒武纪等国产 AI 芯片出货放量，算力供给正在补缺口。**
- **成本传导。大厂资本开支高企（腾讯上半年 847 亿、阿里三年或超 3800 亿），最终会体现到服务价格上。**

API（应用程序编程接口）就是**开发者按调用量付费、把大模型能力嵌进自己产品**的通道。你用的 AI 助手、写作工具，背后多半在调这些 API。

## 跟你有什么关系

- **AI 应用可能变贵。依赖 DeepSeek 等 API 的第三方 AI 工具、插件，很可能把成本转嫁给用户——订阅费、会员价留意下。**
- **免费额度更稀缺。大模型厂商涨价后，免费额度与低价套餐大概率收缩。**
- **算力投资。AI 芯片、算力租赁是这轮涨价的核心受益方向，也是普通人可通过基金间接参与的赛道。**

## 以后怎么看

- **看定价窗口。峰谷机制下，开发者会把重任务挪到夜间空闲时段，个人用户同理——错峰用更便宜。**
- **看资本开支。大厂算力投入（资本开支）是 AI 景气度的“晴雨表”，季报里重点看这项。**
- **记住一句话。AI 涨价不是终点，是算力从“补贴抢市场”走向“按成本定价”的转折点。**

记住：`模型越聪明，算力越金贵——AI 服务告别“白菜价”时代。`
