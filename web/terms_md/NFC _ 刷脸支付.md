# NFC / 刷脸支付

> 手机碰一下、脸一刷，钱就付完了。

## 1. 这是什么

**碰一下、刷个脸就付钱**

**NFC 支付 = 利用手机近场通信完成的支付（Apple Pay、华为 Pay、云闪付"碰一碰"）；刷脸支付 = 通过人脸识别完成付款（支付宝"刷脸付"、自助机刷脸买单）。**

> 一句话：扫码之外的两种"无感"支付方式，一个靠碰、一个靠脸。

## 2. 为什么重要

**为什么重要：更快更安全的支付**

- **快**：支付只要 1-2 秒，不用打开 App 找付款码；
- **安全**：NFC 用令牌（Token）技术，商家拿不到银行卡号；刷脸支付用生物特征，很难被盗刷；
- **无接触**：疫情后更卫生，公共交通、商超场景普及率高；
- **离线可用**：部分 NFC 支付在弱网环境也能完成。

## 3. 怎么用 / 怎么看

**怎么用：绑卡开通与验证**

- **NFC**：在钱包 App 绑定银行卡 → 双击电源键或靠近 POS 机 → 指纹/面容确认；
- **刷脸**：在支付宝等平台开通刷脸支付 → 绑定银行卡 → 商户设备前刷脸并确认；
- **小额免密**：低于免密额度（通常几百元）无需二次验证，大额仍需密码/指纹。

## 4. 常见坑 / 误区

**常见坑：误刷与信息泄露**

- **NFC 误触**：靠近 POS 机就触发小额免密，不留意可能被"碰一碰"扣款；
- **刷脸信息不可重置**：人脸泄露后没法像改密码一样"换脸"，风险更难补救；
- **限额更低**：NFC/刷脸支付单笔限额通常低于扫码支付，大额支付会失败；
- **攻击风险**：少数低端设备对照片、3D 面具攻击防护不足，尽量选官方渠道开通。
