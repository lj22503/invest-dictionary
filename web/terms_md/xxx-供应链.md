# 供应链

> —— 投资词典 · Invest Dictionary · 最后更新：2026-11-02

**定义**：从原料、生产、物流到柜台上那台手机，中间每一环串起来就是供应链——一环断，全线堵。

## 一台手机走完的链条

> 一句话：你买到的东西，是一整条链协作的产物。

**供应链 = 产品从原材料变成成品、再送到你手里的完整链条。**一台手机：芯片设计 → 晶圆制造 → 封测 → 组装 → 物流 → 门店，任何一环出问题，整条线都跟着停。

全球化之后，供应链早就跨出国境：中国的零件、韩国的屏幕、美国的芯片、东南亚的组装，**一条链牵动几个国家的工厂**。

## 通胀的开关，企业的命门

> 一句话：供应链紧张的时候，涨价的钱往往被上游赚走。

供应链是通胀的开关：运费暴涨、芯片缺货、港口拥堵，最终都变成你看到的价格上涨。它也是企业的命门：2021 年的"缺芯"让汽车厂停产，2022 年的运价让出口企业利润缩水。

对投资者，供应链是明晃晃的线索：**哪一环紧张，哪一环就在涨价、就有业绩弹性；哪一环在转移，哪一环就有新产能和新机会**。

## 四个观察口

- **看数据**：PMI 新订单、原材料库存、航运运价指数（SCFI/BDI），是供应链松紧的体温计。
- **看新闻**：缺货、涨价函、港口拥堵、工厂停电，都是供应链紧张的早期信号。
- **结合库存周期**：主动补库存 → 供应链景气上行；被动去库存 → 需求转弱信号。
- **看卡脖子环节**：越紧缺、越有定价权的环节，业绩弹性越大，国产替代是长期主线。

## 把紧张当长期利好

- **把供应链紧张当长期利好**：很多涨价是一过性的，产能释放后价格就回落。
- **只盯终端品牌、不盯上游**：涨价的钱往往被上游赚走，终端反而是受害者。
- **忽视物流环节**：运费是通胀传导的重要管道，别只看工厂报价。
- **把局部短缺当全局紧缺**：某一环堵 ≠ 整条链崩，分清结构性问题还是全局问题。
