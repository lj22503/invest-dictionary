# 云闪付

> 银联官方 App，一张 App 管多张银行卡。

## 1. 这是什么

**银行卡的聚合钱包**

**云闪付 = 中国银联推出的移动支付 App，绑定银行卡后可扫码付款、转账、查账单，还聚合了各家银行的优惠活动。**

> 一句话：微信、支付宝之外的"银联系"支付入口，主打银行卡聚合。

## 2. 为什么重要

**为什么重要：跨行转账不花钱**

- **跨行转账 0 手续费**：个人账户间转账免手续费，比传统网银转账省一笔；
- **一 App 管多卡**：多家银行卡的余额、账单、还款集中管理；
- **羊毛多**：银联和各银行经常发消费券、立减金、满减活动；
- **银联背书**：支付通道安全性有保障。

## 3. 怎么用 / 怎么看

**怎么用：绑卡、付款、薅羊毛**

- **注册绑卡**：手机号注册，绑定常用银行卡（Ⅱ类户也支持）；
- **付款**：出示付款码或扫商户二维码；
- **转账还款**：跨行转账、信用卡还款、查余额账单；
- **领优惠**：在 App 内领取各银行与银联活动优惠券，付款时自动抵扣。

## 4. 常见坑 / 误区

**常见坑：生态不如微信支付宝**

- **以为它取代微信/支付宝**：商户覆盖有限，很多小店不支持云闪付；
- **优惠有门槛**：立减金、满减券常有"满 X 减 Y"和使用商户限制；
- **付款码安全**：免密小额支付额度注意设置，付款码别截图外发；
- **App 功能重**：功能多但入口深，不常用容易忽略优惠。
