# 康波周期

> 康波周期，是俄国经济学家康德拉季耶夫提出的约 60 年一轮的超长经济周期，由技术革命驱动，分为回升、繁荣、衰退、萧条四阶段。

## 1. 这是什么

**康波周期 ≈ 60 年一轮的超长经济周期**，由俄国经济学家康德拉季耶夫提出，所以也叫“长波周期”。每一轮都由一次技术革命驱动：蒸汽机、铁路、电力、汽车、信息技术……

一轮康波分四阶段：`回升``繁荣``衰退``萧条`。新技术出来→资本涌入→产能过剩→危机出清→下一轮新技术接棒。
> 一句话：康波周期，是技术革命给经济上的“节拍器”。

## 2. 为什么重要

康波周期太长了，长到**决定一个人职业生涯里的大多数机会**。在新技术早期入场 vs 在产能过剩末期接盘，人生完全不同。
- <strong>繁荣期</strong>：景气行业工资、资产价格一起涨；- <strong>衰退萧条期</strong>：就业收缩、资产缩水，现金为王；- <strong>新回升期</strong>：新一代技术公司崛起，是长期布局窗口。> 一句话：看懂康波，不是预测明天，而是知道自己在历史长河的哪一段。

## 3. 怎么用 / 怎么看

- <strong>识别当前主导技术</strong>：AI、新能源、生物科技……康波新回升期往往对应新基础设施的普及；- <strong>长期资产配置顺周期方向</strong>：但要用自己能拿得住的仓位，而不是押注式梭哈；- <strong>结合经济周期一起看</strong>：康波定方向，基钦/朱格拉周期定节奏。> 一句话：康波是望远镜，别拿它当放大镜用。

## 4. 常见坑 / 误区

- <strong>把短期波动都归因于康波</strong>：大多数涨跌是库存周期或情绪波动，跟康波没关系；- <strong>预测拐点</strong>：60 年一轮的拐点极难精确定位，谁告诉你“马上萧条”都别全信；- <strong>因为“在衰退期”就不投资</strong>：个人现金流、资产配置依然要做，周期只是背景板。
