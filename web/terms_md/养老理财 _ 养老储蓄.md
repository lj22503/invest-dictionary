# 养老理财 / 养老储蓄

> 银行专为养老设计的理财和存款，期限长、收益稳。

## 1. 这是什么

**专为养老设计的钱袋子**

**养老理财 = 银行理财子公司发行的养老主题理财产品，封闭期通常 5 年以上；养老储蓄 = 银行推出的养老专属存款，利率一般高于普通定存。**

> 一句话：把"以后养老要用的钱"单独放一类长期产品里慢慢攒。

## 2. 为什么重要

**为什么重要：锁定长期收益**

养老资金最怕"追涨杀跌"和"随意挪用"，这类产品用长封闭期帮人管住手：

- 养老理财净值波动通常比普通理财平滑，主打稳健增值；
- 养老储蓄 5 年期利率可达 3% 左右，明显高于普通定存（约 2%）；
- 锁定长期收益，避免利率下行后无处安放。

## 3. 怎么用 / 怎么看

**怎么用：看期限、选风险**

- **看封闭期**：5 年以上起步，确认自己 5-10 年用不到这笔钱；
- **看风险等级**：多为 R1-R3，风险承受能力低优先选储蓄和 R1/R2 理财；
- **用闲钱投**：不要影响日常生活和应急资金；
- **组合配置**：养老储蓄 + 养老理财 + 商业保险搭配，分散单一产品风险。

## 4. 常见坑 / 误区

**常见坑：封闭期取不出**

- **养老理财不保本**：净值会波动，极端行情下可能亏损本金；
- **封闭期内取不出**：急用钱违约赎回要付高额费用或直接亏；
- **"养老"只是名字**：不看底层资产，养老理财也可能配权益类资产；
- **当活期用**：用随时可能要花的钱买长期养老产品，流动性错配。
