# 朱格拉周期

> 大约 8-10 年一轮的“设备更新周期”——企业集体换机器、扩产能，带来一波接一波的投资起伏。

## 1. 什么是朱格拉周期


**朱格拉周期 = 约 8-10 年一轮的“设备投资周期”。**机器会老化、产能会饱和，企业每隔一段时间就要集中换设备、扩产能，这个集体行为就形成了经济的中周期波动。
完整循环大概是：**设备老旧 → 企业集中更新 → 投资拉动经济 → 产能过剩 → 投资收缩 → 等设备再次老化**。经济学家朱格拉在 19 世纪发现，法国、英国、美国的这种投资波动，周期长度都落在 8-10 年左右。
> 一句话：朱格拉周期是“企业的换机周期”，机器换一轮，经济起伏一轮。


## 2. 为什么重要：中周期决定制造业景气


在层层叠叠的经济周期里，朱格拉周期正好卡在中间，承上启下：
- **比库存周期长**：库存周期（基钦周期）约 3-4 年，朱格拉周期约 8-10 年，一个朱格拉周期通常装下两三个库存周期；
- **比康波周期短**：康波周期约 50-60 年，是技术革命级的长波，朱格拉周期是其中一截；
- **决定制造业景气**：设备投资是制造业景气的发动机，判断周期位置可预判工程机械、机床、自动化等行业的表现；
- **与政策共振**：设备更新、以旧换新等政策会提前点燃设备投资，放大周期。
> 一句话：看懂朱格拉周期，就抓住了“制造业景气”的中期脉搏。


## 3. 怎么看：盯住设备投资这根线


- **看资本开支**：制造业投资增速、设备购置支出，是朱格拉周期的核心指标；
- **看产能利用率**：产能利用率高 → 企业有动力扩产；低 → 投资收缩；
- **看利润-投资链条**：企业利润改善 → 投资意愿上升 → 设备订单放量，是周期向上的信号；
- **叠加看**：与库存周期共振向上时，制造业景气弹性最大；方向相反时，以朱格拉周期为主。
> 一句话：朱格拉周期不盯“消费”，盯“企业愿不愿意花钱买设备”。


## 4. 常见坑：周期不是“准时器”


- **把库存周期当朱格拉周期**：两者长度差一倍，混用会把短期波动误判成中期趋势；
- **用单一指标判断阶段**：只盯某个月的投资数据，噪音太大，要看趋势与结构；
- **以为周期像时钟一样准**：8-10 年是统计规律，不是铁律，技术革命、政策刺激都会改变节奏；
- **忽视产业变革的“重塑”**：AI、新能源带来的设备革命，可能让传统设备周期提前或延长。
> 一句话：周期是“大概率的方向”，不是“精确的闹钟”。
