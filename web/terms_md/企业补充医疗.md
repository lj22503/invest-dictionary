# 企业补充医疗

> 公司额外买的商业医疗保险，报销社保不报的部分——员工福利，离职后往往失效。

## 1. 这是什么

**公司帮你多买的医疗报销**

**企业补充医疗 = 企业为员工购买的商业补充医疗保险，用来报销基本医保不覆盖的部分。**常见的有团体门诊险、住院补充险、重大疾病团体险等。

它是员工福利的一部分，保费一般由企业承担，员工看病后按规定报销。

> 一句话：社保报完剩下的，公司这份保险再帮你报一层。

## 2. 为什么重要

**为什么重要：社保外的第二道报销**

基本医保有起付线、封顶线和报销比例限制，门诊自付、乙类药、部分进口药都要自己掏钱。

举例：一次门诊花费 1000 元，医保可能只报 300，**企业补充医疗再把剩余合规部分报一部分</span>，员工自付大幅下降。

- 覆盖门诊、住院自付、家属子女（看方案）；
- 报销流程由保险公司与单位对接，个人操作少；
- 作为福利计入求职考量，但别当终身保障。

## 3. 怎么用 / 怎么看

**怎么用：报销时先社保后补充**

- **先走社保**：就医结算先刷医保，取得医保结算单；
- **再报补充**：按公司/保险公司要求提交发票、结算单、病历；
- **关注限额**：补充医疗有年度保额和报销比例，看方案说明书；
- **离职处理**：离职后多数不再续保，可在过渡期自行购买商业医疗险衔接。

## 4. 常见坑 / 误区

**常见坑：离职就没了，别当长期保障**

- **把公司福利当终身保障**：离职、裁员后保障立即中断，空窗期要自己补；
- **以为所有费用都报**：牙科、美容、既往症等免责项通常不报；
- **忘留票据**：补充医疗报销需要发票原件，丢了就报不了；
- **和医保个人账户混淆**：补充医疗是保险报销，不是账户余额。
