# 富时A50

> 富时A50，是追踪 A股 市值最大的 50 家公司（全是行业龙头）的指数，全球资金看中国股市先看它。

## 1. 这是什么

**富时A50（富时中国A50指数）由富时罗素编制，从沪深两市挑出市值最大的 50 家 A股 公司，按自由流通市值加权。**

它的成分股你基本都认识：贵州茅台、宁德时代、招商银行、中国平安、美的集团……这 50 家公司占了 A股 总市值的 30% 以上，是名副其实的"中国核心资产"。

比指数本身更有名的是它的**期货**：新加坡交易所（SGX）上市的 A50 期货，是境外资金唯一能直接对冲 A股 风险的工具，所以全球投资者盯着它。

> 一句话：富时A50 是 A股 的"龙头名单"，也是境外资金交易中国股票的"遥控器"。

## 2. 为什么重要

- **全球资金的风向标**：A股 收盘后（15:00）和节假日，A50 期货还在交易，美股开盘、突发消息都会先反映在 A50 上，第二天 A股 往往跟着它走。
- **境外对冲工具**：外资想对冲 A股 持仓风险，只能在新加坡用 A50 期货，它的价格里藏着外资的真实看法。
- **判断隔夜情绪**：晚上看 A50 期货涨跌，基本能预判第二天 A股 是高开还是低开。
- **龙头集中**：50 只龙头代表中国经济最强的一批公司，比上证指数更能反映"核心资产"的强弱。

它和上证 50 很像（都是大盘蓝筹），但编制规则不同：A50 覆盖沪深两市，上证 50 只覆盖沪市。

## 3. 怎么用 / 怎么看

- **隔夜看盘**：A股 收盘后，打开行情软件看"富时A50 期货"，涨跌 1% 以上通常预示次日 A股 有方向。
- **结合事件**：美联储议息、关税消息、美股大跌等，先看 A50 反应，再决定第二天 A股 操作。
- **买产品**：想配置 A股 龙头，可以买跟踪 A50 的 ETF（国内有 A50ETF），比选个股分散。
- **看北向资金配合**：A50 期货 + 北向资金流向同时指向一个方向，信号更可靠。
- **注意时差**：A50 期货日盘跟着 A股 走，夜盘跟着全球走，别把夜盘的波动直接当 A股 次日必然。

## 4. 常见坑 / 误区

- **把 A50 当 A股 大盘**：它只有 50 只股票，中小盘行情它反映不出来，指数涨不代表你手里的股票涨。
- **盯着 A50 做短线个股**：A50 反映的是大盘情绪，跟单只个股走势关系不大，别用它指导个股买卖。
- **忽略它只是"期货"**：期货有杠杆和基差，夜盘 A50 的波动幅度不能直接等同于 A股 涨跌幅。
- **把富时A50和上证50混为一谈**：两者成分股和编制方法不同，走势大体同步但细节有差异。
- **把夜盘跳空当必然**：A50 夜盘大跌 2%，A股 次日可能低开高走也可能低开低走，它只是概率参考不是预言。
