# 门诊统筹 / 住院报销

> 医保里门诊和住院两套报销规则：门诊统筹管看门诊的报销，住院报销管住院费用的报销。

## 1. 这是什么

医保里门诊和住院是**两套报销规则**：门诊统筹管你在门诊看病、买药的报销；住院报销管你住院期间费用的报销。前者用“门诊统筹基金”，后者用“住院统筹基金”。

简单说：同样一张医保卡，看门诊和住院走的是不同的“报销通道”。

> 一句话：门诊和住院，医保各有一本账。

## 2. 为什么重要

两套规则的报销比例差别可能很大：职工医保住院报销比例通常能到 70%–90%，而普通门诊统筹报销比例常在 50% 左右，有些城市还有起付线、封顶线。

看懂区别，你才知道“小病扛着不去看”和“大病拖成住院”哪个更亏。

- 门诊：起付线低或无、封顶线有限、比例偏低

- 住院：起付线较高、比例高、封顶线高

- 门诊慢特病：备案后门诊也能按较高比例报

> 一句话：报销比例可能差一倍，别用住院的账算门诊。

## 3. 怎么用 / 怎么看

- 看结算单两条线：起付线以下自付，起付线到封顶线之间按比例报

- 普通小病：优先走门诊统筹，别为报销去挂住院

- 慢性病长期用药：办理门诊慢特病备案，门诊报销比例大幅提高

- 异地就医：先备案（线上即可），否则报销比例可能下降

> 口诀：小病看门诊、大病住医院、慢病先备案。

## 4. 常见坑 / 误区

- 以为门诊一分不报：职工医保门诊统筹早就有了，只是比例低些

- 忽略起付线：金额没到起付线，确实报不了

- 为报销硬住院：门诊能解决的病硬住院，费钱又费时间

- 异地就医不备案：直接结算不了，报销比例还可能打折

> 一句话：规则两套，先看懂再就医，钱才不白花。
