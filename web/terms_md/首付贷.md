# 首付贷

> 借钱凑首付的违规贷款，风控红线别碰。

## 1. 这是什么

**借钱付首付的违规操作**

**首付贷 = 以"装修贷、消费贷、经营贷"等名义借钱用于支付购房首付。监管明确禁止：首付必须来自自有资金，信贷资金严禁流入楼市。**

> 一句话：把借来的钱当首付，等于把两个杠杆叠在一起。

## 2. 为什么重要

**为什么重要：双重杠杆风险高**

- **风控底线**：首付是银行评估还款能力的第一道闸，首付贷直接击穿它；
- **负资产风险**：首付只有两成还是借的，房价跌 20% 就可能资不抵债；
- **银行抽贷**：被发现首付资金来源异常，银行可拒贷、抽贷、要求提前结清；
- **法律风险**：伪造用途申请贷款，可能被认定骗取贷款。

## 3. 怎么用 / 怎么看

**怎么用：首付必须自有资金**

- **正确姿势**：首付用工资、存款等自有资金，不够就再攒、或降低总价预算；
- **识别套路**：中介推荐的"过桥 + 装修贷""经营贷买房"都是首付贷变种；
- **算清成本**：消费贷年化利率普遍 10% 以上，拿它付首付，月供压力巨大。

## 4. 常见坑 / 误区

**常见坑：装修贷/消费贷包装**

- **"过桥"陷阱**：先用过桥资金垫首付，再用消费贷还，链条一断就爆雷；
- **以为自己聪明**：银行风控一查征信消费贷记录，用途立刻穿帮；
- **期限错配**：首付贷一般期限短、利息高，现金流断裂风险大；
- **连累征信**：被抽贷、逾期，征信受损影响未来一切贷款。
