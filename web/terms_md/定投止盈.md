# 定投止盈

> 定投止盈，就是定投赚了钱后，在合适的位置分批卖出落袋为安，防止"赚了又亏回去"。

## 1. 这是什么

**定投止盈 = 给定投设置一个"卖点"，当收益率达到目标或估值进入高位时，分批卖出基金锁定利润。**

定投解决了"怎么买"，但很多人忽略"怎么卖"：市场从高点回落 30%，之前定投攒的浮盈可能全部蒸发，甚至转亏。止盈就是给这笔钱画一条"终点线"。

常见做法：**目标收益止盈**（收益率到 20% 就卖一部分）、**估值止盈**（指数估值分位高于 80% 就分批撤）、**回撤止盈**（从最高点回撤 10% 就触发卖出）。

> 一句话：定投是爬坡，止盈是到站下车，只爬不下车，山顶的风光会连本带利还回去。

## 2. 为什么重要

- **落袋才是赚**：浮盈不是收益，卖出才是。A股 波动大，牛短熊长，不止盈很容易"坐过山车"。
- **解决"贪"**：涨了 30% 想等 50%，涨了 50% 想等翻倍，最后跌回原点——止盈用规则对抗贪婪。
- **复利再出发**：止盈拿回的钱，可以在市场低位重新开始定投，资金循环利用，复利效率更高。
- **历史数据支撑**：长期定投若在牛市顶部不止盈，下一轮熊市可能把多年收益全部吞掉（2007 年、2015 年、2021 年都是活教材）。

定投 3~5 年一个周期，止盈一次、再定投一轮，比"永远不止盈"的长期收益高得多。

## 3. 怎么用 / 怎么看

- **先定目标**：常见目标年化 10%~15% 或累计收益 20%~30%，结合自己的风险承受力定一个数，写下来。
- **分批止盈**：到目标先卖 1/3 或 1/2，再涨再卖，避免"卖飞"后悔，也避免"没卖"坐过山车。
- **看估值辅助**：估值分位 > 70% 开始减，> 85% 大幅减，把"贵了"当止盈信号。
- **回撤止盈**：设定"从最高点回撤 8%~10% 就卖出"的移动止盈，牛市里让利润奔跑。
- **止盈后继续定投**：卖出的钱分批回到定投（或等市场回调再进），保持在场内。

## 4. 常见坑 / 误区

- **止盈后又追高**：卖飞后看它继续涨，忍不住全仓追回，结果买在山顶——止盈后的钱要管住手。
- **目标定太高**：定 100% 才止盈，大概率等不到，最后在山顶大回撤中离场。
- **只止盈不止损**：定投标的如果基本面恶化（如行业逻辑变了），该换标的一样要处理，不止是"等回本"。
- **把止盈当清仓离场**：止盈是"阶段收割"，不是"永久退出"，长期投资还是要保持在场。
- **忽视持有时间**：定投时间短（不到 1 年）就急着止盈，手续费高、复利没起来，止盈也别太频繁。
