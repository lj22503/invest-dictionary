# 红利低波

> 红利低波，是同时筛选“股息率高 + 股价波动小”的股票打包的 Smart Beta 策略，典型代表是中证红利低波动指数。

## 1. 这是什么

**红利低波 = 同时筛“股息率高 + 股价波动小”的股票打包。**红利因子管“分得多不多”，低波因子管“跌得狠不狠”，两者叠加，就是 Smart Beta 里的经典组合。

典型代表是`中证红利低波动指数`：成分股多为银行、煤炭、公用事业等现金牛行业，整体估值低、分红稳、波动小。
> 一句话：红利低波，是“既要收息、又怕颠簸”的折中方案。

## 2. 为什么重要

红利低波的核心价值在“体验”：
- <strong>熊市抗跌</strong>：低波因子天然过滤高波动股票，回撤通常更小；- <strong>震荡市有分红</strong>：股息是实打实的现金流，拿着不焦虑；- <strong>长期复利</strong>：红利再投资，长期累积效果显著。> 一句话：它不负责带你飞，但负责让你拿得住。

## 3. 怎么用 / 怎么看

- <strong>选跟踪指数</strong>：红利低波、红利低波 100、央企红利等指数编制规则不同，先看明白；- <strong>场内选 ETF、场外选指数基金</strong>：看自己交易习惯和申赎成本；- <strong>定投或长期持有</strong>：红利低波适合慢节奏，不适合频繁进出。> 一句话：先挑指数，再挑产品，最后挑费率。

## 4. 常见坑 / 误区

- <strong>高股息可能是股价跌出来的</strong>：股息率被动抬高的股票，分红不一定可持续；- <strong>低波动不等于不跌</strong>：系统性熊市里它也会跌，只是跌得少；- <strong>行业集中风险</strong>：红利低波常集中在少数顺周期行业，行业景气下行时同样难受。
