# 智能定投 / 估值定投

> 智能定投，是"升级版定投"：贵的时候少买、便宜的时候多买，用估值或均线自动调节每次扣款金额。

## 1. 这是什么

**智能定投（估值定投） = 在普通定投基础上，根据市场"贵不贵"自动调整买入金额的定投方式。**

普通定投每月固定扣 1000 元，不管市场贵贱。智能定投则加了一个"温度计"：

- **估值定投**：看指数的市盈率/市净率处在历史什么位置（估值分位），低于 30% 分位（便宜）就多买，比如 1.5 倍金额；高于 70% 分位（贵）就少买，比如 0.5 倍。
- **均线定投**：看指数高于/低于 500 日均线的程度，偏离越大越反向调节金额。

本质都是同一句话：**人弃我取，越跌越买，越涨越收**。

> 一句话：智能定投是把"低买高卖"写进规则里的定投，让机器帮你执行反人性操作。

## 2. 为什么重要

普通定投有个隐藏痛点：**在高位也照买不误**，如果从牛市顶部开始定投，可能定投好几年还在回本。智能定投就是来治这个病的：

- **降低持仓成本**：便宜时买得多，拉低平均成本，反弹时回本更快、收益更高。
- **自动止盈补仓的雏形**：贵时少买相当于"半止盈"，便宜时多买相当于"半抄底"，一进一出都在优化。
- **收益对比**：历史回测中，沪深 300 等宽基的智能定投长期收益率通常高于普通定投 1~3 个百分点/年。
- **适合宽基指数**：指数估值有锚（历史分位），个股没有，所以智能定投几乎都用在指数基金上。

它不改变"长期坚持"的底层逻辑，只是把"什么时候买多少"从拍脑袋变成有规则。

## 3. 怎么用 / 怎么看

- **选宽基指数基金**：沪深 300、中证 500、创业板指等有长期估值数据的指数，最适合估值定投。
- **打开"智能定投"开关**：支付宝、天天基金、且慢等平台都有智能定投功能，选"估值策略"或"均线策略"。
- **看估值分位**：分位 < 30% 加大投入，30%~70% 正常投，> 70% 减半或暂停，用平台的估值工具即可。
- **设好止盈**：智能定投解决"买"，不解决"卖"，配合估值高位的分批止盈，形成完整闭环。
- **坚持 3 年以上**：智能定投的优势需要一轮完整牛熊才能体现，短期看不出差别，别中途放弃。

## 4. 常见坑 / 误区

- **以为智能定投稳赚**：它只优化买入成本，市场长期下跌时照样亏钱，别神化"智能"二字。
- **用在行业基金上**：行业指数估值可能长期失真（如新能源从 60 倍跌到 20 倍还在跌），宽基才适合估值锚。
- **频繁切换策略**：估值策略和均线策略各有适用环境，换来换去等于没有策略。
- **忽略"贵了暂停"的纪律**：看到别人赚钱忍不住在估值高位恢复大额买入，智能定投就白搭了。
- **只看分位不看基本面**：估值分位是历史相对位置，遇到盈利大幅下滑，低分位也可能是"价值陷阱"。
