# XIRR（不定期现金流的内部收益率）

> 隔几个月投一笔、金额还不一样的时候，把所有现金流连同日期一起丢进去，解出一个真正按年计的实际收益率。

## 1. 它和 IRR 差在哪

两个都是让"现金流净现值等于零"的那个利率，区别只在时间间隔怎么算：

- **IRR** 假设每一期等间隔，第 3 期就是第 3 个周期，不问具体是哪一天
- **XIRR** 用真实日期，每笔现金流按 **实际天数 ÷ 365** 折现，公式是：Σ 现金流 ÷ (1 + r)^(天数 ÷ 365) = 0

XIRR 没有解析解，只能数值迭代逼近。Excel 里直接写 `=XIRR(现金流区域, 日期区域)`，第一笔现金流必须是投出的负数，且日期要与金额一一对应、按时间升序。

## 2. 为什么现实里更该用它

只要现金流不是严格等间隔，IRR 就会算错。典型场景：

- **不定额定投**：1 月投 1000、3 月投 3000、7 月忘了投，间隔和金额都在变
- **增额寿与年金险**：缴费期与领取期不规则，销售常报"复利 3%"，用 XIRR 一算才知道真实水平
- **分批建仓与加减仓**：每次买卖金额、日期都不同
- **分期与实际借款成本**：放款日、每期还款日对不上整月时，IRR 会偏离真实年化

## 3. 算例（数字是编的）

- 2025-01-10 投入 10,000 元
- 2025-07-15 追加投入 5,000 元
- 2026-01-05 全部收回 16,200 元

用 XIRR 解出来约 **9.85%**。总投入 15,000、赚 1,200，直觉上像"赚了 8%"，但因为第一笔钱放了将近一年、第二笔只放了不到半年，按资金实际占用时间加权后的年化是 9.85%。这就是 XIRR 与"总收益 ÷ 总投入"的根本差别。

## 4. 常见坑

- **忘了首笔必须为负**：符号全正或全负，函数直接报错
- **日期写成文本或月份序号**：XIRR 只认真正的日期值
- **现金流正负交替多次**：方程可能出现多个解，输出值要看是否符合场景，不能照抄
- **把它当承诺收益**：XIRR 描述的是已经发生（或假设发生）的现金流，不是未来能拿到的水平
- **不满一年也硬说年化**：短期用 XIRR 外推成年化，数字会被放大，波动大的品种尤其失真
- **和 IRR 混着报数**：同一笔投资用两种算法报出两个收益率，通常是在挑对自己有利的那个
