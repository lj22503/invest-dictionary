# 双循环 / 内循环 / 外循环

> —— 投资词典 · Invest Dictionary · 最后更新：2026-11-02

**定义**：双循环是以国内大循环为主体、国内国际双循环相互促进的新发展格局：内循环靠国内消费和生产，外循环靠出口和进口。

## 左手内需，右手外贸

**双循环 = 以国内大循环为主体、国内国际双循环相互促进的发展格局。**内循环 = `国内生产-分配-消费`的闭环；外循环 = `出口 / 进口 / 跨境投资`。

一句话：**左手练内功，右手做外贸**。

## 为什么重要：大国经济的底盘

- **内循环是稳定器**：外部贸易摩擦、需求收缩时，14 亿人市场托底；
- **外循环是竞争力**：出口、技术和供应链参与全球分工；
- **相互促进**：内需强大 → 企业做大 → 出海更有底气。

## 怎么用：三个维度看机会

- **看内需数据**：社会消费品零售总额、地产、基建投资，感受内循环热度。
- **看外需数据**：出口增速、贸易顺差、人民币汇率，判断外循环强弱。
- **找长线主线**：国产替代、扩大内需、自主可控，是双循环下的长线机会。

## 常见坑：把“双循环”当口号

- **以为双循环 = 闭关锁国**：外循环仍是增长的重要引擎。
- **只看口号不看数据**：政策说了不算，投资和消费数据才算数。
- **忽视供给端**：内循环不是“自己人买自己货”，还要技术、供应链自主。
