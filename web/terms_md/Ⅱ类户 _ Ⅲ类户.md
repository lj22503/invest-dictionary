# Ⅱ类户 / Ⅲ类户

> 银行账户分三类：Ⅰ类是主账户随便花，Ⅱ类是钱包有额度限制，Ⅲ类是零钱包只能小额支付——钱放哪级，风险敞口不一样。

## 1. 这是什么

**银行账户的三个等级**

**Ⅱ类户 = 功能受限的“钱包账户”，可以存取、理财、限额消费；Ⅲ类户 = 只能小额支付的“零钱包”。**它们和全功能的 Ⅰ类户（工资卡、主账户）共同构成央行 2016 年推行的账户分级体系。

核心区别在<span class="tag">限额**：Ⅰ类户基本不限，Ⅱ类户非柜面转入转出、消费有限额，Ⅲ类户只能小额支付、余额通常不超 2000 元。

> 一句话：Ⅰ类是保险柜，Ⅱ类是钱包，Ⅲ类是零钱袋——钱分开放，风险也分开放。

## 2. 为什么重要

**为什么重要：分级=给风险上保险**

银行卡被盗刷、手机丢失、支付渠道被黑时，**钱在哪个账户决定了你会损失多少**。

- **大额资金放 Ⅰ 类**：少绑定第三方支付，被盗风险降到最低；
- **日常消费走 Ⅱ 类**：即使被盗刷，损失被限额“兜住”；
- **Ⅲ 类小额支付**：免密、扫码、公交场景用，丢了也不心疼。

加上“断卡行动”严打出租出借账户，账户分级既是便利工具，也是风险隔离手段。

## 3. 怎么用 / 怎么看

**怎么用：把钱放对层级**

- **Ⅰ类户留主账户**：工资、存款、房贷扣款走它，但别到处绑定支付；
- **Ⅱ类户管消费理财**：设置合理限额，日常支付、买基金都用它；
- **Ⅲ类户管小额**：免密支付、刷码乘车放这里，余额小、风险小；
- **大额转账用 Ⅰ 类**：配合 U 盾/人脸/短信多重认证再操作。

## 4. 常见坑 / 误区

**常见坑：Ⅱ类当Ⅰ类用，转账被卡**

- **误把Ⅱ类当Ⅰ类**：想大额转账或收大额汇款时才发现被限额，急用钱干瞪眼；
- **以为一人一卡只能开一个**：一家银行只能开一个Ⅰ类户，但可以开多个Ⅱ/Ⅲ类户，正好用来分装资金；
- **出租出借账户**：借卡给他人过账，轻则限额惩戒，重则涉“断卡行动”甚至犯罪；
- **忽略各行差异**：不同银行对Ⅱ类户的限额、升级规则不完全一样，开户时问清楚。
