# 跳空缺口

> 跳空缺口，是相邻两根 K 线之间出现的“价格真空带”：开盘价直接跳过上一根 K 线的区间，留下一个空白。

## 1. 这是什么

**跳空缺口 = 相邻两根 K 线之间出现的“价格真空带”**：今天开盘价直接跳过了昨天的最高价（向上跳空）或最低价（向下跳空），中间没有任何成交。

向上跳空叫`跳空高开`，向下跳空叫`跳空低开`。缺口越大，说明当时的情绪越极端。
> 一句话：缺口，是价格“一步跨过去”留下的空白脚印。

## 2. 为什么重要

跳空不是随机发生的，背后通常是消息、资金或情绪的集中爆发：
- <strong>利好刺激</strong>：买盘太猛，价格直接高开跳过前日区间；- <strong>利空恐慌</strong>：卖盘涌出，低开砸出真空带；- <strong>缺口位置</strong>：之后常成为支撑或压力参考，市场会“惦记”这里。> 一句话：缺口是情绪的“化石”，回头还能在盘面上找到它。

## 3. 怎么用 / 怎么看

- <strong>突破缺口</strong>：放量突破重要阻力/支撑形成的缺口，趋势启动信号；- <strong>持续缺口</strong>：趋势中途出现，说明动能还在；- <strong>衰竭缺口</strong>：趋势末端出现，往往预示行情接近尾声；- <strong>回补与否</strong>：强势行情缺口短期不补，弱势行情很快回补。> 一句话：缺口要跟位置、量能一起看，才能分清是“起跑”还是“冲刺”。

## 4. 常见坑 / 误区

- <strong>“缺口必补”是最大误区</strong>：强势缺口可能很久不补，等回补会踏空；- <strong>分不清除权除息</strong>：除权造成的“假缺口”是规则性的，没有情绪含义；- <strong>把缺口当独立指标</strong>：缺口要配合成交量、位置、趋势一起判断。
