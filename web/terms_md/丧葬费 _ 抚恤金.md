# 丧葬费 / 抚恤金

> 参保人去世后，社保发给家属的一笔丧葬补助和一次性抚恤金——标准各地不同，记得及时申领。

## 1. 这是什么

**人走了，社保还有最后一笔钱**

**丧葬费（丧葬补助金）+ 抚恤金 = 参保人去世后，社保基金发给遗属的一次性待遇。**丧葬费补贴办后事的费用，抚恤金是对家属的慰问补偿。

在职职工、退休人员、城乡居民参保人去世，符合条件的家属都能申领，标准各地不同。

> 一句话：这是社保“身后保障”的一环，别漏领。

## 2. 为什么重要

**为什么重要：身后事也需要经济托底**

丧葬费用少则几千多则数万，突然的离世还会让家庭收入中断。这笔钱虽不算多，但能实实在在减轻负担。

举例：某地企业职工丧葬补助金为**上年度城镇居民月人均可支配收入的 2 倍</span>，抚恤金另按缴费年限发放 9-24 个月工资，加起来是一笔可观金额。

## 3. 怎么用 / 怎么看

**怎么用：家属怎么领**

- **准备材料**：死亡证明、火化证明、户口注销证明、继承人与逝者关系证明；
- **到社保机构申请**：单位在职的通过单位申报，灵活就业/退休人员由家属到社保经办窗口或线上申请；
- **关注到账**：审核通过后发放至继承人银行账户；
- **养老金停发同步**：去世后次月起养老金停发，别继续领（多领需退还）。

## 4. 常见坑 / 误区

**常见坑：不知道领、拖过期**

- **以为只有职工有**：城乡居民参保人去世也有相应的丧葬补助，记得咨询；
- **抚恤金标准看缴费年限**：年限越长、金额越高，别按最低标准估算；
- **逾期申领麻烦**：部分地区有时效要求，家属尽快办理；
- **隐瞒死亡继续领养老金**：属于骗保，会被追回并处罚。
