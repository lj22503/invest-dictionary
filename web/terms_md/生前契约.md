# 生前契约

> 生前与殡葬服务公司签好身后事服务合同，提前锁定服务内容和价格。

## 1. 这是什么

**生前契约**：生前和殡葬服务公司签好“身后事服务合同”，提前锁定火化、告别仪式、墓位等服务项目和价格，家人到时候直接按合同执行。

本质是“把最慌乱的时候要做的决定，提前做好”。

> 一句话：生前契约 = 把身后事提前签成合同，价格和项目都锁死。

## 2. 为什么重要

殡葬费用涨得快，而且亲人办后事时往往没有议价能力——悲痛慌乱中容易被层层加价、捆绑推销。一份合同能锁住价格，也给家人省去临场决策的压力。

- 价格锁定：合同价通常低于临终临时购买价

- 家人省心：不用在悲痛中货比三家

- 防被宰：服务项目明明白白，减少二次推销

> 一句话：殡葬费用年年涨，趁早锁定是省钱也是省心。

## 3. 怎么用 / 怎么看

- 查资质：确认公司有合法殡葬服务经营资质

- 看明细：服务项目、规格、数量逐项列明，不要只写“一条龙”

- 谈退款：写明未使用服务的退款条件和比例

- 留凭证：合同、发票、付款记录都收好

> 一句话：签之前查资质、看明细、谈退款，三件事缺一不可。

## 4. 常见坑 / 误区

- 高价推销：业务员提成驱动，报价水分大

- 理财化包装：把契约包装成“理财产品”“增值套餐”，本质是变相集资

- 捆绑消费：低价的“基础套餐”里藏着必买的加价项

- 口头承诺：销售口头答应的一律写进合同才算数

> 一句话：身后事市场信息差大，越冷静越不吃亏。
