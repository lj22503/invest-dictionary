# 优惠券经济学

> 优惠券不是商家发福利，而是价格歧视工具：让你觉得自己赚了，同时把不同人愿意付的价格区分开。看懂它才能真的省钱。

## 1. 一张券，商家为什么还赚钱

**优惠券经济学 = 商家用优惠券把顾客分成“价格敏感”和“不敏感”两类，让愿意花时间的人少付一点，愿意直接买的人多付一点。**

商家不亏的秘诀：

- 发券成本几乎为零，却能刺激本来不打算买的人下单；
- “满 300 减 50”让人凑单，客单价反而更高；
- 限时券制造紧迫感，减少比价和犹豫的时间。

> 一句话：优惠券的本质不是省钱工具，是商家的“心理定价器”。

## 2. 为什么重要：你以为省了，其实花了更多

你以为在用券省钱，实际常常相反：**凑单多买的东西，往往是你本来不需要的**；“第二件半价”让单件均价下降，但总量翻倍；用券可能要先充值、办会员，钱先被锁定。

更隐蔽的是大数据杀熟：平台可能针对你发**“高价券”**——同样的商品，券后价比别人还贵。

真正省钱的不是“用券的人”，而是**“不为凑单多买的人”**。

> 一句话：省钱的本质不是领到券，而是没多花。

## 3. 怎么看：三种券的真实套路

- 满减券：先算“凑单后的真实需求”，不为凑而凑；
- 折扣券：对比历史价格——先涨价再打折是常见操作；
- 限时 / 限量券：问自己“不用今天买会怎样”，答案是不怎样就别买；
- 口诀：券是用来“买刚需更便宜”的，不是用来“把非刚需变合理”的。

> 一句话：用券的正确姿势——先定要买什么，再看有没有券；而不是先看券，再决定买什么。

## 4. 常见坑：凑单、过期、冲动消费

- 坑：为了用券凑单——多买的退货麻烦，还可能搭运费；
- 坑：囤货囤到过期——便宜没占到，反而浪费；
- 坑：以为“不领券就亏了”——结果为了用券增加了消费；
- 坑：忽略隐藏门槛——满额、会员、特定渠道，算完发现根本不划算；
- 坑：用“反正有券”合理化非理性消费——这是最贵的坑。
