# 同业存单

> 银行之间互相借钱时开的“借条”，利率走势是观察资金面松紧最灵敏的窗口之一。

## 1. 这是什么：银行间的“借条”

**同业存单 = 银行面向其他银行、金融机构发行的短期存款凭证，期限通常 1 个月到 1 年。**它是银行“同业负债”的重要工具，可以在银行间市场转让，流动性好。
发行主体主要是大行和股份制银行（AAA 评级为主），利率随行就市、市场化定价。

> 一句话：大银行缺钱了，先开张“借条”找同行借钱。

## 2. 为什么重要：资金面的体温计

同业存单利率反映银行体系资金松紧：季末、年末冲存款时发行量激增、利率上行；央行放水后利率回落。
对普通人：货币基金和现金管理类产品大量配置同业存单，它的利率直接关系你“余额宝”类产品的七日年化；现在也有“同业存单指数基金”可以直接买。

> 一句话：别看它叫“存单”，它决定的是你零钱理财的收益。

## 3. 怎么用 / 怎么看：三步跟踪发行与利率

- **看发行利率曲线**：1M / 3M / 1Y 的利率水平与走势；- **看发行量**：月末、季末冲量时发行量会明显放大；- **看信用利差**：AAA 与 AA+ 之间利差走阔 = 市场开始挑挑拣拣。
> 一句话：量价齐看，才知道银行是真缺钱还是假紧张。

## 4. 常见坑 / 误区：常见坑：把它当“大额存单”

- **把同业存单当大额存单**：大额存单是银行向个人/企业吸储、受存款保险保障；同业存单是银行间批发融资，性质完全不同；- **以为绝对无风险**：有银行信用，但不在 50 万存款保险范围内；- **为多一点收益买低评级存单基金**：小银行违约概率虽低但并非为零。
