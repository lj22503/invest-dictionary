# 基金投顾

> 把“买什么、买多少、何时调仓”交给专业团队打理，按年收管理费的投资服务。

## 1. 这是什么：雇个专业管家管你的基金

**基金投顾 = 持牌机构根据你的风险承受能力，帮你构建基金组合、持续调仓、做再平衡的付费服务。**你只需要设好目标和风险偏好，剩下交给投顾团队。
和“基金代销”的区别：代销是“卖你产品”（卖方），投顾是“替你管钱”（买方），收费也从销售佣金转向按资产规模收投顾费（通常 0.2%~1%/年）。

> 一句话：它是“帮你管基金组合的私人管家”。

## 2. 为什么重要：专治“不会选、管不住手”

大量基民亏损不是输在基金差，而是输在追涨杀跌、拿不住。投顾用组合分散 + 纪律性调仓，从行为上帮你少犯错。
对个人：门槛低（很多 100 元起投），省心，组合层面比单只基金更抗跌。

> 一句话：买的不只是组合，是“管住自己”的纪律。

## 3. 怎么用 / 怎么看：三步挑投顾

- **看策略与风险等级是否匹配**：稳健型别选进取型组合；- **算总费率**：投顾费 + 底层基金费，合计年化成本是多少；- **看调仓透明度与业绩基准**：是否定期披露调仓记录，跟业绩基准比是否真的跑赢。
> 一句话：投顾也亏钱，关键看它亏的时候是不是比大盘少。

## 4. 常见坑 / 误区：常见坑：以为投顾=稳赚

- **以为投顾 = 稳赚不赔**：投顾也会亏损，只是控制波动；- **忽略双重收费**：底层基金费 + 投顾费叠加，成本要算总账；- **频繁换策略**：一年换 3 次组合，费用和时间成本都高；- **把投顾当“荐股”**：投顾管的是组合，不是个股买卖点。
