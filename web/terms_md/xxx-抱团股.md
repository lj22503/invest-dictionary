# 抱团股

> —— 投资词典 · Invest Dictionary · 最后更新：2026-11-02

**定义**：抱团股是被基金们集体重仓、一起买成“共识”的明星股票：涨的时候一起狂欢，散的时候一起踩踏。

## 机构抱团取暖的明星股

> 一句话：抱团是机构们“抱团取暖”，取暖过度就成了互相壮胆的泡沫。

**抱团股＝大量公募基金同时重仓买入的少数股票**，大家买的是同一个逻辑（白酒、新能源、医药都抱过团）。

抱团不是阴谋，是“业绩考核下的理性选择”：买大家都买的票，涨了一起赚，跌了不容易被单独骂。

典型周期：发现好逻辑 → 净值拉升 → 申购资金涌入 → 继续加仓 → 估值泡沫 → 松动踩踏。

## 为什么重要：共识散了，好公司也扛不住

- **权重高、影响大**：2020—2021 年“茅指数”抱团，重仓基金净值飞天；2021 年春节后抱团松动，不少基金一年回撤 30% 以上；
- **瓦解螺旋**：赎回 → 卖出 → 净值下跌 → 更多赎回，好公司照样被踩踏；
- **看懂了抱团**，就能看懂为什么“好公司”也会突然大跌——不是公司变了，是资金的共识散了。

抱团股的涨跌，决定了你买的基金的脸色。

## 怎么用：三步识别抱团“温度”

> 一句话：抱团股涨的不是公司，是“资金共识”；共识没了，估值回归快过想象。

- **查持仓抱团度**：看基金前十大重仓与同类基金的重叠度，重叠越高越要警惕“一荣俱荣一损俱损”；
- **看估值分位**：抱团股贵不贵用 PE 百分位说话，历史极高分位时控制仓位；
- **跟踪申赎情绪**：基金发行火热、散户疯狂申购，往往是抱团加速的尾声信号；
- **分散持有**：不押单一抱团赛道，用宽基指数对冲“抱团瓦解”风险。

## 常见坑：在最火热时上车

- **把“基金都买”当“安全”**：机构抱团不等于基本面稳，2015 年抱团创业板照样崩；
- **在最高潮时上车**：抱团最疯狂的阶段，往往是基金发行最火爆的阶段，也是风险最高的阶段；
- **以为抱团股“永远涨”**：抱团瓦解时没有“价值支撑”兜底，回撤速度远超想象；
- **只看涨幅跟风买入**：涨幅最大的抱团股，恰恰是未来回撤可能最大的品种。
