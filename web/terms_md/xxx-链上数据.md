# 链上数据

> —— 投资词典 · Invest Dictionary · 最后更新：2026-11-03

**定义**：链上数据是区块链上公开可查的一切交易记录，被称作“加密世界的财务报表”。大户转账、交易所流出、活跃地址都藏在这里。

## 链上即账本

> 一句话：链上数据透明，但解读它需要耐心。

**每一笔转账、每个地址的余额、每次合约调用都公开可查**。常用指标：活跃地址数、大额转账、交易所净流入/流出、持币地址分布、Gas 消耗。

## 为什么重要：不用等财报

传统金融的数据靠披露，链上数据靠透明——**你不需要等公司财报，就能看到“巨鲸在动”**。它也是识别真假行情的工具：价格涨但链上活跃度不动，可能只是存量博弈。

## 怎么用：三条观察线

- **“交易所流出增加”**：往往代表有人把币转入自托管钱包，偏向囤币。
- **“活跃地址创新高”配合价格新高**：信号更可信。
- **看巨鲸地址动向要结合成本价**：别只看单笔转账。

## 常见坑：把转账当涨跌信号

- **把“大户转账”当涨跌信号**：转账可能是交易所内部归集。
- **链上数据只能反映链内事实**：链下（OTC、合约）看不到。
- **不同工具口径不一**：同一指标两家平台数值能差一倍。
