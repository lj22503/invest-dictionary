# 指数增强基金

> 大部分仓位复制指数、小部分仓位主动操作，目标是“指数收益 + 超额收益”。

## 1. 这是什么：被动里掺点主动

**指数增强基金 = 以跟踪某个指数为主（通常 80% 以上仓位），再用一小部分仓位做“增强”操作（选股、择时、打新等），目标是跑赢指数。**
它和纯指数基金的区别：纯被动“复制粘贴”、完全跟着指数走；增强基金“抄作业 + 自己多写几题”，争取多考几分。

> 一句话：想要指数的“稳”，又想要一点超越指数的“惊喜”。

## 2. 为什么重要：跑不赢指数的焦虑解药

A 股长期看，主动基金整体难以稳定跑赢指数，但头部指数增强基金确实能长期贡献 2%~5% 的年化超额，成了很多人的折中选择。
对个人：费率比纯被动高（管理费约 0.8%~1.2%），如果超额收益稳定，多付的费用也值得。

> 一句话：它赌的是“基金经理能不能比指数聪明一点点”。

## 3. 怎么用 / 怎么看：三步筛选增强基金

- **看跟踪误差**：不能离指数太远（年化跟踪误差通常控制在 2%~4%）；- **看超额收益稳定性**：连续 3 年以上跑赢才有说服力，别只看最近一年；- **看规模与团队**：规模太小易清盘，量化团队频繁换人是减分项。
> 一句话：超额要“稳”不要“猛”，一年翻倍第二年腰斩的增强没有意义。

## 4. 常见坑 / 误区：常见坑：把“增强”当“保证”

- **把“增强”当“保证跑赢”**：增强也可能变成“增弱”；- **只看短期超额**：一年的超额运气成分很大；- **忽视跟踪误差放大的风险**：跑输指数更多时你更痛；- **把它当主动型基金买**：仓位规则和风格完全不同，别张冠李戴。
