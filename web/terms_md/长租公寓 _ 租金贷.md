# 长租公寓 / 租金贷

> 长租公寓收房装修再按月租给你，租金贷则是让你一次性贷一年房租、按月还贷——公司一跑路，你就人财两空。

## 1. 这是什么

**租金贷：一次贷一年，按月还贷款**

**租金贷 = 租客向消费金融公司/银行贷出一年的房租，一次性付给公寓方，然后按月还贷款；长租公寓 = 把房子收来装修、再转租赚差价的“二房东”。**

模式本身不违法，但链条脆弱：公寓方用“一次性到账”的租金去扩张收房，租客按月还贷。一旦公寓资金链断裂跑路——<span class="tag">蛋壳公寓爆雷**就是典型——房东收不到钱要收房，租客已经贷款却没了房，还得继续还贷。

> 一句话：租金贷把“按月付房租”变成“按月还贷款”，风险错位是爆雷的温床。

## 2. 为什么重要

**为什么重要：公司跑路，你人财两空**

爆雷时最惨的是两头：**房东没收租**要赶人，**租客已贷款**却无处可住，而且贷款在征信上照算——停止还款就是逾期。

- 经济损失：预付的一整年房租可能打水漂；
- 征信损伤：租金贷逾期进征信，影响未来房贷车贷；
- 维权困难：房东、公寓、放贷机构三方互相推责，追偿周期长。

## 3. 怎么用 / 怎么看

**怎么用：签合同前看清三件事**

- **看清付款方式**：问清“月付”到底付给谁——是公寓，还是金融机构？付给金融机构就是贷款；
- **警惕“年付便宜很多”**：大幅折扣背后往往就是租金贷，别只看便宜；
- **优先月付、直租、正规平台**：个人直租或品牌直营房源，风险小得多；
- 已签租金贷的：保留合同、贷款协议、付款流水，爆雷时第一时间投诉放贷机构。

## 4. 常见坑 / 误区

**常见坑：爆雷后还要还贷**

- **以为“押一付一”就没贷款**：不少租金贷就包装成“押一付一”，实际是贷了 11 个月房租；
- **爆雷后停贷**：停止还贷=征信逾期，先跟放贷机构协商，别直接断供；
- **被三方互推拖垮**：维权要同时盯住放贷机构和公寓方，保留全部证据；
- **忽略二房东资质**：收房时查公寓方有没有拖欠房东租金的口碑和纠纷记录。
