# 主力合约

> 同一品种有好多份不同月份的期货合约，其中交易量最大、最活跃的那份，就是“主力合约”——大家说的期货价格一般指它。

## 1. 什么是主力合约


**主力合约 = 同一期货品种里，成交量与持仓量最大的那份合约。**比如螺纹钢同时有 2501、2505、2510 三个到期月份在交易，大家交易最集中的那一份，就是主力合约。
为什么会有多个合约？因为期货有到期日，不同月份代表“不同时间交割的货物”。主力合约是**流动性最集中**的一份，通常也是**买卖价差最小**的一份。
> 一句话：主力合约就是期货市场里“最多人交易的那一档”，它最代表市场真实想法。


## 2. 为什么重要：市场定价的“话事人”


对交易者来说，主力合约几乎等于“期货价格”的代名词：
- **定价最真**：参与者最多、博弈最充分，价格最能反映市场供需；
- **交易最顺**：流动性好，想买想卖都容易成交，滑点小；
- **分析基准**：看行情、画K线、做趋势判断，都应该看主力合约，而非冷门合约。
当持仓量最大的合约换月时，市场还会出现“主力合约切换”——新旧主力交替那几天，价格和波动都可能异常。
> 一句话：期货交易的第一课，就是“跟着主力走，别在冷门合约里打转”。


## 3. 怎么看：怎么找到并利用它


- **找主力**：看成交量与持仓量最大的月份，交易软件一般会标注“主力”或“主连”；
- **看主连**：用“主力连续”合约看长期趋势，它把历次主力合约拼接在一起，适合趋势分析；
- **顺势交易**：个人交易尽量只做主力合约，流动性好、规则透明、不容易被操纵；
- **留意换月**：临近换月，提前关注新旧主力价差，不要死守即将失去主力的旧合约。
> 一句话：交易软件里标“主力”的那份，才是你该盯的那份。


## 4. 常见坑：别被冷门合约带偏


- **把“主力合约”当“主力资金”**：前者是期货术语，后者是股票里的大资金概念，别混为一谈；
- **交易冷门合约**：流动性差的合约，买卖挂单稀薄，一个不留神就被大单扫走；
- **临近交割月还不换仓**：主力早已移仓到远月，你还守在旧合约里，容易吃亏；
- **拿非主力合约的价格做判断**：冷门合约价格与主力合约可能差很多，看错月份就做错决策。
> 一句话：只做主力合约，能避开期货市场一半以上的“新手陷阱”。
