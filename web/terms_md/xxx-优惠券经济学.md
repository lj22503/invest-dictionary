# 优惠券经济学

> —— 投资词典 · Invest Dictionary · 最后更新：2026-11-02

**定义**：优惠券不是商家发福利，而是价格歧视工具：让你觉得自己赚了，同时把不同人愿意付的价格区分开。看懂它才能真的省钱。

## 专盯“养老钱”的套路

> 一句话：所有老年理财陷阱的入口都一样——先给你甜头，再惦记你的本金。

- **高息养老项目**：投资养老公寓、养老床位，年化 12%~24%，先尝甜头再收大钱；
- **免费旅游 + 会销**：免费体检、免费旅游拉去会场，讲师洗脑后现场刷卡；
- **收藏品增值**：纪念币、字画、紫砂壶，承诺“半年翻倍”，最后人去楼空；
- **保健品返利**：买保健品送积分、返现金，本质是庞氏结构。

**老年理财陷阱 = 利用老年人“想让养老金增值 + 不想拖累子女”的心理，精心设计的收割套路。**

## 为什么重要：本金不可再生

> 一句话：老年理财陷阱骗走的不是钱，是老人晚年的安全感和家庭的信任。

老年人是骗局的重灾区：手里有钱、信息相对闭塞、又特别怕给子女添麻烦，**被骗了往往还不敢说**。

养老钱是`不可再生资源`：退休后收入断了，亏掉的本金很难再赚回来；一场骗局可能让晚年生活直接降档。

更隐蔽的是**家庭信任危机**：很多老人不听子女劝，只信“朋友”和“专家”，子女越反对越要投，最后血本无归还怪子女。

## 怎么防：五条保命线

> 一句话：五条线守住一条，骗子就得换人骗；全守住，骗局就绕着你家走。

- **牢记“保本高息=诈骗”**：正规理财做不到保本，更做不到高息，两者同时出现必是骗局；
- **不参加免费旅游/讲座**：所有免费活动背后都有销售，不去就断了源头；
- **大额转账前问一句**：让老人养成习惯，超过 1 万先和子女或银行柜员商量；
- **查正规持牌**：投资前在中国理财网、基金业协会官网查产品登记；
- **给老人设“冷静期”**：任何投资先放 3 天再决定，急催交钱的基本都是骗子。

## 常见坑：熟人介绍也不保险

- **以为“熟人介绍就安全”**：很多骗局就是熟人带熟人，佣金驱动下“好心邻居”也成了帮凶；
- **被小礼品迷惑**：一袋米、一桶油换来的信任，最后可能值几十万；
- **把收藏品当投资**：字画、纪念币流动性极差，所谓“拍卖价”全是托；
- **听信“国家项目”背书**：伪造红头文件、假冒养老政策，正规项目不会上门推销；
- **出事不敢报警怕丢脸**：越拖越难追，第一时间报警 + 联系银行冻结，才是止损正路。
