# 基金转换

> 基金转换，就是把手里 A 基金直接换成同一家公司的 B 基金，不用先赎回再申购，省时间省钱。

## 1. 这是什么

**基金转换 = 在同一家基金公司内，把持有的 A 基金份额按净值折算成 B 基金份额，一步完成"卖出 A + 买入 B"。**

比如你持有 1 万元债券基金，想换成股票基金：普通做法是"赎回债券基金（等 2~3 天到账）→ 再申购股票基金（再等确认）"，资金在中间"空转"好几天。基金转换则当天申请、当天按 A 的赎回净值和 B 的申购净值直接折算，中间不经过现金。

它能转换的前提：两只基金属于**同一家基金公司**，且开通了转换业务。

> 一句话：基金转换是"换基金不换现金"，资金无缝衔接，少等几天、少付一次手续费。

## 2. 为什么重要

- **省时间 = 省机会成本**：赎回再申购一般要 4~7 个交易日资金才到位，转换当天就完成，牛市里多一天就多一天收益。
- **省手续费**：转换时 B 的申购费 =（B 申购费 - A 申购费）的差额，如果 A 申购费更高，转换甚至免申购费；而先赎回再申购要交两笔费用。
- **灵活调仓**：市场风格切换时，快速从债券基金切到股票基金、或从成长切到价值，不用等资金到账。
- **降低择时焦虑**：转换按当日净值成交，不用纠结"先赎回等低位再买"的空窗期。

普通投资者一年调仓 2~3 次，用转换能省下的时间和费用相当可观。

## 3. 怎么用 / 怎么看

- **确认同门**：先查两只基金是否同一家基金公司，且都支持转换（产品页面有"转换"入口）。
- **看费率差额**：转换费用 = 转出基金赎回费 + 转入基金申购费补差，仔细算清楚再决定。
- **看净值确认时间**：一般 T 日 15:00 前申请，按 T 日净值折算，15:00 后算 T+1 日。
- **适合的场景**：市场风格切换、基金业绩持续走差、想从债基切换到股基时优先考虑转换。
- **注意限额**：部分基金对转换有单笔金额上限，大额转换前看公告。

## 4. 常见坑 / 误区

- **跨公司"转换"**：不同基金公司之间不能直接转换，只能赎回再申购，别在平台上看岔了。
- **以为转换永远免费**：转出基金有赎回费，转入申购费可能补差，费用≠0，先算再动。
- **用转换追热点**：频繁转换 = 频繁择时，手续费再省也架不住来回折腾，反而可能两边挨打。
- **忽略转入基金的规则**：B 基金如果有最短持有期、大额限购，转进去可能"出不来"。
- **把转换当"免费 T+0"**：转换当日没有现金到账，如果急着用钱，还是要走赎回。
