# 打板 / 连板 / 炸板 / 天地板

> —— 投资词典 · Invest Dictionary · 最后更新：2026-11-02

**定义**：打板是冲涨停价排队买入，连板是连续涨停，炸板是涨停被砸开，天地板是从涨停直接跌到跌停。

## 涨停板上的黑话

> 一句话：涨停板是资金情绪的共识，也是资金情绪的赌场。

- **打板**：在涨停价附近排队买入，赌它封死涨停、次日继续冲高。
- **连板**：连续多个交易日涨停（2 连板、3 连板……）。
- **炸板**：涨停封单被大额抛单砸开，价格从涨停回落。
- **天地板**：开盘涨停、收盘跌停，一天之内从天堂到地狱（反过来叫地天板）。

## 情绪的温度计

> 一句话：情绪温度计不只能追涨，更能帮你避坑。

**涨停家数、连板高度、炸板率，是 A 股短线情绪最直观的温度计**：连板股多、炸板率低 → 情绪亢奋；连板股断、炸板率高 → 情绪退潮。游资、打板客、跟风盘都围着这套信号转。

对普通投资者，看懂这套生态至少能帮你避开最凶险的玩法——**很多散户的第一笔大亏，就亏在"听说要涨停了"冲进去接盘**。

## 看情绪周期，只打龙头

- **看情绪周期**：涨停家数连续增加 + 炸板率下降 = 上升期；涨停家数萎缩 + 炸板率飙升 = 退潮期，别逆着做。
- **只打龙头**：板块里最强、封单最厚的那只，跟风股最容易炸。
- **看封单量与排队位置**：封单小、你排在后面，可能根本买不进。
- **分清规则**：主板涨停 10%，创业板/科创板 20%，北交所 30%，同样是"涨停"含义完全不同。

## 九死一生的游戏

- **散户打板九死一生**：好板买不到，买到的大多是烂板、炸板。
- **天地板一天能亏 20% 甚至更多**：涨停价买入，跌停价收盘，账面直接掉一档。
- **一字板根本买不进**：排单排到收盘，白占资金还可能产生废单。
- **只看到幸存者**：涨停敢死队活下来的都被写成故事，亏光的都沉默。
