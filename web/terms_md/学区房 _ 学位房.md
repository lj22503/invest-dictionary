# 学区房 / 学位房

> 学区房=房子绑着名校入学资格。溢价可能高达同地段普通房的一倍，但多校划片、学位锁定、政策变动都可能让预期落空。

## 1. 房子绑着学位的“入场券”

**学区房 / 学位房 = 房子所在片区对应特定学校的入学资格，本质是“用房价买教育资源”。**

两种常见形态：

- 学区房：按片区划分入学，可能多校划片、电脑派位；
- 学位房：开发商承诺的入学资格，兑现更脆弱；
- 溢价：同地段、同品质，带学区可能贵 30%~100%。

> 一句话：学区房买的不是房子，是那张“入学资格券”，而券的有效期由政策决定。

## 2. 为什么重要：溢价与政策风险并存

学区溢价是家庭资产里最大的一笔“教育投资”，动辄几十万到上百万。**但它的价值随时可能缩水**：

- 多校划片——买了学区房也不一定进名校；
- 学位锁定——一套房几年内只能用一个入学名额；
- 教师轮岗、名校集团化——教育资源的“确定性”在变弱；
- 生育率下降——未来学位需求减少，学区溢价长期承压。
**入学资格一落空，房子就回归普通房价格**。

> 一句话：学区房的逻辑是“用溢价换确定性”，但确定性本身正在被政策改写。

## 3. 怎么看：四问判断值不值

- 一问：政策怎么变——多校划片、锁定年限、落户年限要求，逐条查官方文件；
- 二问：溢价多少——同地段非学区房差价多少，这笔钱值不值；
- 三问：持有多久——孩子读完书，房子还要持有几年，流动性如何；
- 四问：最坏情况——入学资格没了，这房子你还愿意按普通房留着吗。

> 一句话：把“政策变了怎么办”想清楚，再决定要不要为学区溢价买单。

## 4. 常见坑：名校预期≠兑现

- 坑：只信开发商宣传——不核实教育局官方划片文件；
- 坑：学位锁定没查——买了才发现名额已被占用；
- 坑：落户年限不够——入学资格轮不到你；
- 坑：高位接盘老破小——孩子读完书，房子砸手里；
- 坑：把学区房当稳赚投资——政策一改，溢价可以瞬间蒸发。
