# 挤兑（银行挤兑）

> 一群人同时冲进银行取钱，银行一下子拿不出那么多现金——这就是挤兑，再好的银行也可能被它挤垮。

## 1. 为什么大家突然一起取钱


**银行挤兑 = 存款人同时冲去取钱，银行一时拿不出那么多现金。**银行不是金库：你存进去的钱，大部分已经贷给了企业和买房的人，账上只留一小部分现金备付。
平时没人在意这件事，因为大家不会同时取。可一旦有风声说“这家银行不行了”，每个人都想赶在别人前面把钱取走——**取钱的人越多，现金越不够，恐慌传得越快**，本来没事的银行也可能被取到关门。
> 一句话：挤兑不是银行突然没钱了，是“大家都怕没钱”这个念头本身，把钱挤没了。


## 2. 为什么重要：好银行也会被挤垮


银行的商业模式是**短借长贷**：用短期存款放长期贷款，赚中间的利差。这个模式平时运转良好，但天生怕“集体取钱”。
挤兑的可怕之处在于：**哪怕银行资产完全健康，只要现金被取光，它就可能被迫低价甩卖资产、甚至倒闭**——这就是金融学里说的“自我实现的预言”。
所以挤兑不是个人小事：它会传染。一家银行被挤兑，储户会怀疑所有“听起来像它”的银行，恐慌可能蔓延到整个金融体系。这也是为什么国家要设**存款保险**和**央行最后贷款人**两道防线。
> 一句话：挤兑考验的不是银行的资产，而是储户的“信心余额”。


## 3. 怎么看：三条信号与三层防线


- **看信号**：银行出现负面新闻、网点排队取现、理财或存款产品集中赎回，都是挤兑前兆；
- **看保障**：我国有存款保险，**同一家银行 50 万以内的存款本息有保障**，超出的部分才需要担心；
- **看自身**：分散存放——大额资金别全放一家中小银行，50 万以内放存款保险覆盖的银行即可；
- **看行动**：真遇到传言，先核实官方信息，**不要跟风排队取现**——你的冷静就是对银行最好的保护。
> 一句话：把钱放对地方、留足应急金，挤兑再凶也伤不到你。


## 4. 常见坑：把恐慌当成机会


- **以为“银行一定不会倒”**：小银行、村镇银行的风险明显更高，存款也要看牌照和存款保险标识；
- **以为存款保险保所有产品**：它只保存款，**理财、基金、保险产品都不在保障范围内**，且是“同一家银行合计 50 万以内”；
- **以为取现越快越安全**：挤兑时去凑热闹，反而放大恐慌，还可能取不回（网点现金有限）；
- **把“挤兑”当“机会”去抄底**：赌银行股反弹、买高息揽储的“存款”类产品，都可能踩中风险。
> 一句话：挤兑面前，第一原则是“别慌”，第二原则是“看存款保险，而不是看排队人数”。
