# 医保断缴 / 补缴

> 医保费断了一个月以上，报销资格和待遇等待期都会受影响——断缴后怎么补救，看这里。

## 1. 这是什么

**断了医保，看病全自费**

**医保断缴 = 连续缴费中断，报销资格被暂停或降级。**职工医保一般断缴次月起停止享受统筹报销，个人账户里的钱还能用，但住院、门诊报销就没了。

断缴 3 个月以内补缴，多数城市视为“连续”，恢复待遇；超过 3 个月，很多地方要重新计算**等待期**（比如 3-6 个月不能报销）。

> 一句话：医保断缴不是扣点钱，是把你报销的“开关”关了。

## 2. 为什么重要

**为什么重要：断一次，可能影响一整年**

职工医保断缴后：次月不报销、超3个月重算等待期、连续缴费年限清零重计（影响终身医保待遇的累计年限）。

举例：小李离职后忘了交医保，第 4 个月补上，结果要再等 6 个月才能报销——这半年里感冒住院，全自费。

- 住院报销比例一般 70%-90%，断缴期全额自费；
- 连续缴费年限影响退休后免费医保待遇；
- 部分城市买房摇号、落户也看社保连续性。

## 3. 怎么用 / 怎么看

**怎么用：断缴了怎么补救**

- **3 个月内**：尽快补缴，多数地区视为连续缴费，报销不断档；
- **离职空窗**：以灵活就业人员身份自己交职工医保，或转居民医保过渡；
- **换城市**：办理医保关系转移，衔接两地缴费；
- **单位漏缴**：要求单位补缴，因单位原因断缴可追溯报销。

## 4. 常见坑 / 误区

**常见坑：以为补缴就能立刻报销**

- **补缴≠立即恢复**：超 3 个月补缴通常有等待期，别以为钱一交就万事大吉；
- **居民医保补缴有限制**：很多地区过了集中缴费期，要等次年才能参保；
- **断缴期间住院**：补缴后能否追溯报销因城市而异，别指望全部兜底；
- **借别人医保卡**：冒名就医属于骗保，轻则拒赔重则违法。
