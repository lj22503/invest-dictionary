# 个人破产

> 欠的钱实在还不上，法律允许你申请“破产”：把名下资产按规矩分给债主，剩下的债务依法豁免，给你一次重新做人的机会。

## 1. 这是什么

**欠到还不起，法律给的出口**

**个人破产 = 欠的钱实在还不上了，法律帮你把资产按规矩分给债主，剩下的债务依法免掉。**它不是“赖账不还”，而是给**诚实而不幸**的债务人一个重新开始的机会。

2021 年 3 月，<span class="tag">深圳**率先试点《深圳经济特区个人破产条例》，成为全国第一个有个人破产制度的地方。申请后，法院会指定管理人盘点你的资产和负债，再走**破产重整**（谈一个分期还债方案）或**破产清算**（变卖资产偿债）两条路。

> 一句话：个人破产是“翻篇”的合法通道，不是逃债的借口。

## 2. 为什么重要

**为什么重要：诚实而不幸的人有救**

创业失败、大病、给朋友担保爆雷——普通人可能一夜背上几百万债务。没有个人破产制度时，债务人只能被催收、上失信名单、一辈子翻不了身。

深圳试点的机制是：破产人进入考察期（最长 3 年），期间保留基本生活费和合理支出，其他收入拿去还债；考察期满，**剩余债务可以豁免**。债务从“压死你”变成“还能活”。

- 对债务人：欠债不再等于终身卖身契；
- 对债主：清算和重整反而比“追到天涯海角”拿回更多；
- 对社会：减少因债务引发的极端事件，也让民间借贷更理性。

## 3. 怎么用 / 怎么看

**怎么用：申请破产三步走**

- **先看资格**：目前只有深圳试点，且在深圳居住、参加社保满一定年限才可申请；
- **再理账目**：把所有负债（本金、利息、罚息）和全部资产列成清单，如实申报；
- **最后选路径**：有稳定收入选**破产重整**（分期还），无收入选**破产清算**（处置资产）；
- 进入考察期后按时报告财产变化，期满申请债务豁免。

> 口诀：诚实申报是前提，考察期内守规矩，期满才能真翻篇。

## 4. 常见坑 / 误区

**常见坑：别以为破产=免单**

- **以为申请就不用还钱**：资产要清算、考察期还要用收入还债，不是一笔勾销；
- **想靠转移财产蒙混**：隐匿、转移资产会被驳回申请，严重的还涉嫌犯罪；
- **忽视破产“后遗症”**：破产记录会影响消费、贷款、部分职业准入，好几年内都不好借钱；
- **被“代办个人破产”骗**：全国多数地区还没有个人破产制度，网上收费代办基本都是骗局。
