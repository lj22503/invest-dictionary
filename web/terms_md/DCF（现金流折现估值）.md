# DCF（现金流折现估值）

> 把公司未来能赚到的钱，按"今天的钱比明天的钱值钱"折回今天再加总，得出它现在大约值多少。

## 1. 它在算什么

**DCF（Discounted Cash Flow，现金流折现估值）= 把未来每一期的自由现金流，按一个折现率换算成今天的钱，然后加总。**

结构是三段：

- **预测期**（通常 5–10 年）：每年自由现金流 ÷ (1 + 折现率) 的年数次方，逐年折回并相加
- **终值**：预测期之后用永续增长模型，终值 = 末年自由现金流 × (1 + 永续增长率) ÷ (折现率 − 永续增长率)，再折回今天
- **股权价值** = 预测期现值 + 终值现值 − 净负债

全部结论由三个输入决定：**自由现金流**、**折现率**（企业整体估值常用 WACC）、**永续增长率**。

## 2. 为什么它被当作"正统"

- 它从现金流出发，不依赖同行给多少倍市盈率，也不用假设市场愿意付多少溢价
- 它对"公司靠什么赚钱"要求最严：说不清现金流从哪来，模型就填不出数
- 券商深度报告、并购定价、一级市场测算，底层普遍是它
- 它是唯一能把"增长"和"风险"分开摆在明面上的估值法：增长进分子，风险进折现率

## 3. 假设算例（数字是编的，只为看清结构）

某公司未来 5 年自由现金流依次为 10、12、14、16、18 亿元，折现率 10%，永续增长率 3%：

- 预测期现值 ≈ 9.09 + 9.92 + 10.52 + 10.93 + 11.18 ≈ **51.6 亿元**
- 终值 = 18 × 1.03 ÷ (10% − 3%) ≈ 264.9 亿元，折回今天 ≈ **164.5 亿元**
- 企业价值 ≈ **216 亿元**，其中终值占 76%

把折现率改成 9%、永续增长率改成 3.5%，企业价值立刻变成约 **273 亿元**。两个假设各动 1 个百分点以内，结果差了三成，这就是 DCF 的真实性格。

## 4. 常见坑

- **拿它估周期股和早期亏损公司**：自由现金流为负或大起大落，模型输出没有意义
- **永续增长率设成高于长期 GDP 增速**：数学上能算，现实里等于假设它永远比整个经济跑得快
- **终值占比超过 70% 还当成精确结论**：说明结论几乎全部由假设决定，不是由已知数据决定
- **把小数位当精度**：DCF 的输出是一个区间，不是一个点
- **用会计净利润代替自由现金流**：两者的差额正是资本开支和营运资金占用
- **先有目标价、再倒推假设**：这是最常见也最难自查的一种
