# 转融通

> 转融通 = 把券源集中批发给券商的机制。它分两半：转融资是借钱给券商，转融券是借券给券商，券商再转手借给客户做融资融券。

## 1. 这是什么
融券做空的第一步是**得有券可借。散户手里那点券杯水车薪，真正的大水库是机构持仓——转融券就是打通“大股东/机构持股 → 券商 → 融券客户”的管道。

2024 年 2 月起，监管暂停转融券新增券源；7 月起进一步暂停转融券业务，存量券源逐步了结。A 股的做空弹药库被收走了大半。


> 一句话：转融通是融券的上游，上游关闸，下游做空的火力自然受限。

## 2. 为什么重要
转融券余额 = 市场上“能借来砸盘”的券总量。它和融券余额配合看：

- **余额上升**：空头弹药增加，做空力量在积聚；
- **余额下降**：空头在撤退，抛压预期减轻；
- **余额归零**：做空机制基本停摆（当前暂停状态下的现实）。
机构和个人在工具上天然不对等：机构能借券做空，散户大多只能做多。看懂转融通，就明白了“融券余额”新闻背后的真正主角。

## 3. 怎么用 / 怎么看
- **盯“转融券余额”数据**：它比融券余额更靠上游，是空头力量的源头信号；
- **区分转融资与转融券**：一个借钱（多空都有用），一个借券（主要做空），方向完全不同；
- **跟随监管节奏**：政策暂停/重启转融券，对市场情绪影响立竿见影，新闻解读要跟得上；
- **别用它预测点位**：它是情绪指标之一，不是涨跌的充分条件。

## 4. 常见坑 / 误区
- **以为暂停=永远取消**：监管政策是动态的，未来可能按新规则重启；
- **混淆转融通与转融资**：看新闻先分清是借券还是借钱；
- **以为散户能轻松融券**：融券门槛高、券源稀缺，普通人基本用不上；
- **把转融通当唯一利空**：做空只是众多因素之一，别用它解释一切下跌。
