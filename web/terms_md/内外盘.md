# 内外盘

> 外盘是主动买进成交的量，内盘是主动卖出成交的量，看的是买卖双方谁更着急。

## 1. 这是什么

**外盘 = 以卖方挂出的价格成交的量（主动买入），内盘 = 以买方挂出的价格成交的量（主动卖出）。**
打个比方：你想赶紧买 100 股，不等别人降价，直接按卖一价成交，这笔算`外盘**；你想赶紧卖，直接砸到买一价成交，这笔算`内盘**。
软件里外盘通常标红，内盘标绿。外盘大，说明**买方更着急、买入意愿更强**；内盘大，说明卖方更着急、抛压更重。
> 一句话：谁更着急成交，谁就计入哪一边。

## 2. 为什么重要

光看涨跌，你不知道是“有人抢着买”还是“没人卖所以涨”。内外盘能反映主动买卖的意愿：
外盘大于内盘、股价上涨，说明**买盘主动性强，涨得“有底气”**；内盘大于外盘、股价下跌，说明卖压主动释放。如果内盘大但股价不跌，可能有人在悄悄承接，值得留意。

## 3. 怎么用 / 怎么看

- **看比值**：外盘/内盘明显大于 1，偏强；明显小于 1，偏弱。
- **看位置**：低位放量外盘大，是资金进场信号；高位外盘大可能是主力对倒出货。
- **看大单小单**：主力常拆单买卖，大单连续主动买入比散单更有参考价值。
- **结合分时与成交量**：内外盘要配合量价一起看，单看比值容易误判。

## 4. 常见坑 / 误区

- **对倒造假**：主力自买自卖，可以制造外盘放大的假象，吸引跟风盘。
- **口径不一致**：不同软件对内盘外盘的统计方式略有差异，别跨软件对比。
- **忽略价格位置**：同样的大外盘，低位和高位含义完全相反。
- **当精确资金数据用**：内外盘只是“主动成交方向”的近似统计，不是主力资金的完整流向。
