# 杀估值 / 杀业绩 / 杀逻辑

> —— 投资词典 · Invest Dictionary · 最后更新：2026-11-02

**定义**：杀估值是估值太贵回落，杀业绩是盈利不及预期，杀逻辑是长期叙事被推翻——三种跌法，应对完全不同。

## 跌法不同，命不同

- **杀估值**：公司还是那家公司，但之前买太贵了，现在价格回归合理；
- **杀业绩**：公司赚钱能力真的下滑了，盈利预期被下修；
- **杀逻辑**：支撑股价的长期故事被推翻——行业没了、模式错了、护城河塌了。

股票下跌，表面看都是"跌"，但背后原因分三种：

## 三种杀，三种应对

三种杀的应对完全不同：杀估值可能是机会，杀业绩要看基本面有没有恶化，杀逻辑则要果断离场。判断错了，要么错失机会，要么死扛深套。

典型的"戴维斯双杀"就是杀业绩 + 杀估值同时发生：盈利下滑导致估值中枢下移，两者叠加，股价跌幅远超想象。

## 判断属于哪种杀

- 先看盈利预期：业绩预告、分析师一致预期是否下修——下修说明是杀业绩；
- 再看估值分位：PE/PB 处于历史什么位置——高位回落更像杀估值；
- 最后看行业与公司逻辑：需求是否消失、技术是否被替代、政策是否逆转——逻辑变了才是最危险的；
- 三者叠加判断：逻辑没变 + 业绩没坏 + 只是估值贵 = 跌出来的是机会。

## 杀跌的三个想当然

- 把杀估值当杀逻辑恐慌割肉——好公司贵了跌下来，反而是加仓窗口；
- 把杀逻辑当杀估值抄底——逻辑塌了的公司，越跌越便宜是错觉；
- 分不清业绩下修是一次性还是持续性——一次性暴雷可能利空出尽；
- 只看跌幅大小不看原因——跌 50% 的逻辑崩坏和跌 50% 的估值回归，是天壤之别。
