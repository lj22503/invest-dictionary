# 两融余额

> 两融余额 = 融资余额 + 融券余额，是市场“借钱炒股 + 借券做空”的总规模，看杠杆情绪。

## 1. 这是什么

**融资 = 向券商借钱买股票（看多），融券 = 向券商借股票卖出（看空）。两融余额就是沪深两市融资余额与融券余额加在一起的总盘子。**
融资余额占绝对大头，所以两融余额上升，一般理解为**杠杆资金进场、市场情绪回暖**；余额下降，说明杠杆资金在撤退。
它每天收盘后由交易所公布，是观察市场风险偏好的公开数据之一。
> 一句话：两融余额是“市场借了多少钱在炒股”的账本。

## 2. 为什么重要

行情上涨时，两融余额跟着放大，说明增量资金带着杠杆进场，**上涨有“燃料”**；但杠杆是双刃剑：
一旦行情反转，融资盘面临强平，会形成“下跌 → 强平 → 再下跌”的踩踏链条，**跌起来比涨起来更猛**。所以监管和媒体盯两融余额，不只是看情绪，更是看系统性风险的水位。
对普通投资者，它是判断“市场热不热、杠杆高不高”的实用指标。

## 3. 怎么用 / 怎么看

- **看趋势**：连续上升说明风险偏好抬升，连续下降说明在去杠杆。
- **结合位置**：指数低位两融回升，是增量信号；指数高位两融创历史新高，要警惕泡沫。
- **结合成交量**：两融余额与成交额同步放大，行情才“有劲儿”；余额涨、成交缩，说明钱在堆积没干活。
- **融券余额参考有限**：规模太小，主要看融资余额的方向。

## 4. 常见坑 / 误区

- **把余额当“当天买盘”**：两融余额是存量规模，不是当日增量，别拿它解释单日涨跌。
- **忽略踩踏风险**：融资盘重的股票，下跌时强平卖压集中，波动会被放大。
- **把融券余额当主要做空指标**：A 股融券规模很小，做空力量主要看别处（股指期货、期权等）。
- **以为两融涨就是牛市**：杠杆堆积也可以是顶部特征，方向看错了很危险。
