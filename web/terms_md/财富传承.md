# 财富传承

> 遗嘱、保险、信托、赠与——把一生积累稳稳交给下一代，靠的不是运气，而是一套提前设计的安排。

## 1. 把钱稳稳交给下一代

**财富传承 = 提前设计“你的钱在你去世后归谁、怎么给、怎么少折腾”，而不是等意外发生再让法律替你安排。**

常见的三种安排：

- 法定继承：按法律顺序来，配偶、子女、父母平分，未必是你想给的人；
- 遗嘱：写明给谁，但要合法有效，否则形同虚设；
- 保险 / 信托：指定受益人，定向、私密、还能防挥霍。

> 一句话：传承不是“写不写遗嘱”的问题，而是“你希望它怎么发生”的问题。

## 2. 为什么重要：传的不是钱，是选择权

没有规划的传承，可能带来三个意外：钱给了不想给的人、家人为分财产打官司、资产被冻结多年。

具体来说：**法定继承会平均分配**，再婚家庭、非婚子女、想多给某个孩子——法律不会替你想；继承纠纷平均耗时 1~3 年，期间房产、存款可能被冻结；房产继承过户还有税费和手续成本。

更重要的是**给下一代一笔巨款，未必是礼物**：没有管理能力的子女，可能快速挥霍，或在婚变中被分走一半。

> 一句话：没有规划的传承，是给家人留问题；有规划的传承，才是留礼物。

## 3. 怎么做：四件套组合拳

- 第一步：盘点资产清单——房产、存款、股权、保单、数字资产，先知道自己有什么；
- 第二步：写有效遗嘱——关键财产指定继承人，最好公证，别用自书遗嘱赌运气；
- 第三步：用保险定向传承——身故受益人写具体的人，理赔金直接到账，不用走继承程序；
- 第四步：资产规模大再上信托——家族信托可以约定“分批给、有条件给”，防挥霍、防婚变分割。

> 一句话：小家庭靠遗嘱 + 保险就够了，大家族才需要上信托。

## 4. 常见坑：遗嘱不是万能的

- 以为遗嘱写了就完事：未公证、被篡改、形式有瑕疵，都可能被认定无效；
- 保险受益人写成“法定”：等于白指定，身故金还是要走继承；
- 现金直接赠与：子女婚变时可能被分走一半，想定向就得用工具；
- 听信“遗产税马上来了”的焦虑营销：国内目前没有遗产税，但房产过户税费要提前算清楚；
- 只传钱不传能力：下一代接不住，财富反而成了麻烦。
