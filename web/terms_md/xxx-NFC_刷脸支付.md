# NFC / 刷脸支付

> —— 投资词典 · Invest Dictionary · 最后更新：2026-11-02

**定义**：不带钱包也不掏手机：NFC 让手机贴一下 POS 就付掉，刷脸让脸本身成为付款凭证——两种“无感支付”正在接管日常。

## 让“掏手机”都省掉的两种支付

> 一句话：扫码是“打开 App 出示”，NFC 是“碰一下”，刷脸是“看一眼”。

**NFC 支付 = 手机贴近 POS 机“滴”一下完成付款；刷脸支付 = 摄像头扫一下脸，直接从绑定的账户扣款。**

NFC 背后是银行卡的“电子化”：把卡号装进手机芯片，交易走银联通道；刷脸支付背后是生物识别 + 支付账户，主要被微信、支付宝和部分银行采用。

## 为什么重要：效率和安全的新平衡

- **更快**：NFC 免解锁、免开 App，公交闸机、便利店结账比扫码快 2-3 秒。
- **更稳**：NFC 走银行卡通道，不依赖 App 余额，网络差也能付。
- **更贵**：刷脸设备成本高，商户改造慢，目前多出现在大超市、医院、政务场景。
- **更有争议**：刷脸是“把生物特征当钥匙”，一旦泄露不可更改，监管对采集和留存卡得很严。

## 怎么用：开好开关，设好限额

> 一句话：NFC 可以放心常用，刷脸要看清场合、管好限额。

- **NFC**：手机钱包 App（Apple Pay / 华为钱包 / 云闪付）绑定银行卡，双击电源键或贴近 POS 验证指纹/面容即可；建议关闭“小额免密”或把免密额度设低。
- **刷脸**：在微信/支付宝开通刷脸付，设置独立的支付限额；公共场所优先选“带活体检测”的设备。
- **留退路**：两种方式都建议保留扫码作为兜底，避免设备故障时付不了款。

## 常见坑：便利背后有四道雷

- **免密额度过高**：手机丢了，NFC 免密可能被小额盗刷，记得设低限额并开启“查找手机”远程锁定。
- **刷脸被“误刷”**：未成年、醉酒、被胁迫状态下，面容支付可能替别人买单，法律上追责难。
- **人脸数据泄露**：别在陌生设备上录人脸，也别用同一张人脸图到处上传。
- **POS 有假**：看到异常贴片、被要求输两次密码，立刻停止交易并报警。
