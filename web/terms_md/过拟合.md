# 过拟合

> 策略在历史数据上完美得离谱，一到实盘就翻车——因为它只是“背下了历史”，没学会规律，这就是过拟合。

## 1. 什么是过拟合


**过拟合 = 模型把历史数据里的“噪音”当成了“规律”。**为了在回测里表现完美，策略把每一个历史波动都背了下来，结果一遇到真实市场（永远和过去不完全一样），立刻失灵。
想象一个学生把练习册的答案全背下来，考到原题就满分，题目一换就零分——**背答案不是学会，就是过拟合**。量化里常见的表现是：参数调得极其精细、回测曲线完美向上，实盘却稳定亏损。
> 一句话：过拟合是“策略界的学霸背答案”，回测越完美越要警惕。


## 2. 为什么重要：完美回测的陷阱


过拟合是量化投资最大的隐形杀手：
- **回测收益≠未来收益**：过拟合策略在样本内完美，样本外（新数据）立刻现原形；
- **对微小变化极度敏感**：参数动一点点结果大变，说明模型不是在学规律，是在背数据；
- **实盘成本更高**：过拟合策略往往换手频繁，真实交易成本一算，收益更是大打折扣；
- **毁掉信任**：很多“完美策略”实盘亏钱后，投资者才明白：历史曲线越漂亮，越可能是陷阱。
> 一句话：过拟合让人亏得最惨的方式，是让你先相信“这次一定行”。


## 3. 怎么看：三个体检指标


- **看样本外表现**：把一段历史数据留出来不参与调参，只看策略在“没背过”的数据上的表现，过拟合会在样本外大幅缩水；
- **看参数稳健性**：把参数微调 10%-20%，结果变化很小 → 稳健；结果剧烈波动 → 过拟合信号；
- **看逻辑合理性**：策略的赚钱逻辑能否用人话讲通？纯靠统计巧合的“规律”基本不可信；
- **控制复杂度**：参数越少、逻辑越简单，过拟合概率越低；数据量越大，越能检验真伪。
> 一句话：判断过拟合，就看三点——样本外还灵不灵、参数动一动还稳不稳、逻辑讲不讲得通。


## 4. 常见坑：把回测当提款机


- **拿回测收益当未来收益**：回测曲线是“后视镜”，不是“天气预报”；
- **参数优化到极致**：把每个参数都调到回测最优，就是典型的曲线拟合；
- **只看一段历史**：只在牛市或单一行情里回测，样本内再漂亮也是自欺；
- **忽视幸存者偏差**：只统计“活下来的策略”，死掉的全被抹掉了，胜率被严重高估；
- **忽略交易成本**：过拟合策略高频换手，真实成本可能把理论收益吃光。
> 一句话：回测是体检报告，不是印钞机；报告越完美，越要问一句“哪里造假了”。
