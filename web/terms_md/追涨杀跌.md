# 追涨杀跌

> 追涨杀跌，是看到涨了赶紧买、看到跌了恐慌卖的行为模式，是散户亏钱最常见的原因。

## 1. 这是什么

**追涨杀跌 = 看到涨了赶紧买、看到跌了恐慌卖。**涨得越猛越心动，跌得越狠越想跑。

它不是“操作失误”，而是人类本能：价格涨刺激了`贪婪`，价格跌触发了`恐惧`。市场专门利用这种本能收割。
> 一句话：追涨杀跌，是把“别人恐惧我贪婪”反过来活成“别人贪婪我更贪、别人恐惧我更怕”。

## 2. 为什么重要

追涨杀跌的可怕之处，在于它精确地做反微笑曲线：
- <strong>高位接盘</strong>：涨得最热闹时买入，买在顶部附近；- <strong>低位割肉</strong>：跌得最惨时卖出，卖在底部附近；- <strong>反复来回</strong>：高买低卖一次亏一点，来回几次本金就没了。> 一句话：它不靠一次亏大的，靠的是“每次都做反”。

## 3. 怎么用 / 怎么看

- <strong>买前问三问</strong>：它贵不贵？我为什么买？跌了 20% 我怎么办？- <strong>设好止损纪律</strong>：提前定好“跌破多少就走”，而不是跌了才临时决定；- <strong>用定投对抗情绪</strong>：固定时间、固定金额，让纪律代替冲动。> 一句话：把“因为涨所以买”换成“因为便宜且看好所以买”。

## 4. 常见坑 / 误区

- <strong>止损 ≠ 杀跌</strong>：止损是按纪律卖出，杀跌是恐慌逃跑，前者有预案、后者纯情绪；- <strong>以为“顺势”就是追涨</strong>：趋势跟踪有入场标准，追涨没有，区别在纪律；- <strong>看别人赚钱就眼红</strong>：羡慕是最贵的情绪，它直接把你推进高位接盘区。
