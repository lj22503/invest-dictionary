# 布林带 BOLL

> 布林带 BOLL，是三根线组成的“波动通道”：中轨是 20 日均线，上下轨是中轨加减两倍标准差，用来判断价格是偏热还是偏冷。

## 1. 这是什么

**布林带 BOLL = 三根线组成的“通道”**：中轨是 20 日均线，上轨 = 中轨 + 2 倍标准差，下轨 = 中轨 − 2 倍标准差。

价格大多数时间在通道里来回跑。通道的宽窄就是**波动率**的直观体现：波动大，通道张开；波动小，通道收窄。
> 一句话：布林带，就是给价格画了一条“正常活动范围”的走廊。

## 2. 为什么重要

布林带的精髓不在“上下轨会撑住价格”，而在**通道宽度变化**。
- <strong>收口</strong>：波动率被压缩到极致，说明多空僵持，往往是大行情前的“蓄力”；- <strong>开口</strong>：波动率放大，趋势正在展开；- <strong>触上轨偏热、触下轨偏冷</strong>：是判断短线“贵不贵”的参考尺子。> 一句话：别跟轨道较劲，要跟宽度做朋友。

## 3. 怎么用 / 怎么看

- <strong>收口后向上突破上轨 + 放量</strong>：趋势可能开启，可关注；- <strong>价格贴着上轨持续走</strong>：强势特征，别急着“抄顶”；- <strong>触下轨企稳 + 缩量</strong>：超跌反弹的候选观察区；- <strong>跌破下轨且开口放大</strong>：波动失控，先避让。> 一句话：布林带是概率工具，不是精确买卖点。

## 4. 常见坑 / 误区

- <strong>把“触上轨必跌”当铁律</strong>：强趋势里价格会贴着上轨/下轨跑很久，逆着做容易被打脸；- <strong>参数乱调</strong>：默认 20 日、2 倍标准差是经典配置，改参数要有明确理由；- <strong>单独使用</strong>：布林带最好配合成交量、MACD 一起看，单指标容易误判。
