# 风险等级（R1-R5）

> 产品的风险等级不描述能赚多少，只描述本金可能亏多少、净值可能波动多大。

## 1. 五个档位怎么来的

依据是《证券期货投资者适当性管理办法》（2017 年 7 月施行）：经营机构把产品与服务的风险由低到高划成 **R1、R2、R3、R4、R5** 五级，同时把普通投资者的风险承受能力划成 **C1 至 C5** 五类，两边必须匹配销售。等级越高，意味着亏损可能性和波动幅度越大。

- R1 低风险：存款类、国债、货币基金一类
- R2 中低风险：纯债、短债、同业存单指数基金一类
- R3 中风险：混合型基金、可转债、商品期货（期货业协会名录里商品期货定在 R3）
- R4 中高风险：股票型基金、指数增强、金融期货与期权、部分跨境 QDII
- R5 高风险：杠杆与衍生品策略、场外衍生品无限敞口、私募股权一类

银行理财沿用自己的 PR1–PR5（谨慎型、稳健型、平衡型、进取型、激进型），分档逻辑与 R1–R5 大体一致，购买时按渠道展示的口径看即可。

## 2. 匹配规则才是重点

适当性匹配的方向是单向的：低承受能力不能买高等级产品，高承受能力可以买低等级产品。

- C1 只匹配 R1
- C2 匹配 R1、R2
- C3 匹配 R1 至 R3
- C4 匹配 R1 至 R4
- C5 匹配 R1 至 R5

专业投资者不受这套匹配限制，但产品本身若另有准入要求（资金门槛、交易经验），仍从其规定。

## 3. 那个 C 级是怎么来的

风险承受能力测评问卷了解的是：收入来源与数额、资产与负债状况、投资知识与经验、投资期限与目标、能接受的亏损幅度、诚信状况。机构据此综合评定，不是按单一得分发牌。测评结果有有效期，过期需重做；个人情况发生重大变化时也应当主动更新。

## 4. 常见坑

- **把 R5 理解成"高收益保证"**：等级只标风险，不标收益，R5 里的亏损案例远多于暴富案例
- **问卷随手填**：为了买某只产品而抬高承受能力，等于自己拆掉了唯一的保护层
- **只看等级不看底层**：同为 R3，一个是混合基金、一个是商品期货，波动来源完全不同
- **以为 R1、R2 保本**：资管新规之后不得承诺保本保收益，R1 只是历史波动极小
- **跨渠道比等级**：同一只产品在不同销售机构可能被评在不同等级，以你实际购买渠道的评定为准
- **忽略期限匹配**：适当性不只看风险等级，还要看投资期限与用钱计划是否冲突
