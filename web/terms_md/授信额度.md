# 授信额度

> 授信额度 = 银行评估后愿意借给你的最高金额上限。它是一张“预批条”：银行说最高敢借你这么多，但你没借、也没花。

## 1. 这是什么
你每次申卡、申贷，银行都会做一次“风险评估”：看收入、看资产、看征信、看负债，然后给出一个`最高可借金额——这就是授信额度。

它无处不在：信用卡额度、借呗/微粒贷额度、消费贷额度、经营贷额度……**额度是银行对你信用“定价”的结果，代表你在银行眼里值多少“信用”。


> 一句话：额度不是钱，是银行给你的一根“可借上限”标尺。

## 2. 为什么重要
- **征信变化**：逾期、频繁查询、负债率飙升，额度会被砍；
- **收入变化**：银行定期重估，收入下降额度跟着缩水；
- **使用行为**：长期不使用可能被降额，频繁刷爆会被怀疑“缺钱”；
- **政策调整**：监管收紧消费贷时，银行会批量压降额度。
额度是`动态的，今天给的高额度，明天可能就没了——这提醒你：别把额度当成稳定的资金来源。

## 3. 怎么用 / 怎么看
- **按时还款**：这是养额度的地基，一次逾期可能压掉大半额度；
- **控制使用率**：信用卡使用率长期低于 30%~50%，像“不差钱”的人，银行更愿意提额；
- **减少硬查询**：半年内频繁申卡申贷，每查一次都像“到处借钱”，会压额度；
- **大额贷款前 3~6 个月养征信**：别临时抱佛脚。

## 4. 常见坑 / 误区
- **把可用额度当“有钱”**：额度是负债不是资产，用了就要还，还有利息；
- **为了提额乱办卡**：每办一张多一次硬查询，反而伤征信、压额度；
- **点“提额”短信链接**：很多是钓鱼短信，点进去验证码一输就被盗刷；
- **以为额度只升不降**：银行随时可能调降，资金安排别全押在额度上。
