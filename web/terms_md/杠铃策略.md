# 杠铃策略

> 杠铃策略，是把资产分成两头：一头极端保守（国债/现金），一头极端进取（高风险高弹性），中间不上不下的一律不碰。

## 1. 这是什么

**杠铃策略 = 把资产分成两头：一头极端保守，一头极端进取，中间不上不下的一律不碰。**

保守那头是国债、现金、大额存单；进取那头是高风险高弹性的资产——期权、成长股、加密货币这类。中间那些“看起来稳又有点收益”的，恰恰是杠铃最嫌弃的。
> 一句话：像举杠铃一样，两头都抓牢，中间空着。

## 2. 为什么重要

这是塔勒布（《黑天鹅》《反脆弱》作者）推崇的策略，逻辑很直白：
- <strong>保守那头</strong>：保证最坏情况下你还有底，睡得着觉；- <strong>进取那头</strong>：万一黑天鹅正向降临，你还有暴击的可能；- <strong>放弃中间</strong>：中间资产“涨不赢、跌不惨”，两头不讨好。> 一句话：杠铃不追求“稳稳的幸福”，追求“输得有底、赢得有上限”。

## 3. 怎么用 / 怎么看

- <strong>比例因人而异</strong>：常见 90% 保守 + 10% 进取，风险承受力高可以调到 80/20；- <strong>进取那头要“真进取”</strong>：要么高弹性、要么高赔率，别拿“稍激进”冒充；- <strong>定期再平衡</strong>：涨多了卖掉一部分，跌多了补回来，保持两头比例。> 一句话：两头比例是锚，再平衡是纪律。

## 4. 常见坑 / 误区

- <strong>把“中间”也买了</strong>：买着买着就变成“梭哈型混合配置”，杠铃失效；- <strong>进取那头 overbet</strong>：10% 的仓位亏光也心疼，说明你高估了自己的承受力；- <strong>保守那头不是真保守</strong>：拿“高收益债”当保守资产，等于两头都是风险。
