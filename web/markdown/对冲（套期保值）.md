# 对冲（套期保值）

**一句话定义：对冲就是持有方向相反的仓位，把不确定的风险“锁”住——像给投资买一份保险。**

## 这是什么

对冲（Hedging）的核心不是赚钱，而是**减少损失的可能性**。做法是：手里持有 A 资产，同时买入一个与 A 反向波动的工具（期货、期权、融券做空等），当 A 下跌时，反向仓位赚钱，两相抵消。

套期保值是对冲最经典的用法，主要在企业和机构里：

- 航空公司担心油价上涨 → 买入原油期货锁价；
- 农户担心粮食丰收后价格暴跌 → 提前卖出期货锁定卖价；
- 基金经理担心持仓下跌 → 用股指期货或期权对冲系统性风险。

## 为什么重要

因为**裸奔的风险波动太可怕**。你重仓一只股票，公司基本面没变，但大盘一个月跌 20%，你的股票也可能跟着跌 20%。对冲的意义在于：把“不可控的市场波动”换成“可控的少量成本”。

对冲不是让你不亏，而是让你**亏得有上限**。代价是“保险费”——对冲工具本身有成本（期权权利金、期货保证金利息），而且在行情向好时，对冲仓位还会拖累收益。所以对冲的本质是：**用收益的上限，换回本金的底线。**

## 怎么用

普通人能接触的对冲工具：

1. **股指期货/期权**：门槛较高（50 万以上、知识测试），用一手上证 50/沪深 300 股指期货可以对冲一篮子股票；
2. **融券做空**：向券商借股票卖出，适合对冲你持有的同板块个股；
3. **买入看跌期权**：最灵活，最大亏损就是权利金，但需要开通期权权限；
4. **最简单的方式——分散配置**：股债搭配本身就是一种对冲，债券和股票经常“跷跷板”，天然互相兜底。

## 常见坑

- **把对冲当套利**：对冲是降风险，套利是赚价差，目的完全不同；
- **过度对冲**：本来只想防 20% 的下跌，结果买了 100% 的仓位做空，行情一涨，反而亏更多；
- **忽略基差风险**：期货和现货的价差会变动，完全“锁死”在现实中并不存在；
- **把对冲当长期策略**：持续对冲的成本会慢慢侵蚀收益，多数人更适合“降低仓位”而不是“开反向仓”。

> 一句话：对冲是用小钱买大平安，不是用大钱赚小钱；给投资买保险的前提是——你确实有需要保的东西。
