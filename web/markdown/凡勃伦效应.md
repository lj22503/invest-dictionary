# 凡勃伦效应

> 凡勃伦效应（Veblen Effect）指商品价格越高，部分消费者反而越想买——因为“贵”本身成了炫耀性消费的卖点。经济学里正常是“越便宜买越多”，凡勃伦商品却反着来。

## 1. 这是什么

凡勃伦效应（Veblen Effect）指商品价格越高，部分消费者反而越想买——因为“贵”本身成了炫耀性消费的卖点。经济学里正常是“越便宜买越多”，凡勃伦商品却反着来。

典型例子：奢侈包、名表、豪车、高价白酒、限量球鞋。买它们的人要的不是功能，而是“我买得起”的社会信号。

> 一句话：凡勃伦商品卖的是“让别人知道我买得起”这件事。


## 2. 为什么重要

凡勃伦效应解释了为什么有些公司能把“涨价”做成增长策略：品牌溢价越高，越能吸引目标客群，形成“越贵越买、越买越贵”的正循环。

对投资者，这意味着：有定价权（能持续涨价）的公司，往往比只会拼低价的公司更值得关注；对普通消费者，认清凡勃伦效应能避免为身份溢价买单。

它和“面子消费”“智商税”高度相关：三者都靠信息差和心理暗示获利，只是凡勃伦效应更强调“用价格证明身份”。


## 3. 怎么用 / 怎么看

- 问功能：去掉 logo，它和便宜款在核心功能上差多少？
- 问溢价来源：贵在真材实料/技术，还是贵在故事、明星和稀缺感？
- 问转手价值：二手市场真的有人接盘，还是只是一厢情愿？

用这三个问题过滤消费，同时可以反向用于选股：一家公司若能持续提价且销量不跌，说明它拥有品牌护城河。


## 4. 常见坑 / 误区

- 把消费品当投资品：买限量款指望升值，多数最终只是“贵价旧物”；
- 以为贵=质量好：凡勃伦溢价与质量不一定成正比，很多溢价付给了身份符号；
- 为面子加杠杆：借钱买奢侈品，是凡勃伦效应最危险的用法；
- 忽略维护成本：高价品的保养、折旧、贬值速度，往往比想象中更伤人。
