# AI荐股 / 直播荐股

## 1. 这是什么

AI 荐股 / 直播荐股指用“AI 智能选股”“量化模型”“直播间老师带你做”等话术包装的荐股服务。正规投顾尚需牌照与风险提示，而这些“老师”多数是拉人接盘的骗子。

常见剧本：直播间/群内晒收益 → 制造“跟着老师赚”的幻觉 → 诱导付费入群、下载指定 APP → 在虚假平台“操作”，最终本金无法提现。

> 一句话：AI 只是新马甲，骗局还是那个骗局——让你交钱、让你把资金交给陌生人。


## 2. 为什么重要

“AI 荐股”比传统荐股更迷惑人：科技词汇制造专业感，算法话术消解怀疑。受害者会觉得“机器算出来的总比我准吧”。

现实中，真正的 AI 模型也做不到稳定预测个股涨跌；公开监管规则明确，未经许可的荐股服务本身涉嫌违规，更不用说收你钱带你“炒股”的。


## 3. 怎么用 / 怎么看

- 一问：如果真能稳定赚钱，为什么还要拉我？——真赚钱的策略不会到处招人，更不会缺你的“服务费”；
- 二问：老师有没有投顾牌照？——证监会官网可查，无牌荐股即违规；
- 三问：资金进的是谁的账户？——正规交易走券商，让你下载“专用 APP”入金的，九成是虚拟盘；

> 一句话：凡是“包赚钱、稳收益、限时名额”的荐股，先按骗局处理。


## 4. 常见坑 / 误区

- 信收益截图：截图可以 P，盈利单可以只发赢的，还可以用模拟盘；
- 信“老师”的预测准确率：连蒙带猜总能蒙对几次，幸存者偏差而已；
- 付费进群后越陷越深：交了服务费还会被诱导“升级”，层层加码；
- 分不清“分析”与“荐股”：正规机构做的是风险提示与合规分析，不是喊单带单。
