# 保本（保本保息骗局）

**一句话定义：任何承诺“保本保息”的理财，要么是真存款（受 50 万赔付上限保护），要么是骗局，没有第三种。**

## 这是什么

“保本保息”这四个字，翻译过来就是：**你的本金不会少，收益写多少给多少。**听上去很美，但在今天的金融世界里，它只属于极少数“类存款”产品：

- 银行存款：受存款保险保护，50 万以内本息有保障；
- 国债、地方政府债：以国家/地方信用背书；
- 储蓄型保险的现金价值：按合同约定走。

除此之外，**任何理财产品、基金、信托、私募、甚至“银行代销”的理财，监管都明令不得承诺保本保息**。2022 年资管新规落地后，银行理财全面净值化，“保本理财”这个品类已经正式退出历史舞台。

所以当有人拍胸脯说“我们这个产品保本保息、年化 8%”时，你听到的不是一个产品，而是一个警报。

## 为什么重要

因为“保本保息”是骗局最常用的糖衣。高收益 + 保本，在数学上就不成立：

- 如果真能稳定赚 8%，他为什么不去银行借钱自己赚，而要分给你？
- 资金链一旦断裂，承诺的“本息”就是借新还旧的击鼓传花；
- 等你想赎回时，平台可能已经跑路，本金都拿不回。

监管打破“刚兑”、存款保险 50 万上限、理财净值化——这些都是在教你同一件事：**收益和风险是一体的，谁承诺只拿收益不担风险，谁就是在骗你。**

## 怎么用

三步识别“保本保息”是真是假：

1. **看牌照**：对方是不是持牌金融机构？银行、券商、基金公司官网可查。没有牌照的“财富管理公司”“投资管理公司”，一律当骗子处理。
2. **看收益**：承诺收益明显高于同期存款/国债（比如年化 5% 以上还保本），直接怀疑。**“保本 + 高收益”同时出现 = 骗局。**
3. **看资金去向**：问清楚钱进了谁的账户。正规理财资金托管在银行，骗局的钱直接打给个人或空壳公司账户。

## 常见坑

- **把“保本型结构性存款”当理财**：结构性存款本质是存款 + 衍生品，保本是“部分保本”，收益可能只有下限；
- **银行员工飞单**：在银行大厅签的合同，也可能是员工私自卖的第三方产品，章是假的，出事银行不赔；
- **“稳赚不赔”的养老项目**：高息返利 + 免费旅游，专骗老年人，本质是非法集资；
- **把“过往业绩”当保本承诺**：历史收益高不等于未来保本，更不等于合同承诺。

> 一句话：保本保息四个字，正规渠道里几乎绝迹；谁还在喊这四个字，谁就最可疑。
