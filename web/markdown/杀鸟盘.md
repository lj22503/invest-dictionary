# 杀鸟盘

## 1. 这是什么

杀鸟盘是刷单返利骗局的“黑话”称呼：骗子以“动动手指日入几百”为饵，专挑宝妈、学生、待业人群下手，像“杀鸟”一样先喂食、再宰杀。

剧本分四步：“挂鸟”（在社交平台发兼职广告）→ “喂鸟”（派小额任务，真给几块钱佣金获取信任）→ “杀鸟”（引导做大额任务，声称系统卡单、需要充值解冻）→ “收网”（拉黑消失，本金佣金全没）。

> 一句话：先给你尝甜头的“兼职”，多半是在为杀你做准备。


## 2. 为什么重要

杀鸟盘精准瞄准“想赚钱但门槛低”的人群：宝妈想贴补家用、学生想赚零花、待业者想找副业。骗子利用的正是“急需用钱”的焦虑。

这类骗局报案量极高，单笔损失从几百到几十万都有。更危险的是，受害者往往为了“回本”继续投入，越陷越深。

它与“刷流水 / 跑分”常组合出现：一旦你把银行卡交给“平台”收款，还可能背上洗钱的法律风险。


## 3. 怎么用 / 怎么看

- 一看是否垫资：任何要求你先垫钱再返佣的“兼职”，一律是骗局；
- 二看是否要求下载不明 APP：正规兼职不需要安装第三方平台，不明 APP 往往是伪造界面；
- 三看是否小额试饵：头几单真返利是诱饵，一旦做大额单，系统必然“卡单”；
- 四看是否要求“解冻”：以系统故障、账户冻结为由让你继续充值的，100% 是诈骗。

> 一句话：凡是“先垫钱、后返利”的兼职，直接报警止损，别给骗子第二单的机会。


## 4. 常见坑 / 误区

- 赌“下一单能回本”：骗子正是利用沉没成本心理，让你越投越多；
- 以为小额返利是真的福利：头几单返利是“喂鸟”成本，不是平台发善心；
- 把银行卡借给平台收款：轻则被骗，重则涉嫌帮助信息网络犯罪活动；
- 相信“手工活外发”类变体：诱导交押金、材料费的“手工活”，同样是杀鸟变种。
