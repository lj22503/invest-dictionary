# 港美股打新

> 港美股打新就是参与港股、美股的首次公开发行（IPO）申购，中签后在上市首日卖出赚差价。规则和 A 股打新完全不一样，机会与风险都更刺激。

## 1. 这是什么

A 股打新靠"市值配售+抽签"，中签率低但几乎不破发；港美股打新是**现金申购或融资申购**，不需要持有股票市值，拼的是资金量和认购倍数。

- **港股打新**：通过香港券商（或支持港股的互联网券商）申购，热门股经常超额认购几百上千倍，中签率按"一手中签率"分配，人人有份但可能只有一两手；
- **美股打新**：多数中概股 IPO 采用"配售制"，普通散户拿不到额度，通常只能通过承销商、券商或打新平台参与，门槛比港股高。

> 一句话：A 股打新像摇号，港股打新像抢货，美股打新更像"有关系才能买到"。

## 2. 为什么重要

- **制度红利窗口**：港股小盘新股长期存在"首日必涨"的壳资源效应，2016-2020 年是普通人低门槛参与的黄金期；
- **资金利用率高**：现金申购成本极低，融资申购能用杠杆放大中签量，小资金也能参与；
- **全球化资产入口**：通过打新认识港美股交易规则（T+0、无涨跌幅、绿鞋机制），是理解全球市场摩擦成本的第一课。

但必须清醒：**无涨跌幅限制+破发常态化**意味着打新不再是"无风险套利"，规则变了，盈亏分化极大。

## 3. 怎么打

- **第一步：开户入金**。选持牌券商，完成港股/美股账户开户，按券商要求入金（港卡直连或银证转账，注意出入金渠道）；
- **第二步：挑新股**。关注招股期，看四件事：基本面（是否盈利）、估值（相比同行贵不贵）、热度（认购倍数）、基石投资者（有没有大机构背书）；
- **第三步：申购**。在招股期内提交申购，现金一手或融资多手；港股常用"孖展"（融资）放大中签，但要付利息和手续费；
- **第四步：上市卖出**。上市首日或暗盘（上市前一晚的场外交易）卖出，落袋为安；破发则按纪律止损，别死扛。

## 4. 常见坑

- **把打新当稳赚**：港股小盘股破发率不低，美股中概股破发更是常态，2021 年后"无脑打新"亏钱的人一大把；
- **融资打新忽略成本**：孖展利息、认购费、暗盘价差，小涨小跌时这些成本可能吃掉全部收益；
- **忽略绿鞋机制**：有绿鞋（超额配售）的新股承销商能托价，但也可能压制上涨空间，不懂就别重仓博弈；
- **暗盘冲动**：暗盘涨了 50% 还想等 100%，结果开盘跳水；纪律应该是"暗盘/开盘达标就走"；
- **境外资金合规**：出入金要走合法渠道，警惕"代购打新""保本打新"等灰色服务，多数是杀猪盘。

> 一句话：港美股打新是"专业活"，玩的是资金效率、信息差和纪律，不是"中签就发财"。
