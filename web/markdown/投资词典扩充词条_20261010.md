## 词条 1：超额收益（跑赢基准的部分）

# 超额收益（跑赢基准的部分）

> 你赚到的钱里，比“闭眼买指数”多出来的那一部分，叫超额收益。

## 1. 这是什么

**超额收益 = 你的实际收益 − 基准收益。**基准通常选指数，比如沪深300。

假设今年沪深300涨了10%，你的基金涨了15%，那5%就是超额收益；如果基金只涨了7%，超额收益就是−3%，也就是跑输。

它衡量的是：**去掉“市场顺风”之后，你（或基金经理）自己到底有没有本事**。



## 2. 为什么重要

买主动基金，你要多付1%~1.5%的管理费。这笔钱买的就是超额收益。

如果一只基金长期跑不赢沪深300，那不如直接买指数基金——省钱、省心、还不用赌基金经理。

历史数据反复提醒：**大多数主动基金长期跑不赢指数**，能稳定创造超额收益的是少数。

- 看3年以上超额收益，别只看1年；
- 超额收益为负的年份里，基金经理怎么应对；
- 超额收益的来源是选股、择时还是运气。

## 3. 怎么用 / 怎么看

- **第一步，找基准**：股票型基金对沪深300，行业基金对行业指数，别拿错尺子；
- **第二步，算差额**：把基金各年收益减去基准收益，画出超额收益曲线；
- **第三步，看稳定性**：超额收益年年为正比“某一年暴涨”更值钱。工具上，晨星、韭圈儿、且慢等平台都有“超额收益”指标，可以直接看。



## 4. 常见坑 / 误区

- **只看一年**：某年大涨可能是风格刚好踩中，不代表有超额能力；
- **拿错基准**：拿基金和存款比，得出“跑赢”的假象；
- **忽略波动**：超额收益高但回撤巨大，体验可能很糟；
- **追刚夺冠的**：上一年冠军基金，下一年常跑输（冠军魔咒）。

## 词条 2：禀赋效应（我的东西更值钱）

# 禀赋效应（我的东西更值钱）

> 同一件东西，一旦归了你，你就觉得它比别人手里的更值钱。

## 1. 这是什么

心理学家做过经典实验：给一半人发一个杯子，另一半人没有。然后让有杯子的人报价卖掉，没杯子的人报价买下。

结果：**卖家的报价往往是买家的2倍以上**。杯子还是那个杯子，仅仅因为“已经是我的”，价格就变了。

这就是禀赋效应：**人对已经拥有的东西，会系统性地高估它的价值**。



## 2. 为什么重要

手里的股票跌了30%，为什么还是舍不得卖？除了不想认输，禀赋效应也在发力：**因为“我的股票”被自动加上了感情溢价**。

你会为它找各种理由：公司基本面还行、迟早会涨回来……而同样一只股票，如果是别人推荐你买，你大概率会躲开。

禀赋效应还会影响生活决策：旧东西舍不得扔、房子挂高价卖不掉、纪念品越积越多。



## 3. 怎么用 / 怎么看

- **灵魂三问**：如果我没持有它，今天这个价格我会买入吗？不会，就卖；
- **设卖出条件**：买入前先写下“跌到多少、涨到多少就操作”，避免事到临头被感情绑架；
- **给旧物设试用期**：把想扔的东西放门口一周，一周没用到就处理掉。

## 4. 常见坑 / 误区

- **把成本价当锚**：非要等回本才卖，结果越套越深；
- **只记赚的不记亏的**：卖掉赚钱的股票、留下亏钱的（处置效应叠加）；
- **对赠品/中奖资产格外高估**：白来的东西舍不得卖，错过最佳时点；
- **搬家/清理时高估旧物**：以为还能值钱，其实挂闲鱼半年无人问。

## 词条 3：货币幻觉（名义 vs 实际）

# 货币幻觉（名义 vs 实际）

> 看到工资涨了5%，却没发现物价也涨了5%——钱其实一点没变多。

## 1. 这是什么

老板说给你涨薪5%，你挺开心。但如果今年的物价（CPI）也涨了5%，那你的**实际购买力一分没变**。

只盯着“数字变大”，忽略“物价也涨了”，就是货币幻觉。

经典区分：**名义值=纸面上的数字；实际值=数字−通货膨胀**。



## 2. 为什么重要

货币幻觉会同时影响赚钱和花钱两头：

- **谈薪资**：涨薪5%但通胀6%，实际是降薪1%；
- **看理财**：年化收益4%，通胀3%，真实收益只有1%；
- **看存款**：2%的存款利率跑不赢3%的通胀，存款在“实际缩水”；
- **做预算**：只按名义金额规划，容易被涨价打乱。

## 3. 怎么用 / 怎么看

- **薪资谈判**：要求“实际涨幅”，即名义涨幅−预期CPI；
- **理财比较**：用“实际收益率=名义收益率−通胀率”横向比；
- **长期规划**：养老、教育金目标按3%~4%年通胀滚动；
- **看数据**：关注“实际GDP”“实际工资”“实际利率”这些扣过通胀的指标。

## 4. 常见坑 / 误区

- **把4%当宝**：通胀3%时实际只有1%，还没跑赢银行理财；
- **忽视负实际利率**：存款利率2%、通胀4%，存得越多实际亏得越多；
- **用名义值做长期规划**：20年后的100万，购买力可能只剩一半多；
- **只记工资涨幅不记物价**：感觉“越来越有钱”，实际越来越紧。

## 词条 4：框架效应（换个说法，换个决定）

# 框架效应（换个说法，换个决定）

> 同一件事，说法不同，你的选择就会跟着变——这就是框架效应。

## 1. 这是什么

同样一台手术，跟病人说“存活率90%”，同意手术的人很多；说“死亡率10%”，很多人就犹豫了。

事实完全一样，只是**表述的“框架”不同**，决策就变了——这就是框架效应。

人脑对“损失”和“获得”的敏感度天生不同：**把同一件事包装成“获得”，人就更容易接受**。



## 2. 为什么重要

基金宣传“历史正收益概率90%”，理财经理说“这个产品很稳”，保险公司说“不买就亏了”——全是在选框架。

- **“保本”框架**：让你忽略收益其实很低；
- **“限时”框架**：制造稀缺，逼你快速下单；
- **“省下”框架**：“每天省一杯奶茶”听上去轻松，实际年化收益可能很低。

## 3. 怎么用 / 怎么看

- **自动转译**：听到“稳”“保本”“几乎不会亏”，翻译成“可能亏多少、最坏情况是什么”；
- **换框架自测**：把“赚了5%”改说成“本金100万赚5万”，感觉完全不同，再想想还买不买；
- **主动设负面框架**：问自己“如果这个产品亏30%，我扛得住吗”；
- **延迟决策**：被框架打动时，先放24小时再决定。

## 4. 常见坑 / 误区

- **只问收益不问风险**：宣传单上永远是“年化X%”，没有“可能亏X%”；
- **被“限时/限量”催单**：好产品不需要催，催你的往往有坑；
- **把“别人都买”当理由**：从众也是框架的一部分；
- **复盘时只记结果**：赚钱了就觉得自己英明，忽略了决策过程是否被框架影响。

## 词条 5：代表性偏差（以貌取股）

# 代表性偏差（以貌取股）

> 因为“长得像牛股”就以为它会是牛股——用印象代替概率，就是代表性偏差。

## 1. 这是什么

听说邻居靠炒股买了房，你是不是也觉得自己炒股能发财？

这是典型的代表性偏差：**用“个例像不像”代替“概率有多大”**。

你看到的暴富故事很“典型”，所以大脑自动给它加权；但真实世界里，炒股亏钱的人远比暴富的人多。

判断应该看**概率分布**，而不是看“故事像不像”



## 2. 为什么重要

代表性偏差在投资里的表现：

- **买“长得像牛股”的股票**：名字带“科技”“AI”就冲进去；
- **追明星基金经理**：觉得他过去牛，未来一定牛；
- **把牛市当常态**：因为最近涨得好，就以为一直会涨；
- **根据长相判断公司**：PPT漂亮、赛道性感，就忽略了估值和现金流。

## 3. 怎么用 / 怎么看

- **先问基数**：这类公司/基金/策略，历史上成功的比例是多少；
- **找反例**：主动找一个“长得像但失败了”的案例，打破相似性直觉；
- **看数据不看故事**：营收、利润、现金流、估值分位，比“赛道故事”可靠；
- **分散持有**：承认自己判断会错，用组合对冲“看走眼”。

## 4. 常见坑 / 误区

- **把1次成功当方法**：一次押中题材股，就以为自己会选股；
- **幸存者偏差叠加**：只看到成功者，看不到大批失败者；
- **被“典型性”骗**：名字、包装、创始人故事都像“好公司”，但基本面不是；
- **频繁切换风格**：每次看到“新典型”就换方向，成本越换越高。

---

**相关词条**：幸存者偏差、确认偏误（只看自己想看的）、赌徒谬误、羊群效应（跟风）

## 词条 6：长期主义（用时间换复利）

# 长期主义（用时间换复利）

> 相信时间站在自己这边，用5到10年的耐心，换复利慢慢长大。

## 1. 这是什么

长期主义像种树：前几年看不出什么，但树一旦长起来，回报是指数级的。

短期主义像摘果：今天摘今天就吃，但果园永远不会变大。

复利公式很诚实：**本金 × (1+收益率)^时间**。时间是指数，前面慢，后面快。



## 2. 为什么重要

格雷厄姆那句名言说透了：**短期股价由情绪决定，长期由价值决定**。

- 短期：消息、情绪、资金面主导，像投票，今天涨明天跌；
- 长期：公司盈利、现金流、行业格局主导，像称重，好公司最终会被市场认出来；
- 统计上，**持有越久，正收益概率越高**（A股主要宽基指数10年滚动持有几乎全为正）。

## 3. 怎么用 / 怎么看

- **定投**：固定金额、固定频率，自动摊平波动，避免择时焦虑；
- **再平衡**：每年把股债比例调回目标，机械执行“高抛低吸”；
- **少看账户**：把看盘频率从每天降到每月，减少情绪干扰。再加一条：**用长期资金投资**——3年内要用的钱别进股市。



## 4. 常见坑 / 误区

- **套牢就当长期投资**：被套了安慰自己“长期持有”，其实是逃避决策；
- **长期≠永远**：公司基本面恶化时，长期主义也要求你卖出；
- **用短期资金硬扛**：买房、结婚的钱被套，被迫割肉；
- **只看长期不看估值**：再好的公司，买贵了也可能几年不涨。

---

**相关词条**：定投（定期定额投资）、资产配置（核心-卫星策略）、再平衡（动态调整仓位）、均值回归

## 词条 7：成长投资（买的是明天的故事）

# 成长投资（买的是明天的故事）

> 买那些收入和利润还在快速长大的公司，赌的是它未来的样子比现在更好。

## 1. 这是什么

成长投资的核心逻辑：**公司现在还小、还贵，但收入和利润增速很快，未来会变得更大、更值钱**。

典型画像：营收增速20%以上、行业空间大、产品有壁垒的科技/消费/医药公司。

买成长股=买“未来的现金流”，所以今天的高市盈率可以被高增速“消化”。



## 2. 为什么重要

- **涨幅弹性大**：成长股在牛市中往往是涨幅最大的那批；
- **机构重仓**：基金抱团股里，成长风格长期占主流；
- **对应“戴维斯双击”**：业绩增长+估值提升，收益可以翻倍再翻倍；
- **风险也大**：增速一旦不及预期，估值杀起来同样凶。

## 3. 怎么用 / 怎么看

- **营收/利润增速**：连续3年保持20%以上，才是真成长；
- **PEG**：市盈率÷利润增速，<1说明估值还没跑赢成长；
- **护城河**：增速高的公司多，能持续高增长的少，看产品力、品牌、网络效应。再配一条纪律：**分批买入、设定止损/止盈线**，防止单一公司证伪。



## 4. 常见坑 / 误区

- **把题材当成长**：没有业绩支撑的“AI概念”“元宇宙概念”，涨得快跌得更快；
- **只看增速不看持续性**：一年暴增50%，可能是低基数或一次性收益；
- **忽视估值透支**：增速20%却给100倍PE，等于提前透支了5年业绩；
- **不设止损**：成长股一旦证伪，腰斩是常事，死扛伤害极大。

---

**相关词条**：成长股 / 价值股、PEG、市盈率（PE / 滚动PE / 静态PE）、护城河

## 词条 8：高利贷（年利率超过法定上限）

# 高利贷（年利率超过法定上限）

> 借钱时看着便宜，实际年化远超法定保护上限的贷款，就是高利贷。

## 1. 这是什么

法律对民间借贷的保护利率上限，目前按**1年期LPR的4倍**计算（现行约13.8%上下，随LPR浮动）。

超过这个利率的部分，法律不予保护——也就是“借了可以不给那么高利息”。

但现实中，高利贷从来不会直接写“年化30%”，而是用**砍头息、服务费、保证金**等各种名目包装。



## 2. 为什么重要

高利贷最凶的不是利率本身，是**复利滚动+借新还旧**：

- 借1万、日息1%（年化约365%），一年后本息接近4.5万；
- 还不上就“续借”，服务费再砍一刀，实际利率更高；
- 一旦以贷养贷，几个月就能滚到倾家荡产。714高炮、套路贷、校园贷大多是高利贷的变种。



## 3. 怎么用 / 怎么看

- **第一步，算真实到账**：砍头息要算进去，借1万只到账8500，实际本金就是8500；
- **第二步，算真实年化**：用IRR算真实利率（月供模式尤其要算）；
- **第三步，和红线比**：折算年化超过LPR 4倍，就是法律不保护的高利贷。工具：Excel的IRR函数、各种贷款计算器App都能算。



## 4. 常见坑 / 误区

- **砍头息**：借1万先扣1500“手续费”；
- **超短期限**：7天、14天借款，日息看着低，年化吓死人；
- **阴阳合同**：合同写低利率，实际执行高利率；
- **暴力催收/软暴力**：逾期后骚扰家人朋友，逼你借新还旧；
- **以贷养贷建议**：“再借一笔把前面的还上”，是滚雪球的开始。

---

## 词条 9：以贷养贷（借新还旧的死循环）

# 以贷养贷（借新还旧的死循环）

> 用新贷款还旧贷款的利息，窟窿越补越大——这就是以贷养贷。

## 1. 这是什么

工资不够花，刷了A卡；到还款日还不上，刷B卡套现还A；B卡也还不上了，再办C卡……

这就是以贷养贷：**不断借新钱还旧账，本金一分没少，利息越滚越多**。

每一笔“续命”都要付手续费和利息，负债以复利速度膨胀。



## 2. 为什么重要

以贷养贷的杀伤力在于：

- **负债指数增长**：月息2%看似不高，复利下2年翻一倍多；
- **多头借贷**：网贷平台几十家，征信越查越花；
- **收入被利息吃光**：每月还款额远超收入，只能继续借；
- **最终爆雷**：所有平台同时收紧额度，资金链瞬间断裂。很多“上岸”故事背后，是从10万滚到80万再艰难爬出来的真实案例。



## 3. 怎么用 / 怎么看

- **第一步，停新贷**：从今天起不再借任何一笔新钱，包括套现；
- **第二步，算总账**：把所有负债列成清单：金额、利率、还款日，算清总债务和月供；
- **第三步，和债权人协商**：和银行/平台谈分期、减免利息、延长期限，表明还款意愿；如果债务已失控，寻求家人帮助或专业债务重组，别硬扛。



## 4. 常见坑 / 误区

- **“再借一笔就能周转开”**：周转的前提是收入能覆盖利息，否则只是续命；
- **“逾期一次没关系”**：逾期上征信，后面所有贷款都会变贵或借不到；
- **“还最低还款就行”**：最低还款剩余部分继续计息，复利照样滚；
- **“以贷养贷别人也这样”**：别人爆雷的时候，不会通知你。

## 词条 10：房产税（持有环节的税）

# 房产税（持有环节的税）

> 对持有的房子按价值征税，不交易也要交——房产税是持有环节的税。

## 1. 这是什么

买房时交的契税、卖房时交的增值税和个税，都是**交易环节**的税——只有发生买卖才交。

房产税是**持有环节**的税：只要房子在你名下，每年按评估价值交一次，跟买卖无关。

它更像“物业税”：**房子是资产，持有资产就要付持有成本**。



## 2. 为什么重要

- **对持有多套房的人**：每年多一笔固定支出，持有成本上升；
- **对房价预期**：持有成本提高，投机需求会被抑制，短期利空房价；
- **对租金**：房东可能把税转嫁给租客，租金上涨；
- **对刚需**：首套一般有免征面积/免征额，影响相对小。国内目前在上海、重庆等地试点，尚未全国推开。



## 3. 怎么用 / 怎么看

- **第一步，看免征**：试点方案通常有人均免征面积（如60㎡），超出部分才计税；
- **第二步，看税率**：各地不同，多在0.4%~1.2%，按评估价或交易价计税；
- **第三步，算年度成本**：超出面积×单价×税率，就是每年要多花的钱；
- **第四步，重估资产配置**：如果持有成本吃掉租金收益，就要考虑是否继续持有。

## 4. 常见坑 / 误区

- **以为只对富人收**：多数方案按面积和套数累进，中产多套房也可能被覆盖；
- **以为会立刻全国铺开**：立法和试点节奏缓慢，短期影响有限；
- **忽略转嫁**：房东可能涨租金，租客也要承担部分成本；
- **忽略评估价上涨**：房价涨，评估价跟着涨，持有税也会变多；
- **以为“房产税=取消限购”**：两者是不同工具，别混为一谈。
