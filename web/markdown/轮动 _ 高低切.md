# 轮动 / 高低切

**一句话定义：轮动是资金在板块之间转圈圈；高低切是资金从涨太多的切向跌太多的。**

## 这是什么

**板块轮动**：市场资金总量有限，钱不可能同时买所有板块。于是它像一个“热点接力棒”：今天新能源，明天半导体，后天消费——资金在行业板块之间轮番进出，形成“你方唱罢我登场”的节奏。

**高切低（高低切）**：当某个板块已经涨到高位、估值很贵时，一部分资金会获利了结，切向还没怎么涨、估值便宜的板块——从“高”切向“低”。

两个概念常常同时出现：轮动是现象，高低切是轮动的一种典型形态。

## 为什么重要

因为 A 股是典型的“结构性行情”市场：**指数可能没怎么动，但板块之间冰火两重天。**理解轮动，你就理解了三件事：

- 为什么你拿的股票基本面没变，却突然不涨了——不是公司坏了，是资金去别的板块了；
- 为什么“追热点”经常追在最高点——你看到的热点，往往是资金已经炒过一轮的板块；
- 为什么有些“便宜”板块一直便宜——资金没来之前，便宜可以便宜很久。

轮动的背后是**情绪周期 + 估值差 + 政策催化**三者的合力，读懂轮动方向，是把握结构性行情的关键。

## 怎么用

1. **观察资金流向**：北向资金、主力资金、ETF 份额变化，谁在被持续买入，谁在被持续卖出；
2. **看板块估值分位**：估值处于历史低分位的板块，是潜在轮动方向；高分位板块，警惕资金流出；
3. **看催化事件**：政策、业绩、产业新闻往往是轮动启动的扳机；
4. **不追末端**：一个板块已经连涨 3 个月、人人都在讨论时，大概率轮到别人了；
5. **组合而非单押**：均衡配置几个高景气 + 低估值板块，比押注单一“轮动方向”更稳。

## 常见坑

- **把“高低切”当铁律**：低估值板块可以长期低估值（“便宜有便宜的理由”），高切低不一定马上兑现；
- **追轮动追在末端**：你看到消息时，资金往往已经完成第一轮炒作，进去就是接盘；
- **只看板块不看个股**：板块轮到了，但你的个股是板块里的弱势股，照样不涨；
- **频繁交易交学费**：每次轮动都换仓，手续费 + 踏空，一年下来跑输不动的朋友。

> 一句话：轮动是市场的常态，高低切是轮动的一种；别追轮动的尾巴，要看估值与资金的位置。
