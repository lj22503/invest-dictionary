# 港股通 / 南向资金

**一句话定义：港股通是内地投资者买卖港股的官方通道；南向资金就是从内地流向港股的钱。**

## 这是什么

港股通是“沪港通”“深港通”体系的一部分，让内地投资者不用开香港券商账户，直接用 A 股账户就能买港股。

- **沪港通（2014 年开通）**：上交所 ⇄ 港交所；
- **深港通（2016 年开通）**：深交所 ⇄ 港交所；
- **南向**：内地 → 港股，资金叫“南向资金”；
- **北向**：港股（外资）→ 内地，资金叫“北向资金”。

南向资金每天收盘后公布净买入额，是观察内地资金动向的重要指标。港股通可买的股票有限制（纳入“港股通标的”名单的才可买，主要是大中盘蓝筹和部分科技股）。

## 为什么重要

对普通投资者，港股通是**资产配置里为数不多的“出海”渠道**：

- 能买到 A 股没有的优质公司（部分互联网、消费、医药龙头只在港股/美股上市）；
- 同一家公司同时在 A 股和港股上市时，常出现 **A/H 溢价**——港股可能更便宜；
- 港股市场机制更成熟：做空、T+0、衍生品齐全，定价更市场化。

对观察市场的人，南向资金是“聪明钱”风向标之一：连续大额净流入往往意味着内地资金看好港股，反之则是撤退信号。

## 怎么用

1. **开通条件**：A 股账户近 20 个交易日日均资产不低于 50 万人民币（含市值 + 现金），线上即可开通；
2. **交易规则**：T+0 回转交易（当天买可当天卖），但资金交收是 T+2；
3. **无涨跌幅限制**：单日可以涨 50% 也可以跌 50%，波动比 A 股大得多；
4. **汇率与费用**：以港币报价、人民币结算，有汇率折算；佣金、印花税、交易征费等与 A 股不同，整体摩擦成本更高。

## 常见坑

- **以为港股便宜就能闭眼买**：港股很多股票常年低估值是有原因的（流动性差、治理瑕疵、退市风险），便宜有便宜的道理；
- **忽略流动性**：小市值港股一天成交几百万港元，买入容易卖出难，一卖就是“跳空”；
- **汇率风险被忽视**：人民币升值时，你持有的港股即使股价没跌，换算回人民币也会缩水；
- **50 万门槛刚够就冲**：账户资产达标 ≠ 你懂港股，先用小仓位试水，别把门槛当水平。

> 一句话：港股通是通道，南向资金是风向标；通道能开，但要带着“波动比 A 股大、流动性比 A 股差”的预期进去。
