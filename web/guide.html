01

查词学词

单个词条是什么

看到“可转债”“M1”“最大回撤”这种词，想知道它的准确定义、为什么重要、怎么用、有什么坑。

提示词PROMPT
用投资词典的方法写一个词条：可转债
配套 SKILL invest-dictionary-generator（单词条生成）

心法：只查一个词就用它。每个词条都是“一句话定义 → 为什么重要 → 怎么用 → 常见坑”四段式，3 分钟能看懂。

02

看新闻

一段新闻说人话

刷到“央行降准释放 1 万亿”“CPI 又涨了”这类新闻，每个字都认识，连起来看不懂。

提示词PROMPT
帮我翻译这段新闻：央行降准0.5个百分点，释放长期资金约1万亿，说人话
配套 SKILL combo-narrative（新闻翻译机）

心法：把新闻拆成几个核心概念 → 串成因果链 → 落到“对你意味着什么”。不预测涨跌，只讲关系。

03

持仓亏了

现象倒查

理财亏了、被推荐了高息产品、听说黄金要涨，心里没底，不知道该看什么、该慌不该慌。

提示词PROMPT
我买的理财亏了，要不要赶紧卖掉？
配套 SKILL symptom-lookup（理财急诊 / 症状倒查）

心法：你说一句口语化的“症状”，它倒查出你最该看的 3-5 个词条，并告诉你先看哪一条。不给买卖结论，只帮你分清“是正常波动还是买错了”。

04

产品对比

二选一对打

在“存定期还是买理财”“买房还是租房”之间纠结，两边都有销售说好话。

提示词PROMPT
手里有 10 万，存定期还是买银行理财？
配套 SKILL duel-compare（二选一擂台）

心法：先校验两个选项是不是真的在同一个场景里对打，再按“最坏情况 / 流动性 / 收益来源 / 适合谁”四维并排看，最后给分界线和一个今天能算的试算。

05

重大决定

决策拼图

面对“要不要提前还贷”“该不该存教育金”“该不该买增额寿”这种单边决策，不知道取决于什么。

提示词PROMPT
我要不要提前还房贷？
配套 SKILL decision-mosaic（决策拆解桌 / 决策拼图）

心法：把决策拆成“取决于哪几个变量” → 每个变量让你填一个数字 → 给分界线（什么条件倾向做、什么条件先别动）→ 给一个今天能做的清单。不替你做决定。

06

防坑提问

该问什么

销售说“锁定 3% 复利”“保本保息”“过去三年年化 20%”，你听着心动，但不知道该怎么问、怕被绕进去。

提示词PROMPT
增额终身寿险，我该问销售什么问题？
配套 SKILL question-probe（防坑提问器 / 该问什么）

心法：输出你应该问销售的 3-5 个问题，每个问题配“为什么重要”和“对方可能怎么绕”，最后给红灯信号——什么回答意味着“别继续了”。

07

复杂事件

概念串联

一段复杂的宏观数据 / 政策 / 财报要讲给别人听（客户、家人），或者你要发一份客户简报。

提示词PROMPT
把这段做成网页：央行降准后市场怎么看，讲给客户听
配套 SKILL invest-dictionary-concept-combinator（概念串联）

心法：6 类内容（数据 / 事件 / 政策 / 异动 / 财报 / 个人决策）各有模板，拆成核心词条串成叙事线，输出 6 屏可发布网页。想快速听懂不求成品时，用 combo-narrative（新闻翻译机）即可。

08

今日热词

追热点

今天市场都在聊什么？缩量、放量、LPR、创新高……这些词什么意思，怎么串成一件完整的事？

提示词PROMPT
今日热词，今天市场都在聊什么？
配套 SKILL daily-hotword（每日热词）

心法：围绕一条热点话题拆出 3-5 个今天必须懂的热词，每个词讲人话 + 说明为什么今天要看它，最后串成一句能复述给朋友的话。
