# LPR 是什么？你的房贷利率到底怎么算的（2026年）

> 结论先放这：**你的房贷利率 = LPR + 加点**。LPR 是"贷款市场报价利率"，每月 20 日由 18 家报价行报出，2026 年 8 月 5 年期以上 LPR = **3.5%**（已连续 15 个月不变）。选浮动利率，月供会随 LPR 每年调整一次；选固定利率，30 年不变。**选浮动还是固定，赌的是未来利率走势**。用[房贷计算器](https://fintools.mangofolio.com/tools/mortgage.html)算清每种利率下的月供，再决定。

## 一、LPR 是什么？

- **全称**：Loan Prime Rate，贷款市场报价利率；
- **谁报的**：18 家商业银行每月 20 日报价，去掉最高最低后算术平均；
- **怎么用**：银行放贷以 LPR 为基准，加（减）基点形成实际利率；
- **两种期限**：1 年期 LPR（企业/消费贷基准）、5 年期以上 LPR（房贷基准）。

**一句话**：LPR 是银行贷款的"批发价"，你的房贷是"零售价" = 批发价 + 加点。

## 二、房贷利率怎么算？公式就一条

```
你的房贷利率 = 5年期以上LPR + 加点（BP）
1 BP = 0.01%
```

举例（2026 年 8 月，5 年期以上 LPR = 3.5%）：

| 加点 | 房贷利率 | 100万30年月供 |
|---|---|---|
| −20 BP | 3.30% | 4,372 元 |
| 0 BP | 3.50% | 4,490 元 |
| +30 BP | 3.80% | 4,660 元 |
| +80 BP | 4.30% | 4,948 元 |

**关键**：加点在贷款合同里**固定不变**（签合同那一刻锁定），变动的只有 LPR。

## 三、浮动 vs 固定，怎么选？

| | 浮动利率（主流） | 固定利率 |
|---|---|---|
| 利率怎么变 | 每年重定价日按最新 LPR 调整 | 签合同时锁定，30 年不变 |
| 重定价日 | 每年 1 月 1 日 或 贷款发放日对应日 | 无 |
| 降息时 | 月供跟着降 | 享受不到 |
| 加息时 | 月供跟着涨 | 不受影响 |
| 适合谁 | 预期利率下行 | 预期利率大幅上行/极度厌恶波动 |

**现状**：2019 年 LPR 改革后，绝大多数新房贷都是浮动利率；2024 年起 LPR 持续下行，浮动利率用户普遍受益。

## 四、存量房贷也会跟着变吗？

- **浮动利率存量房贷**：每年重定价日自动按最新 LPR 调整月供（2026 年 1 月 1 日不少人的月供已下调）；
- **加点太高怎么办**：2024 年国家统一调整过一次存量房贷加点（多数调到 −30BP 附近，二套另有政策）；之后如利率仍偏高，可关注各银行"商转公"或提前还款。

## 五、3 个实操提醒

1. **看合同两个数**：LPR 基准（会变）+ 加点（不变），别只记"利率 3.5%"；
2. **重定价日别忘**：降息后月供不是立刻变，要等重定价日才生效（多数是每年 1 月 1 日）；
3. **未来利率怎么看**：当前 5 年期以上 LPR 3.5% 处于历史低位，是否继续下行取决于经济和通胀——选浮动前想清楚自己的判断。

## FAQ

### 1. LPR 是什么？
贷款市场报价利率，每月20日由18家报价行报出。5年期以上LPR是房贷基准利率，2026年8月为3.5%。

### 2. 房贷利率怎么算？
房贷利率 = 5年期以上LPR + 加点（BP）。LPR会变，加点在签合同时锁定不变。1BP = 0.01%。

### 3. 选浮动还是固定利率？
浮动利率每年按最新LPR调整，降息受益；固定利率锁定30年不变。预期利率下行选浮动，极度厌恶波动选固定。

### 4. 存量房贷利率会变吗？
浮动利率存量房贷每年重定价日自动调整（多数为每年1月1日）；加点过高的可关注2024年统一调整后的政策、商转公或提前还款。

### 5. 降息后月供什么时候变？
要等重定价日（多数为每年1月1日或贷款发放日）才生效，不是立刻变。
