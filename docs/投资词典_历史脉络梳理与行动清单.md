#### ⭐ 10 月中 对标调研（用户理解的分水岭）

**用户是谁**（与工作台的"觉醒的受困者"截然不同）：
> 词典服务的是"**被术语挡在门外的普通人**"——不是想建立交易体系，而是**想看懂、想不被忽悠、想消除信息差**。

三层画像：
1. **"理财文盲"型小白** —— 词都认识，连起来看不懂
2. **"被动签署"型** —— 闭眼签、不好意思追问
3. **被黑话刺痛的情绪型** —— 焦虑的不是"不懂"，是"别人好像都懂，只有我不懂"

**四类痛点** → 每类直接对应一个场景入口：术语加密通话 / 说明书不说人话 / 新闻数字读不懂 / 合规权限规则没人讲透

**差异化壁垒（这是你真正的护城河）**：
1. **场景化入口** —— 用户不是来"查词"的，是带着具体困惑来的
2. **合规的边界感** —— "不推荐买什么、不预测涨跌"，这在投资科普领域是**信任资产**

**关键词挖掘四渠道**（可直接执行）：小红书评论区 / 雪球·韭研公社 / 支付宝·天天基金吧 / 微信搜一搜
> 提炼公式：`术语词 + 困惑形态（什么意思/怎么看） + 场景（基金/理财/可转债/北交所）`

**（2）四组数据验证法**（决定一个场景该不该加码）

#### ⭐ 10-08 备案清单（战略红线）

**实测结论**：整条链路（域名解析 → Cloudflare CDN → Vercel 托管）**均在海外** → 不触发 ICP 备案义务。

**但代价是**：

| 渠道 | 是否可行 |
|---|---|
| 百度竞价/推广 | ❌ ICP 是硬门槛，直接驳回 |
| 百度 SEO 自然流量 | ❌ 未备案进"观察期"，收录慢 3-5 倍 |
| 微信生态（公众号/朋友圈/小程序） | ❌ 2026 起未备案域名几乎无法在微信内打开 |
| 信息流广告 | ❌ "三不政策" |
| 内容平台软文（小红书/知乎） | ⚠️ 半可行，落地页体验差 |
| 海外用户 | ✅ 可行 |

**核心矛盾**：想在国内正规推广 → 必须备案；但备案要求解析到国内服务器 IP + 备案期间关站 → 与当前 Vercel/Cloudflare 架构互斥。

**最大风险**：备案时若被认定涉金融类，**需金融主管部门前置审批文件**。dictionary 作为纯词典/科普，是**最可能被认定为非金融属性的那个站**，适合做备案试水先手。

## 三、三个结构性观察到的问题

### 1. 调研在加厚，回填在停滞

从 9 月到 10 月产出了一批高质量调研（对标 81KB、备案清单、游戏化设计、IMA 接入指引），
**但没有一篇的结论被回填进产品**。词条数 380 → 985 说明生产能力很强，
而 P0-1/P0-2 纹丝不动说明**回填通道是断的**。

> 这不是执行懒，是缺路径：调研停在 md 里，没有变成 issue / checklist / CI 检查。

### 2. 基建与分发严重失衡

基建侧持续投入（词条、Skill、PWA、APIs、品牌令牌），
分发侧 7 类渠道零痕迹。**985 个词条如果没有人进来，边际价值接近零。**

而 10 月调研已经给出了低启动难度的最优解：**社媒内容 + AI GEO 布局**（均为"低"难度），却没动。

### 3. 最大卡点被日常技术工作挤走了

**备案是唯一能让 985 条内容在国内产生复利的开关**，但它的优先级被 UI 细节持续挤后。
而 UI 优化在天字第一级的约束下……**再精致的页面，微信里打不开就是零**。

## 五、给回填建通道（**2026-10-31 已落地**）

这批问题之所以反复出现，根因是**调研 → 产品之间没有强制通道**：
调研停在 md 里，没有变成 issue / checklist / CI 检查，于是 P0-1/P0-2 横跨一个半月纹丝不动。

**通道已经建好了**：`scripts/site-audit.py` 新增 **backfill（历史回填）** 维度，
把你提的那几项全部固化成检查 —— 每次跑都会报警，不再等人记起。

| 检查项 | 判什么 | 实测 |
|---|---|---|
| P0-1 URL 残留 `.html` | 本站域名 + 相对路径的 URL 后缀（含分享链接 query 里二次编码的） | ✅ 0 |
| P0-2 首页静态词条内链 | 剥掉 `<script>` 后数真锚点，覆盖率下限 95% | ✅ 995/995 |
| sitemap 覆盖率 | 词条页 + 主页面双向零缺口 | ✅ 995/995 + 5/5 |
| llms.txt 覆盖率 | **解码后比对**（编码会让比对假性全通过） | ✅ 995/995 |
| 隐私政策 / 用户协议页 | 文件存在 + footer 挂入口 | ✅ 存在且已挂 |

**这条通道第一次跑就抓到了真 bug**：20 个词条页的微博分享链接里，
`url=` 参数仍指向 `.../terms/黄金储备.html`（二次编码，P0 的规范化脚本没扫到 query 参数），
分享出去会多一跳 308 —— 已修。**说明"调研 → 检查"这条链路真的能兜住人脑兜不住的东西。**

**写检查项时的三条经验（别踩）**：
1. **口径要对齐实际形态** —— 首页静态链接是相对路径 `terms/xxx`，正则若只认 `/terms/` 就会误报 0 条。
2. **别扫全文找关键词** —— CSS 注释里的基准页路径、JSON 里的 `"filename": "货币.html"`、
   外站本来就用 `.html` 的（`invest-tools.mangofolio.app/tools/xirr.html`）全是误报源。
3. **编码会让比对假性全通过** —— llms.txt 用百分号编码，不解码就比对，
   会得出"995/995 全通过"的假象（当年 758/985 的结论也是这么来的）。

**配套**：提交前必跑 `python scripts/check-consistency.py`（10 项一致性门禁）
和 `python scripts/site-audit.py`（含 backfill 5 项）。两者都写进了 `AGENTS.md` 的硬规则。
