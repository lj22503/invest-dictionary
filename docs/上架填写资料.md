## 一句话介绍（40~50 字）

把投资的词翻译成人话。8 个场景技能覆盖查词、读新闻、拆决策、比选项、防坑提问，只帮理解与分辨，不给买卖建议。

## 详细介绍

买理财亏了不知道该看什么、销售说"保本保息"你不知道该问什么、新闻里"降准"两个字看了三年还是不懂——问题往往不在你，而在没人把这些词讲成人话。

Mangofolio 是一套围绕 1000+ 中文投资词条的理财科普方法论，拆成 8 个场景技能：

1. **投资翻译** · 金融词条说人话 — 你说一个词，它写成普通人 3 分钟能看懂、AI 和搜索引擎也能读懂的词条。
2. **新闻拆解** · 财经新闻说人话 — 把看不懂的财经新闻拆成核心概念，串成从"发生了什么"到"对你意味着什么"的因果链。
3. **概念串联** · 宏观事件说人话 — 把复杂宏观事件串成 6 屏网页，手机上能读完，可发给客户或家人。
4. **热点追踪** · 市场热点说人话 — 围绕今天一条热点，挑 3-5 个必须懂的热词逐个讲人话。
5. **财务决策** · 财务决策说人话 — "我要不要做这件事"，拆出取决于哪几个变量，每个变量配一个该看的词条。
6. **产品对比** · 产品对比说人话 — "A 还是 B"，按最坏情况、流动性、收益来源、适合谁四个维度并排比，给分界线。
7. **话术防坑** · 销售话术说人话 — 给一段销售话术，输出你该当面问的 3-5 个问题，附"为什么重要"和"对方可能的回避话术"。
8. **理财痛点** · 理财焦虑说人话 — 你说"我买的理财亏了"，它倒查出你真正该搞懂的几个概念，并告诉你先看哪一条。

> 8 个技能统一体例：**主名 + 一句"XX 说人话"**。市场列表展示主名，详情页副标与介绍用后半句。

**三条底线**：说人话（不用术语解释术语）；不给结论（只给"什么条件下倾向 A"）；不编词条（输出前核对包内词条索引，索引里没有的不凭空造）。

**适合谁**：刚接触理财、被产品说明和新闻术语卡住的人；需要给客户讲清楚概念的从业者。

**不适合谁**：想要"买什么、什么时候买"这类具体投资建议的人——这套工具刻意不做这件事。

## 两个上传入口：传什么、版本写在哪

平台是两条独立入口，包结构不同，不能互换：

| 入口 | 传哪个文件 | 版本写在哪 | 更新时的硬性要求 |
| :--- | :--- | :--- | :--- |
| 技能 | `dist/workbuddy/<技能名>.zip` × 8 | `SKILL.md` frontmatter 的 `version` | 大于线上该技能的当前版本 |
| 专家 | `dist/mango.zip` | `.codebuddy-plugin/plugin.json` 的 `version` | 大于线上该专家的当前版本 |

技能包结构里**没有** `plugin.json`（只有 `SKILL.md` + `references/scripts/templates`，见 https://open.workbuddy.cn/docs/skill ）。所以凡是报错里提到 `plugin.json` 的，说的都是专家包。

### 报错 `包内版本号 "1.0.0" 必须大于当前最新版本 "1.0.0"`

出现在**专家上传入口**，不是传错了包。意思是包内 `plugin.json` 与线上已发布版本都是 1.0.0，等于没升版；根因是 `expert/.codebuddy-plugin/plugin.json` 首发之后一直停在 1.0.0。

修复五步，顺序不能省：

```bash
# 1) 改 expert/.codebuddy-plugin/plugin.json 的 version（name / agentName 不能动）
python scripts/sync-expert.py      # 2) 元文件 + 8 个技能副本 → 本地专家目录；成功后会打印下面三条命令
python <expert-manager>/scripts/validate_expert.py <专家目录>   # 3) 校验
python <expert-manager>/scripts/register_expert.py <专家目录>   # 4) 注册
python <expert-manager>/scripts/package_expert.py <专家目录> dist  # 5) 打包
```

只要动过任一 `SKILL.md`，就必须重打 `mango.zip`：专家包里装的是技能副本，不重打则专家内仍是旧版技能。

传前自检：

```bash
unzip -p dist/mango.zip "mango/.codebuddy-plugin/plugin.json" | grep -m1 version          # 1.1.1
unzip -l dist/workbuddy/mangofolio-symptom-lookup.zip | grep -c plugin.json               # 必须 0
unzip -p dist/workbuddy/mangofolio-symptom-lookup.zip "*/SKILL.md" | grep ^version:       # 1.2.1
```

3. 销售说这个产品保本保息，我该当面问他什么

## 为什么是 Agent 型

一个 Mango 人格 + 8 个技能挂在它下面。用户的提问由 Mango 判断意图、路由到对应技能、最后压成一句能复述的话。八种能力是"技能"，不是一个"团队"——不需要多角色互相汇报，所以不走 Team 型。

## 三条不能碰的

- `plugin.json` 的 `name`、`agentName`、专家目录名、`agents/*.md` 文件名 = 唯一标识，改了专家会消失，只能重建
- `tags` 固定 3 个、`quickPrompts` 固定 3 个，第一条 `quickPrompt` 必须等于 `defaultInitPrompt`
- `displayDescription` 中文控制在 40-50 字，超了市场卡片会截断
