# 投资词典 · ICP 备案操作手册

> 适用站点：`dictionary.mangofolio.com`（当前托管 Vercel，静态页 1133 个 + 13 个 API）
> 网站性质：金融词条科普与检索，非经营性，无交易、无荐股、无付费
> 编制日期：2026-11-13 ｜ 版本 v1.0
> 说明：政策与各省执行尺度会有差异，本手册给出的是通行做法，最终以**接入商备案系统提示**与**属地通信管理局**答复为准。

## 0. 三十秒判断

| 问题 | 答案 |
| :--- | :--- |
| 能不能备 | 能 |
| 卡在哪 | ① 主体（个人身份基本过不了）② 站名含"投资" ③ 必须迁到大陆服务器 |
| 最短路径 | 办个体工商户 → 中性站名 → 签《不涉及前置审批承诺书》→ 迁大陆云 |
| 总周期 | 主体 3–7 天 + 迁移 3–5 天 + 备案 5–20 个工作日 |
| 备案本身花钱吗 | 不花。管局不收费用，成本只有服务器（约 60–100 元/月） |

**一句话**：ICP 备案本身是免费的行政手续，真正的工作量在"主体资格"和"服务器搬迁"这两件前置事情上。

## 2. 三条路线选择

| | 主体 | 站名要求 | 成功率 | 代价 | 适用 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **A** | 个人 | 必须去掉"投资/理财/金融"字样 | 偏低，各省差异大 | 零成本，可能白跑一轮 | 失业金不能中断、或不想办执照 |
| **B** | 个体工商户 | 可保留「投资词典」 | 明显更高 | 3–7 天，几乎零成本 | **推荐** |
| **C** | 不备案，迁香港节点 | 无限制 | — | 不用关站不限内容 | 微信内打开和 SEO 仍不如大陆站 |

### 走 B 之前必须先做的动作

注册个体工商户会被工商登记系统记录，部分地区的社保系统会据此判定"已重新就业"，**影响失业保险金**。各地执行不同：

- 广东、福建部分地区：登记为个体户经营者即视为重新就业，**停发**；
- 甘肃等地：凭营业执照可**一次性领取剩余期限**失业金，其他待遇停止；
- 海南等地：明确无身份限制，**不停发**。

**打电话给参保地 12333，就问这一句**：

> "我正在领失业保险金，如果注册个体工商户、不雇人、也不给自己缴社保，会不会停发？需不需要先办停领手续？"

得到答复再决定走 A 还是 B。**不要先注册再补问**——被数据比对出来属于不当领取，已发的要退回。

### 如果还在应届期内

注册个体户本身不影响应届生身份，判定关键是**有没有以个体户名义给自己缴职工社保**。只办执照、不缴社保、不签劳动合同，身份通常保留；一旦缴了职工社保，人社系统会标记"已就业"，身份可能失效。**注册后不要给自己缴社保。**

### 通用（两种主体都要）

- [ ] 网站负责人身份证正反面，四角完整、不反光
- [ ] 手机号：必须实名且与身份证一致，用于接收工信部核验短信
- [ ] 邮箱：能正常收发

- [ ] 《不涉及前置审批承诺书》：按**属地管局模板**签署，见第 6 节
- [ ] 人脸核验：接入商 App 或小程序完成（部分省份仍要求幕布拍照）

- [ ] 营业执照副本（清晰扫描件）

- [ ] 部分省份要求居住证、社保流水或本地户籍证明，提前确认

## 4. 完整流程（七步）

### 第 1 步：确定主体（3–7 天，A 路线跳过）

一网通办或当地市场监管窗口办理个体工商户。多地支持线上申请，经营场所可用住宅或网络经营场所。拿到执照后，**等 1–2 天**让工商数据同步到备案系统。

### 第 2 步：买大陆云服务器（当天）

| 项目 | 要求 |
| :--- | :--- |
| 地域 | **必须中国大陆**（华北/华东/华南均可）。香港、新加坡、日本一律不能备案 |
| 类型 | 轻量应用服务器即可，2 核 4G 起（要跑 Node 服务 + 1133 个静态页） |
| 时长 | **≥ 3 个月**，否则拿不到备案服务号 |
| 服务商 | 阿里云 / 腾讯云 / 华为云 / 天翼云 均可，选你域名所在的接入商最省事 |
| 备案服务号 | 购买后在控制台「备案」里申请，一个实例通常可申请 5 个 |

### 第 3 步：迁移站点（3–5 天，技术活，另见迁移清单）

必须顺序：**先把站跑通，再提交备案**。备案审核期间你不能再改网站内容。

- 静态部分：1133 个词条页 + 首页 + 词典页 → 服务器本地目录或对象存储
- 接口部分：13 个 `runtime: 'edge'` 接口 → 写一层 Node 适配（标准 `Request`/`Response`，Node 18+ 原生支持，业务逻辑不用改）
- `@vercel/kv`（订阅列表）→ 本机 SQLite 或云数据库
- 邮件推送 → 阿里云邮件推送 DirectMail

### 第 4 步：在接入商备案系统提交（1 小时）

入口：云厂商控制台 → 备案 → 新增备案。

填写要点见第 5 节。提交后**不要再改网站内容**，直到管局通过。

### 第 5 步：接入商初审（1–2 个工作日）

- 客服会电话核实：网站用途、是否本人办理、主体信息
- 可能要求补材料或重拍证件
- 通过后由接入商提交至省通信管理局

### 第 6 步：工信部短信核验（**24 小时内，超时作废**）

接入商提交后，负责人手机会收到 **12381** 发来的短信。

- 必须**本人**在 24 小时内点击链接、输入验证码完成核验
- 超时未核验，本次备案自动退回，要重新排队
- 这一步是整个流程里最容易翻车的地方，务必保持手机畅通

### 第 7 步：管局审核（1–20 个工作日）

- 多数省份 5–10 个工作日，个别省份更慢
- 审核期间可能电话回访，核实网站内容
- 通过后下发 **ICP 备案号**（形如「京ICP备2026XXXXXX号-1」）

### 第 8 步：备案通过后（当天 + 30 日内）

1. **切解析**：域名从 Vercel 切到大陆服务器 IP，配置好 HTTPS 证书
2. **页脚挂备案号**：全站页脚展示，且必须链接到 `https://beian.miit.gov.cn`
3. **公安联网备案**：网站开通后 **30 日内**，登录「全国互联网安全管理服务平台」提交，拿到公安备案号同样挂页脚
4. 检查所有页面（含 API 返回的 HTML）都带备案号

## 5. 填表最关键的三栏

这三栏决定能不能过，其余都是格式问题。

### 5.1 网站名称

**不能含**：投资、理财、金融、基金、证券、股票、资产管理、财富管理、交易所、网贷、支付。

候选（按通过率排序）：

1. **Mangofolio 金融知识库** —— 含"金融"两字，风险中等
2. **芒果树财经词条库** —— 最稳，"财经"不在敏感列表
3. **中文金融概念百科** —— 含"金融"，同样中等风险
4. **Mangofolio 学习站** —— 最保守，但与内容关联弱

> 走 A 路线（个人）建议直接用第 2 或第 4 个；走 B 路线（个体户）可以试第 1 个，被退回再降级。

### 5.2 网站服务内容

照这个句式写，把"不做什么"写清楚，比写"做什么"更重要：

> 提供中文金融与投资基础概念的词条解释、名词检索与知识科普服务。内容为公开资料的整理与通俗化解读，**不提供投资建议、不推荐具体产品、不涉及证券投资咨询、不提供交易撮合或资金归集、不销售任何金融产品、不收取任何费用**。

### 5.3 前置审批

- 选项选「**不涉及前置审批**」
- 上传《不涉及前置审批承诺书》（属地管局模板）
- 个别省份系统里叫「不涉及前置审批的说明」或「声明书」，以系统实际名称为准

## 6. 承诺书要点

承诺书的核心是**逐项排除**，写得越具体越容易过。建议在模板基础上补充：

- 网站名称与备案主体一致（或已说明关系）
- 明确列出不涉及的业务：**不涉及证券投资咨询、不涉及基金销售、不涉及贷款撮合、不涉及支付业务、不涉及虚拟货币相关业务**
- 不提供任何形式的荐股、择时、买卖点建议
- 不向任何持牌或非持牌机构导流并获取分成
- 不销售课程、会员、软件等任何付费产品
- 承诺单位/个人签字并按手印（单位需加盖公章，法人签字）
- 部分省份要求同时上传网站内容截图或业务说明，准备 3–5 张关键页面截图

**注意**：承诺书是法律文件。备案通过后如果网站真的开始做荐股、卖课、导流分成，会被认定为**虚假备案**——备案号注销、记入主体信用档案、一定期限内限制再次备案。

站上现有的"不构成投资建议"声明是**有利证据**，签承诺书前把相关页面截图留存。

## 7. 备案期间怎么不丢用户

首次备案的硬规定：**审核期间域名不能解析到大陆服务器，网站必须处于不可访问状态**。未备案域名指向境内 IP 会被云厂商在端口层直接阻断。

推荐做法：

| 对象 | 做法 |
| :--- | :--- |
| 主域名 `dictionary.mangofolio.com` | 挂一个极简"备案中"单页，不含任何文章、外链、联系方式 |
| 现有用户 | 临时走备用地址（`xxx.vercel.app` 或另备一个域名），在公众号/邮件里通知 |
| 搜索引擎 | 备案期间爬虫会看到"备案中"，可接受；通过后恢复，索引 1–2 周回来 |

真正的中断只有 DNS 切换那几十分钟。

> 也有站长在备案期间保持域名解析到境外服务器继续提供服务。这不推荐：部分省份管局审核时会访问域名核对内容，看到完整站点可能被判定"未备案先上线"而驳回。

## 8. 常见驳回原因与对策

| 驳回原因 | 对策 |
| :--- | :--- |
| 网站名称含金融敏感词 | 见 5.1，降级换名 |
| 主体与域名持有者不一致 | 先过户，等 3 天再提交 |
| 网站内容与备案信息不符 | 备案填的"服务内容"要和首页实际表述一致 |
| 备案期间网站可访问 | 主域挂"备案中"单页 |
| 短信核验超时（24 小时） | 手机保持畅通，收到即办 |
| 域名实名未生效 | 实名后等 3 个工作日 |
| 服务器不在大陆 / 时长不足 3 个月 | 重新购买 |
| 涉及前置审批未提供文件 | 签承诺书，或改内容表述 |
| 同主体备案数量超限 | 单个主体通常限 5 个网站 |
| 经营范围含"金融/投资/基金" | 办执照时避开这些字 |

## 9. 备案后的持续义务

1. **页脚备案号**：全站可见，链接 `https://beian.miit.gov.cn`
2. **公安联网备案**：开通后 30 日内完成
3. **信息变更**：主体、负责人、联系方式、网站内容有变，30 日内做变更备案
4. **内容抽查**：金融类属于重点抽查行业，保持"科普不荐股"的边界
5. **不要上线 AI 对话入口**：网站如果提供 AI 问答服务，可能触发「生成式人工智能服务备案」，是另一套手续。当前的词条检索、MCP 接口不算。

| 阶段 | 耗时 | 谁做 | 产出 |
