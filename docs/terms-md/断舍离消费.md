# 断舍离消费

> 少买不需要的、处理掉多余的、只留真正有用的——用整理物品的方式整理钱包的消费观。

## 1. 这是什么

断舍离的三个字拆开看：

- **断**：不买不需要的东西；
- **舍**：处理掉家里多余的东西；
- **离**：脱离对物品的执念。

它不是"穷人的活法"，而是**让每一分钱都花在真正提升生活质量的东西上**。核心不是少花钱，是"不再为拥有而买"。

## 2. 为什么重要

消费主义让人"为拥有而买"：换季买衣服、囤打折货、追新款数码，家里堆满一年用不了几次的东西，钱却没攒下。

断舍离的反击是：

- 房间空了，心情好了，找东西不焦虑；
- 买得少了，存款变多了，财务更从容；
- 每一件留下的东西都是"主动选择"，而不是"顺手买的"。

它和攒钱直接挂钩：**省下的钱会自动变成你的存款和底气**。

## 3. 怎么用

- 第一步：整理房间，把一年没碰过的东西挑出来——能卖的挂闲鱼，能捐的捐掉，能扔的扔掉；
- 第二步：购物车前加一个"冷静 72 小时"，想买的先放购物车，三天后还想买再说；
- 第三步：执行"一进一出"：买新的之前，先处理掉一件旧的同类物品；
- 第四步：记账复盘，月末看看哪些钱花在"将就""囤着没用"上，下月砍掉。

## 4. 常见坑 / 误区

- **断舍离≠清贫苦行**：健康、教育、体验这些该花的钱照花，它不是让你当苦行僧；
- **扔东西上瘾**：把"处理旧物"当消费替代品，买一堆收纳神器再断舍离，反而更浪费；
- **家人不支持就硬逼**：一个人强制扔家人的东西容易爆发家庭矛盾，要先沟通；
- **一刀切不买**：断舍离是"想清楚再买"，不是"什么都不买"，否则容易反弹报复性消费。
