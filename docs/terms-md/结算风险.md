# 结算风险

> 交易完成了，钱和货却没能同时到账——中间这段时间，就是结算风险的窗口。

## 1. 这是什么

**结算风险 = 交易双方在结算环节（钱货交割）中，一方履行了义务、另一方却没履行，造成的损失风险。**经典例子是"赫斯塔特风险"：一家银行在纽约时间上午付了美元，但等到欧洲时间下午才收到对方付的马克——这半天里，对方如果倒闭，钱就没了。

交割时间差、清算系统故障、一方违约，都会让"已经成交"的交易变成坏账。

> 一句话：结算风险是"钱货交接的半路上，对方突然不认账"。

## 2. 为什么重要

**结算风险平时被清算系统挡在门外，一旦发生就是连锁反应。**T+1 交易、中央清算、货银对付（DVP）制度，都是为了压缩结算风险。

- 股市交易：T+1 制度让"卖出后钱未到账"的时间窗口被制度化管理；
- 跨境支付：时差让结算风险放大，是国际银行最头疼的风险之一；
- 场外交易：私下约定"先付钱后交货"，没有清算所兜底，风险全在自己身上；
- 个人场景：二手交易先款后货、代购先付款，本质都在裸奔式承担结算风险。

## 3. 怎么用 / 怎么看

- **选正规渠道**：股票、基金走交易所/登记结算机构，有中央清算兜底；
- **坚持货银对付**：能走平台担保交易就走平台（如二手平台、支付宝担保），别私下先款；
- **看清交割时间**：跨境转账、大额汇款问清到账时间和失败退款规则；
- **个人交易**：大额二手买卖当面交付、留凭证，别被"先付款后发货"套路。

## 4. 常见坑 / 误区

- 坑1：私下"先款后货"。对方收钱不发货，你没有任何清算保障；
- 坑2：以为"成交了"= "钱到账了"。卖出、买入都只是成交，交割完成才算数；
- 坑3：跨境汇款只盯汇率，不看到账风险。中转行扣费、延迟、冻结都可能发生；
- 坑4：把结算风险和信用风险混为一谈。信用风险是对方"不想还"，结算风险是交割环节"没接上"。
