# 举牌

> 举牌是"有人愿意公开表态看好"，但看好不等于会一直拿。

## 1. 这是什么

**举牌，指投资者持有上市公司已发行股份达到 5% 时，必须依法公告，并在规定期限内不得继续买卖；此后持股比例每增加或减少 5%，以及每增减 1% 的通报要求，都需要披露。**

- **规则核心**：达到 5% → 规定时间内公告（即"举牌"），公告期间及公告后规定时间内不得继续买卖
- **谁在举牌**：产业资本、保险资金、公募与私募、外资，以及少数游资
- **两种动机**：战略投资（看好长期价值或寻求控制权）与财务投资（赚差价或做博弈）

> 一句话：举牌会把大资金的动作，放到明面上。

## 2. 为什么重要

- **它是公开信号**：举牌必须公告，等于把"谁在买、买了多少"摊开给你看
- **它改变筹码结构**：被举牌公司往往股权分散、市值适中，容易成为控制权争夺的对象
- **它带来短期催化**：市场常把举牌解读为价值认可，股价短期活跃度上升
- **它也可能只是财务投资**：赚了就走，和被收购完全是两件事

## 3. 怎么用 / 怎么看

- **先看举牌方是谁**：产业资本看协同，险资看长期现金流，私募与游资可能只管股价
- **看后续动作**：是否继续增持、是否提名董事、是否提交议案，才是真信号
- **看公司质地**：被盯上的公司通常现金充裕、负债低、股权分散，值得顺着线索研究
- **看成本与节奏**：举牌方的持仓成本区间，决定了它的容错空间
- **看规则约束**：举牌后继续买卖受限制，短期博弈空间比想象中小

## 4. 常见坑 / 误区

- **把举牌等同于重组**：多数举牌只是财务投资，不涉及控制权变化
- **忽视"被动举牌"**：指数基金、ETF 调仓也可能触发披露，不代表看好
- **不看后续减持**：举牌方在锁定期结束后可能减持，甚至"举牌即高点"
- **忽略股权分散的双刃剑**：容易被举牌，也容易被争夺，波动会加大
- **把举牌与要约收购混淆**：持股达到一定比例后的强制要约，是另一套规则
- **不更新规则细节**：披露比例与期限以现行证券法规和交易所规则为准
