# 消费信心指数

> 老百姓愿不愿意花钱、敢不敢花钱的心理温度计，由调查问卷统计出来的信心分数。

## 1. 这是什么

**消费信心指数 = 通过问卷询问居民对当前和未来收入、就业、消费意愿的主观判断，标准化成一个指数。**以 100 为荣枯线：高于 100 表示乐观，低于 100 表示悲观。中国通常看国家统计局发布的消费者信心指数，以及央行城镇储户问卷中的"消费意愿"分项。

场景：统计局抽样访问一万个家庭，问"你觉得未来半年收入会涨吗""现在适合买东西吗"，把回答折算成分数——这就是指数的来源。它测的不是钱包里有多少钱，而是心里敢不敢花。

> 一句话：信心高，有钱就花；信心低，有钱也存。

## 2. 为什么重要

信心会自我实现：**大家都不敢花钱，企业收入就差，于是裁员降薪，大家更不敢花钱——这是信心的负循环**；反过来，信心回升会带动消费、企业营收、股价一起转好。它因此被看作"预期的预期"，往往领先实际消费数据。

数字参考：消费者信心指数大幅下台阶的时期，社零增速往往同步走弱；指数回升但社零还没动时，常被视为"黎明前"信号。

对普通人的意义：信心指数持续下滑，说明多数人选择现金为王、防御消费——这时你也要谨慎加杠杆；回升则意味着消费类资产（消费股、零售、旅游）可能迎来修复。

> 一句话：它预告的不是现在花多少，而是未来敢不敢花。

## 3. 怎么用 / 怎么看

- **看方向，更看分项**：收入预期、就业预期、消费意愿三个分项，比总分更有信息量。
- **看连续性**：连续 2-3 个月回升才算趋势，单月反弹别激动。
- **与社零互验**：指数升 + 社零升 = 真回暖；指数升 + 社零不动 = 信心没变成行动。
- **与 CPI 对照**：信心低 + 物价低迷，往往是需求不足的信号。

> 一句话：信心指数是"方向盘"，社零是"车速表"，两个一起看。

## 4. 常见坑 / 误区

- **单月数据当趋势**：问卷型指数噪音大，至少看三个月。
- **指数高不代表人人有钱**：它是"相对乐观程度"，收入分化时整体指数可能失真。
- **受短期新闻扰动**：突发利好利空会让当月指数跳变，不代表基本面变了。
- **拿它做炒股择时**：它是慢变量，适合判断大方向，不适合精确择时。
