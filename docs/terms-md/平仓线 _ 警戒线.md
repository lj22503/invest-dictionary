# 平仓线 / 警戒线

> 融资买股后，账户担保比例跌破警戒线会被提醒、跌破平仓线会被强制卖出——这是杠杆交易的“生死线”。

## 1. 这是什么

融资交易中，券商按你账户的维持担保比例盯风险：担保比例 =（现金 + 证券市值）÷ 融资负债 × 100%。

- 警戒线：常见 150%，跌破会被券商提醒补钱；

- 平仓线：常见 130%，跌破且未及时补足，券商有权强制卖出你的持仓（强平）。

> 一句话：警戒线是“警告”，平仓线是“动刀”。

## 2. 为什么重要

算一笔账：本金 50 万融资 50 万，买 100 万市值的股票。股价跌 20%，市值剩 80 万，担保比例 = 80 ÷ 50 = 160%；再跌到 65 万，比例 = 130%，触发平仓线。

触发后券商不等你，系统自动卖出持仓，直到担保比例恢复——强平往往发生在最恐慌的底部区域，卖完就反弹是常见剧本，“倒在强平价”比普通套牢惨得多。

## 3. 怎么用 / 怎么看

- 盯比例，不盯股价：券商 APP 里有“维持担保比例”实时数值，把它当成第一仪表盘；

- 提前行动：跌破警戒线就主动补保证金或还融资，别拖到平仓线；

- 预留缓冲：把仓位控制在 60%-70% 以下，给波动留足安全垫；

- 记住补仓时效：补仓通常要求 T+1 内到账，别指望“明天再说”。

## 4. 常见坑 / 误区

- 以为券商先打电话再动手：强平是系统自动执行，通知往往和强平同时到达；

- 低估波动：连续跌停时想卖都卖不掉，强平也平不掉，可能进一步“穿仓”；

- 不看合约条款：不同券商警戒/平仓线不同（140%/130% 或 150%/130%），杠杆倍数越高线越紧；

- 忽视亏损放大：融资把亏损放大 2 倍，回本难度远大于 2 倍。
