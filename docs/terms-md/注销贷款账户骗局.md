# 注销贷款账户骗局

> 冒充网贷或银行客服，说你名下“贷款账户没注销会影响征信”，诱导你贷款转账到指定账户“清零额度”的诈骗。

## 1. 这是什么

骗子冒充知名平台客服，准确报出你的部分身份信息建立信任，说你多年前注册过贷款账户、不注销会影响征信；随后让你下载会议 App 共享屏幕，或去借呗、微粒贷等平台把额度借出来，转到所谓“银保监会清算账户”。钱一转走，人就失联。

> 一句话：让你“先贷款再注销账户”的，100% 是诈骗。

## 2. 为什么重要

这类骗局的高明之处在于：受害者往往没多少存款，骗子就诱导他去正规平台贷款再转账，等于让受害者亲手制造债务送给骗子。国家反诈中心已多次预警此类“注销贷款账户”诈骗。

> 一句话：骗子要的不是你账户里的钱，是你现贷出来的钱。

## 3. 怎么用 / 怎么看

- 第一步：挂断，自己去官方 App 或官方客服电话核实，不要用对方给的号码回拨。
- 第二步：记住常识——个人无法“注销”央行征信记录，贷款结清后账户状态自然更新，不影响征信。
- 第三步：凡是要求“共享屏幕”“转账到个人或所谓清算账户”“先贷款再注销”的，直接挂断并拨打 96110 反诈专线。

## 4. 常见坑 / 误区

- 误区一：对方能报出我的姓名身份证，一定是真的——你的信息可能来自泄露，不能当凭证。
- 误区二：“不注销会影响房贷”——征信系统没有“注销账户”的操作，结清即可，骗子在吓你。
- 误区三：已经转了第一笔，想再转一笔“凑齐解冻”——立即停止并报警，骗子只会越要越多。
