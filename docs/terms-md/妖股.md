# 妖股

> 妖股不是“涨得快的好公司”，是“资金堆出来的价格幻觉”。

## 1. 这是什么

**妖股，指短期内暴涨暴跌、走势严重脱离基本面的股票。**它的上涨靠资金和情绪，不靠业绩。

- **典型特征**：连续涨停、换手率极高、市值偏小、题材概念多、龙虎榜上全是游资席位

- **常见剧本**：消息引爆 → 连续涨停 → 游资接力 → 高位放巨量 → 一地鸡毛

- **和成长股的区别**：成长股有业绩兑现，妖股只有故事

> 一句话：妖股不是“涨得快的好公司”，是“资金堆出来的价格幻觉”。

## 2. 为什么重要

- **它是市场情绪的极端表达**：妖股活跃度高，往往出现在资金充裕、题材炒作火热的阶段

- **也是最容易亏钱的地方**：涨的时候一天 10%，跌的时候能连续跌停，跑都跑不掉

- **对市场的信号意义**：妖股频繁出现说明投机情绪高，往往也是该提高警惕的时候

- **对个人的意义**：看清它，才不会被“七天翻倍”的故事带节奏

记住一点：妖股的上涨是击鼓传花，音乐停下时，手里有货的人承担全部成本。

## 3. 怎么用 / 怎么看

- **看走势**：短期连续涨停、又找不到业绩支撑，基本可以判定是情绪驱动

- **看资金**：龙虎榜上出现多家游资营业部、机构几乎不参与，是典型的妖股特征

- **看换手**：换手率突然放大到 20% 以上，说明筹码在高位快速交换，风险急剧上升

- **看题材**：概念越宏大、越难验证，越容易成为炒作的壳子

- **处理方式**：如果一定要参与，只能是“小仓位 + 明确止损 + 不隔夜”，并且清楚这是博弈不是投资

> 一句话：妖股的行情，往往在“你想买的时候”就已经结束了。

## 4. 常见坑 / 误区

- **接最后一棒**：连续涨停时买不进，能买进的时候往往是开板放量，也就是资金开始出货

- **用基本面给它找理由**：先看到暴涨，再回头找逻辑，是最常见的自我说服

- **重仓博一把**：妖股波动是普通股票的数倍，一次判断失误可能亏掉大部分本金

- **死扛不割**：跌停板上没有流动性，很多人从小亏扛成巨亏

- **相信“还会再来一波”**：妖股退潮后往往长期阴跌，回到起涨点是常态
