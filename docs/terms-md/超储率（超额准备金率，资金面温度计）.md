# 超储率（超额准备金率，资金面温度计）

> 银行放在央行的“闲钱”占存款的比例，钱松钱紧一看便知。

## 1. 这是什么

银行吸收存款后，必须按一定比例把一部分钱存在央行，这叫法定存款准备金。在法定要求之上多存的钱，叫超额准备金——相当于银行放在央行“保险柜”里的闲钱。

超储率 = 超额准备金 ÷ 银行各项存款。它是衡量银行体系流动性松紧的核心指标：超储率越高，银行手里越宽裕；超储率越低，银行越“缺钱”。

> 一句话：超储率是银行体系的“钱包厚度”，钱多钱少一看便知。

## 2. 为什么重要

银行的钱多钱少，直接决定拆借市场利率（DR007、R007 等）的高低。超储率高，银行不缺钱，不愿意高价借钱，利率就低；超储率低，资金紧张，利率就被抬上去。

央行每个季度发布的《货币政策执行报告》都会披露超储率。季末考核、税期、春节前现金投放，都会让超储率阶段性下降——这些时候央行会通过降准、逆回购投放来“补血”。

- 季末、年末超储率通常走低：银行冲存款规模、缴准缴税，资金面易紧
- 降准后超储率跳升：释放的长期资金直接变成银行的超额准备金
- 超储率 + DR007 一起看：超储率低且 DR007 高 = 资金面确实紧

## 3. 怎么用 / 怎么看

- 看央行季报披露的超储率：一般 1%—2% 是常态，跌破 1% 说明偏紧，高于 2% 说明偏松
- 看 DR007 走势：它是超储率以外最灵敏的资金价格信号
- 看公开市场操作：央行连续净投放（逆回购）说明在给超储率“补水”
- 看同业存单发行利率：银行主动负债成本升高，往往是超储率偏低的信号

## 4. 常见坑 / 误区

- 坑 1：以为超储率越高越好——过高可能说明银行“钱多到贷不出去”，资金空转、经济活力不足
- 坑 2：拿不同口径比较——超额准备金分子口径（是否含备付金）各机构统计不一
- 坑 3：忽略季节性——春节前、季末超储率下降是常态，不等于货币政策收紧
- 坑 4：把超储率当短线交易指标——它是季度级慢变量，不是每日行情触发器
