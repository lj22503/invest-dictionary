# 溢缴款

> 溢缴款是还信用卡时多还的钱，存在卡里不产生利息，取出来还可能倒贴手续费。

## 1. 这是什么

<strong>溢缴款 = 信用卡还款金额超过应还金额的部分。</strong>比如这个月账单 3000 元，你转了 5000 元进去，多出来的 2000 元就是溢缴款。

这笔钱会留在你的信用卡账户里，抵扣下一期消费，但<strong>不产生任何利息</strong>——既不是存款，也不是理财，就是一笔“被银行免费借用”的钱。

> 一句话：溢缴款是还多了的钱，放着不涨息，取出来还要看银行脸色。

## 2. 为什么重要

溢缴款最坑的地方在“取出来”这一环：

- 取现收费：很多银行对溢缴款取现收 0.5%-1% 手续费，取 1 万就要付 50-100 元，纯白送；

- 转账收费：溢缴款转出到储蓄卡，同样可能按取现标准收费；

- 资金闲置：2000 元放着不涨息，一年下来连一杯奶茶都攒不出，还要占着信用卡额度；

- 错误还款：还错卡、重复还款是溢缴款最常见的来源，越乱越容易产生。

一句话：溢缴款不是“存钱”，是“多付钱+可能再被收钱”的双重失误。

## 3. 怎么用 / 怎么看

- 第一步：还款前先看账单——在手机银行确认“本期应还金额”，别凭记忆转账；

- 第二步：误存了先消费——溢缴款优先用于下一期消费抵扣，这是零成本消化方式；

- 第三步：要取回选对渠道——部分银行手机银行转出溢缴款免费（如一些股份行的 App 转账），取现前先查本行规则；

- 第四步：开通自动还款——绑储蓄卡自动还款，金额按账单来，从根上避免多还。

> 一句话：对溢缴款的最优策略是——别让它产生，产生了就花掉，非要取就找免费渠道。

## 4. 常见坑 / 误区

- 坑一：以为多还的钱有利息——信用卡不是储蓄卡，溢缴款不产生任何收益；

- 坑二：ATM 直接取溢缴款——ATM 取现按取现收费，溢缴款也照收，1 万块白扔 100 元；

- 坑三：还款日记错时间——以为还了，实际是溢缴款，下一期账单照样出利息；

- 坑四：还错卡——几张卡来回转账，溢缴款和欠款混在一起，越理越乱；

- 坑五：为了“凑整”多还——故意多还几十一百“好记”，积少成多都是被占用的资金。
