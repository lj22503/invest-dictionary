# 展期

> 展期 = 把到期日期往后推，债券、贷款、理财产品、期货合约都可能用到。

## 1. 这是什么

**债券展期**：发行人还不上钱，和持有人商量"晚点再还"，通常伴随利息调整或额外补偿；**贷款展期**：借款人和银行协商延期还款，利息照算；**期货/期权展期**：平掉近月合约、开远月合约，把持仓"搬"到下一个交割月。

## 2. 为什么重要

债券展期往往是违约的前奏或"软性违约"——本金没有按期兑付，就是信用事件，评级会下调、再融资会变难。对持有人来说，展期意味着**资金被占用 + 可能损失**；对个人来说，贷款展期用得好能救急，用得差会越陷越深。

## 3. 怎么用 / 怎么看

- 持有人拿到展期方案，先算三笔账：**额外补偿有多少、担保有没有变化、发行人现金流有没有改善**
- 拿方案和"直接违约清算"比一比，哪个回收率更高
- 个人贷款要展期，**主动联系银行**说明情况、提供证明，别拖到逾期
- 期货移仓要注意**价差成本**和保证金变化，不是免费操作

## 4. 常见坑 / 误区

- 以为"展期 = 没事了"，其实本金风险只是被推迟
- 接受展期方案不细看条款：利率、期限、担保、劣后顺序都要抠
- 把期货移仓当零成本，价差和保证金波动可能吃掉利润
