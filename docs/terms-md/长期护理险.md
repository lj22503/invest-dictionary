# 长期护理险

> 老了失能、卧床时帮你报销“请人照顾”费用的保险，国家试点版被称为社保“第六险”。


## 1. 这是什么

**长期护理险 = 当被保险人因年老、疾病、意外导致失能（吃饭、穿衣、洗澡、移动等不能自理）时，报销或补贴请人护理的费用。**国家从 2016 年起在多地试点，俗称社保“第六险”，很多城市职工医保参保人每年只需交几十元就能享受。它和医保的分工不同：**医保管“看病”，长护险管“照顾”**——住院费报销靠医保，出院后卧床没人管，就轮到长护险。> 一句话：医保管你“治病”，长护险管你“过日子”。

## 2. 为什么重要

失能是长寿时代最贵的风险之一：在大城市请一个住家护工，**每月 5000-8000 元**；进护理院，每月 4000-10000 元。一个人失能 5 年，护理支出可能 30-60 万，远超大多数人的存款。更扎心的是，**失能往往和长寿绑定**：活得越久，卧床的概率越大。等你真需要时再想买保险，已经买不到了。> 一句话：养老最贵的不是吃饭，是“被照顾”。

## 3. 怎么用 / 怎么看

- **社保版（第六险）**：缴费极低，报销或补贴有限，通常按月给定额（每月几百到两千元），覆盖基础保障，看所在城市是否试点。
- **商业版**：按保额赔付，可月领几千元，适合中年起配置，注意缴费年限和等待期（一般 90-180 天）。
- **领取条件**：需专业机构评估失能等级（轻、中、重度），达不到等级拿不到钱。> 一句话：社保版打底，商业版补差，别把“有医保”当成“有保障”。

## 4. 常见坑 / 误区

- **以为百万医疗险能报销护理**：医疗险报销医疗费，不报长期照护，这是最常见的误解。
- **失能评估严**：达不到等级标准，一分钱领不到。
- **等待期内失能不赔**：刚买完就出事，保险公司不退不赔。
- **只看“月领多少”不看杠杆**：保费贵不贵、通胀下够不够用，都要算。
- **社保版有城市差异**：异地居住、异地享受受限，先查本地政策。> 一句话：买之前先问清楚“什么情况下赔、赔多少、怎么评估”。
