# 世界银行

> 专门给发展中国家搞基建、扶贫、教育医疗提供"长期低息贷款"的全球银行，和 IMF 是"兄弟组织"。

## 1. 这是什么

世界银行（World Bank）与 IMF 同源于 1944 年的布雷顿森林会议，总部也在华盛顿。它由国际复兴开发银行（IBRD）等五个机构组成，主业是**开发贷款**：

- 借钱给成员国政府搞基建：修路、建电站、供水、农业；
- 投资教育、卫生、减贫项目；
- 贷款特点是：金额大、期限长（20~30 年）、利率比市场低。

中国早年是世界银行的大借款国，如今已成为主要出资国之一。

## 2. 为什么重要

世界银行是判断全球经济与新兴市场的重要参考源：

- 它每年发布的增长预测、营商环境报告，被各国政府和机构广泛引用；
- 它的项目贷款流向，能看出哪些国家、哪些行业正在获得国际资金；
- 理解"世界银行贷款"，能帮你读懂很多国际新闻——比如某国拿到世行贷款，往往是该国基建、营商环境改善的信号。

## 3. 怎么用（怎么看新闻）

- 看世行的增长预测：它对全球和各国的预测，是宏观研究的高频引用来源；
- 看贷款流向：世行重金投向哪个国家/领域，说明那里的长期发展机会被看好；
- 记住贷款性质：世行贷款是**要还的、低息的开发贷款**，不是免费援助；
- 区分世界银行与 IMF：世行管"长期发展"，IMF 管"货币急救"。

## 4. 常见坑 / 误区

- **世行不贷款给个人**：它只贷给成员国政府和机构，个人拿不到"世行贷款"；
- **别把它当"世界央行"**：它不发行货币、不调节利率，和央行是两回事；
- **世行报告也有滞后性**：报告反映的是过去和预期，别拿它当短线操作依据；
- **把世行和 IMF 混为一谈**：两者是独立机构、职能不同，新闻里也常一起出现，注意区分。
