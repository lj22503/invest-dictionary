# 规模效应 / 网络效应 / 转换成本

> 三种护城河：干得越大越便宜、用的人越多越值钱、换掉它要付出代价。

## 1. 这是什么

一家公司凭什么长期赚超额利润？靠壁垒，常见三种：

- **规模效应**：产量越大，单件成本越低——比如大型制造业摊薄固定成本；
- **网络效应**：用户越多，产品对每个用户越有价值——比如微信、电商平台；
- **转换成本**：用户一旦使用，换到别家要付出时间、金钱、学习代价——比如企业软件。

## 2. 为什么重要

有护城河的公司，才能长期保持高毛利、高 ROE，赚"别人抢不走"的钱；没有护城河的公司，利润再高也会被竞争抹平。

三种壁垒硬度不同：**网络效应和转换成本最难复制**——竞争对手花钱也抢不走存量用户；规模效应相对脆弱——对手靠更大的规模就能反超。

## 3. 怎么用 / 怎么看

- 问"它的成本会不会随规模下降"：会，且对手难复制，是规模效应；
- 问"用户多了对存量用户有没有好处"：有，是网络效应；
- 问"用户换掉它的代价大不大"：大，是转换成本；
- 三种叠加越多的公司，护城河越宽，越能长期持有。

## 4. 常见坑 / 误区

- 把"大"当规模效应：规模不经济的行业，越大越亏（如部分重资产服务业）；
- 把"用户多"当网络效应：单纯人多不等于互联价值，要看互动与依赖；
- 把"暂时不换"当转换成本：靠补贴锁客是假护城河，补贴一停用户就跑；
- 忽略技术变革：再深的护城河，也可能被新一代技术整体绕过。
