# 教育金保险 / 婚嫁金保险

> 为了孩子上大学、结婚专门存钱的人寿保险，主打“到点领钱”，防止钱被挪走。

## 1. 这是什么

**教育金保险 = 父母给孩子存的一笔“目标储蓄”**，每年交一笔钱，等孩子到约定年龄（高中、大学、深造阶段）分批领钱。婚嫁金保险原理一样，约定到婚龄一次性或分期给付。

它本质是`储蓄型人寿保险`：预定利率写进合同、到点领钱、附赠身故保障，投保人身故/全残通常还带豁免（后面保费免交）。

> 一句话：用合同把“孩子未来的钱”锁住，到点自动发。

## 2. 为什么重要

孩子18岁上大学、22岁深造，这笔钱**到时候必须有，一天都拖不得**——这就是教育的“时间刚性”。

教育金保险解决两件事：

- **防挪用**：钱在股票里可能亏、在卡里可能花掉，教育金用“到点领钱”把目标锁死；
- **长期锁定利率**：预定利率写进合同，未来利率再降也不影响已买保单；
- **豁免保障**：投保人不幸身故/全残，后续保费免交，孩子领钱不受影响。

## 3. 怎么用 / 怎么看

- **孩子越小越划算**：复利需要时间，0-3岁买比10岁买收益差一大截；
- **按目标倒推保费**：先估算大学四年需要多少，再倒推每年交多少；
- **优先选带豁免的产品**：投保人豁免是教育金的“灵魂条款”，没有豁免的教育金不完整；
- **先保障、后储蓄**：重疾、医疗、意外先配齐，再考虑教育金，顺序不能反。
> 一句话：教育金买的是“确定性”，不是“高收益”。

## 4. 常见坑 / 误区

- **以为收益很高**：教育金 IRR 通常只有2-3%左右，长期看跑不赢通胀，别拿它当暴利工具；
- **前期退保血亏**：前几年现金价值很低，退保可能只拿回一半；
- **婚嫁金“领的是自己的钱”**：多数产品到点领的是“已交保费+少量增值”，别被“领几十万”的演示骗了；
- **保障没配齐就买教育金**：孩子大病一场，教育金计划全乱，保障优先级更高。
