# 香港保险

> 跑到香港签的保单，多是美元计价，卖点在分红和全球配置。

## 1. 这是什么

香港保险 = 内地居民赴港投保的保单，常见重疾险和储蓄分红险（终身寿、年金），受香港法律与保监局监管，多数以**美元或港币**计价。

卖点通常是三点：**美元资产、分红演示收益看着高、以及部分海外医疗资源**。对做全球资产配置的人来说，它是一个可选项，而不是必选项。

## 2. 为什么重要

人民币资产占绝大多数的家庭，配一点美元保单，可以对冲单一币种风险。

储蓄分红险的长期演示 IRR 常见在 4%~5%，看着比内地同类产品高；但这份收益里，**非保证部分可能占七成以上**。

关键不是「能不能买」，而是你清不清楚：哪部分写进合同，哪部分靠保险公司投资表现。

## 3. 怎么用 / 怎么看

- **本人必须赴港签单**：在境内签的「地下保单」不受两地法律保护，出了问题两头都难维权。
- **区分保证与非保证**：打开利益演示表，把「保证现金价值」和「分红/非保证」分开看。
- **自己算一遍 IRR**：按乐观、中性、悲观三种分红情形分别算年化收益。
- **看清前期退保成本**：前几年退保可能只拿回三到五成本金。
- **算上汇率**：人民币升值时，美元保单折算成人民币的价值会缩水。
- **理赔流程更长**：资料需寄往香港，周期通常比内地长。

## 4. 常见坑 / 误区

- **只看演示收益**：演示表上的高数字多数来自非保证分红，历史实现率要单独查。
- **地下保单无效**：贪方便在境内签单，等于花钱买了一张不受保护的纸。
- **忽略汇率风险**：美元走弱时，账面收益可能被汇率吃掉。
- **高佣金导向的话术**：储蓄险佣金高，销售推荐时未必站在你的角度。
- **资金出境合规**：个人年度便利化购汇额度为 5 万美元，别踩外汇管制的红线。
