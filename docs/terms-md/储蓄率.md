# 储蓄率

> 收入里存下多少的比例，是家庭财务健康度最朴素的风向标。

## 1. 这是什么

储蓄率=储蓄额÷可支配收入，衡量你赚的钱里真正存下来的比例。

中国居民储蓄率长期处于全球较高水平（约30%左右），但不同家庭差异很大，年轻人普遍偏低。

对个人来说，储蓄率是最朴素的财务健康指标：存得下钱，说明收支有余量。

> 一句话：储蓄率就是你的"财务安全系数"。

## 2. 为什么重要

同样月入2万，储蓄率10%和30%，一年下来差出近5万本金，复利差距会随时间放大。

高储蓄率=更强的抗风险能力：失业、生病、意外时，有存款才有缓冲。

从宏观看，居民储蓄率影响消费和经济增长：储蓄率过高消费不足，过低则透支未来。

> 一句话：攒钱速度，一半看收入，一半看储蓄率。

## 3. 怎么用 / 怎么看

**第 1 步**：发薪日先转走储蓄（先存后花），而不是月底剩多少存多少。

**第 2 步**：设定目标储蓄率：稳健家庭建议20%-30%，存钱困难户从10%起步。

**第 3 步**：用记账确认储蓄率，每季度复盘一次，存不下就砍非必要支出。

**第 4 步**：储蓄资金放进能跑赢通胀的资产（定投、存款组合），别全放活期。

> 一句话：提高储蓄率最有效的方法，是发工资当天先"藏"起来。

## 4. 常见坑 / 误区

**坑 1**：把还房贷当储蓄——还贷是资产置换+利息支出，不是净储蓄，净资产没增加。

**坑 2**：只追求储蓄率数字，生活质量被压到极致，反而不可持续。

**坑 3**：存下的钱全放活期，年化0.2%，被2%+的通胀慢慢吃掉。

> 一句话：储蓄率要高，但更要"存得下、放对地方"。
