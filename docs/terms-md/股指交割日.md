# 股指交割日

> 股指期货、股指期权到期必须"算总账"的日子，一般是每月第三个星期五。

## 1. 这是什么

交割日 = 合约到期结算日。到期当天，持仓合约按当日结算价强制平仓、盈亏落袋，多空双方各回各家。A 股股指期货（IH/IF/IC/IM）的交割日是每月第三个星期五，股指期权同理。

交割分两种：现金交割（按结算价算盈亏、划转资金，股指期货/期权都是这种）和实物交割（真要交出商品，商品期货才有）。不用紧张，你不会真的收到一篮子股票。

## 2. 为什么重要

交割日附近市场波动经常放大，俗称"交割日效应"：持仓方要了结、套利资金要收敛基差，多空博弈在最后时刻集中爆发。

更实际的是：如果你持有期货或期权仓位，交割日就是你的"deadline"——要么主动平仓或移仓（展期），要么被动按结算价了结。现货与期货的价差（基差）在交割日会被强制拉平，这也是很多人用基差判断市场情绪的窗口。

## 3. 怎么用 / 怎么看

- 持有合约的人，提前 1—2 天决定：平仓离场，还是移仓到下一个月份，别拖到最后一天。
- 关注交割日收盘前的基差变化：贴水快速收敛，往往意味着空头力量在了结。
- 没有持仓的普通人，把它当作"波动可能放大"的日子，别在交割日当天追涨杀跌。
- 记住交易所日历：每月第三个星期五，一年 12 个交割日，提前圈出来。

## 4. 常见坑 / 误区

- 忘记自己的合约哪天到期：到期没处理，被强制平仓，成交价可能很差。
- 把"交割日魔咒"当玄学：波动放大是持仓了结的结果，不是"这天必跌"。
- 以为现金交割不疼：不交割实物，但按结算价算的盈亏照样真金白银进出。
- 用现货思维理解交割：现货跌了可以扛，期货到期必须了结，没有"扛一扛"的选项。
