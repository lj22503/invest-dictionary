# 转债下修 / 回售

> 股价跌多了，公司可以把转股价往下调（下修）；持有人也能按约定把转债卖回给公司（回售）——一降一退，是转债的"保命条款"。

## 1. 这是什么

**下修 = 公司把可转债的转股价格调低**（比如从 10 元降到 8 元），这样股价 7 元也能转股了，转债持有人能换到更多股票；**回售 = 股价长期低迷时，持有人有权按约定价格（通常是面值+利息）把转债卖回给公司**。两者都是写进转债条款的保护机制：下修帮公司避免还钱、推动转股，回售给持有人一个"止损出口"。转股价、回售触发条件，每只转债的募集说明书里都写得清清楚楚。> 一句话：股价不给力时，下修是公司"降价促销"，回售是持有人"退货退款"。

## 2. 为什么重要

下修和回售是决定转债"下有保底"的关键：正股暴跌时，回售条款把转债价格托在面值附近，这就是"债底"；而下修则是转债最大的"惊喜来源"——下修后转股价值跳升，转债价格常常应声大涨。历史上不少转债靠下修"起死回生"，从 90 元涨到 110 元以上。对双低转债策略、打新转债的投资者来说，会不会下修、什么时候下修，直接决定收益高低。> 一句话：会看下修，转债投资就赢了一半；懂回售，才知道什么时候"不玩了"。

## 3. 怎么用 / 怎么看

- **查条款**：打开转债募集说明书或行情软件里的"条款信息"，看回售触发价（通常转股价的 70%）、回售期、回售价。
- **盯下修信号**：触发下修条件（股价低于转股价的 80%~85% 持续一段时间）后，公司可能提议下修——公告"董事会提议向下修正转股价"就是信号。
- **下修博弈**：临近回售、大股东持有大量转债、公司缺钱时，下修概率更大；下修后关注"新转股价"是否接近市价。
- **回售决策**：触发回售时，要么在回售申报期卖出转债（通常不亏），要么转股或持有等待；别错过申报窗口。
- **警惕"下修到底" vs "下修不到位"**：下修到底（贴近当前股价）利好大；只修一点点则可能引发失望下跌。> 一句话：下修看公司意愿，回售看条款日历，两件事都要提前记。

## 4. 常见坑 / 误区

- **以为下修必然上涨**：下修要开股东大会通过，可能被否；修不到位还可能导致转债补跌。
- **忽略回售期**：回售有时间窗，错过申报就得多等一年，甚至被迫面对更差的价格。
- **把"强赎"和"回售"搞混**：强赎是公司"逼你转股"，回售是你"逼公司还钱"，方向完全相反，别弄反。
- **只盯转股价不看正股**：下修只是把门槛降低，正股基本面烂，转债照样可能继续阴跌。
- **在回售价附近无脑买**：回售价值≈债底，但正股持续恶化时，公司可能"赖着不下修"，转债仍会阴跌。> 一句话：条款是给你的保护，但别把保护当成稳赚。
