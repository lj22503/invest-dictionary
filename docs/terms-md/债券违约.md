# 债券违约

> 借钱的公司还不上钱了，持有人可能血本无归——违约正从「个案」走向「常态」，买债先看信用。

## 1. 这是什么

### 到期还不上钱

**债券违约 = 发债的公司到期付不出利息、或还不上本金。**债券不是「借条」那么简单，违约意味着你借出去的钱可能只拿回一部分，甚至血本无归。

2014 年「11 超日债」成为中国首只违约的公募债，此后违约从个案变成常态，每年都有几十上百只债券出险。

一句话：债券的「稳」，前提是借钱的人讲信用；信用一破，本金就悬了。

## 2. 为什么重要

### 为什么重要：打破刚兑后的常态

过去买债券等于「躺着收息」，因为发行人多是国企、城投，违约了也有人兜底（刚性兑付）。刚兑打破后，风险真实地落到投资者头上：违约债券通常只能按 20%~40% 的价格回收，损失惨重。

对市场来说，违约让信用债真正分化：好债更抢手、差债被抛弃，债券市场从「赌信仰」转向「看信用」。

一句话：违约不是黑天鹅，是利率市场化后的必然，买债必须先学会识别信用。

## 3. 怎么用 / 怎么看

### 怎么用：怎么回避违约风险

**买前看评级与财务**：主体评级、负债率、现金流、行业景气度都过一遍；**分散持仓**：单只债券或单一发行人别重仓，违约是「全损」级风险，分散才有活路；**警惕高收益债**：票面利率明显高于同评级均值的债，往往已经在定价「违约预期」；**盯紧预警信号**：评级下调、审计非标意见、大股东股权质押爆仓、再融资困难，都是违约前兆；**普通人不直接买债**：买债基更省心，但要查持仓券种，避开重仓「网红债」的基金。

## 4. 常见坑 / 误区

### 常见坑：以为国企不会违约

**以为国企/城投不会违约**：永煤、华晨都是国企，照样违约；城投信仰也在松动；**被高息吸引**：垃圾债的高票息，本质是市场给的「违约补偿」，你没研究能力就是送钱；**重仓单一券种**：一只债违约，可能吃掉你债券组合好几年的收益；**忽略条款风险**：回售、交叉违约等条款复杂，出险时才知道条款比利率重要。
