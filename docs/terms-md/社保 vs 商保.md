# 社保 vs 商保

> 社保是国家兜底的基础保障，商保是花自己钱买的补充保障。

## 1. 这是什么

社保（社会保险）是国家强制建立的基本保障：养老、医疗、失业、工伤、生育五险。商保（商业保险）是自愿购买的补充保障：医疗险、重疾险、寿险、年金险等。

简单类比：社保是“基础款”防护网，商保是“升级款”补丁。社保解决“有没有”的问题，商保解决“够不够”的问题。

两者不是替代关系，而是接力关系。

## 2. 为什么重要

社保的定位是“广覆盖、保基本”，这意味着它有很多管不到的地方：

- 医保有起付线、封顶线和报销比例：大病自费部分可能高达几十万
- 医保只报“目录内”费用：进口药、特效药、院外购药常需自费
- 养老金替代率下降：只靠社保养老，退休生活质量大概率打折

所以“有社保就够了”的认知，在大病和养老面前很脆弱。

## 3. 怎么用 / 怎么看

- 先保底：社保一定要交，别为省几百块断缴
- 再补漏：优先配百万医疗险（报销大病）、重疾险（弥补收入损失），预算够再加定期寿险
- 后养老：社保养老金打底，再用年金险/指数基金做第三支柱

配置顺序：先保障后理财，先大人后小孩。

## 4. 常见坑 / 误区

- 坑 1：有社保就不买商保。一场大病下来，自费部分可能掏空积蓄
- 坑 2：盲目买一堆重复的。医疗险买多份并不会多赔（报销型）
- 坑 3：为了“返本”买返还型重疾。不如“消费型+自己定投”组合划算
