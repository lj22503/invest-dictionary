# 股票代码 / 板块

> 股票代码 = 每只股票的"身份证号"（如 600519、300750）；板块 = 按上市地点、板块定位划分的股票群体（沪市主板、深市主板、创业板、科创板、北交所等）。

## 1. 这是什么

**股票代码是交易所给每只股票分配的编号**，A 股代码的数字段通常暗示所属板块和交易所。

关键点：

- **6 开头**：上海证券交易所（600 沪市主板、688 科创板、605 沪市主板次新段）；
- **0/3 开头**：深圳证券交易所（000 深市主板、002 中小板并入主板、300 创业板）；
- **8/4 开头**：北交所（8 开头为主，4 开头为老三板平移）；
- **板块差异**：不同板块的上市门槛、涨跌幅限制、投资者门槛完全不同。

> 一句话：股票代码 = 股票的身份证号，看一眼开头数字，大概就知道它混哪个圈子。

## 2. 为什么重要

**代码与板块决定了一只股票的交易规则和风险属性，是看盘的第一步：**

- **涨跌幅不同**：主板 10%、创业板/科创板 20%、北交所 30%、新股上市初期规则也不同；
- **门槛不同**：创业板/科创板/北交所都有资金门槛，主板没有；
- **代码段=市场记忆**：市场讨论"688 的票""300 的票"，代码就是圈层标签；
- **打新与退市规则不同**：各板块的发行、退市制度差异巨大，直接影响持有体验。

**真实场景**：新股民小美看到"688xxx"涨了 15% 很开心，以为买到了"10% 涨停的妖股"——其实科创板涨跌幅是 20%，她只是普通波动，虚惊一场。

## 3. 怎么用 / 怎么看

- 第一步：记规律——6 开头沪市、0/3 开头深市（3 是创业板）、8/4 开头北交所；
- 第二步：看板块规则——交易前确认该板块的涨跌幅、门槛、交易时间差异；
- 第三步：区分"代码段"与"题材"——代码只说明板块，不说明公司质地；
- 第四步：关注代码变更——股票改名/代码不变，退市摘牌代码会消失；
- 第五步：用代码快速定位——看盘软件输入代码直接调出，比搜名字快。

> 一句话：先认代码看板块，再谈买卖——交易规则不对齐，操作容易翻车。

## 4. 常见坑 / 误区

- **坑 1：按代码猜板块出错**：601/603/605 都是沪市主板，别只看"60"就以为是科创板；
- **坑 2：忘记创业板/科创板门槛**：没开通权限却想买 300/688 的票，下单直接被拒；
- **坑 3：混淆新股代码段**：主板新股 605、创业板新股 301，申购权限和规则都不同；
- **坑 4：把"板块"当"题材"**：板块是制度分类，题材是市场炒作标签，别混为一谈；
- **坑 5：以为代码永久不变**：股票退市、吸收合并后代码会注销，别按旧代码找新票。
