# 信用利差

> 同一期限的信用债比国债多出来的利息，是市场给「不还钱风险」的定价，也是债市情绪的体温计。

## 1. 这是什么

### 多出来的风险溢价

**信用利差 = 信用债的收益率 - 同期限国债的收益率。**国债几乎不会违约，信用债可能违约，那多出来的利息，就是市场给「不还钱风险」的定价。

举例：3 年期 AAA 企业债收益率 2.8%，同期国债 2.0%，信用利差就是 0.8 个百分点。

一句话：利差就是市场对「万一不还钱」收的保险费。

## 2. 为什么重要

### 为什么重要：债市情绪温度计

信用利差会随市场情绪波动：经济好、信心足时，利差收窄（投资者觉得风险小，愿意买）；经济差、风声紧时，利差走阔（投资者要求更高补偿）。

利差极端走阔，往往对应债市的恐慌底；利差压到历史低位，则说明「买债的钱太多」，风险补偿已经不足。

一句话：利差是债市的「体温计」，发烧还是发冷，一看便知。

## 3. 怎么用 / 怎么看

### 怎么用：怎么看信用利差

**看绝对水平**：利差处于历史 90% 分位以上，债市往往过度悲观，是配置窗口；30% 分位以下则偏贵；**看结构分化**：高等级利差低、低等级利差高的「信用分层」，反映的是风险偏好收缩；**配合资金面看**：流动性宽松时利差容易压缩，紧缩时利差容易走阔；**关注信用事件**：一起大违约，常导致同行业、同评级债券利差集体走阔。

## 4. 常见坑 / 误区

### 常见坑：只看收益率不看利差

**只看收益率不看利差**：6% 的票息看着诱人，但同期限利差已到历史极值，说明市场在定价违约；**利差走阔就抄底**：利差高可能是因为基本面真的在恶化，不是所有「便宜」都能捡；**利差低 ≠ 无风险**：利差收窄到低位，只说明风险补偿薄，不说明风险消失；**跨品种比口径**：不同评级、不同期限的利差不可直接对比，要比就比同口径。
