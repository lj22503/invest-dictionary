# 选股

> 选股 = 从几千只股票里挑出值得买的那个。方法不重要，重要的是你有一套自己说得清的理由。

## 1. 这是什么
选股就是回答一个问题：在这么多股票里，为什么选它？

常见的选股路子有两类：
- **看公司**：研究财报、行业、管理层，选"好公司"（基本面选股）。
- **看价格**：看图形、看趋势、看资金，选"好时机"（技术面选股）。

## 2. 为什么重要
买股票赚不赚钱，一半取决于选股，一半取决于买入价格和持有时间。

- 选错股，再好的买入点也可能被套；
- 选对股但买贵了，可能几年不涨；
- 选股最大的价值，是让你在下跌时拿得住——因为你清楚为什么买它。

## 3. 怎么用 / 怎么看
- 先看**好公司的门槛**：连续盈利、ROE 稳定在 15% 以上、现金流健康。
- 再看**价格是否合理**：用市盈率（PE）对比历史区间和同行，避免追高。
- 看**护城河**：这家公司的优势别人能否轻易复制？品牌、牌照、规模、成本都是护城河。
- 看**行业空间**：行业天花板高不高，公司是不是受益者。
- 自问三连：我为什么买它？它跌了我敢不敢加？我打算拿多久？

## 4. 常见坑 / 误区
- 只看涨得多就买：涨幅不代表价值，追高是套牢的第一步。
- 只看便宜就买：低市盈率可能是"价值陷阱"，公司基本面在恶化。
- 听消息选股：小道消息是最贵的选股方式，接盘概率极高。
- 不设卖出条件：只研究怎么买、不研究怎么卖，盈利会坐过山车。
