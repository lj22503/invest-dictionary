# 冠军魔咒

> 上一年业绩冠军的基金，第二年往往表现平庸甚至垫底——冠军是“后视镜”。

## 1. 这是什么（去年的冠军，今年的垫底）

冠军魔咒 = 上一年排名第一的基金，下一年大概率**跑输市场**。原因：冠军基往往重仓押注单一风格/行业（赌对了风口）；规模暴涨后策略容量不够；市场风格反转，押注失效。

一句话：冠军是过去式，买的是未来式。

## 2. 为什么重要（为什么重要：追冠军最容易亏钱）

普通人最爱“看排名买基金”，而排名恰恰是最容易亏钱的买法：**你买入时它已在高位**，规模已经膨胀，风格可能即将反转。

一句话：追冠军，就是拿真金白银为别人的过去买单。

## 3. 怎么用 / 怎么看（怎么看：冠军为什么难以持续）

不追“近 1 年冠军”，要看 **3-5 年长跑能力**；看基金是“风格型冠军”还是“均衡型冠军”——风格型冠军反转概率更高；看冠军时的规模是否暴涨；看基金经理的换手率、持仓集中度。

一句话：冠军看三年，别只看一年。

## 4. 常见坑 / 误区（常见坑：只看排名买基金）

看到“年度冠军”就冲进去——大概率接盘；以为“冠军基金经理=永远冠军”——风格会失效；只看收益不看回撤——冠军往往也是回撤王；追高“网红基金”（明星经理+高收益）——正是冠军魔咒的重灾区。

一句话：把冠军当参考，别把冠军当信仰。
