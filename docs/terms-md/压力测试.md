# 压力测试

> 先假设最坏情况真的来了，看看你的钱和心态扛不扛得住，这叫压力测试。

## 1. 这是什么
**压力测试 = 故意假设最坏的行情已经发生，然后看你的账户会亏多少、还能不能睡得着。**它不是预测"明天会跌"，而是回答一个问题：如果真跌成这样，我扛得住吗？

银行和基金公司天天在做这件事：监管会要求它们假设极端情景——比如利率瞬间飙升、股市一天跌 10%、大量客户同时取钱——然后看资本金够不够。

> 一句话：压力测试不是算命，是给财务状况做"地震演习"。

## 2. 为什么重要
个人做压力测试，核心不是算出精确亏损，而是提前知道两件事：**会亏多少，以及亏的时候你会不会被迫做傻事。**

- **仓位是否过高**：假设持仓再跌 30%，你的亏损绝对值是否超过心理承受线；
- **现金流是否紧张**：如果市场大跌叠加失业/急用钱，你是否必须割肉套现；
- **是否会恐慌操作**：很多人自认"长期持有"，真到跌 40% 那几天，最容易在最低点割肉——压力测试能提前暴露这个弱点。

## 3. 怎么用 / 怎么看
- **第一步：写最坏情景**——比如"股市再跌 30%、房价再跌 15%、收入中断 6 个月"，三个一起发生；
- **第二步：算损失**——把各类资产按该跌幅折算，算出总资产会缩水多少、是否触及你的红线（如本金亏 20%）；
- **第三步：看应对**——手头应急金能撑几个月？有没有必须卖出的资产？需要减仓或补保险，就在现在调整，而不是等大跌那天。

> 一句话：压力测试的产出不是数字，是"提前想好的应对方案"。

## 4. 常见坑 / 误区
- **假设太温柔**：只测"跌 5%"等于白测，真正吓人的是 30%、40% 级别的极端情景；
- **只测资产不测现金流**：很多人账户没事，但收入一断、房贷照付，就被迫割肉——收入中断才是最大的压力源；
- **把通过测试当保票**：测试通过只代表"按假设扛得住"，假设本身可能不完整，不代表真实风险消失。
