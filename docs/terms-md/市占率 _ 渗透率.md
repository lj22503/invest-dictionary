# 市占率 / 渗透率

> 市占率看谁强，渗透率看还有多少增量。

## 1. 这是什么

- **市占率**：一家公司在一个行业里卖出的份额，比如空调行业某品牌一年卖了全市场 30% 的量，市占率就是 30%。它回答"谁是老大"。
- **渗透率**：一个产品在目标人群里的普及程度，比如智能手机在全体用户中的渗透率 95%，说明几乎人手一台。它回答"市场还有多大"。

## 2. 为什么重要

两个率组合起来，能快速给一家公司定性：

- **渗透率低 + 市占率升**：行业还在长大，龙头在抢增量——最好的成长股画像；
- **渗透率高 + 市占率稳**：行业见顶，龙头守份额——赚的是格局钱，估值难给高；
- **渗透率高 + 市占率低**：红海市场，混战期，谁都没有定价权。

## 3. 怎么用 / 怎么看

- 查行业总规模：用公开行业报告或上市公司年报里的"市场空间"口径；
- 算渗透率：行业累计销量 / 目标人群总需求，判断行业处于早期、成长期还是成熟期；
- 算市占率：公司销量 / 行业总销量，结合近三年趋势看是升是降；
- 关注渗透率从 10% 到 50% 的过程：这是成长股最肥美的阶段。

## 4. 常见坑 / 误区

- 市占率口径混乱：不同报告对"行业"定义不同，对比前先统一口径；
- 把"渗透率低"当"一定有空间"——低渗透率也可能是因为产品本身没需求；
- 忽略行业天花板：渗透率接近 100% 后，市占率再高也难增长；
- 只看市占率不看盈利质量——靠烧钱补贴抢来的份额，未必值钱。
