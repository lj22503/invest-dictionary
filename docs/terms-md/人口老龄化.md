# 人口老龄化

> 人口老龄化=老年人占总人口比例持续上升的过程，是影响未来几十年经济和资产的慢变量。

## 1. 这是什么

国际上通常把65岁以上人口占比超过7%叫“老龄化社会”，超过14%叫“深度老龄化”。中国2021年65岁以上人口占比已超过14%，进入深度老龄化。

背后是两股力量：寿命变长让老年人口增加，出生率下降让年轻人变少，抚养比（每个劳动人口要养的老人孩子）持续上升。

> 一句话：人口结构像一艘大船，转向很慢，但一旦转过来，谁也挡不住。

## 2. 为什么重要

宏观层面：劳动力减少→潜在经济增速下移；养老、医疗支出上升→财政压力；储蓄和投资结构随之改变。

资产层面：老龄化通常伴随利率中枢下行（投资需求弱、储蓄多），利好长久期债券；消费结构从“住行”转向医疗、养老、保险。

个人层面：它直接提醒你——养老不能光靠社保，个人养老金、商业保险和长期投资要尽早安排。

> 一句话：老龄化改变的不只是老人数量，还有利率、消费和每个人未来的养老账本。

## 3. 怎么用 / 怎么看

- 第 1 步：看总量指标：出生率、65岁以上占比、抚养比，判断慢变量的方向。
- 第 2 步：看政策对冲：延迟退休、生育支持、个人养老金制度等落地节奏，能部分对冲老龄化冲击。
- 第 3 步：做个人规划：尽早搭建“养老三支柱”（社保+企业/职业年金+个人养老金/商业养老），用长钱做配置，让复利帮自己打工。

## 4. 常见坑 / 误区

- 坑 1：把“老龄化概念股”当万能药——老龄化是几十年的慢变量，短期炒作主题股往往是一阵风。
- 坑 2：以为老龄化=所有行业都完蛋——医疗、保险、养老产业反而长期受益，结构性机会一直在。
- 坑 3：到快退休才开始准备——养老靠的是时间和复利，越晚越被动。
