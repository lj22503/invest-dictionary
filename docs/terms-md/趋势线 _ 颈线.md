# 趋势线 / 颈线

> 趋势线连低点/高点指示方向，颈线连形态关键点提示拐点——技术分析的两条地基线。

## 1. 这是什么

**趋势线**：上升趋势里，连接两个以上依次抬高的低点画一条线；下降趋势里，连接两个以上依次降低的高点画一条线。它告诉你**当前走在什么方向**。

**颈线**：头肩顶、W 底、M 头等形态里的“分界线”——连接形态的两个关键极值点（如 W 底的两个反弹高点）。价格**突破或跌破颈线，才意味着形态确认**。

两者合起来就是一张地图：趋势线管方向，颈线管拐点。


## 2. 为什么重要

趋势线把“顺势而为”从口号变成可执行规则：**线上持股、跌破离场**。颈线把“反转确认”变成开关：**不破不算数**。

对普通人最实用的一点：判断一只基金或股票**还在不在上升趋势里**——很多人亏损是趋势早已破坏、还在死扛。趋势线一画，该不该继续持有，至少有了一个客观参照。


## 3. 怎么用 / 怎么看

- 画趋势线：至少两个点起步、第三个点验证有效，连线只经过低点（上升）或高点（下降）
- 看角度：角度越陡越脆弱，60° 以上的趋势线一根大阴线就可能击穿
- 画颈线：连接形态的两个关键极值点（如 W 底的两个高点），水平或略倾斜
- 认跌破：跌破颈线超过 3%，或连续 3 天收不回去，视为确认


## 4. 常见坑 / 误区

- 坑 1：随意画线——不同人画法不同，标准是“至少两点、第三点验证”，别在图上找自我安慰
- 坑 2：把假突破当真破位/真突破——看量能配合，无量破位多是洗盘
- 坑 3：只会事后画线——图上完美、事前模糊，要养成“先画后走”的习惯
- 坑 4：用技术线否定基本面——技术位失效要认错，别和基本面硬拗
