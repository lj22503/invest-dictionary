# 基建投资

> 修桥铺路、建地铁、搞新基建花的钱——基建投资是政府稳经济的"压舱石"。

## 1. 这是什么

基建投资是固定资产投资中投向基础设施的部分，包括交通（公路、铁路、机场）、水利、能源、市政（供水、燃气）以及 5G、数据中心等新基建。

它主要由政府主导，资金来自财政拨款、专项债、政策性金融工具等。经济下行压力大时，基建往往是第一个"发力"的稳增长抓手。

## 2. 为什么重要

- 基建是逆周期调节的核心工具：经济偏弱时加大投入，见效快、带动产业链广；
- 专项债的主要投向就是基建，发债节奏直接反映基建力度；
- 基建链涉及钢铁、水泥、工程机械、建材等板块，是投资机会的重要线索。

## 3. 怎么用 / 怎么看

- 跟踪专项债：发行进度快，基建项目就有资金弹药；
- 看重大项目开工：各省重大项目清单、开工率是先行信号；
- 看高频实物量：挖掘机销量、水泥出货量、螺纹钢表观消费量；
- 区分新旧基建：传统基建看"铁公基"，新基建看 5G、算力、充电桩。

## 4. 常见坑 / 误区

- 把"新基建"和传统基建混为一谈：资金渠道、受益板块完全不同；
- 只看计划不看落地：项目入库不等于开工，开工不等于形成实物量；
- 忽视项目收益率约束：地方债务压力大时，缺收益的项目可能放缓。
