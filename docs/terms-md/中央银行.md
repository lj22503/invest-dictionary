# 中央银行

> 管钱的“总行”：不办个人业务，专管货币发行、利率、银行体系和金融稳定。

## 1. 这是什么

央行是国家的最高金融管理机构：发行货币、制定货币政策、监管银行、维护金融稳定。
中国是中国人民银行，美国是美联储（Fed），欧洲是欧洲央行（ECB）。
它不对个人办业务——你存钱的银行才是商业银行。

## 2. 为什么重要

降准降息 → 存款利息、房贷利率、理财收益随之变化。
公开市场操作 → 市场流动性 → 股市债市涨跌。
汇率干预 → 出国消费、海淘成本变化。

## 3. 怎么用 / 怎么看

- **看货币政策报告**：每季度发布，讲未来政策方向
- **看 LPR 报价**：每月 20 日左右发布，直接影响你的房贷
- **看降准降息公告**：判断宽松还是收紧

## 4. 常见坑 / 误区

坑 1：把央行和商业银行混为一谈。办业务找商业银行，央行不管个人开户。
坑 2：以为央行会直接给个人发钱。中国货币政策是间接调控。
坑 3：忽视央行独立性。美联储相对独立于政府，货币政策不完全听命于行政。
