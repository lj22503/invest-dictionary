# 个税汇算清缴

> 个税汇算清缴=每年3-6月把上一年预缴个税全年对账一次，多退少补，多数人还能退税。

## 1. 这是什么

个税汇算清缴=把去年12个月预缴的个税加总，再按全年真实收入、扣除项重新算一遍“应缴税额”，对比后多退少补。

平时发工资是“累计预扣、边发边扣”，没有完整考虑年终奖、劳务收入、多处收入、漏填的专项附加扣除，所以需要年度总清算。

打个比方：像水费抄表——平时按预估量交（预缴），年底抄一次实际表（汇算），用多了补、用少了退。

> 一句话：汇算清缴=你与国家的一年一度对账日。


## 2. 为什么重要

多数人会退税：漏填专项附加扣除、年中换工作（两边都扣了起征点导致预缴偏多）、有劳务报酬未合并计税的人，汇算时都能退一笔。

也有人要补税：多处拿工资、副业收入高、年终奖计税方式选错，全年合并后应纳税额会超过已预缴。

办理期限是每年3月1日到6月30日，退税申请逾期不办就等于放弃这笔钱。

> 一句话：退税是国家发的上年度红包，别让它过期。


## 3. 怎么用 / 怎么看

第1步：3-6月打开“个人所得税”App，首页点“综合所得年度汇算”。

第2步：核对收入与扣除：看全年收入是否正确、专项附加扣除有没有漏填，漏了先补填再计算。

第3步：年终奖计税二选一：在“奖金计税方式”里分别试“单独计税”和“并入综合所得”，系统会提示哪个更省，选更省的提交。

第4步：绑定银行卡提交：退税一般1-2周到账。

第5步：需补税超过400元的按时缴纳，避免滞纳金。


## 4. 常见坑 / 误区

坑1：一看“要补税”就不办：补税超400元逾期不缴，每日按万分之五加收滞纳金，还影响纳税信用。

坑2：年终奖直接默认“单独计税”：有人并入综合所得反而更省，务必两个选项都点一遍看差额。

坑3：轻信“退税代办”：汇算完全可以在官方App免费自办，所谓“专业代办”多是骗信息、收手续费，甚至借机虚报退税实施诈骗。

> 一句话：汇算的坑大多不在算法，而在“偷懒”和“贪心”。
