# 流动性风险

> 你需要用钱时，钱拿不出来或只能贱卖的风险

## 1. 这是什么

**流动性风险** = 资产无法在需要时**以合理价格快速变现**的风险。

简单说：钱被"锁住"了——定期存款提前取要损失利息、房子急卖要降价、基金赎回要等好几天、长期理财锁定期内根本取不出来。

## 2. 为什么重要

- 很多人把全部积蓄砸进房子、长期理财、锁定期产品，**急用钱时一分钱拿不出来**。
- 被迫贱卖资产（割肉股票、降价卖房）或借高息网贷，一次流动性危机能吃掉几年收益。
- 流动性管理是家庭财务的"安全气囊"，比收益率更重要。

## 3. 怎么用 / 怎么看

**三步管好流动性：**

1. **留应急金**：3-6 个月生活费的活期/货币基金，随时可取，这部分坚决不动。
2. **资产分层**：按"随时可取 → 短期（1年内）→ 长期（3年+）"分层配置，急用的钱不投长期。
3. **大额支出提前规划**：买房、结婚、教育等大额用钱提前 1-2 年安排，避免临时变卖资产。

**检查清单**：你的资产里，能 1 天内到账的占比多少？3 天内呢？低于 20% 就要警惕。

## 4. 常见坑 / 误区

**坑 1：全部身家买房/锁定期理财** — 房和锁定期产品流动性最差，急用钱时只能贱卖或违约。

**坑 2：把应急金投进长期产品** — 应急金的核心是"随时能取"，收益是次要的，别本末倒置。

**坑 3：忽略赎回限制** — 基金 T+1/T+2 到账、私募半年锁定期、保险前几年退保巨亏，都是流动性陷阱。

**坑 4：市场暴跌时被迫割肉** — 满仓股票又急需现金，只能在低点卖出，双重损失。
