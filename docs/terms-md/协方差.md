# 协方差

> 协方差=衡量两只资产“会不会一起涨跌”的数字：正数同向走，负数反向走，接近 0 各走各的。

## 1. 这是什么

协方差，简单说就是**两只资产联动关系的数学记账**。

拿股票 A 和股票 B 举例：当 A 涨时 B 往往也涨，A 跌时 B 往往也跌——它们同向波动，协方差为正；A 涨 B 跌、A 跌 B 涨——反向波动，协方差为负；两人基本没关系——协方差接近 0。

它是由“每只资产偏离自己平均值的程度相乘再平均”算出来的，方向（正/负）比数值更容易理解。

> 一句话：协方差回答的是“这两只资产，是队友还是对手还是路人”。

## 2. 为什么重要

分散化的数学基础就是协方差：把协方差低（最好是负）的资产放一起，组合波动会被互相抵消，整体比单只更稳。

我们常用的**相关性系数**，就是把协方差“归一化”到 -1 到 1 之间，方便比较——协方差是原料，相关系数是成品。

理解了它，你才明白“鸡蛋别放一个篮子”不是玄学，而是数学：篮子之间关联越低，越安全。

## 3. 怎么用

**第 1 步**：拿资产的历史收益率，算两两协方差（或直接看相关性矩阵）。

**第 2 步**：挑协方差小或为负的资产搭配，比如股票+债券、国内+海外、成长+价值。

**第 3 步**：比较资产时用**相关系数**（-1~1），别直接比协方差数值——它受价格单位和规模影响，不同资产间不可比。

**第 4 步**：定期重算：资产间的相关性不是永恒不变的，危机时往往一起跌（相关性趋近 1）。

## 4. 常见坑

**坑 1**：以为“负相关=稳赚”，两只反向资产在系统性下跌时照样一起跌。

**坑 2**：直接比较不同资产的协方差数值，单位不同根本没意义。

**坑 3**：用历史协方差预测未来——市场结构变了，过去的联动关系会失效。

**坑 4**：只看到协方差“接近 0”就以为安全，忽略了极端尾部事件（低相关也会同时暴涨暴跌）。
