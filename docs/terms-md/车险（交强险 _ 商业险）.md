# 车险（交强险 / 商业险）

> 交强险是法律强制、赔别人的；商业险是自愿买、赔自己和别人的，搭配好才不花冤枉钱。

## 1. 这是什么
交强险 = 法律强制购买，赔对方：死亡伤残 18 万、医疗 1.8 万、财产 2000 元（有责时）。商业险 = 自愿购买，三大主险：三者险（赔别人）、车损险（赔自己车）、车上人员责任险（赔自己车上的人）。

## 2. 为什么重要
只买交强险，撞伤别人 18 万额度根本不够——大城市人伤动辄几十万，剩下的全要自己掏。不买车损险，自己车撞了全自费。三者险保额建议 200 万+，一年只贵几百块，杠杆极高。

## 3. 怎么用 / 怎么看
- 交强险必买，不买不能上路
- 三者险 200 万起，是性价比最高的保障
- 车损险：新车、贵车必买；车龄老、车价低可视情况取舍
- 附加险按需：医保外医疗责任险（人伤用药）、驾乘意外险
- 新能源车险更贵，比价 2-3 家再下单

## 4. 常见坑 / 误区
- 以为"全险"什么都赔：涉水、自燃、玻璃单独破碎都有附加条件
- 小剐蹭频繁出险：出险一次明年保费上涨，几百块的小伤自费更划算
- 脱保：保费恢复原价，还影响续保优惠
- 借车/代驾出险，理赔条件更复杂，别随便把车借出去
