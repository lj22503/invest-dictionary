# 大盘股 / 小盘股

> 大盘股拼的是“稳”，小盘股拼的是“弹性”。

## 1. 这是什么

**大盘股和小盘股，是按公司市值（总市值或流通市值）划分的两类股票。**

- **大盘股**：通常是行业龙头，市值千亿以上，比如银行、白酒、能源、通信里的巨无霸

- **小盘股**：市值几十亿到一两百亿，多为细分行业公司或成长型企业

- **中间还有中盘股**：界限没有统一标准，常用参照是沪深 300（偏大盘）和中证 1000（偏小盘）

> 一句话：大盘股拼的是“稳”，小盘股拼的是“弹性”。

## 2. 为什么重要

- **涨跌节奏不同**：大盘股波动小、分红稳；小盘股弹性大、对题材敏感

- **资金偏好会切换**：市场活跃、资金充裕时小盘更容易跑赢；避险情绪浓时资金抱团大盘

- **影响你的组合**：持仓全在一边，等于把一个风格赌注押满，波动会非常集中

- **影响操作方式**：大盘股适合长期持有和定投，小盘股更适合有研究能力的人

风格切换是 A 股最常见的亏钱原因之一——不是选错了公司，是站错了风格。

## 3. 怎么用 / 怎么看

- **先判断当前风格**：看沪深 300 与中证 1000 的相对强弱，谁在跑赢，市场就在哪个风格上

- **大盘股怎么看**：看盈利稳定性、分红率、估值分位，赚的是确定性的钱

- **小盘股怎么看**：看成长性、行业空间、股东结构，赚的是预期差的钱，容错率低

- **组合两头配**：大盘股打底求稳，小盘股增强求弹性，别全押一边

- **用指数代替选股**：看好大盘用沪深 300 类指数，看好小盘用中证 500 / 中证 1000 类指数

> 一句话：风格判断错了，选股再努力也可能白搭。

## 4. 常见坑 / 误区

- **以为小盘一定涨得快**：小盘股涨得快，跌得也快，流动性和财务风险都更高

- **把大盘股当“没机会”**：低估值高分红的大盘股，长期回报未必输给小盘

- **忽略流动性差异**：小盘股在极端行情里可能直接被“闷杀”，想卖卖不掉

- **用市值代替质量**：市值小不等于成长性好，也可能只是因为公司不行

- **风格来回追**：看到哪边涨就换到哪边，结果两边的高点都赶上
