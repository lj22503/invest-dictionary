# 市值配售

> 打新不再先交钱再摇号，而是按你手里的股票市值分配额度——想打新，先持有市值。

## 1. 这是什么

**市值配售 = 申购新股时，按投资者持有的股票市值分配申购额度的制度。**过去打新需要预先冻结资金，现在改成先持有市值、再按市值配额度，中签后才缴款。

**核心规则（大意，具体以交易所现行规定为准）**：

- 沪市、深市的市值**分开计算**，各算各的额度；
- 通常按申购前特定交易日往前若干天的**日均市值**计算，不足规定金额的部分不计入；
- 有了额度也不能超额度申购，超出部分属于无效申购；
- 中签后才缴款，中签不缴款会被记录，多次弃购可能被限制申购。

> 一句话：市值配售把打新从资金游戏改成了持仓游戏。

## 2. 为什么重要

- **门槛是市值，不是现金**：想打沪市新股，就得先有沪市股票，还得按市场分别配置；
- **持仓本身有风险**：为了打新而持有的股票，下跌可能吃掉远多于打新收益的金额；
- **额度与市值挂钩**：市值太分散或不足，额度就少，中签概率随之下降；
- **规则与市场一起变**：注册制之后新股定价更市场化，中签不再等于稳赚。

## 3. 怎么用 / 怎么看

- **先分市场看市值**：沪市、深市（含创业板、科创板对应规则）分别计算，别混在一起算；
- **再看时间窗口**：额度按前若干个交易日的日均市值估算，临时买入往往来不及；
- **顶格但不越线**：按系统提示的额度申购，超过额度即无效；
- **中签必缴款**：账户留足资金，弃购次数多了会影响后续申购资格；
- **破发会真亏**：先看公司基本面，再决定是否参与申购。

> 一句话：市值是门票，申购是动作，缴款才是承诺。

## 4. 常见坑 / 误区

- **本末倒置**：为了打新去买不熟悉的股票，是拿打新的一点收益去承担持仓的大风险；
- **忽略分市场额度**：只买一个市场的股票，另一个市场的新股根本没法申购；
- **算错市值口径**：以为当天买入就算市值，实际按前若干交易日日均市值计算；
- **中签不缴款**：账户余额不足导致弃购，记录累积后可能被暂停申购；
- **把打新当无风险收益**：注册制下破发常见，靠上市必涨的老经验容易吃亏。
