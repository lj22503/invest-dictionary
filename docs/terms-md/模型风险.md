# 模型风险

> 用公式、算法、AI 做决策，公式本身错了或数据喂错了，跟着亏钱。

## 1. 这是什么

**模型风险 = 因为模型（数学公式、算法、AI）本身设计有缺陷、用错了场景、或输入数据有问题，导致决策错误并造成损失的风险。**模型不是"客观真理"，它是对现实的近似，天生可能出错。

量化基金、银行风控、保险公司定价、推荐算法，全都依赖模型。模型错了，系统会"很自信地犯大错"。

> 一句话：模型风险不是"算错了"，是"用错公式算对了一笔亏钱账"。

## 2. 为什么重要

**模型越强大，模型风险的破坏力越大。**AI 和量化时代，模型在毫秒级自动执行交易，一个错误假设可能瞬间放大成巨额亏损。

- 量化基金：回测漂亮的策略，实盘失效——过拟合是模型风险的高发区；
- 银行风控：模型误判让你被拒贷，或误判让坏账漏过；
- 保险定价：定价模型低估赔付，保费定低了，亏损要很多年才能暴露；
- 个人使用：用 IRR、估值公式做投资决策，公式用错场景，结论全偏。

## 3. 怎么用 / 怎么看

- **把模型当助手，不当上帝**：任何模型结果都要追问"假设是什么、输入数据哪来的"；
- **看回测更要看实盘**：样本外测试、压力测试通过，才说明模型有一定鲁棒性；
- **关注模型失效预警**：市场结构变化（新规则、新参与者）会让老模型集体失灵；
- **个人应用**：用现成公式时先搞清楚适用条件，别拿不适用场景硬套。

## 4. 常见坑 / 误区

- 坑1：迷信"AI 预测"。AI 也会过拟合，回测跑赢不代表未来跑赢；
- 坑2：只报喜不报忧。很多模型在极端行情下才暴露缺陷，日常看不出；
- 坑3：数据脏了还硬跑。输入数据有偏，输出再漂亮也是错的（垃圾进，垃圾出）；
- 坑4：以为模型风险只是量化机构的事。个人用估值模型、自动化定投也一样会踩。
