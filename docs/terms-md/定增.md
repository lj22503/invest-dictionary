# 定增

> 定增是上市公司向特定投资者打折发行新股、锁定一段时间才能卖，本质是“定向批发股票换钱”。

## 1. 这是什么

定向增发（定增）是上市公司最重要的再融资方式之一：
公司缺钱搞项目、扩产能、还债、收购，就向少数机构和大股东发行新股。发行价通常比市价打个 8-9 折，认购后要锁定 6-18 个月才能卖。

> 一句话：定增=公司打折批发股票换钱，投资者赌它以后能涨回来。

## 2. 为什么重要

定增对股价是双刃剑：
短期看，新增股票会摊薄每股收益，是压力；但定增价和参与方透露了机构的真实判断——知名机构、大股东真金白银认购，说明他们看好；若募资投向靠谱，定增反而是未来增长的起点。

## 3. 怎么用 / 怎么看

看定增就盯三件事：

- **发行价 vs 市价**：折价越高越像“便宜卖”，但也越像公司急等钱用；
- **锁定期与解禁日**：解禁前 1-2 个月通常有抛压，提前做好心理准备；
- **认购人是谁**：大股东、知名机构认购=信心；关联方、凑数资金认购=多留个心眼。

> 一句话：定增价附近往往形成支撑或套牢盘，量价验证后再动手。

## 4. 常见坑 / 误区

四个典型误区：

- **以为定增价=地板价**：跌破定增价很常见，定增参与者也在浮亏；
- **以为解禁必跌**：解禁是压力不是必然，还得看减持意愿和公司基本面；
- **把“定增获批”当利好猛炒**：利好出尽经常变利空，消息落地那天往往就是高点；
- **忽略摊薄**：定增后股本变大，同样的利润每股分到更少。
