# 心理账户

> 心理账户=大脑把钱按来路和用途贴标签、分抽屉存放，导致同样一笔钱被区别对待。

## 1. 这是什么

心理账户指人心里装着多个“隐形钱包”：工资、奖金、红包、理财收益被放进不同抽屉，花钱时也分“生活必需、人情往来、娱乐、投资”等账户，每个账户的消费标准都不一样。

最典型的例子：辛苦赚的1000块工资不舍得花，路边捡到或中奖来的1000块转眼就请客花掉——钱明明一样，却被贴了不同标签。

这个概念来自诺贝尔经济学奖得主塞勒，人人都有，只是程度不同。

> 一句话：钱没有贵贱，但大脑给每笔钱都贴了标签。


## 2. 为什么重要

心理账户解释了“为什么越省越穷”：把大额收入当“意外之财”随手挥霍，把投资盈利当“白来的钱”继续加仓，都是账户分错类。

亏钱场景：股票浮盈5000元时觉得是“赚来的”，亏起来不心疼，越拿越久不设止盈，最后盈利变亏损。

它也解释了为什么有人舍不得买保险、却舍得买彩票：医疗和教育被划入“能省则省”，娱乐却被划入“该花就花”。

> 一句话：管钱先管分类，分错类就管不住。


## 3. 怎么用 / 怎么看

第1步：把全部资产当成一个账户，看整体收益率，不纠结单笔盈亏。

第2步：给大钱立规矩：年终奖、奖金到账先划走20%-50%进储蓄/定投账户，再谈消费。

第3步：投资收益与本金一视同仁：浮盈也是钱，到了止盈位就该卖。

第4步：反向利用心理账户：给储蓄账户起名“自由基金”，给娱乐消费设小额专户，花完即止。

> 一句话：好习惯，是给每笔钱安排好对的抽屉。


## 4. 常见坑 / 误区

坑1：用“这是意外之财”麻痹自己：中奖、退税、红包最容易进入“挥霍账户”，先存后花是解药。

坑2：把浮盈当“免费的钱”：盈利加仓一把亏光，等于把赢家账户直接并给了输家。

坑3：被话术牵着走：“每天只需一杯奶茶钱”“这是给努力的你的奖励”，都是想让你把该存的钱划进消费账户。

> 一句话：看到“奖励”“白赚”这类词，先捂紧钱包。
