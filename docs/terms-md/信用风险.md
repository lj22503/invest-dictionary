# 信用风险

> 信用风险 = 借钱的人或机构还不上钱的风险，债券暴雷、P2P 跑路都属这类。

## 1. 这是什么
信用风险（违约风险）= 债务人无法按时还本付息的可能性。债券、P2P、民间借贷、应收账款都有。政府债违约概率低，垃圾债违约概率高。

## 2. 为什么重要
高收益债的"高收益"，本质就是对信用风险的补偿——你多赚的利息，是别人可能赖账的风险溢价。2021 年地产债违约潮、城投债波动，都是信用风险的现实版：一旦违约，本金可能直接打水漂。

## 3. 怎么用 / 怎么看
- 看评级：AAA 违约率远低于 BB，评级是第一步筛选
- 看利差：信用利差越大，市场认为风险越高
- 看财务：负债率、经营现金流、再融资能力
- 分散持有：单只债券别重仓，别把全部身家押一个主体
- 普通人优先用债券基金代替单只债券，让专业机构分散踩雷风险

## 4. 常见坑 / 误区
- 迷信"国企/央企不会违约"——历史上有过违约先例
- 被"高息理财"诱惑：高收益 = 高风险补偿，不是白捡
- 以为买基金就不会踩雷：债券基金会踩雷，只是分散了
- 忽视评级下调的预警信号，等到违约公告才反应
