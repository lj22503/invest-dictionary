# 滞胀

> 滞胀=经济增长停滞甚至下滑、通胀却持续走高，两个坏消息同时出现的状态，是政策最头疼的局面。

## 1. 这是什么

正常经济周期里，经济差→需求弱→物价应该跌。滞胀的诡异在于供给端出事（石油危机、疫情冲击、战争），东西生产少了，价格反而涨。

最经典的案例是1970年代石油危机：油价暴涨导致物价飞涨+经济停滞，美国股市多年不涨，还叠加高失业。

> 一句话：滞胀=生病了还吃不下药，经济最难受的组合。

## 2. 为什么重要

对企业：成本涨+需求弱→利润被两头挤压，股市很难好。

对债券：通胀高→央行不敢大放水甚至要加息→债券价格也跌。所以滞胀期股债常“双杀”。

对普通人：工资不涨、物价涨，购买力缩水；此时“现金”相对值钱（虽然也在贬值，但比大多数资产跌得少）。

> 一句话：滞胀期最好的策略往往不是进攻，而是少犯错。

## 3. 怎么用 / 怎么看

- 第 1 步：同时看两个数据：GDP增速往下+CPI往上，两者背离才可能是滞胀，缺一不可。
- 第 2 步：确认源头：是需求过热还是供给冲击（能源、粮食、供应链）？供给冲击型滞胀最难治。
- 第 3 步：配置上偏向现金/短债、抗通胀资产（如黄金）、上游资源，避开长久期债券和高估值成长股。

## 4. 常见坑 / 误区

- 坑 1：看到经济不好就说“滞胀来了”——没有高通胀就不叫滞胀，那只是衰退。
- 坑 2：滞胀期“现金为王”≠永远拿现金——滞胀结束后往往迎来资产大底，要留意拐点信号。
- 坑 3：以为央行会立刻救市——高通胀约束下央行政策空间有限，别赌快速大放水。
