# 原始股骗局

> 拿"马上上市"当诱饵，卖你根本不值钱的股权

## 1. 这是什么

**原始股** = 公司上市前发行的股票，只有早期股东、员工、机构能拿到。
**原始股骗局** = 骗子虚构"内部原始股""上市前认购"名额，让你掏钱买，钱一到手就失联，或者给你一张永远无法兑现的纸质凭证。

套路通常长这样：声称某公司即将在境外或新三板上市，现在低价认购原始股，翻几倍几十倍回报。

## 2. 为什么重要

- 正规原始股**普通散户基本接触不到**，公开发行要证监会审核、要走招股说明书。
- 凡是主动找上你、催你赶紧打款的"原始股"，**99% 是骗局**。
- 受害者多为中年人、小企业主，一投就是几万到几十万，基本追不回来。

## 3. 怎么用 / 怎么看

**三连问，问完就清醒：**

1. **这家公司真在排队上市吗？** → 去证监会官网 / 交易所网站查招股书，查不到就是假的。
2. **股权凭证在工商系统登记吗？** → 要求出示工商变更记录，个人私下转让的"股权"不受法律保护。
3. **这么好的赚钱机会，为什么轮得到你？** → 陌生人主动让利，先想他图什么。

**记住一句话**：合法投资永远是你找平台，不是平台追着你塞名额。

## 4. 常见坑 / 误区

**坑 1：假借"新三板/北交所"背书** — 真上新三板也是公开市场交易，不会私下卖你"原始股"。

**坑 2：合同陷阱** — 签的是"股权代持""期权协议"，权利义务完全不对等，出事不认账。

**坑 3：钱打个人账户** — 正规股权投资款走公司对公账户；打到个人/微信/支付宝，基本是骗局。

**坑 4：和非法集资、资金盘混着来** — 常借"原始股"名义吸收资金，拆东墙补西墙，最终跑路。
