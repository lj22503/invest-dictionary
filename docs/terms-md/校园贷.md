# 校园贷

> 面向在校学生的网络借贷，以“零门槛、秒到账”吸引学生，普遍利息高、催收狠，监管已禁止向大学生放贷。

## 1. 这是什么

学生没有稳定收入，正规银行通常不放贷，于是大量非正规平台把目光瞄准校园：宣传“凭学生证即可借款”“3 分钟到账”，再借分期购物、培训贷、美容贷等马甲混进校园。

> 一句话：校园贷不看你还不还得起，只看你好骗不好骗。

## 2. 为什么重要

学生还款能力弱，几千元借款逾期后利息、违约金迅速滚大，催收会打到父母、老师、同学那里，退学、抑郁甚至轻生的案例都真实存在。国家已明令：未经批准，小贷公司、消费金融公司不得向大学生发放互联网消费贷款。

> 一句话：正规渠道不向学生放款，主动找上门的“学生贷”大概率是坑。

## 3. 怎么用 / 怎么看

- 别碰：任何“学生专享、零门槛贷款”，直接拉黑举报。
- 急用钱先走正规渠道：和家里沟通、学校资助/助学贷款、勤工俭学，都比网贷安全。
- 已被套住：停止借新还旧，马上告知父母和辅导员；涉及威胁恐吓立刻报警。

## 4. 常见坑 / 误区

- 误区一：“只借几百块没事”——砍头息加高罚息，能让几百变成几万。
- 误区二：把身份证、学生证甚至手持视频借给同学“帮忙刷单”——你的身份可能被拿去贷款。
- 误区三：以为“还完就没事”——逾期记录、催收骚扰都可能长期纠缠，必须果断报警而不是默默硬扛。
