# 元宇宙 / Web3

> 元宇宙是虚拟世界的“集合名词”，Web3 是“数据归你”的互联网愿景。两者常被混着说，落地却各不相同。

## ① 两个愿景

**元宇宙（Metaverse）＝沉浸式虚拟空间**，强调体验与社交（游戏、虚拟地产、数字分身）；**Web3＝去中心化互联网**，强调数据与资产归用户所有，以区块链为底层。二者交集是“虚拟资产”。

> 一句话：元宇宙是体验，Web3 是权属，投资请先分清。

## ② 为什么重要：概念潮水退得快

它们代表了下一波注意力与资金的去向预期，也催生了大量“讲故事”项目。对普通人，风险在于：概念宏大，但大部分项目没有可验证的收入与用户。

## ③ 怎么看：先问体验还是权属

- **先分清项目解决的是“体验”还是“权属”**。- **看用户量与留存**：别信官方白皮书吹嘘。- **数字资产（虚拟地产、头像）的流动性极差**：卖出可能等半年。

## ④ 常见坑：被口号裹挟

- **把“买虚拟地产”当投资**：结果无人接盘。- **被“Web3 革命”口号裹挟**：忽略项目跑路风险。- **混淆概念**：以为元宇宙＝Web3，被包装话术收割。
