# 政策风险

> 政策风险不是"利空消息"，是游戏规则本身被改写。

## 1. 这是什么

**政策风险，指监管、财政、货币或产业政策发生变化，让某个行业原本的赚钱逻辑和估值中枢被重新定价。**

- **四类常见来源**：行业监管（教培双减、游戏版号、医药集采）、宏观政策（加息降准、财政扩张与收缩）、产业政策（补贴退坡、反垄断）、规则变化（交易制度、税收口径）
- **为什么它比普通利空更狠**：普通利空影响一年业绩，政策变化可能直接否定整个商业模式
- **典型表现**：政策一落地，全行业估值一起下台阶，龙头也躲不开

> 一句话：政策风险不是"利空消息"，是游戏规则本身被改写。

## 2. 为什么重要

- **它决定行业天花板**：政策给的空间，就是行业收入的上限
- **它的传导链条是"预期 → 估值 → 股价"**：不用等业绩变差，估值先重估
- **对个人的意义**：重仓单一政策敏感行业，等于把账户押在一次政策选择上
- **它也有正向的一面**：政策支持的方向（早期的新能源、半导体）会带来估值扩张

- 记住一点：政策风险的特点是，你无法用财务分析去对冲它。

## 3. 怎么用 / 怎么看

- **分层看政策**：总量政策（货币、财政）影响整体估值；行业政策影响具体赛道
- **看层级与节奏**：意见稿 → 征求意见 → 正式文件 → 执行细则，越往后越确定
- **区分"规范"与"取缔"**：多数政策是规范而非消灭，行业还在，但赚钱方式会变
- **关注时间差**：政策底常在业绩底之前，市场往往提前反应
- **用仓位纪律代替预测**：单一政策敏感行业不宜重仓，分散化比猜政策更可靠

## 4. 常见坑 / 误区

- **把政策利好当业绩**：政策只给空间，不给利润，兑现还要看公司自己
- **只看标题不看细则**：同一份文件，执行口径决定谁受益、谁受损
- **以为政策立竿见影**：从文件到落地常有 1-3 年时滞，节奏比方向更难判断
- **把"规范"当"消灭"**：恐慌杀跌和盲目抄底，都是在赌情绪而不是逻辑
- **忽略政策周期会反复**：宽松与收紧会来回切换，单次判断不能长期沿用
