# 存款准备金

> 银行收了你 100 块存款，必须按比例“锁”在央行一部分，剩下的才能拿去放贷。

## 1. 这是什么

存款准备金率：银行必须保留在央行的存款比例，目前大型银行约 7%~10%。
它是储户存款的“压箱底”：防止银行把存款全部贷光、挤兑时没钱付。
降准 = 比例下调 = 银行可贷资金变多。

## 2. 为什么重要

准备金率决定货币乘数：比率越低，同样的存款能放大出越多贷款。
降准释放长期资金，利好银行利润、股市流动性、楼市预期。
升准则相反，是明确的收紧信号。

## 3. 怎么用 / 怎么看

- **看公告幅度**：全面降准 vs 定向降准（只针对特定银行）
- **看释放资金量**：央行一般会公布“释放长期资金约 X 亿元”
- **看市场反应**：债市利率下行、股市情绪回暖，但别指望“明天就涨”

## 4. 常见坑 / 误区

坑 1：把降准当大放水。企业和居民不愿借钱时，钱会空转，未必到实体。
坑 2：以为准备金是银行自己的钱。它本质是储户存款的保证金。
坑 3：只盯降准不盯降息。两者常组合使用，信号力度不同。
