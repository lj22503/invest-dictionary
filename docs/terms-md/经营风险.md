# 经营风险

> 经营风险不是"股价跌了"，是"生意本身在变难做"。

## 1. 这是什么

**经营风险，指公司因为产品卖不动、成本失控、客户流失、管理失误等经营层面的原因，导致收入和利润下滑的可能性。**它来自生意本身，而不是市场情绪。

- **常见来源**：需求下滑、竞争加剧、原材料涨价、客户或供应商过度集中、供应链断裂、管理层动荡、扩张过快
- **和财务风险的区别**：经营风险是"生意赚不到钱"，财务风险是"借的钱还不上"；前者常常引发后者
- **看它出现的位置**：它出现在利润表的上游——收入、毛利率、费用

> 一句话：经营风险是"生意变难做"，不是"股价跌了"。

## 2. 为什么重要

- **它会层层传导**：收入下滑 → 毛利下滑 → 现金流恶化 → 被迫融资甚至违约
- **它通常比财务风险更早出现**：财报里的毛利率、应收账款、存货往往先给出信号
- **对个人的意义**：买股票本质是买这门生意，生意变差，再低的估值也可能还是贵
- **它决定"能不能熬"**：同样的行业下行，经营质量差的公司先出局

## 3. 怎么用 / 怎么看

- **看毛利率趋势**：连续下滑通常意味着竞争加剧或成本失控
- **看应收账款和存货增速**：明显快于收入增速，往往是"卖出去却收不回钱"
- **看经营现金流与净利润的比值**：长期显著小于 1，利润质量要打问号
- **看集中度**：前五大客户或供应商占比过高，一旦丢单影响巨大
- **看管理层动作**：频繁更换 CFO、大额计提、关联交易增多，都是预警信号

## 4. 常见坑 / 误区

- **把行业下行当"暂时的"**：周期变长时，"暂时"可能持续好几年
- **只看利润不看现金流**：利润可以做会计处理，现金流很难修饰
- **把订单或框架协议当收入**：没有交付落地的合同，不是利润
- **忽略公司治理**：激励错位时，经营风险会变成个人风险
- **轻视扩张后遗症**：扩产、跨界、收购带来的整合问题，常在两年后集中暴露
