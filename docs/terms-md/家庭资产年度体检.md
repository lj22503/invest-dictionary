# 家庭资产年度体检（Annual Financial Checkup）

> 一年一次，给家里的钱做次全身检查

## 1. 这是什么

家庭资产年度体检，就是**每年固定做一次“钱的全面盘账”**，像体检一样查五项：

- **家底**：资产负债表——有多少资产、多少负债
- **流量**：收入支出表——一年赚多少、花多少、存多少
- **安全**：应急金是否还有 3-6 个月、负债率是否低于 50%
- **保障**：保险保额够不够（涨薪了、生娃了都要加保）
- **收益**：各项投资的实际年化收益率、最大回撤有没有超出预期

产出物是一页纸的报告：净资产多少、同比增长多少、明年要调整哪几件事。

## 2. 为什么重要

你的钱在变，环境也在变：工资涨了保额不够、利率降了存款收益腰斩、股市涨了仓位失衡——**不体检就发现不了**。

年度体检能回答三个要命的问题：**今年到底存下钱了吗？负债危险吗？赚的钱是真赚吗？**

数据不会骗人：记账记一年，年底一算“月度支出比想象中高 30%”，比上十节理财课都有用。

固定时间和频率，才不会把这件事拖成“等有空再说”。

## 3. 怎么用 / 怎么看

**第 1 步：定时间。** 选生日、元旦或年终奖到账那天，写进日历，每年重复执行。

**第 2 步：拉真实数据。** 银行/基金/券商 App 查余额，房贷看还款计划，信用卡查账单，公积金查余额——**不靠记忆估算**。

**第 3 步：算五个数。**

- 净资产（总资产 − 总负债）
- 负债率（建议 < 50%）
- 储蓄率（建议 > 20%）
- 应急金月数（3-6 个月）
- 重疾保额（建议 ≥ 3-5 年收入）

**第 4 步：做三个决定。** 要不要加保？要不要再平衡？提前还贷还是继续投？

**第 5 步：存档。** 今年的报告和去年的放一起，变化一眼看清。

## 4. 常见坑 / 误区

**坑 1：一年一次变成“想起来才做”。** 不固定时间就等于不做，最后只剩一句“感觉还行”。

**坑 2：凭记忆估算，不查账。** 误差能差出一辆车，必须拉真实数字。

**坑 3：只看总资产不看结构。** 资产涨了，全是房子涨的，流动性一塌糊涂；或者全是股票，遇到熊市直接腰斩。

**坑 4：体检完什么都不改。** 查出负债率 70%、重疾保额为 0，却一条都不调整——那这次体检只是自我安慰。
