# 白银 / 铂金 / 钯金

> 黄金之外，白银、铂金、钯金也是贵金属家族成员。它们各有工业属性，价格逻辑和黄金并不相同。

## ① 贵金属四兄弟

**白银兼具货币与工业属性**（光伏、电子）；**铂金用于汽车催化与首饰**；**钯金主要用于汽车尾气净化**。供给集中、工业需求占比高，价格波动普遍大于黄金。

> 一句话：贵金属不等于黄金，工业属性决定它们更刺激。

## ② 为什么重要：价格逻辑不同

它们的价格不只看“避险情绪”，更看工业周期与供给扰动（矿山事故、地缘冲突、车企需求）。想“买贵金属避险”，白银的波动可能让避险变成冒险。

## ③ 怎么看：四个维度

- **区分“货币属性”与“工业属性”权重**。- **关注库存（交易所库存变化）与供给新闻**。- **看金银比、铂金-钯金价差的历史区间**。- **通过黄金 ETF、贵金属积存产品参与更省心**。

## ④ 常见坑：把白银当“便宜版黄金”

- **把白银当“便宜版黄金”满仓抄底**。- **被“铂金比黄金稀有”话术带节奏**：忽略工业需求下滑。- **追高钯金历史高点**：忽略电动车对催化需求的长期冲击。
