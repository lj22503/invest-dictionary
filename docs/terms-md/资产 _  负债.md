# 资产 / 负债

> 钱往你口袋流的是资产，从你口袋流的是负债

## 1. 这是什么

**资产** = 把钱放进口袋的东西。
**负债** = 从你口袋掏钱的东西。

最直白的判断标准：**不工作时，这东西是给你钱还是跟你要钱？**

- 自住的房子：不工作时不产生现金流，是负债；出租的房子收租，是资产。
- 自用的车：加油保养都花钱，是负债；跑滴滴的车赚流水，是资产。
- 股票账户：持仓分红 + 升值，是资产；信用卡账单，是负债。
- 一项技能：能让你加薪或接活赚钱，是资产；一段无效社交，是负债。

## 2. 为什么重要

普通人一生都在"负债 → 资产"之间挣扎。

理解这两个概念的真正威力，来自于**"自住房是不是资产"**的重新定义：
- 会计上：自住房算资产（你有产权）
- 财富上：自住房是负债（每月消耗你的钱，没产生现金流）

这个视角翻转，让你能区分"账面有钱"和"真有钱"。

**富人的秘密**：买入资产（让钱流进口袋），避免负债（别让钱流出去）。
**穷人的陷阱**：把负债当资产买（房贷买车），以为"升值"就算赚。

## 3. 怎么用 / 怎么看

**步骤 1：列你的"现金流清单"**
把名下所有东西列出来，标注每月现金流方向：
- 工资 → 流入
- 房租（如果有）→ 流入
- 自住房月供 / 物业 / 维修 → 流出
- 车贷 / 油费 / 保险 → 流出
- 存款利息 → 流入
- 信用卡还款 → 流出
- 股票分红 → 流入

**步骤 2：算"净被动收入"**
所有流入 - 所有流出 = 净被动现金流。
- 正数：你有真正的资产
- 零：你收支平衡
- 负数：你被负债拖着走

**步骤 3：调整结构**
- 能转出租的房子转出租（自住房变投资房）
- 减少不必要的负债（高息信用卡、车贷、消费贷）
- 增加资产（指数基金定投、债券、租金收入）

**步骤 4：长期看比例**
财务自由的核心指标：被动资产 / 总资产。
- 低于 30%：被工作绑架
- 30-70%：开始有底气
- 70%+：基本自由

## 4. 常见坑 / 误区

**坑 1：把"账面价值"当资产**
"我有套 500 万的房子"——但你卖了就得住别处，多出来的 500 万才能算资产。**自住房升值但不出售，对你生活没实质改变**。

**坑 2：把"负债"当成"投资"**
"我刷信用卡买理财，套利 1%"——大部分人算不过真实年化（信用卡分期 18% vs 理财 3%）。**信用卡负债从来不是低成本资金**。

**坑 3：忽视隐性负债**
"我不用信用卡，没负债"——但你买的车每年贬值 15%、你的手机每月流量费、你买的会员订阅，这些都是隐性负债。**算总账时别只看显性负债**。

**坑 4：把"消费负债"当"投资负债"**
房贷是中性负债（资产可能升值），但消费贷是纯负债。**借钱的目的是为了赚钱，才是良性负债；借钱是为了消费，就是恶性负债**。

**坑 5：资产只算金融的不算技能的**
你的英语能力、写作能力、行业人脉——这些是"非金融资产"。失业时它们能帮你快速找到下家，**也是真实资产**。
