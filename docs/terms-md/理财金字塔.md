# 理财金字塔

> 把家里的钱按"底层保命、中层保值、顶层增值"分成三层的家庭资产配置框架。

## 1. 这是什么

理财金字塔把家庭资产分成三层，从下往上，比例由大到小：

- **底层（最厚）**：应急金、保险、存款——用来"保命"，防意外、防大病、防失业；
- **中层**：债券、稳健理财、年金——用来"保值"，跑赢通胀，波动小；
- **顶层（最尖）**：股票、偏股基金等——用来"增值"，博取高收益，但风险也最大。

**底层越厚，塔越稳**。顺序不能乱：先有底，再谈尖。

## 2. 为什么重要

很多人理财的顺序是反的：先买股票基金，后配保险和应急金。结果行情一跌就割肉，一次大病就把积蓄掏空——**塔尖再高，地基不牢照样塌**。

理财金字塔提供一套检查顺序：

- 你的应急金够不够 3~6 个月开销？
- 保险配齐了吗（重疾、医疗、定寿、意外）？
- 稳健层能不能兜住日常和中期目标？
- 最后，高风险的钱是不是"亏光了也不影响生活"的闲钱？

想清楚这四步，你就不会把保命钱拿去梭哈。

## 3. 怎么用

- 第一步：按顺序搭建——先存应急金（3~6 个月生活开销），再配基础保险，然后才谈投资；
- 第二步：参考 4321 法则分配比例：40% 保值层、30% 增值层、20% 保障层、10% 现金（按家庭情况调整）；
- 第三步：每年做一次"再平衡"——涨多了的顶层止盈一部分补进中层，保持结构稳定；
- 第四步：人生阶段变了就调比例：年轻没负担可以顶层多些，上有老下有小就加大底层。

## 4. 常见坑 / 误区

- **把高风险放底层**：用养老钱、看病钱去炒股，等于把地基掏空；
- **顶层比例过高**：满仓股票、不留现金，遇到急用只能割肉；
- **没有应急金就投资**：一分钱备用金都没有，市场一跌心态先崩；
- **以为金字塔一成不变**：比例不是死的，要随收入、家庭、年龄动态调整。
