# 泡沫破裂

> 资产价格被炒到远超真实价值后，突然大幅下跌的那一下，就是泡沫破裂。

## 1. 这是什么

<strong>泡沫破裂 = 资产价格在狂热中涨到离谱，然后像气球一样被戳破，价格断崖式下跌。</strong>涨的时候有多疯狂，跌的时候就有多惨烈。

历史上的名场面：17 世纪荷兰郁金香、2000 年互联网泡沫、2008 年房地产与次贷泡沫、2021-2022 年的加密货币与元宇宙概念——每一个都逃不过“涨过头 → 跌透底”的剧本。

> 一句话：泡沫不是跌出来的，是涨出来的——它破裂前，看起来永远像“还会涨”。

## 2. 为什么重要

泡沫破裂不是“回调”，是<strong>价值毁灭</strong>：

- 跌幅惊人：历史大泡沫通常跌 50%-90%，且多年不回头（2000 年纳指直到 2015 年才收复前高）；

- 追高的人最惨：泡沫顶部冲进来的人，可能十年都回不了本；

- 连带效应：资产缩水 → 消费收缩 → 企业裁员 → 经济衰退，个人收入也会被拖累。

泡沫破裂的规律很反直觉：<strong>涨得越急、跌得越狠；破裂前总有人喊“这次不一样”</strong>。而“这次不一样”往往是最后一波接盘者最有信心的时刻。

## 3. 怎么用 / 怎么看

- 信号一：全民都在聊——出租车司机、电梯里的大妈都在荐股/荐币，说明新钱正在涌入；

- 信号二：新手入场——平时不理财的人开始加杠杆，开户数暴增；

- 信号三：估值离谱——市盈率、市梦率远超历史均值，价格脱离基本面；

- 信号四：杠杆加满——融资余额、信用卡套现炒股成为流行操作。

应对泡沫的正确姿势不是“精准逃顶”，而是：<strong>不追高、控制单一资产仓位、手里留现金、定期再平衡</strong>。你不一定躲过每一次下跌，但可以保证泡沫破裂后自己还能活着。

> 一句话：泡沫破裂前没人知道是泡沫，所以普通人靠纪律，不靠预测。

## 4. 常见坑 / 误区

- 坑一：“还能涨”的幻觉——跌 10% 觉得是上车机会，跌 30% 觉得是错杀，结果越买越深；

- 坑二：以为跌 20% 就是底——大泡沫腰斩之后再腰斩很常见，抄底抄在半山腰；

- 坑三：加杠杆扛单——泡沫破裂时杠杆最先爆，爆仓的人等不到反弹；

- 坑四：恐慌割肉在最低点——破裂后期情绪最差，反而容易把底部筹码交出去；

- 坑五：把“泡沫破裂”当“跌出机会”无脑买——破裂后接飞刀，和追高一样危险。
