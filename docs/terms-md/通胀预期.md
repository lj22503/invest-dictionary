# 通胀预期

> 大家“觉得”未来物价会涨还是会跌——这个感觉本身会变成现实。

## 1. 这是什么

通胀预期 = 公众对未来一段时间物价走势的判断。
它会自我实现：预期涨价 → 提前抢购 → 需求推高物价 → 通胀真的来了。
反之，预期通缩 → 大家持币观望 → 需求萎缩 → 物价更低迷。

## 2. 为什么重要

一旦公众坚信“钱会越来越不值钱”，工资-物价螺旋上升就很难刹住。
所以央行反复强调“把通胀预期锚定在合理区间”。
锚定成功的标志：通胀高点回落，但大家仍相信长期物价稳定。

## 3. 怎么用 / 怎么看

- **看消费者信心、通胀新闻热度**：热度越高，预期越强
- **预期升温时**：可锁定长期固定利率贷款（通胀稀释债务），配置抗通胀资产
- **预期降温时**：现金和固收的相对吸引力上升

## 4. 常见坑 / 误区

坑 1：把通胀预期当实际通胀。预期可能落空，别据此梭哈。
坑 2：央行喊“物价稳定”时全盘相信或全盘否定。要结合数据看。
坑 3：以为自己能精准预测通胀。连专业机构都常错，普通人更适合“防御性配置”。
