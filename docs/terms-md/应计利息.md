# 应计利息

> 债券在你手里多拿一天，就多"攒"一天的利息，这笔攒下来的钱就是应计利息。

## 1. 这是什么

**应计利息 = 从上一次付息日到现在，债券已累积但还没发放的利息。**债券通常半年或一年付一次息，两次付息之间，利息其实每天都在"生长"——你持有债券，这部分利息就是你的；中途卖出时，买家要把这段时间的利息补偿给你。所以债券交易价格通常报"净价"（不含应计利息），实际成交时按"全价 = 净价 + 应计利息"结算。基金里也一样，债券基金每天公布的净值已经包含了当日应计利息。> 一句话：应计利息是债券的"日结工资"，攒着一起发。

## 2. 为什么重要

它解释了两个常见现象：第一，为什么债券持有期间净值/价格会"慢慢往上爬"——因为利息每天在累积；第二，为什么除息日前后债券会"跳水"——付息后应计利息清零，价格自然回落。如果你在付息日前买入债券，要付给卖方一大笔应计利息，可能"买在高点"；在除息日附近操作不当，还可能误以为暴跌。看懂应计利息，才能理解债券价格为什么不是一条直线。> 一句话：债券价格里藏着"时间价值"，应计利息就是那个刻度。

## 3. 怎么用 / 怎么看

- **算清楚再买**：付息日前买入要支付应计利息，先算"净价 + 应计利息"的总成本，别只看报价。
- **避开除息日操作**：除息日前后债券价格会因利息清零而回落，这不是利空，是正常机制。
- **看基金净值包含利息**：债券基金净值逐日上升的一大来源就是应计利息，别误以为"天天都在赚资本利得"。
- **用全价判断真实盈亏**：看收益要按"全价"进出对比，只看净价会漏掉应计利息这部分的损益。> 一句话：买债先算应计利息，卖债别忘拿回应计利息。

## 4. 常见坑 / 误区

- **把"付息后价格下跌"当暴跌**：那是应计利息清零，持有人的总回报没变，是"左口袋到右口袋"。
- **忽略跨付息日的税费**：个人持有到期免税，但中途买卖的利息归属、机构税收处理不同，别一概而论。
- **以为净值涨=真的赚了**：债基净值上涨里可能大部分是应计利息，扣除管理费等费用后实际到手要打折扣。
- **付息日前冲动买入**：为拿利息而在付息日前追高，实际支付了全部应计利息，等于"自己给自己发利息"。> 一句话：应计利息不是惊喜，是早就写好的账单。
