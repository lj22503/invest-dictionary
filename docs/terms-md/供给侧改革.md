# 供给侧改革

> 从"生产端"动手：去掉多余产能、降低库存杠杆，让"生产什么、生产多少"变得更合理。

## 1. 这是什么

供给侧改革是 2015 年底提出的政策主线，核心是"三去一降一补"：去产能、去库存、去杠杆、降成本、补短板。最典型的动作是关停小煤窑、压缩钢铁和水泥的过剩产能。

逻辑很简单：生产的东西太多、太烂、太同质化，大家只能打价格战；把低效产能关掉，供给收缩，价格和利润自然修复。

## 2. 为什么重要

它改变了一批周期行业的赚钱逻辑。2016—2017 年，钢铁、煤炭、水泥在去产能推动下价格大涨、企业盈利大幅修复，催生了著名的"供给侧行情"。看懂它，你就看懂了周期股最大的上涨来源之一：不是需求多好，而是供给变少了。

它也会影响就业和区域经济：关停的工厂背后是工人、是地方财政，所以政策节奏往往"稳中求进"。

## 3. 怎么用 / 怎么看

- 盯政策文件里的关键词：产能利用率、淘汰落后产能、能耗双控、错峰生产。
- 对比行业数据：开工率下降 + 库存下降 + 价格上升 = 典型的供给收缩特征。
- 判断涨价性质：问一句"这涨价是需求驱动还是供给收缩驱动"，两种行情持续性和弹性完全不同。
- 供给收缩行情里选龙头：成本低、产能合规、现金流好的公司最受益。

## 4. 常见坑 / 误区

- 把供给收缩行情当成长股长期持有：周期品在顶部照样大跌，别只记得涨价时的美好。
- 忽视需求端：供给收缩 ≠ 需求旺盛，需求塌了，供给再少也扛不住价格。
- 追高"涨价概念"：等你在新闻里看到"钢铁大涨"时，行情往往已经走完大半。
- 以为去产能=永久减产：价格一涨，产能随时可能重新开起来。
