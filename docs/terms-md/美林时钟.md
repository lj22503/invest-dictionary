# 美林时钟

> 美林时钟=按经济增长快慢和通胀高低把经济切成四个阶段，指导股票、债券、商品、现金轮动配置的框架。

## 1. 这是什么

美林时钟把经济切成四个象限：复苏（增长↑、通胀↓）→股票为王；过热（增长↑、通胀↑）→商品为王；滞胀（增长↓、通胀↑）→现金为王；衰退（增长↓、通胀↓）→债券为王。

核心逻辑：先判断经济走到哪个“季节”，再把钱放到当下赚钱效应最强的资产里。

> 一句话：先看季节再穿衣服，先定周期再配资产。

## 2. 为什么重要

它给“什么时候该买什么”一个可操作的判断框架，比拍脑袋配置靠谱，是资产配置和基金组合里常用的大类轮动参考。

对普通人：与其天天猜热点、追涨杀跌，不如先定位周期阶段，再决定股债比例，能少交很多“情绪税”。

但要清醒：它是“经验规律”而非物理定律，现实中的阶段经常快速跳过甚至倒退。

> 一句话：时钟不会错，错的是你以为它永远按表走。

## 3. 怎么用 / 怎么看

- 第 1 步：用两个指标定位：增长看PMI、工业增加值、企业盈利；通胀看CPI、PPI。
- 第 2 步：把当前位置放进四象限：增长向上+通胀向下=复苏；都向上=过热；增长向下+通胀向上=滞胀；都向下=衰退。
- 第 3 步：按象限调配置：复苏多配股票，过热配商品/周期股，滞胀降仓位留现金，衰退多配债券。
- 第 4 步：每季度复核一次，看到阶段切换信号就及时再平衡。

## 4. 常见坑 / 误区

- 坑 1：机械套用四阶段——现实经济不是钟表，可能从过热直接掉进衰退，中间没有滞胀。
- 坑 2：被滞后数据误导——等官方数据确认阶段时，市场往往已经提前反应，要结合预期和领先指标。
- 坑 3：把时钟当择时神器——它擅长“配大类”，不擅长告诉你明天该买哪只股票。
