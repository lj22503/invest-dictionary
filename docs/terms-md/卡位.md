# 卡位

> 热点还没火、轮到它涨之前先占住位置——卡位是轮动行情里抢低成本的进场机会。

## 1. 这是什么

**卡位，就是在新热点还没完全确认、资金还没大规模进场之前，先在那个"可能轮到"的方向上占个位置**。

轮动行情里，钱从一个板块流向下一个板块。等热点人尽皆知再追，成本已经高；**卡位是在"它还没轮到"的时候提前蹲守**。

典型的卡位对象：龙头涨完后的二线、主线调整时冒头的新方向、同一逻辑里还没启动的分支。


## 2. 为什么重要

轮动行情追高最伤人：今天涨停明天就跌，接力资金一个比一个慌。**卡位的好处是成本低、容错高**——蹲在低位，错了损失有限，对了就是主升浪起点。

对看盘的人来说，卡位能力决定你在轮动里是"低吸的赢家"还是"接盘的输家"。


## 3. 怎么用 / 怎么看

- 线索 1：龙头溢出——板块龙头涨不动了，钱往往流向同板块滞涨股（补涨逻辑）
- 线索 2：政策/消息催化——新方向刚有消息，资金还在犹豫，先卡位等发酵
- 线索 3：高低切信号——高位板块放量滞涨、低位板块缩量企稳，是轮动开始的信号
- 纪律：卡位只小仓试探，确认"卡对了"（放量拉升）再加仓；卡错了及时撤


## 4. 常见坑 / 误区

- 坑 1：卡在已经炒过一轮的高位板块——那叫接盘，不叫卡位
- 坑 2：全仓卡位——卡位本质是试错，仓位必须轻
- 坑 3：卡位后死等——逻辑没兑现就走，别把试探熬成重仓
- 坑 4：把"听说要炒"当线索——没有确认信号前，传闻只是噪音
