# 法拍房

> 法院把欠债人（被执行人）的房子强制拍卖还债，起拍价常比市场价低，但税费和腾房是两大隐藏成本。


## 1. 这是什么

**法拍房 = 法院把欠钱不还的人（被执行人）的房子强制拍卖，拍卖所得用来还债。**流程是：债权人申请 → 法院查封 → 评估定价 → 公开拍卖 → 成交过户。最常见的来源有三个：`断供**（房贷还不上被银行起诉）、`民间借贷纠纷**、`欠税欠费**。你在淘宝、京东司法拍卖频道看到的房子，大多属于这一类。> 一句话：法拍房不是“捡漏游乐园”，是法院主持的“强制卖房还债”。

## 2. 为什么重要

起拍价一般是评估价的 7-8 折，如果没人买、流拍了还会再降：**一拍 7 折，二拍最低能到 5.6 折**。一套评估 300 万的房子，起拍价可能只有 210 万，二拍甚至 168 万。便宜不是白来的：**房子的“麻烦”已经写进价格里了**——有没有人住、有没有租约、税费谁出、能不能贷款，每一项都可能让“便宜”变成“烫手山芋”。> 一句话：便宜是真实惠还是真麻烦，取决于公告里那几行小字。

## 3. 怎么用 / 怎么看

- **第一步看“现状”**：公告里写清楚有没有人居住、是否凶宅、租约到什么时候——买卖不破租赁，有租约的房子你可能几年收不回来。
- **第二步算税费**：法拍房的卖方税费常常要买家扛，增值税、个税、契税加一起可能占到房价的 10% 以上，不同房源差别很大。
- **第三步问贷款**：很多城市要求成交后 7-15 天付清尾款，银行按揭能不能批、放款来不来得及，必须先问清楚，否则只能全款。> 一句话：先看公告、再算税费、最后谈贷款，顺序反了容易踩坑。

## 4. 常见坑 / 误区

- **腾房难**：原房主赖着不走，法院强制执行也要排队，可能拖几个月甚至更久。
- **税费刺客**：公告写“税费各自承担”和“买家全包”差别巨大，个税、增值税可能比你想的多好几万。
- **户口迁不出**：学区、落户受影响，法院一般不管户口迁移。
- **瑕疵叠加**：欠物业费、水电费、有违章搭建，都要买家自己处理。
- **悔拍不退保证金**：拍下后反悔，保证金（通常 10%-20%）直接没收。> 一句话：普通小白别只看“比市场价便宜”，先把麻烦清单算完再出价。
