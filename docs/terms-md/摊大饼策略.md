# 摊大饼策略

> 把一篮子候选全部等权买入——摊大饼是不做选择、用广度换胜率的策略。

## 1. 这是什么

**摊大饼策略，是把一篮子候选标的（比如同行业的多只转债/ETF）全部等权买入**，哪个都不重仓，哪个涨了都吃得到。

名字很形象：像摊煎饼一样把面糊（资金）均匀铺开，摊得越平，单点风险越小。在可转债、行业 ETF、低估值股票池里特别常见。


## 2. 为什么重要

很多人的痛苦是"选不中"：押一只，押错了整年白干。**摊大饼放弃了"选中最强"的暴利，换来了"不踏空任何上涨"的稳定**——单只翻倍你赚一份，十只里五只涨你就赚五份。

它特别适合**新手和懒人**：不用精准择时、不用深度研究个股，只要篮子本身选得好（同一逻辑、估值不高），长期就是"跟着板块吃平均收益"。


## 3. 怎么用 / 怎么看

- 步 1：选篮子——同一逻辑、相关性高的候选（如 10 只低价转债、5 只行业 ETF）
- 步 2：等权买——每只买相同金额，别因为"更看好某只"就加码
- 步 3：定期调——每季度/半年检查：涨太多的部分卖出、跌回低估的补回，维持等权
- 步 4：设下限——篮子里的标的如果基本面变坏（退市、违约），直接剔除


## 4. 常见坑 / 误区

- 坑 1：篮子选得太杂——买 20 个八竿子打不着的品种，那是乱买不是摊大饼
- 坑 2：摊着摊着变成重仓——"顺手多买点"某只，饼就摊不开了
- 坑 3：不设剔除规则——烂标的留在篮子里，摊大饼变成攒垃圾
- 坑 4：把摊大饼当万能策略——单边下跌行情里，摊得再平也躲不过系统性下跌，要配合止损与仓位
