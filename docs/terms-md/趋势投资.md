# 趋势投资

> 趋势投资 = 顺着已经走出来的方向做，涨了跟涨、跌了跟跌，不猜顶底，只做"顺势"。

## 1. 这是什么
趋势投资的核心理念：**价格会沿着已有趋势继续走一段时间**。

- 上涨趋势：高点不断抬高，低点也在抬高，就拿着或买入。
- 下跌趋势：高点不断降低，就别接飞刀，空仓或离场。
- 它不做"抄底"和"逃顶"，只赚趋势中间最肥的那段。

## 2. 为什么重要
- 对普通人来说，判断"正在涨"比判断"马上要涨"容易得多。
- 顺势而为可以减少逆势扛单的煎熬，也能吃到行情的大部分利润。
- 趋势投资最怕的不是"晚"，而是"逆着来"——逆势操作是散户亏损的主因之一。

## 3. 怎么用 / 怎么看
- 确认趋势：价格站上关键均线（如 20 日、60 日均线），且均线向上，视为多头趋势。
- 顺势买入：趋势确认后再进，宁可买贵一点，也要等信号明确。
- 让利润奔跑：趋势没破坏就拿住，别涨一点就跑。
- 严格止损：跌破关键支撑位（如 60 日线）就离场，不抱侥幸。
- 口诀：**截断亏损，让利润奔跑。**

## 4. 常见坑 / 误区
- 把震荡当趋势：横盘时追涨杀跌，会被反复"打脸"，趋势系统在震荡市会连续小亏。
- 没有止损：趋势投资的命门是止损，扛单一次就能把利润全还回去。
- 追在趋势末端：涨了很久、人人都在喊"牛市"时进场，容易接最后一棒。
- 趋势与价值混用：用趋势的规则买价值股，或用价值的逻辑扛趋势单，两头不讨好。
