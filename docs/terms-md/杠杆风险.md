# 杠杆风险

> 借钱投资，赚了放大收益，亏了也放大亏损，甚至亏光本金倒欠钱。

## 1. 这是什么

杠杆就是借钱投资：融资买入、期货保证金、配资都是杠杆。2 倍杠杆下，涨 10% 你赚 20%，跌 10% 你亏 20%。

杠杆本身不产生收益，它只放大波动——方向对了加速赚，方向错了加速亏。

> 一句话：杠杆是放大器，不是印钞机。

## 2. 为什么重要

2 倍杠杆买入，标的跌 50%，你的本金就亏光了（爆仓）；如果还有利息成本，可能穿仓倒欠券商钱。

A 股融资保证金比例通常 100%（约 2 倍杠杆），期货保证金比例 10%-15%（约 7-10 倍杠杆），波动稍大就触发强平。

历史反复上演：用杠杆的人不是死于判断错误，而是死于波动本身——方向最终对了，但中间扛不住强平。

> 一句话：杠杆最大的风险，是让你等不到“对”的那天。

## 3. 怎么用 / 怎么看

底线 1：杠杆比例别超过 1.5 倍，给自己留足缓冲。

底线 2：设好止损，触发就执行，别赌“马上反弹”。

底线 3：只用闲钱，绝不借钱加杠杆炒股。

底线 4：密切关注维持保证金比例，别等强平通知。

> 一句话：用杠杆前，先想清楚“亏光”能不能承受。

## 4. 常见坑 / 误区

坑 1：只算“涨了赚多少”，不算“跌了亏多少”。

坑 2：忽视利息和手续费，长期持有成本很高。

坑 3：下跌时舍不得止损，被强平在最低点，然后反弹——这是最常见的“死于杠杆”。

> 一句话：杠杆风险的坑，全在“低估下跌”四个字里。
