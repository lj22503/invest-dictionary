# 票息

> 债券每年按面值的一定比例付给你的利息，就是票息。注意票息率不等于你实际赚到的收益率。

## 1. 这是什么（每年固定打给你的利息）

一张面值 100 元的债券，票面利率 3%，那么每年付给你 3 元利息，这就是票息。
票息在债券发行时就定死了（固定利率债），持有人每年（或每半年）固定收到一笔钱，到期拿回本金。
记住这个关键区分：票息率 ≠ 实际收益率。债券价格会波动——如果你用 95 元买入这张 100 元面值的债，实际收益率就高于 3%；用 105 元买，实际收益率低于 3%。
一句话：票息是“名义利息”，到期收益率才是“真实回报”。

## 2. 为什么重要（为什么重要：现金流与信用信号）

票息是债券投资者的现金流来源，对靠收息生活的人（退休金、现金流规划）尤其重要。
票息高低也是发行人的信用名片：
国债：票息低，因为几乎不会违约；企业债：票息高，多出来的部分是“违约风险补偿”；垃圾债：票息极高，因为违约概率也极高。
利率变化时，新发债的票息也会跟着变——市场利率高，新债票息就高；这就是为什么利率上升期，老债价格会下跌。
一句话：票息是糖，信用风险才是判断甜不甜的秤。

## 3. 怎么用 / 怎么看（怎么用：票息不等于真实收益）

先看票面利率，再看到期收益率（YTM）：YTM 才是你持有到期的真实年化回报；分清付息频率：同样票面利率，半年付息比年付息的实际复利略高；认识零息债：零息债没有票息，发行时打折卖（比如 80 元买、到期 100 元还），差价就是收益；看现金流匹配：需要每年有现金流选分次付息债，只想锁收益选零息债。
一句话：买债先问“到期收益率”，别被票面利率带跑。

## 4. 常见坑 / 误区（常见坑：高票息背后是高风险）

以为票息=实际收益：债价下跌会吃掉票息，甚至让你总体亏损；被“高票息”吸引：高票息往往对应高违约风险，小心本金直接归零；忽略付息频率：年付息和半年付息，长期复利差一截；中途卖出按市价结算：只有持有到期才拿回全部本金，中途卖可能亏。
一句话：票息高不是捡钱的理由，先问一句“为什么不违约？”
