# 保险 IRR（真实收益）

> IRR 是算清保险"实际年化收益率"的照妖镜，业务员说的收益高不高，一算便知。

## 1. 这是什么
IRR（内部收益率）= 把保单所有的现金流（交的保费、领的钱）折算成年化复利收益率。举例：某年金险交 10 万，10 年后领 13 万，IRR 大约 2.7%——远低于业务员嘴里"复利 4%"。

## 2. 为什么重要
储蓄险宣传常用"保额增长""演示利益"迷惑人。用 IRR 一算，很多"高收益"产品真实年化只有 2%-3%，还不如国债。防止被"3.5% 复利"话术收割，这是普通人最该学会的一把小计算器。

## 3. 怎么用 / 怎么看
- 列出现金流：每年交费记负数，每年领取记正数，按年度排好
- 用工具算：Excel 的 =IRR() 函数，或小程序 IRR 计算器
- 对比基准：把结果和同期国债、存款、大额存单利率比一比，再决定值不值

## 4. 常见坑 / 误区
- 用"保额增长率"冒充收益率——保额涨不代表你拿到手的钱涨
- 只算领取，不算前期现金价值，忽略回本慢的问题
- 信演示利率（高档），那不是保证利率
- 用单利/累计收益冒充年化复利，数字瞬间好看一倍
