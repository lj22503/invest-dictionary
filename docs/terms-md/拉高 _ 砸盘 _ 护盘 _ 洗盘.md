# 拉高 / 砸盘 / 护盘 / 洗盘

> 拉高、砸盘、护盘、洗盘是主力（大资金）在盘面上常演的四个动作：把价格拉上去、砸下来、托住不让跌、故意吓跑散户。

## 1. 这是什么

这四件事本质都是“大资金在关键价位做动作”：

- **拉高**：用大买单快速把价格推高，吸引散户跟风追涨；
- **砸盘**：用大卖单把价格砸低，制造恐慌，逼人割肉；
- **护盘**：在关键价位挂大买单托住，防止崩盘，常见于增持、国家队、机构维持市值；
- **洗盘**：故意制造下跌或长时间横盘，把不坚定的散户震出去，再轻装拉升。

> 一句话：拉高是诱饵，砸盘是恐吓，护盘是托底，洗盘是清场。

## 2. 为什么重要

看懂这四个动作，才能判断“涨是真是假”：
拉高可能是出货前奏，砸盘可能是吸筹机会，护盘可能只是面子工程，洗盘常常出现在主升浪之前。
散户最经典的亏钱路线就是：拉高时追进去、砸盘时割在地板、洗盘时被震下车。

## 3. 怎么用 / 怎么看

单个动作没有意义，要把它们连起来读：

- **拉高 + 放量 + 利好满天飞**：警惕，很可能是出货，边拉边卖；
- **关键支撑缩量企稳、有人托**：更像是洗盘，浮筹清干净后还有行情；
- **护盘只说明“有人不想它跌”**：不说明“它会涨”，护盘资金一撤照样跌；
- **看成交量与换手率验证**：放量下跌是出货，缩量下跌是洗盘，量价结合才能定性。

> 一句话：先看量，再看位置，最后才谈主力意图。

## 4. 常见坑 / 误区

四个典型误区：

- **拉高就追**：追高买入往往正好接在出货位上；
- **洗盘当反转**：在洗盘里割肉离场，随后眼睁睁看它起飞；
- **以为护盘=稳赚**：护盘资金撤走，股价照样创新低；
- **分不清洗盘和出货**：关键看量价：洗盘缩量、出货放量；洗盘不破关键位、出货连支撑都放弃。
