# 限购 / 限贷 / 限售

> 限购限贷限售 = 楼市调控的三板斧：限制你"能不能买"、"能贷多少"、"多久才能卖"。买房前先对号入座。

## 1. 这是什么
- **限购**：限制买房资格。常见规则：本地户籍限套数、外地户籍需社保/个税年限、单身限购等。
- **限贷**：限制贷款条件。比如二套房首付比例提高、房贷利率上浮、限制第三套贷款。
- **限售**：限制卖出时间。买房后需持有一段时间（常见 2~5 年）才能转让，打击短期炒作。

## 2. 为什么重要
- 有没有购房资格，直接决定你能否上车：没资格，钱再多也买不了。
- 限贷直接影响首付和月供：二套房首付可能从 30% 跳到 60%，预算差一倍。
- 限售影响流动性：房子不是想卖就能卖，急用钱时可能被锁住几年。
- 政策随市场变化，各地松紧不同，买房前必须查当地最新规则。

## 3. 怎么用 / 怎么看
- 查资格：先确认自己有没有购房资格（户籍、社保年限、家庭套数），再谈看房。
- 算贷款：按当地限贷政策算首付比例和利率，评估自己扛不扛得住月供。
- 看限售：问清楚拿证后几年才能卖，想短期变现的人慎入。
- 关注政策变化：政策放松期（降首付、松限购）往往是上车窗口，收紧期则要谨慎。

## 4. 常见坑 / 误区
- 找"路子"破限购：假离婚、代持、伪造社保，都有法律和征信风险，别碰。
- 只看限购不看限售：买的时候便宜，卖的时候被锁住，资金被套好几年。
- 以为限贷只影响首付：还影响月供和总成本，利率上浮 1 个点，30 年多付十几万。
- 赌政策放松抄底：政策不可预测，用杠杆赌调控转向，风险极大。
