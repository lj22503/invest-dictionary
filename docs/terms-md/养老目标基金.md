# 养老目标基金

> 基金公司帮你打包好的养老专用基金组合，一键配置养老钱。

## 1. 这是什么

养老目标基金 = 基金公司专门为「养老」设计的基金，多数是 FOF（基金中的基金），买的是别的基金。

分两类：**目标日期型**（如「养老目标日期 2045」，随着 2045 年临近自动降低股票比例）和**目标风险型**（稳健/平衡/积极，风险水平固定）。在国家个人养老金制度下，这类产品还有专门的 Y 份额，可享税收优惠。

## 2. 为什么重要

大多数人既不会择时，也懒得每年调整股债比例。目标日期基金会自动执行**下滑轨道**：年轻时股票占 70%~80%，临近退休逐年降到 20%~30%。

再叠加个人养老金账户的税收优惠（缴费时税前扣除、投资收益暂不征税），等于用制度帮你强制储蓄。

## 3. 怎么用 / 怎么看

- **按退休年份挑**：2040、2045、2050，选离你退休最近的那一档。
- **看费率**：FOF 存在「双重收费」（管理费 + 底层基金费用），费率差 0.5%，长期影响不小。
- **看持有期**：多数要求持有 1~3 年以上，急用钱别买。
- **用个人养老金账户买**：可抵个税，Y 份额费率通常更低。
- **一年看一次就够**：它是长期配置工具，不适合天天盯盘。

## 4. 常见坑 / 误区

- **以为「养老」= 保本**：2022 年不少养老 FOF 也出现 10% 以上回撤。
- **双重收费吃掉收益**：长期看，费率的差距就是收益的差距。
- **买完短期就赎回**：有最短持有期，强行赎回代价高。
- **只买养老基金、不做整体配置**：它只是资产配置里的一块，不是全部。
- **忽略底层资产**：打开持仓看一看，别买到风格漂移的产品。
