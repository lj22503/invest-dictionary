# 第三方销售平台

> 支付宝、天天基金等持牌机构，代销基金并收取申购费，是普通人买基金的主要渠道。

## 1. 这是什么（在支付宝上买基金靠谱吗）

第三方销售平台 = 拥有**基金销售牌照**的机构（蚂蚁财富/支付宝、天天基金、京东金融等），代销全市场基金。它们不管理基金，只负责“卖”，靠申购费、管理费分成赚钱。

一句话：平台是“卖场”，不是“生产商”。

## 2. 为什么重要（为什么重要：费率便宜一半）

平台竞争把**申购费打到 1 折**（0.15% 左右），比银行柜台（1.5%）便宜 90%。平台还提供：基金排行、定投工具、持仓分析、投顾服务，大大降低普通人的选择成本。

一句话：同样的基金，平台买比柜台买便宜一大截。

## 3. 怎么用 / 怎么看（怎么用：选平台看三件事）

选平台三看：**持牌资质**（证监会官网可查基金销售牌照）；**费率**（申购费折扣、是否免申购费）；**服务**（是否有持仓诊断、定投计划、赎回提醒）。

一句话：平台选得好，一年省下几百块申购费。

## 4. 常见坑 / 误区（常见坑：平台推荐≠专业建议）

以为“平台推荐=专业建议”——首页推荐位很多是商业合作；在无牌照 App 上“买基金”——资金可能根本没进托管账户；看排行榜追热门——排行榜是后视镜；忽略平台对特定基金的倾向性（自家系基金优先展示）。

一句话：平台是工具，决策还得靠自己。
