# 对手方风险

> 你赚钱的前提是"对方还钱/履约"，对方赖账或倒闭，你赚的变亏的。

## 1. 这是什么

**对手方风险 = 交易对手不履行合约义务，给你造成损失的风险。**你买债券，对方到期不还钱；你做场外衍生品，对方违约不结算；你把钱存在银行，银行倒闭——这些都是对手方风险。

它和"市场风险"不同：市场风险是"行情亏了"，对手方风险是"人没了/不认账了"。

> 一句话：市场风险是行情跌，对手方风险是"说好给钱的人跑路了"。

## 2. 为什么重要

**对手方风险最怕的是"同时爆"：市场一乱，很多对手方一起违约。**2008 年雷曼倒闭，所有和它做交易的机构瞬间暴露对手方风险。

- 债券投资：信用债违约，本金损失可能远超预期；
- 场外衍生品：私募、非标产品承诺高收益，底层对手方跑路，血本无归；
- 券商/银行：选择持牌机构，有存款保险和投资者保护制度兜底；
- 个人借贷：把钱借给朋友、P2P 暴雷，本质都是对手方风险。

## 3. 怎么用 / 怎么看

- **看对手方信用**：债券看评级、看发债人经营；存款选纳入存款保险的银行；
- **控制单一对手方敞口**：别把所有钱押在同一个机构、同一个产品上；
- **看清算机制**：交易所场内交易有中央清算对手方（CCP）兜底，风险远低于场外；
- **个人层面**：大额借贷签协议、留凭证，小额借款做好"收不回来"的心理准备。

## 4. 常见坑 / 误区

- 坑1：把"高收益"当"低风险"。收益越离奇，底层对手方风险越大；
- 坑2：以为大机构不会违约。雷曼、包商银行都倒过，大不等于安全；
- 坑3：场外私下交易不看对手。和非持牌机构、个人做衍生品/借贷，出事难追责；
- 坑4：分散了但都买"同一个圈子"。看似分散，底层资产和对手方其实是同一拨人。
