# A类 / C类基金

> 同一只基金分 A 类和 C 类，收费方式不同：长期买 A 类划算，短期进出买 C 类划算。

## 1. 这是什么

很多基金名字后面带 A 或 C，比如"XX沪深300指数A"和"XX沪深300指数C"。它们其实是同一只基金、同一个基金经理、买同样的股票，唯一区别是收费方式。

A 类：买入时收一笔申购费（通常 0.1%-0.15%），持有期间不收销售服务费。

C 类：买入时不收申购费，但持有期间每天按年化约 0.4%-0.8% 收销售服务费。

> 一句话：A类=进门买票，C类=按天收费，同一个游乐场。

## 2. 为什么重要

选错类别，成本能差出几倍。尤其定投和短线交易，A/C 差异直接决定你实际到手收益。

按买入 10 万元、持有 1 年估算：A 类多付约 100-150 元申购费，C 类一年多付约 400-800 元销售服务费——持有越久，C 类越贵。

> 一句话：持有越久，C 类的销售服务费越不划算。

## 3. 怎么用 / 怎么看

**第 1 步**：判断计划持有时间。通常 1 年以内进出选 C，1-2 年以上选 A。

**第 2 步**：留意 A 类申购费有没有打折——互联网平台常 1 折，这时候"长期持有选 A"的临界时间会变短。

**第 3 步**：定投超过一年，无脑选 A 类通常更省。

**第 4 步**：在基金页面看"费率说明"，算清持有多少天 A/C 成本打平。

> 一句话：拿得久买 A，进出勤买 C，先看费率表再下单。

## 4. 常见坑 / 误区

**坑 1**：以为 A 和 C 是两只不同的基金，把同一基金买了两份。

**坑 2**：短期炒作买 A 类，一笔赎回费把利润全吃掉。

**坑 3**：以为 C 类"免费"——它只是把申购费拆成每天扣的销售服务费。

> 一句话：A/C 不是好坏之分，是时间长短的成本账。
