# 因子投资（价值/质量/小市值）

> 因子投资 = 按"某种股票的共同特征"批量买入，比如便宜的、赚钱质量高的、盘子小的。它买的不是某只股票，而是一类规律。

## 1. 这是什么
学术研究发现，某些特征的股票长期更容易跑赢市场，这些特征就叫"因子"。

- **价值因子**：买便宜的股票（低市盈率、低市净率），赌估值回归。
- **质量因子**：买赚钱质量高的公司（高 ROE、低负债、盈利稳定），少踩雷。
- **小市值因子**：买市值小的股票，历史上小盘股长期有超额收益（但波动也大）。

## 2. 为什么重要
- 因子投资把"选股"变成"按规则筛选"，可复制、不靠运气。
- 指数基金里的"红利指数""低波指数""300 价值"等，底层就是因子策略。
- 对普通人来说，与其天天追热点，不如用因子逻辑选"一篮子"股票或指数基金，分散风险。

## 3. 怎么用 / 怎么看
- 新手入门：买跟踪因子的指数基金（如红利指数、价值风格 ETF），别自己逐个筛股。
- 进阶做法：用估值指标（PE、PB）在同类股票里选便宜的前 20%，定期再平衡。
- 组合搭配：价值 + 质量 + 小市值搭配，避免单一因子失效期全仓挨打。
- 长期持有：因子溢价需要时间兑现，3~5 年为周期看待，别按月评判。

## 4. 常见坑 / 误区
- 因子会"失效"：价值因子可能几年不涨，此时很多人放弃，恰好在底部割肉。
- 小市值是双刃剑：涨起来猛，跌起来也凶，还可能有退市风险。
- 把因子当"圣杯"：因子是概率优势，不是必胜公式，单年可能跑输市场。
- 频繁换因子：看到哪个因子涨得好就换过去，永远买在高点。
