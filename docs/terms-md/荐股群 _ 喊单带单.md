# 荐股群 / 喊单带单

> 荐股群/喊单带单 = 骗子组建“股神群”，用晒盈利截图、喊单带操作制造赚钱假象，再以会员费、服务费、跟单费或让你接盘的方式收割。

## 1. 这是什么

群里几十上百人，除了你几乎全是托：老师晒盈利截图，托们刷“已跟上”“又赚了”“感谢老师”。

接下来套路分三步：让你交几千上万的**会员费/服务费**；让你下载“专属交易软件”（往往是假盘）；偶尔推荐的“牛股”，可能是他们提前买入、等散户抬轿出货的。

> 一句话：真正的投资高手没空拉你进群喊单。

## 2. 为什么重要

这类骗局不一定要你一次亏光，而是温水煮青蛙：先收“服务费”落袋，再让你在假平台亏掉本金，两头通吃。

正规证券投资咨询需要**证监会牌照**，合法机构绝不会拉你进微信群喊单带单——凡是群里“稳赚不赔”“内幕消息”的，都是违法的。

> 一句话：荐股群不生产财富，只生产“接盘侠”。

## 3. 怎么用 / 怎么看

**一查资质**：证监会官网可查合法证券投资咨询机构与人员名单。

**二查平台**：开户、入金只能在正规券商/期货公司，凡让你下不明 App 充值的一律是坑。

**三查套路**：任何“保证收益、稳赚不赔、带你翻倍”的说法都违反证券法。

想明白一句：真有稳赚的策略，人家凭什么 99 元卖给你？

> 一句话：查资质、查平台、查套路，三查之后骗子现形。

## 4. 常见坑 / 误区

**坑 1**：看到“老师昨天推荐的票今天涨停”就心动——截图可以 P，蒙对的概率可以吹。

**坑 2**：以为“老师不收费、只分成”就安全——分成的时候，你的本金已经在对方控制的平台里了。

**坑 3**：把正规分析师公开发表的观点当“带单信号”——公开观点≠带你操作，更不会向你收费。

> 一句话：记住：带你赚钱的人不会要你的钱，要你钱的人不会带你赚钱。
