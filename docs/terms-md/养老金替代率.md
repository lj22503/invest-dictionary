# 养老金替代率

> 养老金替代率是退休后每月养老金 ÷ 退休前工资，衡量“退休后生活质量打几折”。

## 1. 这是什么

替代率是个简单到不能再简单的数字：
退休后每月到手养老金 ÷ 退休前每月工资。替代率 100%＝退休前后生活水平不变；70% 是国际通行的警戒线，低于它生活质量会明显下降；我国职工养老金的平均替代率近年约 40%-45%，很多人的实际数字更低。

> 一句话：替代率是退休生活质量的“打折力度”。

## 2. 为什么重要

退休后收入骤降，但支出不会跟着骤降：吃穿住行、看病吃药、人情往来，一样不少。
只靠社保养老金，替代率不到 50% 的话，退休生活质量大概率“跳水”——年轻时存下的钱，才是退休生活的真正底气。

## 3. 怎么用 / 怎么看

三步给自己算账：

- **算目标替代率**：目标 70%-80%：退休后维持体面生活，替代率要尽量接近这个区间；
- **算缺口**：预计养老金替代率 45%，缺口就是 25-35 个百分点，需要自己补；
- **补缺口**：个人养老金账户（每年 1.2 万额度且有税收优惠）、养老目标基金、商业养老保险、长期定投，越早开始复利越给力。

> 一句话：社保打底，自己补差，替代率才能从 45% 提到 70% 以上。

## 4. 常见坑 / 误区

四个典型误区：

- **以为交了社保就有保障**：替代率逐年承压，只靠社保大概率不够；
- **只算养老金总额，不算替代率**：同样的养老金，工资高的人替代率低，生活质量掉得更狠；
- **把个人养老金当存款**：它也是投资，会波动，别当成稳赚的理财；
- **退休前才着急补**：退休前十年才开始，复利差距已经拉得很远了。

**相关词条**：社保养老金（现收现付制）、养老目标基金、商业养老保险、FIRE（财务独立提前退休）
