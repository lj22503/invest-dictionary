# 茅指数 / 宁组合

> A 股两类风格资产的代名词：茅指数代表消费白马，宁组合代表成长赛道，是观察市场审美切换的镜子。

## 1. 这是什么

### A 股两派风格的名片

**茅指数 = 以贵州茅台为代表的核心资产，多为消费、医药等商业模式稳定的龙头白马；宁组合 = 以宁德时代为代表的成长赛道，多为新能源、半导体等高景气行业龙头。**

它们不是官方指数，而是市场约定俗成的观察标签：茅指数买的是「确定性」，宁组合买的是「成长性」。

一句话：茅指数是「稳稳的幸福」，宁组合是「高歌的猛进」。

## 2. 为什么重要

### 为什么重要：市场审美的钟摆

2019—2021 年，资金抱团茅指数，核心资产估值冲到天上；2021 年后风格转向宁组合，新能源接棒；2022 年两者一起回调。两股力量的此消彼长，就是 A 股市场风格的晴雨表。

看懂它，你能知道当下市场在「求稳」还是在「追梦」——这直接决定了买消费白马还是买成长赛道更占便宜。

一句话：茅指数和宁组合的强弱，是 A 股审美钟摆的刻度。

## 3. 怎么用 / 怎么看

### 怎么用：拿它当风格温度计

**看强弱对比**：茅指数持续跑赢宁组合，说明市场避险情绪重，偏好确定性与现金流；反之则说明风险偏好高；**看成分股构成**：茅指数里消费、医药权重高，宁组合里新能源、半导体权重高，先看清再下判断；**配合估值看**：风格极致时（如茅指数市盈率到 40 倍以上）往往就是风格切换的前夜；**用于定投分散**：两种风格的基金各配一部分，避免单押一边。

## 4. 常见坑 / 误区

### 常见坑：追高抱团

**追高抱团**：2021 年初买茅指数、2021 年末追宁组合的人，都站在了高点；**把标签当基本面**：一只股票进了茅指数不代表永远是好公司，成分股会调整；**忽视估值**：再好的资产，买贵了也是坏投资；**死守一端**：风格切换时还在重仓旧风格，会眼睁睁看着别人赚钱；**误以为「组合」是基金**：茅指数/宁组合是观察指标，不是可以直接申购的产品。
