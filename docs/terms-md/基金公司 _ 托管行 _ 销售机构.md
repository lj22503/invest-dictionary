# 基金公司 / 托管行 / 销售机构

> 一只基金背后三家机构：基金公司管投资，托管行管钱，销售机构管卖。

## 1. 这是什么（一只基金背后的三家公司）

**基金公司**（管理人）：负责投资运作，基金经理属于它。**托管行**（托管人）：通常是银行，负责保管基金资产、监督基金公司（钱不在基金公司手里）。**销售机构**：银行/券商/第三方平台，负责把基金卖给你。

一句话：管钱的、管投资的、管卖的各是各，谁也不越位。

## 2. 为什么重要（为什么重要：钱在谁手里，亏了找谁）

这个三角结构是公募基金**“不敢跑路”的制度基础**：资金在托管行，管理人只能下指令不能碰钱。买基金时看三件事：

一句话：钱在托管行，亏了找管理人，买贵了怪销售渠道。

## 3. 怎么用 / 怎么看（怎么看：分清各自的职责）

基金合同里会写明**“管理人/托管人/销售机构”**三方的名称。

一句话：买基金前，先翻合同认三个人。

## 4. 常见坑 / 误区（常见坑：把销售员当基金经理）

以为“钱在基金公司手里”——实际在托管行；以为“托管行=包赚”——托管只保证资金安全，不保证收益；只看“明星基金经理”不看公司治理；在非正规平台买基金（第三方平台也要有基金销售牌照）。

一句话：分清三方职责，才能分清责任和风险。
