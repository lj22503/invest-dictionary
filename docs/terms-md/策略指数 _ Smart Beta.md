# 策略指数 / Smart Beta

> 按"聪明规则"（低波动、红利、价值等）挑股票编成的指数，比普通指数更"带脑子"，也叫聪明贝塔。

## 1. 这是什么

**策略指数 = 不按市值大小、而是按某种投资规则（红利、低波、价值、质量、成长等）挑选和加权股票编制的指数；Smart Beta = 它的英文叫法，直译"聪明贝塔"。**普通指数（如沪深 300）按市值加权，等于"谁大买谁"；策略指数则按规则加权，比如红利指数只选高股息股票、按股息率加权，低波指数选波动小的股票。它介于主动基金和被动指数之间：规则透明、费率低，但又能"定制"某种风格暴露。> 一句话：策略指数=给指数装上规则引擎，不用基金经理也能"选股"。

## 2. 为什么重要

它回答了"被动投资会不会太笨"的问题：完全按市值的指数在泡沫期会越涨越买贵，而策略指数通过规则天然规避一些风险。最典型的是红利低波指数——长期跑赢沪深 300，回撤更小，成为近年"资产荒"下最火的配置方向。对普通人，策略指数基金是把"机构级选股规则"平民化：花指数基金的钱，拿到接近主动基金风格的效果，是资产配置里"可解释、可预期"的增强工具。> 一句话：Smart Beta 想让你"既要指数便宜，又要规则聪明"。

## 3. 怎么用 / 怎么看

- **看清规则因子**：红利（股息率高）、低波（波动小）、价值（估值低）、质量（盈利好），不同因子适合不同市况。
- **看指数编制方案**：样本怎么选、权重怎么算、调仓频率多少，决定策略的实际暴露，别只看名字。
- **搭配使用**：红利低波适合防守，成长因子适合进攻；把策略指数当组合的"风格卫星"配置。
- **对比超额来源**：看策略指数相对宽基的超额收益是否长期稳定，别被单一年份的爆发迷惑。
- **关注费率与跟踪误差**：Smart Beta 产品费率通常略高于普通指数基金，但远低于主动基金，跟踪误差别太大。> 一句话：选策略指数先问三件事——什么因子、怎么加权、贵不贵。

## 4. 常见坑 / 误区

- **以为 Smart Beta = 稳赚**：任何因子都有失效期，红利指数在成长牛市中会大幅跑输。
- **把"策略指数"和"主动基金"混为一谈**：规则是透明的、不会换基金经理，但也没有"人"帮你避坑。
- **只看名字不看编制**：两个"红利指数"可能选股完全不同，收益差几个点很正常。
- **因子拥挤时追高**：某因子被资金追捧后估值抬升，未来超额收益反而下降，别在热门时重仓。> 一句话：Smart Beta 的"聪明"是规则的聪明，不是包赚的聪明。
