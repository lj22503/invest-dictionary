# 黄金分割 / 斐波那契

> 斐波那契回调线 = 用 0.382、0.5、0.618 这些"黄金比例"画出来的支撑位和压力位。

## 1. 这是什么

斐波那契数列（1、1、2、3、5、8、13……）里相邻两项的比值越来越接近 **0.618**，衍生出 0.382、0.5、0.618、1.618 等"黄金比例"。交易软件里的画线工具，把一段行情的高低点按这些比例分割，用来预判回调到哪里会企稳、反弹到哪里会受压。

## 2. 为什么重要

它是技术分析里流传最广的"心理价位"工具：全球大量交易者都盯着 0.618 这个位置，大家都在同一个价位挂单，就容易形成**自我实现的支撑与压力**。配合趋势、成交量使用，比单看裸 K 线多一个参考维度。

## 3. 怎么用 / 怎么看

- 先选一段**明显的上升或下跌波段**，从低点画到高点（或反过来）
- 重点看 **0.382 / 0.5 / 0.618** 三档回撤位
- 价格在 0.618 附近**放量企稳** = 强支撑，可以观察入场信号
- 放量**跌破 0.618** = 趋势可能反转，别死扛

## 4. 常见坑 / 误区

- 把斐波那契当预测神器——它是概率工具，不是定理
- 起点终点乱画，同样的图能画出完全不同的结论
- 在震荡市里用它等于抛硬币，只有在趋势行情里才有意义
- 只看画线不看基本面，忘记"支撑位"也可能被一根消息击穿
