# 证券私募（阳光私募）

> 证券私募是面向少数有钱人的基金：100 万起投、玩法更自由，业绩分成也更高，普通人一般够不着。

## 1. 这是什么

**合格投资者的“私人订制”基金**

- **证券私募（阳光私募）＝非公开募集的证券投资基金**，主要投股票、债券、期货等二级市场品种；
- 门槛高：金融资产 300 万以上或近三年年均收入 50 万以上，单只产品**起投 100 万元**；
- 收费猛：普遍“2% 管理费＋20% 业绩提成”，净值创新高才有提成（高水位线）；
- 限制少：可做对冲、加杠杆、集中持仓，仓位和策略比公募灵活得多。
> 一句话：公募是大众食堂，私募是高端包间——包间收费贵，但菜式自由，还只招待“够资格”的客人。

## 2. 为什么重要

**你听到的“大神基金经理”，很多在私募**

- 明星基金经理“奔私”后操盘私募，策略更激进也更能打，但产品净值波动可能大得吓人；
- 私募是观察市场聪明钱的窗口：多空对冲、量化高频、宏观策略等玩法都在这里；
- 对普通人的意义：销售渠道会拿“私募同款策略”包装公募或资管产品，得会识别“同款”是不是真同款。
> 一句话：私募决定了很多“明星策略”的上限，也定义了普通投资者够不着的天花板。

## 3. 怎么用 / 怎么看

- **先验合格投资者身份**：达不到门槛就别碰，代持、拼单、凑钱买私募都是踩红线；
- **看历史回撤和最大亏损**：别只看累计收益，要看极端行情下的最大回撤和修复时间；
- **看管理人真实业绩**：查基金业协会备案信息，别信销售嘴里的“年化 30%”；
- **看清收费结构**：管理费＋业绩提成＋赎回费，算清楚 20% 提成对净收益的侵蚀。

## 4. 常见坑 / 误区

- **把“私募”当“更高级更安全”**：私募产品信息少、流动性差（常有锁定期），风险未必比公募低；
- **听信“保本”“兜底”话术**：私募不允许承诺保本，凡是承诺高收益保本的十有八九是伪私募/非法集资；
- **以为 100 万能分散**：100 万只够买 1—2 只产品，集中度风险反而比买公募高；
- **忽略高水位线的陷阱**：净值大跌后再创新高才提成，但“提成 20%”照样会磨平你的大部分超额收益。
