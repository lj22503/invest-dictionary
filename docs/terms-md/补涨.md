# 补涨

> 龙头涨完，同板块还没涨的“落后生”跟上来——板块行情进入后期的信号。

## 1. 这是什么

**补涨，是同一板块/同一逻辑里，龙头股涨完后，还没涨的“落后生”跟着涨上来**。

逻辑很简单：板块行情启动，龙头股率先大涨，龙头太贵后，资金溢出寻找“同逻辑但便宜”的股票——滞涨的同板块股票被买起来，就是补涨。

典型场景：新能源行情里，电池龙头翻倍后，设备、材料等二线股开始跟涨；白酒行情里，茅台五粮液涨完后，区域酒企补涨。


## 2. 为什么重要

轮动行情有固定节奏：**先龙头、后二线、再补涨**。当补涨出现，往往意味着这个板块的行情进入后期——能涨的差不多都涨过了。

对普通人的两层价值：

- 参与价值：补涨是“可参与但别恋战”的机会——肉比龙头少、风险在积累
- 警示价值：龙头高位滞涨 + 滞涨股补涨，是板块热度接近尾声的警告信号，此时再追高容易站岗


## 3. 怎么用 / 怎么看

- 条件 1：同板块龙头已经明显上涨，行情还在强势期
- 条件 2：目标股与龙头“同源”——同一个题材、同一产业链、估值不高
- 条件 3：股价还没怎么动、开始放量异动——异动当天往往是补涨起点
- 纪律：补涨股涨幅接近龙头涨幅时，就该走了——补涨的空间本来就有限


## 4. 常见坑 / 误区

- 坑 1：把补跌当补涨——板块退潮时，滞涨股会“补跌”，走势同样是从没涨到跌
- 坑 2：龙头已走弱还去做补涨——补涨的前提是板块还在强势，龙头倒了，补涨就没了
- 坑 3：随便选一只“没涨的”——没涨也可能是有硬伤（基本面差、有雷）
- 坑 4：补涨股追高——补涨本身空间有限，追高很容易变成站岗
