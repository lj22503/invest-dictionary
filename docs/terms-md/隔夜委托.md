# 隔夜委托

> 隔夜委托 = 收盘后把买单/卖单提前挂到第二天，让券商帮你"排队"。排得越早，次日开盘成交越有优势。

## 1. 这是什么

隔夜委托（也叫夜市委托），是指**当天收盘后（通常晚上 20:00 或 21:00 之后）把委托单挂进去，券商在次日开盘前统一报给交易所**，参与次日的集合竞价。

关键点：

- **不是"现在就能成交"**：委托只是"排队"，真正撮合要等次日开盘；
- **券商有截止时间**：每家券商开放时间不同（有的 20:00，有的 21:00，周日晚上也能挂周一的单）；
- **撤单限制**：部分券商次日 9:20 前可撤，9:20-9:25 不能撤，撤单规则要看清；
- **作用**：想按开盘价第一时间买入/卖出（比如抢涨停、挂跌停出逃），隔夜委托能排在前面。

> 一句话：隔夜委托 = 提前排队，第二天开盘帮你抢"第一班车"。

## 2. 为什么重要

**隔夜委托解决的是"抢时间"和"抢价格"的问题**：

- **抢筹/抢跑**：利好出来后，想次日开盘就买入，隔夜委托能让你排在大量"开盘才下单"的投资者前面；
- **应对极端行情**：跌停预期下想尽早卖出，隔夜挂跌停价卖出，按"时间优先"原则更容易成交；
- **避免早起盯盘**：挂好单就去睡觉，第二天开盘自动参与竞价，不用 9:15 爬起来操作；
- **A 股特有机制**：A 股开盘价由集合竞价决定，9:15-9:25 撮合，隔夜委托能提前进入竞价队列。

**真实场景**：某股隔夜出重大利好，小陈担心第二天一字板买不到。当晚 22:00 用券商 App 挂了涨停价买单，第二天开盘果然一字涨停，他的委托因排得早顺利成交。没挂隔夜单的只能干瞪眼。

## 3. 怎么用 / 怎么看

- 第一步：确认券商**隔夜委托开放时间**（一般在券商 App 的"交易-夜市委托"里查看），晚上 20:00/21:00 后即可挂单；
- 第二步：明确委托类型——想"开盘就买/卖"，用**限价单**挂目标价；想"一定成交"，按涨跌停价挂；
- 第三步：算好价格——挂涨停价买入是按**开盘价成交**（不会真的付涨停价），但要注意开盘瞬间的价格；
- 第四步：记住**撤单时间窗口**——9:15-9:20 能撤，9:20-9:25 不能撤，挂错单要趁早撤；
- 第五步：大额资金慎用隔夜挂跌停/涨停——极端价格委托可能被"钓鱼单"影响，先看集合竞价走势再决定。

> 一句话：隔夜委托 = 提前排队抢竞价，注意撤单窗口和价格风险。

## 4. 常见坑 / 误区

- **坑 1：以为挂涨停价买=按涨停价成交**：限价单只保证"不高于你的挂价"成交，开盘价低就按低的开盘价成交；
- **坑 2：忘记撤单时间**：9:20 之后撤不了，挂错价格只能等开盘自己吃哑巴亏；
- **坑 3：把隔夜委托当"保证成交"**：如果开盘直接跌停且卖单堆积，挂买单也可能排不上；
- **坑 4：忽略券商开放时间**：有的券商晚上 20:00 才开，有的 21:00，周日晚上也能挂周一的单，别在 19:00 就傻等；
- **坑 5：习惯性隔夜挂单**：没明确计划就天天挂隔夜单，容易冲动交易，还可能在竞价阶段被大单误导。
