# 摊余成本法

> 把买入时的折价溢价摊到每一天，让净值“天天涨一点”——货币基金看起来很稳的估值方法。

## 1. 这是什么

**摊余成本法 = 以买入成本为基础，把债券的折价或溢价按剩余期限平均摊销，每天确认金额接近的利息收益，而不是按每天的市场价重新估值。**

举例子最直观：用 99 元买一张一年后还本 100 元的债券，摊余成本法不是“今天 99、明天 98”地跟着市场跳，而是把那 1 元收益摊到每一天，净值看起来每天稳定增加一点点。

和它相对的是市值法：每天都按市场价重新估值，价格涨跌立刻反映在净值里。绝大多数债券基金和净值型理财用的是市值法。

> 一句话：摊余成本法让净值走直线，市值法让净值跟着市场走曲线。

## 2. 为什么重要

货币基金长期给人“每天涨一点、几乎不亏”的印象，关键之一就是摊余成本法，再配合“影子定价”做偏离度监控，净值不会因为债券价格的日常波动而上下跳。

代价是波动被平滑而非消失：如果市场利率大幅上行、持仓债券的真实市价低于摊余成本，偏离度就会扩大，超过阈值需要调整。

2022 年 11 月债市调整时，大量理财产品净值回撤并引发赎回，被普遍认为与净值化后用市值法、波动显性化有关——这正是两种估值方法差异的现实注脚。

> 一句话：摊余成本法是波动平滑器，不是风险消除器。

## 3. 怎么用 / 怎么看

- 看产品说明书：明确写的是摊余成本法还是市值法，货币基金、现金管理类产品多以摊余成本法为主。

- 看适用范围：资管新规之后，摊余成本法的使用被严格限制，主要用于货币基金、现金管理类产品以及符合条件的特定产品。

- 看净值曲线形态：几乎不波动的平滑曲线，通常意味着用了摊余成本法或类似的摊平处理。

- 看偏离度披露：定期报告会披露影子定价与摊余成本的偏离情况，这是判断风险的关键材料。

> 一句话：想知道产品稳不稳，先看它怎么写估值方法。

## 4. 常见坑 / 误区

- 当成保本：它只平滑波动，不承诺不亏，极端行情下仍会出现负偏离。

- 忽略赎回节奏风险：利率上行时集中赎回，压力会传导给留下的持有人。

- 以为“稳健理财”都是市值法：口径不同，收益表现差异很大。

- 只盯七日年化：货币基金收益随资金面波动，短期高收益不代表长期稳定。

- 把平滑曲线当无风险：曲线越平滑，越要看清楚底层资产和偏离度控制机制。
