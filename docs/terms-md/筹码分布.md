# 筹码分布

> 筹码分布 = 一张图，看"股票在各个价位上被多少人握着"，帮你猜主力成本和散户成本。

## 1. 这是什么

把历史上每一笔成交按价格"堆"起来，就得到一座座山峰状的分布图：某个价位堆得越高，说明在这个价位买入并一直持有的人越多。软件里常配套看三个数：**获利盘比例、平均成本、90% 与 70% 成本区间**。

## 2. 为什么重要

股价涨跌的本质是筹码换手。筹码分布能直观看出：主力的大概成本区在哪、上方套牢盘重不重、下方获利盘会不会随时砸盘。它是判断"支撑位 / 压力位"的经典辅助工具。

## 3. 怎么用 / 怎么看

- **底部密集峰 + 股价站上峰顶** = 趋势转强，筹码从低位锁住
- **顶部密集峰 + 股价跌破** = 套牢盘压制，反弹容易受阻
- 看**获利比例**判断市场情绪：获利盘极高时注意止盈抛压
- 一定要结合**换手率和成交量**看，单纯一张图容易误读

## 4. 常见坑 / 误区

- 把筹码分布当精确数据——它是估算模型，不同软件算出来不一样
- 只看分布不看量价，容易得出相反结论
- 以为"筹码集中 = 主力控盘"，也可能是散户在某个价位扎堆
