# 发起式基金

> 基金公司自己掏钱、跟持有人一起买的那类基金：利益绑定更紧，但别把它当"保本"。

## 1. 这是什么

**发起式基金 = 基金公司（或其股东、高管）用自有资金认购不少于 1000 万元、且锁定 3 年以上的基金。**普通基金靠外部投资者募集成立，发起式基金则是"基金公司带头买"，用真金白银表示"我跟你一起扛"。它的成立门槛更低（募集规模满 5000 万、认购人数满 200 人即可），但为了激励公司管好钱，发起资金要锁 3 年。> 一句话：发起式基金=基金经理和公司先把钱放进去，跟你坐同一条船。

## 2. 为什么重要

它缓解了基金行业一个老大难问题——"基金公司赚管理费，亏的是基民"。发起式基金把公司的钱和基民的钱绑在一起：公司要亏，先亏自己的 1000 万。历史上发起式基金多用于新产品、创新产品（如养老目标基金、ETF 联接）或冷门方向，公司用"自购"给市场信心。对投资者来说，它是判断"公司有没有诚心做这只产品"的参考信号之一，但注意：它只是"态度承诺"，不是收益保证。> 一句话：发起式基金是基金公司的"投名状"，代表态度，不代表结果。

## 3. 怎么用 / 怎么看

- **查发起资金**：基金公告或招募说明书里看"发起资金金额""持有期限"，确认是真金白银锁定 3 年。
- **作为辅助信号**：公司自购+高管跟投的产品，利益绑定更深，可作为选基的加分项，但不是唯一依据。
- **关注规模与清盘风险**：发起式基金若规模长期做不起来，3 年后可能触发清盘，留意基金规模变化。
- **警惕"发起式"营销话术**：别因为"公司自购"就重仓，仍要看基金经理能力、业绩、回撤。> 一句话：把"公司自购"当参考之一，别当买入理由。

## 4. 常见坑 / 误区

- **以为"自购=不会亏"**：发起资金是公司愿赌服输，基金照样可能大幅亏损，1000 万对公司是小钱。
- **忽略 3 年锁定期的含义**：发起资金 3 年后可以赎回，那时公司可能"撤退"，利益绑定是有期限的。
- **被"发起式"标签吸引而忽略业绩**：一只烂基金无论谁自购都救不了，业绩才是硬道理。
- **把发起式当"稀缺"**：发起式只是成立方式的区别，市场上此类产品并不少，别被稀缺感误导。> 一句话：投名状只代表诚意，投资还是要看成绩单。
