# 顺周期 / 逆周期

> 跟着经济一起涨跌的行业叫顺周期，经济越差它越稳的行业叫逆周期。

## 1. 这是什么

- **顺周期行业**：业绩与经济景气同向波动。经济好，它赚得盆满钵满；经济差，它最先受伤。典型：钢铁、煤炭、有色、化工、地产、券商、航空
- **逆周期行业**：需求刚性、与经济关联弱，经济差时也相对稳定。典型：医药、必需消费（食品饮料）、公用事业（水电燃气）、教育医疗

注意"逆周期"不等于"经济越差它越赚"，更多是"抗跌"而非"反涨"。

## 2. 为什么重要

- **决定你持仓的波动大小**：顺周期股弹性大，牛市翻倍、熊市腰斩；逆周期股温吞，但熊市里是避风港
- **决定资产配置方向**：经济复苏初期配顺周期（弹性大），经济衰退期配逆周期（防御强）
- **影响政策与投资逻辑**：政策"逆周期调节"（经济差时放水基建）会直接利好基建、建材等顺周期方向
- **帮助你理解基金风格**：主动基金的行业配置，本质上就是在顺周期和逆周期之间做切换

## 3. 怎么用 / 怎么看

- **判断所处周期位置**：PMI、社融、PPI 回暖 → 加配顺周期；指标走弱 → 减顺周期、加防御
- **看盈利弹性**：顺周期行业在经济拐点处业绩弹性最大，也最考验择时
- **组合搭配**：顺周期（进攻） + 逆周期（防守）按比例配置，比单一押注更稳
- **关注政策信号**：财政发力、降准降息往往是顺周期行情启动的号角

## 4. 常见坑 / 误区

- **把"逆周期"当"永远涨"**：公用事业、医药也有估值泡沫，逆周期只是波动小，不是稳赚
- **在周期顶部追顺周期**：经济最热时顺周期股估值最高，恰恰是风险最大的时候
- **忽略行业内部差异**：同是消费，高端白酒是顺周期、必需食品是逆周期，不能一刀切
- **频繁切换**：判断周期拐点很难，来回切换容易两头挨打，不如定好比例长期持有
