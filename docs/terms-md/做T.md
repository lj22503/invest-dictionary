# 做T

> 做T是在T+1规则下，用手里已有的底仓“当天先买后卖”或“先卖后买”，一天内赚差价。

## 1. 这是什么

A 股实行 T+1：当天买入的股票，次日才能卖出。
但如果你手里已经持有某只股票（叫底仓），就能变出“T+0”效果：

- **正 T（低买高卖）**：当天股价回落时加仓买入，冲高后卖出等量的旧仓，一买一卖赚差价；
- **反 T（高卖低买）**：当天股价冲高时先卖出底仓，跌下来再买回等量，同样赚差价；
- **半仓做 T**：手里留一半仓位不动，另一半来回做 T，持仓总量不变。

> 一句话：做T不是加仓也不是减仓，是让同一份仓位一天多赚几次差价。

## 2. 为什么重要

做T的价值在于降低持仓成本：
套牢时通过反复做 T，成本能一点一点降下来；强势股一天波动 2%-3%，一年积累下来很可观。
但反过来说，做T失败=成本越做越高、仓位越做越乱，是技术活不是躺赚。

## 3. 怎么用 / 怎么看

新手做T，先记住四条纪律：

- **只做熟悉的票**：不熟波动规律，做T等于赌博；
- **只动小仓位**：每次用 1-3 成仓做T，错了不伤筋骨；
- **看分时找买卖点**：分时均线、支撑位、压力位是参考锚点；
- **T单不过夜**：做T是短线，别把T单做成加仓长线。

> 一句话：先算好手续费，再谈赚差价；T飞了要认错，不追不扛。

## 4. 常见坑 / 误区

四个高频翻车点：

- **忽略交易成本**：佣金+印花税来回一趟约千分之一点几，T 得越勤，费用越高；
- **T飞了不敢认**：卖飞后看着它涨，心态崩了追高；
- **把做T变加仓**：买回的数量超过卖出数量，T着T着仓位失控；
- **单边下跌还做T**：一路下跌一路接刀，成本越T越高。
