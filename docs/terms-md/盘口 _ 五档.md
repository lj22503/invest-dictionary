# 盘口 / 五档

> 盘口是股票的“实时交易窗口”，五档就是买卖双方各挂出的五档价格和手数——看盘的起点，也是被忽悠的起点。

## 1. 这是什么

**买卖双方的实时报价单**

- **盘口＝股票分时交易界面上的实时数据**，核心是“五档”：买一至买五、卖一至卖五的委托价和委托量；
- 五档反映“此刻想买的人出到什么价、想卖的人挂到什么价”，是市场短期供需的直接呈现；
- 配合看：现价、成交量、内外盘、大单，构成盘口的完整信息。
> 一句话：五档是交易所柜台上的“排队清单”，买的人和卖的人各排五队，量大的队占上风。

## 2. 为什么重要

**短线交易的“战场地图”，也是庄家“化妆”的地方**

- 挂单、撤单、大单进出是主力操盘的常用手段，五档可以**“画”出来**给你看；
- 买一买二堆大买单（托单）未必真买，可能是诱多；卖一卖二挂大卖单（压单）未必真卖，可能是吓人；
- 对普通投资者：盘口适合辅助判断日内情绪，但**把它当预测工具，容易被主力反利用**。
> 一句话：盘口是主力给散户看的“前台”，真实意图往往藏在撤单和成交明细里。

## 3. 怎么用 / 怎么看

- **看“垫单”是否真实**：大托单迟迟不成交、反复撤单重挂，多半是表演；
- **结合成交量看**：五档挂单配合放量/缩量才有意义，无量时挂单再多也说明不了趋势；
- **区分内外盘**：主动买成交（外盘）多代表买方积极，主动卖成交（内盘）多代表卖方占优；
- **盘口信号只做参考**：日内波动大，别拿五档的瞬时挂单当买入依据，趋势判断要靠更长时间框架。

## 4. 常见坑 / 误区

- **以为大买单就是“主力买入”**：主力常用“挂大单—撤单—再挂”制造买盘假象，真正的买入藏在成交明细；
- **盯盘口做短线决策**：五档信息转瞬即逝，普通人的网速和手速都拼不过量化资金；
- **被“封单巨大”骗上车**：涨停板封单大不等于明天还能涨，撤单式“开板”反而套人；
- **忽略盘口之外的更大逻辑**：基本面、情绪、政策都比五档挂单重要，别为芝麻丢了西瓜。
