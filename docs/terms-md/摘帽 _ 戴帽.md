# 摘帽 / 戴帽

> 帽子上写的是"风险警示"，摘帽不等于好公司。

## 1. 这是什么

**戴帽，是交易所对公司股票实施风险警示——简称前加 ST（其他风险警示）或 *ST（退市风险警示）；摘帽，是问题消除后申请撤销这一警示。**

- **常见戴帽原因**：财务指标不达标（如净利润为负且营业收入过低）、审计意见非标、资金被占用、违规担保、内控被否
- **\*ST 与 ST 的区别**：\*ST 是退市风险警示，离退市更近；ST 是其他风险警示，多数还没到退市边缘
- **摘帽的前提**：导致警示的问题实质性消除，并经交易所审核同意

> 一句话：摘帽只说明"问题解决了"，不说明"生意变好了"。

## 2. 为什么重要

- **它改变交易规则**：主板 ST、\*ST 股票日涨跌幅通常为 5%，波动被压缩，风险没有减少
- **它改变资金资格**：部分机构、两融账户、指数基金不能或不愿持有，流动性会变差
- **它是情绪的放大器**：摘帽常被当成题材炒作，戴帽则常引发连续跌停
- **对公司的意义**：戴上帽子后，再融资、并购、股权激励都受限制，翻身难度更大

## 3. 怎么用 / 怎么看

- **先分清类型**：\*ST 看退市风险，ST 看其他风险，处理难度完全不同
- **读公告原文**：警示原因、整改要求、时间节点，都写在交易所公告里
- **看利润质量**：靠卖资产、政府补助、债务重组实现"扭亏"的，摘帽后容易再次戴帽
- **看时间窗**：年报披露季是戴帽与摘帽的高发期，提前了解规则比事后追消息有用
- **看流动性**：摘帽前后成交量往往剧烈变化，别用重仓去接这种波动

## 4. 常见坑 / 误区

- **赌摘帽行情**：预期兑现即卖出，"利好出尽"最常发生在这里
- **把摘帽当基本面改善**：帽子摘了，生意未必变好
- **忽略非经常性损益**：靠一次性收益扭亏，下一年度可能重新亏损
- **混淆撤销警示与撤销退市风险**：有的只是"摘星"，风险等级只降一级
- **忽视退市整理期**：真触发退市后，流动性和价格都会断崖式变化
- **不更新规则**：风险警示与退市规则多次修订，判断前务必看最新口径
