# 资本充足率

> 资本充足率 = 银行自己的“本钱”能扛住多少坏账损失的安全线，是监管的硬指标。

## 1. 这是什么

**资本充足率 = 银行自有资本 ÷ 风险加权资产**，衡量银行用自有本钱吸收损失的能力。监管划了三档底线：核心一级资本充足率 ≥ 5%、一级资本充足率 ≥ 6%、总资本充足率 ≥ 8%（系统重要性银行要求更高）。

场景：银行“家底”（股东投入+留存利润）越厚、风险资产越少，资本充足率越高，越扛得住坏账冲击。

> 一句话：本钱厚不厚，决定了银行扛不扛摔。

---

## 2. 为什么重要

**资本是银行吸收损失的“最后一道防线”**。资本充足率不达标，银行会被要求补充资本（定增、发可转债），或收缩放贷，直接影响信贷投放与经济增长。这也是判断银行股安全边际的关键指标。

数字参考：监管红线是硬约束，但不意味着越高越好——资本占用太多可能说明业务扩张保守、资金效率低。

> 一句话：不达标要补血，达标是底线，过高也可能低效。

---

## 3. 怎么用 / 怎么看

- **看达标线**：先确认三项充足率是否高于监管要求（核心一级 ≥5%、一级 ≥6%、总资本 ≥8%）。
- **看趋势**：连续下滑说明消耗资本快或盈利弱，警惕再融资摊薄风险。
- **结合不良率看**：资本充足率低 + 不良率高 = 危险组合；两个指标一起看才完整。

> 一句话：先看是否达标，再看趋势和不良率搭配。

---

## 4. 常见坑 / 误区

- **只看总资本充足率**：核心一级资本充足率才是“真本钱”，要优先看它。
- **把达标当优秀**：监管达标只是及格线，盈利能力、资产质量才决定长期价值。
- **忽略分母变化**：风险加权资产规模变动会影响比率，光看比率不看资产结构会误判。
