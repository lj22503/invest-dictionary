# 新增信贷

> 这个月银行又新放出去多少钱——新增信贷是经济"有没有在借钱干活"的体温计。

## 1. 这是什么

新增信贷指一定时期内（通常按月）金融机构新发放的贷款总量，最常看的是"新增人民币贷款"数据，由央行在每月金融统计数据中公布。

它衡量的是"这个月实体经济借了多少钱"：企业借钱扩大生产、居民借钱买房消费，都会体现在新增信贷里。

## 2. 为什么重要

- 信贷是经济的先行指标：钱先借出去，投资和消费才会跟上，经济回暖往往从信贷放量开始；
- 看结构比看总量更关键：企业中长期贷款多，说明企业真在投资；票据冲量多，则可能是"水分"；
- 信贷收缩往往是经济下行的前奏，也是政策放松的信号灯。

## 3. 怎么用 / 怎么看

- 对比历年同期：每年 1 月有"开门红"效应，要和去年同月比，别和上个月比；
- 拆结构：关注"企业中长期贷款"和"居民中长期贷款（房贷）"的增减；
- 结合社融看：社融口径更全（含债券、非标等），比单看新增信贷更全面；
- 关注 LPR：贷款利率下行通常会刺激信贷放量，两者互相印证。

## 4. 常见坑 / 误区

- 被单月冲量误导：季末、年末银行冲存款冲信贷，单月数据波动大；
- 只看总量不看结构：票据融资冲量是"虚胖"，不代表真实需求；
- 把信贷数据当股价涨跌信号：数据是滞后确认，市场往往已提前反应。
