# 价值投资

> 价值投资=用低于内在价值的价格买入好公司并长期持有，赚企业盈利增长的钱，而不是赚市场情绪的钱。

## 1. 这是什么

价值投资的核心就三句话：买好公司（有护城河、能持续赚钱）、等好价格（价格低于内在价值，留出安全边际）、拿得住（长期持有，分享企业盈利增长）。

开奶茶店类比：你不会因为隔壁奶茶店排队，就花 500 万盘下来；你会先算它一年真能赚多少、值多少钱，再决定出价。

> 一句话：价值投资是花 5 毛买值 1 块的东西，然后等市场慢慢发现。

## 2. 为什么重要

短期股价是投票器（情绪），长期是称重机（业绩）。买贵了可以用时间消化，买错公司则会价值毁灭。

巴菲特年化约 20% 看起来不高，靠 60 年复利滚成巨富；对没时间盯盘的普通人，价值投资是最可复制的一条路。

> 一句话：价值投资不是不亏钱，而是亏了也知道自己在买什么。

## 3. 怎么用 / 怎么看

- 第 1 步：圈能力圈——只研究自己看得懂的行业（消费品、银行、医药等），不懂的不碰。
- 第 2 步：找好公司——连续多年高 ROE、现金流好、有护城河（品牌 / 成本 / 牌照 / 网络效应）。
- 第 3 步：等好价格——用市盈率、股息率等做粗略估值，在低估区间分批买入，保留安全边际。
- 第 4 步：长期跟踪——每季度看财报验证逻辑：逻辑没破就持有，明显高估或逻辑破了再卖。

## 4. 常见坑 / 误区

- 坑 1：买的是垃圾公司还死扛：那不是价值投资，是价值毁灭；跌再多也不代表便宜。
- 坑 2：把“便宜”当价值：低市盈率可能是基本面恶化的价值陷阱，要先确认是好公司的便宜。
- 坑 3：以为价值投资等于永不卖出：公司逻辑变坏或严重高估时一样要卖，“永远持有”是被误读的标签。
- 坑 4：用价值投资的名义掩盖懒惰：不研究不跟踪，买了就当甩手掌柜，这和买彩票没区别。
