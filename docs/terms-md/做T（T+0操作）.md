# 做T（T+0操作）

> 做T=利用手里的底仓，在当天先买后卖或先卖后买做差价，把持仓成本一点点做低的操作。

## 1. 这是什么

A 股股票当天买入不能当天卖出（T+1），但如果你手里本来就有这只股票，就能当天先卖出老仓、再买回同样数量，变相实现“当天买卖”。

做T分两种：正T=先低买、后高卖（先加仓后减仓）；倒T=先高卖、后低买（先减仓后加仓），靠差价把持仓成本一点点做低。

> 一句话：做T的本质是拿底仓当“库存”，赚当天波动的差价。

## 2. 为什么重要

做得好，成本越做越低，跌下来心理压力小；做不好，一次做飞（卖完就涨、买完就跌）就白干好几次，还要倒贴佣金和印花税。

它特别诱人是因为“每天都有机会”，但频繁交易恰恰是散户亏钱的头号原因之一。

> 一句话：做T是专业交易者的工具，不是上班族的副业。

## 3. 怎么用 / 怎么看

- 第 1 步：只用底仓的一部分做T（如 1/3），永远不清仓式做T，避免做飞后高价追回。
- 第 2 步：只做波动大、且你有时间盯盘的票；开盘急拉不追，尾盘跳水不慌。
- 第 3 步：设当日纪律——赚 1%-2% 就走，亏 1% 就认，别把做T慢慢做成加仓。
- 第 4 步：先算成本——佣金加印花税加滑点，日波动小于 1% 的票基本没得赚。

## 4. 常见坑 / 误区

- 坑 1：想做正T低吸，结果越买越多：从“做T”变成“满仓扛单”，是新手最常见的变形。
- 坑 2：做飞后心态崩：卖完就涨停，忍不住高价追回，成本反而更高。
- 坑 3：上班族偷偷盯盘做T：没有时间盯盘的人做T，基本是在给券商打工。
