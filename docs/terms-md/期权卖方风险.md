# 期权卖方风险

> 卖出期权是"收租"生意，但租金可能不够赔一次事故——卖方承担的风险比买方大得多。

## 1. 这是什么

期权买方花钱买"未来选择权"，最多亏掉权利金；期权卖方收权利金，换来一份义务：对方要行权，你必须履约。卖认购（Call），理论上亏损没有上限——标的涨到天上去你都得按行权价交出去；卖认沽（Put），亏损有下限但同样巨大——标的跌到零，你按行权价接盘。

一句话：买方风险是"有限且已知"，卖方风险是"有限或无限且后知"。

## 2. 为什么重要

散户最容易踩的坑就是"卖出 = 稳收租金"。实际上卖方是经典的"捡钢镚、被压路机碾"：绝大多数日子都在收小钱，但碰到一次极端行情，之前收的几十次租金都不够赔。

A 股场内期权市场里，做空波动率、裸卖 Call 的账户在行情暴涨时爆仓的案例并不少见。权利金收入是你收到的，风险是你要扛的——这笔账很多人只算了一半。

## 3. 怎么用 / 怎么看

- 卖任何一张期权前，先算最大亏损：卖 Call 假设标的大涨 50%，卖 Put 假设标的归零，看自己扛不扛得住。
- 盯紧维持保证金：保证金不够会被追保，追不上就被强平，强平价往往很惨。
- 裸卖 Call 必须封顶：买入一张更虚值的 Call 做保护（牛市价差），把无限风险变成有限风险。
- 仓位控制：卖方总权利金收入，控制在你能承受"全数归零"的范围内。

## 4. 常见坑 / 误区

- 忽略 Gamma 风险：越临近到期日，标的稍微一动，卖方浮亏就剧烈放大。
- 波动率极低时卖期权"看着稳"，恰恰是最危险的时刻——低波动率本身在积累爆炸能量。
- 以为保证金够就不会爆：强平可以发生在分秒之间，补保证金根本来不及。
- 卖方也要交保证金、也会被追保，不是"免费收租"。
