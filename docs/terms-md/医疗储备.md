# 医疗储备

> 专门为看病花钱准备的专用资金，和应急金是两回事。

## 1. 这是什么

医疗储备指为应对大病、意外、门诊等医疗支出预留的专用资金池，专款专用。

它的规模要覆盖：医保报销后的自费部分、商业险免赔额、异地就医的额外开销等。

它不是投资，是"保命钱"，安全性和流动性优先。

> 一句话：医疗储备是给未来的自己准备的"看病专款"。

## 2. 为什么重要

大病自费部分动辄数万到几十万，医保有报销上限和目录限制，进口药、特效药、先进器械常要自费。

商业保险有免赔额（百万医疗险通常1万）和等待期，理赔前还是要先垫钱。

医疗支出刚性且突发，没有专项储备，就只能动用应急金甚至借贷。

> 一句话：医疗储备补的是"保险和医保都管不到"的缺口。

## 3. 怎么用 / 怎么看

**第 1 步**：先配齐基础保障（医保+百万医疗险+重疾险），储备金和保险互补。

**第 2 步**：储备目标建议覆盖家庭一次大病的自费部分，参考10万-20万，至少覆盖1万免赔额+自费药。

**第 3 步**：以高流动性资产持有（货币基金、短期存款），随取随用。

**第 4 步**：单独账户管理，和应急金、日常资金分开，用完及时补回。

> 一句话：医疗储备的优先级是"能取出来"，不是"收益高"。

## 4. 常见坑 / 误区

**坑 1**：以为有医保就万事大吉，忽略自费药、进口器械、异地就医这些医保覆盖不到的支出。

**坑 2**：医疗储备和应急金混用一个账户，紧急挪用后专项余额归零。

**坑 3**：为省保费不买医疗险，大病全靠自费扛，储备金瞬间见底。

> 一句话：保险管大额，储备管垫付，两个都要有。
