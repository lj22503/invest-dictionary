# 深V / 反弹 / 反转 / 企稳

> 跌下去之后市场怎么走，这四个词说的不是一回事：反弹是"喘口气"，反转是"换了方向"，企稳是"跌不动了"。

## 1. 这是什么
跌了之后，行情不是只有一个剧本。这四个词是投资者给"下跌后的走势"贴的标签：

- **反弹**：跌势中的短期上涨，涨完往往接着跌，属于"死猫跳"。
- **反转**：趋势真的变了，从下跌转为上涨，是"新行情"的起点。
- **深V**：先急跌、再急涨，走势图像个 V 字，通常伴随恐慌盘砸出低点。
- **企稳**：跌不动了，横盘整理，多空暂时平衡，但还没确认方向。

## 2. 为什么重要
把反弹当反转，是最常见的亏钱方式之一：在反弹里重仓追进去，结果行情只是"喘了口气"，接着跌，追高的人再次被套。

- 反转 = 可以进场做多，赚钱概率更大；
- 反弹 = 只是噪音，追进去容易被"打脸"；
- 企稳 = 观察期，不急着重仓。

判断错了方向，轻则踏空，重则亏损扩大。

## 3. 怎么用 / 怎么看
- 看**时间**：反弹通常只有几天到几周；反转要经过更长的时间验证。
- 看**量能**：反弹往往缩量，反转往往放量突破。
- 看**位置**：底部区域放量上涨，更可能是反转；高位放量下跌后的回升，更可能是反弹。
- 看**均线**：价格站上并守住关键均线（如 20 日线），企稳信号更强。
- 口诀：**急跌之后先当反弹看，确认突破再当反转看。**

## 4. 常见坑 / 误区
- 把"深V"当天降神迹：深V 反转的概率不高，盲目抄底接飞刀，越接越深。
- 把反弹当反转重仓：反弹最诱人，也最危险，追高被套的人大多死在这一步。
- 企稳就以为安全：企稳只是"不再跌"，不代表马上涨，可能横盘几个月。
- 只看一天大涨：单日大涨可能是超跌反弹，需要用一周以上的走势确认。
