# 领先指标 / 同步指标 / 滞后指标

> 经济指标按"谁先动"分三类：领先指标先报信，同步指标跟着走，滞后指标最后确认。

## 1. 这是什么

领先指标：提前几个月预示经济拐点，比如 PMI 新订单、社会融资规模、M1、新开工面积、股票指数本身。同步指标：和经济同步变化，比如 GDP、工业增加值、社会消费品零售总额。滞后指标：经济都变了它才反应过来，比如 CPI、失业率、库存。

打个比方：领先指标是"信号灯"，同步指标是"仪表盘"，滞后指标是"后视镜"——三个都看，你才知道车往哪开。

## 2. 为什么重要

看宏观最怕"用错镜子"：CPI 还在涨，你判断经济过热，其实 CPI 是滞后指标，经济可能已经开始回落了。资产价格本身是领先指标——股市常常在经济数据见底前就先涨，就是这个道理。

会用三类指标，你就能比市场早半步感知拐点：领先指标连续回升 → 经济大概率要回暖；滞后指标还在创新高 → 警惕"利好兑现"。

## 3. 怎么用 / 怎么看

- 组一个领先组合：PMI 新订单 + 社融 + M1，三者连续 2—3 个月同向回升，拐点信号更可靠。
- 判断拐点看领先，确认趋势看同步，防追高看滞后。
- 单月数据当噪声：宏观数据波动大，至少看 3 个月趋势再下结论。
- 投资中用它定方向：领先指标转好 → 布局顺周期；领先指标转弱 → 降低仓位防守。

## 4. 常见坑 / 误区

- 用滞后指标（CPI、库存）判断当下经济冷热，方向经常看反。
- 把单月反弹当趋势反转：一个月的 PMI 回升说明不了问题。
- 忽略数据修正：宏观数据经常事后修正，"当时看着对"的结论可能被推翻。
- 迷信单一指标：任何一个领先指标都会失灵，组合使用才靠谱。

**相关词条**：PMI（采购经理指数，经济体温计）、社融（社会融资规模）、GDP增速目标、失业率
