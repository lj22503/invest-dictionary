# 风格切换

> 市场风格从一种切到另一种——押错风格，指数涨你也不涨。

## 1. 这是什么

市场不是铁板一块，而是有"风格"的：某一阶段资金偏爱成长股，下一阶段又偏爱价值股；一段时间大盘蓝筹强，另一段时间小盘题材猛。

这种偏好从一种切换到另一种，就叫**风格切换**。典型的有：成长 ↔ 价值、大盘 ↔ 小盘、高股息 ↔ 高弹性。

## 2. 为什么重要

风格切换期，最典型的体验是"指数涨了，我的基金不涨"。因为你的持仓风格和市场当前风格不一致，再好的个股也可能被冷落。

判断对风格，收益事半功倍；判断错，可能满仓踏空一整轮行情。对普通投资者，识别风格切换比预测个股涨跌更重要。

## 3. 怎么用 / 怎么看

- 看风格指数相对走势：上证 50（大盘）vs 中证 1000（小盘）、创业板指（成长）vs 红利指数（价值）；
- 看利率环境：利率下行、流动性宽松，往往利于成长风格；
- 看政策导向：产业政策扶持的方向，容易成为阶段性风格主线；
- 看资金流向：北向、两融余额的偏好变化，能提前反映风格切换迹象。

## 4. 常见坑 / 误区

- 以为"切换完了"就追着换仓：风格切换往往持续数月，追在切换中段最难受；
- 把风格当基本面：风格是资金偏好，会变；基本面是公司质地，相对稳定；
- 频繁跟随风格调仓：来回打脸，交易成本还会吃掉收益；
- 忽略大小盘切换的周期规律：A 股大小盘风格经常几年一轮，别只看一两个月。
