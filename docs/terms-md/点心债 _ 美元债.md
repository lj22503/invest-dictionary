# 点心债 / 美元债

> 点心债是境外人民币债券，美元债是境内企业去海外借的美元债券——都是“借洋钱”的门路。


## 1. 这是什么

**点心债 = 在中国香港等离岸市场以人民币发行的债券**，像“点心”一样小而精致，发行方可以是内地企业，也可以是外国机构。**美元债（中资美元债）= 内地企业跑到境外用美元发行的债券**。还有一对容易混的概念：**熊猫债**是外国机构到中国境内发行人民币债券；点心债是人民币在境外发行。一个在境内，一个在境外。> 一句话：点心债是“人民币出洋”，美元债是“借美元进门”。

## 2. 为什么重要

企业为什么舍近求远去借钱？三个理由：- **融资成本**：境外利率低时，借美元比借人民币便宜；
- **币种匹配**：有美元收入（出口、海外业务）的企业，天然想借美元，避免汇率错配；
- **绕开额度审批**：境内发债有额度窗口，境外市场更灵活。对投资者（以机构为主）来说，这类债券是配置外币资产、分散风险的途径；普通个人主要通过 QDII 债基间接参与。> 一句话：企业借洋钱图便宜，投资者买洋债图分散。

## 3. 怎么用 / 怎么看

- **看发行主体**：国企、城投、地产、民企，信用差别巨大，收益率差几个点很正常。
- **看币种**：点心债收人民币（无汇率敞口），美元债收美元（有汇率敞口）。
- **看期限与收益率**：中资美元债常有“高息”品种，高息背后是违约风险。
- **看查询工具**：彭博、DM 查债、中债估值都能看到报价和信用评级。> 一句话：先分清“谁借的、借的什么钱、利息为什么这么高”。

## 4. 常见坑 / 误区

- **只看票息不看汇率**：人民币升值会把美元债收益吃掉；反过来升值才“双赚”。
- **高息等于高风险**：地产美元债前几年批量违约，“利息 8% 的美元债”不是白送的。
- **流动性差**：点心债买卖价差大，想跑的时候不一定跑得掉。
- **城投“信仰”幻觉**：别把隐性担保当保障，违约照样发生。
- **误买复杂结构**：个人在 APP 里买的“海外债基”，底层可能是垃圾债，说明书要看清楚。> 一句话：美元债的收益，一半靠利息，一半靠汇率，两头都得盯。
