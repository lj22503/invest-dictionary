# 大宗商品

> 大宗商品是油、金、铜、大豆这类“论吨卖”的原材料，价格由全球供需决定，也是通胀与地缘冲突的体温计。

## 1. 这是什么

大宗商品分三大类：

- **能源**：原油、天然气、煤炭，价格跟着地缘和减产协议走；
- **金属**：黄金避险、铜被称为“铜博士”、铝和铁矿石看基建地产；
- **农产品**：大豆、玉米、棉花、白糖，天气和收成说了算。

> 一句话：大宗商品是标准化的、全球定价的、波动很大的“原材料大超市”。

## 2. 为什么重要

大宗商品的价格会传导到你生活的每一个角落：
油价涨→机票和物流变贵；粮价涨→食品变贵；铜价涨→家电和电缆变贵。
对投资来说，它是很好的信号灯：商品价格往往领先通胀数据，黄金在避险时上涨，原油在供给收缩时飙升——通胀和地缘冲突，都先写在商品价格里。

## 3. 怎么用 / 怎么看

普通人碰大宗商品，首选这三种低门槛方式：

- **商品ETF**：黄金ETF、原油基金，一键打包，不用管仓储和交割；
- **资源类股票**：有色、能源股，相当于“商品的股票化”，但还受公司经营影响；
- **期货**：高杠杆、会爆仓，普通人最好只看不碰。

> 一句话：看供需、看库存、看美元指数——美元强，商品往往弱。

## 4. 常见坑 / 误区

四个典型误区：

- **买金条当投资**：实物金有溢价、难变现、不生息，更适合收藏不是投资；
- **上期货杠杆**：杠杆放大收益也放大归零，普通人爆仓概率极高；
- **把资源股当“买商品”**：股价还受公司经营、管理层、行业政策影响，不等于商品价格；
- **追涨杀跌**：大宗商品波动剧烈，情绪高点进场往往接在山顶。
