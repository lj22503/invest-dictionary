# 跟踪误差

> 指数基金的表现和它跟踪的指数差多少。误差小是指数基金的“本职能力”，误差大说明你买的基金名不副实。

## 1. 这是什么（基金跑输指数的“差价”）

跟踪误差 = 指数基金的收益率 − 它跟踪的指数收益率。理想情况是 0（完全复制），实际总有偏差。
偏差来源：
费用：管理费、托管费每年要扣，基金天然跑输指数一点；现金拖累：基金必须留一部分现金应对赎回，现金不涨，拖累收益；抽样复制：成分股太多（比如沪深 300 的 300 只），有的基金会“买一部分代表”；申赎冲击：大额申购赎回会让基金经理被迫买卖，产生成本。
通常 ETF 的跟踪误差比场外指数基金小。
一句话：跟踪误差是“忠实度”指标——说好跟指数，到底跟没跟住。

## 2. 为什么重要（为什么重要：买指数基金就要忠实）

买指数基金的唯一理由就是“赚指数的钱”——如果跟踪误差大，你买的“指数基金”就名不副实：指数涨 10%，你的基金可能只涨 8%。
跟踪误差还直接影响你定投的复利：每年差 1%，20 年下来，最终财富可能差 20% 以上。
对指数增强基金，误差是“有意的”，关键看超额收益是否稳定——跑赢指数是加分，跑输就白交管理费。
一句话：误差小是本职，误差大是失职。

## 3. 怎么用 / 怎么看（怎么用：选误差小费率低的）

查指标：天天基金、晨星等平台可查“跟踪误差”和“跟踪偏离度”；选同指数基金：跟踪误差小 + 费率低优先；看长期：别只看近 1 个月的误差，要看年化跟踪误差；定期复盘：每半年、一年检查一次，基金是否忠实复制指数；指数增强要看超额稳定性：单期爆发不算数，连续 3 年跑赢才可信。
一句话：选指数基金，误差和费率是唯二重要的参数。

## 4. 常见坑 / 误区（常见坑：指数涨了基金没涨）

以为“指数涨了基金一定涨”：跟踪误差大的基金，可能指数涨它涨得少，甚至指数涨它跌；只看短期误差：近 1 个月误差小可能是运气，要看长期年化口径；买迷你基金：规模太小的指数基金，申赎冲击大，跟踪误差容易放大；把“增强基金跑赢”当“跟踪误差为负”：增强基金本来就允许偏离，要看超额收益的持续性，而不是单期表现。
一句话：跟踪误差小是底线，超额稳定是加分。
