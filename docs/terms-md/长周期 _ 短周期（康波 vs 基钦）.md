# 长周期 / 短周期（康波 vs 基钦）

> 经济像钟摆，有 50 年的大摆动，也有 3—4 年的小摆动，长短叠加构成大势。

## 1. 这是什么

经济学家把经济波动按长度分成几档：长周期（康德拉季耶夫周期，约 50—60 年，由技术革命驱动）、中周期（朱格拉周期，约 8—10 年，由设备投资驱动）、短周期（基钦周期 / 库存周期，约 3—4 年，由库存调整驱动）。

我们常说的“康波”就是长周期——蒸汽机、电力、互联网、AI，每一次技术革命都开启一轮长达几十年的景气与调整；而“基钦周期”是短周期，企业补库存、去库存的节奏就构成 3—4 年一轮的小循环。

> 一句话：长周期定时代大方向，短周期管库存小节奏，两者叠在一起才是完整的周期图景。

## 2. 为什么重要

长周期决定“时代的贝塔”：康波上升期，新技术、新产业是最强主线（比如互联网时代的科技股）；康波下行期，防御型资产和现金流资产更吃香。

短周期决定“库存的拐点”：补库存阶段，周期股、商品价格往往上涨；去库存阶段，它们容易承压。对做商品期货、周期股投资的人来说，库存周期比康波更“用得着”。

- 看长周期：跟踪技术革命、人口结构、资本开支大周期，定配置大方向
- 看短周期：跟踪 PPI、工业库存、PMI 新订单，判断补库 / 去库拐点
- 长短叠加：短周期上行 + 长周期上行 = 最顺的风；短周期下行 + 长周期下行 = 最难熬

## 3. 怎么用 / 怎么看

- 长周期参考：康波理论把经济分为回升、繁荣、衰退、萧条四段，可用技术渗透率辅助定位
- 短周期参考：库存周期看“主动补库 / 被动去库”四阶段，对应商品与周期股的不同表现
- 多周期共振：多个周期同时向上或向下时，趋势最可靠
- 数据抓手：PPI 同比、工业企业产成品库存、PMI 新订单—产成品库存差

## 4. 常见坑 / 误区

- 坑 1：拿周期预测精确拐点——周期给出的是“位置感”，不是几月几号的闹钟
- 坑 2：忽视政策与黑天鹅——降准降息、疫情、战争都会暂时扭曲周期节奏
- 坑 3：只信一种周期——只用库存周期判断十年大趋势，等于用显微镜看地图
- 坑 4：以为周期永远对称——衰退可能比理论更长，底部可能反复磨
