# 再通胀

> 再通胀指经济从通缩/低通胀中“回暖”：通过政策刺激把物价和需求重新拉起来，让“冷”的经济重新发热。

## 1. 这是什么

**给经济“升温”**

**再通胀（Reflation）＝用政策让物价水平从低迷中回升**，方向与“抗通胀”相反：不是压制涨价，而是鼓励适度涨价。
手段通常是：央行降息/放水＋政府扩大支出/减税，让需求回暖、企业敢投资、居民敢消费。
> 一句话：再通胀是给“冻僵”的经济盖被子、喂药。
## 2. 为什么重要

**通缩比通胀更可怕**

通缩螺旋是经济最怕的剧本：物价跌 → 企业利润跌 → 裁员降薪 → 消费更少 → 物价更跌。
再通胀政策就是为了打断这个循环。它对资产影响巨大：
- **股市**：利率下行＋盈利预期改善，估值与盈利双击；
- **大宗商品/周期股**：需求回暖直接受益；
- **债券**：利率先下后上，长债后期承压。
> 一句话：再通胀行情里，钱从“避险”流向“冒险”。
## 3. 怎么用

**怎么识别再通胀交易**

- **盯政策转向**：央行从加息转降息/暂停、财政推大规模刺激 → 再通胀窗口打开；
- **看先行指标**：PMI 回升、社融放量、大宗商品涨价，是再通胀的“体温计”；
- **资产打法**：早中期配权益与周期，通胀确认回升后再转向抗通胀资产；债券在利率反弹前及时减仓。
> 一句话：政策转向是发令枪，PMI 和大宗是确认信号。
## 4. 常见坑

**再通胀≠大牛市**

- **把再通胀当必然上涨**：如果政策力度不足或传导不畅，可能“雷声大雨点小”；
- **忽视“再通胀失败”风险**：刺激过度会变成恶性通胀，刺激不足则滞胀，两个极端都不好；
- **追高已经涨过的品种**：再通胀交易抢的是“预期差”，等所有人都上车了，收益就薄了。
> 一句话：再通胀交易赚的是“从冷到热”的预期，不是永动机。
