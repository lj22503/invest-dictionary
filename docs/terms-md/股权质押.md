# 股权质押

> 质押本身不是风险，质押比例高加上股价下跌才是风险。

## 1. 这是什么

**股权质押，是股东把自己持有的股票作为抵押品向银行、券商、信托等机构融资，到期还本付息后解除质押。**质押率通常为股票市值的 3-6 折，机构会设置预警线和平仓线。

- **谁在质押**：大股东最典型，也常见于员工持股计划、并购配套融资
- **关键机制**：股价跌到预警线要补保证金或追加质押，跌破平仓线可能被强制卖出
- **两个常用口径**：质押股数占其持股比例、质押股数占总股本比例

> 一句话：质押公告里写着大股东的资金压力。

## 2. 为什么重要

- **它制造负反馈**：股价下跌 → 追保或平仓 → 卖压 → 股价继续下跌
- **它暴露大股东资金链**：高比例质押往往意味着股东现金紧张，可能演变成资金占用、违规担保
- **它影响公司稳定**：控制权被平仓可能引发实际控制人变更，战略连续性被打断
- **对个人的意义**：它是少数"能从公告里提前看到"的风险信号

## 3. 怎么用 / 怎么看

- **先看两个比例**：质押占其持股比例超过 70%-80%，风险明显上升；再看占总股本比例
- **再看距离**：公告里常写预警线与平仓线，用来估算当前股价的安全距离
- **看动作**：频繁补充质押、展期、解押后又质押，都是资金紧张的表现
- **看质押对象与用途**：质押给银行还是非银机构，用于公司经营还是个人资金，含义不同
- **看公告节奏**：解押公告集中出现，有时是为后续减持或股权转让做准备

## 4. 常见坑 / 误区

- **以为只有小公司才高质押**：部分大型民企、次新股控股股东的质押比例同样很高
- **以为股价不跌就没事**：质押率、维持担保比例、利率都会变化，安全边际会被侵蚀
- **把解押当利好**：解押可能只是换机构续贷，资金压力并未解除
- **忽略平仓的执行细节**：机构通常先协商，但极端行情下会直接处置
- **只看比例不看成本**：股东质押时的股价，决定了平仓压力有多大
- **忽视连带合规问题**：违规质押、资金占用、违规担保往往一起出现，需要一并排查
