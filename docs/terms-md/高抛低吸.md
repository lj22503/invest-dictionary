# 高抛低吸

> 涨上去卖一点、跌下来买一点——听起来稳赚，做起来最考验判断和纪律。

## 1. 这是什么

**高抛低吸 = 在价格相对高位卖出、相对低位买入，靠反复做差价摊低成本或赚取波动收益。**它对应的是一段“低吸区间”和一段“高抛区间”，而不是预测明天涨还是跌。

它和“追涨杀跌”正好反着来：涨了才想买、跌了才割肉，是追涨杀跌；在情绪最热时减一点、最冷时补一点，才叫高抛低吸。

关键在“相对”两个字：高低是相对估值分位、相对你的成本、相对你该有的仓位，不是绝对点位。3000 点可以是高，也可以是低，取决于拿什么做参照。

> 一句话：高抛低吸不是猜点位，是提前给自己划好价格区间。

## 2. 为什么重要

市场大部分时间在震荡。长期持有的人赚的是企业盈利增长，做高抛低吸的人赚的是波动本身——这是两套完全不同的赚钱方式，混着做最容易两头不讨好。

波动对不同的人意义不同：对没有纪律的人是来回摩擦的成本，对定好区间的人是摊薄成本的机会。

**它更大的价值在心态**：手里有仓位时，涨了怕回撤、跌了怕套牢，是最容易做错事的状态。事先写好“卖一点”和“买一点”的价位，情绪就有了出口。

- 涨到目标区间 → 减一部分仓，落袋为安；

- 跌到预设区间 → 分批补一点，摊薄成本；

- 区间没到 → 什么都不做，这也是操作的一部分。

> 一句话：高抛低吸的价值不是多赚，而是少被波动牵着走。

## 3. 怎么用 / 怎么看

- 先定区间再谈买卖：用估值历史分位（PE/PB 百分位）或关键均线画两条线，写下来再去执行。

- 分批而不是一次：分成 3~5 档，每跌一档买一点、每涨一档卖一点，避免一次性押错位置。

- 只对波动大、你看得懂的资产做：宽基指数、行业 ETF 比个股更适合练手，因为不会遇到个股黑天鹅。

- 永远留出补仓的子弹：满仓的人没有“低吸”这一说，只能被动看着。

- 记流水：把每次买卖的价格和理由写下来，三个月后回看，才知道自己做的是策略还是手痒。

> 一句话：做不到分批、留子弹、做记录，高抛低吸就只是口号。

## 4. 常见坑 / 误区

- 把“低吸”做成“越跌越买”：基本面已经变坏时的下跌不是机会，是风险重新定价，这类标的不适用低吸。

- 卖掉之后不敢买回来：涨了嫌贵，于是长期空仓等大跌，错过整段行情。

- 忽略摩擦成本：佣金、印花税、买卖价差会吃掉大部分差价收益。

- 用短期要用的钱做：急用钱时往往正好在低点，只能被动割肉。

- 把纪律交给情绪：跌了想等更低，涨了想等更高，最后区间失效、操作变形。
