# 债牛债熊

> 债券市场的牛市和熊市：债牛=利率下行、债价上涨，债熊=利率上行、债价下跌。

## 1. 这是什么

**债券市场同样有牛熊，但方向和股票相反着看。** 债券价格和利率是跷跷板：市场利率往下走，存量债券的票息显得“更值钱”，债券价格上涨——这就是债牛；利率往上走，债券价格下跌——这就是债熊。

举个例子：你 3% 买的一张 10 年期国债，央行降息后新发债券只有 2.5%，你的旧债反而成了“香饽饽”，价格会涨；反过来加息，你的旧债就被嫌弃，价格会跌。

## 2. 为什么重要

**债牛债熊决定你的债基、银行理财赚不赚钱。** 2024 年利率持续下行，债市走牛，债基和理财普遍赚得不错；2025 年利率低位震荡、波动加大，不少人发现“稳健的债基也能亏”。理解债牛债熊，你就知道：

- **利率下行周期**：债基、长久期产品吃香，可适当多配；
- **利率上行周期**：债基回撤放大，要降低久期、多留短债和现金；
- **股债跷跷板**：股票强时债往往弱，反之亦然，是资产配置的底层逻辑。

## 3. 怎么看

盯住这几盏灯，判断当前是债牛还是债熊：

- **10 年期国债收益率**：下行=债牛，上行=债熊，是最重要的“体温计”；
- **央行政策**：降准降息周期利好债市，收紧周期利空债市；
- **资金面**：银行间利率（DR007 等）走高，债市承压；
- **交易拥挤度**：债市“涨太猛、太拥挤”时，往往是债牛尾声的信号。

判断口诀：**利率是债市的“股价”**——想判断债市方向，先问利率要往哪走。

## 4. 常见坑 / 误区

- **以为债基不会亏**：债熊回撤照样有，长久期债基单年回撤可以到 3%~5%；
- **只看收益不看久期**：同样叫“债基”，久期不同，利率波动下的涨跌天差地别；
- **把利率债和信用债混为一谈**：债牛救不了信用暴雷，利率风险≠信用风险；
- **在债牛尾声追高**：长端利率已经很低时买入，赚不了多少，跌起来却不少。
