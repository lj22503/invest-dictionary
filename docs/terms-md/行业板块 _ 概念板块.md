# 行业板块 / 概念板块

> 行业板块按公司主业归类（白酒、银行、半导体），概念板块按题材/事件归类（AI、机器人、国企改革）——两者都是市场的"分组标签"。

## 1. 这是什么

**板块是市场给股票贴的"分组标签"**：把相似的股票放在一组，方便投资者按主题观察行情。

关键点：

- **行业板块**：按公司所属行业划分，如食品饮料、银行、医药、半导体，相对稳定；
- **概念板块**：按题材/事件/预期划分，如 AI 概念、低空经济、国企改革，灵活多变；
- **分类来源**：行情软件（同花顺、东方财富）有各自的板块划分，标准不完全一致；
- **交叉归属**：一只股票可同时属于多个行业与概念板块（如某股既是半导体行业，又是 AI 概念）。

> 一句话：行业板块看"它是干什么的"，概念板块看"市场在炒它什么"。

## 2. 为什么重要

**板块是资金流向的"热力图"，也是市场情绪的放大器：**

- **资金轮动**：钱在不同板块之间流动（高低切），板块涨跌就是资金进攻/撤退的路线图；
- **龙头效应**：板块行情通常由龙头股点火、带动跟风股，看板块先看龙头；
- **题材炒作**：概念板块常由消息/政策催化，爆发快、退潮也快，情绪特征明显；
- **选股框架**：自下而上选个股之外，自上而下先选板块，是多数机构的标配思路。

**真实场景**：周五盘中"低空经济"政策文件发布，相关概念股集体大涨，某只做无人机零部件的公司主业平平，却因被归入低空经济概念两天涨了 20%。概念炒作期一过，股价又跌回原点。

## 3. 怎么用 / 怎么看

- 第一步：分清归属——先看它属于哪个行业（稳定），再看叠加哪些概念（灵活）；
- 第二步：看板块强度——板块内上涨家数占比、龙头是否封板，判断行情成色；
- 第三步：看轮动位置——板块是刚启动、主升还是末端补涨，位置决定风险收益比；
- 第四步：看催化逻辑——概念有没有实质性政策/业绩支撑，还是纯情绪博弈；
- 第五步：警惕"一日游"——没有持续催化的概念，往往涨一天就熄火。

> 一句话：先看行业定质地，再看概念定节奏——板块给你的是地图，不是承诺。

## 4. 常见坑 / 误区

- **坑 1：把概念当基本面**：题材归入不等于业绩兑现，炒作退潮后一地鸡毛；
- **坑 2：追涨不追龙头**：龙头买不进就买"沾边股"，结果龙头继续涨、沾边股先跌；
- **坑 3：忽略板块内部轮动**：同板块个股节奏不同，高位接盘跟风股风险大；
- **坑 4：迷信软件板块标签**：不同软件的板块归类不一，标签只是参考，不是官方定义；
- **坑 5：把行业景气与概念热度混淆**：行业景气看业绩，概念热度看情绪，两回事。
