# 物流景气指数

> 快递、货运、仓储行业忙不忙的"景气仪表盘"：货在跑，经济就在动。

## 1. 这是什么

**物流景气指数（LPI，物流业景气指数）= 中国物流与采购联合会发布的月度指数，反映物流业业务总量、新订单、库存周转、从业人员等景气状况。**以 50 为荣枯线：高于 50 扩张，低于 50 收缩。

场景：双 11 大促期间快递业务量暴增、货车满路跑、仓储爆仓，当月 LPI 就会明显冲高；春节淡季业务清淡，指数回落。它测的就是"货物在多大程度上流动起来了"。

> 一句话：经济是活的还是蔫的，看货跑得勤不勤。

## 2. 为什么重要

物流是实体经济的"动脉"：**工厂生产要运进原料，商品卖出要运到消费者手里**。物流景气回升，说明产销两旺、货物流转加快；持续低迷，说明从上游到下游都在"躺平"。

它也是克强指数里"铁路货运量"的精细化补充——不只铁路，公路、快递、仓储都覆盖。对普通人：物流景气影响快递时效和运费，也直接影响电商、物流公司的盈利和股价。

数字参考：业务总量分项冲上 55 以上往往对应旺季，从业人员分项持续收缩则是行业收缩的前兆。

> 一句话：它是观察"实物经济"活跃度的月度体温计，比很多抽象指标更接地气。

## 3. 怎么用 / 怎么看

- **看荣枯线**：50 以上扩张、以下收缩，先定方向。
- **看分项**：业务总量、新订单、从业人员、库存周转四个分项各有含义，订单先动、从业人员滞后。
- **与 PMI 互验**：制造业 PMI 回升 + 物流景气回升 = 生产到流通都转好。
- **与社零互验**：消费旺季物流冲高是正常季节性，别把季节当趋势。

> 一句话：50 定方向，分项看结构，和 PMI、社零交叉验证才可靠。

## 4. 常见坑 / 误区

- **被节日效应骗了**：双 11、春节前单月跳升是季节性，要和去年同期比、看累计趋势。
- **它衡量"量"不衡量"价"**：货量涨但运费跌，说明需求弱、供给过剩，量增价跌不是好信号。
- **全国指数掩盖局部冷热**：华东电商旺、北方制造业淡，全国均值看不出结构。
- **当领先指标用**：物流景气更多是同步甚至滞后指标，订单数据才是领先的。
