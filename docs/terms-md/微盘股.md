# 微盘股

> 微盘股 = 市值最小的那一批股票，通常总市值几十亿元以下，涨跌像过山车。

## 1. 这是什么

A 股按市值大小分梯队：大盘股、中盘股、小盘股，最末端的就叫**微盘股**。没有全国统一的门槛，大致指总市值 **50 亿元以下**、甚至 20 亿元以下的那批公司。市值小意味着"一点点资金就能推动股价"，所以它们波动特别大，也特别受量化资金和游资喜欢。

## 2. 为什么重要

微盘股"小而灵"，过去几年超额收益明显——很多量化基金靠"小市值因子"赚得盆满钵满。但硬币的另一面是：流动性差、容易暴涨暴跌、容易被操纵、退市风险高。买微盘股不是买"便宜"，是买"高风险高波动"。

## 3. 怎么用 / 怎么看

- 先看**市值**：确认它是微盘还是小盘，别混为一谈
- 再看**成交量**：日成交额太小的票，想跑都跑不掉
- 然后看**业绩与基本面**：市值小不等于质地差，但质地差的小票更危险
- 要参与就用**一篮子分散**：买微盘股指数基金或量化基金，而不是单吊一只

## 4. 常见坑 / 误区

- 以为"市值小 = 涨得多"，忘了跌起来同样加倍
- 把微盘股当小盘股买，风险认知错位
- 忽视退市风险，退市新规下小票被"扫出"的速度很快
- 追高涨停的微盘妖股，往往买在游资出货的最后一棒
