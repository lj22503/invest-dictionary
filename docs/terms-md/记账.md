# 记账

> 给每一笔钱写流水账，知道钱都去哪了。

## 1. 这是什么

记账就是记录每一笔收入和支出，像给家里的钱流写流水账：工资进多少、房租花多少、外卖点多少，一笔不落。

它可以是手写账本，也可以是记账 App、Excel 表格。关键是持续记录、定期复盘，而不只是“记了就行”。

记账不是抠门，而是掌握自己花钱的事实。

## 2. 为什么重要

很多人月底发现“钱没怎么花就没了”，不是因为花得离谱，而是从来不知道钱去哪了。

记账带来的三个改变：

- 看见真相：外卖、奶茶、会员订阅，零零碎碎加起来可能占月支出 30%
- 控制预算：知道固定支出后，才能给“想要”的花销设上限
- 积累数据：3 个月账单一拉，该砍哪笔、能省多少，一目了然

理财的起点不是买基金，而是先搞清楚自己的现金流。

## 3. 怎么用 / 怎么看

- 先记大后记小：第一周只记超过 50 元的支出，降低启动门槛
- 固定时间：每晚睡前 2 分钟，或每周日统一补记
- 用支付记录倒推：微信/支付宝账单直接导出，比自己记更省事

记住原则：记不全也比不记强，先跑起来再优化。

## 4. 常见坑 / 误区

- 坑 1：追求“一分不差”，坚持两天就崩。记账是习惯不是任务
- 坑 2：只记不复盘。每月花 10 分钟看看分类占比才有意义
- 坑 3：把记账当“省钱工具”而非“看清工具”。过度压抑消费反而容易报复性反弹
