# 涨停敢死队

> 专门在涨停板附近重仓进出、博隔日收益的游资——短线情绪的温度计。

## 1. 这是什么

**涨停敢死队，是一类以短线打板为生的游资**：习惯在个股封涨停瞬间或排队买入，博“今天涨停、明天冲高卖出”的隔日收益。

他们的特点：资金大、动作快、纪律强、对情绪周期极度敏感。行情好时一天进出几十亿，行情差时集体隐身。

历史上最著名的敢死队席位在宁波，如今龙虎榜上依然活跃着各路游资席位——他们的名字常出现在涨停股的前五大买入席位里。


## 2. 为什么重要

敢死队的动向，是短线市场的**体温计**：

- 敢死队活跃、封板率高 → 市场情绪热，短线好做
- 敢死队集体熄火、次日溢价差 → 亏钱效应扩散，短线难做

对普通人的价值：**看热闹可以，模仿要命**。新闻里出现“涨停敢死队”时，读懂它意味着什么就好——它是情绪指标，不是买入信号。


## 3. 怎么用 / 怎么看

- 看席位：龙虎榜里知名游资席位出现在买一，说明有资金在博弈，但持仓通常只有一两天
- 看封单：涨停封单厚、开板次数少，次日溢价的概率高
- 看情绪周期：冰点期敢死队也吃面，别把“敢死队买入”当“主力锁仓”
- 记住：敢死队的钱是“过路钱”，它不陪你走长路


## 4. 常见坑 / 误区

- 坑 1：散户学敢死队打板——资金、速度、纪律完全不对等，多数人变成接盘侠
- 坑 2：把敢死队席位当“主力吸筹”——他们的持仓周期以天计算，不是长期资金
- 坑 3：忽视监管风险——异常交易、频繁拉抬可能被监管关注甚至处罚
- 坑 4：以为敢死队永远赚钱——打板失败一天亏 10% 以上很常见，只是你看不到
