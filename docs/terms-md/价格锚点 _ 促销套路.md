# 价格锚点 / 促销套路

> 商家先给你一个“高价参照物”，让你觉得后面的价格特别划算，不知不觉就下单。

## 1. 这是什么

价格锚点，是指消费者判断“贵不贵”时依赖的第一个参照价格。商家故意摆出高价锚点，让目标价格显得便宜。

常见手法：原价 999 划线价 vs 现价 299（锚点是 999）；套餐里放一个“贵得离谱”的大杯（让你选中间档）；“限量 100 份”“今天最后一天”制造稀缺。促销套路本质是：先锚定你的心理价位，再让你在“对比差价”里感到占便宜。

## 2. 为什么重要

人几乎无法独立判断一件商品值多少钱，全靠比较。锚点一旦种下，“现在买最划算”的判断就被接管了——你买的不是商品，是“省下的钱”带来的爽感。

双 11、618、直播间“全网最低价”，都是在批量制造锚点。每年因“比原价便宜 200 块”买下根本不需要的东西而多花的钱，远大于省下的那点折扣。

## 3. 怎么用

- 看绝对价格，不看划掉的价格：问自己“这 299 值不值”，而不是“从 999 降到 299 值不值”。
- 提前锚定自己：下单前查历史价格（比价插件、慢慢买等），用真实底价当锚点，而不是商家给的划线价。
- 区分“真需求”和“差价快感”：不需要的东西，降再多价也不买。
- 对“限量、最后一天”设防：稀缺是万能催单器，真稀缺的商品不需要吆喝。

## 4. 常见坑

- 划线价不一定是真实原价：有些“原价”是商家自己标上去的，从未按此价格卖出过。
- “第二件半价”可能比单买两件更贵，先算单件净价。
- 套餐里的“诱饵档”是设计出来的：中间档往往不是最划算，而是利润率最高的。
- 直播间“厂家补贴价”多数是话术，对照全网比价再决定。
- 促销时最容易买“伪需求”：先列购物清单，促销只买清单里的东西。
