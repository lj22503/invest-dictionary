# 保单贷款 / 减额交清

> 保单贷款是用现金价值向保险公司借钱；减额交清是交不起保费时，用现金价值换一份保额更低的保单。

## 1. 这是什么

<strong>保单贷款</strong>：拿你保单里的现金价值作抵押，向保险公司借钱。通常能贷出现金价值的 80% 左右，利率一般比银行信用贷低，期限常见 6 个月，到期还息可续贷。

<strong>减额交清</strong>：以后不再交保费，用保单已经攒下的现金价值，一次性“买断”一份保额更低的保单——保障还在，只是缩水，以后也不用再交钱。

这两个工具的前提是：你的保单<strong>有现金价值</strong>（长期寿险、年金险、增额终身寿险都有）。消费型医疗险、意外险没有现金价值，用不上。

> 一句话：退保是“撕合同”，保单贷款是“借钱不撕”，减额交清是“降配不撕”。

## 2. 为什么重要

长期保单前期现金价值很低：比如年交 2 万的增额寿，前三年现金价值可能只有保费的 30%-50%。这时退保=巨亏，但又急用钱，怎么办？

- 保单贷款：不用退保就能拿钱，保障不中断，比退保划算得多；利率通常 4%-6%，比消费贷低；

- 减额交清：失业、收入骤降，实在交不起后续保费，又不想彻底失去保障——减额交清比退保拿现金更“保值”，因为退保拿到的钱通常远低于“买断”出的保障价值。

一句话总结两者的价值：<strong>保单贷款解决“短期缺钱”，减额交清解决“长期交不起”</strong>，都是比退保损失更小的选项。

## 3. 怎么用 / 怎么看

- 第一步：翻出现金价值表——合同里有，或打客服电话问清当前现金价值；

- 保单贷款怎么用：确认可贷额度（现金价值×80%左右）→ 通过保险公司 App 或柜台申请 → 钱一般几天内到账 → 记住 6 个月还一次利息，本金可续借；

- 减额交清怎么用：确认减额后的保额还够不够用 → 向保险公司申请“减额交清” → 之后不用再交保费，保障按新保额继续；

- 选哪个：短期周转选贷款；确定未来交不起保费、且保障仍需要，选减额交清；两者都不适合，才考虑退保。

## 4. 常见坑 / 误区

- 坑一：以为保单贷款不用还——到期不还，利息滚进本金，现金价值不足时保单直接失效，保障归零；

- 坑二：只还利息不还本金——6 个月一结是利息周期，本金一直欠着会持续滚利；

- 坑三：减额交清后保额大幅缩水没细看——可能从 50 万降到 8 万，要提前算清够不够用；

- 坑四：贷款的钱拿去买高风险投资——借来的钱有成本，投资亏了保单也岌岌可危；

- 坑五：消费型保单也用这套——没有现金价值的保单贷不了款，别白跑一趟。
