# 存货 / 应收账款

> 公司压在仓库里的货和没收回来的货款——账上赚了，兜里没到。

## 1. 这是什么

存货，是公司买来还没卖出去的货：原材料、半成品、成品，都算。应收账款，是货已经卖出去了，但客户的钱还没打过来的欠条。

它们都躺在资产负债表上，是利润表上"赚了"但还没变成现金的那部分。比如一家公司账上利润 1 个亿，但如果这 1 个亿全是应收账款，那它实际拿到手的现金可能是 0。

## 2. 为什么重要

利润是可以"装"出来的——把东西卖给关联公司、调低费用计提，报表上的利润都能变好看。但存货和应收账款很难藏：货真不真、钱收不收得回来，早晚要现原形。

- 存货突然暴涨，可能不是备货，而是东西卖不动、堆在仓库里；
- 应收账款暴涨，可能不是生意变好，而是客户开始赊账、甚至压根不想给钱。

## 3. 怎么用 / 怎么看

- 看存货增速 vs 营收增速：存货比营收涨得快，警惕滞销；
- 看应收账款增速 vs 营收增速：应收比营收涨得快，警惕放宽信用冲收入；
- 看应收账款占营收比例：超过营收的三分之一就要留意回款质量；
- 看存货周转天数 / 应收周转天数：天数越长，钱压在货和欠条上的时间越久。

## 4. 常见坑 / 误区

- 以为存货是资产就一定是好事——卖不掉的存货会跌价，还要计提跌价准备；
- 以为应收账款"以后总会收回来"——账龄越长的应收，坏账概率越高；
- 把"收入高"当"现金流好"——收入和利润是权责发生制，现金流才是真金白银；
- 忽略季节性备货——春节前备货导致存货涨，不一定是坏事，要结合行业节奏看。
