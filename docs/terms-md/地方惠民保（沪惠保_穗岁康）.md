# 地方惠民保（沪惠保/穗岁康）

> 政府牵头、保险公司承保的“补充版医保”，一年几十到一两百块，大病自费再报一层。

## 1. 这是什么

**地方惠民保 = 政府出面指导、商业保险公司承保的“城市定制型商业医疗险”。**沪惠保（上海）、穗岁康（广州）、北京普惠健康保、深圳惠民保，都是这一类的代表。

它和医保的关系像“第二层”：医保先报，剩下的自费大额部分，惠民保再帮你兜一层。投保门槛极低——只要你有本地医保，**不限年龄、不限职业、健康告知宽松（或没有）**，一年保费通常只要几十到一两百块。

> 一句话：这是给“买不了百万医疗险的人”准备的大病补充保障。

## 2. 为什么重要

医保有三大限制：只报目录内、有起付线、有封顶线。一场大病下来，目录外自费药、进口器材、放化疗费用，个人可能要掏十几万甚至几十万。

惠民保的价值就在这：**把“医保报完之后的自费大头”再报一层**。对60岁以上老人、有慢病史、被百万医疗险拒保的人来说，这几乎是市面上唯一买得起的商业医疗险。

- **保费低**：一年100-200元，全家买也负担得起；
- **门槛低**：不问健康告知、不限年龄；
- **保额高**：年度保额通常100万-300万，主要覆盖住院医疗和特药费用。

## 3. 怎么用 / 怎么看

- **看投保窗口**：惠民保通常每年集中投保一次（沪惠保一般5-7月），错过等明年；
- **看免赔额**：多数产品免赔额1.5-2万元，是“医保报销后个人自费部分”再扣掉免赔额才开始赔；
- **看既往症条款**：带病可以投保，但既往症的赔付比例通常打折（健康人群约70%，既往症人群约30%）；
- **看特药清单**：目录内的院外特药（靶向药等）才是惠民保的“隐藏价值”。
> 一句话：先医保结算，再申请惠民保理赔，住院单据一张都别丢。

## 4. 常见坑 / 误区

- **以为“啥都报”**：惠民保主要报住院医疗和特定药品，门诊、普通感冒发烧不在保障范围；
- **忽略免赔额**：自费不到1-2万，一分钱赔不到；
- **拿它替代百万医疗险**：百万医疗险免赔额更低（通常1万）、报销比例更高、保障更全，能买百万医疗险就别只靠惠民保；
- **以为“政府背书=保证续保”**：产品一年一签，第二年可能调整保障甚至停售；
- **被“外地也能买”忽悠**：必须参保当地基本医保才能买当地惠民保。
