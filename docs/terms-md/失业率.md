# 失业率

> 失业率=正在找工作却没找到工作的人，占想工作人口的百分比，是衡量就业冷暖的核心指标。

## 1. 这是什么

统计失业率时分母是“劳动力”（有工作或正在找工作的人），分子是“想工作但没找到”的人。学生、全职主妇、彻底躺平不找工作的人不算失业，只算“退出劳动力市场”。

中国主要看两个数：城镇调查失业率（统计局每月抽样调查）和16-24岁青年失业率（不含在校生）。

> 一句话：失业率越高，说明想干活的人里越多找不到活干。

## 2. 为什么重要

对政策制定者：失业率上升=经济转差，政策会倾向降息放水刺激；失业率太低=招工难、工资涨得快，反而容易推高通胀，政策就得收紧。

对你：失业率走高往往意味着就业市场竞争激烈、涨薪困难；对投资者，失业率通过影响利率预期，间接影响股市、债市和楼市。

> 一句话：失业率是判断“要不要放水”的关键钥匙，而水往哪流，决定资产往哪涨。

## 3. 怎么用 / 怎么看

- 第 1 步：看趋势不看单月：连续3个月回升，才说明就业在实质转弱。
- 第 2 步：看结构：16-24岁青年失业率、31个大城市失业率比总量更敏感，青年数据高往往是结构性矛盾的信号。
- 第 3 步：交叉验证：结合新增就业人数、PMI从业人员分项、招聘平台数据一起看，避免单一指标失真。

## 4. 常见坑 / 误区

- 坑 1：失业率下降不等于一定好转——很多人放弃找工作（退出劳动力市场）后分母变小，失业率会“被动下降”。
- 坑 2：拿中美失业率直接对比——两国统计口径、劳动参与率和社保体系差异很大。
- 坑 3：把失业率当股市单一指标——就业要和通胀、利率放一起看才有效。
