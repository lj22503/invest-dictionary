# 住房公积金

> 住房公积金=单位和个人按月缴存的住房储金，可低息贷款买房、可提取，是买房人最值得用足的福利。

## 1. 这是什么

住房公积金=单位和个人各按工资5%-12%（多数单位7%-12%）缴入你的个人账户，钱归你所有，可用于买房贷款、租房提取、还贷冲抵、装修等。

它像国家给你开的“强制储蓄+低息贷款”组合：账户余额按一年期定存利率计息（目前约1.5%），但真正值钱的是用它申请公积金贷款。

打个比方：单位每月往你的“买房小金库”存一笔钱，买房时还能凭这个小金库申请便宜贷款，相当于双重福利。

> 一句话：公积金=公司白给的买房钱+低息贷款额度，别让它睡大觉。


## 2. 为什么重要

低息贷款：公积金首套贷款利率目前约2.6%-3.1%，比商业贷款低一大截；贷款100万、30年，利息能省十几万到几十万。

公司缴存是免费福利：月薪1万按12%缴存，公司每月帮你存1200元，一年1.44万，是实打实的“额外工资”。

提取灵活：租房、购房、还房贷、加装电梯、退休等都能提取，多数城市手机一键可办。

> 一句话：不缴公积金或按低基数缴，等于主动放弃公司的隐形加薪。


## 3. 怎么用 / 怎么看

第1步：查：用公积金App或支付宝“市民中心”查余额、缴存基数、可贷额度。

第2步：贷：买房优先申请公积金贷款；贷款额度与余额、缴存挂钩，别把账户掏空到影响额度。

第3步：冲：每月用公积金月对冲还房贷，或提取余额提前还贷，减少商贷利息。

第4步：提：不买房的人，租房可凭合同定期提取；退休后一次性全额取出。

> 一句话：用好公积金：能贷则贷、能提则提、能冲则冲。


## 4. 常见坑 / 误区

坑1：签“自愿放弃公积金”：公积金是法定强制缴存，公司不能因为你“同意”就不缴，否则违法。

坑2：余额常年躺着：公积金利率只有1.5%左右，跑不赢通胀，能提就提、能贷就贷。

坑3：为了省事全款买房、不用公积金：现金价值再高，也不如把低息额度用足、闲钱去做合理配置划算。

> 一句话：公积金的正确姿势：低息额度用满，活钱不闲置。
