# 4321法则（40/30/20/10 Rule）

> 工资到手先分四份：40% 投资、30% 生活、20% 存、10% 保险

## 1. 这是什么

4321 法则是一个按比例分配月收入的老办法：

- **40% 投资创富**：基金定投、股票、还房贷
- **30% 家庭生活开支**：吃饭、通勤、日用
- **20% 储蓄备用**：应急金、存款
- **10% 保险保障**：保费

月入 1 万就是：4000 拿去投、3000 过日子、2000 存起来、1000 买保险。

各地版本略有差异，也有人按“40% 生活、30% 房贷、20% 存、10% 保险”来用。

**比例不是重点，顺序才是重点**——把投资、储蓄、保险变成“先扣掉的固定支出”，而不是月底剩下多少算多少。

## 2. 为什么重要

多数人存不下钱，不是因为不会理财，而是因为**钱到手先花了**（收入 − 支出 = 储蓄）。

4321 法则是把它倒过来：**收入 − 储蓄 − 保险 = 可花的钱**。

- 20% 存下来，一年就是 2.4 个月工资；三年能攒出应急金 + 第一笔投资本金；
- 10% 保险，把“一夜返贫”的大风险（重疾、意外）转给保险公司，这是理财的地基；
- 40% 投资，靠复利把时间变成钱（参考：复利）。

一句话：**它让存钱变成默认动作，而不是靠意志力。**

## 3. 怎么用 / 怎么看

**第 1 步：用税后到手工资算基数**，不要用税前。

**第 2 步：工资到账当天自动划转。** 40% 进投资账户、10% 进保险/保障账户，剩下的才用来花。

**第 3 步：按自己的阶段调比例。**

- 25-35 岁、无房贷：投资可以提到 40%-50%，生活压到 30% 以内；
- 有房贷有娃：生活 + 房贷常常占到 70%，那就把投资降到 20%，**但 10% 保险和 10%-20% 应急储蓄必须保留**；
- 收入不稳定（自由职业）：先把储蓄提到 30%，投资可以等应急金攒够再说。

**第 4 步：用记账验证。** 连续记 3 个月，看“生活 30%”是不是真的守住了。

## 4. 常见坑 / 误区

**坑 1：把 40% 全押股票。** “投资创富”不等于满仓梭哈，这 40% 里也要分配股票和债券，别在牛市顶部进场。

**坑 2：顺序搞反。** 先花后存，永远存不下；要改成先存后花。

**坑 3：10% 保险买成了理财型。** 返还型、分红险保费高、保障低；同样预算应该优先买消费型的重疾 + 百万医疗 + 定期寿险。

**坑 4：照搬比例不看现金流。** 房贷已经占了收入 50% 的家庭，硬套“生活 30%”，最后只能靠信用卡补窟窿。
