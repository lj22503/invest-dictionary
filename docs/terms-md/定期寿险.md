# 定期寿险

> 保障期内身故或全残，赔一笔钱给家人，是家庭支柱的责任险。

## 1. 这是什么

定期寿险很简单：在约定保障期内（如保到60岁）身故或全残，保险公司赔一笔保额给家人。保障期结束没出事，保费就当消费掉了。

它不保自己，保的是家人——万一家庭支柱倒下了，房贷、孩子教育、父母赡养还能继续。

> 一句话：站着是印钞机，躺下是人民币。

## 2. 为什么重要

很多人以为寿险是给老人准备的，恰恰相反：最需要的是有房贷、有娃、有老人的家庭经济支柱。

- 房贷：几百万的负债不会因人不在了而消失。

- 孩子教育：十几年的教育金是刚需。

- 父母赡养：父母的养老钱也要有人管。

保费便宜、杠杆高：30岁男性100万保额，一年千元上下。

## 3. 怎么用 / 怎么看

- 保额 = 剩余房贷 + 孩子教育金 + 父母赡养费 + 家庭3-5年生活费。

- 期限：保到孩子独立或房贷还完即可，一般60岁够用。

- 选免责条款少的：通常只免除故意犯罪、酒驾等极少数情况。

- 健康告知同样如实填，别因小失大。

## 4. 常见坑 / 误区

- 坑1：买成终身寿险。保费贵好几倍，保障属性弱，多数人没必要。

- 坑2：保额算太少。只保了50万，房贷都覆盖不了。

- 坑3：给老人小孩买。他们不是经济支柱，买了意义不大。

- 坑4：健康告知遗漏。吸烟、体检异常等如实告知，避免理赔被拒。
