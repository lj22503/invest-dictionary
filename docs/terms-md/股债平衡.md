# 股债平衡

> 股债平衡=把资金按固定比例分到股票和债券两类资产（如60/40），用两类资产的“跷跷板”效应降低整体波动。

## 1. 这是什么

股债平衡=把资金按固定比例分到股票和债券两类资产上（比如股票60%、债券40%），并定期调回这个比例。股票负责进攻：长期收益高但波动大；债券负责防守：收益平稳、回撤小。

打个比方：像做菜要荤素搭配——只吃荤（全仓股票）容易消化不良，只吃素（全买债券）营养不够；股债平衡是给自己定好“几荤几素”。

常见比例：激进型70/30、均衡型60/40、稳健型50/50、保守型30/70（股票/债券）。

> 一句话：股债平衡的本质不是预测涨跌，而是让两类资产互相“补位”。


## 2. 为什么重要

股票和债券多数年份呈低相关甚至负相关：股市大跌时，资金常流向债市，债券反而上涨。股债平衡让你“东方不亮西方亮”，整体波动明显小于单压股票。

看数字：2008年A股最大回撤超过70%，同期债市反而走牛；满仓股票可能要熬七八年才回本，而60/40组合回撤大幅收窄、回本快得多。

对普通人来说，最大的风险不是赚得少，而是亏到拿不住、在最底部割肉离场。股债平衡正是少数能让你“拿得住”的简单办法。

> 一句话：平衡的不是收益，是心态。


## 3. 怎么用 / 怎么看

第1步：定比例。可用“100-年龄”粗略估算股票占比（30岁→股票约70%），稳健型可从50/50起步。

第2步：选工具。股票部分用宽基指数基金（如沪深300、中证500），债券部分用国债、纯债基金或货币基金，少碰看不懂的品种。

第3步：做再平衡。每年或每半年把比例调回目标：股票涨多了就卖一点补债券，跌多了就反向操作，自动实现“高抛低吸”。

第4步：定期复盘。收入、家庭结构、人生阶段变化时，重新评估比例是否需要调整。


## 4. 常见坑 / 误区

坑1：比例定了却从不做再平衡：涨得好的部分越占越重，风险不知不觉被放大，等于悄悄变回满仓股票。

坑2：用“感觉”替代规则：跌怕了把股票全砍光，涨疯了又全买股票——平衡变成了追涨杀跌。

坑3：把“固收+”、银行理财当纯债券：含权益的产品在极端行情照样会亏，先看清底层资产再归类。

> 一句话：平衡最大的敌人是“手痒”。
