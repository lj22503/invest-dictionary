# 规模魔咒

> 基金规模越大越难做出超额收益——船大难掉头，收益被摊薄。

## 1. 这是什么（基金越大越难赚钱）

规模魔咒 = 主动基金规模超过一定量级（一般 100-300 亿）后，**超额收益明显下降**。原因：大资金进出冲击成本高；小盘股容量有限买不进；打新、定增等增强收益被摊薄；调仓迟钝。

一句话：规模是业绩的敌人，越大越钝。

## 2. 为什么重要（为什么重要：规模是超额收益的敌人）

买主动基金时，“规模”和“业绩”同样重要：**一只 500 亿的明星基金，很难复制它 50 亿时的灵活**；而“冠军魔咒”的底层机制之一就是规模暴涨。

一句话：看懂规模，才能看懂业绩为什么“变差”。

## 3. 怎么用 / 怎么看（怎么看：多大算“大”）

主动权益基金：警惕 **200 亿以上**；量化基金：警惕 100 亿以上（策略容量更小）；小盘风格基金：50 亿就可能开始吃力。选基金公式：**策略容量内选业绩好、回撤小的**。

一句话：选基金先看规模，再看排名。

## 4. 常见坑 / 误区（常见坑：迷信明星基金经理）

以为“大基金=稳”——大不等于稳，反而等于钝；只看“明星经理”不看规模——他可能管着 300 亿；以为“规模大说明大家认可”——认可和收益是两回事；用规模小的老基金做基准——要对比同规模区间的同类。

一句话：明星经理+超大规模，往往是规模魔咒的重灾区。
