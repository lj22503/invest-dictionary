# 封闭式基金

> 封闭式基金是一只能像股票一样买卖的基金：份额固定、到期才开放，价格由市场说了算。

## 1. 这是什么

**份额锁死，场内交易**

- **封闭式基金＝份额固定、到期前不能申购赎回的基金**，发行时凑齐一笔钱，封闭期内规模不变；
- 想买卖？去交易所像股票一样挂单，价格由买卖双方实时撮合，不按净值结算；
- 封闭期通常 3—15 年，到期后要么清盘、要么转为开放式基金。
> 一句话：封闭式基金是把钱锁进箱子，箱子里是基金经理替你打理，箱子外按市场价转让。

## 2. 为什么重要

**折价与溢价的套利空间**

- 基金净值涨到 1.2 元，场内价格却可能只卖 1.05 元——这叫**折价**，折价率高了就有捡便宜的机会；
- 反之价格高于净值叫**溢价**，追高的人往往在“情绪税”上吃亏；
- 因为不能随时赎回，基金经理能拿钱做长期投资（比如定增、长期债券），少受赎回冲击。
> 一句话：封闭式基金的涨跌，一半看净值、一半看市场情绪，两者之间的差价就是机会和陷阱。

## 3. 怎么用 / 怎么看

- **看折价率**：场内价格 ÷ 净值 − 1，折价超过 15%—20% 时要看原因，别只贪便宜；
- **看到期日**：临近到期，价格会向净值收敛，折价率太高往往隐含风险（比如底层资产暴雷）；
- **看底层资产**：封闭期长，投的是债券还是股票、信用等级如何，先查持仓再说；
- **场内买卖认准场内代码**：封闭式基金在券商账户里交易，跟场外申购不是一个通道。

## 4. 常见坑 / 误区

- **把折价当白捡**：高折价可能是市场在提前“审判”底层资产，便宜有便宜的道理；
- **忽略净值与价格的时差**：场内价格是实时成交，净值每天盘后公布，别拿昨天的净值算今天的价差；
- **以为封闭期能赎回**：封闭期内只能场内卖出，场外份额想走得等开放期或到期；
- **溢价追高**：热门封基被炒出高溢价，一旦情绪退潮，价格可能向净值回归挨“双杀”。
