# ADR（美国存托凭证）

> 外国公司想在美国上市，就先发行一种"股票替身"——这就是 ADR，美国存托凭证。

## 1. 这是什么
**ADR（American Depositary Receipt）= 外国公司把股票打包存进美国托管银行，再由银行发行一份"凭证"在美股交易。**你买到的是凭证，但它背后对应着真实的外国公司股票，可以像普通美股一样买卖、分红。

打个比方：你想买法国红酒，不用跑到波尔多，本地进口商把酒存进保税仓，发你一张提货单——ADR 就是股票界的"保税仓提货单"。

> 一句话：ADR 让美国投资者不用开外国账户，也能用美元买卖外国公司。

## 2. 为什么重要
- **绕开两地上市门槛**：中国公司要在美股直接上市，要满足美国监管的财报、审计等要求；走 ADR 由托管银行操作，流程更顺；
- **阿里、京东、网易都在用**：这些公司既有港股，也有美股 ADR，一份 ADR 通常对应若干股普通股（比例由公司定）；
- **对个人投资者方便**：在美股账户直接搜代码就能买，不用去开香港或境内账户，也不用换汇到境外券商。

## 3. 怎么用 / 怎么看
- **确认 ADR 比例**：比如 1 份 ADR = 8 股普通股，算市值和每股价格时别直接用报价；
- **注意交易时间与费用**：ADR 在美东时间交易，托管银行会收存托费，长期持有有成本；
- **看汇率影响**：ADR 用美元计价，底层资产是人民币计价的港股/A股，人民币升值时美元换算会"缩水"，这层汇率波动逃不掉。

## 4. 常见坑 / 误区
- **把 ADR 价格当普通股价格**：两者存在换算比例和折溢价，直接对比会误判贵贱；
- **以为没有汇率风险**：底层资产在境外，汇率波动会直接影响美元回报；
- **忽视退市风险**：监管变化可能触发中概股 ADR 退市，届时可能强制转板或清仓，别把"在美股挂着"当永远。
