# 业绩预告 / 业绩快报

> 一个是提前打招呼，一个是先报个大概数——它们把业绩从定期报告变成了可以跟踪的过程。

## 1. 这是什么

**业绩预告，是公司在正式财报发布前对本期业绩做的提前披露；业绩快报，是在正式财报前发布的、接近定稿的主要财务数据。**两者都是正式定期报告之前的预告版本。

- **业绩预告**：给出方向或区间，如预增、预减、扭亏、首亏，通常在业绩变动达到一定幅度时披露；
- **业绩快报**：给出营业收入、净利润、每股收益等具体数字，准确度更接近正式财报。

> 一句话：预告看方向，快报看数字，正式财报才是最终答案。

## 2. 为什么重要

- **提前暴露风险**：巨亏、商誉减值、订单下滑，往往先在预告里露头；
- **提前确认景气**：预增幅度是判断行业景气度的第一手线索；
- **它是预期差的来源**：披露数据与市场预期之间的差距，直接决定短期股价反应；
- **快报与正式财报可能不一致**：快报数据未经完整审计，后续调整并不罕见。

## 3. 怎么用 / 怎么看

- **看方向与幅度**：预增、预减、扭亏、首亏，配合变动幅度判断趋势；
- **看变动原因**：主营增长、产品涨价，还是资产处置与政府补助，含金量完全不同；
- **看扣非口径**：扣除非经常性损益后的利润，才反映主业的真实能力；
- **与快报、正式财报交叉验证**：出现差异时，差异来源比差异本身更关键；
- **结合股价位置**：同样的预增，在低位是催化，在高位可能是兑现。

> 一句话：预告只是路标，别把它当成终点。

## 4. 常见坑 / 误区

- **把预告当定论**：预告是区间和估计，最终数字可能落在区间下沿甚至之外；
- **只看净利润不看来源**：卖房、卖股权带来的一次性收益无法持续；
- **忽略基数效应**：去年基数极低时的高增长，可能只是回到正常水平；
- **忘记快报不等于审计结果**：后续正式财报调整会带来新的波动；
- **忽视披露时间差**：等公告落地再行动，往往已经错过价格反应最快的一段。
