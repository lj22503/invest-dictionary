# 销售误导

> 卖保险时夸大收益、隐瞒条款、偷换概念，让你买到不合适的产品——这就是销售误导。

## 1. 这是什么

<strong>销售误导 = 卖保险时用话术让你对产品产生错误理解。</strong>最常见的形式有四类：

- 夸大收益：把分红险、万能险的“演示利率”说成“确定收益”，甚至说“比存款利息高”；

- 偷换概念：把保障型产品说成“理财”，把“现金价值”说成“本金”；

- 隐瞒条款：不说免责条款、不说退保损失、不说健康告知的义务；

- 制造焦虑：“马上停售”“最后一天”“额度有限”催你当场下单。

> 一句话：误导的核心不是骗你钱，是让你在错误的理解下签下名字。

## 2. 为什么重要

保险是长期合同，买错的代价很大：

- 退保损失：理财型保险前几年退保，现金价值通常只有已交保费的 50%-70%，5 万保费可能只拿回 3 万多；

- 保障缺失：该买医疗险结果买了理财险，真住院时一分不赔；

- 时间成本：保费占收入比例有限，被误导占用的缴费能力，让你错过真正需要的保障。

真实例子：有人听销售说“一年交 2 万，五年后连本带利拿回 11 万”就买了分红险，结果五年后退保只拿回 8.6 万——销售嘴里的“11 万”是演示收益，不是保证收益。

## 3. 怎么用 / 怎么看

- 口诀一：先保障、后理财——医疗、重疾、意外没配齐，别碰理财险；

- 口诀二：只看“保证”部分——收益只认合同里写死的保证利率，演示利率仅供参考；

- 口诀三：退保损失问到底——让销售出示现金价值表，问清第 1 年、第 3 年退保拿回多少；

- 口诀四：口头承诺要留证——要求双录，重要承诺让对方写进合同或发书面文件；

- 压舱石：用足犹豫期——保单签收后通常有 10-15 天犹豫期，期内退保无损失，回家冷静核对条款。

> 一句话：合同没写进去的，都别当真；销售没写在纸上的，都别相信。

## 4. 常见坑 / 误区

- 坑一：把“演示收益”当承诺——非保证部分写的是中档/高档利率，实际可能只有低档；

- 坑二：只盯收益率不看保障——理财险的保障责任往往很薄，住院不赔很常见；

- 坑三：健康告知被带过——销售说“随便填都行”，结果理赔时查出隐瞒，拒赔；

- 坑四：停售、限量话术——真停售不等于产品好，限量的东西也可能是清库存；

- 坑五：代签字——被诱导让家人代签、代答，合同效力都可能出问题。
