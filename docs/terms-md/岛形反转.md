# 岛形反转

> 价格先跳空拉升、再跳空砸落，中间像一座孤岛——顶部反转的强烈信号。

## 1. 这是什么

岛形反转，是价格被两个方向相反的跳空缺口夹在中间，像一座孤岛。**顶部岛形**最常见：先一个向上跳空缺口快速拉升，随后几天横在缺口上方（岛上），再突然一个向下跳空缺口砸破下方——孤岛悬空，里面的买盘全被套住。

底部岛形则相反：先向下跳空、横盘、再向上跳空，是反转向上的信号，但比顶部岛形少见得多。

它多出现在情绪亢奋后的急转直下——题材炒作末期、利好兑现后的“见光死”，就是典型场景。


## 2. 为什么重要

顶部岛形反转意味着：**在岛上买入的资金被一网打尽**，上方从此堆满套牢盘，后市往往持续走弱。它是一个“离场信号”，不是“抄底机会”。

历史经验：不少大级别顶部（指数和热门板块）都伴随岛形结构出现，因为它是资金在情绪顶点集体出货的图形化痕迹。

对普通人的价值：**一旦确认顶部岛形，要做的不是抢反弹，而是管住手**——它提示后面大概率还有下跌。


## 3. 怎么用 / 怎么看

- 第一步：确认两个缺口方向相反——先向上跳空、再向下跳空（或反之），方向一致不叫岛形
- 第二步：确认中间横盘数日——岛上的价格要真正“悬空”几天，不能当天就补缺
- 第三步：看向下跳空当天量能——放量跳空向下，信号更可信
- 补充：指数级别的岛形比个股可靠——个股的缺口容易被资金操纵


## 4. 常见坑 / 误区

- 坑 1：单个缺口就喊岛形——岛形必须由两个方向相反的缺口构成，缺一不可
- 坑 2：确认后还幻想反弹——顶部岛形一旦确认，反弹多是逃命机会
- 坑 3：忽略缺口回补——A 股普通缺口常被回补，岛形要看关键缺口是否快速被回补
- 坑 4：拿分时/小时级别看岛形——级别太小噪音太大，日线以上级别才更有意义
