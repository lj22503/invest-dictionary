# 达克效应

> 能力越差的人越容易高估自己——新手觉得炒股很简单，老手反而战战兢兢，这条曲线叫达克效应。


## 1. 这是什么

**达克效应（邓宁-克鲁格效应）= 能力不足的人往往意识不到自己能力不足，反而自信爆棚；真正懂行的人因为知道“不知道的东西太多”，反而谦虚谨慎。**画成图就是一条曲线：**“愚昧之巅 → 绝望之谷 → 开悟之坡”**。两个心理学家凭这个研究拿了 2000 年搞笑诺贝尔奖，但它是真的。> 一句话：自信爆棚的时候，往往是你最无知的时候。

## 2. 为什么重要

在投资里，最危险的不是不懂，而是“不知道自己不懂”：新手刚入市碰上牛市，买啥涨啥，马上觉得自己是股神——这种状态最容易加仓、上杠杆、借钱炒股，然后被一次大跌打穿。行为金融学有大量实证：**散户亏损的一大来源就是过度自信导致的频繁交易**。买的越多、换的越勤，手续费和错误越多，收益越差。> 一句话：牛市是新手的“愚昧之巅”，也是老手的“毕业考试”。

## 3. 怎么用 / 怎么看

- **定期给自己打分**：你的投资能力 1-10 分能打几分？写下“我凭什么赚到钱”的理由。
- **设“无知道德约束”**：不懂的品种不碰；凭运气赚的钱单独记账，别算进能力。
- **复盘归因**：每笔亏损都要写清楚是运气、市场还是决策问题。
- **听高手的语气**：真正懂行的人常说“我不确定”，满嘴“必然”的多半在愚昧之巅。> 一句话：把“我猜”和“我知道”分开，是投资的第一课。

## 4. 常见坑 / 误区

- **把牛市收益当能力**：Beta 当 Alpha，退潮时才发现自己在裸泳。
- **看几本书就当专家**：去“指导”别人、代客理财，赔了钱还要背骂名。
- **拒绝认错，加倍下注**：亏损后摊平成本，越跌越买，直到弹尽粮绝。
- **用结果反推能力**：赚钱 ≠ 懂，短期结果噪音极大，掷硬币也能连赢十把。
- **嘲笑别人“不懂还自信”**：你指出别人在山顶时，自己可能也在另一座山顶。> 一句话：承认自己不知道，是知道一切的开始。
