# 龙头股

> 龙头不是“涨得最多的那只”，而是“行业离不开的那家”。

## 1. 这是什么

**龙头股，通常指一个行业里市占率、盈利能力、品牌影响力排第一梯队的公司。**

- **两种“龙头”要分清**：基本面龙头是真正的行业第一，市场龙头是资金炒作的领涨股

- **常见特征**：市占率高、毛利率稳定、定价权强、机构持仓集中

- **黑话里的“龙一”“龙二”**：更多指题材炒作里的领涨和跟涨股，和基本面关系不大

> 一句话：龙头不是“涨得最多的那只”，而是“行业离不开的那家”。

## 2. 为什么重要

- **资金效率高**：行情起来时资金优先买确定性最高的标的，龙头通常先启动、涨幅居前

- **抗风险强**：行业下行时靠规模和成本优势活得比同行好，跌得也相对少

- **是行业景气度的温度计**：龙头的业绩和股价，往往是整条产业链的先行指标

- **对普通投资者友好**：不想研究一整个行业，买龙头是性价比最高的简化方案

但要注意：龙头股往往“贵”，溢价来自确定性；一旦确定性被打破，杀估值也很狠。

## 3. 怎么用 / 怎么看

- **三条硬指标**：市占率行业前三、ROE 长期高于同行、毛利率稳定或有提升趋势

- **看定价权**：能不能提价而不丢客户，是护城河最直接的证据

- **看资金认可度**：机构持仓比例、北向资金持股变化，能反映“聪明钱”的态度

- **看产业链位置**：上游资源、中游制造、下游品牌，谁在链条里拿走最多利润，谁更可能是龙头

- **分清楚再下手**：基本面龙头可以长期持有，题材龙头只能短线参与，风险和仓位完全不同

> 一句话：找龙头，本质是找“行业里最有定价权的那家公司”。

## 4. 常见坑 / 误区

- **把“涨得最多”当龙头**：题材炒作里的领涨股可能基本面平平，退潮时跌得最惨

- **在最高点买龙头溢价**：龙头长期享受估值溢价，但溢价到极致同样会均值回归

- **忽略行业周期**：行业下行时龙头也扛不住，只是相对跌得少

- **混淆“行业龙头”和“龙头股炒作”**：前者是投资，后者是博弈，仓位和纪律完全不同

- **只买一只所谓龙头**：行业格局会变，曾经的龙头也可能被技术路线淘汰
