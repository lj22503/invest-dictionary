# 股息率策略

> 专门买“分红多、股息率高”股票的收息策略，像股票版的“收租”。高股息通常意味着低估值，防御属性强。

## 1. 这是什么（股票版的“收租”策略）

股息率策略 = 专门买“分红多、股息率高”股票的收息策略。
股息率 = 每股分红 ÷ 股价。比如一只股票股价 10 元、每年分红 0.5 元，股息率就是 5%——比很多理财都高。
买这类股票就像“股票版收租”：股价涨不涨都有分红现金流。
经典代表：格雷厄姆、约翰·聂夫；指数代表：中证红利、上证红利等红利指数。
一句话：不赌股价，只收“房租”——这就是股息率策略。

## 2. 为什么重要（为什么重要：分红与估值的双重保护）

高股息股有双重保护：
分红现金流：股价不涨，每年也有钱拿，适合现金流规划；低估值缓冲：股息率高通常意味着估值低，下跌空间相对小。
长期看，红利策略在震荡市和熊市表现稳健（防御属性），牛市往往跑输成长股。
银行、煤炭、电力、高速公路、公用事业，是高股息股的集中营。
一句话：它赚的是“慢钱”，但慢得稳。

## 3. 怎么用 / 怎么看（怎么用：四步筛出好红利股）

筛股息率：目标 4% 以上，才有明显的“收息”意义；看分红持续性：连续 3–5 年稳定分红，别买“今年分完明年不分”的；看分红比例：分红占利润比例别超 100%（全分光不可持续），50%–70% 比较健康；看负债与现金流：高负债 + 低现金流的分红，迟早缩水；分红再投资：把分红再买入，复利滚雪球，长期收益差距巨大。
一句话：先看能不能持续分，再看分多少。

## 4. 常见坑 / 误区（常见坑：股息率陷阱）

股息率陷阱：股价暴跌会让股息率“被动升高”——分母变小了，可能是基本面恶化，这就是经典的价值陷阱；忽略除息：分红后股价要除息（跌掉分红额），短期看“等于没赚”，别以为分红是白送的；以为高股息=高回报：公司利润持续下滑，分红也会缩水，股息率再高也白搭；忘掉红利税：内地个人投资者持股 1 个月内分红扣 20% 税、1 年以上免税——短线做红利策略会被税吃掉利润。
一句话：高股息率要配高分红质量，缺一不可。
