# 分级基金

> 分级基金是把一只母基金拆成保守和激进两层：一层吃固定收益，一层加杠杆博高收益，曾火遍市场、现已基本退场。

## 1. 这是什么

**一只母基金，两层子份额**

- **分级基金＝母基金拆成 A 类（约定收益）和 B 类（杠杆份额）**，A 拿“固定利息”，B 用借来的钱放大涨跌；
- B 份额向 A 份额“借钱”炒股：母基金涨，B 放大上涨；母基金跌，B 加速下跌甚至“下折”；
- 2015 年股灾后监管收紧，2020 年底存量的分级基金已基本整改清零。
> 一句话：分级基金是把同一笔钱拆成“吃利息的”和“赌杠杆的”两拨人，B 赚的是波动的钱、担的是波动的命。

## 2. 为什么重要

**杠杆的教科书：看懂 B 份额，就懂杠杆的双刃剑**

- 2015 年牛市里分级 B 一周翻倍，股灾里却一周跌掉七八成，甚至触发**下折**一夜巨亏；
- 下折机制：净值跌破阈值（通常 0.25）时按净值折算，杠杆归零、份额缩水，账面浮亏变成永久损失；
- 它教给普通人的一课：**加杠杆的产品，跌起来不是按百分比，是按“归零的速度”**。
> 一句话：分级 B 是给散户上的“杠杆风险公开课”，学费往往很贵。

## 3. 怎么用 / 怎么看

- **先分清 A 和 B**：A 类收益接近“类固收”，B 类是风险资产，两者风险和收益天差地别；
- **盯紧折算阈值**：净值逼近下折线（0.25 附近）时要果断处理，别赌“差一点不触发”；
- **算清楚杠杆倍数**：初始杠杆 2 倍，跌到临界区杠杆会飙升，波动被进一步放大；
- **认准整改状态**：存量分级基金陆续转型为普通 LOF 或清盘，买前先确认它还是不是“分级”。

## 4. 常见坑 / 误区

- **以为 B 类“涨得快跌得也快但能扛”**：下折是“重置”，不是普通回撤，跌下去的部分可能永远回不来；
- **把 A 类当无风险存款**：A 类也有信用风险和市场波动，牛市里反而常被折价甩卖；
- **不懂“溢价买入”**：B 类高溢价时买入，一旦下折，溢价瞬间蒸发，亏损远超净值跌幅；
- **以为分级已彻底消失就无关**：它的杠杆逻辑今天仍在——杠杆 ETF、融资盘都是同一个故事的不同版本。
