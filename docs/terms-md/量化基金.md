# 量化基金

> 用数学模型和程序代替人工做交易决策的基金，纪律严格、持仓分散，但也会在市场极端时集体踩踏。

## 1. 这是什么

### 用程序代替人脑炒股

**量化基金 = 用数学模型、统计规律和计算机程序来做投资决策的基金。**人脑靠经验拍板，量化靠海量数据回测：哪类股票在什么条件下大概率跑赢，程序就按规则批量买卖。

典型操作是分散持仓几百上千只股票，赚「大概率」的钱，而不是赌单只牛股。

一句话：量化基金买的不是「感觉」，是「统计优势」。

## 2. 为什么重要

### 为什么重要：规模与争议并存

量化在国内曾管理上万亿规模，贡献了市场大量成交，是 A 股不可忽视的力量。但它的短板也暴露过：2024 年初小微盘股踩踏，多只量化产品单周回撤超过 20%，原因是大量策略挤在同一条「小市值」赛道上。

量化不创造额外收益，只是把一部分超额收益从别人手里「抢」过来——你买的主动基金跑不赢指数，可能就输给了量化。

一句话：量化是市场的「鲶鱼」，也是踩踏时的「同向列车」。

## 3. 怎么用 / 怎么看

### 怎么用：看懂量化基金

**先分类型**：指数增强对标指数+超额收益；市场中性对冲掉市场涨跌、只赚超额；量化多头不对冲、波动大；**看超额收益稳定性**：连续 2~3 年稳定跑赢，比某一年爆发更可信；**看最大回撤**：中性策略回撤一般控制在 5% 以内，超过要警惕策略失效；**警惕规模膨胀**：同一策略管 10 亿和 100 亿，效果完全不同，规模是量化的敌人。

## 4. 常见坑 / 误区

### 常见坑：以为量化稳赚

**以为量化稳赚不赔**：2024 年初的踩踏证明，量化回撤起来一样吓人；**把「高频」当「必胜」**：高频交易拼的是速度与成本，个人根本没法参与，别被概念洗脑；**忽视拥挤交易风险**：大家都用同一种因子时，因子就会失效甚至反向；**不看过往规模变化**：一只产品业绩好是因为当年规模小，规模上来了业绩就变脸；**买看不懂的策略**：净值曲线再漂亮，说不清策略逻辑的产品，先放一放。
