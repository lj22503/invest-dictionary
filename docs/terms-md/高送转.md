# 高送转

> 上市公司大比例送红股或转增股本，常被当成“发红包”，本质是拆股。

## 1. 这是什么

高送转指上市公司大比例送红股或转增股本，常见“10送10”“10转8”这类方案。送股用的是利润，转增用的是资本公积。

关键要懂：股份变多了，但总市值不变。10送10后你股票数量翻倍，股价除权后也腰斩，手里的总资产一分没多。

> 一句话：一张100块换成两张50块，不是发钱。

## 2. 为什么重要

高送转常被市场当利好炒作，因为它传递了“公司有底气、愿意回馈股东”的信号，尤其配合高增长预期。

- 降低股价：让高价股“变便宜”，吸引散户参与。

- 流动性提升：股本变大，交易更活跃。

- 炒作窗口：年报/中报披露前后是高送转行情高发期。

## 3. 怎么用 / 怎么看

- 送转本身不产生价值，真正有意义的是除权后的“填权”——股价涨回除权前。

- 配合业绩看：高送转+高增长，填权概率大；单纯炒作，追高风险高。

- 算清除权价：送转后成本价同步下调，别被“便宜了”误导。

## 4. 常见坑 / 误区

- 坑1：以为白得股份=白得钱。除权后股价同步下调，资产没变。

- 坑2：追“高送转预期”。预期提前透支，公布后反而“利好出尽”下跌。

- 坑3：忽视减持配合。高送转+股东减持组合，往往是高位出货套路。
