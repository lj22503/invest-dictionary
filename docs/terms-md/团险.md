# 团险

> 公司给一群人集体买的保险，价格比个人单买便宜，很多人第一份保障就来自这里。

## 1. 这是什么

**团险 = 以“团体”为单位集体投保的保险**，最常见的场景是企业给员工买团体意外险、团体医疗险、团体重疾险。

因为是一群人一起买、风险分散，保险公司敢给更低价格、更松门槛：**个人健康告知宽松（或只问几个大项）、不限既往症、费率便宜**。很多人的第一份保障，其实就是公司团险。

> 一句话：团险是“批发价”的保险，个人买是“零售价”。

## 2. 为什么重要

对刚工作的年轻人，团险常常是唯一一份保险。它解决了一个关键问题：**给“没保险意识、没预算”的阶段兜底**。

团险的价值不只是免费：

- **价格低**：同样保障，团险费率常比个险便宜30%以上；
- **门槛低**：有慢性病、年纪大的员工也能买；
- **覆盖广**：意外、医疗、重疾、寿险常打包在一起。
但它有个致命特点：**团险是“在职福利”，离职即失效**。

## 3. 怎么用 / 怎么看

- **入职先摸底**：向HR要团险手册，看清楚保什么、保多少、门诊报不报；
- **离职前查转保**：很多公司团险支持“离职转个人版”，在原保单上继续交费，通常免健康告知——这是薅羊毛的好机会；
- **把团险当“底”，自己补“缺口”**：公司保额普遍不高（意外10-30万常见），重疾、寿险缺口自己补上。
> 一句话：团险是公司发的“福利底”，不是终身依靠。

## 4. 常见坑 / 误区

- **以为保一辈子**：离职、退休、公司换供应商，团险随时可能没了；
- **以为保额够用**：团险保额普遍偏低，真出大事不够赔；
- **没注意“换保险公司”**：公司明年换供应商，新保单可能重新核保；
- **以为含门诊**：很多团险只保住院和意外，门诊要自费；
- **忘记给家人配**：团险保的是员工本人，配偶和子女要么没有、要么额度很低。
