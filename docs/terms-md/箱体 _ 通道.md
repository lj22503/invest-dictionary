# 箱体 / 通道

> 价格在上下两条平行线之间来回震荡——上沿压力、下沿支撑，来回“坐电梯”。

## 1. 这是什么

**箱体**：价格在一个矩形区间里来回震荡——上沿反复触顶回落（压力），下沿反复触底反弹（支撑），像在箱子里上下弹。

**通道**：趋势行情里，价格沿两条平行斜线走：上升通道（低点不断抬高）、下降通道（高点不断降低）。

本质都一样：**多空双方在某个价格区间暂时达成平衡**，谁也打不赢谁，价格就在里面来回“坐电梯”。


## 2. 为什么重要

A 股大部分时间处于震荡期，识别箱体可以避免最伤人的两件事：**上沿追高、下沿割肉**。

箱体里的正确姿势是反过来：上沿附近别追、下沿附近别慌。而通道则是趋势行情里的“安全带”：沿着上升通道走，跌破下沿就要警惕趋势结束。

对基金定投者也重要：震荡箱体里定投，成本会被摊在区间中部，比追高舒服得多。


## 3. 怎么用 / 怎么看

- 第一步：找出两个以上上沿高点和下沿低点，画平行线确认箱体/通道
- 第二步：上沿附近分批减仓、下沿附近分批加仓，箱体内不追高不杀跌
- 第三步：盯突破——放量突破上沿可能开启新趋势（转多头思维），放量跌破下沿要防下跌趋势
- 纪律：箱体策略要设好“破位离场”条件，最怕把箱体当永动机


## 4. 常见坑 / 误区

- 坑 1：把趋势行情当箱体高抛低吸——主升浪里“高抛”后买不回来，等于卖飞
- 坑 2：箱体上下沿没经过多次验证——只碰过一次的点位画线，误差太大
- 坑 3：突破时量能不足还追——大概率假突破，会被拉回箱体
- 坑 4：长期横盘箱体被打破后没有应对计划——破位是最需要纪律的时刻
