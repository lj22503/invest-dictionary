# 破净率

> 破净率 = 股价跌破每股净资产的股票占全部股票的比例。破净率越高，市场越悲观，也越接近"底部区域"。

## 1. 这是什么

破净率，就是统计范围内**市净率（PB）小于 1（股价 < 每股净资产）的股票占比**。比如 5000 只股票里有 500 只破净，破净率就是 10%。

为什么看它？因为"破净"意味着**市场愿意用低于账面家底的价格买公司**，通常反映极度悲观或行业困境。全市场破净率是判断 A 股"冷到什么程度"的经典指标之一：

- **历史底部特征**：A 股几次大底（2005、2008、2013、2018 前后）破净率都明显抬升；
- **风格特征**：银行、地产、钢铁等传统行业破净最多，科技、消费股极少破净；
- **不是万能的**：破净率只是"温度计"，不代表"必然反转"。

> 一句话：破净率 = 多少股票跌破账面家底，越高说明市场越冷，历史上常出现在大底附近。

## 2. 为什么重要

**破净率是"市场极端位置"的参考标尺**：

- **情绪冰点**：破净率大幅上升，说明悲观情绪弥漫、抛压充分释放；
- **历史对照**：把当前破净率与历次大底对比，能判断市场处于什么"温度区间"；
- **结构性机会**：破净股集中的行业（银行、周期）中，部分被错杀的公司可能有修复空间；
- **风险提示**：破净率低位（股价普遍远高于净资产）时，要警惕估值泡沫，尤其是牛市后期。

**真实场景**：2018 年底，A 股破净率一度超过 10%，市场悲观到极点。随后 2019-2020 年走出结构性慢牛。破净率没告诉你"哪一天见底"，但确实提示了"已经很冷"。

## 3. 怎么用 / 怎么看

- 第一步：找全市场**破净股票数量 ÷ 全部股票数量**，算出当前破净率（数据平台有现成统计）；
- 第二步：对比历史区间——破净率超过 8%-10% 往往对应深度熊市区域，跌破 2% 常对应牛市亢奋期；
- 第三步：看**破净集中的行业**——是普跌还是个别行业崩塌，决定是"全市场底"还是"行业底"；
- 第四步：结合估值（市盈率分位）、成交额、开户数等交叉验证，别只看单一指标；
- 第五步：破净率高时，优先看**基本面没有恶化的错杀股**，而不是单纯"便宜就买"。

> 一句话：破净率是"寒冷计"，高破净=冷到极致，但拐点还要等基本面/资金面确认。

## 4. 常见坑 / 误区

- **坑 1：把破净率当"精确抄底信号"**：它只能提示"处于历史低温区"，不能预测反弹时间；
- **坑 2：以为破净股都便宜**：银行破净背后可能是坏账担忧，账面净资产"水分"要挤一挤；
- **坑 3：忽略破净率的统计口径**：不同平台是否包含 ST、次新股、退市整理股，数据会有差异；
- **坑 4：拿它判断牛市顶部**：破净率低说明市场贵，但贵可以更贵，顶部常伴随"破净率极低 + 情绪极热"双重信号；
- **坑 5：只看全市场不看个股质量**：破净率高不等于每只破净股都能涨，基本面烂的公司可能一直破净。
