# 开放式基金

> 开放式基金是可以随时申购赎回的基金：今天买、明天卖都行，规模随资金进出变大变小。

## 1. 这是什么

**份额敞开，随时进出**

- **开放式基金＝没有固定规模、投资者随时能申购和赎回的基金**，余额宝、大多数场外基金都是这一类；
- 你申购的钱进来、赎回的钱出去，基金规模随之变化，基金经理得留一部分流动性应对赎回；
- 赎回按**当日收盘后的净值**成交，买入和卖出的价格每天只有“一个数”。
> 一句话：开放式基金像自助餐厅，随时进场随时离场，价格每天结算一次。

## 2. 为什么重要

**门槛低、流动性好，是普通人买基金的主力形态**

- 起点低：1 元、10 元就能申购，钱包、理财 App 里的基金基本都是开放式；
- 赎回灵活：急用钱时 T+1、T+2 就能到账，不像封闭式要等开放期；
- 代价也在这：资金随时进出，基金经理做长期投资时多了“赎回挤兑”的约束，规模越大越考验能力。
> 一句话：开放式基金用“随时能走”换“更多人愿意来”，代价是基金经理不能完全按长期思路梭哈。

## 3. 怎么用 / 怎么看

- **看清赎回到账时间**：货基最快、债基 T+1 左右、股基 T+1 确认再 T+1 到账，急用钱要留足提前量；
- **看规模与流动性**：迷你基金容易清盘，暴涨暴跌的规模也影响经理操作，选规模适中的更稳；
- **大额申赎注意限额**：有的基金会暂停大额申购或设置单日限额，别临场才发现买不进去；
- **看净值计价方式**：15:00 前申购按当日净值，15:00 后按下一交易日净值，卡点操作要算清。

## 4. 常见坑 / 误区

- **以为开放式基金“随时都能卖”**：赎回要 T+N 到账，且部分基金有赎回费惩罚，短期频繁进出成本很高；
- **把“开放式”当“保本”**：开放的是进出通道，不是收益保障，照样可能亏；
- **忘记巨额赎回规则**：发生巨额赎回时基金可以延期支付或部分赎回，极端情况下并不“想走就走”；
- **只看七日年化不看净值波动**：货币类以外的开放式基金净值天天变，别拿“每天都有收益”的预期去套。
