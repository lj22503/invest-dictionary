# 房价

> 房价=一套房子的成交价格，它一半是居住品价格，一半是金融资产价格。

## 1. 这是什么

房子有双重身份：居住品（住得舒服）和金融资产（能升值、能抵押贷款）。所以房价既受收入、人口等基本面影响，也受利率、政策和市场预期影响。

官方发布的“全国均价”是把一二三四线城市混在一起的平均数，参考意义有限，看城市比看全国更重要。

> 一句话：房价短期看金融（利率和情绪），长期看人口和收入。

## 2. 为什么重要

对多数家庭，房子是最大资产，也是最大负债（房贷）。房价大幅下跌，很多家庭几年的积蓄就没了，还会拖累消费信心。

房地产链条很长：卖地收入关系地方财政，建材、家电、装修带动就业，房贷影响银行资产质量，所以“稳楼市”常被视为稳经济的重要抓手。

房价上涨还有财富效应：房子值钱了，人们觉得自己有钱了，才敢花钱。

> 一句话：房价波动的不只是砖头，而是家庭的资产负债表和整个经济的预期。

## 3. 怎么用 / 怎么看

- 第 1 步：看城市别用全国数字：一线、强二线和收缩型城市完全是三个市场。
- 第 2 步：看二手房成交量和挂牌量：量在价先，成交量连续放大往往是价格企稳的前兆；挂牌量暴增则说明抛压在增加。
- 第 3 步：看租金回报率：年租金/房价接近甚至高于房贷成本，才更像“真资产”；租金回报率过低的城市，价格更多靠预期撑着。
- 第 4 步：看政策组合与收入预期：限购、房贷利率、首付比例的变化是先行信号，但政策底不等于市场底。

## 4. 常见坑 / 误区

- 坑 1：看“均价”判断自己城市涨跌——豪宅成交会大幅拉高均价，结构差异巨大。
- 坑 2：用过去20年涨幅线性外推——“闭眼买房躺赚”依赖人口红利和货币宽松，这两个条件都在变化。
- 坑 3：把“政策利好”当“马上要涨”——从政策底到市场底往往要磨很久，高杠杆抄底可能先被利息和阴跌打爆。
