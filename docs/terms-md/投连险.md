# 投连险

> 保险壳子里的"基金"，涨跌自负、不保本不保息

## 1. 这是什么

**投连险（投资连结保险）** = 保费扣除费用后，进入多个**投资账户**（类似基金组合），账户价值随市场涨跌，风险和收益全部由投保人承担。

账户通常分**激进型（股票为主）、稳健型（债券为主）、保守型（货币为主）**，可自由配置和转换。

## 2. 为什么重要

- 它是保险里**最像投资**的产品——**可能亏本**，且没有保底收益。
- 很多人把它当"理财"买，市场跌了才发现账户缩水、欲哭无泪。
- 保险保障只是薄薄一层，主要功能其实是"通过保险渠道买基金"。

## 3. 怎么用 / 怎么看

**买之前先搞懂三件事：**

1. **账户类型**：激进账户波动大，可能一年跌 20%+，保守账户才接近存款收益。
2. **费用结构**：初始费用、账户管理费、转换费都比普通基金高，长期持有才划算。
3. **风险自担**：合同明确"投资风险由投保人承担"，亏了保险公司不赔。

**适合**：有投资经验、能承受波动、有长期闲置资金的人；不适合当养老金/教育金的主力。

## 4. 常见坑 / 误区

**坑 1：当"理财产品"买** — 以为像存款一样稳，结果账户跟着股市大跌，本金缩水。

**坑 2：销售误导"稳赚"** — 投连险历史上出过大量纠纷，监管要求销售时必须充分揭示风险。

**坑 3：频繁转换账户** — 每次转换有费用，频繁操作收益没赚到，手续费先花掉一大笔。

**坑 4：费用比基金贵** — 同样的钱买指数基金更便宜透明；投连险的"保险外壳"价值有限。
