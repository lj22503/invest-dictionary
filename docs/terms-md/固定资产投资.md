# 固定资产投资

> 全社会"盖厂房、修路、买设备"的钱——固定资产投资是拉动经济增长的三驾马车之一。

## 1. 这是什么

固定资产投资指建造和购置固定资产的工作量，涵盖基建、房地产、制造业三大块，是衡量"全社会有多少钱在搞建设"的核心指标。

统计上常看"固定资产投资（不含农户）"同比增速，由统计局按月公布。它是 GDP 中"投资"分项的主体，与消费、出口并称拉动经济的三驾马车。

## 2. 为什么重要

- 投资增速变化直接反映政府稳增长的力度：经济偏弱时，基建往往率先加码；
- 制造业投资更市场化，反映企业对未来的信心；
- 房地产投资影响上下游产业链，是观察地产周期的重要窗口。

## 3. 怎么用 / 怎么看

- 拆结构：把总量拆成基建、房地产、制造业三块，看谁在发力、谁在拖后腿；
- 看资金来源：专项债、财政支出到位，基建才有弹药；
- 看实物量：挖掘机销量、水泥价格、开工率等高频数据可提前验证；
- 结合价格：名义增速扣掉价格因素，才知道真实工作量。

## 4. 常见坑 / 误区

- 只看总量忽略结构：总量持平但内部"一升一降"，含义完全不同；
- 把房地产投资当成全部：房地产只是三块之一，制造业和基建同样关键；
- 忽视统计口径：同比增速受基数影响，去年低基数年份增速会"虚高"。
