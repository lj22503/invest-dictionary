# 纸黄金

> 银行账户里"记账式"的黄金，1 克起买，跟着金价涨跌、但不能提实物金条的纸黄金。

## 1. 这是什么

纸黄金是在银行开一个黄金账户，**按实时金价买入"克数"**：账户里记着你拥有多少克黄金，价格跟着国际金价波动。想卖出时，按市价换成人民币，T+0 到账。

关键区别：纸黄金是"记账"，不是"实物"。它**不能兑换成金条搬回家**（部分银行支持补差价提取实物，但规则复杂、成本不低），买的就是账户里的黄金数字。

## 2. 为什么重要

实物金条有三大麻烦：保管要安全、回购有折价、还要防假货。纸黄金把这些都省了：

- **门槛低**：1 克起买，几百块就能参与；
- **无保管费**：不用租保险柜、不用买金条盒；
- **交易灵活**：交易日随时买卖，T+0。

它是普通人参与金价的低门槛方式，也是资产配置里对冲通胀、分散风险的一个选项。

## 3. 怎么用

- 第一步：在银行开通贵金属账户（多数手机银行可自助开通，需做风险测评）；
- 第二步：看懂报价——国内人民币金价 ≈ 国际金价 × 汇率 + 升贴水，买入价和卖出价之间有"点差"；
- 第三步：别一把梭，用定投的方式分批买入，摊平成本；
- 第四步：设好心理价位：既想清楚为什么买黄金，也定好什么时候卖。

## 4. 常见坑 / 误区

- **纸黄金≠黄金ETF**：纸黄金是银行报价、柜台交易；黄金 ETF 是场内交易、可实物申赎，两者机制不同；
- **以为买了金条**：纸黄金提不了实物，别把它当"压箱底的黄金"；
- **忽略点差和手续费**：频繁短线买卖，点差和费用会吃掉大部分利润；
- **以为黄金只涨不跌**：金价同样会大幅波动，它不是保本理财，照样会亏。
