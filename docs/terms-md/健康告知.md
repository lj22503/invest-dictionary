# 健康告知

> 买保险前如实回答身体状况的问卷，问什么答什么，是决定能不能赔的关键。

## 1. 这是什么

买重疾险、医疗险、定期寿险时，保险公司会问：有没有住过院、查出的结节、慢性病、体检异常等。你按问什么答什么的原则如实填。

它决定保险公司是否承保、按什么价格承保、是否除外某些疾病，也直接决定将来能不能顺利理赔。

> 一句话：健康告知 = 理赔的“考试卷”，填错可能不及格。

## 2. 为什么重要

《保险法》第十六条：故意不履行如实告知义务的，保险公司可以拒赔并解除合同、不退保费。

即使不是故意的，只要足以影响承保决定，保险公司也能拒赔，最多退还现金价值。

而如实告知的后果最多是：正常承保 / 加费 / 除外责任 / 拒保——至少不会“买了白买”。

> 一句话：健康告知的坑，理赔时才爆，代价最大。

## 3. 怎么用 / 怎么看

原则一：有限告知，只回答问卷问到的，没问的不必主动补充。

原则二：以记录为准，对照体检报告、门诊病历回忆，别凭印象。

原则三：先核保再投保，有异常项先走智能核保/人工核保，留好结论记录。

> 一句话：问什么答什么，有记录就如实写。

## 4. 常见坑 / 误区

坑 1：听业务员说“带病投保，熬过 2 年不可抗辩期就能赔”——重大恶意隐瞒仍可能拒赔。

坑 2：投保前特意去体检，查出新异常反而更难买。

坑 3：医保卡借给别人买药/看病，记录可能算在你头上，理赔时说不清。

> 一句话：健康告知最大的坑，是听别人替你“保证”。
