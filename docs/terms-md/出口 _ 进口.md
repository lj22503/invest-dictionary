# 出口 / 进口

> 出口=把商品和服务卖给外国人赚外汇，进口=向外国人买东西花钱，两者是国家对外贸易的两扇窗。

## 1. 这是什么

出口：本国企业把商品或服务卖给其他国家，比如中国工厂把手机、家电、新能源车卖到欧美和东南亚。进口：从其他国家买商品或服务，比如中国买芯片、铁矿石、原油。

这两个数字由海关逐笔记录，每月公布一次：出口多少、进口多少、以及两者之差（顺差或逆差）。

> 一句话：出口是“赚外国人的钱”，进口是“花外国人的钱”。

## 2. 为什么重要

对宏观：出口是拉动中国经济的“三驾马车”之一（消费、投资、出口）。出口景气=工厂有订单、企业有利润、普通人有工作。

对普通人：出口企业订单好，就业和收入就稳；进口带来便宜的国外商品和原材料，能压住国内物价；净出口大还会带来外汇流入，人民币汇率偏强，海淘和出国更划算。

> 一句话：出口好不好，关系到你身边有没有活干；进口多不多，关系到你买东西贵不贵。

## 3. 怎么用 / 怎么看

- 第 1 步：看月度出口同比增速：连续回升说明外需回暖，出口链、航运相关公司的盈利预期会改善。
- 第 2 步：拆结构：是“量”涨还是“价”涨？是新能源车、机电等高附加值产品，还是服装玩具等低附加值产品？含金量差很多。
- 第 3 步：结合汇率看：人民币升值会削弱出口价格优势，升值太快时出口企业压力会明显增大。

## 4. 常见坑 / 误区

- 坑 1：以为“出口额创新高”就等于全行业都赚钱——出口结构分化极大，有的行业订单爆满，有的已在萎缩。
- 坑 2：觉得进口多是坏事——进口芯片和原材料是生产的必需品，进口减少有时反而是内需转弱的信号。
- 坑 3：只看单月数据就下结论——春节错位、大单扰动都会造成单月大起大落，至少要看三个月趋势。
