# 社保缴费基数 / 缴费比例

> 社保缴费基数 = 你交社保时按哪个"工资数"来算钱，缴费比例 = 按这个数交百分之几。它直接决定你每月扣多少钱、以后领多少钱。

## 1. 这是什么
- **缴费基数**：社保局给你核定的"计算工资"，不是你实际到手工资，通常是你上年度月平均工资，但有上下限（一般为当地社平工资的 60%～300%）。
- **缴费比例**：养老、医疗、失业、工伤、生育五险各自的比例。个人和单位各交一部分，养老个人交 8%、单位交 16%（各地略有差异）是主流。

## 2. 为什么重要
- 基数定得高，每月扣得多、到手少，但养老金账户、医保账户进账也多。
- 基数定得低（有的公司按最低标准交），你到手多，但养老、医保待遇跟着缩水，长远吃亏。
- 医保报销额度、养老金水平，都和缴费基数挂钩，这是"现在的钱"换"未来的保障"。

## 3. 怎么用 / 怎么看
- 查基数：登录当地社保 App / 支付宝社保查询，看自己按什么基数申报。
- 对照工资条：每月养老个人扣款 = 基数 × 8%，可以反推公司按什么基数给你交。
- 关注调整：每年 7 月前后各地会调整基数上下限，工资涨了记得看是否同步调基。
- 换工作核对：跳槽后确认新公司申报基数，别被"按最低交"糊弄。

## 4. 常见坑 / 误区
- 公司按最低基数交"省成本"：员工到手多，但养老金少、医保待遇差，长期亏。
- 基数越高越好？不一定：基数高扣得多，现金流压力大，要在保障和到手之间权衡。
- 以为缴费基数=实际工资：工资 2 万，基数可能是 1.8 万（上限截断），不是按全额算。
- 换城市不转移：社保断缴或转移不及时，影响养老累计年限和医保待遇。
