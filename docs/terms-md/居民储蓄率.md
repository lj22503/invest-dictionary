# 居民储蓄率

> 居民把可支配收入里存起来不花掉的比例。中国居民储蓄率长期全球最高，直接影响消费、投资和你的资产选择。

## 1. 这是什么（居民每赚 100 块，存下多少）

居民储蓄率 = 居民储蓄 ÷ 居民可支配收入。比如你一年可支配收入 10 万，存下 3 万，你的储蓄率就是 30%。
中国居民储蓄率长期全球最高：2010 年代一度接近 45%–50%，近年有所回落，仍明显高于欧美（美国、日本通常在 20% 上下甚至更低）。
疫情后还出现过一个热词——“超额储蓄”：2022–2023 年居民存款大幅增加，市场期待“报复性消费”，结果并没有如期到来。
一句话：储蓄率是国家“消费意愿”的温度计。

## 2. 为什么重要（为什么重要：高储蓄的双面性）

储蓄率高的直接结果：钱留在银行，没去消费。所以它对资产的影响很直接——
利好银行：存款多了，银行的负债端充裕；利空消费股：消费不旺，白酒、餐饮、家电的业绩就承压；宏观上：高储蓄率是“产能过剩”的另一面——生产多、消费少，只能靠出口消化。
反过来，储蓄率下降 + 消费信贷上升，往往是消费复苏的早期信号。
一句话：储蓄率一端连着你的存款利息，一端连着消费股的股价。

## 3. 怎么用 / 怎么看（怎么用：看数据看趋势）

看官方数据：国家统计局的住户部门资金流量表、央行公布的居民存款新增；看趋势组合：储蓄率下行 + 消费贷回升 = 消费复苏信号；配置参考：储蓄率上升期，防御型资产（银行、公用事业、债券）相对占优；储蓄率下降期，消费、成长风格相对受益；个人视角：把“家庭储蓄率”当成自己的财务健康指标——留足应急金后，储蓄率过高说明钱没在干活。
一句话：宏观储蓄率定方向，个人储蓄率定健康。

## 4. 常见坑 / 误区（常见坑：别把存款增速当储蓄率）

把“存款增速”当“储蓄率”：口径完全不同，存款增速受基数、理财搬家影响很大；以为高储蓄率一定利空：高储蓄国家往往有巨大的投资潜力——钱总要找去处，储蓄率高也意味着可投资的“弹药”充足；拿它预测短期股市：储蓄率是慢变量，月度数据噪音很大，不适合短线参考；中美直接对比：统计口径不同（社保体系、统计方法差异），美国居民储蓄率低并不完全等于美国人“不爱存钱”。
一句话：看储蓄率要懂口径，更要看趋势，别拿一个数字下结论。
