# 三方存管

> 你的炒股钱不放在券商手里，而是存在银行专用账户里，券商动不了你的钱——这就是三方存管。

## 1. 这是什么

三方存管 = 你炒股的资金，由“你 + 券商 + 银行”三方共同监管：钱存在你名下的银行专用存管账户里，券商只能“看得到、动不了”。

2008 年后 A 股全面强制实施三方存管制度，从此“券商挪用客户保证金”成了历史。

> 一句话：你的钱在银行账上，券商只是“指挥员”，没有你的密码谁也划不走。

## 2. 为什么重要

没有三方存管之前，客户保证金放在券商自有账户，券商拿去自营、理财，一旦亏损客户的钱就没了（挪用保证金是当年券商风险事件的重灾区）。

有了三方存管：银行、券商、你三方对账，券商即使破产清算，这笔钱也不在清算资产里，会直接划回客户。

- 转账免费：银证互转不收费，实时到账；

- 出金安全：资金划出必须经过你的银行端操作；

- 多卡支持：多数券商可绑定多家银行存管卡。

## 3. 怎么用 / 怎么看

- 选存管银行：开户时指定存管银行（很多券商支持 5 家以上，可多绑几张卡）；

- 银证转账：券商 APP → 银证转账 → “银行转证券”（入金）/“证券转银行”（出金）；

- 看清时间与限额：交易日 8:30-16:00 可转账，当天卖出股票的钱 T+1 才能转出，大额出金需提前安排。

> 判断标准：如果平台让你把钱直接打给“某某理财账户”而不是你名下的银行存管账户，立刻警惕。

## 4. 常见坑 / 误区

- 以为钱在券商账户：实际在银行存管账户，券商 APP 只是“显示”余额；

- 忽略出金时间：收盘后和节假日不能转出，急用钱要提前规划；

- 换券商忘了迁移存管关系：转户前需在原券商办理撤销指定/转托管，存管银行关系同步变更；

- 遭遇“假三方存管”：非法平台伪造存管截图，实际打款到私人账户——以银行官方流水为准。
