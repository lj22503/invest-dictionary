# 恩格尔系数

> 恩格尔系数 = 食品支出 ÷ 总消费支出。一个国家或家庭越穷，花在吃饭上的钱占总支出的比重就越高；越低则越富裕。

## 1. 这是什么

1857 年德国统计学家恩格尔发现：收入越低的人，食品支出占总支出的比重越高。于是有了这个经典指标：**恩格尔系数 = 食品支出 ÷ 总消费支出**。

联合国常用分档：**60% 以上为贫困，50%-60% 为温饱，40%-50% 为小康，30%-40% 为相对富裕，30% 以下为富裕**。

> 一句话：看一个家庭过得好不好，先看它“吃”占了多少。

## 2. 为什么重要

平均工资容易被少数高收入拉高，恩格尔系数看的是普通家庭的钱怎么花——**吃饱之后还剩多少钱干别的**，更能反映真实生活水平。

中国城镇恩格尔系数从上世纪 90 年代的 50% 左右，一路降到近年的 30% 上下，背后是“从吃饱、到吃好、再到有钱旅游教育娱乐”的消费升级。

> 一句话：恩格尔系数下降，是普通人生活改善最朴素的证据。

## 3. 怎么用 / 怎么看

**第 1 点**：看趋势，别盯单年——某一年食品涨价会让系数短期跳升，不代表生活倒退。

**第 2 点**：结合“服务消费占比”一起看——教育、医疗、旅游支出占比上升，通常说明消费在升级。

**第 3 点（个人版）**：算算自己每月工资有多少花在吃饭上。如果超过一半，说明“生存占比”偏高，该想想怎么提高收入或强制储蓄。

> 一句话：个人版用法：吃饭花掉工资的比例，就是你生活质量的“压力表”。

## 4. 常见坑 / 误区

**坑 1**：以为系数越低就一定越好——极端低可能因为“不敢消费”或统计口径缩窄，要结合收入一起看。

**坑 2**：用“点外卖 vs 自己做饭”来套公式——恩格尔系数统计的是食品总支出，不是下馆子次数。

**坑 3**：拿个人月度账本直接和国家口径比——统计范围、补贴口径不同，个人数据更适合自己和自己比。

> 一句话：系数是镜子不是尺子：照自己看趋势，别拿去和别人硬比。
