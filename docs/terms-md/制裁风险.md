# 制裁风险

> 因政策或法律被禁止交易特定对象，导致相关资产被冻结、无法买卖的风险。

## 1. 这是什么（一夜之间资产被冻结）

一个国家（如美国 OFAC）把某个国家、公司或个人拉入**制裁名单**后，全球金融机构都不能再与它交易。被制裁方的资产被冻结、交易被切断、美元通道关闭。

一句话：制裁一纸令下，你的钱可能“想卖都卖不掉”。

## 2. 为什么重要（为什么重要：被制裁等于被锁死）

你买的基金如果重仓了被制裁的股票/债券，会遭遇：**流动性瞬间消失**（想卖卖不掉）、估值暴跌、甚至清盘。

一句话：制裁风险会让“正常投资”突然变成“困在里面的钱”。

## 3. 怎么用 / 怎么看（怎么看：普通人怎么避雷）

关注三件事：**OFAC 制裁名单（SDN List）**、基金持仓里有没有敏感地区公司、新闻里的“制裁/出口管制/SWIFT 剔除”关键词。

一句话：普通人避雷法就两条：别贪便宜，别集中押注。

## 4. 常见坑 / 误区（常见坑：觉得离自己很远）

以为“制裁跟我没关系”——你买的基金可能躺着中枪；以为“被制裁反而便宜”——便宜是有原因的，流动性可能归零；以为“过一阵就解除”——制裁往往持续数年，不是短线利空。

一句话：便宜是诱饵，流动性才是命。
