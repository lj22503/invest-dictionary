# 个税起征点（免征额）

> 个税起征点（正式说法是“基本减除费用标准”）= 每个月先把收入减掉5000元再算税，它是“免税额度”，不是“交税分界线”。

## 1. 这是什么

个税起征点现在的标准是**每月 5000 元**。正确用法是：先把你当月的工资薪金减掉 5000，剩下的部分才进入计税。比如小王月薪 8000 元，计税起点不是 8000，而是 8000-5000=3000 元；再减掉五险一金个人部分和专项附加扣除，实际需要交税的钱常常只剩几百块。

打个比方：起征点像超市的“满减门槛”——先减掉 5000 的“免单额度”，超出的部分才按档计价。

**一句话**：5000 是“免税额度”，不是“超过就全额交税”的开关。

> 一句话：5000 元是每个月先砍掉的免税额，砍完剩下的才交税。

## 2. 为什么重要

回顾历史：起征点从 800 元一路调到 1600、2000、3500，再到 2018 年的 5000 元，每次上调，中低收入者省下的税最多，因为它让“起征点以下”的收入全部免税。

它也是国家调节收入分配的工具：起征点越高，低收入群体越受益。对个人来说，理解起征点才能看懂工资条上的个税数字，也才不会被“我工资刚好超 5000，要被狠狠扣税”的传言吓到。

> 一句话：起征点越高，普通打工人交的税越少。

## 3. 怎么用 / 怎么看

**第 1 步**：看月收入是否超过 5000 元。没超过？工资个税基本为 0。

**第 2 步**：算“应纳税所得额”= 收入 - 5000 - 五险一金个人部分 - 专项附加扣除。

**第 3 步**：对照 3%-45% 的超额累进税率表，只对“超出的部分”分段计税。

实际体感：月入 1 万、填报了房租或赡养老人扣除的人，很多情况下税负接近于零，别被“月入过万就要交很多税”的段子带偏。

> 一句话：想知道自己该交多少税，公式只有一行：收入-5000-五险一金-专项扣除，剩下的才按档算。

## 4. 常见坑 / 误区

**坑 1**：以为“超过 5000 就要全额交税”——错，只对超出部分按档计税。

**坑 2**：以为“有 5000 免税额就够了，专项附加扣除无所谓”——专项附加扣除是在 5000 之外再往下减，房贷房租、养娃、赡养老人不填报，等于每年多交几千块。

**坑 3**：把“起征点”和“免征额”混为一谈——两者计税逻辑不同，网上很多文章故意混淆博流量，别被带节奏。

> 一句话：不懂起征点，只会被网上“个税恐怖故事”反复收割焦虑。
