# 个人所得税

> 个人所得税=国家对工资、劳务、经营等所得按超额累进税率征收的税，懂规则的人能合法少缴。

## 1. 这是什么

个人所得税=国家对个人收入收的税。工资薪金、劳务报酬、稿酬、经营所得、利息股息、房租、中奖等都要缴，但规则各不相同。

工资个税按“累计预扣法”计算：每月收入先减5000元起征点，再减五险一金个人部分和专项附加扣除，剩下的“应纳税所得额”才按3%-45%的超额累进税率缴税。

打个比方：个税像过收费站——先减掉你的“免票行李”（起征点+社保+专项扣除），超出的部分才按不同档收费。

> 一句话：大部分人的个税没有想象中高，但懂规则的人还能更少。


## 2. 为什么重要

税率是累进的：应纳税所得超过3.6万元部分按10%、超过14.4万元部分按20%……收入越高边际税率越高，合理规划就是省钱。

专项附加扣除覆盖房贷/房租、养娃、赡养老人等最多7类支出，不填等于每年多缴几千块。

年终奖单独计税、个人养老金每年1.2万元限额税前扣除，都是国家给的合法省税通道。

> 一句话：个税是“会者少缴、不会者多缴”的税。


## 3. 怎么用 / 怎么看

第1步：看工资条：每月个税=（累计收入-累计起征点-累计五险一金-累计专项附加扣除）×适用税率-速算扣除数-已预缴税额。

第2步：及时填报专项附加扣除：房贷利息/房租、子女教育、赡养老人、继续教育、大病医疗、婴幼儿照护，填了当月就少缴。

第3步：用好税前扣除：个人养老金每年最高1.2万元税前扣除，企业年金、符合条件的商业健康险也有额度。

第4步：次年3-6月做汇算清缴：多退少补，把全年多预缴的税退回来。

> 一句话：个税App一年打开两次：填专项扣除一次，汇算清缴一次。


## 4. 常见坑 / 误区

坑1：以为到手少=税太重：到手少更多是因为五险一金缴得多，那是你的储蓄和保障，不是白交。

坑2：不填专项附加扣除：几分钟的填报，每年最多能少缴几千块。

坑3：副业、劳务收入不申报：多处收入合并后可能触发补税，汇算漏报会被催缴并加收滞纳金。

> 一句话：不研究个税，等于每年主动放弃几千块。
