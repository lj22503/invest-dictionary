# 涨跌幅限制

> 涨停不是“涨到位了”，是“今天只能涨到这”。

## 1. 这是什么

**涨跌幅限制是交易所给每只股票设的「单日涨跌天花板」**——当天涨到顶就停，跌到底也停。

- **主板（60/00 开头）**：±10%

- **创业板（30 开头）、科创板（68 开头）**：±20%

- **北交所（8/4 开头）**：±30%

- **ST / *ST 股**：±5%

- **新股上市**：注册制下前 5 个交易日不设涨跌幅，波动最剧烈

> 一句话：涨停不是“涨到位了”，是“今天只能涨到这”。

## 2. 为什么重要

这条规则直接决定你能不能买进、能不能跑掉：

- **买的时候买不到**：一字涨停时买一挂着几百万手封单，你排在后面，成交概率极低

- **卖的时候卖不掉**：跌停板上没人接，挂跌停价也未必成交，只能第二天继续等

- **决定一天最多亏多少**：主板一天最多 -10%，创业板、科创板一天 -20%，两天连着就是 -36%

- **影响所有短线策略**：打板、做 T、网格、量化，全都建立在涨跌幅和价格笼子之上

对融资盘更直接：20% 的板意味着一根大阴线就可能触及平仓线。

## 3. 怎么用 / 怎么看

- **先认板子**：60/00 主板 10%，30/68 双创 20%，8/4 北交所 30%，ST 只有 5%；股票戴帽、摘帽，涨跌幅也会跟着变

- **看涨停封单**：封单越大越难买进；封单快速减少（炸板）说明分歧加大，是短线风险信号

- **看板数节奏**：连板股的情绪通常在第 3—5 板开始分化，越往上愿意接力的资金越少

- **新股单独一套规则**：注册制下上市前 5 日不设涨跌幅，别拿老经验套

> 一句话：涨跌幅限制给你的是缓冲带，不是安全垫。

## 4. 常见坑 / 误区

- **把涨停当利好**：涨停可能是资金炒作、可能是超跌反弹，也可能是“利空出尽”，并不等于公司变好了

- **追一字板**：开盘就封死的票能买到概率极低，追进去往往正好赶上炸板那一刻

- **忘了双创是 20%**：创业板、科创板一天能跌 20%，杀伤力是主板的两倍，仓位要相应缩小

- **以为跌停一定跑得掉**：跌停是“没人买”，不是“能卖掉”，真想跑的时候流动性早就没了

- **忽略 ST 的 5%**：戴帽股涨得慢，跌起来是天天跌停，很难找到反弹机会出逃
