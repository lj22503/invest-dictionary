# 减持新规

> 减持新规 = 监管为约束上市公司股东、董监高减持股份而制定的规则体系（最新核心是 2024 年 5 月发布的《上市公司股东减持股份管理暂行办法》）。

## 1. 这是什么

**减持新规是股东卖股票的"交通规则"**：A 股历史上大股东"清仓式减持"屡屡重创股价，监管因此给减持套上层层约束。

关键点：

- **限制对象**：控股股东、持股 5% 以上大股东、董监高，以及 IPO 前股东等"特定股东"；
- **核心限制**：破发、破净、分红不达标时，控股股东不得通过集中竞价/大宗交易减持；
- **时间与比例**：集中竞价 3 个月内不超过总股本 1%，大宗交易 3 个月内不超过 2%；
- **信息披露**：减持需提前 15 个交易日预披露计划，减持过半/完毕要披露进展。

> 一句话：减持新规 = 给大股东减持上"时间、比例、条件"三道锁。

## 2. 为什么重要

**减持新规是影响 A 股供给端（抛压）的核心制度，直接关系到股价的顶和底：**

- **压制抛压**：破发/破净/分红不达标"三红线"下不能减，大股东想跑也跑不了；
- **稳定预期**：预披露制度让市场提前知道减持计划，减少突发砸盘；
- **倒逼分红**：把分红与减持资格挂钩，鼓励公司真金白银回报股东；
- **影响定增/质押链条**：减持受限后，"定增-套现"的链条被收紧，博弈格局改变。

**真实场景**：某公司股价破净，控股股东想减持套现，但按新规"股价破净不得通过集中竞价减持"。公告一出，市场解读为"大股东被迫与散户共进退"，股价反而稳住了。

## 3. 怎么用 / 怎么看

- 第一步：判断主体——控股股东/5% 以上股东/董监高，约束强度不同；
- 第二步：核对三红线——是否破发、破净、分红不达标（年报后一年内都不能减）；
- 第三步：看减持方式——集中竞价（天天压制）vs 大宗交易（接盘方承接，盘面冲击小）vs 协议转让；
- 第四步：看减持比例和节奏——小额、分阶段减持 vs 大额、集中减持，压力完全不同；
- 第五步：结合公司基本面——基本面好的公司减持是噪声，基本面差的公司减持是警报。

> 一句话：看到减持公告先别慌，套用新规算一算：能不能减、减多少、怎么减。

## 4. 常见坑 / 误区

- **坑 1：把"拟减持"当"已减持"**：预披露只是计划，可能一股没卖；
- **坑 2：忽视违规减持后果**：新规下违规减持要责令购回，别小看监管的执行力度；
- **坑 3：把集中竞价和大宗交易混为一谈**：前者直接在盘面砸，后者找接盘方，冲击力不同；
- **坑 4：以为新规管住所有股东**：通过转融通、ETF 换购等通道仍可能有变相减持；
- **坑 5：把减持和基本面脱钩**：同样是减持，高增长公司和小市值壳公司含义完全不同。
