# 核准制

> 核准制下，上市是“被批准的特权”；注册制下，上市是“合规的常态”。

## 1. 这是什么

**核准制，是监管机构对拟上市企业做实质性审查、替投资者判断“值不值得投”的制度。**

- **关键机关**：发审委，逐家开会投票，通过率一度是市场热点

- **硬门槛**：持续盈利要求（比如连续几年净利润达标），亏损企业基本无缘上市

- **背后逻辑**：监管替投资者筛选好公司，所以上市资格本身很值钱，也就是所谓“壳价值”

2023 年全面注册制落地后，核准制退出 A 股主板，成为历史制度。

> 一句话：核准制下，上市是“被批准的特权”；注册制下，上市是“合规的常态”。

## 2. 为什么重要

- **解释了“新股不败”**：审批节奏决定新股供应量，供应少就打新必赚

- **解释了壳价值**：上市名额稀缺时，连年亏损的公司也能靠卖壳赚钱，退市难、ST 股有博弈价值

- **解释了估值结构**：小盘股、绩差股长期有溢价，很大程度来自供给管制

- **理解制度变迁**：才能看懂市场风格为什么在变

制度变了，玩法就会跟着变——核准制时代的经验，照搬到注册制下常常失效。

## 3. 怎么用 / 怎么看

- **看制度差别**：核准制重“实质判断 + 盈利门槛”，注册制重“信息披露 + 合规门槛”

- **看历史数据要留心**：2023 年之前的新股行情、壳股行情，不代表现在还会重演

- **看新股逻辑**：注册制下新股供给变多、破发常见，“无脑打新”不再成立

- **看退市**：注册制配套更严的退市规则，A 股“只进不出”的局面正在改变

> 一句话：制度决定玩法，玩法决定输赢。

## 4. 常见坑 / 误区

- **以为注册制就是放水**：注册制是审核重心从实质判断转向信息披露，不是“谁都能上”

- **拿老经验打新**：注册制后新股上市前 5 日不设涨跌幅，破发概率大幅上升

- **迷信“壳资源”**：退市常态化后，重组借壳的机会明显减少

- **把制度当利好或利空**：制度影响的是长期生态，短期涨跌更多由资金和情绪决定

- **忽略信息披露**：注册制把“看懂公司”的责任交回给投资者，原来靠监管背书的那部分没有了
