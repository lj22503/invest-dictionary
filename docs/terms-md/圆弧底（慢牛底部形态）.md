# 圆弧底（慢牛底部形态）

> 股价像碗底一样慢慢磨出圆弧——跌势放缓、横盘、再慢慢抬头，是个慢性子的底部形态。

## 1. 这是什么

圆弧底是技术分析里的底部反转形态：价格从下跌逐渐放缓，进入横盘，再缓慢抬升，走势连起来像一个 U 形或碗形。它不靠一根大阳线逆转，而是“磨”出来的底部。

圆弧底的形成逻辑：下跌末期抛压逐步衰竭，主力资金（机构）在低位慢慢吸筹，买卖力量从“卖多买少”渐变到“买多卖少”，价格重心随之缓慢上移。

> 一句话：圆弧底是慢性子的底部，磨得越久，后面的行情往往越扎实。

## 2. 为什么重要

与 V 形反转的急涨不同，圆弧底确认后往往对应持续时间更长、节奏更稳的上涨——因为底部的筹码被充分换手，浮筹少，上涨抛压轻。历史上不少大牛股（如白酒、医药的几轮大行情）启动前都出现过圆弧底。

对普通投资者来说，圆弧底是“可以慢慢建仓”的形态：左侧低吸、右侧加仓，容错率比追 V 形反转高。

- 左侧：跌势放缓、成交萎缩——开始少量布局
- 底部：横盘震荡、量能极低——耐心持有底仓
- 右侧：价格缓慢抬升、量能温和放大——加仓区
- 突破：放量突破“碗沿”（颈线）且回踩不破——确认信号

## 3. 怎么用 / 怎么看

- 第一步：画碗沿——把左右两侧的高点连线（颈线），价格突破它才算形态成立
- 第二步：看量能——底部必须缩量，右侧突破必须放量（温和放大即可，不需要天量）
- 第三步：看回踩——突破后回踩颈线不破（或小幅跌破又收回），形态有效

## 4. 常见坑 / 误区

- 坑 1：下跌途中短暂企稳的“浅 U”被当成圆弧底——必须左侧跌幅充分、底部横盘够久（数周以上）
- 坑 2：未放量突破就提前重仓——圆弧底右侧的确认信号是突破颈线，不是“看着像碗”
- 坑 3：圆弧底形成时间长（可能数月），拿不住——要么分批建仓，要么等突破再进
- 坑 4：忽略基本面——技术形态再好，公司基本面恶化也可能圆弧“磨穿”
