# 退市整理期

> 被决定退市的股票还有一段最后的交易窗口——退市整理期，是卖出还是被套住的分水岭。

## 1. 这是什么

**退市整理期 = 上市公司被决定终止上市后，为股东提供的最后一段可交易时间，通常为 15 个交易日。**

期间股票仍在交易，但标识和板块归属会变化，通常会带「退」字标识，提醒这是一只即将摘牌的股票。

整理期结束后股票摘牌，转到全国股转系统的退市板块（俗称「老三板」）继续挂牌转让。流动性、交易方式和估值逻辑，跟主板完全不是一回事。

有一个重要区分：交易类强制退市（比如面值退市、市值退市）通常不进入退市整理期，而是直接摘牌，具体以交易所现行规则为准。

> 一句话：退市整理期不是「复活期」，是「最后下车窗口」。

## 2. 为什么重要

整理期之内想卖还能卖，摘牌之后交易对手骤减，报价可能进一步缩水。流动性本身，就是这段时间最值钱的东西。

波动剧烈：整理期常出现恐慌性抛售与大幅波动，与你熟悉的主板交易节奏完全不同。

参与门槛：买入通常有额外要求，比如签署风险揭示书或开通特定权限，临时想买可能买不进。

时间成本高昂：死扛等于把资金长期锁在流动性极差的地方，等一个极不确定的「重生」。

> 一句话：能在这十几个交易日里出来，比死扛着等重生现实得多。

## 3. 怎么用 / 怎么看

- 先分类：财务类、规范类、重大违法类、交易类，不同退市类型的后续处理方式完全不同。

- 确认起止日：公告会写明整理期首个交易日与最后交易日，别错过最后一天。

- 评估重新上市可能性：少数公司满足条件后可申请重新上市，但周期长、条件严，属于极小概率事件。

- 算清成本与税务：亏损卖出所得可用于相关抵扣安排，死扛则可能长期无法处置，具体以现行税务规定为准。

- 如果决定卖出，越早越好：整理期前期流动性通常优于末期。

> 一句话：整理期的价值在「流动性」，不在「价格」。

## 4. 常见坑 / 误区

- 赌「退市后重组复活」：重新上市案例极少，时间成本极高。

- 在整理期首日冲进去抄底：波动最剧烈，跌到「仙股」价格后仍可能继续下跌。

- 忽略权限与风险揭示要求：买不进、卖不出，白白浪费时间窗口。

- 以为一定能卖个好价：整理期买盘稀薄，挂单可能长时间无法成交。

- 混淆退市整理期与停牌：停牌是完全不能交易，整理期是给你最后的机会。
