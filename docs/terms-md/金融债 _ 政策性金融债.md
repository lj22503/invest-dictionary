# 金融债 / 政策性金融债

> 银行等金融机构发的债券叫金融债；其中政策性银行发的、几乎不可能违约的，叫政策性金融债（政金债）。

## 1. 这是什么

**金融债 = 银行、券商、保险等金融机构为补充资金而发行的债券；政策性金融债 = 国开行、进出口行、农发行这三家政策性银行发行的金融债。**普通金融债的信用来自发债机构本身，好坏看银行实力；政金债则被视为"准国债"——由国家信用背书，违约概率极低，是债券市场最重要的投资品种之一，规模仅次于国债。政金债利率略高于国债，但流动性好、安全性高，是机构"票仓级"资产。> 一句话：金融债是机构借条，政金债是"国家信用盖过章的借条"。

## 2. 为什么重要

政金债是债市投资的"压舱石"：收益比国债高那么一点点，风险却几乎一样低，所以银行理财、债券基金、保险资金都在重仓它。对普通人来说，你可能没直接买过政金债，但你买的银行理财、纯债基金的底层资产里，很大一块就是它。看懂政金债，就理解了为什么"稳健理财"的收益会跟着它走；而普通金融债（尤其中小银行发的）则提醒你：同样是"债"，风险等级可以差很远。> 一句话：你手里理财产品的收益曲线，一半是政金债在背后撑腰。

## 3. 怎么用 / 怎么看

- **区分三兄弟**：国债（政府发）> 政金债（政策性银行发）> 金融债（商业银行/券商发），安全性和利率依次递减/递增。
- **看基金持仓**：买债券基金前，翻一下季报前十大持仓，如果满屏"国开债""农发债""口行债"，说明基金走的是"稳"路线。
- **看利差信号**：政金债与同期限国债的利差扩大，往往说明市场风险偏好下降或流动性收紧，是债市情绪的温度计。
- **普通投资者别直接买**：政金债主要在银行间市场交易、门槛高，普通人通过债券基金间接参与即可。> 一句话：想稳稳吃债市收益，政金债是机构的首选，你借道基金上车。

## 4. 常见坑 / 误区

- **把政金债当"绝对无风险"**：它违约概率极低，但价格会随利率波动，持有中仍可能浮亏，不等于保本。
- **混淆"金融债"和"国债"**：普通金融债是机构信用，尤其中小银行、民营金融机构的债，风险不能和国债比。
- **以为"银行发的债都一样"**：国有大行金融债和村镇银行金融债，信用差距天壤之别，别只看"银行"两个字。
- **用政金债利率去对比存款**：两者期限、税收、流动性都不同，直接比数字会得出错误结论。> 一句话：政金债稳，但"稳"的是信用，不是价格。
