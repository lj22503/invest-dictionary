# 全额退保骗局

> 号称“帮你把保费全额退回来”，实则是收割手续费的骗局，还偷你的个人信息。

## 1. 这是什么

**全额退保骗局 = 骗子声称能帮你把已交保费“全额退回来”，先收手续费、再偷你信息。**

话术通常是：“保险公司是骗人的，你的保单被坑了，我能帮你全额退保。”然后要求你：先交**保费10%-30%的手续费**，交出身份证、银行卡、保单、手机号。

> 一句话：真正赚钱的不是“退保”，是收你的手续费和卖你的信息。

## 2. 为什么重要

监管已把这类行为定性为`“代理退保”黑产`，全链条违法：

- 伪造证据：教唆投保人谎称“代签名”“被误导”，向监管恶意投诉施压；
- 收取高额手续费：成功退保抽走30%-50%的“佣金”；
- 二次收割：诱导“退旧买新”，再赚新保单佣金；
- 贩卖信息：身份证、银行卡信息被拿去贷款、洗钱或二次诈骗。
真正能“全额退保”的，只有犹豫期内退保，或能证明确实被销售误导且证据充分——而这些根本不需要中介。

## 3. 怎么用 / 怎么看

- **先看现金价值表**：合同里明确写了每一年退保能拿回多少，心里有数；
- **犹豫期外理性评估**：退保有损失是正常的，权衡“继续交”和“止损退出”哪个更优；
- **走官方渠道**：直接打保险公司客服、或向金融监管部门投诉热线反映问题，任何“全额退保”中介都不要碰。
> 一句话：退保是合法权利，但“包退”的中介一定是骗子。

## 4. 常见坑 / 误区

- **手续费打水漂**：多数人交了手续费后，退保根本办不成，钱不退；
- **伪造证据涉嫌违法**：按中介教唆谎称“代签名”投诉，可能构成骗保，反被追责；
- **个人信息泄露**：身份证、银行卡交出去，可能被贷款、被二次诈骗；
- **“成功案例”都是剧本**：所谓成功退保截图，多半是伪造或极少数特殊个案。
