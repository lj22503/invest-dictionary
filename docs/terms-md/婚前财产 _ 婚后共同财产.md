# 婚前财产 / 婚后共同财产

> 婚前攒的是你的，婚后一起赚的才是两人的

## 1. 这是什么

- **婚前财产** = 结婚登记**之前**一方已经取得的财产，包括存款、房产、车辆、股票、彩礼（一般算女方婚前财产）等。
- **婚后共同财产** = 婚姻关系存续期间双方取得的工资、奖金、投资收益、经营所得、公积金等，离婚时原则上**一人一半**。

婚前财产**不因结婚时间变长自动变成共同财产**，但容易因为"混同"而说不清。

## 2. 为什么重要

- 离婚分割财产时，**能不能说清钱是哪来的，直接决定你能保住多少**。
- 婚前一套房，婚后共同还贷部分及增值，对方有权分——很多人不知道。
- 婚前财产和婚后收入混在一个账户，时间一长**无法举证**，法院只能按共同财产处理。

## 3. 怎么用 / 怎么看

**守住婚前财产的四个动作：**

1. **留证据**：保留婚前存款的银行流水、房产购买合同、过户时间凭证。
2. **分账户**：婚前存款单独放一个账户，不跟婚后工资混在一起。
3. **大额资产可公证**：婚前房产、股权等可做婚前财产公证或签婚前协议，明确归属。
4. **共同还贷要记账**：婚前房婚后共同还贷，留存还款记录，离婚时才能主张"还贷部分及增值"的补偿。

## 4. 常见坑 / 误区

**坑 1：婚前存款存进共同账户** — 一混同就说不清了，法院可能认定为共同财产。

**坑 2：房产加名** — 婚前房加对方名字 = 主动赠与，离婚时可能被分走一半。

**坑 3：彩礼/嫁妆性质** — 领证前后给的性质不同，领证前给的彩礼一般算女方个人财产。

**坑 4：婚后继承/受赠** — 除非遗嘱/赠与合同明确"只给一方"，否则婚后继承的遗产算共同财产。
