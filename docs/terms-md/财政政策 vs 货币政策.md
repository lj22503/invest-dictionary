# 财政政策 vs 货币政策

> 财政政策是政府用收税和花钱调节经济，货币政策是央行用利率和货币量调节经济，两者是国家调控的两只手。

## 1. 这是什么

财政政策动的是政府的“钱包”：减税降费、发消费券、扩大基建投资、增加民生支出，执行主体是财政部。

货币政策动的是央行的“水管”：降准、降息、公开市场操作等，决定市场上钱多还是少、贵还是便宜。

> 一句话：财政管“政府怎么花”，货币管“央行放多少水”。

## 2. 为什么重要

想刺激经济，光靠财政花钱可能没钱，要靠政府发债；发债多了又需要央行配合流动性，否则利率会被推高。所以财政和货币经常“打配合”。

对普通人：降息（货币）直接降低房贷、经营贷成本；减税和补贴（财政）直接增加可支配收入。

对投资：财政发力利好基建、消费链；货币宽松利好成长股和债市；两者同时发力，往往带来大级别行情。

> 一句话：两只手一起松，经济和资产价格往往最兴奋。

## 3. 怎么用 / 怎么看

- 第 1 步：财政看三件事：赤字率（敢不敢多花钱）、专项债与特别国债规模（钱往哪花）、减税降费（企业和居民能留下多少钱）。
- 第 2 步：货币看三件事：政策利率（7天逆回购、LPR）、存款准备金率、央行表态（“稳健”“适度宽松”等措辞变化）。
- 第 3 步：合起来判断组合拳力度：财政货币双宽松=强刺激；财政宽但货币紧=效果打折。

## 4. 常见坑 / 误区

- 坑 1：把央行降息当成财政政策——执行主体和工具完全不同。
- 坑 2：以为放水就一定通胀——钱如果空转进不了实体，可能先涨的是资产价格而非物价。
- 坑 3：看到政策宽松就闭眼加杠杆——政策从宣布到落地有时滞，短期预期透支很常见。
