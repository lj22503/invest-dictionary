# 公积金提取

> 把公积金账户里的钱按规定的场景取出来用，不用非得等买房或退休。

## 1. 这是什么

公积金是强制储蓄，账户余额按年计息（目前 1.5% 左右），但这笔钱不是“死钱”——在购房、还房贷、租房、离职、退休、大病等场景下都可以按规定提取。

提取政策因城市而异：有的城市支持租房按月提、离职满一定期限提、加装电梯提；有的城市对提取额度、频次、材料有严格限制。核心规则是“专款专用场景 + 本地政策”。

## 2. 为什么重要

公积金余额利率只有 1.5% 左右，跑不赢通胀，长期趴着等于购买力悄悄缩水。租房一族如果从不提取，可能每年白白放着几万元低息资金。

租房提取多地每月 1500—3000 元，一年就是 2—4 万元现金流；用于还房贷的按月提取，能直接减轻月供压力。对现金流紧张的家庭来说，这是“看不见的存款”。

## 3. 怎么用

- 查政策：登录当地公积金官网或小程序，看“提取指南”里的场景清单，先确认自己符合哪类。
- 备材料：租房一般需要身份证、租房合同；还贷需要贷款合同；离职提取需离职证明（各地不同）。
- 线上办：多数城市支持“公积金小程序 / 支付宝市民中心 / 当地 App”线上申请，提交后当天或 1—3 个工作日到账。
- 选方式：还贷提取可选一次性或按月；租房提取也分月提和年提，按现金流需求选。
- 买房前先算账：部分城市贷款额度与账户余额挂钩，打算买房的人别把余额提空。

## 4. 常见坑

- 伪造租房合同“骗提”是红线：查实后会被列入失信名单，暂停提取和贷款资格，得不偿失。
- 离职不等于必能提：是否可提、是否要销户，取决于本地政策和离职原因，先查再操作。
- 装修不是所有城市都能提，多数城市不支持以“装修”名义提取，别被中介误导。
- 提取会影响后续贷款额度（余额挂钩的城市），先确认当地规则再决定提取多少。
- 警惕“公积金提取代办”：正规提取不收费，代办中介多为伪造材料骗取服务费。
