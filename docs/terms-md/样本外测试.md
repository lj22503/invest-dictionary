# 样本外测试

> 样本外测试=用“设计策略时没看过的数据”来检验策略，防止它只在历史数据上灵。

## 1. 这是什么

样本外测试，就是**把历史数据分成两段：一段用来开发策略，一段留着考试**。

比如你用 2015—2020 年数据设计了一套“突破买入”策略，调整参数、验证逻辑，都表现很好——这还不够。真正的考试是：用 2021—2023 年这段**你开发时完全没碰过**的数据再跑一遍，看它还是不是赚钱。

前一段叫“样本内”，后一段叫“样本外”。样本外表现好，策略才可信。

> 一句话：样本内是你照着答案做题，样本外才是真正上考场。

## 2. 为什么重要

量化策略最大的坑叫**过拟合**：策略被调得“完美贴合”历史数据，换了新数据立刻失灵——就像背下了旧试卷的答案，新试卷一考就废。

样本外测试是检验“策略学到的规律 vs 只是背下噪声”最直接的方法。

不光是量化：任何“用历史经验总结规律”的场景——择时规则、选股因子、买基金看历史业绩——都需要样本外检验，否则你相信的规律可能只是巧合。

## 3. 怎么用

**第 1 步**：切数据。常见的做法：最后 20%~30% 作为样本外，剩下的做样本内（可再细分训练集/验证集）。

**第 2 步**：只在样本内开发、调参，样本外数据完全隔离，不能偷看。

**第 3 步**：样本外只跑一次——跑完觉得不好又回头调参，样本外就“污染”了，等于第二次考试前先看了答案。

**第 4 步**：看样本外收益的同时看回撤、胜率、换手率，别只看一个数字。

## 4. 常见坑

**坑 1**：样本外反复用：跑完不满意就调参再跑，样本外悄悄变成了样本内。

**坑 2**：窗口太短没代表性，比如只用 3 个月样本外，刚好碰上单边行情。

**坑 3**：只看收益不看回撤，样本外赚钱但回撤 40%，实盘根本拿不住。

**坑 4**：忽视幸存者偏差——只测活下来的标的，退市、暴雷的没进样本，结果虚高。
