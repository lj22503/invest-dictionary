# 账户贵金属

> 在银行开个账户，直接买卖"记账式"黄金、白银、铂金等贵金属，不用抱着金条回家的投资方式。

## 1. 这是什么

账户贵金属是银行推出的一类产品：**你开一个贵金属账户，账户里买卖的是"克数/盎司数"，而不是实物**。常见品种包括账户黄金（纸黄金）、账户白银、账户铂金等。

交易按银行实时报价成交，T+0 可买卖，部分品种支持做空（先卖后买）。买进卖出的差额就是盈亏，不涉及实物交割和仓储。

## 2. 为什么重要

账户贵金属把贵金属投资的门槛拉得很低：

- 黄金 1 克起、白银按克交易，几百元就能参与；
- 无仓储、无保管、无回购折价，流动性比实物好得多；
- 贵金属价格和股票、债券相关性低，是分散风险的配置选项之一；
- 部分品种可做空，行情下跌也有操作空间（但也意味着波动更大）。

## 3. 怎么用

- 第一步：在银行开通账户贵金属交易权限（需要风险测评，风险等级较高）；
- 第二步：看清报价——买入价与卖出价之间有"点差"，来回一次先亏点差；
- 第三步：设止损——贵金属波动比存款大得多，不设止损可能深套；
- 第四步：控制仓位——贵金属建议只占总投资资产的 5%~10%，别当主力。

## 4. 常见坑 / 误区

- **把短线交易当理财**：账户贵金属适合有判断、有纪律的人做波段，不适合当"存钱"；
- **忽略交易时间**：不同品种交易时段不同，隔夜国际金价跳空，一觉醒来可能亏一截；
- **高杠杆品种风险更大**：部分品种波动剧烈，仓位管理不到位容易爆亏；
- **产品规则会变**：历史上多家银行曾暂停部分账户贵金属的开仓，买入前要看清条款，别以为永远能交易。
