# 产业链转移

> 工厂和供应链从一地搬到另一地的"搬家潮"：搬走的是订单、就业和利润，留下的是空厂房。

## 1. 这是什么

**产业链转移 = 某个行业的生产环节（从原料、零件到组装）因成本、关税、政策等原因迁往其他地区。**常见形式是劳动密集环节（服装、电子组装）从高成本地区迁往越南、印度、墨西哥等低成本地区。

场景：一家手机代工厂把组装线从深圳搬到越南，因为当地人工便宜、关税更低；同时把核心芯片研发留在国内——这叫"部分转移"，比整体搬家更常见。

> 一句话：哪儿便宜、哪儿好做生意，工厂就往哪儿挪。

## 2. 为什么重要

产业链转移**重塑一国的出口结构、就业分布和增长潜力**。对转出方：低端岗位流失、相关出口份额下降、增长动能减弱；对承接方：出口和外资流入激增，越南就是典型受益者。

对普通人的影响：外贸工厂工人面临订单和岗位压力；投资上，转出国的制造业板块承压，承接国的出口链、基建链受益。它和贸易摩擦（关税逼你走）、人口老龄化（人工变贵）叠加，是十年维度的长期变量。

数字参考：近年来部分劳动密集型产品在中国出口份额下降、在越南份额上升，就是产业链转移的可见证据。

> 一句话：别只盯短期关税新闻，工厂搬家是更慢、更深的浪潮。

## 3. 怎么用 / 怎么看

- **看 FDI 流向**：外资直接投资从哪国流向哪国，是转移方向的最硬证据。
- **看出口份额**：同类产品在各国的出口占比变化，能看出产能真的挪没挪。
- **区分"组装外迁"和"核心外迁"**：只转组装，供应链主导权还在手里；核心研发、设备也走，才是真抽血。
- **跟踪企业公告**：上市公司海外建厂、产能布局公告是高频信号。

> 一句话：先分清转走的是什么环节，再谈影响有多大。

## 4. 常见坑 / 误区

- **以为"转走 = 全面去中国化"**：实际大多是部分环节转移，中国仍保有核心供应链和巨大市场。
- **把个别企业搬迁当行业趋势**：一家厂搬走可能是个案，要看行业层面的 FDI 和份额数据。
- **低估回迁与近岸外包**：疫情后"近岸化""友岸化"趋势让部分产能回流或就近布局，方向会反复。
- **只盯人工成本**：基础设施、工人技能、配套产业链同样重要，很多"低人工"国家承接不了高复杂度产业。
