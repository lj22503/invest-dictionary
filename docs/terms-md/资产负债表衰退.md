# 资产负债表衰退

> 企业集体忙着还债、不借钱不投资，把整个经济拖进长期低迷。

## 1. 这是什么

资产负债表衰退，是日本学者辜朝明用来解释“企业集体躺平”的说法。它的起点通常是资产泡沫破裂：房价、股价大跌后，企业手里的资产缩水，负债却没变，账面瞬间变难看。

为了把资产负债表的窟窿补回来，企业开始疯狂省钱：不扩产、不招人、不借钱，赚到的钱全部拿去还债。哪怕银行把利率降到地板，也没人愿意借钱——因为大家的目标从“利润最大化”变成了“负债最小化”。

打个比方：一个人炒股亏光了积蓄，从此省吃俭用、不消费不买房，只想着把欠款还清。整个社会要是几千万人同时这么干，消费和投资就会一起熄火。

## 2. 为什么重要

它解释了一个反直觉的现象：降息可能没用。1990 年代日本泡沫破裂后，央行把利率降到接近零，经济依然低迷了十几年，就是因为企业不借钱。

对中国普通人来说，地产下行阶段如果企业集体缩表，会传导为：工资涨得慢、就业机会变少、房价阴跌、银行存款利率越来越低。看懂这个框架，就不会把“政策放水就该立刻见效”当真理，也能理解为什么政府要亲自下场发债、搞基建来托住总需求。

## 3. 怎么看

- 盯住私人部门信贷：企业贷款增速长期徘徊在低位的年份，缩表压力大。
- 看“信贷脉冲”：新增信贷占 GDP 比重的变化，快速回落常对应需求走弱。
- 观察企业行为：龙头公司账上现金堆积却不愿扩产，是典型信号。
- 留意政策转向：政府扩大财政赤字、发特别国债、居民加杠杆，往往是对冲缩表的关键动作。

## 4. 常见坑

- 误区一：以为只是普通经济周期。普通衰退靠降息能修复，资产负债表衰退靠降息很难，因为没人敢借钱。
- 误区二：把“政府发债”看成坏事。在缩表环境下，政府加杠杆恰恰是为了接住企业和居民不花钱留下的缺口。
- 误区三：拿美股思维套 A 股。资产负债表衰退更常出现在高杠杆、资产泡沫破裂之后，时机判断要看债务周期而不是只看 K 线。
