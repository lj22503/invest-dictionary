# 智商税

> 为“显得高级、听着有用、别人都有”而多付的钱，就是智商税——买之前问一句“这钱买到了什么”，能帮你省下大笔冤枉钱。

## 1. 这是什么

智商税 = 为实际价值远低于价格的东西付的钱：买的是“听起来厉害”“显得有钱”“大家都在买”的情绪价值。

- 伪科学类：量子水、防辐射贴、能量手环；

- 身份溢价类：logo 大牌溢价远高于成本；

- 焦虑收割类：“三天速成”“内部渠道”“限时优惠”催你下单。

> 一句话：不是东西没用，是你为“感觉”付的钱远超它的实用价值。

## 2. 为什么重要

单笔智商税金额不大，但次数频繁：一杯“网红”咖啡贵 15 元、一件“必入”外套 500 元、一年 N 个“限量”——一年下来可能数万。

更隐蔽的是机会成本：这笔钱如果不花，放进定投或应急金，5 年、10 年后的差距是指数级的。省下的每一分“税”，都是未来财富的种子。

## 3. 怎么用 / 怎么看

- 问功能：它解决了我哪个具体问题？答不上来就不买；

- 问替代：有没有 1/10 价格的平替做到同样功能？

- 问时间：放购物车 72 小时，还想买再买——冲动期过去，大多不需要；

- 算“时薪”：把它除以你的时薪，值不值一目了然。

## 4. 常见坑 / 误区

- 只防“保健品式”智商税：知识付费、面子消费、情绪溢价同样是税，只是包装更好看；

- “便宜的不算税”：9.9 包邮、会员自动续费，积少成多更可怕；

- 陷入价格锚点：原价 999 折后 199 的“便宜”，其实你原本不需要；

- 用消费证明自己：买贵不是能力，攒得住才是。
