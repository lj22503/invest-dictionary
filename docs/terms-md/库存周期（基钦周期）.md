# 库存周期（基钦周期）

> 企业"补库存—去库存"大约 3~4 年一轮的小周期，像呼吸一样存在于经济中。

## 1. 这是什么

1923 年经济学家基钦发现，经济存在一种约 40 个月的小周期，核心是企业的库存行为：

- 经济向好 → 企业担心不够卖，拼命补库存 → 订单增加、生产扩张
- 需求转弱 → 仓库堆满 → 企业停止采购、降价去库存 → 生产收缩

这个"补库存—去库存"循环就是库存周期，也叫基钦周期，是四大经济周期里最短的一个。

## 2. 为什么重要

- **判断经济短期拐点**：库存见底回升往往领先经济复苏，是"春江水暖鸭先知"
- **影响周期股**：补库存阶段，上游资源、化工、钢铁等周期股业绩弹性最大
- **影响大宗商品**：全球补库存推升铜、油等商品价格，去库存则压制
- **指导个人配置**：库存周期位置可以帮你判断该偏股还是偏债、该配周期还是配防御

## 3. 怎么用 / 怎么看

- **看 PMI 库存分项**：原材料库存 + 产成品库存两个分项，是官方公布的"库存体温计"
- **看工业企业产成品存货增速**：增速见底回升，通常是补库存启动的信号
- **四阶段定位法**：主动补库存（经济好、库存升）→ 被动补库存（需求弱、库存积压）→ 主动去库存（主动降价清仓）→ 被动去库存（需求回暖、库存被动下降）
- **叠加看**：库存周期要和价格周期（PPI）一起看，PPI 见底往往领先库存见底

## 4. 常见坑 / 误区

- **把库存周期当长周期用**：它只有 3~4 年，别用它判断十年维度的趋势
- **忽视外生冲击**：疫情、贸易摩擦会打断库存节奏，模型会失灵
- **只看库存不看需求**：没有需求配合的补库存是"假补库"，很快会变成被动去库存
- **用单一指标下结论**：产成品存货口径有滞后，要结合 PPI、PMI 新订单一起判断
