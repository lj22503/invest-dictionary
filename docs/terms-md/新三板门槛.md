# 新三板门槛

> 新三板门槛 = 个人投资者参与新三板（全国股转系统）交易需满足的资金与经验条件：各层级（精选层/创新层/基础层）要求不同。

## 1. 这是什么

**新三板是服务中小企业的全国性股权交易市场**，为了控制风险，监管设置了较高的投资者准入门槛。

关键点：

- **基础层/创新层**：个人投资者需前 10 个交易日日均资产 200 万元（基础层）/100 万元（创新层），加 2 年投资经验；
- **精选层**：已并入北交所，个人门槛 50 万元（与北交所一致）；
- **资产认定**：证券账户资产，不含融资融券融入资金；
- **开户方式**：需临柜或线上开通权限，不能像主板一样直接买。

> 一句话：新三板门槛 = 用"资金+经验"双重过滤，只放合格投资者进场。

## 2. 为什么重要

**门槛直接决定新三板的流动性与风险生态：**

- **流动性分层**：门槛越高，参与者越少，成交越清淡，退出越难；
- **风险隔离**：新三板公司大多体量小、治理弱、波动大，高门槛是保护散户；
- **转板预期**：新三板→北交所→沪深市场的转板通道，让门槛差异成为"套利"路径；
- **改革方向**：门槛随改革动态调整（精选层并入北交所后门槛降至 50 万），是制度风向标。

**真实场景**：老王想参与某家新三板公司的转板行情，一看门槛：创新层要 100 万日均资产+2 年经验，他不达标。他退而关注已在北交所上市的同赛道公司——门槛 50 万，参与起来更顺。

## 3. 怎么用 / 怎么看

- 第一步：核对自身资格——资产规模、投资年限是否满足对应层级要求；
- 第二步：分清层级——基础层（200 万）、创新层（100 万）、北交所（50 万）依次递进；
- 第三步：评估流动性——新三板成交清淡，买入前先看日成交量能否支持退出；
- 第四步：研究公司质量——小盘股信息披露和研究覆盖弱，尽调难度大；
- 第五步：关注转板/北交所路径——有明确转板预期的公司，流动性溢价更值得关注。

> 一句话：门槛是准入证，不是安全证——够格进场，也得掂量流动性再出手。

## 4. 常见坑 / 误区

- **坑 1：以为开了权限就能随便买**：各层级门槛不同，权限未开齐会下单失败；
- **坑 2：忽略流动性陷阱**：能买进不代表能卖出，小盘股想卖时可能无人接盘；
- **坑 3：把新三板当主板炒**：没有涨跌幅限制（部分）不等于更刺激，风险更大；
- **坑 4：迷信"转板概念"**：转板有严格条件，不是挂牌公司都转得了；
- **坑 5：借道产品规避门槛**：通过私募/资管参与新三板，仍有净值波动和信息不透明风险。
