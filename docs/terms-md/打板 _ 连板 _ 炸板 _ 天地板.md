# 打板 / 连板 / 炸板 / 天地板

> 打板是冲涨停价排队买入，连板是连续涨停，炸板是涨停被砸开，天地板是从涨停直接跌到跌停。

## 1. 这是什么

在 A 股涨跌停制度下，涨停板是短线资金情绪的最高共识：主力愿意把价格推到涨停，说明"明天还有戏"。围绕涨停板衍生出一整套黑话：

打板：在涨停价附近排队买入，赌它封死涨停、次日继续冲高。连板：连续多个交易日涨停（2 连板、3 连板……）。炸板：涨停封单被大额抛单砸开，价格从涨停回落。天地板：开盘涨停、收盘跌停，一天之内从天堂到地狱。反过来还有"地天板"。

## 2. 为什么重要

涨停家数、连板高度、炸板率，是 A 股短线情绪最直观的温度计：连板股多、炸板率低 → 情绪亢奋；连板股断、炸板率高 → 情绪退潮。游资、打板客、跟风盘都围着这套信号转。

对普通投资者，看懂这套生态至少能帮你避开最凶险的玩法——很多散户的第一笔大亏，就亏在"听说要涨停了"冲进去接盘。

## 3. 怎么用 / 怎么看

- 看情绪周期：涨停家数连续增加 + 炸板率下降 = 情绪上升期；涨停家数萎缩 + 炸板率飙升 = 退潮期，别逆着做。
- 打板只打龙头：板块里最强、封单最厚的那只，跟风股最容易炸。
- 看封单量与排队位置：封单小、你排在后面，可能根本买不进。
- 分清规则：主板涨停 10%，创业板/科创板 20%，北交所 30%，同样是"涨停"含义完全不同。

## 4. 常见坑 / 误区

- 散户打板九死一生：好板买不到，买到的大多是烂板、炸板。
- 天地板一天能亏 20% 甚至更多：涨停价买入，跌停价收盘，账面直接腰斩一档。
- 一字板根本买不进：排单排队排到收盘，白占资金还可能产生废单。
- 只看到"涨停敢死队"赚钱的传说，没看到幸存者偏差：活下来的都被写成故事，亏光的都沉默。
