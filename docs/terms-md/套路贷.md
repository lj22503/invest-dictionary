# 套路贷

> 打着“低息无抵押贷款”旗号，用虚增债务、恶意平账、软硬兼施逼你还钱的犯罪行为，本质是诈骗不是贷款。

## 1. 这是什么

典型剧本：先以“低息、秒批”吸引你签下虚高借条（实际借 5 万、借条写 10 万）；再制造银行流水假象，把钱转给你又让你取现交回；然后以“逾期”“违约”为由要求翻倍还款，或介绍另一家“过桥”平台帮你平账，债务越垒越高；最后用威胁、骚扰甚至打官司逼你签下房产抵押。

> 一句话：套路贷的每一步都在设局，目标不是利息，是你的本金和抵押物。

## 2. 为什么重要

套路贷已被明确为违法犯罪，多地以诈骗罪、敲诈勒索罪定罪。如果你已经中招：不要私下反复转账“消灾”，第一时间停止还款、固定证据并报警。

> 一句话：欠高利贷是民事纠纷，被套路贷是刑事犯罪，处理方式完全不同。

## 3. 怎么用 / 怎么看

- 信号一：借条金额明显大于实际到手金额。
- 信号二：要求把还款打进个人账户或第三方账户。
- 信号三：逾期后不协商，反而诱导你去“另一家”借钱平账。
- 信号四：放款前要先交各种“保证金、验资费”。
- 信号五：催收动辄威胁“起诉你”“让你坐牢”“卖你房子”。

## 4. 常见坑 / 误区

- 误区一：觉得“白纸黑字签了借条就得认”——受欺诈、胁迫签的合同可撤销，虚增部分不受法律保护。
- 误区二：用网贷填套路贷的坑——只会让窟窿越来越大。
- 误区三：以为报警没用——公安设有打击套路贷专班，报案时带齐借条、转账记录、聊天记录，证据越全立案越快。
