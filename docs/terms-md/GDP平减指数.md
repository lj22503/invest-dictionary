# GDP平减指数

> 把名义GDP“挤掉”物价水分算出来的整体物价变化指标，比CPI覆盖范围更广，是观察通胀最全面的温度计。

## 1. 这是什么（整个经济的“通胀体温计”）

GDP平减指数 = 名义GDP ÷ 实际GDP × 100。
名义 GDP 是“按当年价格算”的总产出，实际 GDP 是“按不变价格算”的总产出。两者之差，就是整个经济体所有商品和服务的价格变化。
它覆盖的范围比 CPI 广：居民消费品投资品出口品全都算，而 CPI 只覆盖居民消费的一篮子商品。
一句话：CPI 看“菜篮子”，GDP平减指数看“整个经济体的价格”。

## 2. 为什么重要（为什么重要：比 CPI 更全面）

它是观察通胀最全面的指标，对央行尤其重要：
投资品涨价（钢铁、水泥、设备）：CPI 可能毫无反应，但 GDP平减指数会涨；出口品跌价：CPI 不反映，但 GDP平减指数会跌；与 CPI 背离：往往说明通胀是“结构性”的——钱在投资和出口端涨，没进消费端。
所以央行不能只看 CPI 做决策，GDP平减指数是“第二只眼”。
一句话：只看 CPI 会漏掉半个经济的物价信号。

## 3. 怎么用 / 怎么看（怎么用：看懂名义与实际的差）

算通胀贡献：名义 GDP 高增长但实际 GDP 温和 → 说明涨价贡献了大头；看剪刀差：对比“GDP平减指数 vs CPI”，判断涨价是消费驱动还是投资/出口驱动；关注发布节奏：它随 GDP 季度发布（统计局），频率低于 CPI 的月度，别等它做短线判断；关联资产：平减指数持续走高 → 货币政策可能收紧 → 债市承压、银行息差变化，间接影响你的基金和理财。
一句话：它是慢指标，用来定方向，不用来抢时机。

## 4. 常见坑 / 误区（常见坑：别拿它当 CPI 用）

把 GDP平减指数当 CPI 用：口径完全不同，一个是全经济价格，一个是一篮子消费价格；以为越低越好：通缩同样危险，价格持续下跌会让企业利润恶化、债务变重；忽略滞后性：季度发布，等你看到数据，市场可能早就反应完了；跨国直接对比：各国统计口径不同，用平减指数做国际比较要非常小心。
一句话：指标越全面，越要理解它的口径和节奏。
