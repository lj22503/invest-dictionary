# 医保共济

> 医保共济 = 把家里医保个人账户里的钱"共享"着用，给配偶、父母、子女看病买药。

## 1. 这是什么

2021 年起推行的职工医保**门诊共济改革**包含两层：一是**家庭共济**——个人账户里的钱可以给配偶、父母、子女使用；二是**门诊共济**——普通门诊费用也能按规定报销了，小病不用硬扛成大问题。

## 2. 为什么重要

以前个人账户里的钱"死"在账上，年轻健康的用不上，家里老人孩子又不够用。现在能全家共用，门诊也能报了，等于把"躺着的钱"盘活，同时降低了小病拖成大病的经济门槛。

## 3. 怎么用 / 怎么看

- 在医保 app / 小程序里做**家庭共济绑定**，填家人身份信息
- 绑定后，家人看病、买药可刷你个人账户的余额
- 注意：共济的是**个人账户余额**，报销额度、起付线各自独立计算
- 记得查看门诊报销的**起付线、封顶线和报销比例**，心里有数

## 4. 常见坑 / 误区

- 把"共济"当"随便刷"——只能给**直系亲属**用，且必须用于本人就医购药
- 以为可以把医保卡借给家人"住院报销"，那是**骗保违法**
- 忘了门诊报销有起付线、封顶线，以为全部都能报
