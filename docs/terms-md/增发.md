# 增发

> 增发 = 上市公司在首次上市（IPO）之后，再次向市场发行新股融资。简单说：公司又要"印股票换钱"了。

## 1. 这是什么

**增发是上市公司的再融资手段**：公司已经上市了，但还需要钱（扩产、并购、还债），于是再发行一批新股卖给投资者，拿回现金。

关键点：

- **和 IPO 的区别**：IPO 是第一次上市募资，增发是上市之后的"第二次、第三次募资"；
- **两大类型**：**定向增发（定增）**——只卖给少数机构/大股东，最常见；**公开增发**——向全体投资者公开发售，门槛高、案例少；
- **定价机制**：定增通常按市价打 8 折左右发行，且有锁定期（6-18 个月不等）；
- **对股价的影响**：新股增加 → 每股收益（EPS）被摊薄 → 短期股价往往承压。

> 一句话：增发 = 上市公司再融资，用"多发股票"换"真金白银"。

## 2. 为什么重要

**增发是股东手里股份被"稀释"的关键事件，也是判断公司资金需求的信号：**

- **摊薄效应**：总股本变大，同样的利润分到每股就变少，老股东权益被摊薄；
- **资金信号**：公司缺钱才融资，要看清它是"缺钱扩张"还是"缺钱续命"；
- **机构入场**：定增常有机构参与，折价发行+锁定期意味着机构愿意中长期看好，也可能只是"捡便宜"；
- **监管风向**：监管对增发的审核节奏，反映再融资政策的松紧，影响市场资金面预期。

**真实场景**：某科技公司公告"拟向 35 名特定对象定增募资 50 亿元用于新产线"。老股东小周第一反应"又要圈钱"，但仔细一看：发行价打了 9 折、机构踊跃认购、资金投的是当下最热门的算力方向——他判断这是"扩张型融资"，反而在股价回调时加了仓。

## 3. 怎么用 / 怎么看

- 第一步：区分类型——**定增**（定向、折价、锁定期）还是**公开增发**（面向大众、定价市场化）；
- 第二步：看募资用途——扩产/研发/并购=扩张型；补流/还债=压力型，要警惕；
- 第三步：看发行对象和价格——机构踊跃认购、折价幅度小，说明认可度高；
- 第四步：看历史摊薄——对比增发后 EPS、ROE 的变化，判断"钱花得值不值"；
- 第五步：结合解禁节奏——定增锁定期结束后，解禁抛压常是股价的阶段压力。

> 一句话：增发不是简单的利好利空，要拆开看"为什么融资、谁在买、钱花哪"。

## 4. 常见坑 / 误区

- **坑 1：把增发一律当利空**：扩张型定增配合好项目，可能是中长期利好；
- **坑 2：只看到折价、看不到锁定期**：定增便宜是有代价的，6-18 个月不能卖；
- **坑 3：忽视"补流式"定增**：募资主要用于还债、补流动性的，往往说明主业造血不足；
- **坑 4：把增发和配股混为一谈**：配股是向全体老股东按比例配售、不配就吃亏，增发是面向新老对象，机制完全不同；
- **坑 5：解禁期不设防**：定增解禁前，股价容易提前走弱，别在解禁窗口期重仓博弈。
