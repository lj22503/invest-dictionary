# 洗盘

> 洗盘=主力在拉升前故意砸价或来回震荡，把持仓不坚定的散户吓下车，好让后面拉升更轻松。

## 1. 这是什么

洗盘=主力在拉升前，故意制造下跌或长时间震荡，把持仓不坚定的散户吓下车，这样后面拉升时抛压更小。

常见手法：急跌吓人（几分钟砸 3%-5%）、长时间横盘磨人、跌破关键均线制造恐慌。它的目的是“洗掉浮筹”，不是真的出货。

> 一句话：洗盘是主力开车前清空座位，让后面坐得更稳。

## 2. 为什么重要

洗盘阶段散户最容易割肉离场，刚卖完股价就起飞；反复几次后心态崩坏，再也不相信任何股票，拿不住任何好票。

区分洗盘和出货，直接决定你是拿住吃大肉，还是接盘站高岗。

> 一句话：被洗下车的人，往往在黎明前卖掉了天亮后的涨幅。

## 3. 怎么用 / 怎么看

- 第 1 步：看位置——刚启动或大涨前的下跌更可能是洗盘；已经大涨几倍后的放量下跌，出货概率大。
- 第 2 步：看量价——洗盘常缩量下跌（没人真卖），出货常放量下跌（有人真在跑）。
- 第 3 步：看基本面——你买的是业绩和逻辑还在的公司，急跌可以扛；逻辑破了（如业绩暴雷），再像洗盘也要走。
- 第 4 步：终极答案——别猜主力：设好止损线，用仓位应对，而不是用“是不是洗盘”说服自己死扛。

## 4. 常见坑 / 误区

- 坑 1：把出货当洗盘：主力高位放量出货，散户以为“洗一洗还会涨”，一路接盘接到山顶。
- 坑 2：把洗盘当真跌：主力刚启动前砸一下，散户吓得割肉，完美错过主升浪。
- 坑 3：迷信“主力思维”：天天猜庄家意图，不如老实做基本面加仓位纪律。
