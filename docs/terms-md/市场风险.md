# 市场风险

> 整个市场一起跌、谁也躲不掉的风险，也叫系统性风险。

## 1. 这是什么

市场风险是指由宏观经济、政策、危机等整体因素引起的下跌——熊市里几乎所有的股票一起跌，好公司也不例外。

它和个股风险不同：个股暴雷可以换股躲开，市场风险是整个市场的事，分散买股票也躲不掉。

> 一句话：市场风险 = 潮水退了，才发现大家都在裸泳。

## 2. 为什么重要

A 股历史上多次出现30%-50%级别的整体回撤（如 2015 年、2018 年、2022-2024 年）。

对满仓股票的人来说，市场风险意味着账户可能腰斩；对加了杠杆的人来说，可能直接爆仓。

但它不是不可管理的：通过股债配比、现金仓位、定投节奏，可以把市场风险对生活的影响降到可控范围。

> 一句话：市场风险不可消灭，但可以“对冲”和“留余地”。

## 3. 怎么用 / 怎么看

招 1：资产配置，股债搭配，债券/现金在市场大跌时兜底。

招 2：定投节奏，下跌时按计划买入，摊低成本，而不是恐慌清仓。

招 3：留足现金，永远留 10%-20% 现金，跌下来才有子弹，也睡得着。

> 一句话：应对市场风险，靠的是仓位纪律。

## 4. 常见坑 / 误区

坑 1：以为“我选的都是好公司，不怕熊市”——熊市里好公司照样腰斩。

坑 2：高位满仓、低位割肉，把市场波动做成了永久亏损。

坑 3：用杠杆对抗下跌，把浮亏放大成爆仓。

> 一句话：市场风险下，活得久比赚得快重要。
