# 代理退保黑产

> 号称帮你全额退保的中间商，赚的是手续费，图的可能是你的个人信息。

## 1. 这是什么

代理退保黑产的操作套路：在社交平台打广告，声称「保险公司销售违规，可以帮你全额退保」，然后收**退保金额 30%~50%** 的手续费。

他们会要你提供身份证、保单、银行卡、手机号，甚至让你签一份「授权代理」，教你伪造证据、反复恶意投诉。

而真正合法的「全额退保」只有两种情况：**犹豫期内退保**，或者**你手握销售误导的证据直接找保险公司/监管投诉**——这两种都不需要中介。

## 2. 为什么重要

退 10 万，手续费 3 万~5 万，到手可能只剩一半；更糟的是你的证件信息被打包倒卖，后续可能被冒名贷款、被精准诈骗。

保单一旦退掉，保障就没了。等你几年后想重新投保，年龄涨了、体检有异常，可能被拒保或者加费。

如果按黑产教的伪造证据、恶意投诉，你自己也可能被认定为恶意行为，留下不良记录。

## 3. 怎么用 / 怎么看

- **犹豫期内退保**：一般 10~15 天，全额退还，自己在保险公司 APP 或柜面就能办。
- **过了犹豫期**：只能退现金价值，这是合同约定，不是「被坑」，先翻合同里的现金价值表。
- **确有销售误导**：收集聊天记录、录音、宣传单，直接找保险公司客服，或拨打银保监会消费者投诉热线 **12378**，全程免费。
- **已经上套**：立即书面解除授权、修改银行卡与手机服务密码、保留证据报警，并向 12378 反映。
- **想减负而不是退保**：先看能不能减额交清、保单贷款、调整缴费期，往往比退保损失小。

## 4. 常见坑 / 误区

- **手续费高得离谱**：30%~50% 的抽成，比很多投资收益都高。
- **个人信息被卖**：身份证 + 银行卡 + 手机号打包，是诈骗的完美素材。
- **保单失效难回头**：重新投保要重新健康告知，年龄越大越难。
- **被教唆伪造证据**：涉嫌违法，风险全由你承担。
- **先交钱再办事**：付了钱对方消失，投诉都找不到主体。
