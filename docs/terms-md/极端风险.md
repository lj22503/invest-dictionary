# 极端风险

> 平时几乎不发生、一发生就巨亏的"小概率大事"——黑天鹅们的共同名字。

## 1. 这是什么

**极端风险 = 发生概率极低、但一旦发生会造成巨大损失的事件。**2008 年雷曼倒闭、2020 年疫情暴跌、某只股票单日闪崩 90%，都属于极端风险。

它和普通风险的区别：普通风险可以用历史数据估计（比如股票波动率），极端风险几乎没有足够的历史样本，很难预测"何时来、多大"。

> 一句话：极端风险是"百年一遇"却总在十年内遇到的亏钱事件。

## 2. 为什么重要

**极端风险平时看不见，一旦爆发，足以抹掉很多年积累的收益。**市场可以慢慢涨十年，但一次极端下跌可能跌掉五年涨幅。

- 对资产组合：极端下跌时"股债双杀"也常发生，分散化未必扛得住；
- 对个人：杠杆持仓在极端行情下会被强平，本金归零；
- 对机构：压力测试就是专门用来评估极端风险承受力的工具；
- 对心态：极端行情最容易引发"底部割肉"，把账面浮亏变成真实亏损。

## 3. 怎么用 / 怎么看

- **假设极端情景**：组合再跌 30%、40% 会怎样，提前算清楚，而不是等跌了再想；
- **控制杠杆**：极端行情中最快爆仓的就是杠杆仓位，杠杆是极端风险的放大器；
- **留足流动性**：保留应急金、避免被迫在极端低点卖出；
- **分散到"真不相关"**：股、债、黄金、现金的搭配，比单一资产更能扛极端冲击。

## 4. 常见坑 / 误区

- 坑1：以为"这次不一样"。极端风险每次都有新理由，但结果都是巨亏；
- 坑2：用历史最大回撤当底线。历史没发生过的极端跌幅，不代表未来不会发生；
- 坑3：极端行情里"抄底加仓"。方向可能对，但时间点、仓位控制不住照样重伤；
- 坑4：只防市场极端，不防生活极端。失业+大病+市场大跌同时来，才是真正的极端风险。
