# 狄德罗效应 / 鸟笼效应

> 得到一件新东西后，为了“配套”不断买更多，消费像多米诺骨牌一样停不下来。

## 1. 这是什么

狄德罗效应：18 世纪哲学家狄德罗收到一件华贵睡袍后，觉得旧书桌、旧地毯“配不上”新睡袍，于是把书房全套换新。鸟笼效应：朋友送他一个鸟笼，他为了不让笼子空着，买了只鸟。

两个效应说的是同一件事：人会为了“配套一致”而持续消费——新手机配新壳、新壳配新耳机、新耳机配新包。消费一旦启动，就很难只停在第一件。

## 2. 为什么重要

商家非常擅长制造这种效应：给你一个“新锚点”（赠品、新款、装修建议），让你看旧东西越来越不顺眼，然后“配套清单”自动生成。

一次换新往往带出 3—5 倍的连带消费：换手机花了 6000，壳、膜、耳机、充电器、手表再花 3000。你以为买的是单品，实际买的是整套“生活方式”——这正是消费主义温水煮青蛙的入口。

## 3. 怎么用

- 买新东西前先列“配套清单”：这件东西到手后，我还会想买什么？列出来，总价算清楚。
- 问自己一句：能接受“新旧混搭”吗？允许不配套，链条就断了。
- 对“免费赠品”保持警惕：最贵的往往不是赠品本身，而是它触发的后续购买。
- 给冲动设冷静期：看到“配套需求”时等 24 小时，多数念头会自己消退。

## 4. 常见坑

- “就差一步”心理：买了包觉得该买双鞋配，买了鞋觉得该换条裤子，一步接一步。
- 鸟笼常常是别人送你的：商家送的小礼品、会员赠品，都是精心设计的“鸟笼”。
- 每笔都不大，所以更难察觉：链条上每笔消费几百元，全年累计可能上万元。
- 以为控制单笔金额就行：真正的失控是“件数”，不是“单价”。
- 别把“配套消费”合理化为人情或品味，先看清它是不是又一个鸟笼。
