# 需求侧管理

> 需求侧管理 = 政府用货币、财政、消费等手段给总需求“点火”，托住经济，和供给侧改革相对。

## 1. 这是什么

**需求侧管理 = 通过刺激总需求（消费 + 投资 + 出口）来托底经济的宏观调控**。手段包括降息降准、扩大财政支出（专项债、赤字）、消费刺激（以旧换新、消费券、汽车家电补贴）、房地产松绑等。

场景：“以旧换新”补贴家电汽车、专项债投向基建、降息降首付——这些都是需求侧管理的具体抓手。

> 一句话：需求不足时，政府出手给经济加燃料。

---

## 2. 为什么重要

**需求侧管理直接影响经济增速和市场预期**：政策发力 → 信贷扩张、消费投资回升 → 企业盈利改善 → 股市修复。“政策底”往往先于“市场底”出现，跟踪需求侧政策节奏是把握行情窗口的关键。

数字参考：大规模以旧换新、专项债提速、降准降息组合拳，往往对应消费链（家电、汽车）和基建链（建材、工程机械）的阶段性行情。

> 一句话：政策一发力，顺周期板块先闻风而动。

---

## 3. 怎么用 / 怎么看

- **跟踪政策关键词**：盯“扩内需、促消费、以旧换新、专项债提速、降准降息”等表述与落地文件。
- **用数据验证**：社零、地产销售、PMI、信贷数据是否跟得上政策，政策底不等于数据底。
- **分阶段布局**：预期阶段看政策弹性大的板块，落地阶段看数据兑现的行业。

> 一句话：先跟踪政策，再等数据验证，最后看兑现。

---

## 4. 常见坑 / 误区

- **把刺激当万能**：短期刺激可能推迟出清、累积债务，长期效果要看结构改革。
- **只看政策不看数据**：政策底和市场底有时间差，盲目追政策容易接在半山腰。
- **忽略结构性约束**：需求侧要和供给侧（产能、供给质量）搭配，单腿走路难持续。
