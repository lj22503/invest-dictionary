# 克强指数

> 用电量、铁路货运量、银行贷款三个硬指标拼出的“实体经济体温表”，比单一官方数据更难注水。


## 1. 这是什么

**克强指数 = 用三个“硬数据”粗略衡量实体经济冷热**：①全社会用电量（工业一动就要用电）；②铁路货运量（货物在跑，经济就在动）；③金融机构中长期贷款余额（企业愿意借钱扩张）。据说这个思路来自李克强 2007 年在辽宁任上——判断经济冷暖，与其等统计报表，不如看电表、货表和银行表。> 一句话：经济好不好，看灯亮不亮、货车跑不跑、贷款借不借。

## 2. 为什么重要

为什么有人爱看它：GDP、PMI 来自抽样调查和统计口径，而**用电量、货运量是物理世界实打实的数据，造假成本极高**。一家工厂可以说自己增产，但骗不了电表。所以当官方数据“很好看”、克强指数却走弱时，市场会怀疑两者之间出现了“温差”。反过来，克强指数连续转正，说明实体经济真的在动。> 一句话：它是给官方数据“验真”的民间温度计。

## 3. 怎么用 / 怎么看

- **工业看用电量**：工业用电增速是否转正、是否提速，直接反映工厂开工率。
- **物流看货运量**：铁路货运量同比变化，反映货物流通热度。
- **信心看贷款**：中长期贷款增速，反映企业愿不愿意借钱扩产。
- **交叉验证**：和官方 PMI、工业增加值、GDP 增速对照，如果数据打架，就要警惕“温差”。> 一句话：单看一个数会误判，三个数一起看才是体温表。

## 4. 常见坑 / 误区

- **权重是经验值**：传统上按 4:3:3 加权，但产业结构变了，敏感度也会变。
- **单月波动大**：要看 3-6 个月的趋势，别被一个月的数据带节奏。
- **服务业占比上升**：用电量对 GDP 的弹性在下降，“量”涨不代表“价”和“利润”好。
- **它衡量“量”不衡量“价”**：量增价跌（通缩式增长）也是隐忧。> 一句话：克强指数是“体温计”，不是“体检报告”，别指望它什么都告诉你。
