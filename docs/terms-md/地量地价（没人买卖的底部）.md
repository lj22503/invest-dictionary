# 地量地价（没人买卖的底部）

> 成交量缩到地板上、价格也趴在地板上——市场冷到极致，往往离底部不远。

## 1. 这是什么

地量 = 成交量萎缩到极低水平（比如不足 20 日均量的一半甚至三分之一）；地价 = 价格处于阶段低位。股市俗语“地量见地价”，说的是成交量冷到极致时，往往就是价格底部区域。

逻辑很简单：跌到没人愿意卖了，卖盘枯竭，价格就跌不动了；缩量下跌说明抛压衰竭，而不是恐慌抛售。历史上 A 股的重要底部（2008 年底、2018 年底、2024 年初）都出现过明显的地量特征。

> 一句话：地量地价是“卖无可卖”的信号，市场冷到极致，底部常在不远处。

## 2. 为什么重要

底部判断不能靠拍脑袋，地量是少数可以量化的证据之一：它说明浮筹（想卖的人）已经洗得差不多，筹码开始沉淀。对长线投资者来说，地量区域往往是分批布局的窗口。

但注意：地量是“区域信号”不是“点信号”——它告诉你这里接近底部，不告诉你哪一天反转。

- 量能标准：单日成交额萎缩到前期高点的 1/3 以下、或低于 20 日均量的 50%
- 位置标准：股价/指数已从高点回撤 30% 以上，估值进入历史低分位
- 配合信号：地量 + 政策底（利好频出）+ 估值底，三者共振更可靠

## 3. 怎么用 / 怎么看

- 第一步：确认“地量”不是偶然——连续多日（一周以上）缩量更有效
- 第二步：等待右侧确认——放量上涨（阳线）出现后再分批介入
- 第三步：分批建仓，不一次打满——底部可能反复磨，留子弹应对二次探底
- 第四步：设定止损——若地量后继续放量下跌，说明判断错误，及时止损

## 4. 常见坑 / 误区

- 坑 1：地量之后还有更地量——阴跌行情里“无量阴跌”可以持续很久
- 坑 2：拿个股地量当买入信号——小盘冷门股常年低量，可能是没人关注而不是没人卖
- 坑 3：把“缩量上涨”和“缩量下跌”混为一谈——缩量下跌才是抛压衰竭，缩量上涨可能是买盘不足
- 坑 4：地量当天就冲进去——等放量确认再动，胜率更高
