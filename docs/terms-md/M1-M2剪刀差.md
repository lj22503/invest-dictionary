# M1-M2剪刀差

> 活钱（M1）和总钱（M2）增速拉开的口子，是判断经济冷热的经典指标。

## 1. 这是什么

M1 是"随时能花的钱"：现金 + 活期存款；M2 是 M1 加上定期存款等"不太活跃的钱"。

剪刀差 = M1 增速 - M2 增速。如果 M1 涨得比 M2 快，说明钱在从"存起来"转向"花出去"，经济活跃；如果 M1 增速长期低于 M2，说明钱都趴在定期里不动，大家不愿消费和投资。

## 2. 为什么重要

M1-M2 剪刀差被称作"经济体温计"：

- **剪刀差走阔（M1 快）**：企业愿意留活钱做生意，居民愿意把钱拿出来花，股市、楼市、消费通常回暖
- **剪刀差倒挂（M1 慢）**：企业回款慢、居民不敢花钱，钱全部转定期，往往是通缩压力、资产价格低迷的信号
- 对普通人：它影响你手里的存款利率、理财收益，也影响股票基金能不能赚钱

## 3. 怎么用 / 怎么看

- **看方向**：剪刀差从负转正、持续走阔，是经济企稳的积极信号
- **看拐点**：M1 增速掉头向上，通常领先企业盈利和股市 1~2 个季度
- **配合看**：单独看会误判，要结合社融、PMI 一起读
- **看月度变化**：单月波动大，看 3~6 个月趋势更可靠

## 4. 常见坑 / 误区

- **把剪刀差当买卖信号**：它是宏观指标，不是个股操作信号，别拿它直接决定买哪只股票
- **忽略基数效应**：去年同期基数低，今年 M1 增速可能"虚高"
- **不区分统计口径**：中国和美国 M1 口径不同（美国 M1 不含个人活期以外的项目差异），直接对比会出错
- **只看单月**：春节、季末等时点扰动大，单月剪刀差波动不代表趋势

---

**相关词条**：货币供应量（M0/M1/M2）、社融（社会融资规模）、CPI（居民消费价格指数）、PMI（采购经理指数，经济体温计）
