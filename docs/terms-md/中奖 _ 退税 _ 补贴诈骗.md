# 中奖/退税/补贴诈骗

> 通知你“中了大奖、能退税、有补贴”，但领钱前要先交“手续费/保证金”，交完就再也联系不上。

## 1. 这是什么

这类诈骗用一个共同的钩子：给你画一块“天上掉的馅饼”——中了百万大奖、可以退一笔税、符合某项补贴政策，然后用“先缴费才能领钱”完成收割。

中奖版：短信/邮件通知中奖，领奖前先交“公证费”“手续费”“税费”；退税版：冒充税务或社保人员，说你有未领取的退税，引导到钓鱼页面填银行卡和验证码；补贴版：冒充电商/政府发“消费补贴”“助学补贴”，诱导点击链接、下载不明 App。

## 2. 为什么重要

这类骗局精准利用了两种心理：贪便宜和怕吃亏。前面画饼越大，后面“要是不交这笔钱，大奖就没了”的胁迫感越强，受害者往往在一小时内完成全部转账。

它还在不断进化：利用“个人所得税年度汇算”“家电以旧换新补贴”等真实政策包装，让人更难分辨。一旦输入银行卡信息或验证码，卡内资金可能被瞬间转走。

## 3. 怎么用

- 牢记一条铁律：正规发奖/退税/补贴，永远不会让你“先交钱再领钱”。先交钱 = 骗局。
- 退税类：个税退税走“个人所得税”App 官方流程，不点短信里的链接，不给任何人验证码。
- 补贴类：以政府/平台官方渠道发布为准，来电自称“客服发放补贴”的，自己打官方电话核实。
- 中奖类：凡是“公证费”“保证金”“激活费”，一律挂断；中奖概率极低，主动通知你中奖的更不可能。
- 已转账：立即拨打 110 / 96110，并联系银行冻结账户，保存聊天和转账记录。

## 4. 常见坑

- “官方红头文件截图”可以 PS，验证码只属于你自己，任何索取验证码的行为都是诈骗。
- 钓鱼链接常伪装成“xx 税务”“xx 政务”，域名与官方差一个字母，先核对网址再操作。
- “小额手续费先试”是放长线，退回小额是为了钓出你的大额。
- 冒充“退税客服”让你开启屏幕共享的，与“注销账户骗局”同套路，共享即失守。
- 别转发给亲友“帮忙操作”，信息一旦泄露，骗子会用你的通讯录继续骗你的家人。
