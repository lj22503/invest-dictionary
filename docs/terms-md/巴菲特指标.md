# 巴菲特指标（总市值 / GDP）

> 用股市总市值 ÷ GDP，看股票贵不贵；超过 100% 就要小心泡沫。

## 1. 这是什么

巴菲特指标，是巴菲特 2001 年在《财富》杂志上提出的估值指标：把一个国家股市的总市值除以国内生产总值（GDP），用来衡量股市相对经济规模的“贵贱”。

原理很朴素：股票市值最终要由实体经济产出支撑，市值 / GDP 比值越高，说明股价跑得比经济产出快，泡沫成分越大。

他本人说过，这个指标“可能是在任何时点衡量股市估值水平的最佳单一指标”。当比值显著高于历史区间时，往往对应市场高位。

## 2. 为什么重要

它是判断“大周期位置”的粗筛工具：美股历史上，该比值在 2000 年互联网泡沫、2021 年疫情放水顶部都冲到过 150% 以上，随后都出现了深度调整。

对 A 股投资者，看懂它能帮你回答“现在该重仓还是该谨慎”：当 A 股总市值 / GDP 处于历史低位区间（比如 60%-70%），长期布局的安全边际更高；冲到高位（比如 100% 以上），就要降低收益预期、控制仓位。

它不精确，但足够给你一个大方向的“红灯/绿灯”提示。

## 3. 怎么看

- 算口径：A 股总市值一般统计沪深两市，GDP 用名义 GDP；海外研究机构有统一口径可直接查。
- 看区间：经验参考值——70% 以下偏低，70%-100% 正常偏贵，100% 以上泡沫预警，但新兴市场波动区间更宽。
- 结合估值分位：把市盈率百分位、股债性价比一起看，避免单一指标误判。
- 动态跟踪：按月或按季看趋势，比看单日数值更有意义。

## 4. 常见坑

- 坑一：口径不同没法比。A 股、港股、美股的总市值统计范围不同，直接搬国外阈值会失真。
- 坑二：新兴市场分母特殊。GDP 增速快、上市结构偏成长的阶段，指标天然偏高，未必是泡沫。
- 坑三：单指标定买卖。它是方向性参考，不提供择时精度，更不能替代基本面研究。
- 坑四：忽略利率环境。低利率时代，市场愿意给更高估值，指标高位不一定立刻崩。
