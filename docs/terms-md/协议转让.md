# 协议转让

> 协议转让 = 买卖双方在交易所体系外，通过私下协商确定价格和数量，再按规定程序一次性完成股份过户的大宗交易方式。

## 1. 这是什么

**协议转让是"谈好再卖"的交易方式**：不同于在盘面上挂单撮合，协议转让是双方直接谈价格、谈数量，然后通过交易所指定的通道完成过户。

关键点：

- **适用对象**：主要是上市公司股东（尤其大股东、机构投资者）的大额股份转让；
- **最低门槛**：一般要求单笔转让数量不低于 30 万股，或金额不低于 200 万元（视板块规则）；
- **定价规则**：转让价格有下限约束，通常不低于协议签署日前收盘价的一定比例（如 90%）；
- **与大宗交易的区别**：协议转让是场外协商、线下流程+交易所登记；大宗交易在盘后撮合，更标准化。

> 一句话：协议转让 = 大股东"私下谈好价、批量过户"的股份转让通道。

## 2. 为什么重要

**协议转让是大股东进退场、公司控制权变更的关键通道，信息含量极高：**

- **大股东减持/增持**：大额股份走盘面会砸盘/拉爆，协议转让能"悄悄"完成；
- **控制权变更**：收购方通过协议受让控股股东股份，是上市公司易主最常见路径之一；
- **折价信号**：转让价相对市价的折让幅度，反映卖方的急迫程度；
- **引入战投**：产业资本、国资通过协议受让成为重要股东，常被解读为利好。

**真实场景**：某公司控股股东拟转让 15% 股份给一家产业基金，协议价较市价折价 8%。公告后市场解读为"新股东入主+产业协同"，股价不跌反涨——协议转让背后的接盘方是谁，比价格更重要。

## 3. 怎么用 / 怎么看

- 第一步：看接盘方——国资/产业资本/知名机构接盘 vs 神秘自然人接盘，含义天差地别；
- 第二步：看转让价格——折价过大说明卖方急，溢价受让说明买方看好控制权价值；
- 第三步：看转让比例——是否涉及控制权变更、是否触发要约收购义务；
- 第四步：看后续动作——受让方是长期持股还是短期套利，锁定期承诺值得细读；
- 第五步：注意信息不对称——协议转让是线下谈的，普通投资者只能看到"结果公告"，别过度追涨。

> 一句话：协议转让的关键不是"卖了多少"，而是"谁买走了、多少钱买的"。

## 4. 常见坑 / 误区

- **坑 1：把协议转让一律当利好**：也可能是大股东着急套现、找人接盘；
- **坑 2：只看折价、不看身份**：神秘第三方接盘未必是好事，可能隐藏复杂利益安排；
- **坑 3：忽略转让后的减持**：受让方拿到股份后同样受减持规则约束，解禁压力照样存在；
- **坑 4：以为协议价=公允价**：协议价只是双方谈的结果，不代表市场合理估值；
- **坑 5：把协议转让当普通交易**：它有严格门槛和流程，普通投资者无法参与，别照搬思路。
