# 大数据杀熟

> 大数据杀熟 = 平台根据你的消费历史、搜索记录、设备型号等数据，对同一商品或服务给出不同价格——常客、老用户反而可能看到更贵的价。

## 1. 这是什么

平台根据你的**消费习惯、搜索记录、下单频率、设备型号**，把同一个酒店房间、同一趟航班、同一份外卖标成不同价格：常订酒店的人看到的房价更高，用苹果手机的人可能比安卓用户贵，会员价有时反而不如非会员便宜。

你以为刷到的是“千人千面”的个性化推荐，其实是“千人千价”的差异化定价。

**一句话**：杀熟杀的不是陌生人，恰恰是最信任、最常下单的你。

> 一句话：你以为是算法更懂你，其实是算法更会“宰”你。

## 2. 为什么重要

媒体多次实测：同一家酒店，两个账号同时查询差价几十上百元；同一家外卖店，会员价比非会员还贵——这类“杀熟”案例屡见报端。

对个人来说，识别杀熟等于每年少被“静默收割”几百到上千元；更重要的是理解它背后的逻辑：你的每一次搜索、每一次比价、每一次冲动下单，都在训练算法对你的“定价模型”。

> 一句话：被多收的钱不会出现在账单里，只出现在平台的利润里。

## 3. 怎么用 / 怎么看

**第 1 招**：多平台比价，别只用一个 App 下单，尤其是酒店、机票、打车这类大额消费。

**第 2 招**：大额消费前先“冷静”——加入购物车或收藏放一两天，很多“限时优惠”会自动降价。

**第 3 招**：用浏览器无痕窗口、或借家人手机对比价格，发现差价就是杀熟的实锤。

**第 4 招**：管住隐私授权——关掉不必要的定位、通讯录、麦克风权限，减少平台给你“画像”的素材。

> 一句话：比价不是抠门，是对抗“千人千价”的基本操作。

## 4. 常见坑 / 误区

**坑 1**：把正常的“动态调价”全当杀熟——机票酒店本来就随供需浮动，淡旺季价差不是杀熟。

**坑 2**：以为“卸载重装换新号”就能摆脱——设备指纹、支付账号照样能认出你，换号不如换习惯。

**坑 3**：只顾着比价，却把大量隐私授权给平台——关掉权限才是治本，否则算法永远比你更了解你的钱包。

> 一句话：与其每次下单斗智斗勇，不如先关掉那排隐私授权开关。
