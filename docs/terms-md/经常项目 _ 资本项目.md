# 经常项目 / 资本项目

> 国际收支的两本大账：一本记"做生意赚的钱"，一本记"投资流动的钱"。

## 1. 这是什么

**经常项目 = 靠真实交易赚的钱**：货物进出口、服务（旅游、运输、软件）、初次收入（工资、分红、利息）和二次收入（援助、汇款）。**资本项目 = 靠跨境投资流动的钱**：外资建厂、买股票债券、跨境贷款，以及外汇储备的变动。

场景例子：中国向欧洲出口手机赚回 100 亿美元，记经常项目；沙特主权基金投资中国新能源企业 30 亿美元，记资本项目；你在海外炒股赚的分红汇回国内，也属于相关科目。

> 一句话：一个是"生意账"，一个是"资金账"，合起来就是国际收支。

## 2. 为什么重要

两本账的此消彼长，直接决定汇率和外汇储备的净变化：**经常项目顺差是压舱石**（靠产品竞争力赚外汇，稳定），**资本项目是放大器**（热钱进出，波动剧烈）。看懂它，才能分清"人民币升值是因为贸易强，还是外资冲进来"——性质完全不同，应对方式也不同。

对普通人：资本项目大幅流入时股市、楼市往往偏热；大幅流出时人民币贬值和资产承压。做外贸、留学、海淘的人感受最直接。

> 一句话：分不清两本账，就分不清汇率的涨跌到底是"生意好"还是"钱冲进来"。

## 3. 怎么用 / 怎么看

- **看差额组合**：经常项目顺差 + 资本项目净流入 = 双顺差，外储稳增；经常项目顺差收窄 + 资本外流 = 汇率承压。
- **区分资本项目结构**：直接投资（建厂、并购）稳定且含金量高；证券投资（股债热钱）易变，大进大出要警惕。
- **与储备变化对照**：两本账差额之和约等于外汇储备变动，账对不上就要查"净误差与遗漏"。

> 一句话：两本账一起看，才能判断汇率和资金流向的成色。

## 4. 常见坑 / 误区

- **把"资本项目"当"资本管制"**：国际收支的资本项目是资金流动记录，和国内常说的"资本账户开放/管制"是两个概念。
- **只看总差额忽略结构**：证券投资大进大出可能撑起漂亮总账，但极不稳定。
- **误以为顺差 = 一直升值**：汇率还受利差、预期、政策干预影响，双顺差也可能被贬值预期对冲。
- **把月度猜测当数据**：国际收支是季度数据且发布滞后，别拿它做高频判断。
