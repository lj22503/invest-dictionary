# 配股

> 不掏钱参与就会被稀释——配股是老股东的一道选择题：要么出钱，要么掉份额。

## 1. 这是什么

**配股 = 上市公司向现有股东按持股比例、以通常低于市价的价格发行新股，募集资金的行为。**你有权按比例认购，也可以选择放弃。

几个关键要素：

- **配股比例**：例如每 10 股配售 3 股；
- **配股价格**：一般低于市价，形成折扣；
- **除权处理**：配股完成后股价除权，账户市值不会因为低价买入而凭空增加；
- **认购期**：有明确起止日期，过期作废，需要自己操作缴款。

> 一句话：配股不是分红，是向你要钱——不参与就要承担被稀释的那部分。

## 2. 为什么重要

- **不参与就被稀释**：别人的股数变多，你的持股比例下降，对应的每股权益被摊薄；
- **除权会让股价技术性下跳**：不理解除权机制，容易把正常调整误读成暴跌；
- **它带着资金压力的信号**：能发债、能定增却选择配股，往往说明融资并不轻松；
- **它考验你的现金流**：认购期要真金白银，临时凑钱容易被动。

## 3. 怎么用 / 怎么看

- **先算除权价**：用配股比例与配股价格估算除权后的理论价格，判断这笔钱花得值不值；
- **再看募资用途**：投主业扩产、补充流动资金，还是偿还债务，含义完全不同；
- **看大股东态度**：大股东全额认购通常传递信心，放弃认购则要多打一个问号；
- **看自身成本与仓位**：原持仓成本高且看好长期，参与可以摊薄成本；不看好就尽早决策；
- **记牢时间表**：股权登记日、认购起止日、缴款方式，漏一项就可能白白被稀释。

> 一句话：配股这道题没有标准答案，但要算清楚再交卷。

## 4. 常见坑 / 误区

- **把低价配股当打折买入**：除权后价格同步下调，账面价值不会凭空增加；
- **忘记操作被稀释**：不认购不会自动补偿，持股比例照降；
- **被除权的下跳吓到**：看到价格下跌就慌忙卖出，反而卖在除权后的低位；
- **不看用途就掏钱**：为还债、补流动性的配股，与为扩产的配股质量差别很大；
- **忽视频繁配股**：反复向股东要钱，说明自身造血能力有限。
