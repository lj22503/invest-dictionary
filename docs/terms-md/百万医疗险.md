# 百万医疗险

> 每年几百元保费、几百万报销额度，专管住院大额医疗费。

## 1. 这是什么

百万医疗险：保费低（30 岁左右一年几百块）、保额高（一般 200 万~400 万）的住院医疗报销险，用来报销社保外的大额医疗费。

它覆盖住院医疗费、手术费、特殊门诊、进口药/自费药等，凭医院发票实报实销。

杠杆极高：一年几百块，撬动几百万报销额度，是普通人配置保险的第一张“入门券”。

## 2. 为什么重要

一场大病，社保之外的自费部分可能高达数十万：

- 进口药、靶向药：CAR-T 一针几十万
- ICU：一天几千到上万
- 社保目录外的检查、器材、护理：全部自费

百万医疗险就是为这种“花大钱救命”的场景兜底，避免“一场病回到解放前”。

对年轻上班族，几百块保费换几十万风险保障，性价比极高。

## 3. 怎么用 / 怎么看

- 续保条件：优先“保证续保 20 年”的产品，防止理赔后买不了
- 免赔额：一般 1 万，越低越容易赔到
- 外购药：是否包含院外购药（抗癌药），最好写进合同
- 增值服务：就医绿通、住院垫付很实用
- 健康告知：如实填写，否则理赔可能被拒

记住：先看续保和外购药，再看保额数字。

## 4. 常见坑 / 误区

- 坑 1：以为“几百万保额”都会赔。它有 1 万免赔额，小病小痛基本用不上
- 坑 2：健康告知隐瞒。理赔时保险公司查病历直接拒赔
- 坑 3：续保风险。“保证续保”只写一年、理赔后可能拒保

搭配提示：百万医疗险是报销型，重疾险是给付型——一个报销医疗费，一个补偿收入损失，两者不冲突。
