# 日本失去的三十年

> 日本“失去的三十年” = 1990 年资产泡沫破裂后，经济长期低增长、通缩、企业居民去杠杆的一段历史，是研究资产负债表衰退的经典样本。

## 1. 这是什么

**日本失去的三十年 = 1990 年代资产泡沫破裂后，日本经济陷入长期低增长与通缩的三十年**。股市 1989 年见顶、地产 1991 年崩盘，此后企业为修复资产负债表而“债务最小化”，居民消费谨慎，利率长期接近零，人口老龄化加剧。

场景：讨论“中国会不会日本化”“资产负债表衰退”时，日本是绕不开的参照系。

> 一句话：泡沫破裂后，日本用三十年消化了债务。

---

## 2. 为什么重要

**日本的教训是理解通缩与债务周期的教科书**：资产价格崩塌 → 资产负债表受损 → 微观主体缩表 → 通缩螺旋 → 政策空间收窄。研究它，能帮助判断中国当前地产调整、居民去杠杆的可能路径与政策应对。

注意：日本股市并非三十年不涨——2012 年安倍经济学后日股大幅反弹并于近年创出历史新高，“失去”主要体现为 GDP 停滞、工资与消费低迷。

> 一句话：看日本，是为了不走它的老路。

---

## 3. 怎么用 / 怎么看

- **对比衰退指标**：观察企业/居民借贷意愿、资产价格与名义增长是否背离，判断是否进入资产负债表衰退。
- **看政策组合**：财政扩张 + 货币宽松 + 结构改革是否同步，政策钝化往往是日本化的信号。

> 一句话：用资产负债表视角看宏观，比看单一指标更准。

---

## 4. 常见坑 / 误区

- **把日本当宿命**：中国政策空间、产业竞争力、人口与城镇化阶段与日本不同，类比要谨慎。
- **以为日股三十年不涨**：日股 2012 年后大幅反弹，“失去”不等于股市永远不涨。
- **忽略汇率与全球化**：日元升值、全球化环境变化是日本困局的一部分，不可剥离。
