# 次级债

> 清偿顺序排在普通债务后面的债：平时利息高一点，出事时先亏的是它。

## 1. 这是什么

**次级债 = 偿还顺序靠后的债券，公司或银行破产清算时，要等普通债权人拿完钱才能轮到它。**它分两类：企业发的次级债（风险补偿更高）和银行发的二级资本债（用来补足资本充足率）。因为"后还钱"的风险更高，次级债一般票息更高；反过来，发行人用它来满足监管的资本要求。最出名的例子是银行的"永续债/二级资本债"，还有可转债的"次级属性"——可转债清偿顺序也在普通债之后。> 一句话：次级债是"排队靠后的债"，用更高的利息换你接受更晚拿钱。

## 2. 为什么重要

它直接影响你判断两类资产：第一，银行股的"资本充足率"靠次级债支撑，次级债出问题往往意味着银行经营承压；第二，普通人买的银行理财如果重仓某家银行次级债，那家银行出事，理财净值会先受伤。次级债还有著名的"减记条款"——银行资本不足时，监管可以直接把次级债本金减记（清零），持有人一分钱拿不回，这是它和普通债最大的区别。> 一句话：次级债的高利息，是用"本金可能被砍掉"换来的。

## 3. 怎么用 / 怎么看

- **看清偿顺序**：同一家公司，普通债 > 次级债 > 优先股 > 普通股；级别越靠后，风险越大、利息越高。
- **看减记条款**：银行次级债（二级资本债）都带减记/转股条款，必须看清触发条件——资本充足率低于红线就可能触发。
- **看发行人资质**：次级债不保本，发行人信用是唯一保障；优先选大行、AAA 评级，回避经营恶化的小机构。
- **散户参与方式**：柜台市场、债券基金可以间接买到；直接买门槛高、流动性差，谨慎重仓。> 一句话：想买次级债，先回答"这家机构倒了，我能接受本金归零吗"。

## 4. 常见坑 / 误区

- **只看利息不看顺序**：次级债票息比普通债高 1~2 个点，出事时却可能血本无归，"高息"是风险溢价不是福利。
- **以为"银行发的就稳"**：银行次级债同样会减记，包商银行、海外银行的例子说明：机构再大，次级债也可能清零。
- **把次级债当"存款替代"**：它不享受存款保险 50 万保障，本质是投资品，不是储蓄。
- **忽视"次级"二字的含义**：同一只债，一旦加了"次级"，风险等级立刻上了一个台阶，别被发行人名头迷惑。> 一句话：次级债的"次级"，翻译成人话就是"最后拿钱、可能拿不到"。
