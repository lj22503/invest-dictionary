# 剁手冷静期

> 看中想买的东西，先放 24~72 小时再决定——用时间浇灭冲动消费的"冷静期"。

## 1. 这是什么

剁手冷静期是给冲动消费加的一道"时间闸门"：**看到想买的东西，不立刻付款，先放进购物车或收藏夹，等 24~72 小时**。到时如果还想买、确实需要，再下单。

原理很简单：冲动消费的高峰出现在"想要"的瞬间，多巴胺上头的几分钟里，人会高估东西的价值。冷静期让冲动退潮，你会发现大部分东西"其实没那么想要"。

## 2. 为什么重要

电商的限时折扣、直播间的"最后 3 单"、满减凑单……全都在抢你的**即时决策**。你越着急下单，越容易买错。

冷静期能拦住相当一部分非必要支出：

- 大件数码、衣服鞋子、直播间小玩意儿，放两天再看，一半以上会被放弃；
- 省下来的钱不是小数目，一年下来可能是一两个月的工资；
- 它治的不是"买"，是"冲动"——让你重新拿回消费的主动权。

## 3. 怎么用

- 第一步：默认规则——任何超过月收入 10% 的东西，强制冷静 72 小时；
- 第二步：想买就先加入购物车或收藏夹，设一个 24 小时后的提醒；
- 第三步：建一个"想买清单"，月底统一翻一遍，看还有几件真想要；
- 第四步：增加付款摩擦——不绑快捷支付、不开启免密支付、不收藏直播间，付款越麻烦，冲动越容易刹车。

## 4. 常见坑 / 误区

- **冷静期≠永远不买**：真需要、用得上的东西，冷静完照买，别矫枉过正；
- **靠意志力硬扛**：冷静期要靠机制（不绑卡、不进直播间）而不是硬忍，意志力会被消耗光；
- **把冷静期当拖延**：机票、刚需药品、限时刚需活动，该买就买，冷静期是为冲动设的，不是为所有消费设的；
- **冷静后遇到促销又上头**：记住当初为什么冷静，别让"今天便宜"推翻"我并不需要"。
