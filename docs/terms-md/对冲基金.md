# 对冲基金

> 用做空、杠杆、衍生品等策略追求绝对收益的私募基金，目标是不管涨跌都赚钱，门槛与风险都不低。

## 1. 这是什么

### 目标是不管涨跌都赚钱

**对冲基金 = 用做空、杠杆、衍生品等灵活策略，追求「绝对收益」的私募基金。**普通基金的目标是跑赢指数，对冲基金的目标是：市场涨我也赚，市场跌我也尽量不亏。

做法举例：买入一篮子好股票的同时，做空指数期货——股票跑赢指数的那部分差价，就是它赚的钱，与大盘涨跌无关。

一句话：公募想「比市场好」，对冲想「不看市场脸色」。

## 2. 为什么重要

### 为什么重要：和公募的三点区别

**门槛高**：国内对冲策略多在私募，起投通常 100 万，还需合格投资者认证；**策略灵活**：能做空、能加杠杆、能投衍生品，公募基金基本被禁止这些操作；**信息不透明**：持仓和策略细节很少公开，净值披露频率也低，只能定期看报告。对普通人的意义：市场上总有一批钱在「做空」和「对冲」，理解它才能看懂某些下跌和异动。

## 3. 怎么用 / 怎么看

### 怎么用：普通人怎么接触

**间接参与**：通过私募 FOF 或公募的「对冲策略」产品间接持有，不用自己凑 100 万；**分清策略**：市场中性波动小、收益稳；CTA靠期货趋势；宏观对冲赌宏观方向、波动最大；**看两个指标**：最大回撤（亏多少）和夏普比率（每单位风险的收益），回撤小、夏普高的更值得看；**设好预期**：市场中性年化 6%~10% 是正常水平，别期待「旱涝保收 20%」。

## 4. 常见坑 / 误区

### 常见坑：高门槛高费率

**费率贵**：常见「2+20」模式（2% 管理费+20% 业绩提成），牛市里收益被抽走一大块；**业绩分化极大**：明星对冲基金和垫底产品可能差出天上地下，选错比不选更糟；**杠杆是双刃剑**：加杠杆放大收益也放大亏损，一次黑天鹅可能把多年收益清零；**把「对冲」当「保本」**：对冲只是对冲市场风险，策略本身的风险和欺诈风险并不少；**净值不透明**：季度才披露一次，等你看到大跌可能已经晚了。
