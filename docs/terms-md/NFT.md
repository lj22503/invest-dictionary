# NFT

> 一张写在区块链上的“数字产权证”，证明某件数字东西归你。

## 1. 一张写在链上的数字“产权证”

NFT（非同质化代币）是一串存在区块链上的记录，对应某个独一无二的数字物品：一张图、一段视频、一首歌。它不像比特币可以互换（1 个比特币 = 1 个比特币），每个 NFT 都独一无二。

关键是它自带“所有权证明”：谁拥有、什么时候转手，链上写得清清楚楚，无法伪造。

> 一句话：NFT 是数字世界的“房产证”，证明这东西是你的。
## 2. 为什么重要：数字稀缺第一次有了定价

2021 年的加密头像热潮里，一个 NFT 卖到几十万美元，让“数字稀缺”第一次有了定价工具。它让创作者能直接卖“数字原作”，也让收藏品有了可验证的真伪。

但它也是炒作重灾区：绝大多数 NFT 流动性极差，买完可能再也卖不掉，价格全靠下一个接盘的人。

> 一句话：稀缺可以定价，但没人接盘的价格就是一张图。
## 3. 怎么用：买前问三个问题

**第 1 步**：分清“买 NFT”和“买版权”——买 NFT 通常只买到所有权证明，不自动获得版权。

**第 2 步**：评估流动性：这个 NFT 在哪交易？每天成交量多少？没人接盘就是一张图。

**第 3 步**：只投“自己真喜欢、且亏掉也不心疼”的金额。

**第 4 步**：保管好钱包私钥——NFT 被盗等于永久丢失，平台不赔。

> 一句话：买之前先问：我喜欢它，还是只喜欢它能涨？
## 4. 常见坑：买的是证书，不是版权

**坑 1**：以为买了 NFT 就拥有版权——复制、商用权一般都在作者手里。

**坑 2**：冲“地板价暴涨”的热门项目——热度一退，地板价可能跌 90% 以上。

**坑 3**：被“限量+明星站台”忽悠——限量可以无限发，站台可以花钱买。

> 一句话：NFT 买的是稀缺性证明，不是稳赚承诺。
