# 财务分析

> 财务分析是看公司“家底”的方法：翻它的三大报表，搞清利润是真是假、钱花到哪去、欠的债还不还得上。

## 1. 这是什么

**给公司做“全身体检”**

- **财务分析＝通过资产负债表、利润表、现金流量表三大报表，判断一家公司赚不赚钱、稳不稳、有没有水分**；
- 资产负债表看“家底厚不厚”，利润表看“赚得多不多”，现金流量表看“钱到没到手”；
- 核心思路：**利润可以“做”出来，现金很难“装”出来**，所以要三表交叉验证。
> 一句话：财务分析是扒开公司“打扮过”的外表，看它里面到底有没有料。

## 2. 为什么重要

**财报会骗人，但财务分析能识破**

- 康得新账面 122 亿现金，却还不上 15 亿债券——现金与债务的矛盾就是报警器；
- 学会财务分析，能在暴雷前看到“应收账款激增、经营现金流长期为负、商誉高企”等信号；
- 对个人：买股票、买基金，甚至判断一家公司值不值得去上班，都能用同一套“体检逻辑”。
> 一句话：财务分析是投资的“体检报告”，不体检就上车，等于蒙眼开车。

## 3. 怎么用 / 怎么看

- **先看现金流**：经营现金流 ÷ 净利润，长期低于 0.8 要警惕“纸面利润”；
- **再看负债**：资产负债率、流动比率、有息负债规模，判断极端行情下扛不扛得住；
- **拆利润质量**：扣非净利润占比、毛利率趋势、应收账款增速是否快于营收增速；
- **拉长看 3—5 年**：单季/单年数据噪声大，连续几年的趋势才看得出真实经营状态；
- **交叉验证**：利润、现金流、存货、应收四者互相印证，出现背离就是重点怀疑对象。

## 4. 常见坑 / 误区

- **只看净利润**：一次性卖资产、补贴、公允价值变动都能美化利润，扣非净利润才是“主业真相”；
- **把“增长”当“质量”**：靠赊销堆出来的营收增长，应收账款迟早变成坏账；
- **忽略现金流量表**：利润表可以调，现金流最难造假，不看现金流的财务分析等于白做；
- **迷信单一指标**：ROE 高不代表安全，负债率低不代表能赚钱，指标要组合起来看才有效。
