# 汇率风险

> 汇率风险 = 人民币升值或贬值，让你的海外资产、留学、海淘、外贸的钱悄悄变多或变少。

## 1. 这是什么
汇率风险 = 汇率波动导致资产价值或成本变化的风险。例子：持有 1 万美元，人民币从 7.2 升值到 7.0，美元资产就缩水约 2.8%；反过来人民币贬值，美元资产升值。

## 2. 为什么重要
有海外配置、QDII 基金、留学、海淘、外贸、跨境收入的人都会受影响。汇率一年波动 5%-10% 很正常：可能吞掉你一整年的投资收益，也可能白送一波涨幅——只算收益不算汇率，账会算错。

## 3. 怎么用 / 怎么看
- 确认敞口：没海外需求别乱换汇，汇率风险不存在就不需要对冲
- 长期定投摊平：海外资产按月/按季买入，平抑汇率波动
- 大额跨境收支：企业可用远期结售汇、期权对冲，个人尽量错峰
- 盯信号：央行中间价、美元指数、中美利差，是判断汇率方向的三面镜子

## 4. 常见坑 / 误区
- 只算收益不算汇率：QDII 赚 8% 但汇率亏 5%，到手只剩 3%
- 赌单边汇率：押"人民币必升/必贬"，市场分分钟打脸
- 把对冲当投机：频繁换汇，光手续费和买卖价差就吃掉一大截
- 忽视外汇管制：每人每年 5 万美元便利化额度，大额购汇要申报用途
