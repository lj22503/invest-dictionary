# 万能险

> 缴费灵活、有保底利率的"保险+投资账户"混合体

## 1. 这是什么

**万能险** = 保险产品 + 一个单独的投资账户。你交的保费，扣掉初始费用和保障成本后，剩下的钱进入账户，按合同约定的**保底利率**（通常 1.75%-3%）增值。

特点：缴费灵活（可追加可缓交）、保额可调、账户价值透明可查，每月官网公布结算利率。

## 2. 为什么重要

- 它是保险里**透明度最高**的产品之一，账户价值随时能查。
- 有**保底利率**，写进合同，比分红险的"不保证分红"更确定。
- 但**初始费用和保障成本**会逐月扣除，前几年账户价值可能低于已交保费。

## 3. 怎么用 / 怎么看

**三步看清：**

1. **看保底利率**：合同里写死的才是保证的，当前主流在 2% 左右，别信"终身 4%+"的话术。
2. **看结算利率**：官网每月公布，一般高于保底，但会随市场波动下行。
3. **算长期账**：初始费用高（首年可能扣 5%-10%），持有 5-10 年以上才摊薄成本，短期持有大概率亏。

**适合**：有一笔长期（10 年以上）不用的闲钱，想要保底收益+一定灵活性的人。

## 4. 常见坑 / 误区

**坑 1：被"复利滚存"话术忽悠** — 复利是真的，但基数要先扣掉初始费用，前期扣得多，实际收益打折扣。

**坑 2：短期退保** — 前 5 年退保损失大，万能险是"长跑选手"，急用钱千万别投。

**坑 3：把"演示结算利率"当承诺** — 结算利率每月浮动，未来可能降到保底，演示只是演示。

**坑 4：追加/领取有费用** — 部分产品追加保费有手续费，部分领取也有费用，操作前先看条款。
