# 保险受益人

> 受益人就是出险后拿理赔款的人，写对了，钱才能到想给的人手里。

## 1. 这是什么
受益人 = 保险合同中指定的、出险后领取保险金的人。分两类：生存受益人（医疗险、重疾险的理赔款一般赔给自己）和身故受益人（定期寿险、意外险的身故金赔给家人）。身故受益人可以是"指定"或"法定"。

## 2. 为什么重要
指定受益人：理赔款直接给指定的人，快、准、私密。法定受益人：按继承顺序分，可能引发家庭纠纷，还要证明亲属关系。更麻烦的是——不指定受益人，身故金按遗产处理，若生前有债务，可能先还债再分配。

## 3. 怎么用 / 怎么看
- 投保时明确指定受益人：填姓名、身份证号、与被保险人关系、分配比例
- 人生节点及时变更：结婚、离婚、添丁、父母离世后，重新梳理
- 多受益人按比例分配，并在保单中书面写明，避免事后扯皮

## 4. 常见坑 / 误区
- 默认法定：理赔麻烦，钱还可能落不到你想给的人手里
- 受益人先于被保险人身故又未变更，身故金转按法定处理
- 受益人与被保险人在同一事故中身故且无法判定先后，按保险法推定顺序处理
- 离婚后忘记变更：前任仍可能是受益人，真金白银按合同给
