# 集中度风险

> 把钱都押在一个地方，赚得快，赔得更快。

## 1. 这是什么

集中度风险指的是：单一资产、单一行业或单一地区在你总资产中占比过高，由此带来的额外波动风险。

一个常用的判断口径：**单一持仓超过总资产的 20%~30%，就算集中**。

它本身不产生收益，只放大波动——赚的时候更爽，亏的时候更痛。

## 2. 为什么重要

100 万全买一只股票，跌 50% 剩 50 万，要涨 100% 才回本；同样 100 万分在 10 只票上，某只腰斩对总资产的影响只有 5%。

历史上每一次大亏都带着集中度的影子：2000 年互联网泡沫、2021 年教育股、单一房企暴雷，还有中国家庭 60% 以上资产压在房子上这件事本身。

## 3. 怎么用 / 怎么看

- **先算集中度**：单一持仓 ÷ 总资产，单一行业不超过 30%。
- **设硬性上限**：单只个股 ≤ 10%~15%，单一行业 ≤ 20%~30%，超了就减。
- **多个维度分散**：资产类别、行业、地区、币种、买入时间（分批建仓）。
- **相关性别搞混**：买 10 只银行股不叫分散，它们同涨同跌。
- **每年再平衡一次**：涨多了的减一点，把比例拉回目标。

## 4. 常见坑 / 误区

- **假分散**：买了 8 只基金，打开持仓发现是同一批股票。
- **收入与资产双押注**：在互联网公司上班，还把大部分积蓄买自家行业股票，行业下行时两头受伤。
- **集中赚钱后的错觉**：连续押对几次就以为自己选股神准，仓位越加越重，直到一次归零。
- **忽略隐性集中**：房子这种大额、低流动性的资产，最容易让人「以为自己在分散」。
- **把「熟悉」当安全**：熟悉的公司不等于安全的公司。
