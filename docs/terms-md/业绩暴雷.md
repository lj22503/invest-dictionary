# 业绩暴雷

> 公司业绩远低于市场预期，财报一出股价大跌。

## 1. 这是什么

业绩暴雷指公司实际业绩远低于市场预期：亏损、增速大幅下滑、甚至业绩变脸（预告盈利变亏损），财报发布后股价大跌甚至连续跌停。

它杀伤力大，因为机构资金提前按“好业绩”定价，暴雷=定价逻辑被推翻。

> 一句话：市场给的是“预期分”，你交的是“现实分”。

## 2. 为什么重要

A股长期主线是业绩驱动，业绩暴雷往往带来：

- 短期：股价连续大跌，重仓者损失惨重。

- 中期：估值中枢下移，“杀业绩”行情持续。

- 深层：可能是财务造假的暴露窗口。

躲开一次暴雷，比抓住十个涨停更重要。

## 3. 怎么用 / 怎么看

- 盯时间窗：业绩预告、业绩快报、正式财报三个节点，前后波动最剧烈。

- 看扣非净利润：剔除一次性收益后的主业利润，才见真章。

- 警惕高商誉、高应收账款、现金流与利润背离的公司。

## 4. 常见坑 / 误区

- 坑1：只看表面利润。卖资产、政府补贴撑起的利润，不具持续性。

- 坑2：跌多了就抄底。“杀业绩”可能杀完还有“杀逻辑”，别急着接飞刀。

- 坑3：忽视商誉减值。并购多的公司，商誉爆雷是定时炸弹。
