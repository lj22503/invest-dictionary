# 山顶 / 半山腰（高位黑话）

> 把股价走势比作爬山：买在山顶叫“站岗”，买在半山腰叫“不上不下”。

## 1. 这是什么

散户喜欢把行情走势比作爬山：山顶就是这轮行情的高点区域——情绪最热、估值最贵、人人都在谈论股票的时候；半山腰就是下跌途中的中间位置——已经跌了不少，但还没到底。

“站岗”指买在山顶被套住，“接盘”指在半山腰甚至山顶冲进去给别人抬轿子。这些黑话背后是同一个教训：位置决定风险收益比。

> 一句话：山顶买入，回撤空间大、上涨空间小；半山腰买入，上下两难，最容易磨人。

## 2. 为什么重要

同样的股票，在山顶买和在底部买，结局天差地别。2021 年白酒、新能源见顶后，不少在山顶冲进去的投资者回撤超过 40%；而 2018 年底在底部区域入场的人，后面赚到了完整的修复行情。

判断“现在在山顶还是半山腰”，决定了你该重仓、轻仓还是空仓——这是仓位管理里最朴素也最重要的一课。

- 山顶特征：全民讨论股票、基金发行爆款、估值处于历史高分位、融资余额创新高
- 半山腰特征：已经跌了 30%—50%，但基本面（盈利）还在恶化、政策还在收紧
- 底部特征：无人问津、成交萎缩、利空不断但价格跌不动

## 3. 怎么用 / 怎么看

- 看估值分位：市盈率 / 市净率处于历史 90% 以上分位，警惕“山顶区”
- 看涨幅与时间：短期暴涨 + 高位放量滞涨，山顶概率大
- 看情绪指标：新开户数、基金申购量、股吧热度飙升，往往是山顶前兆
- 看基本面趋势：盈利还在下行的“半山腰”，反弹是逃命不是抄底

## 4. 常见坑 / 误区

- 坑 1：“再不买就来不及了”——FOMO 情绪让你在山顶接盘，回看都是山脚
- 坑 2：“已经跌了一半总该到底了吧”——半山腰可能还有半山腰，下跌不言底
- 坑 3：在半山腰盲目补仓“摊薄成本”——如果基本面恶化，摊薄的是亏损不是风险
- 坑 4：把“山顶”当精确点位——位置是区域不是刻度，别纠结“差 5% 是不是山顶”
