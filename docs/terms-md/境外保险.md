# 境外保险

> 去香港等地买保险，主打美元保单和高演示收益，但汇率、理赔、法律风险都不小。

## 1. 这是什么

**境外保险 = 在境外（最常见是香港）投保的保险**，内地客户主要买两类：`重疾险`和`储蓄分红险`。

香港保险的卖点是：美元计价、保额随分红增长、预期演示收益比内地产品高、还能做海外资产配置。

> 一句话：境外保险买的是“美元资产 + 更高演示收益”，不是“更便宜”。

## 2. 为什么重要

对高净值人群，境外保险有真实需求：子女留学、海外养老、美元资产配置、财富传承。但代价同样真实：

- **汇率风险**：保单以美元/港币计价，人民币升值时，保单价值跟着缩水；
- **演示≠保证**：香港储蓄险收益分“保证”和“非保证”两部分，非保证占比可能超过一半；
- **外汇管制**：续期保费跨境缴付麻烦，理赔款入境也可能受限。

## 3. 怎么用 / 怎么看

- **本人必须到香港签约**：内地签的“地下保单”不受两地法律保护，投保务必本人赴港；
- **算真实IRR**：把保证收益和非保证收益分开算，用 IRR 对比内地同类产品；
- **留足汇率预期**：至少能承受美元对人民币双向波动的心理和财务准备；
- **想清楚理赔**：跨境理赔需英文/繁体材料、汇率结算、可能跨境纠纷，便利性要权衡。
> 一句话：境外保险适合“有海外用途+能承受波动”的人，不是大众理财品。

## 4. 常见坑 / 误区

- **“内地签单”=无效保单**：不在香港本地签署的保单无效，理赔时保险公司可以拒赔；
- **只看演示收益**：香港分红险“预期收益”和“保证收益”差距巨大，只演示好看的会踩坑；
- **忽略退保损失**：香港保单前期退保损失可能比内地还大；
- **外汇管制风险**：续费、理赔跨境资金流动受限时，保单变成“烫手山芋”。
