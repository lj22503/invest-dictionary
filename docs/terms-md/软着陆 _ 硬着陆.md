# 软着陆 / 硬着陆

> 经济降温时，"慢慢刹住"叫软着陆，"一头栽下去"叫硬着陆。

## 1. 这是什么

央行加息、收紧货币把过热的经济降下来，有两种结局：

- **软着陆**：经济增速回落但没陷入衰退，就业保持稳定，通胀回到目标，像飞机平稳降落
- **硬着陆**：收紧过头或太急，经济增速断崖式下跌，失业飙升，甚至引发金融危机，像飞机直接砸向地面

历史上美联储最著名的一次"完美软着陆"是 1994~1995 年；而 2008 年次贷危机就是典型的硬着陆。

## 2. 为什么重要

- **决定你的钱包**：硬着陆意味着裁员潮、资产暴跌、企业经营困难；软着陆则受伤小得多
- **影响资产价格**：软着陆预期下股市债市都能平稳；硬着陆恐慌下，风险资产全线杀跌、避险资产（黄金、美债）大涨
- **影响央行政策**：市场天天在猜"这次是软着陆还是硬着陆"，猜对了就踩对了资产配置节奏
- **中国语境**：房地产深度调整是最大的"硬着陆风险源"，政策"保交楼""稳增长"都是为避免硬着陆

## 3. 怎么用 / 怎么看

- **盯就业数据**：失业率快速上行（如萨姆规则触发）是硬着陆的警报
- **盯收益率曲线**：美债长短期利率倒挂后恢复，常被市场当作衰退临近信号
- **盯信贷与消费**：企业融资断裂、居民消费塌方，是硬着陆进行时的特征
- **区分预期与现实**：市场炒的是"预期"——软着陆预期确立时股市提前反弹，别等数据确认才动手

## 4. 常见坑 / 误区

- **把"增速放缓"当硬着陆**：GDP 增速从 5% 降到 4% 是降温，不是硬着陆；硬着陆是负增长级别的崩塌
- **把"软着陆"当"不会跌"**：软着陆过程中股市照样可以大跌，只是不崩盘
- **迷信单指标**：失业率、收益率曲线都可能误报，要多个指标交叉验证
- **忽视"不着陆"情形**：经济太热、通胀反复，央行被迫继续加息，最难受的其实是"迟迟不降落"
