# 骑乘策略

> 专买"快到期的债券"，等它到期前价格自动上涨、提前落袋的债券赚钱法。

## 1. 这是什么

**骑乘策略 = 买入期限比目标期限更长的债券，持有到期前卖出，赚取"久期缩短带来的价格上升"。**原理：债券临近到期时，价格会向面值靠拢，同时收益率曲线通常"越远越高"——买一个 3 年期债券持有到 2 年，相当于"骑"在收益率曲线上往下滑，既吃票息又吃价差。这是机构做债券投资最经典的"增厚收益"手法之一，也被称为"骑收益率曲线"。> 一句话：骑乘策略=买长一点的债，提前下车，赚"滑下来"的价差。

## 2. 为什么重要

在利率平稳、收益率曲线向上倾斜的正常年份，骑乘策略是债市"白捡"的收益来源：比单纯持有到期多赚价差，风险却几乎一样低。理解它，你就能看懂：为什么债基经理会"不按期限老老实实买"；为什么同样是买债，有的产品收益就是高一点。对普通投资者，骑乘策略还解释了债券基金的调仓逻辑——债券基金赚钱不只有票息，还有"时间"本身的钱。> 一句话：债券基金的超额收益，常常来自"骑"而不是"躺"。

## 3. 怎么用 / 怎么看

- **看收益率曲线形态**：曲线向上倾斜（长期利率高于短期）时，骑乘策略空间大；曲线倒挂时，策略失效甚至反向。
- **选合适的期限段**：一般选 2~5 年、曲线最陡峭的区间，骑乘收益最明显。
- **算目标持有期**：先定"骑到几年卖出"，比如买 3 年债、持 1 年后卖出，赚 2 年段的价差。
- **散户落地**：个人很难直接精确执行，但可以选择"久期偏长、调仓积极"的债券基金，间接享受骑乘收益。
- **关注利率风险**：利率大幅上行时，价格下跌可能盖过骑乘收益，别在加息周期重仓骑乘。> 一句话：骑乘策略的功课在买入前——选对曲线、算对下车点。

## 4. 常见坑 / 误区

- **在曲线倒挂时硬骑**：长短利差为负时，"往下滑"变成"往上爬"，骑乘变成负贡献。
- **忽视利率突变**：央行加息、债市熊市，骑乘收益扛不住价格下跌，策略不是"稳赚"。
- **把骑乘和"期限套利"混为一谈**：骑乘赚的是确定性较高的"到期收敛"，不是赌利率方向的投机。
- **散户照搬机构操作**：机构的资金成本、杠杆、规模优势和散户不同，直接模仿容易翻车。> 一句话：骑乘策略赚的是"时间+曲线"的钱，不是"预测利率"的钱。
