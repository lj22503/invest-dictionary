# 分散 vs 集中

> 鸡蛋分篮子放还是全押一个——分散降低单点风险，集中放大收益与波动，怎么选看你的确定性和仓位。

## 1. 这是什么

**分散**：把钱分到多个不相关的资产里，单个爆雷只伤局部，整体波动被摊平——收益中庸，但睡得着觉。

**集中**：把钱重仓到少数几个最有把握的标的上，涨起来是加速器，跌起来是放大镜——收益上限高，回撤也深。

没有绝对的对错，关键看你的**确定性**和**仓位**：越确定，越可以集中；越不确定，越必须分散。


## 2. 为什么重要

分散几乎是投资里唯一"免费的午餐"：在收益大致不变的前提下，通过低相关性资产组合把波动率降下来——**同样的收益，更小的回撤，复利跑得更稳**。

集中的本质是**用波动换上限**：押对了翻倍，押错了腰斩。对普通人来说，集中的最大风险不是标的本身，而是**押注太重导致心态崩坏**——跌 30% 就睡不着，迟早割在地板上。


## 3. 怎么用 / 怎么看

- 试：先看相关性——分散要买"不同涨跌"的资产，买 5 只同板块股票那不叫分散，叫变相集中
- 试：定比例——单只股票/单个行业上限 10%-20%，再看好也别超过；确定性极高、亏光了也不影响生活，才能突破上限
- 试：看波动承受力——组合回撤你能否在 6 个月内不割肉？不能，就主动降低集中度
- 试：用核心-卫星思路——七成"核心"分散配置打底，三成"卫星"集中博弹性


## 4. 常见坑 / 误区

- 坑 1：买 20 只基金以为分散了——底层重仓同一批股票，其实是"隐形集中"
- 坑 2：为了分散买一堆高相关资产——股市跌起来股基债基一起跌，分散了个寂寞
- 坑 3：集中押注"最看好"的一只还加杠杆——对了暴富，错了清零，这不是投资是赌博
- 坑 4：分散到什么都不了解——买一堆看不懂的产品，风险比集中更大
