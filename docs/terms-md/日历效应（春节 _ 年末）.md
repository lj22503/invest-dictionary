# 日历效应（春节/年末）

> A股在春节前后、年末这些固定时间点上的规律性表现。

## 1. 这是什么

日历效应，指市场在某些固定日历节点出现的、有一定统计规律的行情特征。A 股最常被提到的两段：

- **春节前后**：节前资金面偏紧、逆回购利率容易走高；节后资金回流，历史上"春季躁动"（2-3 月）出现概率较高；
- **年末（11-12 月）**：机构年末排名博弈、调仓换股，市场波动加大；部分资金落袋为安。

## 2. 为什么重要

日历效应不是玄学，背后有真实机制：节日现金需求、发薪节奏、机构考核周期、政策窗口期，都会影响资金和情绪。

对普通投资者，了解这些规律至少能帮你：春节前闲钱别闲着（可做逆回购）、春节后别轻易空仓、年末别追高热门排名基金。

## 3. 怎么用 / 怎么看

- 春节前 1-2 周：资金面通常偏紧，闲钱可考虑国债逆回购，利率常有翘尾；
- 春节后 2 月-3 月：历史上"春季躁动"概率较高，可关注两会政策预期方向；
- 年末 11-12 月：机构调仓博弈期，多看少动，避免追高；
- 统计验证：任何"规律"先用近 10 年数据回测，别凭印象下结论。

## 4. 常见坑 / 误区

- 把"统计规律"当"必然发生"：日历效应是概率，不是保证；
- 拿两三年数据当铁律：样本太短，规律可能是巧合；
- 把相关性当因果：春节后涨，可能只是因为恰好遇到流动性宽松，不是"春节"本身；
- 为日历效应强行操作：为了等"躁动"满仓过节、为了躲"年末"清仓，反而踏空。
