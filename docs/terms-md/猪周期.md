# 猪周期

> 猪肉价格大约 3~4 年一轮的"涨价—扩产—跌价—减产"循环，被称为二师兄的过山车。

## 1. 这是什么

养猪是个"时间差"生意：猪价高 → 大家都去养猪 → 一年半后生猪集中出栏 → 供应过剩、猪价暴跌 → 养殖户亏钱退出 → 供应减少、猪价再涨。

这个循环在中国大约 3~4 年走完一轮，所以叫"猪周期"。猪肉在中国 CPI 权重高，猪价一动，通胀数据就跟着抖。

## 2. 为什么重要

- **直接影响你的菜篮子**：猪肉是中国人第一大肉类消费，猪价翻倍，家庭餐桌开支立刻变贵
- **影响 CPI 和货币政策**：猪价大涨会推高 CPI，可能影响央行降息节奏；猪价大跌则可能压低通胀读数
- **影响相关资产**：猪价上涨利好养殖股和饲料股，猪价下跌时这些股票往往承压
- **反直觉投资点**：最赚钱的时候往往是别人最悲观、猪价最低迷、养殖户大面积亏损退出的时候

## 3. 怎么用 / 怎么看

- **看能繁母猪存栏**：这是猪周期的"领先指标"，存栏开始下降，预示 10~14 个月后供应减少、猪价见底
- **看猪粮比**：猪价与玉米价格之比，低于盈亏平衡线说明养殖户在亏损，离周期底部更近
- **看官方数据**：农业农村部每月公布能繁母猪存栏，是国家队的"周期信号"
- **投资视角**：关注猪价底部区域的养殖龙头，比追高更符合周期规律

## 4. 常见坑 / 误区

- **把"猪价涨"当"通胀要来了"**：猪价有周期性，单靠猪肉推起来的 CPI 往往不可持续
- **以为周期很短**：一轮完整猪周期要 3~4 年，中途的反弹不改变大方向
- **盲目抄底养殖股**：猪价见底不代表股价见底，还要看公司成本、资产负债率，高杠杆猪企可能先倒在黎明前
- **忽视非洲猪瘟等外生冲击**：疫病会打乱正常周期节奏，让周期提前反转或拉长
