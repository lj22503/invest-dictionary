# 低波动策略

> 专挑波动小的资产——低波动策略用少跌换长期更高的复利收益。

## 1. 这是什么

**低波动策略，就是有意识选择价格波动更小的资产（低波动率股票/基金/指数）**——不求暴涨，只求跌得少、回撤浅。

听起来保守，但长期数据反复证明：**低波动组合的长期收益往往不输甚至超过高波动组合**，因为少亏 30% 比多赚 30% 更难能可贵——跌 50% 需要涨 100% 才能回本。


## 2. 为什么重要

复利最怕的不是慢，是**大起大落**：年均赚 10% 但中途腰斩，实际收益远低于"每年稳稳赚 8%"的组合。**控制最大回撤，就是保护复利**。

低波动策略还有**心态价值**：回撤小，拿得住，不容易在底部割肉——行为上的优势，比选股的优势更实在。


## 3. 怎么用 / 怎么看

- 看指标：选波动率（年化标准差）低的指数/基金，或红利低波类产品（如红利低波 ETF）
- 看逻辑：低波动常与高股息重叠——股价稳定+持续分红，双重防御
- 看搭配：低波打底（五到七成），再配一点成长资产博弹性，组合更均衡
- 看周期：震荡市/熊市里低波优势明显；大牛市里它会跑输，要有预期


## 4. 常见坑 / 误区

- 坑 1：把"波动小"当"不会亏"——低波资产也会回撤，只是通常更浅
- 坑 2：只看波动率不看基本面——银行、公用事业波动低，但也要看估值和分红持续性
- 坑 3：低波策略买成"僵尸组合"——常年不涨也不跌，收益率太低，扣掉通胀未必划算
- 坑 4：牛市里嫌弃它慢然后割掉——低波是防守资产，别在进攻期用防守逻辑比收益
