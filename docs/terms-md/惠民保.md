# 惠民保

> 政府指导的"平民版百万医疗险"，几十块保一年，门槛超低

## 1. 这是什么

**惠民保（城市定制型商业医疗险）** = 地方政府指导、多家保险公司联合承保的补充医疗险。

特点：**保费便宜**（几十到一百多元/年）、**投保门槛低**（不限年龄、不限职业、带病也能买）、保额高（通常上百万）。

各地名字不同：沪惠保、北京普惠健康保、穗岁康、皖惠保等，本质都是惠民保。

## 2. 为什么重要

- 给**买不了百万医疗险的老人、慢性病患者**兜底——这是它最大的价值。
- 一年几十块，大病时能报几十万，杠杆极高。
- 政府背书，比普通商业医疗险更可信，续保也更稳。

## 3. 怎么用 / 怎么看

**三步判断要不要买：**

1. **看免赔额**：通常 1.5-2 万（医保报销后自费部分扣除），小病用不上，专管大病。
2. **看报销范围**：医保目录内报销比例高（70%+），目录外和特药按比例报，各城市政策不同。
3. **看健康告知**：多数"带病可投"，但既往症报销比例会降低，投保前看清条款。

**建议**：买不了百万医疗险（老人、病人）→ 必买惠民保；年轻健康能买百万医疗 → 百万医疗更优。

## 4. 常见坑 / 误区

**坑 1：以为能报销所有病** — 免赔额高，普通住院自费几千块根本够不着理赔线。

**坑 2：与百万医疗险重复** — 两个都买，理赔遵循"补偿原则"，不能重复报销，浪费保费。

**坑 3：续保不确定** — 惠民保多为一年期，下一年是否续保、条款是否变化不由你决定。

**坑 4：异地就医限制** — 部分产品限本地医保定点医院，异地就医报销比例低或无法报销。
