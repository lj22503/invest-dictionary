# 承接

> 股价下跌时下方有买盘接住，跌不下去——“有承接”说明跌势可能到头。

## 1. 这是什么

**承接，就是股价下跌时，下方不断有买盘把价格接住**——表现为大买单挂在下方、分时图跌到某个价位就被买回去。

承接分两种：**主动承接**（资金真看好，逢低买入）和**被动承接**（主力护盘，防止跌太深）。两者含义完全不同。

判断一句话：**有承接的下跌叫洗盘，没承接的下跌叫出货**——这是看盘最常用的一个分水岭。


## 2. 为什么重要

同样一根阴线，背后的承接完全不同：放量长下影 + 次日不创新低 = 有承接，跌势可能告一段落；缩量阴跌无反抗 = 没承接，阴跌还可能磨很久。

承接的方向判断很重要：**低位承接**可能是主力吸筹（跌不下去、酝酿上涨）；**高位承接**可能是掩护出货（拉起来让散户接盘）。

对普通人的意义：看到“某某股有承接”的说法时，要先问一句——**在什么位置承接、承接的人是谁**。


## 3. 怎么用 / 怎么看

- 看分时：急跌后能否快速收复，跌下去有人捞就是承接
- 看盘口：下方是否有大买单托住，托单撤没撤要看后续
- 看量能：下跌是否放量——放量跌是真卖压，缩量跌是没人卖（相对安全）
- 看次日：承接需要连续性——今天有人接、明天还有人接，才算数


## 4. 常见坑 / 误区

- 坑 1：把护盘当承接——护盘资金撤了照样跌，护盘不等于看好
- 坑 2：高位承接当利好——高位大买单可能是出货前的诱多，接的是你的筹码
- 坑 3：只看一天承接就抄底——承接至少要连续两天以上验证
- 坑 4：把缩量阴跌当“没抛压=安全”——没承接的缩量阴跌最磨人，跌不动不等于要涨
