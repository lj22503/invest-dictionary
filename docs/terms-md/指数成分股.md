# 指数成分股

> 一只指数具体装着哪些股票、各占多少权重——看懂成分股，才算真看懂指数涨跌。


## 1. 这是什么

**指数成分股 = 组成一只指数的具体股票名单和权重。**比如沪深 300 是沪深两市市值最大的 300 只股票，上证 50 是沪市最大的 50 只。指数的涨跌不是“所有股票平均涨跌”，而是**按权重加权计算**：权重越大，对指数的影响越大。茅台跌 1%，比一家小公司跌 10% 更能拖动上证指数。> 一句话：指数不是“市场合影”，是“按身价排座次的董事会”。

## 2. 为什么重要

成分股决定指数的性格：上证指数被银行、石油、白酒等大盘股主导，创业板指被新能源、医药、科技主导——**看指数涨跌前，先看它的权重股在干什么**。你定投的指数基金，本质就是跟着这张成分股名单一起变动：名单换了，基金持仓也跟着换，不用你操心，但你要知道规则。> 一句话：指数的脸，是权重股画的。

## 3. 怎么用 / 怎么看

- **查“权重前十”**：天天基金、中证指数官网都能查到，前 10 大权重往往占指数的 30%-50%。
- **看“调整公告”**：指数每半年调仓（如 6 月和 12 月），调入调出会带来资金流动。
- **看“行业分布”**：判断指数是“宽”（跨行业）还是“窄”（单一行业），决定它够不够分散。> 一句话：买指数前，先花两分钟看看它的“前十大股东”。

## 4. 常见坑 / 误区

- **以为指数涨了我就赚了**：你的持仓可能全在权重股之外，指数涨你不涨很正常。
- **追“新调入”成分股**：调仓公告出来后买入，往往已经涨过一波，等于是接盘。
- **权重集中风险**：个别权重股暴雷，指数跟着大跌，分散是相对的。
- **把指数当“市场平均”**：指数代表的是“成分股平均”，不是全市场、更不是你的基金平均。> 一句话：看懂成分股，才知道你赚的是谁的钱。
