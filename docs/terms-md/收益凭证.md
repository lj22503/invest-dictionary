# 收益凭证

> 券商用自己的信用"打欠条"的理财产品——约定收益型接近"类固收"，挂钩型则可以用来表达对市场的看法。

## 1. 这是什么

收益凭证是证券公司向投资者借钱、并承诺按约定条件兑付收益的凭证，属于券商的债务融资工具。它有两种主流形态：

- 本金保障型：到期保证本金，收益可以固定，也可以挂钩指数、商品等；
- 非本金保障型：本金可能亏损，收益随挂钩标的表现浮动，比如雪球结构。

## 2. 为什么重要

- 约定收益型收益凭证，是比银行理财更"券商味"的类固收选择，部分期限收益率有吸引力；
- 挂钩型收益凭证让你"小额参与"期权等复杂策略，表达看涨、看跌或震荡观点；
- 本质是券商的信用背书：买收益凭证 = 借给这家券商钱，券商信用等级很重要。

## 3. 怎么用 / 怎么看

- 看类型：先分清本金保障型还是非保本型，收益凭证不等于"保本保息"；
- 看券商：选择资本充足、评级高的头部券商，降低信用风险；
- 看条款：挂钩标的、期限、敲入敲出条件、提前终止条款都要逐字读；
- 看适配：结合自己的风险测评等级购买，别把复杂结构当普通理财。

## 4. 常见坑 / 误区

- 误以为"凭证=保本"：非本金保障型产品亏到本金的可能真实存在；
- 忽视券商信用风险：券商经营出问题，兑付可能受影响；
- 把雪球结构当普通理财：敲入后可能长期亏损甚至亏到本金，先看懂再买。
