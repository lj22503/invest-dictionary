# 牛市 / 熊市 / 震荡市

> 牛市=市场整体持续上涨，熊市=持续下跌，震荡市=在一个区间里来回拉锯没有方向。

## 1. 这是什么

经验上，主要指数从低点涨超20%常叫“技术性牛市”，从高点跌超20%叫“熊市”；如果指数长期在一个区间里上上下下、没有明确方向，就是震荡市。

牛市中“买什么都涨、回调就有人接”；熊市中“利好也跌、反弹是逃命”；震荡市则“追涨杀跌两头挨打”。

> 一句话：牛市靠胆量，熊市靠纪律，震荡市靠耐心。

## 2. 为什么重要

不同市道策略完全不同：牛市重仓持股、少折腾；熊市控制仓位、保住本金；震荡市适合高抛低吸和定投，切忌追高。

对心态：市场大部分时间是震荡或下跌，只有少数时间在涨。搞清楚自己处在哪种市道，才不会在该等的时候乱动，在该拿住的时候吓跑。

> 一句话：判断错市道，再好的方法也会亏钱。

## 3. 怎么用 / 怎么看

- 第 1 步：看趋势：指数均线（20/60/120日线）多头排列+成交量放大，往往是牛；跌破关键均线且反弹无力，警惕熊。
- 第 2 步：看宽度：上涨家数占比、涨停家数——普涨才是牛，少数股票抱团涨只是结构性行情，不是全面牛。
- 第 3 步：定策略：牛市持股为主、熊市降低仓位等待、震荡市分批定投摊低成本。

## 4. 常见坑 / 误区

- 坑 1：牛熊只能事后确认——你以为的牛市顶部往往在半山腰，熊市底部也常被反复打磨，猜顶猜底最伤人。
- 坑 2：把结构性行情当成全面牛市——只看到少数板块大涨就重仓追高，很容易接最后一棒。
- 坑 3：震荡市里频繁追涨杀跌——来回折腾的手续费和情绪损耗，比拿住不动亏得更多。
