# 月光族

> 月初富翁，月底穷光蛋——工资到手就花光的人。

## 1. 这是什么

月光族指每月收入当月花光、存不下钱的人——“月初是富翁，月底是穷光蛋”。

月光不是收入问题：月薪 5000 可能月光，月薪 3 万也可能月光，关键在于支出和储蓄的顺序。

先花后存，永远剩不下；先存后花，才能破局。

## 2. 为什么重要

月光最可怕的地方不是“这个月没钱”，而是遇到意外时没有任何缓冲：

- 生病、失业、家里急事，只能靠借呗/信用卡/网贷——利滚利雪上加霜
- 错过投资窗口：没有本金，复利、定投都无从谈起
- 选择权变少：不敢辞职、不敢换城市、不敢拒绝不合理工作

存钱的意义不是“变富”，而是给自己留一条退路。

## 3. 怎么用 / 怎么看

- 先存后花：工资到账先转 10%~20% 到储蓄账户，雷打不动
- 记账 3 个月：找出钱到底花在哪，砍掉最无感的 3 笔开销
- 设“延迟满足”规则：想买的东西先放购物车 72 小时，冲动期过了再决定

从 10% 开始存，哪怕每月只存 500，也是在建立“钱会留下”的系统。

## 4. 常见坑 / 误区

- 坑 1：把月光美化成“会享受”。毫无储蓄的享受，本质是把风险留给未来
- 坑 2：靠“下个月再存”拖延。储蓄必须靠自动转账等机制强制完成
- 坑 3：用信用卡/花呗“假装不月光”。透支消费只是把下个月的工资提前花掉
