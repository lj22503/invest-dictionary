# 期现套利 / 跨期套利 / 蝶式套利

> 期现套利 = 同一商品"现货价"和"期货价"出现明显价差时，两边一买一卖赚差价；跨期套利 = 不同到期月份的合约之间套；蝶式套利 = 三个月份合约组成的"两头卖、中间买"组合。

## 1. 这是什么

**套利的核心思路只有一个：同一个东西，在两个地方卖出了不同的价，就同时买便宜的、卖贵的，把差价装进口袋。** 期货市场给套利提供了三块常见"价差"：

- **期现套利**：现货市场和期货市场之间的价差。比如螺纹钢现货 4000 元/吨，而一个月后交割的期货却要 4100 元/吨——理论上你可以现在买现货、同时卖空期货，到期交货，稳稳赚 100 元价差（扣除成本后）；
- **跨期套利**：同一个品种不同到期月份的合约之间的价差。比如 1 月合约比 5 月合约贵很多，你可以卖贵的、买便宜的，赌价差回归；
- **蝶式套利**：三个月份合约的组合。比如卖 1 月合约、买 3 月合约、再卖 5 月合约，形成一个"中间高、两头低"的价差赌注，风险比单边赌小。

> 一句话：套利赚的不是"涨跌"，是"价差回归"的钱。

## 2. 为什么重要

**套利是理解期货市场"定价锚"的关键，也是散户少有的"高胜率"玩法：**

- **定价校正器**：套利者把过高的价格卖下来、过低的价格买上来，让期货价格不至于长期脱离现货太远；
- **胜率相对高**：赌"价差回归"比赌"单边涨跌"赢面大，因为价差有成本线、仓储线等"硬约束"；
- **风险更可控**：两头都有仓位，方向错了损失有限；
- **机构基本盘**：量化基金和期货公司自营大量做套利，普通人也可见识别其中的逻辑。

**真实场景**：2026 年某个月份，螺纹钢现货 3900 元/吨、期货 5 月合约 4000 元/吨，价差 100 元超出仓储和资金成本约 60 元。套利者买现货抛期货，把价差压回 60 元以内，赚到约 40 元/吨的确定性收益——**赚的是"价差回归"的钱，不是行情涨跌的钱**。

## 3. 怎么用 / 怎么看

- 第一步：理解价差的"合理区间"——把仓储费、资金成本、交割费加总，超过这个区间才值得套；
- 第二步：选品种——流动性好的品种（螺纹钢、豆粕、原油等）价差更规范，冷门品种价差可能长期不合理；
- 第三步：期现套利需要真实能交割现货（仓单、资金、仓库），散户一般做不了"真"期现，只能做"模拟"或跨期；
- 第四步：跨期套利选主力合约之间的价差，观察历史价差区间，偏离历史均值两个标准差以上才出手；
- 第五步：设好止损——价差可能被突发事件打得更开（如逼仓），套利不等于无风险。

> 一句话：先算"成本线"，再谈套利；偏离够远才出手，止损必须设。

## 4. 常见坑 / 误区

- **坑 1：以为套利零风险**：逼仓、交割违约、流动性枯竭都会让价差继续走扩，套利也会大亏；
- **坑 2：把"跨期"当"期现"**：期现套利有现货交割托底，跨期套利没有，两者风险完全不同；
- **坑 3：忽略成本**：手续费、滑点、资金占用利息没算清，表面价差可能全被成本吃光；
- **坑 4：蝶式套利乱开组合**：三腿组合的盈亏结构复杂，新手容易只看到"稳"，没看到中间的 Gamma 暴露；
- **坑 5：把套利和"搬砖"混为一谈**：现货端没有真实货源，所谓"期现套利"可能只是单边赌方向。
