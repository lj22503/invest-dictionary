# 货币供应量（M0 / M1 / M2）

> 央行印了多少钱，按"活不活"分了三个口袋

## 1. 这是什么

货币供应量（M0/M1/M2）就是央行统计的"市面上到底有多少钱"，按流动性从高到低分成三档：

- **M0**：流通中现金。也就是你钱包里的纸币、硬币。
- **M1**：M0 + 企业活期存款。随时能花的"活钱"。
- **M2**：M1 + 定期存款 + 居民储蓄存款 + 其它存款。包含"半活钱"。

数字越大，覆盖的钱越"沉"。M2 是中国央行最常用的口径。

## 2. 为什么重要

M2 增速是判断"钱多钱少"的关键指标。

M2 涨得快（>12%）：钱多，要么流入资产（房价、股价涨），要么引发通胀（物价涨）。
M2 涨得慢（<8%）：钱紧，资产估值被压制，企业借钱难。
M2 同比转负：极少出现，意味着通缩风险。

普通人盯 M2 增速比盯上证指数更靠谱——它是**钱的总闸门**，影响所有资产价格。

## 3. 怎么用 / 怎么看

**步骤 1：每月 11-15 日看央行 M2 数据**
央行在每月 11-15 日公布上月 M2 余额和同比增速。央行官网 + 各大财经 App 都能查到。

**步骤 2：跟"名义 GDP 增速"对比**
M2 增速 - 名义 GDP 增速 ≈ 实际通胀压力。
- 差值 > 3%：宽松，钱多
- 差值 -1% ~ 3%：中性
- 差值 < -1%：偏紧，钱少

**步骤 3：看 M1 占比**
M1 / M2 比率反映"活钱 vs 死钱"。
- 比率上升：企业活期多，准备要花 → 经济活跃
- 比率下降：钱都躺定期 → 信心不足

**步骤 4：跟自己的资产配置联动**
- M2 高增长期：可适度加股票、房产（钱多推涨）
- M2 低增长期：偏防御，多持现金、债券、货币基金

## 4. 常见坑 / 误区

**坑 1：只看 M2 总量，不看增速**
M2 绝对值每年都在涨（中国经济在扩张），单看数字没意义。**永远看同比增速**。

**坑 2：把 M2 当成"印钞速度"**
M2 增加不等于"印新钱"。大部分增量来自贷款派生（银行放贷→企业存款增加）。这是货币乘数效应，不是开动印钞机。

**坑 3：忽略口径变化**
2018 年起央行调整过 M2 统计口径，把货币基金纳入过一段时间又剔除。**看同比增速比看绝对值更稳**。

**坑 4：把 M2 当先行指标**
M2 是滞后数据（每月 11-15 日才出上月），不是预测指标。想判断未来走势，应该看央行公开市场操作、PMI、社融这些更前瞻的信号。
