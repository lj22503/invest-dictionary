# 基金发行规模（情绪指标）

> 基金发行规模 = 新基金募集了多少钱。它是"增量资金"的晴雨表：发行爆火，市场情绪往往也到了高点附近。

## 1. 这是什么

基金发行规模，就是一段时间内**新发基金募集的资金总量**。基金公司什么时候愿意发新基金、基民愿不愿意买，都跟市场温度强相关：

- **行情好**：赚钱效应强，新基金"日光基""百亿爆款"频出，发行规模冲高；
- **行情差**：没人愿意买基金，新基金发行失败、延长募集期都常见；
- **结构信号**：偏股基金发行猛 = 增量资金涌入股市；债券基金发行猛 = 资金避险。

它常被当作**市场情绪与增量资金的代理指标**：新发基金需要建仓，规模越大，未来一段时间入市的"弹药"越多。

> 一句话：基金发行规模 = 新钱愿意往哪跑，越火爆越要警惕"情绪顶"。

## 2. 为什么重要

**基金发行规模既是"弹药"，也是"情绪钟"**：

- **增量资金**：新发偏股基金有建仓期，规模高峰后的一两个月，市场往往有资金支撑；
- **情绪见顶信号**："百亿爆款""一日售罄"扎堆出现时，往往对应市场情绪的高点，历史上多次如此；
- **发行冰点=布局区**：新基金卖不动、发行失败频出时，市场往往冷清到极致，反而是分批布局的区域；
- **风格风向**：发行集中在哪类基金（成长/价值/医药/科技），能看出增量资金的口味。

**真实场景**：2021 年初，"百亿爆款"基金频现，某顶流基金经理产品单日募集超 1000 亿、配售比例极低。回头看到 2021 年一季度，核心资产见顶回调。发行最火热的时候，往往是该谨慎的时候。

## 3. 怎么用 / 怎么看

- 第一步：关注基金业协会/媒体披露的**月度新发基金规模**，区分偏股型和偏债型；
- 第二步：看"爆款"浓度——单月出现多只"日光基/百亿基"，提高警惕；连续多月发行冰点，关注布局机会；
- 第三步：结合**新增开户数、两融余额**一起看，确认增量资金是否形成合力；
- 第四步：新发基金规模高企时，别把"正在建仓的新钱"当"永远的多头"——建仓完毕，增量就会减弱；
- 第五步：把发行规模当"情绪反向指标"用：太热减一点，太冷敢一点。

> 一句话：发行火爆别上头，发行冷清别恐慌——它是情绪钟，不是倒计时炸弹。

## 4. 常见坑 / 误区

- **坑 1：把"发行规模大"当"一定涨"**：爆款基金往往建仓在高位，规模大反而可能是负累；
- **坑 2：只看总额不看结构**：偏股和偏债要分开看，债基发行火爆说明资金在避险，不是股市增量；
- **坑 3：忽略"配售比例"细节**：一日售罄+低配售比例说明抢购潮，情绪更极端；
- **坑 4：拿"老基金净申购"冒充新发**：存量基金申赎和新发募集是两回事，口径别混；
- **坑 5：以为发行冰点=立刻反转**：冰点可能持续很久，情绪指标只能提示"温度"，不能预测"拐点时间"。
