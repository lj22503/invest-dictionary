# 黑天鹅

> 黑天鹅是谁都没想到、一旦发生就砸盘的大事件——事前无法预测，事后人人说“我早知道”。

## 1. 这是什么

“黑天鹅”由学者塔勒布提出，指三类事件：罕见、冲击巨大、事后看又好像能解释。
2008 年次贷危机、2020 年疫情、某家百年银行的突然暴雷，都是典型黑天鹅。
对普通投资者，最可怕的地方在于：你没办法提前知道“下一个黑天鹅是什么”，市场最怕的不是跌，是不知道会跌什么。

> 一句话：黑天鹅不是“风险大”，是“你根本没把它列进风险清单”。

## 2. 为什么重要

风险最残酷的地方是不对称：你辛苦定投十年攒下 50% 收益，一次黑天鹅可能直接让你回撤 40%。
更危险的是组合放大——满仓单一行业、上了杠杆，黑天鹅一来不是“少赚”，是“归零”。

## 3. 怎么用 / 怎么看

既然预测不了，就做好“黑天鹅来了也死不了”的仓位安排：

- **永远别上杠杆**：融资、合约、满仓梭哈，都是在给黑天鹅递刀；
- **单一个股、单一行业别超过总仓位的 10%-20%**：鸡蛋分开放，最坏情况只是亏一块；
- **留 5%-10% 现金或货币基金**：黑天鹅砸出黄金坑时，你还有子弹；
- **股债、多资产配置对冲**：股票跌的时候债券/黄金往往顶一下；
- **警惕“确定性故事”**：越多人说“稳赚不赔”，越是黑天鹅最爱的猎物。

> 一句话：能活过黑天鹅的人，不是预测准的人，是仓位轻的人。

## 4. 常见坑 / 误区

三个典型误区：

- **把黑天鹅当小概率就忽略**：尾部风险是“肥尾”，不是正态分布里可以忽略的尾巴；
- **事后抢着复盘“我早知道”**：黑天鹅的关键是事前不可预测，事后解释不等于事前能躲；
- **以为黑天鹅只有利空**：突然降息、突发并购、政策转向都是“利好式黑天鹅”，同样能让空仓的人踏空。
