# 再保险

> 保险公司的“保险公司”，保险公司怕赔不起，把大风险转给再保险公司。

## 1. 这是什么

**再保险 = 保险公司给自己买的保险**。保险公司承保了风险（比如一张保额几千万的重疾保单、一整条航线的空难风险），但怕万一出事赔不起，就把一部分风险“批发”给再保险公司。

全球著名的再保险公司有慕尼黑再保险、瑞士再保险、中国再保险等。它们像保险行业的“后盾”，站在每一家保险公司的身后。

> 一句话：再保险让保险公司敢接大单、敢保巨灾。

## 2. 为什么重要

没有再保险，一次大地震、一次大型空难，就可能赔垮好几家保险公司。**再保险把“单点巨灾风险”分散到全球**，让保险体系整体更稳。

对普通人的意义很直接：

- 你的保单背后，可能站着再保险公司，**赔付能力多了一层保障**；
- 保险公司敢承保高风险业务（巨灾险、航空险），因为风险已经分出去；
- 监管考核的“偿付能力”，也把再保险安排算进了风险缓释。

## 3. 怎么用 / 怎么看

- **买保险不用专门查再保安排**：这不是普通消费者的决策变量；
- **但可以看“偿付能力充足率”**：监管披露的偿付能力指标已经反映了再保险的作用，比纠结再保更直接；
- **理解“保险公司为什么敢保”**：遇到巨额保单，背后大概率有再保险分担。
> 一句话：再保险是保险行业的“安全垫”，普通人享受其利，无需操其心。

## 4. 常见坑 / 误区

- **以为有再保险=保险公司一定赔**：再保险是按约定比例/额度分担，不是无条件全额兜底；
- **把再保险和“保险资管”搞混**：再保险是“分风险”，保险资管是“管钱投资”，两回事；
- **以为巨灾一定全额赔**：极端情况下（超大规模巨灾），再保险和直保公司都有赔付上限；
- **忽视直保公司本身的经营风险**：再保险缓解的是“赔不起”，管不了“乱投资”“挪用保费”。
