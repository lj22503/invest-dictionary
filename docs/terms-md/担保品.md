# 担保品

> 担保品 = 你在融资融券、质押等业务中抵押给券商/银行的资产（股票、债券、现金等），用来担保你按时还款。

## 1. 这是什么

**担保品是杠杆交易里的"抵押物"**：你想借钱加杠杆，放款方怕你亏了还不上，于是让你先把股票、现金等资产押在账上。

关键点：

- **融资融券场景**：普通股票买入后自动计入担保品池，券商按"折算率"打折计算其担保价值；
- **质押场景**：股东把股权质押给银行/券商借款，股票就是担保品；
- **折算率**：不同资产打折不同，现金 100%、国债约 95%、普通股票通常 50%-70%；
- **维持担保比例**：担保品市值 ÷ 负债，低于警戒线就要补担保品或被强平。

> 一句话：担保品 = 加杠杆的"抵押物"，市场大跌时它决定你还能不能撑住。

## 2. 为什么重要

**担保品是杠杆交易风控的核心变量，直接决定你能借多少钱、什么时候被平仓：**

- **决定了杠杆上限**：担保品越多、折算率越高，可融资金额越大；
- **是强平的"导火索"**：担保品市值缩水 → 维持担保比例跌破线 → 强制平仓；
- **反映市场杠杆温度**：两融余额（担保品池规模）是市场风险偏好的晴雨表；
- **大股东质押风险**：质押率过高的大股东，股价下跌时可能被动减持或被强平，引发连锁反应。

**真实场景**：小陈融资买入股票，账户担保品市值 100 万、负债 50 万，维持担保比例 200%。股价大跌 30%，担保品只剩 70 万，比例降到 140%——券商发短信要求补担保品，他赶紧转入现金，才躲过强平。

## 3. 怎么用 / 怎么看

- 第一步：搞清折算率——不是"市值多少就能抵多少"，现金 100%、股票可能只有 60%；
- 第二步：盯住维持担保比例——券商警戒线一般 150%，平仓线 130%，别等短信才反应；
- 第三步：预留缓冲——别把杠杆用满，留足应对 20%-30% 波动的担保品余量；
- 第四步：看大股东质押率——持仓公司大股东质押比例超过 50% 要格外小心；
- 第五步：分散担保品——别把单一股票作为唯一担保品，个股闪崩会直接击穿担保比例。

> 一句话：用杠杆前先算好担保品的安全垫，跌 30% 还能扛，才算合格。

## 4. 常见坑 / 误区

- **坑 1：以为市值=担保价值**：折算率会打折，跌得多的股票折算率更低；
- **坑 2：忽略维持担保比例**：平时不看，暴跌时收到强平短信才后悔；
- **坑 3：单一股票满仓担保**：个股跌停+流动性差，想补都补不进去；
- **坑 4：忽视质押爆仓链**：大股东高质押爆仓，会引发减持、踩踏式下跌；
- **坑 5：把担保品当普通持仓**：担保品被占用期间，卖出/转出都有限制，别计划外使用。
