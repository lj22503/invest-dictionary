# 天量天价（情绪顶点的信号）

> 成交量放出历史级别的大、价格冲到高点——情绪最疯的时候，往往就是顶部区域。

## 1. 这是什么

天量 = 成交量异常放大（创出阶段新高甚至历史新高）；天价 = 价格创出阶段新高。俗语“天量见天价”：当市场成交疯狂放大、价格冲到最高点时，往往就是顶部区域。

道理在于：天量意味着多空分歧巨大、换手极其充分——大量筹码在最高位易手，接盘的人把未来的购买力都透支了。情绪最高亢的时候，往往也是后续买盘最稀缺的时候。

> 一句话：天量天价是“买盘透支”的信号，市场最热的时候，往往离顶部最近。

## 2. 为什么重要

历史大顶几乎都伴随天量：2015 年 6 月 A 股单日成交突破 2 万亿后见顶；2021 年初核心资产“抱团”最疯狂时成交与基金发行同步见顶。天量是少数出现在顶部、而不是出现在中途的信号。

- 换手率标准：全市场换手率超过 5%（甚至 8%—10%）时，警惕过热
- 融资余额：两融余额快速飙升、创阶段新高，杠杆资金在顶部加速入场
- 基金发行：爆款基金频出、申购火爆，居民资金跑步进场，往往是情绪顶部
- 成交额：单日成交额创多年新高，之后量能无法持续，警惕天价

## 3. 怎么用 / 怎么看

- 第一步：不追高——天量当天或次日的冲高，是减仓窗口而不是买入窗口
- 第二步：看量能能否维持——连续放量上攻可再看，量能萎缩即撤退信号
- 第三步：结合顶部形态确认——天量 + 长上影 / 十字星，顶部概率大增
- 第四步：分批减仓、落袋为安——别指望卖在最高点，卖在“高位区域”就够了

## 4. 常见坑 / 误区

- 坑 1：以为天量必见顶——牛市主升浪里天量之后还能再创新高（“天量之上还有天量”）
- 坑 2：拿“天量见天价”硬套新股 / 小盘妖股——次新股连续一字板的天量逻辑完全不同
- 坑 3：忽略天量的性质——天量可能是机构调仓、主力换手，不一定是散户接盘
- 坑 4：天量当天恐慌割肉——如果量能持续且价格站稳，可能只是加速段，先看确认再动
