# 次新股

> 上市时间不长的股票：没有历史套牢盘，也没有足够长的业绩记录，波动往往比老股更剧烈。

## 1. 这是什么

**次新股 = 上市时间较短的股票，市场通常以上市不满一年作为大致的口径，具体范围并无统一强制标准。**它最大的特征是筹码新：没有长期套牢盘，流通盘往往偏小。

三个阶段值得分开看：

- **连续涨停期**：上市初期筹码稀缺，容易被连续拉涨，估值快速抬升；
- **开板震荡期**：打开涨停后换手率极高，多空分歧最大；
- **解禁考验期**：原始股东限售股陆续解禁，供给压力上升。

> 一句话：次新股不缺想象力，缺的是足够长的业绩记录。

## 2. 为什么重要

- **流通盘小、换手高**：同样的资金量能撬动更大的涨幅与跌幅；
- **上方没有套牢盘**：上涨阻力小，反过来下跌时也缺少承接盘；
- **限售股在排队**：解禁时间表决定了未来供给会在什么时点出现；
- **业绩记录短**：缺少多轮景气与周期的验证，故事容易被放大，也容易被证伪。

## 3. 怎么用 / 怎么看

- **查解禁时间表**：首发原股东限售股、战略配售、机构配售的到期日，是最硬的供给变量；
- **看换手与成交**：换手率长期高企说明筹码不稳，波动会持续；
- **看募投项目进度**：募集资金是否真正转化为产能与收入，是区分真成长与纯炒作的关键；
- **看上市前后的业绩连续性**：上市前冲刺、上市后变脸的公司要格外小心；
- **控制仓位并预设止损**：小盘次新波动大，仓位与退出规则要事先定好。

> 一句话：打新看运气，持有次新看的是耐心与纪律。

## 4. 常见坑 / 误区

- **以为无套牢盘就不会跌**：没有套牢盘同样意味着没有承接盘，跌起来往往更急；
- **忽视解禁冲击**：解禁不代表一定砸盘，但供给预期会提前压制估值；
- **把高送转当利好**：送转只是把一张饼切成更多块，不改变公司价值；
- **被新股必涨的老经验带节奏**：注册制下破发已经是常态；
- **用短线逻辑长期持有**：买的时候想赚快钱，被套后改成长线，最容易两头挨打。
