# 新三板

> 新三板是“股份能转让”，不等于“股票能随便买卖”。

## 1. 这是什么

**新三板（全国中小企业股份转让系统）是给中小企业挂牌转让股份的市场，和沪深交易所的“上市”不是一回事。**

- **分层**：基础层、创新层（早年的精选层已升级为北交所）

- **门槛**：挂牌门槛比 IPO 低，但投资者门槛高：一般需要 2 年投资经验加 100 万 / 200 万证券资产

- **交易方式**：以集合竞价、做市、协议转让为主，不像主板那样连续撮合

> 一句话：新三板是“股份能转让”，不等于“股票能随便买卖”。

## 2. 为什么重要

- **它是理解北交所的入口**：北交所上市公司的来源，就是新三板创新层企业

- **最大的问题是流动性**：一天可能只有几笔成交，想卖的时候找不到对手盘

- **信息披露要求低于主板**：公司质量分化极大，需要更强的识别能力

- **对普通投资者的定位**：更多是“知道有这回事”，而不是一个合适的交易场所

如果你在创业、或持有创业公司股份，新三板是股权退出路径里需要了解的一环。

## 3. 怎么用 / 怎么看

- **先确认资格**：个人开户门槛通常是 100 万 / 200 万证券资产加 2 年经验，不满足无法参与

- **看层级**：创新层质地好于基础层，但两者都比主板波动更大、流动性更差

- **看股东户数和成交额**：股东太少、成交清淡的公司，买入容易卖出难

- **看信息披露**：至少读一遍近两年的年报，别只看“概念”

- **当研究池用**：发现好公司，等它真的走到北交所再考虑出手

> 一句话：新三板的价值在“发现得早”，风险在“退不出去”。

## 4. 常见坑 / 误区

- **把挂牌当上市**：挂牌企业的知名度、流动性、监管强度都比不上上市公司，别用主板的心态去估值

- **以为“100 万门槛”是保障**：门槛只是把风险集中给承受能力更强的人，不代表风险更小

- **忽略流动性折价**：账面市值 100 万，真想卖可能打七折还没人接

- **被“转板预期”冲昏头**：不是所有创新层公司都能上北交所

- **用短期资金参与**：这类资产可能需要好几年才能退出
