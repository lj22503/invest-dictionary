# 714高炮

> 借期只有 7 天或 14 天、利息高得离谱的网络小贷，俗称“714 高炮”，逾期后常伴随暴力催收。

## 1. 这是什么

“714”指借款期限只有 7 天或 14 天，“高炮”形容利息像炮弹一样猛。常见玩法：借 1000 先扣 300“砍头息”到手 700，到期却要还 1000 多；还不上就被引导“以贷养贷”借新还旧，债务几周内滚成几倍。

> 一句话：7 天期小额贷款，年化利率经常超过 1000%，是网贷里的“野生猛兽”。

## 2. 为什么重要

期限越短，资金周转成本越高：即使“只借了 1000”，多周转几次利息就超过本金。监管已明确打击这类超高利率、暴力催收的非法放贷，多地以非法经营罪、催收非法债务罪立案处理。

> 一句话：碰一次 714，可能半年都在给利息打工。

## 3. 怎么用 / 怎么看

- 看期限：正规消费贷期限至少 3-36 个月，只给 7 天/14 天的几乎都是高炮。
- 看放款方：没有正规金融牌照、只靠短信链接或来路不明的 App 放款，一律别碰。
- 看催收：声称爆通讯录、P 图群发、上门威胁的，属于违法催收，保留证据直接报警。

## 4. 常见坑 / 误区

- 误区一：“只借一周周转一下没事”——到期还不上就借新的补，雪球越滚越大。
- 误区二：以为“不上征信就查不到”——大数据风控一样留痕，正规银行审批会参考。
- 误区三：被催收吓到继续借钱填坑——正确做法是停止以贷养贷，超法定利率部分依法不还，并向公安机关、金融监管部门举报。
