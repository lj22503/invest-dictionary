# 结构化产品

> 结构化产品 = 用固定收益资产+衍生品（期权）组合而成的产品，收益随挂钩标的波动，常见有保本型、雪球、鲨鱼鳍等。

## 1. 这是什么

**结构化产品是把"债券+期权"拼装起来的金融产品**：大部分资金买债券/存款保底，小部分资金买期权博高收益。

关键点：

- **基本结构**：固定收益部分（保本垫底）+ 衍生品部分（挂钩指数、个股、商品等）；
- **常见形态**：银行结构性存款、券商收益凭证、雪球产品、鲨鱼鳍/二元结构等；
- **收益特征**：不是固定收益，而是"区间收益"——涨到某范围给 X%，跌破某价位可能亏损；
- **发行主体**：银行（结构性存款）、券商（收益凭证）、基金专户等。

> 一句话：结构化产品 = 用利息买一张"方向彩票"，保底是壳，期权才是灵魂。

## 2. 为什么重要

**结构化产品把"确定性"和"弹性"打包卖给你，是理解现代资管产品的关键：**

- **收益非线性**：收益与标的关系不是直线，可能"涨了不赚、跌了亏钱"；
- **保本幻觉**：很多产品标榜"保本"，但保本有前提条件（持有到期、挂钩未触发等）；
- **规模巨大**：结构性存款、收益凭证规模庞大，是居民理财的重要去向；
- **敲入敲出机制**：雪球等产品有敲入/敲出条款，本质是卖期权收权利金，不是"无风险高息"。

**真实场景**：小赵买了挂钩中证 500 的"雪球"产品，宣传"年化 15%"。结果指数大跌 20% 触发敲入，产品按跌幅转成指数亏损，他不仅没拿到 15%，还亏了 15%——他这才知道雪球是"卖保险"，市场大跌时自己是赔付方。

## 3. 怎么用 / 怎么看

- 第一步：拆结构——先分清保本垫底占多少、期权部分赌什么方向；
- 第二步：看挂钩标的——指数/个股/商品，波动越大，期权越贵、条款越复杂；
- 第三步：看收益条款——触发条件（敲入/敲出/观察日）、区间范围、封顶收益；
- 第四步：看保本条件——是"完全保本"还是"条件保本"，持有到期才能兑现吗；
- 第五步：匹配风险预算——极端行情下最大亏损是多少，能否承受，再决定配置比例。

> 一句话：买结构化产品先问三件事：保什么底、赌什么方向、最坏亏多少。

## 4. 常见坑 / 误区

- **坑 1：把"保本"当无条件**：多数保本需持有到期+条款未触发，中途赎回可能亏本金；
- **坑 2：只看到"高收益"没看到"敲入"**：雪球类产品大跌时可能转成直接亏损；
- **坑 3：把结构化产品当存款**：结构性存款不等于普通存款，利率是浮动的、还可能拿不到；
- **坑 4：忽视产品复杂度**：条款越复杂越难估值，看不懂的产品别重仓；
- **坑 5：用短期资金买长期结构**：流动性差、提前赎回代价大，资金期限要对齐。
