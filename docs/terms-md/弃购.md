# 弃购

> 弃购 = 新股中签后不交钱、放弃申购，让承销商捡漏包销。

## 1. 这是什么

打新中签后，要在规定时间内**缴款**。没交钱、账户余额不足，就是"弃购"。弃掉的股份由主承销商包销，也就是承销商自掏腰包接盘。弃购分网上弃购（散户）和网下弃购（机构），监管都会盯着。

## 2. 为什么重要

弃购的人多，说明市场普遍不看好这只新股（往往有破发预期）。2021 年后 A 股**破发常态化**，弃购从"傻子行为"变成了理性选择——中签了先研究，值才缴，不值就弃。但连续弃购会被记入诚信记录，影响后续打新资格。

## 3. 怎么用 / 怎么看

- 中签后先看**发行价 vs 可比公司估值**，贵得离谱就谨慎
- 看**行业热度**：冷门行业高发行价新股，破发概率大
- 看**上市首日表现预期**，算不清就不缴，弃购是合法选择
- 记住缴款截止时间，别因为忘记看公告而被动弃购

## 4. 常见坑 / 误区

- 以为弃购只是"损失一次打新机会"，忽略诚信记录影响
- 中签后不看公告，错过缴款窗口被强制弃购
- 以为弃购是"占便宜"——承销商包销后抛压更大，首日可能更惨
