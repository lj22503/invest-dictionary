# 雇主责任险

> 员工上班受伤，保险公司赔给老板的“工伤兜底”，小微企业防大雷的刚需。

## 1. 这是什么

**雇主责任险 = 员工在工作期间受伤、患职业病甚至猝死，依法应由雇主赔偿的，由保险公司赔给雇主。**

它和工伤保险是两码事：`工伤保险`是社保“五险”之一，是企业的法定义务，赔的是员工；`雇主责任险`是商业保险，赔的是雇主——替老板把“要自己掏的赔偿”转嫁给保险公司。

> 一句话：工伤保险管“法定”，雇主责任险管“老板兜底”。

## 2. 为什么重要

很多小微企业、个体户、灵活用工场景没给员工上工伤保险（或者根本没法上），一旦发生工伤事故：

- 一个工人手臂受伤，医疗费+误工费+伤残赔偿，动辄十几万到几十万；
- 如果是猝死或重度伤残，赔偿可能上百万；
- 法院判下来，老板个人财产都可能被追偿。
雇主责任险一年保费通常只要几百到几千块，**是老板花小钱防大雷的典型险种**。

## 3. 怎么用 / 怎么看

- **优先保“没社保兜底的人”**：临时工、外包人员、小时工、实习生，是雇主责任险的重点；
- **看保障范围**：是否含猝死（很多产品要单独加）、上下班途中意外、职业病、诉讼费；
- **按工种定保额**：高空、电工、驾驶等高危工种，费率和保额要单独谈；
- **留好用工证据**：合同、考勤、工资记录，理赔时都要用。
> 一句话：别等出事再买，雇主责任险买的就是“出事那天”的底气。

## 4. 常见坑 / 误区

- **把雇主责任险当团体意外险**：意外险赔给员工本人，雇主责任险赔给雇主；员工受伤后两份都可能拿，但功能不同；
- **以为保“全天24小时”**：多数只保工作时间和工作场所内，下班后出事不赔；
- **忽略猝死责任**：猝死不在一般意外责任里，要确认产品是否含“猝死/过劳死”条款；
- **拿它替代工伤保险**：工伤保险是法定义务，不上是违法的，雇主责任险不能替代。
