# 增持

> 大股东或管理层真金白银买自家股票——增持是最直白的信心表态，但分真买和喊买。

## 1. 这是什么

**增持 = 上市公司的大股东、董监高或其他相关方在二级市场买入本公司股票的行为。**它和回购不同：回购是公司用自有资金买，增持是股东用个人或机构资金买。

常见形式：

- **大股东增持**：控股股东或一致行动人买入，信号意义较强；
- **董监高增持**：金额通常不大，但方向性明确；
- **员工持股与股权激励**：绑定长期利益，但往往附带考核条件与价格折扣。

> 一句话：增持是用钱投票，比任何口头表态都实在。

## 2. 为什么重要

- **信息优势**：管理层对订单、产能、回款节奏的理解，远超外部投资者；
- **利益绑定**：真金白银买入，让股东与管理层的利益站在同一边；
- **估值信号**：当公司认为股价低于内在价值时，增持最常见；
- **它能稳住情绪**：在市场恐慌阶段，增持公告常起到阶段性托底作用。

## 3. 怎么用 / 怎么看

- **看是否真买**：有没有实际成交记录、金额是否落地，比计划公告重要得多；
- **看金额与身家占比**：增持一百万元和增持一亿元，含义天差地别；
- **看成交价格区间**：实际买入价是一个重要的估值参照；
- **看是否连续**：持续多轮增持，比一次性表态更可信；
- **看是否与减持交替**：先增持造势、后减持套现，是常见的套路。

> 一句话：增持的价值不在公告，在成交。

## 4. 常见坑 / 误区

- **只看公告不看兑现**：承诺增持不等于已经买入，计划可能缩水或延期；
- **把增持当买入理由**：增持解决的是信心问题，解决不了基本面问题；
- **忽视附带条件**：员工持股与股权激励常有业绩考核与锁定期，价格也常带折扣；
- **把增持当无条件兜底**：大股东同样可能判断失误，增持之后继续下跌并不少见；
- **忽略锁定期后的动作**：增持买入的股份到期后如何处置，才是关键。
