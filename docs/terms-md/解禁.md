# 解禁

> 限售股锁定期结束、可以上市流通，常带来抛压担忧。

## 1. 这是什么

公司上市时，原始股东、战略投资者、定增机构的股份通常有锁定期（首发股东一般1-3年）。锁定期结束、股份可以上市交易，就叫解禁。

解禁不等于立刻卖，但意味着潜在的抛售压力变大，市场通常提前反应。

> 一句话：闸门开了，水不一定马上放，但池子里的鱼先慌。

## 2. 为什么重要

解禁对股价的影响，本质是“供给增加”的预期：

- 解禁规模大（占总股本比例高）→ 抛压担忧强。

- 解禁方成本低（如原始股东）→ 卖出动力大。

- 叠加减持公告 → 股价短期承压明显。

所以每到解禁高峰期，市场情绪会先跌为敬。

## 3. 怎么用 / 怎么看

- 查解禁日期和规模：占总股本比例，超过5%要重视。

- 看解禁方成本：成本越低、浮盈越大，越有卖出冲动。

- 盯减持公告：解禁后是否配套减持计划，比解禁本身更关键。

## 4. 常见坑 / 误区

- 坑1：以为解禁当天必跌。实际利空常提前消化，解禁日反而可能利空出尽反弹。

- 坑2：只盯首发解禁。定增、股权激励解禁同样有冲击。

- 坑3：忽略基本面。好公司解禁后不减持甚至增持，反而是信号。
