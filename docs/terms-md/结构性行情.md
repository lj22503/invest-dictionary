# 结构性行情

> 结构性行情=大盘指数整体没怎么涨，但部分板块和股票轮番上涨、赚钱效应集中在少数方向的行情。

## 1. 这是什么

结构性行情=大盘指数整体原地踏步，但一部分板块和股票轮流涨、轮流跌，赚钱效应集中在少数地方。

打个比方：整桌菜没上新，但转盘上某几盘菜被反复夹空又补货；如果你只盯着桌子中央（指数），会以为今天压根没人吃饭。

> 一句话：指数是平均分，结构性行情看的是“谁在拉高平均分”。

## 2. 为什么重要

结构性行情里，指数可能是平的甚至跌的，但 AI、新能源、消费等板块可能走出翻倍行情；追错方向的人，却照样亏钱。

它会迷惑人：买指数基金的人觉得“市场不行”，买对赛道的人觉得“牛市来了”，两种体感完全相反。

> 一句话：结构性行情最考验选方向的能力，而不是看大盘的能力。

## 3. 怎么用 / 怎么看

- 第 1 步：看指数与个股是否背离——指数横盘，但每日上涨家数不少、涨停股集中在少数板块，就是结构性行情。
- 第 2 步：看资金去向——北向资金、龙虎榜、板块成交额，钱扎堆往哪几个方向去，行情就在哪。
- 第 3 步：定策略——要么聚焦景气方向做波段，要么干脆定投指数等待全面行情，切忌在弱势板块里死扛。

## 4. 常见坑 / 误区

- 坑 1：只看到少数板块大涨就重仓追高：把结构性行情当成全面牛市，最容易接最后一棒。
- 坑 2：在结构性行情里死守“没被资金看上”的板块：拿着两三年，指数回来了，你的股票还在原地。
- 坑 3：频繁追热点：结构性行情轮动快，追涨杀跌很容易两边挨打。
