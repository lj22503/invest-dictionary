# 每股净资产

> 每股净资产 = 公司账面"家底"摊到每一股上；它是市净率的"分母"，也是判断股价有没有"底"的参考线。

## 1. 这是什么

每股净资产（Book Value Per Share，BVPS），就是把公司的**净资产（总资产 - 总负债）除以总股本**，得到"每一股股票背后对应的账面家底值多少钱"。

公式：**每股净资产 = 净资产 ÷ 总股本**。

打个比方：一家公司净资产 100 亿、总股本 10 亿股，每股净资产就是 10 元。意思是不管股价怎么炒，按账面算，每股背后"实实在在的家底"是 10 元。

它跟每股收益（EPS）不一样：EPS 是"今年每股赚多少"，反映盈利能力；每股净资产是"每股有多少身家"，反映积累了多少家底。

> 一句话：每股净资产 = 把公司账面家底平摊到每股，看"一股值多少账面钱"。

## 2. 为什么重要

**每股净资产是估值和"安全垫"判断的核心**：

- **市净率（PB）的分母**：PB = 股价 ÷ 每股净资产。每股净资产越高，PB 越低，股票看起来越"便宜"；
- **破净线**：股价跌到每股净资产以下（PB<1），意味着市场认为公司"账面家底都不值这个价"，往往是极度悲观信号，也可能是机会；
- **价值股的锚**：银行、钢铁、地产等重资产行业，投资者常用每股净资产衡量"底线在哪"；
- **增发/回购的参考**：公司增发时定价常参考每股净资产，回购时也看它是否被低估。

**真实场景**：银行股股价常年低于每股净资产（破净），股民老张看着"股价比账面家底还便宜"心动买入。但要注意：账面家底可能是"坏的资产"，银行破净背后是坏账担忧，光看数字便宜不代表真便宜。

## 3. 怎么用 / 怎么看

- 第一步：找到公司财报中的**净资产（归属于母公司股东权益）**，除以最新总股本，算出每股净资产；
- 第二步：用**股价 ÷ 每股净资产**算出市净率（PB），横向对比同行业公司谁更便宜；
- 第三步：看每股净资产的**历史趋势**——是逐年增厚（家底变厚）还是原地踏步/缩水（家底被侵蚀）；
- 第四步：重资产行业（银行、地产、周期股）重点看它，轻资产行业（互联网、软件）参考价值有限；
- 第五步：结合 ROE 一起看：ROE 高 + 每股净资产增厚 = 家底在高效增值，比单纯"便宜"更有价值。

> 一句话：每股净资产是"家底尺"，结合 ROE 和行业属性看才有意义。

## 4. 常见坑 / 误区

- **坑 1：以为每股净资产是"最低价"**：账面家底可能虚高（商誉、坏账没提足），股价跌破每股净资产还能继续跌；
- **坑 2：拿它套轻资产公司**：互联网公司大量价值在无形资产和人才上，账面净资产严重低估真实价值；
- **坑 3：忽略"分母"变化**：总股本会因增发、回购、转股变化，每股净资产同步变化，别拿旧股本算新数字；
- **坑 4：把每股净资产当每股收益**：一个是"身家"，一个是"收入"，前者看积累、后者看赚钱能力，别混用；
- **坑 5：只看绝对值不看行业**：不同行业的每股净资产差异巨大，必须同行业横向比较，跨行业比 PB 没有意义。
