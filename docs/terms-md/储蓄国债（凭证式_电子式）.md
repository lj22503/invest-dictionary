# 储蓄国债（凭证式/电子式）

> 国家信用背书的储蓄债券，低门槛锁定利率，老百姓的“压舱石”。

## 1. 这是什么

储蓄国债是国家信用背书的储蓄型债券，面向个人投资者，100元起购，通常3年期、5年期。

两种形式：凭证式（纸质凭证，到期一次性还本付息）；电子式（电子记账，按年付息，支持网上购买）。

> 一句话：比存款利率高，比理财产品稳，比股票省心。

## 2. 为什么重要

国债收益率被视为无风险利率的基准，储蓄国债则是普通人的“利率锚”：

- 安全性最高：国家信用，几乎零违约风险。

- 收益稳定：提前锁定未来3-5年利率，对抗降息。

- 门槛低：100元起，人人都能买，常常“秒光”。

## 3. 怎么用 / 怎么看

- 发行节奏：一般每月10日发行，关注财政部公告。

- 渠道：凭证式去银行柜台，电子式可在手机银行、网银购买。

- 策略：利率下行周期，尽早锁定5年期长期品种。

## 4. 常见坑 / 误区

- 坑1：以为随时能买。储蓄国债额度有限，热门期数开售即空。

- 坑2：提前兑取吃亏。不满一定期限要扣利息，还可能收手续费。

- 坑3：凭证式/电子式计息方式不同。凭证式到期一次付，电子式按年付，别买错。
