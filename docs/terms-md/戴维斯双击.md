# 戴维斯双击

> 业绩涨 + 估值涨，两边一起发力，股价"双击"起飞——戴维斯双击是成长股最性感的上涨方式。

## 1. 这是什么

股价 = 每股收益 × 市盈率。戴维斯双击说的是：当一家公司盈利增长（EPS 提高），同时市场愿意给它更高的市盈率（PE 抬升），两者相乘，股价涨幅远超业绩涨幅。

举例：EPS 从 1 元涨到 1.5 元（+50%），PE 从 15 倍抬到 25 倍（+67%），股价从 15 元涨到 37.5 元（+150%）。业绩和估值共振，就是"双击"。

## 2. 为什么重要

- 它解释了大牛股为什么能涨 3~5 倍：业绩兑现 + 情绪抬估值，戴维斯双击会反复发生；
- 它提醒你区分"赚业绩的钱"还是"赚估值的钱"：前者更可持续，后者容易回吐；
- 反过来就是"戴维斯双杀"：业绩下滑 + 估值收缩，股价可能腰斩再腰斩。

## 3. 怎么用 / 怎么看

- 找"业绩拐点 + 估值不贵"的标的：利润增速回升初期，PE 还没被炒高，双击空间最大；
- 用 PEG 辅助判断：成长股 PEG < 1 且业绩持续兑现，双击概率高；
- 跟踪业绩预告 / 业绩快报：业绩超预期往往是双击的扳机；
- 分批兑现：估值已到历史高分位时，把"估值那部分收益"先落袋。

## 4. 常见坑 / 误区

- 只看业绩增速就追高：买在估值顶部，业绩再涨也可能"杀估值"；
- 把周期股当成长股：周期高点的高盈利 + 高估值，最容易双杀；
- 忽视"预期已打满"：股价提前反映了双击，利好兑现反而下跌。
