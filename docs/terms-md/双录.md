# 双录

> 买保险时对销售过程全程录音录像，让你买的和销售说的一致，事后有据可查。

## 1. 这是什么

<strong>双录 = 录音 + 录像。</strong>监管要求，在银行、保险公司网点销售人身保险时，必须把销售过程全程录下来——销售人员讲了什么、你回答了什么，声画都有记录。

需要双录的场景很具体：<strong>向老年人销售保险、销售分红险/万能险等理财类产品、投保人自愿投保的特定产品</strong>，都属于重点双录范围。录完还要保存，期限通常不短于 5 年（部分险种 10 年），就是为了随时能调出来核对。

> 一句话：双录不是走形式，是给“买保险”这件事装了个摄像头。

## 2. 为什么重要

买保险最怕什么？<strong>销售口头承诺一大堆，出险时保险公司不认。</strong>“这个产品五年就能回本”“收益比存款高”“什么都能赔”——这些口头话术，过去没有双录就是一笔糊涂账。

有了双录：

- 对消费者：销售说过的话、展示过的收益演示都在录像里，将来理赔纠纷可以当证据；

- 对监管：查销售误导有实锤，罚起来有依据；

- 对销售方：规范动作，倒逼他们不敢乱承诺。

真实案例里，很多人投诉“销售说保证 5% 收益”，最后靠双录录像证明确实说过这话，才拿回说法。

## 3. 怎么用 / 怎么看

- 录前先核人：看销售的保险执业证，确认是保险公司还是第三方机构的人；

- 录时听关键话术：收益演示、退保损失、健康告知、缴费期限，每一句都要听清；

- 不确定就说不确定：录像里你点头，将来就是“已知情”，别稀里糊涂说“明白”；

- 录后要自己的那份：问销售方要双录回执或留存方式，万一纠纷用得上；

- 配合“全程在场”：双录要你本人在场、本人回答，不能由别人代答。

> 一句话：双录时你点的每一个头，将来都可能变成“你已确认”。

## 4. 常见坑 / 误区

- 坑一：双录 = 产品没风险——双录只证明“销售过程合规”，不证明“这个产品适合你”；

- 坑二：被诱导“双录时别乱说话”——销售让你别问、别多说，恰恰是最该问的时候；

- 坑三：照稿子念完就算完——双录走过场，你根本没听懂条款，录像里全是“嗯嗯好的”；

- 坑四：关掉录像再补“额外好处”——销售在双录结束后偷偷说“我私下再给你返点”，这种话没录像，也大概率是违规。
