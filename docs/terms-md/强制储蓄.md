# 强制储蓄

> 把钱"藏"起来不让手花掉，靠规则战胜人性。

## 1. 这是什么

强制储蓄指用制度化方式把收入的一部分先存起来：发薪日自动转账、基金定投、零存整取、购买锁定期的产品。

核心思路是"先付给自己"（Pay Yourself First）：拿到钱先存，剩下的才是生活费。

它不需要意志力，靠的是把"存钱"变成自动发生的动作。

> 一句话：强制储蓄是把存钱从"靠自觉"变成"靠系统"。

## 2. 为什么重要

人的本能是"先花后存"，月底"剩多少存多少"的结果通常是永远剩不下。

强制储蓄恰好反着来：钱一到账就转走，花不掉自然就存下了。

它是普通人积累第一笔本金最有效的方法，本金有了，后面才有复利、投资、应急。

> 一句话：先付给自己，剩下的才叫"可花收入"。

## 3. 怎么用 / 怎么看

**第 1 步**：发薪日当天，自动把10%-30%转入储蓄/定投账户，雷打不动。

**第 2 步**：用"四笔钱"框架分配：应急金、目标储蓄、长期投资、日常开销各就各位。

**第 3 步**：金额随收入增长阶梯上调，每次加薪先加储蓄比例。

**第 4 步**：把储蓄账户和消费账户分开，眼不见手不痒。

> 一句话：最好的存钱法是"看不见就花不掉"。

## 4. 常见坑 / 误区

**坑 1**：把还贷、交保费当成强制储蓄——这些是支出，净资产并没有增加。

**坑 2**：存的钱全放活期，收益赶不上通胀，越存购买力越低。

**坑 3**：一开始比例定太高（如50%），生活太紧坚持不了几个月就放弃。

> 一句话：强制储蓄重在"净储蓄"，不是"看起来存了"。
