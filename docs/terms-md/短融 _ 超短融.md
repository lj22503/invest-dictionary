# 短融 / 超短融（短期融资券 / 超短期融资券）

> 大公司发的“一年内要还”的短期借条，超短融一般 ≤270 天，收益比存款略高。

## 1. 这是什么

短期融资券（短融）和超短期融资券（超短融），是信用良好的大企业（多是央企、国企、龙头企业）在银行间市场发行的短期债券，本质是“大公司向你借钱，承诺一年内还”。

两者区别主要在期限：短融期限一般在 1 年以内，超短融通常在 270 天以内，利率也更贴近货币市场资金价格。

普通投资者一般不直接买，但它是你钱包的“隐形居民”——货币基金、银行现金管理类理财、固收+ 产品里，大量底层资产就是这类短期信用债。

## 2. 为什么重要

它是货币基金和银行理财的“压舱石”之一：余额宝、零钱通这类产品为了兼顾流动性和收益，会配置大量超短融。

看懂它，你就知道为什么货基收益会跟着资金面走：市场钱紧时，新发超短融利率上升，货基收益跟着涨；市场宽松时，利率下行，收益就变薄。

同时它也是观察企业融资环境的窗口：短融发行利率走高、发行困难，说明信用市场在收缩，企业借钱变贵变难。

## 3. 怎么看

- 看评级：超短融多是 AAA/AA+ 高评级主体，评级越高违约风险越低。
- 看期限：期限越短，流动性越好，利率风险越小。
- 看发行利率：与同期限同业存单、国债收益率对比，利差越大说明市场对该主体越谨慎。
- 投资者实操：普通人通过货币基金、短债基金间接持有即可，不必自己开户买。

## 4. 常见坑

- 坑一：把“短期信用债”当“保本”。信用债不是存款，主体违约时照样会亏。
- 坑二：只看收益不看期限。超短融收益高一点，但期限短、再投资频繁，收益未必跑赢长期债。
- 坑三：忽视流动性。极端行情下，短债基金也会出现赎回限制或净值回撤。
- 坑四：把“货基收益高”当“安全”。收益异常偏高的货基，往往配置了更多低评级资产，要留意。
