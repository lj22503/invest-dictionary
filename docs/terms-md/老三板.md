# 老三板

> 股票从交易所退市后最后待的地方，交易冷清、流动性差，是"退市股的收容所"。

## 1. 这是什么

**老三板 = 为已退市股票设立的全国性交易场所，正式名称叫"全国中小企业股份转让系统代办股份转让系统"。**公司从沪深交易所退市后，会转到老三板挂牌继续交易，代码以 400 开头；它的"大哥"新三板（现在的北交所前身）门槛和交易制度都不一样。老三板的交易规则和主板完全不同：不是连续竞价，而是每周固定几天、每天一次集合竞价撮合，很多股票一整天也成交不了几手。> 一句话：主板退市不是终点，老三板是"最后的栖息地"。

## 2. 为什么重要

很多人以为股票退市就是"归零"，其实退市股会去老三板继续挂着，股价可能只剩几毛钱、几块钱。如果你手里真有退市股，搞清楚老三板规则才知道：什么时候能卖、怎么卖、钱怎么到账。更重要的是，老三板股票风险极高：公司大多经营困难甚至破产，股价长期阴跌，流动性差到你想卖都找不到买家。对普通散户来说，它是"预警区"而不是"抄底区"。> 一句话：老三板存在的意义，是让你知道退市股最后去哪儿，而不是让你去那儿捡便宜。

## 3. 怎么用 / 怎么看

- **先分清场合**：主板/科创板退市股 → 老三板；新三板自己退市的股票，则留在新三板"基础层"不动。
- **开通权限**：在券商 APP 里开通"退市板块交易权限"（俗称老三板权限），一般免费、线上可办。
- **盯转让日**：老三板股票每周转让 1~5 次不等（按净资产和年报状况分档），每周固定日子、固定时间撮合，不是天天能交易。
- **报单技巧**：只能挂限价单，涨跌幅限制常见为 5%（部分 10%），且成交靠"价格优先、时间优先"的一次性撮合，挂单后未必成交。
- **卖出优先级**：想卖退市股，尽早挂单、价格贴近市价，别指望能"等个好价钱"。> 一句话：老三板只做两件事——让人能卖出退市股，顺便警示你还敢不敢碰高危股。

## 4. 常见坑 / 误区

- **把老三板当"另一个炒股市场"**：它不是投机场所，是"消化风险"的场所，90% 的股票长期无人问津。
- **以为退市就自动清零**：退市股仍有价值归属（净资产、重组预期），但也可能归零，别用"反正跌成这样"安慰自己。
- **漏掉确权手续**：退市整理期结束后，需要办理股份确权（多数券商自动代办，少数要手动），不然无法在老三板交易。
- **被"转板暴富"故事忽悠**：老三板确实有极少数重整成功的例子，但概率极低，多数是"乌鸡还是乌鸡"。
- **忽视交易时间差异**：用主板的习惯盯盘，会发现老三板股票经常一整天不成交——这不是"没人卖"，是"没人买"。> 一句话：看见老三板三个字，先想风险，再想规则，最后才轮到"机会"。
