# 美元指数

> 美元指数=衡量美元对一篮子主要货币整体强弱的数字，涨代表美元在变强。

## 1. 这是什么

美元指数（DXY）把美元和一篮子6种货币放在一起比强弱，其中欧元权重最大（约57.6%），之后是日元、英镑、加元、瑞典克朗、瑞士法郎。

它像一个“美元体温计”：指数涨=美元相对这些货币升值，指数跌=美元变弱。

> 一句话：美元指数涨，全世界都感觉“美元更值钱”。

## 2. 为什么重要

因为黄金、原油等大宗商品大多用美元计价：美元走强→买这些商品变贵→金价油价往往承压。

对新兴市场（含A股和港股）：美元强→资金倾向回流美国→新兴市场流动性和人民币汇率都有压力。

对你：人民币汇率、黄金ETF、海外基金的收益，都和美元指数绕不开关系。

> 一句话：美元指数是全球流动性的“总闸门”，它一动，全球资产跟着晃。

## 3. 怎么用 / 怎么看

- 第 1 步：盯美联储：市场预期加息或不降息，美元往往走强；预期转向降息，美元转弱。
- 第 2 步：看美国经济相对强弱：美国经济比欧洲、日本强，资金买美元资产，指数就上行。
- 第 3 步：看避险情绪：全球动荡时美元常被抢购（“美元微笑”），指数会跳涨。

## 4. 常见坑 / 误区

- 坑 1：美元指数跌不等于人民币一定涨——人民币还取决于中国自身基本面，有时美元弱、人民币也弱。
- 坑 2：把美元指数当成美国经济强弱计——它只是美元对一篮子货币的相对价格。
- 坑 3：看到指数涨就急着换美元——还要算上换汇成本、两国利差和你自己的实际用途。
