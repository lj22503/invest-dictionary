# 投资体系 / 交易体系

> 投资体系是"你怎么想"，交易体系是"你怎么做"——没有体系的买卖，等于闭着眼开车。

## 1. 这是什么
- **投资体系**：你对投资的一整套看法，包括买什么（资产类别）、为什么买（逻辑）、买多少（仓位）、拿多久（期限）。
- **交易体系**：把想法落成动作的规则，包括什么时候买、什么时候卖、亏多少止损、赚多少止盈。

一句话：投资体系回答"为什么赚钱"，交易体系回答"怎么执行"。

## 2. 为什么重要
没有体系的人，每天被消息牵着走：涨了追，跌了慌，卖在最低点，又买在最高点。

有体系的人，面对同样的行情会有"条件反射"：跌了按计划加仓，涨了按计划止盈，不靠情绪做决定。

- 体系的作用是把"运气"变成"可重复"。
- 没有体系 = 凭感觉 = 长期大概率亏钱。

## 3. 怎么用 / 怎么看
- 先立**投资体系**：选 1~2 类你懂的核心资产，写下买入逻辑和持有期限。
- 再立**交易体系**：定下三个数——买入条件、止损位、止盈位。
- 用**交易纪律**约束自己：计划之外的操作，一律不做。
- 每周做**复盘**：记录每笔交易为什么买、为什么卖、结果如何，找规律。
- 小步验证：先用小仓位跑通自己的体系，再逐步加大。

## 4. 常见坑 / 误区
- 把"看多"当体系：只有观点、没有规则，不算体系。
- 体系太复杂：规则多到执行不了，等于没有体系。
- 经常换体系：今天价值、明天趋势，反复横跳，最后哪个都没吃透。
- 不写下来：脑子里"有数"的体系，到执行时一定会变形。
