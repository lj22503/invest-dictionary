# 撤单 / 废单

> 撤单是你主动反悔，废单是系统直接作废——都是没成交的委托，但性质完全不同。

## 1. 这是什么

撤单：委托挂出去之后、成交之前，你主动把它取消。废单：委托根本没挂出去就被交易所或券商判定无效，比如价格超出涨跌停范围、数量不是 100 股的整数倍、账户没开对应权限、集合竞价阶段不能撤的时段撤单。

打个比方：撤单是你在餐厅点了菜还没上桌，跟服务员说"这道不要了"；废单是菜单上根本没这道菜，服务员直接告诉你点不了。

## 2. 为什么重要

撤单本身不收手续费，但它占着你的一笔资金或持仓额度。行情启动时，你撤单换股的速度，直接决定这笔钱能不能赶上下一波。废单的危害更隐蔽：你以为单子已经挂出去了，结果它根本没进入撮合队列，等行情走了你才发现自己压根没上车。

打板、抢反弹这类场景里，一秒的延迟就是几万块的价差。搞不清两种单子，等于连"我的委托到底有没有效"都不确定。

## 3. 怎么用 / 怎么看

- 委托挂出后长时间不成交、而价格已经偏离，果断撤单重挂，别让单子"挂死"。
- 撤单成功后资金和持仓额度一般即时释放，可直接重新下单。
- 下单前自查三件事：价格是否在涨跌停范围、数量是否 100 股整数倍、权限是否已开通（科创板/创业板/北交所）。
- 记住时间窗口：开盘集合竞价 9:20—9:25 不能撤单，这 5 分钟撤单会变成废单。

## 4. 常见坑 / 误区

- 以为废单会自动重试——废单就是废了，必须手动重新下单。
- 以为"撤单"能撤掉已经成交的单子——成交的瞬间撤单就晚了，撤不了。
- 市价单在快速行情里废单率高，因为市价触发瞬间价格可能已超出可接受范围。
- 连续竞价和集合竞价的撤单规则不同，临收盘乱撤单容易被算成废单。
