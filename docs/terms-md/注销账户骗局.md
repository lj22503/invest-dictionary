# 注销账户骗局

> 骗子冒充客服，说你的贷款账户不注销会影响征信，让你转账“验资”，转完就消失。

## 1. 这是什么

注销账户骗局，是冒充金融平台或征信中心客服，以“你的贷款账户未注销”“额度未清空”“影响征信”为由，诱导你转账或共享屏幕的电信诈骗。

典型剧本：接到电话或短信，对方能准确报出你的姓名、身份证号和曾用过的贷款平台，然后说你有一笔“历史贷款记录”或“学生贷账户”需要注销，否则征信受损、贷款利率上浮。接着引导你下载会议软件、开启屏幕共享，指挥你到各平台借款并转入“安全账户”做资金验证。

所谓“注销”从头到尾都是假的，你的钱只会转入骗子账户。

## 2. 为什么重要

这类骗局长期排在电信诈骗高发榜前列，单案损失常常是受害者全部积蓄，甚至包括从网贷平台临时借来的钱。

它最可怕的地方在于“身份真实”：骗子手里的个人信息是真的，让你瞬间放松警惕；再用“影响征信”制造恐惧，人在慌张下最容易服从指令。央行征信中心曾多次声明：任何机构和个人都无权通过“转账验资”的方式消除或修改征信记录。

## 3. 怎么用

- 官方平台不会用个人手机号、QQ 或社交软件联系你注销账户，更不会让你向个人账户转账。
- 凡出现“安全账户”“验资账户”“清空额度”的说法，直接判定为骗局，立刻挂断。
- 对方让你下载会议软件、开启屏幕共享时，马上停止操作——屏幕共享等于把密码和验证码都交给对方。
- 拿不准时，挂断电话后自己拨打该平台的官方客服（从官网或 App 内查找号码）核实，不要回拨来电号码。
- 已被骗：第一时间拨打 110 或反诈专线 96110，同时联系银行尝试冻结转账。

## 4. 常见坑

- 骗子能报出你的真实姓名和贷款记录，不代表他是官方——这是信息泄露后的“精准包装”。
- “不注销会影响征信、以后买不了房”是最常用话术，征信记录只有真实逾期才会受损。
- 共享屏幕一旦开启，验证码、支付密码都会被看到，钱可能在你眼前一笔笔转走。
- “先转小额测试、马上退回”也是套路，退回来的钱是为了让你转更大额。
- 不要帮“客服”去网贷平台借款再转账——你借出来的钱会变成你欠的债，而骗子已消失。
