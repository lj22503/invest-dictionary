# 国债逆回购

> 把闲钱借给金融机构、拿国债做抵押，收固定利息，安全又灵活。

## 1. 这是什么

国债逆回购：你通过券商账户把钱借给金融机构，对方拿国债质押，到期还本付息。期限从1天到182天都有，代码如GC001（沪市）、R-001（深市）。

因为有国债质押，安全性极高，几乎等同于国债。

> 一句话：像“国债版的余额宝”，收益看市场缺钱程度。

## 2. 为什么重要

逆回购利率由市场资金面决定，越是市场缺钱越飙高：

- 月末、季末、年末、长假前：利率经常飙升。

- 节前买1天期，可能享受多天利息（计息规则按实际占款天数）。

- 资金安全、灵活：1天期次日资金可用，几乎不锁流动性。

## 3. 怎么用 / 怎么看

- 第一步：有券商账户即可，不需要额外开通。

- 第二步：交易软件搜“国债逆回购”或代码，选期限和利率。

- 第三步：注意节前最后交易日早买，别拖到收盘前。

门槛：沪市10万元起，深市1000元起，散户常用深市R-001。

## 4. 常见坑 / 误区

- 坑1：节前最后一天买，假期不计息。利息按实际占款天数算，买晚一天少拿好几天利息。

- 坑2：被“高收益”宣传带节奏。平时利率可能只有1-2%，别期待过高。

- 坑3：忘了资金占用天数。到期日是节假日会顺延，钱到账时间要算清。
