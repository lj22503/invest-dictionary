# 最小变动价位

> 最小变动价位 = 期货价格每跳一次的最小单位，比如螺纹钢 1 元/吨，股指期货 0.2 点；价格只能按这个单位的整数倍变动。

## 1. 这是什么

**最小变动价位是期货市场的"价格刻度"：行情不是连续变动的，而是按最小单位一跳一跳地动。** 一个"跳"也叫一个 tick。

- **商品期货**：螺纹钢最小变动价位 1 元/吨；豆粕 1 元/吨；原油期货 0.1 元/桶；
- **股指期货**：沪深300、中证500、中证1000 股指期货最小变动价位均为 0.2 点；
- **组合起来**：一手合约每跳一个 tick 的盈亏 = 合约乘数 × 最小变动价位。股指期货一跳 = 300 × 0.2 = 60 元。

> 一句话：最小变动价位 = 行情"一格"有多小，也是"每跳一下"盈亏多少钱的钥匙。

## 2. 为什么重要

**最小变动价位决定了"最小交易成本"和"每跳盈亏"，直接影响短线交易策略：**

- **算每跳盈亏**：乘数 × 最小变动价位 = 一跳多少钱，这是做日内短线的基本单位；
- **算止盈止损**：你的止损价、止盈价必须落在"最小变动价位的整数倍"上，否则挂单永远不成交；
- **理解流动性**：最小变动价位太小，报价太密，撮合分散；太大，价差成本高，短线难做；
- **跨品种比较**：不同品种"一跳"的价值差异巨大，影响同样资金下的仓位设计。

**真实场景**：做股指期货短线，最小变动价位 0.2 点、乘数 300，一跳就是 60 元。如果止盈设 3 点（15 跳），就是 900 元；如果最小变动价位是 0.2 点，你却把止盈设在 2.1 点这种"非整数跳"位置，单子可能永远差一跳不成交——**挂单前先对齐刻度**。

## 3. 怎么用 / 怎么看

- 第一步：交易前查清楚该品种的最小变动价位（交易所公告或行情软件 F10）；
- 第二步：算"每跳盈亏" = 合约乘数 × 最小变动价位，记住这个数；
- 第三步：挂止盈止损单时，把价位对齐到最小变动价位的整数倍；
- 第四步：做短线前对比"一跳盈亏 vs 手续费"——如果一跳还不够手续费，这个品种不适合高频小波段；
- 第五步：用"跳数"思考——把止盈止损换算成"多少跳"，比单纯看点位更直观。

> 一句话：先看一格多大，再定止盈止损，不然你的单子永远差一格。

## 4. 常见坑 / 误区

- **坑 1：挂单挂在"非整数跳"**：止盈止损价不对齐刻度，行情到了也不成交；
- **坑 2：忽略一跳的绝对价值**：股指一跳 60 元，很多商品一跳 10 元，同样开 1 手，心跳速度完全不同；
- **坑 3：拿"最小变动价位"当"点值"**：两者要乘起来才算每跳盈亏，单看一个数字没用；
- **坑 4：短线高频不看交易成本**：一跳盈亏还没手续费高，做再多次也是给交易所打工；
- **坑 5：不同合约用同一刻度**：主力合约和远月合约最小变动价位相同，但价格不同，百分比波动不同，别用同一套止损幅度。
