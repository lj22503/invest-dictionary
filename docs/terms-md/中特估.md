# 中特估

> 中国特色估值体系，让央企国企的估值不再只看利润，还要看社会责任与安全稳定——低估值板块的重新定价。

## 1. 这是什么

### 给央企国企重新定价

**中特估 = 「中国特色估值体系」，2022 年底由监管层提出，核心是：央企国企的估值，不能只按利润算，还要考虑国家战略、社会责任、安全稳定这些「中国特色」的价值。**

背景是：很多央企盈利稳定、现金流充沛，市盈率却长期只有五六倍，比同类民企便宜一大截。

一句话：中特估就是让「又便宜又稳」的央企被重新看见。

## 2. 为什么重要

### 为什么重要：低估值板块的重估

央企国企占 A 股市值大头，长期低估值不仅压制指数，也让「耐心资本」「长期资金」找不到优质标的。监管推动后，市值管理被纳入央企考核，分红与回购意愿明显提升。

对投资者的意义：低 PE、高股息、稳定现金流的央企资产，恰好契合利率下行期的「资产荒」需求，成为机构增配的方向。

一句话：中特估不是口号，是「考核指挥棒」转向后的价值回归。

## 3. 怎么用 / 怎么看

### 怎么用：怎么理解与参与

**别把它当板块概念**：中特估是估值体系的重构，相关标的分散在能源、电信、银行、建筑等多个行业；**优先看高股息央企**：股息率 4% 以上、分红率稳定的央企，安全垫更厚；**关注考核与政策信号**：市值管理纳入考核、增持回购公告，是直接催化；**用指数产品参与**：央企 ETF、红利类指数基金，比单押一只央企股更稳妥。

## 4. 常见坑 / 误区

### 常见坑：概念炒作与价值陷阱

**概念炒作**：任何「XX 概念」热起来，总有人借机拉高出货，追涨最容易被套；**低估值 ≠ 一定涨**：价值陷阱里，便宜可以更便宜，基本面恶化时低估值毫无意义；**以为所有央企都受益**：只有治理改善、分红提升的央企才有重估逻辑，躺平的不算；**把政策口号当买入理由**：政策提供方向，但买卖点还是要看估值与股息率的性价比。
