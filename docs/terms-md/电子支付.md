# 电子支付

> 用手机代替钱包——扫码、刷脸、碰一碰就把钱付了。

## 1. 这是什么

电子支付就是用电子设备代替现金完成付款：扫码支付、NFC 碰一碰、刷脸支付、网银转账，都属于电子支付。

它不直接搬运钞票，而是记账：你付款时，银行/支付平台把你的账户金额减少、商户账户增加，钱在系统里完成“数字搬家”。

中国的电子支付渗透率全球领先，出门不带现金已经成为常态。

## 2. 为什么重要

电子支付改变了“钱”的形态：钱从“口袋里看得见的现金”变成账户里的数字。

它带来三个变化：

- 更快：转账到账以秒计，跨行跨地区成本极低
- 更透明：每笔消费有记录，天然适合记账复盘
- 更容易花超：没有“掏钱包”的痛感，花钱更无感

余额宝、零钱通、花呗等，都是建立在电子支付体系上的应用。

## 3. 怎么用 / 怎么看

- 绑卡分级：主卡绑定日常小额消费，大额资金放独立账户
- 关掉免密：小额免密虽方便，但手机丢失或被偷扫风险更高
- 定期查账单：每月对一遍账单，及时发现盗刷或重复扣款
- 分账户管理：零钱通/余额宝只放零花钱，工资放银行账户

## 4. 常见坑 / 误区

- 坑 1：自动续费悄悄扣钱。定期检查“自动续费/免密支付”列表
- 坑 2：付款码被“隔空盗刷”。付款码不要提前打开太久
- 坑 3：退款难、维权难。大额交易尽量走平台担保交易，别直接转账给个人
