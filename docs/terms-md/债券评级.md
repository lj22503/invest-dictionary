# 债券评级

> 评级机构给债券发行人打的信用分，决定借钱贵不贵——但评级下调往往比评级本身更值得关注。

## 1. 这是什么

### 发债人的信用成绩单

**债券评级 = 评级机构对「借钱的人还钱能力」打的分数。**国内常见评级从高到低是 AAA、AA+、AA、AA-、A、BBB……一路到 C，AAA 代表偿债能力最强。

评级由中诚信、联合资信、大公国际等机构出具，分「主体评级」（评估公司本身）和「债项评级」（评估这只债）。

一句话：评级是债券的「信用成绩单」，分数决定市场信不信你。

## 2. 为什么重要

### 为什么重要：评级决定借钱成本

评级直接影响利率：AAA 的央企发债，利率可能只有 2% 出头；AA 的民企发债，可能要到 5% 甚至更高——中间的差价，就是市场对违约风险的定价。

对机构投资者，评级还是「准入门槛」：很多保险、银行只允许买 AA 以上的债，评级一被下调，债券会被强制卖出，价格立刻跳水。

一句话：评级下降不是「变差了」这么简单，还可能引发踩踏式抛售。

## 3. 怎么用 / 怎么看

### 怎么用：怎么看评级

**看两个评级**：主体评级看公司，债项评级看这笔债有没有担保、抵押等增信；**看评级展望**：展望「稳定」还好，「负面」就是黄灯，要开始警惕；**关注下调而非上调**：评级上调往往滞后于利好，下调却是风险的强信号；**买债前查评级**：普通投资者买信用债或债基前，先看持仓券种的评级分布。

## 4. 常见坑 / 误区

### 常见坑：评级不是金标准

**评级有滞后性**：等评级机构下调时，市场可能早已用脚投票；**评级可能「注水」**：发行人付费模式下，评级虚高问题长期存在，AAA 里也出过违约；**以为 AAA 等于保本**：评级衡量的是概率，不是承诺，永煤、华晨等 AAA 违约历历在目；**忽略评级和利率的关系**：买高收益债就是在赌「评级错杀」，没有研究能力别碰。
