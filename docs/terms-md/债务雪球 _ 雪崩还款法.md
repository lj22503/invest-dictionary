# 债务雪球 / 雪崩还款法

> 两种还清多笔债务的顺序策略，选对能省利息、更快上岸

## 1. 这是什么

欠了多笔钱（信用卡、网贷、车贷、房贷）不知道怎么还时，有两种主流策略：

- **债务雪球法**：先还**金额最小**的债，其他只还最低额；还完一笔，把省下的钱滚入下一笔。靠"不断清账"获得心理成就感。
- **债务雪崩法**：先还**利率最高**的债，其他只还最低额；还完再攻下一笔。从数学上最省总利息。

## 2. 为什么重要

- 多笔债务同时还款，没有策略的人**东一笔西一笔、利息越滚越多**。
- 雪球法见效快、容易坚持；雪崩法更省钱但前期"看不到清账"容易泄气。
- 选对顺序，**总利息可能差几千上万块**，上岸时间也能提前一年以上。

## 3. 怎么用 / 怎么看

**操作步骤：**

1. **列清单**：把每笔债务的欠款金额、利率、最低还款额全部写下来。
2. **选策略**：自制力强、追求省利息 → 雪崩法；需要正反馈、容易放弃 → 雪球法。
3. **定总额**：算出每月能额外挤出的还款金额（比如工资到手先扣 2000 元还债）。
4. **全力攻一个**：目标以外的债只还最低额，所有额外资金砸向当前目标。
5. **滚雪球**：还清一笔后，把它的最低还款额加到下一个目标上，越滚越快。

## 4. 常见坑 / 误区

**坑 1：只还最低还款** — 信用卡最低还款的剩余部分继续按日计息，年化可能 15%+，永远还不完。

**坑 2：以贷养贷** — 借新还旧，利息层层叠加，最后债务翻几倍。

**坑 3：雪球法被高息拖垮** — 如果有一笔 24% 的网贷，还是建议优先处理高息，别光顾心理爽。

**坑 4：还款顺序换来换去** — 策略定了就执行，反复切换等于没有策略。
