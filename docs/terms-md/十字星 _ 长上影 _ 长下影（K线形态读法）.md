# 十字星 / 长上影 / 长下影（K线形态读法）

> K 线图上的“小蜡烛”：十字星是纠结，长上影是冲高回落，长下影是探底回升。

## 1. 这是什么

十字星：开盘价约等于收盘价，K 线变成一个小“十”字，说明多空双方打了一天打成平手，市场在纠结方向。

长上影：盘中价格冲得很高，但收盘被砸回低位，说明上方抛压沉重——“涨上去就被卖下来”。长下影正好相反：盘中砸得很深，但收盘拉回高位，说明下方有资金承接——“跌下去就被买上来”。

> 一句话：十字星是“多空僵持”，长上影是“上方有压力”，长下影是“下方有支撑”。

## 2. 为什么重要

K 线形态是市场情绪留下的痕迹：长上影说明高位有人急于出货，长下影说明低位有人敢于接盘。把这些“痕迹”和价格位置结合，能读出多空力量对比。

同样一根长下影，出现在高位和出现在低位，含义完全不同——高位长下影可能是“诱多”（拉起来让人接盘），低位长下影才是“探底回升”。位置比形态本身更重要。

- 看位置：高位长上影 / 十字星 = 警惕见顶；低位长下影 / 十字星 = 关注企稳
- 看影线长度：影线占 K 线实体（整体振幅）一半以上才算“长影线”
- 看量能配合：长下影 + 放量 = 承接有力；长上影 + 放量 = 抛压真实

## 3. 怎么用 / 怎么看

- 第一步：先定位置（高位 / 低位 / 中途），再谈形态含义
- 第二步：看实体与影线比例，判断多空力量差距
- 第三步：等次日确认——单根 K 线只是“提案”，次日的 K 线才是“表决”

## 4. 常见坑 / 误区

- 坑 1：单根十字星就判断反转——形态必须结合位置、量能、趋势综合看
- 坑 2：盘中看影线——影线随交易进行随时变化，收盘定型才算数
- 坑 3：把下跌趋势中的“长下影”当反转——可能是诱多，次日继续阴跌
- 坑 4：忽视复权——除权除息会制造假影线，看历史形态要先复权
