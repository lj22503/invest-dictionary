# 年化 vs 累计

> 累计收益率是你总共赚了多少，年化收益率是折算成“每年平均赚多少”。比较不同期限的投资，必须用年化。

## 1. 这是什么（总赚多少 vs 每年赚多少）

投资 3 年，累计赚 30%，年化收益率约 9.1%（(1+30%) 开 3 次方再减 1）。
两个概念的区别：
累计收益率：这一段时间你总共赚了百分之多少——是“结果”；年化收益率：折算成“平均每年赚多少”——是“速度”。
打个比方：累计是总路程，年化是平均时速。
一句话：累计看赚了多少，年化看赚得多快。

## 2. 为什么重要（为什么重要：不同期限必须用年化）

比较不同期限的投资，必须用年化：
A 产品 3 年累计赚 30%；B 产品 1 年赚 10%；看累计，A 赢；看年化，B 赢（10% > 9.1%）。
年化还帮你识别“虚高收益”：短期翻倍不代表长期翻倍——巴菲特的年化约 20%，看起来不起眼，但 50 年复利滚成了天文数字。
基金宣传单上的“近 1 月涨 20%”，折算成年化高达 890%，但没人会按这个数承诺。
一句话：不换成年化，数字就是“鸡同鸭讲”。

## 3. 怎么用 / 怎么看（怎么用：一条公式换算）

换算公式：年化 = (1 + 累计收益率) 的 (1 ÷ 年数) 次方 − 1；统一口径：比较基金、理财、房产、黄金时，全部折算成年化再比；看宣传先问“年化”：别被“累计翻倍”“成立以来 300%”忽悠，问一句“年化多少、几年”；区分口径：“年化收益率”可能是单利（理财常用），“年化复合收益率”是复利（基金常用），后者更真实。
一句话：先折算，再比较，最后才下结论。

## 4. 常见坑 / 误区（常见坑：年化不是每年都赚这么多）

把年化当“每年都赚这么多”：它是平均值，中间可能大起大落——某年赚 40%、某年亏 10%，年化可能只有 12%；用算术平均算年化：正确做法是几何平均（复利口径），算术平均会高估收益；被短期高年化迷惑：货币基金某几天年化 5%，不代表长期如此；只看高光区间：宣传单喜欢挑“表现最好的 3 年”展示年化，要看完整周期的数据。
一句话：年化是平均值，不是保证书。
