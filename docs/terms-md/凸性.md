# 凸性

> 凸性 = 债券价格对利率变化的"弯度"。利率降，债券涨得比想象多；利率升，跌得比想象少。

## 1. 这是什么
**凸性（Convexity）= 衡量债券价格随利率变化时"弯曲程度"的指标。**久期告诉你价格大约会动多少，凸性告诉你这个估算准不准、往哪个方向偏。

利率与债券价格方向相反：利率降，价格涨。但价格涨幅不是均匀的——**利率降 1%，涨的比按久期算的更多；利率升 1%，跌的比按久期算的更少**。这条"下凸"的曲线，就是凸性的来源。

> 一句话：久期是"斜率"，凸性是"弯度"。

## 2. 为什么重要
- **涨多跌少**：正凸性意味着利率下行时资产增值超过久期估算，利率上行时损失小于估算——对债券持有人天然有利；
- **期限越长凸性越大**：长期国债的凸性明显大于短债，所以利率波动大时，长久期债券的"弹性"更夸张；
- **机构用它做风险管理**：银行、保险用凸性修正久期对冲的误差，普通投资者知道"久期估算会有偏差"就够了。

## 3. 怎么用 / 怎么看
- **先找久期 D**：利率变动 Δy，价格近似变动 ≈ -D × Δy；
- **再加凸性修正**：更准的公式 ≈ -D×Δy + ½×C×(Δy)²，凸性项恒为正，所以它总是"拉高"估算值；
- **实操口诀**：降息周期里，同期限选凸性大的品种更占便宜；加息周期里，凸性小（或负凸性）的品种相对抗跌。

## 4. 常见坑 / 误区
- **以为凸性永远是免费午餐**：可赎回债券（如含权债）在利率下行时可能被提前赎回，出现"负凸性"，涨不上去反而可能下跌；
- **把凸性当收益率**：凸性描述的是价格弹性，不是你能拿到的利息，别指望它直接产生回报；
- **忽略久期才是主变量**：多数时候价格变动主要由久期决定，凸性只是修正项，方向别搞反。
