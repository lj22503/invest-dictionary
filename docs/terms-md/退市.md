# 退市

> 股票被交易所摘牌、不能再在二级市场买卖，就是退市。退市不等于公司倒闭，但你的股票会变得很难卖出。

## 1. 这是什么（股票被交易所“开除”了）

退市 = 股票被交易所摘牌，不能再在二级市场买卖。公司还在，但你的股票从“能随时买卖的证券”变成了“几乎卖不掉的凭证”。
A股各板块都有自己的退市标准，主要分三类：
交易类：股价连续 20 个交易日低于 1 元（面值退市）；财务类：连续亏损 + 营收不达标、净资产为负等；重大违法类：欺诈发行、重大信息披露违法等。
一句话：退市是交易所对股票说“你不配在这里交易了”。

## 2. 为什么重要（为什么重要：退市制度越来越严）

2020 年注册制改革后，A股退市制度明显收紧，“面值退市”从罕见变成常见。每年几十家公司退市，不再是“只进不出”。
对普通投资者，退市最坏的结果是：股票转到三板市场，流动性极差，想卖卖不掉价格暴跌；如果公司随后破产清算，普通股东排在最后，很可能血本无归。
所以“只买不退市股票”不能靠运气，得学会识别退市风险。
一句话：退市制度越严，踩中“退市雷”的代价越大。

## 3. 怎么用 / 怎么看（怎么用：提前识别退市风险）

盯股价：股价接近 1 元就要警惕，跌破 1 元连续 20 个交易日直接面值退市；看财报：连续亏损 + 营收不达标（主板 3 亿、创业板/科创板 1 亿）是财务退市红线；看警示：被 ST / *ST 说明风险已经公开，别当“乌鸡变凤凰”的故事；看审计：年报被出具“非标”审计意见（无法表示意见/否定意见）是重大危险信号；看立案：证监会立案调查的公司，随时可能触发重大违法退市。
一句话：手里有这类票，反弹就是卖出的机会，别赌“重整翻盘”。

## 4. 常见坑 / 误区（常见坑：退市不等于公司倒闭）

以为退市=公司倒闭：公司可能还在经营，但股票流动性没了，等于“套死在纸面上”；赌“重新上市”：A股退市后重新上市的案例极少，概率比中彩票还低；忽略退市整理期：退市前有 30 天整理期还能交易，很多人犹豫错过唯一卖出窗口；被“摘帽行情”忽悠：ST 摘帽不代表安全，财务类退市风险照样存在；抄底“1 元股”：你以为跌到 1 元便宜，其实离面值退市只差一步。
一句话：退市股的“便宜”往往是陷阱，不是机会。
