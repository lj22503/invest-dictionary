# 站岗

> 买在高位后被套住，像哨兵一样站在山顶下不来——散户追高的经典处境。

## 1. 这是什么

站岗，就是**追高买入后股价掉头下跌，人被牢牢套住**——像哨兵站在山顶，走也不是、不走也不是。

典型场景：某只股票/基金连续大涨，你看别人赚钱眼红，冲进去想“吃口肉”，结果买在阶段性高点。随后回调，账户变绿，你只能在山上继续站岗。

站岗不只发生在个股：热门赛道、指数基金、甚至楼市高位接盘，本质都是同一件事——**在情绪最热的时候进场**。


## 2. 为什么重要

站岗的代价，不只是“亏钱”，更是“回本难”：买入 100 元，跌 30% 到 70 元，要涨回 100 元需要 **+43%**；跌 50% 则要涨 **+100%** 才能回本。跌得越深，回本越难。

从市场结构看，站岗者往往是行情末端的接盘主力——情绪最热时冲进来的人，买走了赚钱者想卖的筹码。

对普通人的意义很直接：**识别“站岗位置”，不要在情绪最热时进场**，比任何选股技巧都重要。


## 3. 怎么用 / 怎么看

- 先看估值分位：热门指数/板块市盈率分位超过 80% 时，追高要格外谨慎
- 分批建仓：即使看错方向，分批买入也能留出纠错余地
- 设好止损：买入前就想清楚“跌多少我认输离场”，而不是跌了再说
- 用一检验：问自己“如果明天跌 10%，我敢不敢加仓？”——不敢，说明你只是被情绪推着买


## 4. 常见坑 / 误区

- 坑 1：死扛不动——除非基本面没问题、仓位完全可承受，否则“扛”只是把浮亏拖成深亏
- 坑 2：急着补仓摊薄成本——无计划的补仓等于给错误加码，越补越重
- 坑 3：把横盘当企稳——横盘也可能是下跌中继，企稳要等量能和新低消失确认
- 坑 4：把“别人赚钱”当买入理由——你看到的是收益，没看到的是人家早就在车上
