# 数字货币

> 只活在网络里的钱，分三类：央行发行的、民间加密的、锚定法币的，性质完全不同。

## 1. 这是什么

央行数字货币（CBDC）：如数字人民币，是法定货币的数字化，1 元=1 元，国家信用背书。
加密货币：如比特币、以太坊，去中心化、无背书，价格剧烈波动。
稳定币：如 USDT，声称锚定 1 美元，但靠发行方信用，历史上多次脱锚暴跌。

## 2. 为什么重要

数字人民币改变支付形态：更便捷、可离线、可追溯，正逐渐进入日常场景。
加密货币改变“资产”想象：全球 24 小时交易、高波动，也常被用于投机与骗局。
对普通人最关键的：先分清“法定”与“非法定”，别把两者的风险混为一谈。

## 3. 怎么用 / 怎么看

- **数字人民币**：当“电子现金”用，安全、有国家信用，日常支付没问题
- **加密货币**：只用“归零也不心疼”的闲钱，且务必走正规交易所
- **判断资产**：问一句“它的价值由什么支撑？”——国家信用、算法共识，还是别人的承诺

## 4. 常见坑 / 误区

坑 1：以为比特币=法定货币。央行不认，商家可拒收，法律地位和人民币完全不同。
坑 2：被“央行发行 XX 币”骗局忽悠。真正的数字人民币官方 APP 只有一款，认准渠道。
坑 3：迷信稳定币“永远 1 美元”。脱锚事件多次发生，稳定是相对的。
