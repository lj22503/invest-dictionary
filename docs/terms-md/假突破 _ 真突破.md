# 假突破 / 真突破

> 冲过关键位后是真涨还是骗人进场——量能、回踩、站稳三招分辨真假突破。

## 1. 这是什么

**真突破**：价格放量突破压力位/颈线后，站稳并继续上行，突破有效——追进去有肉吃。

**假突破**：价格短暂冲过关键位，随后快速回落，把追高的人套在山腰——突破是骗人的。

核心区别不在“突破那一瞬”，而在**突破之后的确认行为**：量能是否跟上、回踩是否守住、能否站稳几天。这三个确认动作，把真假突破分开。


## 2. 为什么重要

假突破专门利用人性中“突破=趋势开启”的直觉：突破当天放量拉升，散户追进去，次日就跌回来——**你买的不是趋势，是别人的出货位**。

对普通人来说，识别真假突破能避开最伤人的两类操作：**假突破追高被套**、**真突破不敢上车**（以为又是假的）。

技术分析里，“突破买入”是胜率最高的策略之一，前提是你买的是**真突破**。


## 3. 怎么用 / 怎么看

- 招 1：看量能——真突破放量（明显高于近 5 日均量），假突破常常缩量冲高
- 招 2：看回踩——真突破后回踩不破突破位（支撑变压力互转），假突破直接跌回去
- 招 3：看时间——站稳 2-3 天再行动，别在突破当天冲动
- 纪律：突破当天不追，等回踩确认；或小仓试探、确认后再加仓


## 4. 常见坑 / 误区

- 坑 1：突破当天重仓——最容易被假突破打脸，确认前仓位要轻
- 坑 2：把消息刺激的跳空当突破——跳空只是情绪，要看后续量能是否持续
- 坑 3：跌破后不止损——假突破确认后要果断离场，最怕“再等等”
- 坑 4：在无量突破上寄托大行情——量是突破的燃料，没量难走远
