# 模拟盘

> 用虚拟的钱、真实的行情练手——模拟盘是上真钱之前检验策略与心态的"驾校"。

## 1. 这是什么

**模拟盘，就是用虚拟资金、真实行情做的练习账户**——价格、成交、涨跌都和实盘一样，只是钱是假的。

它是投资里最接近"驾校练车"的东西：在零成本的环境里，把开仓、止盈止损、资金管理整套流程跑熟，再去真路上开车。


## 2. 为什么重要

新手最常见的悲剧：拿真钱交学费，一年亏掉 20%-50%，学到的东西还不系统。**模拟盘把学费降为零**，同样的错误先在假钱上犯完。

模拟盘还能用来**验证策略**：一个策略在模拟盘跑三个月都赚不到钱，就别指望实盘能赚钱——它帮你过滤掉大量"感觉能行"的伪策略。


## 3. 怎么用 / 怎么看

- 姿势 1：当实盘练——同样金额、同样纪律、同样写盘后总结，别因为假钱就乱来
- 姿势 2：专练一招——三个月只练一种策略（如网格/定投/突破），直到流程完整跑通
- 姿势 3：记录胜率——统计策略在不同市场下的表现，找出它赚钱和亏钱的边界


## 4. 常见坑 / 误区

- 坑 1：模拟盘全仓追涨杀跌——假钱练不出真心态，实盘照样手抖
- 坑 2：用模拟盘"炫耀收益"——收益是假的，练到的纪律才是真的
- 坑 3：练了不总结——不总结的模拟盘，只是玩了个游戏
- 坑 4：模拟盘一直不毕业——模拟盘稳定盈利且心态平稳，就该小仓实盘，别永远纸上谈兵
