# 全天候策略

> 桥水达利欧的"风险平价"组合：股票、长债、黄金、商品各配一份，让组合在经济的任何天气里都能活。

## 1. 这是什么

经济可以按两个维度分成四象限：增长 + 通胀。增长好 + 通胀低（春天）：股票最受益；增长差 + 通胀低（夏天）：债券最受益；增长差 + 通胀高（秋天）：黄金和商品最受益；增长好 + 通胀高（冬天）：现金和商品更抗打。

既然没法预测下一个季节，干脆每个象限都配一点——这就是全天候：股票 30% 左右、长期国债 50% 左右、黄金和商品 15% 左右（不同版本比例有差异），关键不是比例精确，而是"哪个季节都有赢家资产"。

## 2. 为什么重要

单一资产有"季节"：股票牛市人人赚钱，熊市人人挨打；债券也一样。全天候追求的是"无论什么天气都不饿死"：每年收益不一定最高，但波动小、回撤可控，拿得住、睡得着。

它背后的"风险平价"思想很值钱：按风险贡献配比，而不是按金额配比——波动大的资产少配，波动小的多配，让每份风险都得到同等对待。

## 3. 怎么用 / 怎么看

- 普通人的简化版：股 + 债 + 黄金 + 商品（或用商品基金替代）做一个大比例配置。
- 定期再平衡：每年或每半年把配比拉回目标线，天然实现"高抛低吸"。
- 适合做底仓：养老账户、长期储蓄、4% 法则的退休组合里当"压舱石"。
- 比例按风险预算理解：不是"55% 的钱买债"，而是"债券贡献的风险和股票相当"。

## 4. 常见坑 / 误区

- 以为全天候 = 稳赚：股债双杀（比如 2022 年）、通胀失控时它照样跌，只是跌得少。
- 机械照搬桥水参数：人家的版本用杠杆、用全球资产，普通人照抄比例未必合适。
- 忽略再平衡纪律：涨得多的资产不卖、跌得多的不补，全天候就慢慢变成了"单季候"。
- 把它当短线择时工具：全天候是"配置逻辑"不是"交易信号"，天天调仓反而破坏它。
