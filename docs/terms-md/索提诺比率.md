# 索提诺比率（Sortino Ratio）

> 只看“亏钱的风险”，衡量每承担 1 份下行风险换多少超额收益。

## 1. 这是什么

索提诺比率（Sortino Ratio）是夏普比率的“改良版”：夏普比率把上涨波动和下跌波动一视同仁，索提诺比率只惩罚“下行波动”——也就是亏损那部分的波动。

公式上，分子和夏普一样（收益 − 无风险利率），分母换成“下行标准差”：只统计低于目标收益率的那些时段。

打个比方：一个基金平时涨得猛、跌得也猛，另一个基金稳稳向上、很少大跌。两者夏普比率可能差不多，但索提诺比率会把后者显得更优秀，因为它不把“涨得好的波动”当风险。

## 2. 为什么重要

它对两类人特别有用：一是稳健型投资者——你不介意少赚，但很介意大亏，索提诺比率告诉你“每承担 1 份亏损风险，能换多少收益”；二是评价策略的从业者——私募、CTA、量化策略常用它来筛选“回撤小、收益稳”的管理人。

和夏普比率一起看：如果某基金夏普一般、索提诺很高，说明它波动主要来自上涨端，属于“涨多跌少”的友好型波动；反过来，夏普不错但索提诺低，说明下跌波动也大，风险没你想象的小。

## 3. 怎么看

- 结合回撤看：索提诺比率高，通常对应最大回撤可控，两者互为印证。
- 同策略横向比：股票基金和债券基金的风险结构不同，别跨类别比绝对值。
- 看样本期：至少看 3 年以上数据，跨越一轮牛熊才有意义。
- 参考阈值：一般大于 1 算不错，大于 2 算优秀，但需结合市场环境判断。

## 4. 常见坑

- 坑一：样本期太短。一年半载的高比率很可能是运气。
- 坑二：目标收益率取值影响结果。目标定 0 还是定 5%，下行标准差的算法就不同，数字不可直接比。
- 坑三：忽略“肥尾”。下行标准差只能衡量波动幅度，极端暴跌可能被平滑掉，仍要配合最大回撤与压力测试看。
- 坑四：以为高比率=未来稳。历史表现不能简单外推，策略失效、市场风格切换都可能让比率大幅回落。
