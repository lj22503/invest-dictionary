# 并购重组

> 公司之间买来卖去、把资产重新装进另一个账本——并购重组是股价最爱讲故事的地方。

## 1. 这是什么

**并购重组 = 一家公司通过买股权、买资产或换股合并，把另一家公司的业务装进自己体内，或者自己被装进别人体内。**「并购」是买，目标是拿到控制权；「重组」是把资产、负债、业务重新排一遍座位。

常见路径有三条：从二级市场或大股东手里买股权取得控制权；发行股份购买资产，也就是用股票当钱去买资产；吸收合并，两家变一家，一家的股票按约定比例换成另一家的股票。

方案落地后，你通常会在公告里看到三件事：主营业务变了、股东名单变了、业绩承诺跟着来了。

> 一句话：并购买的是资产，重组换的是账本。

## 2. 为什么重要

股价反应快。重组预案公告前后，股价常出现连续异动，也常在方案生变、监管问询后快速回落。

基本面可能真的变好：优质资产注入能改变盈利能力和行业地位。反过来，高溢价收购会留下商誉地雷，未来减值时直接吃掉利润。

摊薄风险不能忽略：发行股份购买资产会稀释老股东手里的权益，每股收益可能不升反降。

流程长且不确定：预案、董事会与股东大会、交易所审核问询、注册，每一个环节都可能终止。关联交易与利益输送，始终是监管盯得最紧的地方。

> 一句话：并购讲的是预期，落地那一刻才是真正算账的时候。

## 3. 怎么用 / 怎么看

普通人不需要研究方案细节，按下面顺序看，就能判断这是机会还是陷阱。

- 看买的是什么：标的资产是否赚钱、处于什么行业景气度，作价与同类交易比贵不贵。

- 看怎么买：现金收购花的是公司自己的钱，可能抬高负债；发股收购不用现金，但会摊薄股本。

- 看业绩承诺：承诺数字越高、对赌期越长，未来商誉减值的风险通常越大。

- 看流程进度：预案、受理、问询、上会、注册，节点越靠后，确定性越高。

- 看谁在买：产业资本做整合，通常比单纯的题材炒作更值得跟踪。

> 一句话：先看资产质量，再看价格，最后看流程能不能走完。

## 4. 常见坑 / 误区

- 听消息追停牌股：停牌期间无法交易，复牌后一步到位，追高就是在赌运气。

- 把「重组」等同于「必涨」：方案失败、标的太贵、市场环境转变，都能让利好变利空。

- 忽视商誉：高溢价收购形成的商誉一旦减值，利润表会很难看。

- 忘记稀释：发股收购之后，你手里那点股份对应的权益可能变少了。

- 忽略承诺到期：业绩承诺期结束，是业绩变脸与减值的高发时点。

- 混淆并购与借壳：借壳涉及控制权变更与重组上市认定，审核标准更严。
