# 家族信托（Family Trust）

> 把资产交给信托公司代管、按你的规则定向分配，隔离风险、防挥霍。

## 1. 这是什么

家族信托，是把一笔资产（现金、房产、股权等）委托给信托公司，由信托公司按你设定的规则管理并向指定受益人分配。核心特点有三个：信托财产独立、受益人明确、分配规则可定制。

打个比方：你不是直接把钱给子女，而是“存”进一个只听你话的保险箱，由你定规则——孩子 25 岁后才能领、每月最多领 3 万、考名校奖励 100 万。

国内家族信托通常门槛不低，一般 1000 万元起步，也有“保险金信托”用大额保单降低门槛到百万级别。

## 2. 为什么重要

它的价值不在“多赚钱”，而在“锁住钱、隔断风险”：
- 债务隔离：信托财产独立于委托人的债务，企业破产清算时通常不会被拿去抵债。
- 婚姻隔离：婚前设立的信托，离婚时不属于夫妻共同财产。
- 防挥霍：防止子女一夜败光家产，用条款约束领取节奏。
- 传承安排：避免遗产纠纷，也能为将来可能的遗产税做准备（国内目前暂无遗产税，但高净值人群会提前布局）。

一句话：它是“富人的遗嘱 + 保险箱 + 财务管家”，普通家庭了解它，主要是为了识别理财销售话术、以及为财富规划做认知储备。

## 3. 怎么看

- 先看门槛与成本：设立费、管理费、律师费都要算清，金额太小不划算。
- 看受托人资质：优先选持牌信托公司，查监管评级和历史兑付记录。
- 设计条款要留余地：预留变更条款，别把规则锁死到无法应对家庭变化。
- 对比保险金信托：资金门槛低、流程简单，适合 100 万量级家庭的传承需求。

## 4. 常见坑

- 坑一：把“理财信托”当“家族信托”。理财信托是投资产品，可能暴雷；家族信托是法律架构，重在隔离与传承。
- 坑二：以为信托财产绝对安全。恶意逃废债、以信托名义转移资产的，法院可以击穿。
- 坑三：条款设计过死。受益人婚姻变故、子女出国等场景没预留，日后很难改。
- 坑四：忽视资金来源合法性。资金是违法所得，信托照样不保。
