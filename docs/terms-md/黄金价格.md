# 黄金价格

> 黄金价格=买一盎司黄金要花多少钱，国际金价是全球黄金市场的定价基准。

## 1. 这是什么

国际金价通常指伦敦金或纽约金，单位是“美元/盎司”（1盎司约31.1克）；国内金价一般是“元/克”。

金价主要由三股力量决定：实际利率（扣除通胀后的利率）、避险情绪、各国央行购金需求。实际利率越低，持有不生息的黄金机会成本越小，金价越容易涨。

> 一句话：金价是“钱不值钱”和“世界不安分”时的报警器。

## 2. 为什么重要

和你直接相关：金店首饰价、银行积存金、黄金ETF、纸黄金，全都跟着国际金价走。

历史上金价与实际利率大多反向：美联储大幅降息或通胀高企时金价容易涨；地缘冲突、金融危机时避险资金会涌入黄金。

但要警惕：金饰价格含大量加工费和品牌溢价，和“投资金条”完全不是一回事。

> 一句话：金价是全球避险情绪的“晴雨表”，也是普通人资产配置里的“压舱石”选项。

## 3. 怎么用 / 怎么看

- 第 1 步：盯实际利率：10年期美债收益率减去通胀预期，往下走通常利好金价。
- 第 2 步：看美元指数：美元弱、黄金强，二者大多负相关。
- 第 3 步：看央行购金和黄金ETF持仓：持续买金往往是金价的底部支撑。
- 第 4 步：普通人参与优选黄金ETF或积存金，别为了投资买高溢价金饰。

## 4. 常见坑 / 误区

- 坑 1：把金饰当投资品——一口价金饰溢价常在20%以上，买的那一刻就亏了加工费。
- 坑 2：以为金价只涨不跌——1980年金价见顶后跌了近20年，2011年到2015年也近乎腰斩，追高同样会站岗。
- 坑 3：用短线炒金心态做长期配置——黄金波动不小，更适合做家庭资产里5%-10%的长期配置。
