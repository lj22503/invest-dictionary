# 免责条款

> 免责条款就是合同里"这些情况我不赔"的黑名单，出险前不看，理赔时才傻眼。

## 1. 这是什么
免责条款（责任免除）= 保险合同中列明"不赔"的情形清单。常见内容：酒后驾驶、违法犯罪、故意自伤、既往症、高风险运动、战争暴乱等。它是理赔争议的第一大来源。

## 2. 为什么重要
买保险最怕"以为保了，其实没保"。免责条款决定了保障的真实边界。举例：买了意外险去攀岩摔伤，如果合同免责条款列了"高风险运动"，保险公司可以一分不赔——不是保险公司耍赖，是你没看黑名单。

## 3. 怎么用 / 怎么看
- 翻开合同，找到"责任免除"章节（一般在条款中段，加粗或单独成章）
- 逐条对照自己的生活习惯：是否开车、是否极限运动、职业是否高危
- 不理解的当场问客服或经纪人，口头承诺写进合同才算数

## 4. 常见坑 / 误区
- 业务员不主动念免责条款，只讲"什么都赔"
- 只看"保什么"不看"不保什么"，出险才发现被除外
- 把免责和健康告知混为一谈：免责管"赔不赔"，健康告知管"能不能买"
- 以为免责=坑人条款，其实只要签字确认，它就是合法生效的合同内容
