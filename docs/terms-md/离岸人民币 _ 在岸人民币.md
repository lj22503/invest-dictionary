# 离岸人民币 / 在岸人民币

> 同一个人民币，在境内和境外两个市场定价，汇率可以不一样。

## 1. 这是什么

在岸人民币（CNY）在境内市场交易，受央行管理较严，价格相对稳定。

离岸人民币（CNH）主要在境外市场（香港等）自由交易，随国际资金供需波动，市场化程度更高。

正常情况下两个价格很接近，但市场情绪波动大时会出现明显价差（几十到几百个基点）。

> 一句话：CNY是"家里管着的人民币"，CNH是"在外面自由交易的人民币"。

## 2. 为什么重要

离岸价更能反映国际资金对人民币的真实看法：境外投资者买卖CNH更自由，情绪变化会直接体现。

价差扩大说明市场预期分歧大；通常离岸价先动，在岸价后跟，是观察汇率趋势的先行指标。

做外贸、海淘、境外投资、留学汇款的人，会直接感受到两个市场价格的差异。

> 一句话：离岸价是汇率的风向标，在岸价是基本盘。

## 3. 怎么用 / 怎么看

**第 1 步**：关注"人民币中间价"和银行牌价，这是普通人换汇实际用到的价格。

**第 2 步**：看CNY/CNH价差判断市场情绪：价差收窄说明预期稳定，扩大说明分歧加大。

**第 3 步**：跨境消费、汇款时对比离岸和在岸价差，金额大时差距值得注意。

> 一句话：看趋势看中间价，看情绪看离岸价。

## 4. 常见坑 / 误区

**坑 1**：以为人民币只有一个价，看到离岸价大跌就恐慌，其实在岸价可能很稳。

**坑 2**：用离岸价的短期波动去预测在岸价，过度敏感，忽略基本面。

**坑 3**：图离岸价差走地下钱庄换汇，违反外汇管制规定，资金安全也无保障。

> 一句话：两个价格是同一枚硬币的两面，别只盯一面。
