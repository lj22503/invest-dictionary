# 反转策略

> 专买跌过头、卖涨过头的标的——反转策略赌的是物极必反。

## 1. 这是什么

**反转策略，是买入近期跌过头、回避涨过头的资产，赌价格会向均值回归**——别人恐慌时你买入，别人狂热时你退出。

它和**趋势策略**正好相反：趋势策略追强者，反转策略买弱者。两者没有对错，只是赚不同的钱——反转赚的是**情绪定价错误**的钱。


## 2. 为什么重要

短期价格由情绪推动，跌得越急越狠，往往越偏离真实价值。**超跌反弹是 A 股最经典的赚钱模式之一**，但前提是判断"跌过头"而非"基本面崩了"。

反转策略能训练**逆人性**：市场恐慌时你敢于分批买入，这种心理素质本身就有长期溢价——多数人做不到，能做到的人少，所以超额收益存在。


## 3. 怎么用 / 怎么看

- 条件 1：超跌——短期跌幅足够大（如阶段回调 20%-30%），而非刚刚开始下跌
- 条件 2：基本面没坏——下跌是情绪/流动性导致的，不是业绩和逻辑崩坏
- 条件 3：有企稳信号——缩量止跌、放量反包、政策/事件催化出现，别在下跌途中硬接
- 操作：分批进场（先 1 份试探，确认企稳再加），设好止损，反弹到阻力位分批卖出


## 4. 常见坑 / 误区

- 坑 1：下跌初期就抄——"跌了很多"不等于"跌到头了"，接飞刀会被埋半山腰
- 坑 2：基本面崩坏也抄——退市、造假、行业消亡，跌再多也别碰
- 坑 3：一把梭抄底——反转要等信号+分批，一次重仓赌反转等于赌博
- 坑 4：反转成功后贪心——反弹到位不卖，又把它做成"价值投资"
