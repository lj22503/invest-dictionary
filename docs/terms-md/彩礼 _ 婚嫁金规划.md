# 彩礼 / 婚嫁金规划

> 围绕彩礼、嫁妆、婚宴、蜜月等大额支出，提前做预算与安排的"婚嫁金规划"。

## 1. 这是什么

结婚是人生最大的一次性支出之一：彩礼、嫁妆、婚宴、婚戒、蜜月，加起来动辄几万到几十万。婚嫁金规划就是**在婚前把这些钱怎么出、出多少、怎么用，提前算清楚、说清楚、安排清楚**。

它不是"算计对方"，而是让两个家庭在进入婚姻前，就把最大的财务项目摆在桌面上谈好。

## 2. 为什么重要

彩礼在不少地区金额不低（几万到几十万都有），而且绕不开两个问题：

- **钱怎么出**：男方出彩礼、女方出嫁妆，还是两边一起凑；
- **钱算谁的**：彩礼是给女方的"赠予"，还是小两口的"共同生活启动金"。

不提前规划，最常见的后果是：为了面子超预算借钱办婚礼，婚后背着债开始新生活；或者彩礼现金交接不留凭证，日后争执说不清。**结婚本应是资产的合并，不是负债的开局**。

## 3. 怎么用

- 第一步：先定总预算，拆成彩礼、婚宴、婚戒、蜜月、备用金几块，量力而行；
- 第二步：彩礼尽量走银行转账并留好记录，明确它是"赠予"还是"共同生活启动金"（涉及婚前财产界定，可参考相关词条）；
- 第三步：双方家庭开诚布公谈一次，把金额、形式、用途都说清楚，别让中间人传话传变味；
- 第四步：婚后把余钱放进"新婚启动金"账户，一起规划房贷、生育、日常开销。

## 4. 常见坑 / 误区

- **为面子超预算**：借钱办婚礼、彩礼硬撑到极限，婚后几年都缓不过来；
- **现金交接不留凭证**：几十万现金给出去，日后离婚或争议时说不清归属；
- **只算婚礼不算婚后**：预算里只有酒席和彩礼，没有房贷、生育、生活备用金，婚后第一年就财务紧张；
- **把彩礼标签化成"卖女儿"**：不谈钱反而埋雷，大大方方聊清楚才是对两个家庭的尊重。
