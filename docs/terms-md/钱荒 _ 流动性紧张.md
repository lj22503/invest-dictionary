# 钱荒 / 流动性紧张

> 市场上短期缺钱、借钱变贵变难，是资金面紧张的信号。

## 1. 这是什么

钱荒指金融机构之间短期资金供不应求，同业拆借利率快速飙升的现象。

典型标志：DR007、Shibor等短期利率冲高，银行间市场"借钱难、借钱贵"。

最著名的是2013年6月的钱荒，银行间7天回购利率一度飙到10%以上；平时月末、季末、年末也常有"小钱荒"。

> 一句话：钱荒就是市场上的"短期流动资金"突然不够用了。

## 2. 为什么重要

钱荒时市场利率上行，债券价格下跌，股市因资金面收紧而承压。

对普通人也有直接影响：货币基金和国债逆回购的收益会明显升高，房贷利率的定价基准（LPR）也可能受资金面影响。

央行应对钱荒的常规操作是逆回购、MLF、降准等，向市场投放流动性，所以多数钱荒是短期现象。

> 一句话：钱荒时"钱"本身变贵，持币者的收益反而变好。

## 3. 怎么用 / 怎么看

**第 1 步**：盯DR007和Shibor，这两个是资金面最直观的温度计，连续上行说明资金偏紧。

**第 2 步**：关注央行公开市场操作（逆回购规模、MLF续作），净投放是放松信号。

**第 3 步**：月末、季末、年末是传统资金紧张窗口，可提前安排资金。

**第 4 步**：资金紧张期，国债逆回购、货币基金收益往往阶段性走高，可顺势操作。

> 一句话：看懂资金面，就能理解很多短期利率波动。

## 4. 常见坑 / 误区

**坑 1**：看到"钱荒"就恐慌，其实多数是央行可控的短期波动，不等于系统性危机。

**坑 2**：资金紧张时被高收益理财吸引，忽略产品本身的信用风险，高收益往往对应高风险。

**坑 3**：拿长期资金去博短期利率高点，资金错配，收益没多多少，流动性先被锁死。

> 一句话：钱荒是短期插曲，别为它做长期决定。
