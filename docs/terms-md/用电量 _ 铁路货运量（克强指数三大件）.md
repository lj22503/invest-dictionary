# 用电量 / 铁路货运量（克强指数三大件）

> 一个地方经济有没有真在动，先看电用得多了没、货拉得多了没。

## 1. 这是什么

全社会用电量和铁路货运量，是经济活动最实在的“实物量”指标。工业要开工就得用电，商品要流转就得走铁路——它们不像 GDP 那样靠统计核算，而是实实在在“干出来”的。

这两项与中长期贷款发放量合在一起，就是“克强指数”——以时任总理李克强的名字命名，被视为比官方 GDP 更“接地气”的经济观察指标。

> 一句话：用电量看生产有没有开工，铁路货运量看商品有没有流动，两者都是经济的“心电图”。

## 2. 为什么重要

GDP 一个季度才公布一次，还经常被修正；而用电量和铁路货运量月度就有数据，领先或同步反映实体经济。工业用电占全社会用电量约三分之二，工业景气度一波动，用电量立刻有反应。

历史上，克强指数与工业增加值、PMI 走势高度相关。当官方数据还没出来时，分析师就靠它提前判断经济冷热。

- 看同比增速：用电量 / 货运量同比加速 = 经济在回暖
- 对照工业增加值：两者背离时以实物量为准（比如“统计好但电没多用”可能注水）
- 看结构：第三产业用电占比持续提升，说明经济在向服务业转型
- 看环比季调：月度环比更能捕捉拐点

## 3. 怎么用 / 怎么看

- 1-2 月合并看：春节错位导致单月数据失真，统计部门通常合并公布
- 看“工业用电量”而非总量：天气冷暖影响居民用电，会污染信号
- 货运量看“货物发送量”和“周转量”：周转量（吨 × 公里）更能反映物流活跃度
- 配合价格看：用电量升 + PPI 升 = 量价齐升，景气度高

## 4. 常见坑 / 误区

- 坑 1：拿单月数据下结论——春节错位、极寒极热天气都会扭曲单月读数
- 坑 2：忽视异常月份——2020 年初疫情、拉闸限电等时期数据不可比
- 坑 3：把全社会用电量当工业景气单指标——居民和第三产业用电会“稀释”工业信号
- 坑 4：以为货运量与股市直接挂钩——它是宏观背景板，不是个股买卖信号
