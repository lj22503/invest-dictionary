# 回测

> 把策略扔进历史行情里跑一遍，看它过去会不会赚钱——是模拟考试，不是实盘保证。

## 1. 这是什么

回测 = 用历史数据验证你的投资策略。规则写清楚（什么时候买、什么时候卖、仓位多少、止损多少），让电脑从十年前开始一笔笔模拟执行，最后算出收益、回撤、胜率。

它像驾校的模拟器：在虚拟环境里练车，练得好不代表上路一定安全，但总比闭眼上路强。核心价值是暴露策略漏洞，而不是证明策略能赚钱。

## 2. 为什么重要

量化策略的起点就是回测：没有回测的策略等于"我觉得能赚"。它能逼你面对三个残酷问题——扣除手续费滑点后还赚吗？换个时间段还赚吗？换个参数还赚吗？

但回测最大的价值是"证伪"：绝大多数策略在回测里就已经不行了，省下真金白银。剩下的少数还要小心：回测好看，往往是因为踩了某些隐蔽的坑。

## 3. 怎么用 / 怎么看

- 扣成本：手续费 + 滑点必须计入，很多策略的利润全靠忽略成本撑起来。
- 样本外验证：用前 80% 数据定参数，后 20% 数据验证，别用同一段数据又练又考。
- 参数稳健性测试：把参数上下调 20%，结果还稳定才算有效；换个参数就崩 = 过拟合。
- 和基准比：策略年化 12% 不稀奇，同期沪深 300 年化 15% 那就是跑输。
- 看最大回撤：赚 50% 然后回撤 40%，体验和结果都不如稳稳赚 10%。

## 4. 常见坑 / 误区

- 过拟合：参数调到"历史完美"，一到实盘就变形。
- 前视偏差（未来函数）：用到了当时根本拿不到的数据，比如用"当天收盘价"决定"当天买入"。
- 幸存者偏差：只测现在还活着的股票，退市的、暴雷的都被历史淘汰了。
- 忽略交易成本：高频策略在真实市场里会被手续费和滑点吃掉大半利润。
- 把回测年化当实盘年化：历史收益 ≠ 未来收益，回测里 30%，实盘 5% 都很正常。

**相关词条**：凯利公式（每次下注多少合适）、胜率 vs 赔率、夏普比率（性价比：每承担1份风险换多少收益）
