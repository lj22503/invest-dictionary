# 满仓 / 清仓 / 半仓

> 满仓=手里的钱几乎全买成了股票或基金，清仓=全部卖出回到现金，半仓=一半资产一半现金。

## 1. 这是什么

仓位=你的钱里有多少已经“下场”买了股票或基金。满仓=几乎全部资金都在场内；清仓=全部卖出、回到现金；半仓=一半在场内、一半握现金。

打牌类比：满仓是 All in，清仓是这局不玩，半仓是留一手后手。

> 一句话：仓位就是你把多少身家押在了市场的不确定性上。

## 2. 为什么重要

满仓时跌 20%，总资产就亏 20%；半仓时同样跌 20%，总资产只亏 10%，你还有现金可以补仓或应付生活。

很多人亏钱不是因为选错股票，而是因为永远满仓：下跌时既没钱补仓，又被吓得在底部割肉。

> 一句话：满仓的人没有选择权，手里有现金的人才有主动权。

## 3. 怎么用 / 怎么看

- 第 1 步：先定底线——这笔钱亏多少不影响生活？永远不满仓梭哈，保留至少 10%-20% 应急现金。
- 第 2 步：看市道——牛市趋势中可偏高仓位（7-8 成），震荡市降到半仓左右，熊市或看不懂时宁可轻仓等待。
- 第 3 步：定期校准——每季度问自己一次“如果现在满仓，我睡得着吗？”，睡不着就降一档。

## 4. 常见坑 / 误区

- 坑 1：把“满仓”当勇敢、把“清仓”当踏空：牛市末期满仓最爽也最危险，清仓躲过下跌的人常被嘲笑，但活下来最重要。
- 坑 2：半仓不是“永远半仓”：半仓是动态工具，不是让你无论涨跌都只买一半然后看着踏空。
- 坑 3：用杠杆变相满仓：融资加仓等于“超满仓”，跌 30% 可能直接爆仓出局。
