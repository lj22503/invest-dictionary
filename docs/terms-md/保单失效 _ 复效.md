# 保单失效 / 复效

> 忘交一期保费，保单进入"假死"状态——2 年内能救活，超了就彻底作废。

## 1. 这是什么

**保单失效 = 长期保险过了宽限期还没交保费，保障暂时中断；复效 = 在规定期限内补交保费和利息，把保单救活。**宽限期一般是 60 天，宽限期一过保单就"失效"了。

失效不是立刻退保，而是给了一个"缓刑期"：2 年内可以申请复效，超过 2 年保险公司有权解除合同，保单彻底终止。

> 一句话：忘交保费，保单先"假死"2 年，能救活但会留疤。

## 2. 为什么重要

**失效期间出险，保险公司不赔；复效后，等待期还要重新计算。**这两个点最容易被忽视。

- 失效期保障空白：这期间确诊重疾、发生意外，保险公司一分不赔；
- 复效要重新健康告知：身体一旦出现新问题，可能被拒保、加费或除外责任；
- 复效要补利息：欠的保费要连本带息补上；
- 超 2 年不处理：保单解除，只能拿现金价值，长期险前期现金价值远低于已交保费。

## 3. 怎么用 / 怎么看

- **第一步：设自动扣款**，绑定银行卡并保持余额充足，从源头避免忘记交费；
- **第二步：盯住宽限期**，收到催缴短信别忽略，60 天内补交不影响保障；
- **第三步：已失效想复效**：尽快申请，准备重新健康告知，越早身体越容易过；
- **第四步：评估值不值得救**：年龄变大、身体变差就值得复效；如果产品已过时，可能直接退旧买新更划算。

## 4. 常见坑 / 误区

- 坑1：以为失效=退保，直接不交。其实 2 年内都有机会复效；
- 坑2：失效期间出险找保险公司赔。合同处于中止状态，法律不支持；
- 坑3：复效时隐瞒新病情。复效的健康告知和投保时一样严格，隐瞒照样拒赔；
- 坑4：复效后马上出险。等待期（一般 90-180 天）重新起算，这期间出险不赔。
