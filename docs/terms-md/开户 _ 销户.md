# 开户 / 销户

> 开户是去券商开一个炒股“通行证”，销户是把它注销——开户越来越简单，销户反而藏着不少“舍不得”。

## 1. 这是什么

**一张“股市通行证”的办理与注销**

- **开户＝在证券公司开立证券账户和资金账户**，绑定银行卡后才能买卖 A 股；现在线上几分钟就能开好；
- **销户＝注销证券账户及关联的资金账户**，需清空持仓、转出资金、解除三方存管绑定；
- 一个人最多可在 3 家券商各开 1 个 A 股账户，销户后可再开新的。
> 一句话：开户是办证，销户是退证——办证图方便，退证要手续齐全。

## 2. 为什么重要

**开户是投资的“第一道门”，销户是“最后一笔账”**

- 开户渠道决定你的佣金费率：默认佣金可能千分之几，和客户经理谈或互联网开户能低到万分之几，长期省下的手续费很可观；
- 销户不干净会留下隐患：休眠账户、证券账户与银行卡关联未解绑，可能影响新开户或带来年费/管理费问题；
- “销户”还常被用来给券商“施压”谈费率，是普通投资者少有的议价筹码。
> 一句话：开户选错渠道，等于每月悄悄多交“过路费”；销户办不利索，等于给自己埋雷。

## 3. 怎么用 / 怎么看

- **开户前货比三家**：对比佣金（万几）、融资利率、APP 体验和营业部服务，别只挑“开户礼”大的；
- **准备好身份证和银行卡**：线上开户需视频见证和风险测评，全程 10 分钟上下；
- **销户前清账**：先卖出全部持仓、转出可用资金，再申请销户，通常需临柜或线上办理；
- **确认三方存管解绑**：销户完成后跟银行确认银行卡与证券账户的存管关系已解除；
- **善用“销户谈判”**：如果只是想降佣金，先拿别家费率去谈，谈不拢再考虑真销户。

## 4. 常见坑 / 误区

- **只看佣金不看别的**：佣金便宜但服务差、系统卡，关键时刻影响下单体验；
- **以为销户后账户自动消失**：长期不用的休眠账户仍在券商系统里，可能产生记录甚至被用于“开户数”统计；
- **销户前忘了处理理财/新股**：账户里有理财持仓、打新配额或冻结资金时销户会被卡住；
- **被“销户很麻烦”吓退**：正规券商销户流程有明确规范，故意刁难可打 12386 投诉，别放弃自己的权利。
