# 投资词典首页对齐 mangofolio v1.0 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 dictionary 首页 + 446 个详情页 + cron 模板压成 mangofolio v1.0 体系（全站 0 朱砂红、纯白底、芒果橙作电压色、Noto Serif SC + Fraunces 字体、16px 白卡 + 9999px 胶囊按钮），并修 `term-page-regular.html` 防止 cron 继续生成老体系词条。

**Architecture:**
- 引入 `mangofolio-tokens-v09.css`（OPC OS 现成 523 变量）作为全站令牌源，所有颜色/字体/圆角通过 `var(--mf-*)` 引用
- 改 `web/index.html` + `skill/.../templates/term-page-regular.html` + `skill/.../templates/term-page.html` 三份源
- 446 个 `web/terms/*.html` 用 sed 批量 sed 替换（先抽 1 页验证）
- 三波推进：Wave 1 色系主线 → Wave 2 字体圆角 footer → Wave 3 暗色 + 语义色

**Tech Stack:** 纯静态 HTML/CSS、PowerShell（sed 批量）、Google Fonts（Inter / Noto Serif SC / Fraunces）、Vercel 自动部署

**Spec:** `docs/superpowers/specs/2026-09-19-homepage-v1-design.md`（commit `3cb827b`）

## Global Constraints

- **页面底色 = 纯白 `#FFFFFF`**（v1.0 第 1.3 节"默认全站纯白"，宣纸 `#F5F2EC` / 羊皮纸 `#f5efe0` 严禁）
- **朱砂红 `#C43A31` 严禁使用**（v1.0 第 3.3 节，全站 grep 0 残留）
- **主色芒果橙 `#F97316` 电压色**（v1.0 第 3.1.1 节，占页面 ≤5%，只作 CTA / 链接 / 图标 / 焦点 / Logo）
- **正文 `#3A332C` 暖墨**（v1.0 第 3.2.2 节，对比度 ≥7:1）
- **字体链必须含** `"Segoe UI Emoji", "Apple Color Emoji", "Noto Color Emoji"` 三段（CLAUDE.md 09-17 错误避坑）
- **字体链必须移除** `"KaiTi", "STKaiti", "FangSong", "STFangsong"` 四段楷体仿宋（Windows 回退不一致）
- **H1 走 Noto Serif SC**、**en-title 走 Fraunces italic 橙**、**body 走 Inter**
- **卡面 16px 圆角 + 暖墨边**（v1.0 第 7.3 节）、**按钮 9999px 胶囊**（v1.0 第 7.2 节）
- **主按钮橙投影** `0 8px 20px rgba(249,115,22,.22)`（v1.0 第 5.3 节）
- **commit message 格式**：`dictionary: brand align v1.0 wave N · <task>`（AGENTS.md 提交前自查 4 问）
- **Git 操作 PowerShell 执行**（CLAUDE.md 2026-06-11 错误避坑）
- **Git push 用 SSH 443**（CLAUDE.md `ssh-22-blocked-use-443`）
- **每次 commit 前跑** `git status` + `git diff --stat` 自查（CLAUDE.md 2026-08-04 staged 未提交错误避坑）

```powershell
$patterns = @{
  '#C43A31' = '#F97316'
  '#c43a31' = '#F97316'
  '#A33028' = '#E05E0A'
  '#a92e26' = '#E05E0A'
  '#F5F2EC' = '#FFFFFF'
  '#f5efe0' = '#FFFFFF'
  '#faf6ee' = '#FFFFFF'
  '#2C2C2C' = '#3A332C'
  '#3a3a3a' = '#3A332C'
  '#5A5A5A' = '#8A7D70'
  '#5a4a3a' = '#8A7D70'
  '#D9D4CC' = 'rgba(36,22,16,0.10)'
  '#c4b5a0' = 'rgba(36,22,16,0.10)'
  'meta name="theme-color" content="#c43a31"' = 'meta name="theme-color" content="#F97316"'
}

Get-ChildItem "web\terms\*.html" -Exclude "*.bak-*" | ForEach-Object {
  $f = $_.FullName
  $content = Get-Content $f -Raw
  foreach ($p in $patterns.GetEnumerator()) {
    $content = $content -replace [regex]::Escape($p.Key), $p.Value
  }
  Set-Content -Path $f -Value $content -NoNewline -Encoding UTF8
}
```

### Task 15: 暗色模式按钮 + localStorage 持久化

**Files:**

- [ ] **Step 1: 创建 web/js/dark-mode.js**

```javascript
(function() {
  'use strict';

  const STORAGE_KEY = 'mf-color-mode';

  function getStored() {
    try { return localStorage.getItem(STORAGE_KEY); } catch(e) { return null; }
  }

  function setStored(mode) {
    try { localStorage.setItem(STORAGE_KEY, mode); } catch(e) {}
  }

  function apply(mode) {
    const root = document.documentElement;
    if (mode === 'dark') {
      root.setAttribute('data-color-mode', 'dark');
    } else {
      root.removeAttribute('data-color-mode');
    }
    updateButton(mode);
  }

  function updateButton(mode) {
    const btn = document.getElementById('darkModeToggle');
    if (!btn) return;
    btn.textContent = mode === 'dark' ? '☀' : '☾';
    btn.setAttribute('aria-label', mode === 'dark' ? '切换到浅色模式' : '切换到深色模式');
  }

  function init() {
    const stored = getStored();
    const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
    const mode = stored || (prefersDark ? 'dark' : 'light');
    apply(mode);

    const btn = document.getElementById('darkModeToggle');
    if (btn) {
      btn.addEventListener('click', function() {
        const current = document.documentElement.getAttribute('data-color-mode') === 'dark' ? 'dark' : 'light';
        const next = current === 'dark' ? 'light' : 'dark';
        apply(next);
        setStored(next);
      });
    }
  }

  if (document.readyState === 'loading') {
    document.addEventListener('DOMContentLoaded', init);
  } else {
    init();
  }
})();
```
