# 三页改版设计规格（首页 / 全部词条 / 使用指南）

> 2026-10-29 · M2 网站改造 · 本文件是三页共用的唯一设计口径，改页面前先读它。

## 0. 一句话

把 brain.mangofolio.com 的**分块节奏**（一屏一色带）搬过来，但**颜色和字体全部用本项目自己的 mangofolio 令牌**；betterment 参考包只借模块结构，不借它的蓝/金/青/紫。

## 1. 现存问题（排查结论）

| # | 页面 | 问题 | 后果 |
|---|---|---|---|
| 1 | 首页 | 六屏全是纯白底，只靠 1px 分隔线区分 | 用户看不出「一块内容」的边界，滚到底像一张长白纸 |
| 2 | 首页 | 7 张场景卡直接用 Betterment 原始色板（蓝 #1d6ae5 / 紫 / 金 / 青 / 红 / 藏蓝）+ 引入 `web/css/betterment-tokens.css` | 外来色板与芒果橙品牌冲突；令牌文件还是 untracked，别人 clone 后样式直接崩 |
| 3 | 首页 | 场景卡横向滚动条，1440px 下只能看到 5 张，没有「还有 2 张」的提示 | 7 个 Skill 有 2 个等于没展示 |
| 4 | 首页 | 热词卡片孤零零浮在大白区里，左右无内容 | 视觉重心散，页面中段空 |

## 2. 色带体系（每块内容一个底色，全部来自本项目的 mangofolio 令牌）

| 用途 | 类名 | 取值 | 来源令牌 |
|---|---|---|---|
| 基础底（首屏 / 内容带） | `.band--base` | `#FFFFFF` | `--mf-colors-background` |
| 中性纸底（热词 / 目录侧栏 / 页脚） | `.band--paper` | `#F7F5F2` | `--mf-colors-background-neutral` |
| 芒果浅底（场景主推带 / 页头） | `.band--mango` | `#FFF3EA` | `--mf-colors-primitives-mango-050` |
| 暖灰底（步骤 / 工具条） | `.band--grey` | `#EDE9E4` | `--mf-colors-primitives-grey-200` |
| 墨底（初心/边界，唯一深色带，全站只出现 1 次） | `.band--dark` | `#241610` | `--mf-colors-background-abyss` |

规则：
- 相邻两带**必须不同色**；深色带一页最多 1 个，且不放在首屏。
- 色带内文字色由 `.band` 上的局部变量 `--band-ink / --band-ink-weak / --band-line / --band-surface` 决定，组件只引用变量，不写死颜色。
- 强调色只有芒果橙（`--mf-colors-text-link`），**每页占比 ≤5%**：只用于 CTA、链接、序号、焦点态。
- 涨红 / 跌绿只做语义色（`--mf-colors-text-critical` / `--mf-colors-text-success`），不当装饰。

## 3. 字体与字号（令牌里已有的，不新增字体）

- 标题：`--mf-fonts-display`（Noto Serif SC）900
- 英文副题：`--mf-fonts-display-extended`（Fraunces italic）
- 正文 / UI：`--mf-fonts-ui`（Inter + PingFang）
- 字号阶梯：区块标题 `clamp(1.6rem,3vw,2.2rem)` / 卡片标题 1.05-1.15rem / 正文 0.95rem / 辅助 0.82-0.88rem / 序号大字 2.25rem
- 行宽：正文 ≤ 68ch

## 5. 共用件（`web/css/site.css`，三个页面都引，改一次三页生效）

页面自己的样式写在自己 `<style>` 里，**不要**再复制 header/footer。

## 6. 硬规则（评审会打回的点）

1. 不引外来色板：`web/css/betterment-tokens.css` 已移到 `docs/reference/`，三页都只引 `mangofolio-tokens-v09.css` + `site.css`。
2. 不写死颜色：颜色一律 `var(--mf-...)` 或色带局部变量。
3. 不用渐变文字、不用左侧 3px 彩条、不用大圆角（卡片 ≤16px）、不用 1px 描边叠大阴影（阴影 ≤8px 模糊）。
4. 区块标题不套「小大写眉题 + 居中」模板：三页统一左对齐区块头 + 一条 hairline。
5. 正文对比度 ≥4.5:1；弱文字只用来放辅助信息，不放正文句子。
6. 每个动画都要有 `@media (prefers-reduced-motion: reduce)` 兜底。
7. 移动端 390px 宽不横向溢出、不出现被裁的卡片。
8. 功能一个都不能丢：搜索、热词滚动/点击、邮箱订阅、7 个 Skill 弹窗复制、章节筛选、随机一词、埋点 `js/tracker.js`、PWA `manifest.json`。
