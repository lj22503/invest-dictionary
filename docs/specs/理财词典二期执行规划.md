### 3.1 每个 SKILL.md 的统一结构（已全部落地）

frontmatter（name / description 含触发词 / version / license）+ 角色 / 输入 / 处理流程 / 输出结构 / 质量红线 / 示例 / 触发方式 + 「适用场景 / 不适用场景」边界表 + 合规声明"以上为概念梳理与提问参考，不构成投资建议"。

### 3.2 Skill 适用 / 不适用边界（已写入每个 SKILL.md）

| Skill | 适用 | 不适用（关键） | 越界后果 |
|---|---|---|---|
| 理财急诊 | 用户带具体困惑来（亏了/被推荐/要不要买） | 伪命题问题、个性化资产诊断 | 被当成"投资诊断" |
| 新闻翻译机 | 有信息量的内容（数据/事件/政策/财报） | 碎片结论、实时行情预测、要买卖建议 | 硬串出不存在因果，被当"荐股" |
| 二选一擂台 | 同一决策层级的真二选一 | 跨层级对比（黄金 vs 国债）、收益率承诺 | 硬比出错误结论，越界成"投资建议" |
| 决策拆解桌 | 单边决策拆变量 | 非财务因素为主（离婚/生育）、敏感财务数据、时效性决策 | 硬套模板变"算命"，索敏感数据 |
| 防坑提问器 | 验证产品靠不靠谱 | 产品好坏定性、具体公司负面定性 | 被当"诋毁产品" |

一句话原则：只做"帮用户想清楚"，不做"替用户做决定"。
