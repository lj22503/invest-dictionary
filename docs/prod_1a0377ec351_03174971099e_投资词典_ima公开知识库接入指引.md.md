# 投资词典 → ima 公开知识库 · Agent 执行指引

> 目标：把 12 个批次的词条清单（markdown）自动上传至 ima 知识库，并发布为公开知识库。
> 依据：腾讯 ima 官方 OpenAPI（ima.qq.com）+ 官方 IMA Skills 接入包 + ima 客户端公开发布能力。
> 适用范围：任意 Agent / 脚本可照此 SOP 自动执行；仅"生成 API Key"与"开启公开广场发布"两步需人工一次。

---

## 一、一次性人工准备（约 5 分钟，仅做一次）

### 1. 下载官方 IMA Skills 接入包
- 地址：`https://app-dl.ima.qq.com/skills/ima-skills-1.1.2.zip`
- 解压后关键文件：
  - `ima-skill/knowledge-base/scripts/cos-upload.cjs`（COS 直传脚本）
  - `ima-skill/knowledge-base/scripts/preflight-check.cjs`（上传前校验，可选）

### 2. 生成 API 凭证（ClientID + APIKey）
- 打开 ima 客户端（PC 端功能最全）→ 进入「灵感」/「设置 → 开放平台（OpenAPI）」入口
- 点击生成 API Key：会同时给出 **ClientID** 与 **APIKey**
- 注意：**APIKey 只显示一次**，必须立即保存；丢失只能撤销后重新生成
- 凭证保存位置（推荐）：`~/.config/ima/` 下的环境变量或配置文件，勿写入仓库

### 3. 创建/确认知识库并获取 knowledge_base_id
- 方式 A（推荐，可自动）：调用「获取知识库列表」接口查询已有知识库 ID
  - `GET https://ima.qq.com/openapi/wiki/v1/list_knowledge_base`（以实际技能包内脚本为准）
- 方式 B（手动）：客户端新建知识库「投资词典」，进入知识库信息页复制 ID
- 记录：`knowledge_base_id = kb_xxxx`

> 至此人工部分结束。后续全部由 Agent 自动执行。

## 二、Agent 自动执行：上传文件到知识库

### 认证方式（所有请求必带 Header）
```
ima-openapi-clientid: <你的ClientID>
ima-openapi-apikey: <你的APIKey>
Content-Type: application/json
```

### 流程：每个文件走三步（create_media → COS 直传 → add_knowledge）

#### Step 1 · 获取 COS 上传凭证
```
POST https://ima.qq.com/openapi/wiki/v1/create_media
{
  "file_name": "投资词典_扩充词条清单v3_批次1-6.md",
  "file_size": 12139,              # 字节数，先 stat 取
  "content_type": "text/markdown",
  "knowledge_base_id": "kb_xxxx",
  "file_ext": "md"
}
```
返回：`media_id` + `cos_credential`（含 secret_id / secret_key / token / bucket / region / cos_key / start_time / expired_time）

#### Step 2 · 用官方脚本直传 COS（推荐，避免手写签名）
```
node ima-skill/knowledge-base/scripts/cos-upload.cjs \
  --file "本地文件绝对路径.md" \
  --secret-id "<返回的secret_id>" \
  --secret-key "<返回的secret_key>" \
  --token "<返回的token>" \
  --bucket "<返回的bucket_name>" \
  --region "<返回的region>" \
  --cos-key "<返回的cos_key>" \
  --content-type "text/markdown" \
  --start-time "<返回的start_time>" \
  --expired-time "<返回的expired_time>"
```
成功标志：`Upload successful (HTTP 200)`

#### Step 3 · 登记到知识库
```
POST https://ima.qq.com/openapi/wiki/v1/add_knowledge
{
  "media_type": 7,                 # 7=文件
  "media_id": "<Step1返回的media_id>",
  "title": "投资词典_扩充词条清单v3_批次1-6",
  "knowledge_base_id": "kb_xxxx",
  "folder_id": "",                 # 省略则进根目录；建议建"词条清单"文件夹
  "file_info": {
    "cos_key": "<Step1返回的cos_key>",
    "file_size": 12139,
    "last_modify_time": 1784851200,
    "file_name": "投资词典_扩充词条清单v3_批次1-6.md"
  }
}
```
成功标志：返回 `media_id` / 知识条目 ID，客户端知识库可见该文件。

> 变量说明：`cos_key`、`file_size`、`last_modify_time` 与 Step1 保持一致；`file_name` 为展示名。

## 三、批量上传清单（12 个批次文件）

按批次逐个执行「二、」三步，每批完成后核对：

| 顺序 | 文件 | 建议标题 | 说明 |
|---|---|---|---|
| 1 | 投资词典_扩充词条清单v3_批次1-6.md | 批次1-6 词条清单 | 也可按批次拆成 12 个文件更利于知识库检索 |
| 2 | 投资词典_扩充词条清单v3_批次7-12.md | 批次7-12 词条清单 | 同上 |

建议：若追求知识库内可分段问答，可在上传前把两个大文件按批次拆成 12 个小文件（每批一个 md），标题如「投资词典_批次01_钱的本质与个人财务」。拆分脚本放入 temp 目录，产物放入 output。

## 四、公开发布（最后一步，需人工 30 秒）

ima OpenAPI 目前**未开放"发布到广场"端点**，最后一步必须在客户端手动完成：

1. 打开 ima 客户端 → 进入「投资词典」知识库
2. 知识库信息/设置 → 权限设置 → 选择 **「公开发布」**
3. 开启后，其他用户可通过 ima「发现」广场搜索到该知识库并加入
4. （可选）申请「知识号」获取数据分析：加入人数、访问量、问答趋势

> 权限三态说明：
> - **公开发布**：广场可搜可加入，不占个人空间（推荐本场景）
> - **分享可见**：仅链接/二维码分享，占个人空间
> - **私密**：仅自己可见

## 六、常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 404 | API 路径写错或版本不符 | 以技能包内 `ima_api.cjs` 的端点为准 |
| COS 签名失败 | secret/token/bucket 与 create_media 返回不一致 | 严格透传 Step1 返回值，勿手改 |
| 中文乱码 | 文件非 UTF-8 | 上传前强制转 UTF-8；本批 md 均为 UTF-8 |
| 上传后搜不到内容 | 文件仍在解析索引 | 等待 15-30 秒（100 页 PDF 级）后重查 |
| APIKey 丢失 | 一次性展示 | 撤销后重新生成，更新环境变量 |
| 视频/B站链接 | OpenAPI 不支持 | 改用 ima 桌面端手动添加 |

## 七、Agent 执行最小检查单（每批）

1. `stat` 取文件字节数与 mtime
2. 调用 create_media → 校验返回含 media_id / cos_credential
3. 调用 cos-upload.cjs → 校验 HTTP 200
4. 调用 add_knowledge → 校验成功返回
5. 记录 media_id 到 temp 日志，最后汇总核对
