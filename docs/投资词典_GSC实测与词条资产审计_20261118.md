## 三、五个真问题（按影响排序）

### 问题 1｜内容形态和搜索意图错位（最根本）

用户搜「货币是什么意思」，想要的是**一句定义 + 几个要点**。现在词条页给的是 4 张故事卡片（「你手里攥着的100块」「100万亿买半个面板」……），叙事很好读，但定义被藏起来了。

后果有两层：搜索摘要把不准，点击率吃亏；就算点进来，找定义的人发现要读完故事，直接退出。Vercel 那边 **跳出率 80%**，和这个结构是自洽的。

**改法（不用推翻现有风格）**：在页面最顶部、故事卡之前，加一个 60–90 字的「一句话定义 + 3 条要点」区块。故事卡全部保留，往下排。这样搜索和阅读两头都照顾到。

### 问题 2｜标题模板化过重

94% 的标题是同一个句式「X是什么意思？小白也能看懂的理财术语解释 - 投资词典」。

问题不是句式本身，而是**后缀对排名零贡献，却吃掉了标题长度预算**。1140 页同一个后缀，也是程序化内容的典型特征。另有 68 条标题完全没有问句（多是每日热词新加的裸词标题，如「买断式逆回购」「黄金价格」），风格不统一。

**改法**：把后缀换成该词真实的下半截搜索意图。比如「最大回撤」→「最大回撤是什么意思？跌多少算大，怎么看」；裸词标题补齐为问句形态。

### 问题 3｜描述不进词条名，等于放弃摘要控制权

681 条（60%）的 description 里连词条本身都不出现。现在的描述是故事片段，比如最大回撤那条写的是「你投10万，最惨只剩4万5……」

这种写法在搜索结果里，Google 大概率重写摘要，等于把点击率的控制权交出去。

**改法**：统一成「X 是指……。三个要点：①…… ②…… ③……」的结构，60–80 字，词条名必须出现。

### 问题 4｜顺序导航断裂，118 条词条拿不到任何站内入链（已修复）

上一篇/下一篇的导航本来就存在，但链路是断的：43 个页面完全没有这个导航，523 个页面的指向和词条顺序不一致（`next` 字段有断点，有些词条谁都不指向它）。结果是修复前有 **118 条词条零入链**——被收录也没人给它传权重。

**已做（2026-11-18 完成并上线）**：按 `dictionary.json` 顺序重建全站 pager，覆盖 1141/1141；同时修掉 78 处关联词条锚文本的 slug 残留（「零钱通 _ 余额宝」→「零钱通 / 余额宝」，下划线锚文本对关键词匹配是负分）。

修复后：零入链词条 **118 → 0**；每页恰好一个 pager；785 条词条入链达 3 条以上。相关词条仍只有 129 条为空（这部分要人工判断相关性，不适合机器补）。

### 问题 5｜86% 正文偏薄

975 条正文在 1500 字以下。注意：**不要无脑灌字数**，那是踩「低价值内容」的坑。要补的是用户真会追问的东西——怎么算、举个自己的例子、和相近词的区别、常见误区。
